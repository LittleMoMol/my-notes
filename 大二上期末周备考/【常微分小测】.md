# 小测 1
1. 解微分方程 $\dfrac{\mathrm dy}{\mathrm dx} = \dfrac{2x-y+1}{x-2y+1}$ 
2. 解微分方程 $\dfrac{\mathrm dx}{\mathrm dt} + 3x = e^{2t}$ 
3. 验证 $(x^2+y)\mathrm dx + (x-2y)\mathrm dy = 0$ 为恰当微分方程，并用恰当微分方程的判定求解
4. 验证 $(y-3x^2)\mathrm dx + (4y-x)\mathrm dy = 0$ 为恰当微分方程，并用第二类曲线积分积分求解
5. 验证 $\left( \dfrac 1y\sin\dfrac xy - \dfrac y{x^2}\cos\dfrac yx + 1 \right)\mathrm dx + \left( \dfrac 1x\cos\dfrac yx - \dfrac x{y^2}\sin\dfrac xy + \dfrac 1{y^2} \right)\mathrm dy = 0$ 为恰当微分方程，并用配凑法求解
6. 求初值问题 $\begin{cases} \dfrac{\mathrm dy}{\mathrm dx} = x^2-y^2,\ R:|x+1|\le 1,\ |y|\le 1 \\ y(-1)=0 \end{cases}$ 的解的存在区间，并求第二次近似解，给出在解的存在区间的误差估计
# 小测 2
1. 求方程 $\dfrac{\mathrm dy}{\mathrm dx} = x+y^2$ 通过点 $(0,0)$ 的第三次近似解
2. 解方程 $xy'^3 = 1+y'$ 和 $y'^3 - x^3(1-y')=0$ 
3. 解方程 $x''=\dfrac 1{2x'}$ 和 $xx'' - (x')^2 + (x')^3 = 0$，自变量均为 $t$ 
4. 用幂级数解法求解方程 $x''+tx'+x=0,\ x(0)=0,\ x'(0)=1$ 
5. 求非次线性微分方程 $t^2x''-4tx'+6x=36\dfrac{\ln t}t$ 的通解（已知对应的齐次线性微分方程的基本解组为 $x_1=t^2,\ x_2=t^3$）
6. 利用快速方法求常系数线性微分方程 $x''+2x'+5x=4e^{-t}+17\sin{2t}$ 的通解
