# 小测 1
1. 对函数 $f(x,y)=\sin x\cos y$ 应用中值定理证明：存在 $\theta\in(0,1)$，使得 $\dfrac 34 = \dfrac \pi 3 \cos\dfrac{\pi\theta}3 \cos\dfrac{\pi\theta}6 - \dfrac\pi 6\sin\dfrac{\pi\theta}3 \sin\dfrac{\pi\theta}6$ 
2. 求函数 $f(x,y) = \sin x + \sin y - \sin(x+y)$ 在闭区域 $D=\{(x,y) \mid x\ge 0, y\ge 0, x+y\le 2\pi\}$ 上的最大值与最小值
3. 求函数 $f(x,y,z)=x^ay^bz^c\ (x>0,y>0,z>0)$ 在约束条件 $x^k+y^k+z^k=1$ 下的极大值，其中 $k,a,b,c$ 均为正常数；并证明：对任何正数 $u,v,w$ 成立不等式 $\left( \dfrac ua \right)^a \left( \dfrac vb \right)^b \left(\dfrac wc\right)^c \le \left( \dfrac{u+v+w}{a+b+c} \right)^{a+b+c}$ 
4. 证明：$\displaystyle\int_{-\infty}^{+\infty} e^{-x^2}\mathrm dx = \pi^{\frac 12}$ 
5. 改变重积分的积分次序 $\displaystyle \int_0^{2\pi}\mathrm dx \int_0^{\sin x} f(x,y)\mathrm dy$ 
6. 判别反常重积分 $\displaystyle I = \iint\limits_{\mathbb R^2} \dfrac{\mathrm dx\mathrm dy}{(1+x^2)(1+y^2)}$ 是否收敛。如果收敛，求其值
