# 线性
**$n$ 阶线性微分方程**：若方程 $F\left( x, y, \dfrac{\mathrm dy}{\mathrm dx}, \cdots, \dfrac{\mathrm d^n y}{\mathrm dx^n} \right) = 0$ 的左端为 $y, \dfrac{\mathrm dy}{\mathrm dx}, \cdots, \dfrac{\mathrm d^ny}{\mathrm dx^n}$ 的一次有理整式，则称其为 **$n$ 阶线性微分方程** 
$n$ 阶线性微分方程的一般形式为 $\dfrac{\mathrm d^n y}{\mathrm dx^n} + a_1(x)\dfrac{\mathrm d^{n-1}y}{\mathrm dx^{n-1}} + \cdots + a_{n-1}(x) \dfrac{\mathrm dy}{\mathrm dx} + a_n(x)y = f(x)$，其中 $a_1(x), \cdots, a_n(x), f(x)$ 为 $x$ 的已知函数
# 一些特殊的方程
- **伯努利（Bernoulli）微分方程**：$\dfrac{\mathrm dy}{\mathrm dx} = P(x)y + Q(x)y^n,\ (n\not=0, 1,\ n\in \mathbb R)$，其中 $P(x), Q(x)$ 在考虑的区间上是 $x$ 的连续函数
- **克莱罗（Clairaut）微分方程**：形如 $y=xp+f(p)$ 的方程，称为**克莱罗（Clairaut）微分方程**，这里 $p=\dfrac{\mathrm dy}{\mathrm dx}$，$f(p)$ 是 $p$ 的连续可微函数
# 变量代换
形如 $\dfrac{\mathrm dy}{\mathrm dx} = f\left( \dfrac{a_1x+b_1y+c_1}{a_2x+b_2y+c_2} \right)$，这里 $a_1,a_2,b_1,b_2,c_1,c_2$ 均为常数
- 当 $c_1=c_2=0$ 时，$\dfrac{\mathrm dy}{\mathrm dx} = f\left( \dfrac{a_1 + b_1\dfrac yx}{a_2 + b_2\dfrac yx} \right) = g\left( \dfrac yx \right)$ 为齐次微分方程，化为情形 1
- 当 $c_1, c_2$ 不全为零时
	1. $\begin{vmatrix} a_1 & b_1 \\ a_2 & b_2 \end{vmatrix} \not= 0$ 时，方程组 $\begin{cases} a_1x+b_1y+c_1=0 \\ a_2x+b_2y+c_2=0 \end{cases}$ 有唯一解 $\begin{cases} x = \alpha \\ y=\beta \end{cases}$ 
		令 $\begin{cases} X = x-\alpha \\ Y = y-\beta \end{cases}$，则 $\dfrac{\mathrm dy}{\mathrm dx} = f\left( \dfrac{a_1x+b_1y+c_1}{a_2x+b_2y+c_2} \right)$ 化为 $\dfrac{\mathrm dY}{\mathrm dX} = f\left( \dfrac{a_1 + b_1\dfrac YX}{a_2 + b_2 \dfrac YX} \right) = g\left( \dfrac YX \right)$ 
		化为齐次微分方程的情形
	2. $\begin{vmatrix} a_1 & b_1 \\ a_2 & b_2 \end{vmatrix} = 0$ 时
		(1) $a_1=b_1=0$ 时，$\dfrac{\mathrm dy}{\mathrm dx} = f\left( \dfrac{a_1x+b_1y+c_1}{a_2x+b_2y+c_2} \right)$ 变为 $\dfrac{\mathrm dy}{\mathrm dx} = f\left( \dfrac{c_1}{a_2x+b_2y+c_2} \right)$；$a_2=b_2=0$ 时，$\dfrac{\mathrm dy}{\mathrm dx} = f\left( \dfrac{a_1x+b_1y+c_1}{a_2x+b_2y+c_2} \right)$ 变为 $\dfrac{\mathrm dy}{\mathrm dx} = f\left( \dfrac{a_1x+b_1y+c_1}{c_2} \right)$，化为情形 2
		(2) $b_1=b_2=0$ 时，$\dfrac{\mathrm dy}{\mathrm dx} = f\left( \dfrac{a_1x+b_1y+c_1}{a_2x+b_2y+c_2} \right)$ 变为 $\dfrac{\mathrm dy}{\mathrm dx} = f\left( \dfrac{a_1x+c_1}{a_2x+c_2} \right)$；$a_1=a_2=0$ 时，$\dfrac{\mathrm dy}{\mathrm dx} = f\left( \dfrac{a_1x+b_1y+c_1}{a_2x+b_2y+c_2} \right)$ 变为 $\dfrac{\mathrm dy}{\mathrm dx} = f\left( \dfrac{b_1y+c_1}{b_2y+c_2} \right)$，化为**变量分离方程** 
		(3) $\dfrac{a_1}{a_2} = \dfrac{b_1}{b_2}=k$ 时，令 $u=a_2x+b_2y$，此时 $\dfrac{\mathrm du}{\mathrm dx} = a_2 + b_2 \dfrac{\mathrm dy}{\mathrm dx}$，$f\left( \dfrac{a_1x+b_1y+c_1}{a_2x+b_2y+c_2} \right) = f\left( \dfrac{k(a_2x+b_2y)+c_1}{(a_2x+b_2y)+c_2} \right) = f\left( \dfrac{ku+c_1}{u+c_2} \right) = g(u)$，故 $\dfrac{\mathrm dy}{\mathrm dx} = f\left( \dfrac{a_1x+b_1y+c_1}{a_2x+b_2y+c_2} \right)$ 化为 $\dfrac{\mathrm du}{\mathrm dx} = a_2+b_2g(u)$，化为**变量分离方程** 
# 积分因子
函数 $\mu(x,y)\not=0$ 为方程 $M(x,y)\mathrm dx + N(x,y)\mathrm dy = 0$ 的积分因子 $\iff$ $\dfrac{\partial(\mu M)}{\partial y} = \dfrac{\partial(\mu N)}{\partial x}$ $\iff$ $N\dfrac{\partial \mu}{\partial x} - M \dfrac{\partial \mu}{\partial y} = \left( \dfrac{\partial M}{\partial y} - \dfrac{\partial N}{\partial x} \right)\mu$ 
若 $M(x,y)\mathrm dx + N(x,y)\mathrm dy = 0$ 存在只与 $x$ 有关的积分因子 $\mu=\mu(x)$ 
则其充要条件为 $\dfrac{\dfrac{\partial M}{\partial y} - \dfrac{\partial N}{\partial x}}{N} = \psi(x)$，解得 $\mu(x) = e^{\int \psi(x)\mathrm dx}$ 
若 $M(x,y)\mathrm dx + N(x,y)\mathrm dy = 0$ 存在只与 $y$ 有关的积分因子 $\mu=\mu(y)$ 
则其充要条件为 $\dfrac{\dfrac{\partial M}{\partial y} - \dfrac{\partial N}{\partial x}}{-M} = \varphi(y)$，解得 $\mu(y) = e^{\int \varphi(y)\mathrm dy}$ 
# 逐步逼近法
**利普希茨（Lipschitz）条件**、**利普希茨常数**：考虑导数已解出的一阶微分方程 $\dfrac{\mathrm dy}{\mathrm dx} = f(x,y)$，这里 $f(x,y)$ 是在矩形域 $R: |x-x_0| \le a,\ |y-y_0| \le b$ 上的连续函数。函数 $f(x,y)$ 称为在 $R$ 上关于 $y$ 满足**利普希茨（Lipschitz）条件**，如果存在常数 $L>0$，使得不等式 $|f(x,y_1) - f(x,y_2)| \le L |y_1-y_2|$ 对于所有 $(x,y_1), (x,y_2) \in R$ 都成立，$L$ 称为**利普希茨常数** 
**解的存在唯一性定理**：如果 $f(x,y)$ 在矩形域 $R$ 上连续且关于 $y$ 满足利普希茨条件，则方程 $\dfrac{\mathrm dy}{\mathrm dx} = f(x,y)$ 存在唯一的解 $y=\varphi(x)$，定义于 $|x-x_0|\le h$ 上，连续且满足初值条件 $\varphi(x_0) = y_0$，这里 $h = \min \left( a, \dfrac bM \right),\ M = \max\limits_{(x,y)\in R} |f(x,y)|$ 
第 $n$ 次近似解 $\varphi_n(x)$ 和真正解 $\varphi(x)$ 在 $|x-x_0|\le h$ 内的误差估计式 $|\varphi_n(x) - \varphi(x)| \le \dfrac{ML^n}{(n+1)!}h^{n+1}$ 
# 解高阶微分方程的一些符号重现
$\begin{cases} c_1'(t)x_1(t) + c_2'(t)x_2(t) + \cdots + c_n'(t)x_n(t) = 0 \\ c_1'(t)x_1'(t) + c_2'(t)x_2'(t) + \cdots + c_n'(t)x_n'(t)=0 \\ \cdots \\ x_1^{(n-2)}(t)c_1'(t) + x_2^{(n-2)}(t)c_2'(t) + \cdots + x_n^{(n-2)}(t)c_n'(t) = 0 \\ x_1^{(n-1)}(t)c_1'(t) + x_2^{(n-1)}(t)c_2'(t) + \cdots + x_n^{(n-1)}(t)c_n'(t) = f(t) \end{cases}$ 
$f(t) = (b_0t^m + b_1t^{m-1} + \cdots + b_{m-1}t + b_m)e^{\lambda_0 t}$ 特解为 $\widetilde x = t^{k_0}(B_0t^m + B_1t^{m-1} + \cdots + B_{m-1}t + B_m)e^{\lambda_0 t}$ 
$f(t) = [A(t)\cos\beta t + B(t)\sin\beta t]e^{\alpha t}$ 特解为 $\widetilde x = t^{k_0} [P(t)\cos\beta t + Q(t)\sin\beta t]e^{\alpha t}$ 
# 降阶法
- 不显含未知函数 $x$，或更一般地，设方程不含 $x,x',\cdots,x^{(k-1)}$，即方程形如 $F(t,x^{(k)}, x^{(k+1)}, \cdots, x^{(n)}) = 0\ (1\le k\le n)$ 
	- 做变换 $x^{(k)}(t)=y(t)$，等价于求解方程 $F(t,y,y', \cdots, y^{(n-k)})=0$，即可降 $k$ 阶
- **第二类**：不显含自变量 $t$ 的方程 $F(x, x', \cdots, x^{(n)})=0$ 
	- 做变换 $x'(t)=y(t)$ 
	- $x^{(k)}$ 可用 $y,\dfrac{\mathrm dy}{\mathrm dx}, \cdots, \dfrac{\mathrm d^{k-1}y}{\mathrm dx^{k-1}}$ 表示 $(k\le n)$ 
	- 等将于求解方程 $G\left( x,y,\dfrac{\mathrm dy}{\mathrm dx}, \cdots, \dfrac{\mathrm d^{n-1}y}{\mathrm dx^{n-1}} \right) = 0$，$x$ 为自变量，$y$ 为函数，即可降 $1$ 阶
- **第三类**：齐次线性微分方程 $\dfrac{\mathrm d^nx}{\mathrm dt^n} + a_1(t) \dfrac{\mathrm d^{n-1}x}{\mathrm dt^{n-1}} + \cdots + a_{n-1}(t) \dfrac{\mathrm dx}{\mathrm dt} + a_n(t)x = 0$，且已知 $k$ 个线性无关解 $x_1,x_2,\cdots,x_k$ 
	- **方法一**：做变换 $z = \left( \dfrac{x}{x_k(t)} \right)'$，原方程可化为 $z^{(n-1)} + b_1(t)z^{(n-2)} + \cdots + b_{n-1}(t)z=0$（这样算计算量会比较大）
	- **方法二**：令 $x=x_ky$，两边求多次导并代入原方程，可证明 $y$ 前系数必为零，然后令 $z=y'$ 即可降阶
	- 按照上述过程仍可降阶，总共可降 $k$ 阶
# 解一阶微分方程组的一些符号重现
- $\displaystyle \boldsymbol\varphi(t) = \boldsymbol\varPhi(t)\boldsymbol\varPhi^{-1}(t_0)\boldsymbol\eta + \boldsymbol\varPhi(t)\int_{t_0}^t \boldsymbol\varPhi^{-1}(s)\boldsymbol f(s)\mathrm ds$ 
- **$n$ 阶非齐次线性微分方程的常数变易公式**：$x^{(n)} + a_1(t)x^{(n-1)} + \cdots + a_n(t)x = f(t)$ 的满足初值条件 $\varphi(t_0) = 0,\ \varphi'(t_0) = 0, \cdots, \varphi^{(n-1)}(t_0) = 0,\ t_0\in [a,b]$ 的解由**常数变易公式** $\displaystyle \varphi(t) = \sum_{k=1}^n x_k(t) \int_{t_0}^t \dfrac{W_k[x_1(s), x_2(s), \cdots, x_n(s)]}{W[x_1(s), x_2(s), \cdots, x_n(s)]} f(s)\mathrm ds$ 给出
- 求基解矩阵时：
	- 若 $\boldsymbol x' = \boldsymbol A\boldsymbol x$ 的矩阵 $\boldsymbol A$ 只有一个特征值 $\lambda$ 时（其重数显然为 $n$）:
		- $\exp\boldsymbol At = e^{\lambda t}\exp(\boldsymbol A - \lambda\boldsymbol E)t = e^{\lambda t}\sum\limits_{i=0}^{n-1} \dfrac{t^i}{i!}(\boldsymbol A - \lambda \boldsymbol E)^i$ 
	- 若 $\boldsymbol x' = \boldsymbol A\boldsymbol x$ 的矩阵 $\boldsymbol A$ 为一般矩阵：
		- 求出矩阵 $\boldsymbol A$ 的特征值。假设 $\lambda_1, \lambda_2, \cdots, \lambda_k$ 分别是 $n_1,n_2,\cdots,n_k$ 重不同特征值
		- 考虑任一满足初值条件 $\boldsymbol\varphi(0) = \boldsymbol\eta$ 的解 $\boldsymbol\varphi(t)$ 
		- 由方程组 $(\boldsymbol A - \lambda_j \boldsymbol E)^{n_j}\boldsymbol u = \boldsymbol 0$ 的解产生子空间 $U_j\ (j=1,2,\cdots,k)$，可证明 $\boldsymbol\eta$ 可唯一分解为 $\boldsymbol\eta = \boldsymbol v_1 + \cdots + \boldsymbol v_k$，其中 $\boldsymbol v_j \in U_j$，设法求出 $\boldsymbol v_1, \cdots, \boldsymbol v_k$ 
		- 根据 $\boxed{\boldsymbol\varphi(t) = \sum\limits_{j=1}^k e^{\lambda_jt} \left[ \sum\limits_{i=0}^{n_j-1} \dfrac{t^i}{i!}(\boldsymbol A - \lambda_j\boldsymbol E)^i \right]\boldsymbol v_j}$ 求出满足初值条件 $\boldsymbol\varphi(0) = \boldsymbol\eta$ 的解 $\boldsymbol\varphi(t)$ 
		- 令 $\boldsymbol e_1 = \begin{bmatrix} 1 \\ 0 \\ \vdots \\ 0 \\ 0 \end{bmatrix},\ \boldsymbol e_2 = \begin{bmatrix} 0 \\ 1 \\ 0 \\ \vdots \\ 0 \end{bmatrix}, \cdots, \boldsymbol e_n = \begin{bmatrix} 0 \\ 0 \\ \vdots \\ 0 \\ 1 \end{bmatrix}$，分别取 $\boldsymbol\eta = \boldsymbol e_1, \boldsymbol e_2, \cdots, \boldsymbol e_n$，求出对应的 $\boldsymbol\varphi(t)$ 
		- 将上面求出的 $n$ 个 $\boldsymbol\varphi(t)$ 按列排列成矩阵即为所求的基解矩阵 $\exp \boldsymbol At$ 
# 拉普拉斯变换
$\displaystyle F(s) = \int_0^{+\infty} e^{-st}f(t)\mathrm dt$ 
原函数 $f(t) = t^ne^{zt}\ (n>-1)$ 的像函数 $F(s) = \dfrac{n!}{(s-z)^{n+1}}$，且 $F(s)$ 的定义域为 $\Re s >\Re z$ 
原函数 $f(t) = te^{\lambda t}\sin\omega t$ 的像函数 $F(s) = \dfrac{2\omega(s-\lambda)}{[(s-\lambda)^2 + \omega^2]^2}$，且 $F(s)$ 的定义域为 $\Re s >\lambda$ 
原函数 $f(t) = te^{\lambda t}\cos\omega t$ 的像函数 $F(s) = \dfrac{(s-\lambda)^2-\omega^2}{[(s-\lambda)^2+\omega^2]^2}$，且 $F(s)$ 的定义域为 $\Re s >\lambda$ 
原函数 $f(t) = \mathrm{sh}\ \omega t$ 的像函数 $F(s) = \dfrac{\omega}{s^2-\omega^2}$，且 $F(s)$ 的定义域为 $\Re s >|\omega|$ 
原函数 $f(t) = \mathrm{ch}\ \omega t$ 的像函数 $F(s) = \dfrac{s}{s^2-\omega^2}$，且 $F(s)$ 的定义域为 $\Re s >|\omega|$ 
# 一些简单二元函数的全微分
- $y\mathrm dx + x\mathrm dy = \mathrm d(xy)$ 
- $\dfrac{y\mathrm dx-x\mathrm dy}{y^2} = \mathrm d\left( \dfrac xy \right)$ 
- $\dfrac{-y\mathrm dx + x\mathrm dy}{x^2} = \mathrm d\left( \dfrac yx \right)$ 
- $\dfrac{y\mathrm dx - x\mathrm dy}{xy} = \mathrm d\left( \ln \left| \dfrac xy \right| \right)$ 
- $\dfrac{y\mathrm dx - x\mathrm dy}{x^2+y^2} = \mathrm d\left( \mathrm{arctan} \dfrac xy \right)$ 
- $\dfrac{y\mathrm dx - x\mathrm dy}{x^2-y^2} = \dfrac 12 \mathrm d \left( \ln \left| \dfrac{x-y}{x+y} \right| \right)$
