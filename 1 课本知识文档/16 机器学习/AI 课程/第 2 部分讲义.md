## 6-1 从一小块图像发现可重复的局部图案
我们想识别设备照片上的划痕。先把图片看成按行列排列的像素数值表，只有一张这样的表就叫**单通道**。取一个小区域 $\begin{pmatrix}1&2&0\\0&1&3\\2&1&0\end{pmatrix}$，数值代表像素强度。
现在拿一个 $2\times2$ 的小模板 $\begin{pmatrix}1&0\\0&1\end{pmatrix}$，让它对准这个区域的左上角。模板里的每个数，就是用来和对应位置像素相乘的**权重**。对应相乘再相加，得到 $1\times1+2\times0+0\times0+1\times1=2$。乘加完还可以再加一个可学习常数，叫**偏置**；这里暂取偏置 0。
这个用来扫描的小模板，就叫**卷积核**。当前输出只读取输入的一小块区域，而不是读取整张图的所有像素，这体现**局部连接**。
把同一个核向右移动一格，算得 $2+3=5$；再移到下方两个位置，依次得到 1 和 1。输出为 $\begin{pmatrix}2&5\\1&1\end{pmatrix}$。四个位置都用同一组核权重，这叫**参数共享**。
模板执行四次乘加运算，但我们只需要学习 4 个权重与 1 个偏置，不需要为每个位置单独准备一套参数。深度学习里普遍采用不翻转核的互相关运算，习惯上也直接称它为卷积。
步幅 $S$​ 代表滑动窗口每次移动的格数；填充 $P$​ 代表输入边缘每侧补零的数量。假设输入单边长度为 $W$，卷积核单边长度为 $K$，只统计能够完整放入的窗口，输出单边长度公式：

$$W_{out}=\left\lfloor\frac{W+2P-K}{S}\right\rfloor+1$$

$\lfloor\cdot\rfloor$ 表示向下取整。本例 $W=3,K=2,S=1,P=0$，代入得 $W_{out}=2$，两个方向分别从位置 0、1 开始滑动，得到 $2\times2$ 输出。

- **局部连接**：输出仅关联输入局部区域，不是全局全连接。
- **参数共享**：同一卷积核权重在全部空间位置复用，参数量不会随输出位置数量增长。
- **尺寸取整规则**：窗口无法完整放下时直接舍弃，因此公式使用向下取整。

## 6-2 多通道卷积、输出尺寸与参数量计算
真实彩色照片包含红、绿、蓝三个输入通道。普通卷积核会同时覆盖**全部输入通道**，各通道乘加结果求和之后，**仅添加一次偏置**；一个独立卷积核，生成一张输出特征图，也就是**一个输出通道**。
记输入通道数 $C_{in}$，输出通道数 $C_{out}$，方形卷积核边长 $K$，每个核附带一个偏置，可学习参数量公式：
$$\boxed{N_{param}=(K^2C_{in}+1)C_{out}}$$
公式内 $+1$ 对应单个输出通道独有的偏置；输出通道总数等于卷积核的个数。
示例：输入形状 $32\times32\times3$，选用 16 个 $3\times3$ 卷积核，步幅 1、每侧填充 1。
空间尺寸：
$$W_{out}=\left\lfloor\frac{32+2\times1-3}{1}\right\rfloor+1=32$$
参数量：
$$N_{param}=(3^2\times3+1)\times16=448$$
最终输出形状 $32\times32\times16$。

|项目|说明|
|---|---|
|$K^2C_{in}$|单个卷积核全部权重数量|
|$+1$|每个输出通道单独配置一个偏置|
|$\times C_{out}$|独立卷积核的总组数|

参数共享代表参数量**不需要乘输出高、宽，也不乘批次大小**。增大步幅会减少采样位置；填充会改变边缘像素参与程度与最终输出尺寸。

- **参数量易错点**：不要乘输出空间尺寸或者批量大小；数值等于 0 的可学习权重依旧计入参数量。
- **偏置规则**：所有输入通道累加完成之后，每个输出通道只加一次偏置。
- **无偏置版本**：若网络取消偏置，参数量公式删除 $+1$ 即可。

## 6-3 卷积逐元素运算约定
对零填充后的输入记为 $\widetilde X$，采用从 0 开始的空间与通道索引、普通无分组卷积、膨胀率 1。输出计算公式：
$$\boxed{z_{ijo}=b_o+\sum_{c=0}^{C_{in}-1}\sum_{u=0}^{K_h-1}\sum_{v=0}^{K_w-1}W^{(o)}_{uvc}\widetilde X_{iS_h+u,jS_w+v,c}}$$

符号说明：
$i,j$ 为合法输出位置；$o=0,\ldots,C_{out}-1$ 代表输出通道编号；$W^{(o)}$ 为第 $o$ 个卷积核；$b_o$ 为该核偏置；$K_h,K_w$ 为核高、宽；$S_h,S_w$ 为纵横步幅；$u,v$ 是核内行列索引，$c$ 是输入通道索引。

- **运算约定**：深度学习普遍把不翻转核的互相关直接称作卷积，不需要额外翻转模板。
- **尺寸公式推导依据**：单轴合法窗口起点满足 $0\le iS\le W+2P-K$，$i$ 为非负整数，由此推出位置数 $\lfloor(W+2P-K)/S\rfloor+1$；要求窗口至少可以放置一次、$S$ 为正整数。二维特征图两个轴分别计算，输出通道数量由卷积核个数决定。

## 6-4 激活、池化、展平与全连接：模块分工
卷积层得到特征图之后，**ReLU激活函数**逐元素运算：$h=\max(0,z)$。规则带有转折，不是单纯乘加，能够为网络引入**非线性**。
随后使用固定窗口把多个响应汇聚成单一数值，这一操作叫做**池化**，属于**空间降采样**。回到6-1得到的 $2\times2$ 输出 $\begin{pmatrix}2&5\\1&1\end{pmatrix}$：
- **最大池化**：取窗口内最大值 $\max(2,5,1,1)=5$
- **平均池化**：取窗口算术平均值 $(2+5+1+1)/4=9/4$

普通最大池化、平均池化**没有可学习参数**，并且不会混合不同通道的信息。
池化可以降低特征图分辨率，但不能保证模型对所有平移都具备不变性。
把池化后的张量按照固定顺序排成一列，称为**展平**，得到向量；展平只做元素重排，**不会改变元素总数量**。
之后接入**全连接层**，每一个输出读取向量全部分量，分别乘权重、求和再加偏置。如果用于分类任务，对全连接输出的类别分数做 Softmax：取指数后除以指数总和，得到总和为 1 的类别概率分布。

| 模块      | 功能        | 是否包含可学习参数 |
| ------- | --------- | --------- |
| 卷积      | 提取局部特征    | 是         |
| ReLU    | 引入非线性     | 否         |
| 池化      | 空间汇聚、降采样  | 否         |
| 展平      | 张量重排为一维向量 | 否         |
| 全连接层    | 综合全部特征做判断 | 是         |
| Softmax | 输出归一化类别概率 | 否         |

补充：包含偏置、$n$ 个输入、$m$ 个输出的全连接层，参数量为 $(n+1)m$；无偏置时为 $nm$。

- **展平易错点**：只重排元素，元素总数保持不变；$H\times W\times C$ 展平后得到 $HWC$ 维向量。
- **网络结构灵活**：不是所有 CNN 都必须按顺序包含以上全部模块。

## 6-5 感受野、平移等变与平移不变
堆叠多层卷积时，网络深层单个输出位置，能够间接关联到原始输入更大一片区域，这片区域称为**感受野**，描述感受野时必须说明相对哪一层。
两层 $3\times3$、步幅均为 1 的卷积，第二层相对原始输入的感受野大小为 $5\times5$。通用单轴感受野公式：连续两层、膨胀率1、步幅均为1，核宽分别为 $K_1,K_2$，第二层感受野宽度：
$$\boxed{R=K_1+(K_2-1)}$$
图像图案发生平移，特征响应也跟着平移，称为**平移等变**；输入平移之后输出完全不改变，才叫做**平移不变**。
- **图像图案**：就是图片里的一个局部形状。比如一条竖线、一个拐角、一个圆圈、一道划痕。它是输入像素里"长什么样"的那部分信息。
- **特征响应**：卷积核扫过图片之后，在某个位置算出来的那个数值。数值大 = 这个位置“很像”核要找的图案；数值小 = 不太像。所有位置的响应排在一起，就是一张**特征图**。
- **输入**：喂给当前这一层的东西。对第一层来说，输入就是原始图片像素；对第二层来说，输入是第一层输出的特征图。
- **输出**：当前这一层算完之后，交给下一层的东西。对分类任务的最终输出，就是"这是猫/狗/划痕"的概率。

数学定义：设 $T_\Delta$ 为平移算子，$x$ 为输入，$F$ 为待考察映射：
- 平移等变：$F(T_\Delta x)=T_\Delta F(x)$
- 平移不变：$F(T_\Delta x)=F(x)$

步幅、填充边界、池化都会改变上述性质。局部权重共享只能支撑等变，**不能直接推出完整卷积网络具备严格平移不变性**。

- **感受野边界**：感受野代表输出“可能依赖”的输入区域，不代表区域内每个位置影响强度完全相同。
- **等变≠不变**：二者定义不同，考试简答题不要混淆。

## 6-6 考试边界：易错汇总与计算注意点

### 1 输出尺寸与参数量
1. 窗口放不下直接舍弃，尺寸公式统一使用向下取整；二维特征图高度、宽度分开独立计算。
2. 参数量只统计独立权重与偏置；不要乘输出高、宽，也不要乘批量大小。
3. 多输入通道卷积：各通道乘加结果求和，**每个输出通道仅添加一次偏置**。
### 2. 池化与展平
1. 普通池化逐通道独立运算，不会跨通道混合信息；无可学习参数。
2. 最大池化取窗口最大值；平均池化取窗口算术平均值，分母为窗口内有效位置数量。
3. 展平仅重排元素，元素总数不变。
### 3. 平移性质
1. 等变代表输出跟随输入平移；不变代表输出不受平移影响。
2. 步幅、池化、填充都会破坏不变性，不能默认CNN天然平移不变。
### 4. 常见易错对照表

| 易错点           | 正确结论             |
| ------------- | ---------------- |
| 参数量乘输出空间尺寸    | 参数量只统计独立卷积核权重与偏置 |
| 每个空间位置单独加偏置   | 每个输出通道仅添加一次偏置    |
| CNN 一定具备平移不变性 | 仅支持等变，整网不保证严格不变  |
| 展平会改变元素数量     | 展平只重排，元素总数不变     |
| 池化拥有可学习权重     | 普通最大、平均池化无学习参数   |

## 7-1 从词元到嵌入：把文字变成数字
阅读“机器、学习”时，我们不希望每个词只保留孤立含义。模型不能直接处理汉字，需要先把每个词元转换成一行数字，这行数字称为**嵌入表示**。词元是模型处理的基本单位，不一定和日常词语完全对应。所有词元的嵌入按行叠在一起，组成输入矩阵 $X$：每一行代表一个词元，每一列代表一个特征维度。

- **词元与嵌入**：词元是序列里最小的离散单元；嵌入是把离散词元映射成实数向量的过程；输入矩阵 $X$ 按行存放全部词元的嵌入。

## 7-2 查询、键、值：每个位置的三重身份
只靠孤立的嵌入，模型不知道“机器”和“学习”之间的关系。我们需要让每个位置互相交换信息。具体做法是：给每个位置准备三重信息——**查询 Q**​ 表达“我想找什么”，**键 K**​ 供其他位置判断“我是不是你要找的”，**值 V**​ 是“找到我之后你能拿走的内容”。
这三重信息不是手动设定的，而是从同一个输入 $X$ 经过不同的线性变换得到的：
$$Q=XW_Q,\quad K=XW_K,\quad V=XW_V$$
$W_Q,W_K,W_V$ 是三套**可学习的参数矩阵** (类似第 1 章里的 $w,b$，训练时自动调整)。乘矩阵相当于把原有数字按新权重重新组合，这个操作叫**线性投影**，不要求一定降维。
关键：**同一个 $X$，经过三套不同的投影，得到三个不同的矩阵**。

- **查询、键与值**：Q 发起查询，K 提供匹配依据，V 提供被聚合的内容。
    - **投影区别**：三套投影参数不同，同源不等于数值相等。
    - **参数与权重的区别**：投影矩阵是模型参数，而后面算出的注意力权重是由当前输入临时算出的，不是参数。

## 7-3 两种基础网络：FNN 与 RNN
在讲自注意力之前，先认识两种更基础的网络结构，后面才能看清自注意力的优势在哪里。
**前馈神经网络** (**FNN**) 是最简单的结构：信息从输入层一路向前传到输出层，每一层都对上一层的数字做线性组合再加一个非线性变换。它对单个向量很有效——比如第 1 章里用 $\hat y=wx+b$ 预测分数，如果叠几层就是 FNN。但 FNN 有一个局限：它每次只处理一个独立向量，看不到序列中其他位置的信息。把“机器”的嵌入喂给 FNN，它不知道后面还有“学习”。
**循环神经网络** (**RNN**) 专门处理序列。它的核心思想是：维护一个隐藏状态，每读入一个词元，就把“上一个状态的记忆”和“当前词元”结合起来，更新状态。这样理论上最后一个状态包含了前面所有词的信息。

但 RNN 有两个明显问题：
- **难以并行**：必须等第 1 个词处理完才能处理第 2 个，第 2 个处理完才能处理第 3 个，像接力跑一样。
- **长距离遗忘**：当序列很长时，靠递推传递的信息会慢慢衰减，前面的词对后面的影响越来越弱。

- **FNN**：信息单向传播，适合处理独立向量，无法直接建模序列中位置之间的关系。
- **RNN**：通过递推隐藏状态传递序列信息，能捕捉前后依赖，但必须逐步计算、难以并行，且长距离信息容易衰减。

## 7-3 缩放点积注意力：怎样决定“看谁多少”
有了 $Q,K,V$，接下来要解决：每个位置应该向其他位置读取多少信息？这需要三步。
第一步：算匹配分数。​ 用查询和键做点积，得到分数矩阵 $R=QK^T$。点积越大，说明两个位置越匹配。
第二步：缩放。​ 把分数除以 $\sqrt{d_k}$ ($d_k$ 是查询和键的宽度)，得到 $S=R/\sqrt{d_k}$。缩放是为了防止分数过大导致 Softmax 过于极端、梯度消失。
第三步：Softmax 归一化 + 加权求和。​ 对 $S$ 逐行做 Softmax，得到注意力权重矩阵 $A$ (每行和为 1)；再用 $A$ 对 $V$ 加权求和，得到输出 $O=AV$。
我们用“机器、学习”的手算例子串起来。取
$$Q=\begin{pmatrix}1&0\\0&1\end{pmatrix},\quad
K=\begin{pmatrix}0&0\\\sqrt2\ln3&0\end{pmatrix},\quad
V=\begin{pmatrix}2&0\\6&4\end{pmatrix}.$$
查询和键宽度 $d_k=2$，完整计算：
$$\begin{aligned}
R&=QK^T=\begin{pmatrix}0&\sqrt2\ln3\\0&0\end{pmatrix},\\
S&=R/\sqrt2=\begin{pmatrix}0&\ln3\\0&0\end{pmatrix},\\
A&=\operatorname{softmax}_{row}(S)=\begin{pmatrix}1/4&3/4\\1/2&1/2\end{pmatrix},\\
O&=AV=\begin{pmatrix}5&3\\4&2\end{pmatrix}.
\end{aligned}$$
解释：第一行是“机器”这个位置的查询，它对“机器”自己的键得分低、对“学习”的键得分高，所以权重是 $(1/4,3/4)$——它主要从“学习”那里读取值。输出 $(5,3)$ 就是 $\frac14\times(2,0)+\frac34\times(6,4)$ 的结果。
权重表 $A$ 的形状是“查询位置 × 键位置”，输出 $O$ 的形状是“查询位置 × 值的特征”。键负责匹配，值负责提供内容；权重不必对称，也不必只选一个位置。

- **缩放点积注意力**：先算点积分数 $R=QK^T$，再缩放得 $S$，逐行 Softmax 得权重 $A$，最后 $O=AV$。
    - **输出形状**：$R,S,A$ 为 $n\times n$，$O$ 为 $n\times d_v$。
    - **易错点**：加权对象是 $V$，不能换成 $K$。
- **缩放原因**：在查询和键各分量独立、均值 0、方差 1 的简化假设下，点积方差为 $d_k$，除以 $\sqrt{d_k}$ 后方差回到 1，缓解 Softmax 过尖。

## 7-4 多头注意力：多角度看匹配
一套 $Q,K,V$ 只能捕捉一种匹配关系，可能不够。我们可以准备多套投影，每套独立做一遍“投影→匹配→加权求和”，这称为一个**头**。**多头注意力**就是把多个头的输出沿特征维度拼接起来，再乘一个输出投影矩阵 $W_O$ 调整宽度。
注意：多头是让模型从多个子空间分别学习关系，不是把词元分成几组各管各的。

- **多头注意力**：各头使用自己的投影，分别输出后再拼接，最后乘输出投影矩阵。
    - **易错点**：拼接不是求和，也不是把词元分组。

## 7-5 自注意力与 CNN、RNN 的对比
因为这里的 $Q,K,V$ 都来自同一句输入，所以叫**自注意力**。
和第 1 章提到的思路类似，不同模型处理序列的方式不同：
- **CNN (卷积)**：只看固定大小的局部窗口，参数共享。
- **RNN**：按时间一步步递推，当前状态依赖上一步，难以并行。
- **自注意力**：每个位置可以直接和任意其他位置交互，已知全部输入时可以并行计算；但代价是注意力权重表的大小随序列长度平方增长。
- **自注意力**：查询、键和值来自同一输入，依据匹配权重对值加权求和，产生融合了上下文的新表示。
    - **名称含义**：“自”指来源相同，不表示只能读取自身。
- **CNN、RNN 与自注意力**：CNN 偏局部，RNN 递推，自注意力可直接关联远近位置。
    - **并行性与计算代价**：已知输入可并行，但权重表有 $n^2$ 个元素。

## 7-6 位置信息与掩码
基础自注意力只看嵌入数字，不知道“机器”在前、“学习”在后。需要额外加入位置信息。另外，如果规定某个位置不能看后面的词 (比如逐词生成时不能偷看未来)，就用**掩码**：在 Softmax 之前把禁止位置的分数设为 $-\infty$，这样它的权重就变成 0，只在允许的位置中重新归一化。

- **位置与掩码**：基础自注意力不自带顺序；掩码通过 $-\infty$ 屏蔽不可访问的位置。
    - **可见性条件**：每行至少要保留一个可访问位置。
- **补充性质**：查询和键必须等宽，值可以不同宽；注意力权重不一定对称；单头加权输出的每个分量落在对应值列的最小和最大值之间。

## 8-1 翻译任务与位置编码
我们要把“我、爱、猫”翻译成“I、love、cats”。延续第7章的思路，先把“我”“爱”“猫”作为**词元**，为每个词元准备一行可学习的嵌入向量。但只有词义不够，“猫爱我”和“我爱猫”词语相同、含义相反，模型必须知道词元所处的位置。因此需要引入**位置编码**，补充顺序信息。
经典 Transformer 用正弦、余弦函数生成位置编码。我们先看它长什么样，再解释为什么这样设计。
假设特征维度 $d=4$ (即每个向量有 4 个数字)，句子“我、爱、猫”中，“我”排第 0 位、“爱”排第 1 位、“猫”排第 2 位。位置编码的公式：
$$PE(pos,2i)=\sin\left(\frac{pos}{10000^{2i/d}}\right),\quad PE(pos,2i+1)=\cos\left(\frac{pos}{10000^{2i/d}}\right)$$
这里有两个索引，新手容易混淆，先说清楚：
- **$pos$**：词元在句子中的位置编号。“我”的 $pos=0$，“爱”的 $pos=1$，“猫”的 $pos=2$。
- **$i$**：维度配对索引，用来把 4 个维度两两分组。$d=4$ 时，$i$ 只能取 0 和 1。$i=0$ 管第 0 维和第 1 维，$i=1$ 管第 2 维和第 3 维。

所以 $2i$ 和 $2i+1$ 就是实际的维度编号：当 $i=0$，对应维度 0 (用 $\sin$) 和维度 1 (用 $\cos$)；当 $i=1$，对应维度 2 (用 $\sin$) 和维度 3 (用 $\cos$)。偶数维度用 $\sin$，紧挨着的奇数维度用 $\cos$，一一配对。
为什么用 $pos/10000^{2i/d}$ 这么奇怪的东西？​ 它控制的是“震荡频率”。$i$ 越大，分母 $10000^{2i/d}$ 越大，整个分数越小，$\sin$ 和 $\cos$ 变化越慢。也就是说：低维度 ($i$ 小) 变化快，高维度 ($i$ 大) 变化慢。不同维度捕捉不同尺度的位置信息。
现在手算“我” ($pos=0$) 的位置编码：
- $i=0$：角度 $=0/10000^0=0$，维度0 $=\sin0=0$，维度1 $=\cos0=1$
- $i=1$：角度 $=0/10000^{2/4}=0$，维度2 $=\sin0=0$，维度3 $=\cos0=1$

所以"我"的位置编码是 $(0,1,0,1)$。注意它**不是全零**——因为奇数维度用的是 $\cos0=1$。
位置编码和词嵌入的维度相同 (都是 $d=4$)，两者**逐项相加**：对应位置的数字直接加。比如“我”的嵌入是 $(2,-1,3,0)$，加上位置编码 $(0,1,0,1)$ 得到 $(2,0,3,1)$。
源句经过嵌入与位置编码相加后，送入**编码器**。编码器由多层相同结构堆叠，每层依次执行自注意力、残差连接与层归一化、前馈网络、再次残差连接与层归一化。重复堆叠不表示各层共享参数。编码器最终输出源序列全部位置的上下文表示。

- **词嵌入与位置编码**：词嵌入把离散词元映射为向量；位置编码用正弦余弦函数生成，和嵌入同维度、逐项相加。
    - **零位置性质**：位置 0 的编码交替为 0 和 1，不是全零向量。
- **编码器**：源词元经过嵌入与位置编码，再通过多层自注意力、前馈网络；每个子层配有残差和层归一化；编码器输出保留源序列各位置的表示。
    - **层数约定**：层数可以配置，重复结构不表示共享全部参数。

## 8-2 前馈网络、残差连接与层归一化
编码器每一层包含两大运算：自注意力、前馈网络 FFN。自注意力负责让不同词元互相交换信息；而前馈网络 FFN 只单独处理每一个位置自身的向量，不会让词元之间产生信息交互。
我们先看单个位置的计算。假设某一个词元对应的输入行向量是 $x$。经典 Transformer 里 FFN 的公式为：
$$\operatorname{FFN}(x)=\max(0,xW_1+b_1)W_2+b_2$$
$W_1,W_2$ 是可学习权重矩阵，$b_1,b_2$ 是偏置；$\max(0,\cdot)$ 就是 ReLU 激活函数，小于 0 的数值全部置 0。
这里用一组具体数字直观感受。假设输入维度 $d=2$，中间层宽度 $d_{ff}=3$，输出再回到 2维：
$x=(1,2)$，$W_1=\begin{pmatrix}1&0&1\\0&1&1\end{pmatrix}$，$b_1=(0,0,0)$；
第一步：$xW_1+b_1=(1,2,3)$；
经过ReLU，数值全部大于0，保持不变：$(1,2,3)$；
再乘 $W_2$ 并加上偏置得到最终输出。
有三点需要重点区分：
1. **参数共享**：句子里“我”“爱”“猫”三个位置，全部使用同一套 $W_1,b_1,W_2,b_2$ 做运算，不是每个词元单独一套参数。
2. **不混合位置信息**：计算“我”的FFN输出时，只用到“我”自己的向量，完全不会读取“爱”“猫”的向量。位置之间互通消息是**自注意力的任务**，FFN只负责把单个位置的特征做非线性变换、提取更高层语义。
3. **层数说明**：FFN作为一类网络统称，本身不限制层数。经典Transformer固定采用“线性层→ReLU→线性层”这种浅结构；模型整体深度依靠堆叠多层编码器实现，而不是把单个FFN堆深。其他模型也会使用GELU等别的激活函数，但核心逻辑不变。

仅仅做FFN或者自注意力还不够，还需要**残差连接**和**层归一化 LN** 来稳定深层网络训练。
**残差连接**形式为 $x+F(x)$。其中 $x$ 是子层原始输入，$F(x)$ 是子层 (自注意力或者 FFN) 的输出。两者形状必须完全一致，才能对应元素相加。作用：开辟一条梯度直通路，缓解网络变深之后难以训练的问题。
**层归一化 LN** 只对单个位置的特征向量做标准化，不跨词元、也不跨不同样本。对向量 $x=(x_1,\dots,x_d)$，先算这 $d$ 个特征的均值 $\mu$ 与方差 $v$：
$$\mu=\frac1d\sum_{j=1}^dx_j,\quad v=\frac1d\sum_{j=1}^d(x_j-\mu)^2$$
归一化并做可学习仿射变换：
$$\operatorname{LN}(x)_j=\gamma_j\frac{x_j-\mu}{\sqrt{v+\varepsilon}}+\beta_j$$
$\varepsilon>0$ 是防止分母为 0 的稳定项；$\gamma_j,\beta_j$ 是可学习的缩放、平移参数，让模型可以自主调节归一化的强度。
举个简单手算例子：$x=(2,4,6)$，$d=3$。
均值 $\mu=(2+4+6)/3=4$；
方差 $v=[(2-4)^2+(4-4)^2+(6-4)^2]/3=(4+0+4)/3=8/3$；
再代入公式得到归一化后的数值，最后乘 $\gamma_j$ 加 $\beta_j$。
在序列数据常见形状 $B\times T\times d$ 中，$B$ 为批大小、$T$ 为词元数量；LN 对每个样本、每一个位置独立沿 $d$ 个特征求均值方差，**不能把不同样本、不同位置混在一起统计**。

残差和 LN 有两种常见摆放顺序：
$$\text{Post-LN}:\ \operatorname{LN}(x+F(x)) \qquad \text{Pre-LN}:\ x+F(\operatorname{LN}(x))$$
Post-LN：先做残差相加，再做层归一化；Pre-LN：先对输入做层归一化，再送入子层，最后加残差。

- **FFN**：对同层各位置独立使用同一套参数，$\mathrm{FFN}(x)=\max(0,xW_1+b_1)W_2+b_2$。
    - **作用范围**：只加工单个位置内部特征，不混合不同词元信息；自注意力负责词元间信息交互。
    - **层数说明**：经典Transformer采用两层线性+ReLU的浅结构；FFN作为网络类别不限定层数，更多层也属于FFN。
- **残差与LN**：残差 $x+F(x)$ 要求两项同形状，保留直接信息与梯度通路；Post-LN为 $\mathrm{LN}(x+F(x))$，Pre-LN为 $x+F(\mathrm{LN}(x))$；LN沿每位置特征维统计，不跨样本、不跨位置。
    - **统计轴**：每个样本的每个位置独立沿特征维求统计，不能把不同样本或不同位置混成一组。

## 8-3 解码器、右移、因果掩码
负责结合源句表示、逐步生成目标序列的模块叫做**解码器**。训练阶段我们已经拥有完整正确译文，例如目标为“I、love、cats、EOS”。解码器训练输入需要**右移**：输入序列为“BOS、I、love、cats”，对应的预测标签为“I、love、cats、EOS”。BOS 代表序列开始，EOS 代表序列结束。
预测 love 时，模型输入只到 I，无法直接看到待预测的 love，从而避免信息泄漏。训练时使用真实历史前缀，称为**教师强制**。
仅有右移不足以完全屏蔽未来信息，还要配合**因果掩码**。设 $S$ 是已经除以 $\sqrt{d_k}$ 缩放后的分数矩阵，掩码矩阵 $M$ 满足：
$$M_{ij}=\begin{cases}0,&j\le i,\\-\infty,&j>i,\end{cases}\qquad A=\operatorname{softmax}_{row}(S+M)$$
$i$ 是查询行索引，$j$ 是键列索引。Softmax 逐行取指数并归一化，$e^{-\infty}$ 极限为 0，未来位置权重归零。
用三个位置的手算示例：缩放分数全部为 0，值向量 $V=(2,4,9)^T$。加入因果掩码后：
$$A=\begin{pmatrix}1&0&0\\1/2&1/2&0\\1/3&1/3&1/3\end{pmatrix},\qquad O=AV=\begin{pmatrix}2\\3\\5\end{pmatrix}$$
第一行只能看位置1，权重 $(1,0,0)$；第二行看前两个位置，均分权重；第三行看全部三个位置。如果把未来位置分数设为 0 而不是 $-\infty$，指数 $e^0=1$，权重无法归零，这是常见错误。位置编码负责提供位置信息，掩码负责控制可见范围，二者作用不同。

- **右移与教师强制**：训练输入为起始标记和此前真实词元，标签为当前待预测词元；教师强制使用真实历史前缀。
    - **防泄漏条件**：右移与掩码配合，使模型不会泄漏当前标签。
- **因果掩码**：行是查询、列是键，允许当前及此前位置的分数加 0，未来位置加 $-\infty$，随后再计算 Softmax。
    - **易错点**：把未来分数改成 0 不能使其权重归零。
    - **与位置编码的区别**：PE 提供位置，Mask 控制可见范围。

## 8-4 交叉注意力：解码器如何读懂源句
先回答一个直觉问题：为什么 Transformer 里到处都在算 Q、K、V？
回忆第 7 章：自注意力的本质是“每个位置提问、匹配、取内容”——查询 Q 代表“我想找什么”，键 K 代表“我能被匹配到什么程度”，值 V 代表“匹配上之后你实际拿走什么信息”。
Transformer里每一类注意力都做同一件事：用 Q 去匹配 K，拿到权重，再按权重取 V。区别只在于：Q、K、V 分别从哪里来？​来源不同，注意力的功能就完全不同。
### 三种注意力，三种信息来源
解码器里一共出现三种注意力，我们用翻译任务“我→I、爱→love、猫→cats”来理解：
1. 编码器自注意力 (在编码器内部)
	Q、K、V 全部来自编码器当前层的输入 (也就是源句“我、爱、猫”的表示)。
	作用：让中文词元之间互相看上下文。“爱”的表示会参考“我”和“猫”，理解“爱”到底是谁爱谁。
2. 解码器掩码自注意力 (在解码器内部)
	Q、K、V 全部来自解码器当前层的输入 (也就是目标前缀的表示)。
	作用：让已经生成的目标词元之间互相参考。但必须加因果掩码 (第 8-3 节讲过)，防止看到未来位置。
3. 交叉注意力 (解码器读取编码器)
	这是本节重点。Q 来自解码器上一子层的输出 (代表“目标端当前需要什么信息”)，K 和 V 来自编码器的最终输出 (代表“源句提供了什么内容”)。
	作用：解码器在生成“love”时，通过 Q 去匹配中文“爱”的 K，拿到高权重，再从“爱”的 V 里取走语义信息。这就是解码器“读懂中文”的方式。

| 注意力类型     | Q 来自  | K 来自  | V 来自  | 干什么            |
| --------- | ----- | ----- | ----- | -------------- |
| 编码器自注意力   | 编码器输入 | 编码器输入 | 编码器输入 | 中文词元互相理解上下文    |
| 解码器掩码自注意力 | 解码器输入 | 解码器输入 | 解码器输入 | 目标词元互相参考（不看未来） |
| 交叉注意力     | 解码器状态 | 编码器输出 | 编码器输出 | 目标端从源端读取需要的信息  |

### 交叉注意力的形状：为什么是"目标行 × 源列"？
新手最容易晕的地方：输出到底有几行？
记住一条铁律：注意力输出的行数永远由 Q 决定 (因为 Q 是“提问者”，每个 Q 产生一行输出)。
假设源句“我、爱、猫”有 3 个位置，解码器当前要处理目标“I、love”两个位置。
- Q 来自解码侧：2 个目标位置，每个位置产出 1 个查询向量 → Q 形状 $(2 \times d_k)$ 
- K、V 来自编码器最终输出：3 个源位置，每个产出键和值 → K 形状 $3 \times d_k$，V 形状 $3 \times d_v$ 

计算步骤：
1. 分数矩阵 = $QK^T$ → $(2\times d_k) \times (d_k\times 3) = 2\times 3$ 
    2 行 3 列：每一行是一个目标位置，每一列是一个源位置
2. Softmax 逐行归一化 → 注意力权重也是 $2\times 3$  
    第 1 行：目标位置“I”对“我、爱、猫”各分配多少注意力  
    第 2 行：目标位置“love”对“我、爱、猫”各分配多少注意力
3. 权重乘 V → $(2\times 3) \times (3\times d_v) = 2\times d_v$ 
    输出 2 行，跟 Q 的行数一致，不是 3 行！

> 易错点：值 V 虽然来自源序列 (3 行)，但输出行数由 Q (2 行) 决定。不能因为 V 有 3 行就以为输出有 3 行。

### 多头是什么？(简要铺垫)
第 7 章讲过：多头就是让模型**同时用多套不同的 Q、K、V 投影**各自做一次注意力，相当于从多个角度去匹配信息。每个头独立产生一个输出，再把所有头的输出沿特征维度拼接起来，最后乘一个输出投影矩阵调整回需要的宽度。
交叉注意力、编码器自注意力、解码器掩码自注意力**都可以使用多头**，不是只有某一种能用。

- **三种注意力来源**：编码器自注意力的 Q、K、V 同源 (编码器输入)；解码器掩码自注意力同源 (解码器输入) 并屏蔽未来；交叉注意力 Q 来自解码器，K、V 来自编码器。
    - **核心区别**：不在于计算公式不同，而在于 Q、K、V 的信息来源不同，决定了注意力“谁问谁、谁提供信息”。
- **交叉注意力形状**：权重表是“目标长度 × 源长度”，输出行数跟随查询 Q，不由值 V 的行数决定。
- **多头**：三种注意力都可以使用多头机制，从多个角度并行提取信息。

## 8-5 多头、词表映射、自回归生成
**多头注意力**在 Transformer 各处都可以使用：多套独立的查询、键、值投影各自完成注意力计算，把同一位置多个头的输出沿特征维度首尾拼接，再乘以可学习的输出投影矩阵 $W_O$，调整回模型需要的特征宽度。多头是沿特征拼接，不是把词元分组，也不是直接求和。
解码器所有子层运算完成后，通过一组可学习权重映射到**词表**维度。词表是模型全部可选输出的词集合，再经过 Softmax 把分数转化为总和为 1 的下一词概率。位置之间的注意力权重，和最终词表概率属于不同层面的输出，不能混淆。
训练阶段使用教师强制，全部前缀已知，可以并行计算。推理阶段没有真实译文，模型从 BOS 开始，预测出 I，再把 I 接回输入预测 love，不断循环直到输出 EOS，这就是**自回归生成**。
推理时前缀由模型自身生成，存在先后依赖；如果前期预测出错，错误会持续累积。位置编码说明“在哪里”，掩码说明“能看谁”，右移说明“输入与目标怎样对齐”，三者共同保障序列训练正确。

- **多头**：各头使用自己的投影，分别输出后再拼接，最后乘输出投影矩阵。
- **词表**：所有可选词组成词表，模型输出词表中每个词的概率。
- **自回归生成**：推理时依赖已经生成的前缀逐步预测，直到结束标记或题设停止条件。
    - **并行性边界**：训练可并行不等于生成可一次完成。
    - **训练与推理差异**：训练与推理前缀不同可能引起误差积累。

## 8-6 Transformer 与 CNN、RNN 的比较
经典编码器-解码器 Transformer 整体结构：
编码器：嵌入+位置编码 → 自注意力 → 残差/LN → FFN → 残差/LN，多层堆叠；
解码器：右移嵌入+位置编码 → 掩码自注意力 → 残差/LN → 交叉注意力 → 残差/LN → FFN → 残差/LN，最后映射到词表、Softmax输出概率。

和第 7 章对比：
CNN 以局部窗口和共享卷积核引入局部结构偏好；RNN 通过共享递推函数传递历史状态；Transformer 利用自注意力按照内容建立直接位置关联，显式注意力权重表大小随序列长度平方增长。Transformer本身不具备顺序感知，需要位置编码表达次序；已知全部输入时可以并行处理，但自回归生成依旧存在顺序依赖。

- **Transformer结构**：编码器处理源序列，解码器结合源表示与目标前缀生成目标序列，子层均配有残差和层归一化。
- **Transformer 与 CNN、RNN 的比较**：CNN 偏局部，RNN 递推，Transformer 用自注意力建立全局关联，已知输入可并行，但自回归生成仍有先后依赖。

# 9 GAN与生成建模

## 9-1 生成器与判别器的对抗游戏
假设我们想让模型自动画出手写数字图片。我们准备两个网络：
**生成器 G**：输入一个随机向量 $z$ (就是一串随机数)，输出一张图片 $G(z)$。随机向量为不同画法提供变化起点，但刚开始生成的图片往往只是一堆噪声。
**判别器 D**：同时看真实手写图片 $x$ 和生成器造出的假图片 $G(z)$，给出“这张图片像不像真货”的评分。$D(x)$ 是真实图片的评分，$D(G(z))$ 是假图片的评分。评分越接近 1，表示判别器越认为它是真的。
两个网络互相较劲：生成器努力把假图造得更逼真，判别器努力把真假区分开。这种对抗训练的结构就叫**生成对抗网络 GAN**。
显然 G 想要最大化 $D(x)$ 并最小化 $D(G(z))$，为了后续方便，把这两个目标合成最大化 $J=\log D(x)+\log(1-D(G(z)))$ 
而 D 想要最大化 $D(G(z))$，即最小化 $\log (1-D(G(z)))$ 
总结如下：

| 更新对象    | 固定谁     | 目标                    | 希望发生什么        |
| ------- | ------- | --------------------- | ------------- |
| 判别器 $D$ | 生成器 $G$ | 最大化 $J$               | 真图分数升高，假图分数降低 |
| 生成器 $G$ | 判别器参数   | 最小化 $\log(1-D(G(z)))$ | 假图分数升高        |

这就是**极小极大**：判别器想最大化 $J$，生成器想最小化同一个目标里和自己相关的部分 (等价于让假图评分 $D(G(z))$ 升高)。
注意“固定判别器参数”只是说不更新 $D$ 的权重，但梯度仍然可以通过 $G(z)\to D(G(z))\to L_G$ 这条路径传回生成器。

- **GAN 与隐变量**：生成器 $G$ 把随机向量 $z$ 变成假样本，判别器 $D$ 辨别真假；$z$ 通常从简单分布 (如正态分布) 中抽样。
    - **生成阶段**：训练完成后，若只想生成图片，通常只需保留生成器 $G$。
- **原始 GAN 目标**：$\min\limits_G\max\limits_D V(D,G)$，其中 $V(D,G)=\mathbb E_{x\sim p_{data}}\log D(x)+\mathbb E_{z\sim p_z} \log[1-D(G(z))]$。
    - **更新方向**：判别器希望真图评分高、假图评分低；生成器希望假图评分高。

## 9-2 生成器的两种损失：饱和与非饱和
当判别器很强时 (假图评分 $p$ 接近 0)，原始生成器损失 $\log(1-p)$ 会遇到一个问题：梯度变得极小，生成器几乎学不到东西。这叫**梯度饱和**。
解决办法是换一种写法——**非饱和损失** $-\log p$。两者优化方向相同 (都希望假图评分升高)，但梯度信号不同。
用导数看清楚区别。设判别器在 Sigmoid 之前的分数为 $a$，则 $p=\sigma(a)=1/(1+e^{-a})$，且 $dp/da=p(1-p)$。

$$\frac{d\,\log(1-p)}{da}=-p,\qquad \frac{d\,(-\log p)}{da}=p-1$$

当 $p\to0$ (判别器很强、生成器很差) 时：
- 饱和损失的导数 $\to0$：几乎没有学习信号。
- 非饱和损失的导数 $\to-1$：仍然有较强信号推动生成器改进。

> 注意：非饱和损失不是饱和损失的"数值等价改写"，只是优化方向一致、梯度特性更好。

- **饱和生成器损失**：$L_G^{sat}=\mathbb E_z\log[1-D(G(z))]$，判别器过强时梯度可能消失。
- **非饱和生成器损失**：$L_G^{ns}=-\mathbb E_z\log D(G(z))$，在判别器较强时提供更稳定的梯度信号。
    - **关系**：两者都推动假样本评分升高，但不是数值相等的改写。

## 9-3 模式崩溃与训练困难
GAN的训练不像普通监督学习那样只有一个固定目标——**两个网络互为对手，一方变强，另一方就要适应新的对手**。这带来一系列不稳定：
**模式崩溃**：生成器发现“只画一个特别逼真的数字 8”就能骗过当前判别器，于是 100 个不同的随机输入 $z$ 全生成差不多的 8。这里的“模式”指数据中的一种类别或风格，“分布”描述各种模式出现的比例。真实手写数字有多种写法，生成器只产出一种清晰图片，不代表它学会了整个分布。
随机输入 $z$ 本身不能自动保证多样性——如果生成器学会“忽略” $z$ 的大部分变化，只利用少数能骗过判别器的模式，崩溃照样发生。
**其他困难**：
- 判别器太强 → 生成器梯度消失，学不动。
- 判别器太弱 → 生成器得不到有效反馈。
- 双方交替更新，目标随对手变化 → 容易震荡，难以收敛。

- **模式崩溃**：不同随机输入生成高度相似的样本，多样性不足。
    - **质量≠多样性**：一张图清晰，不代表生成器覆盖了全部数据模式。
- **训练不稳定**：双方目标随对手改变，强弱失衡、梯度消失、震荡都可能发生。

## 9-4 JS 散度与理想平衡
理论上，如果判别器已经充分优化到最优状态，原始 GAN 目标和一种叫 **JS 散度**的指标有关：
$$\max_D J=-\ln4+2\,\mathrm{JS}(p_{data}\Vert p_G)$$
JS 散度衡量两个分布之间的差异程度：两分布完全相同时为 0，越大表示差异越大。
理想情况下，生成分布和真实分布完全一致时，最优判别器对所有样本都给出 $1/2$ 的评分 (完全分不清真假)。

但这里有重要的**边界条件**：
1. 这个等式只在“判别器充分优化”等理想条件下成立，不是训练过程中任意时刻都成立。
2. 一个完全没学会的判别器也可能处处给 $1/2$——所以**不能仅凭评分接近 $1/2$ 就宣告训练成功**。

JS 散度还有一个局限：当两个分布几乎不重叠时 (生成图片和真实图片差距很大)，JS 散度很难提供有意义的梯度信号，这也是原始 GAN 训练困难的理论根源之一。

- **JS 散度**：$D_{\text{JS}}(P \parallel Q) = \frac{1}{2} D_{\text{KL}}\!\left(P \parallel M\right) + \frac{1}{2} D_{\text{KL}}\!\left(Q \parallel M\right)$ 衡量两个分布差异的非负指标，两分布相同时为 0。
    - **理想平衡**：分布相同时，最优判别器评分趋近 $1/2$。
    - **解释边界**：判别器总输出 $1/2$ 也可能是尚未学会，不能仅凭此判定训练完成。

## 9-5 WGAN：用“搬运距离”替代 JS 散度
既然 JS 散度在两分布相距很远时信号微弱，WGAN 换了一种思路——**Wasserstein 距离** (直观理解：把一种分布“搬运”成另一种分布，需要的最小平均代价)。
WGAN 做了几个关键改变：
**评价器 $f$ 替代判别器 $D$**：不再输出 0 到 1 的概率，而是输出**实数评分** (比如 3、−2 都可以)。
**训练方向**：$J_W=\mathbb E_x f(x)-\mathbb E_z f(G(z))$ 
- 评价器最大化 $J_W$：拉大真实样本和生成样本的平均分差。
- 生成器最小化 $L_G^W=-\mathbb E_z f(G(z))$：提高生成样本的平均评分。

**1-Lipschitz 条件**：为了让评分差真正对应 Wasserstein 距离，需要限制评价器——任意两个输入，评分变化不能超过它们本身的距离：$|f(x)-f(y)|\le\|x-y\|$ 
直观说：图片改一点点，评分不能跳得离谱。
实际训练中，有几种方式近似满足这个约束：
- **权重裁剪**：把参数限制在一个区间内。
- **梯度惩罚**：对选定位置上梯度大小偏离要求的样本增加惩罚。
- **谱归一化**：限制每层权重矩阵能放大的倍数。

> 这三种方法控制的对象不同，**不能当成严格等价的规则**。WGAN 旨在改善训练信号，但不保证彻底消除模式崩溃或所有不稳定。

- **WGAN 评价器**：输出实数评分，不必落在 0 和 1 之间；目标是扩大真假样本的平均分差。
- **1-Lipschitz 条件**：评分变化幅度受输入距离限制，保证评分差对应搬运距离。
    - **约束方法**：权重裁剪、梯度惩罚、谱归一化是不同控制方式，不等价。
- **WGAN 的局限**：改善训练信号，但不保证消除所有不稳定。

## 9-6 GAN 与 WGAN 对比总结

|       | GAN             | WGAN                   |
| ----- | --------------- | ---------------------- |
| 输出    | 判别器给 0~1 概率     | 评价器给实数评分               |
| 分布比较  | JS 散度 (相距远时信号弱) | Wasserstein 距离 (始终有信号) |
| 生成器损失 | 饱和或非饱和形式        | 直接提高生成样本评分             |
| 额外约束  | 无               | 需要控制 Lipschitz 条件      |
| 训练稳定性 | 容易梯度消失、模式崩溃     | 信号更稳定，但不保证完美           |

- **GAN**：生成器和判别器对抗训练，原始目标与 JS 散度相关，容易出现梯度消失和模式崩溃。
- **WGAN**：改用 Wasserstein 距离思想，评价器输出实数评分并控制 Lipschitz 条件，改善远距离分布下的训练信号。
    - **共同点**：两者都是生成器试图骗过评价方，评价方试图区分真假，形成对抗。
    - **核心区别**：比较分布的方式不同，WGAN 在分布相距远时仍能提供有意义的梯度。

# 10 自监督与自编码器
## 10-1 从日志补词到自监督学习
工厂积累了大量设备文字日志，但只有少量日志被人工标注为“正常”或“故障”。我们不想花大量人力给全部日志打标签。
取一条日志：“电机、温度、升高”。我们把中间的“温度”遮住，让模型根据前后词语预测被遮住的原词。答案本来就藏在原始文本里，不需要人工额外标注，但训练依然有明确目标与损失：模型会给每一个候选词输出预测概率，假设它给正确答案“温度”的概率是 $p$。我们用 $-\ln p$ 作为惩罚项。当 $p$ 越接近 1，惩罚越接近 0；$p$ 越小，惩罚越大。
这种**数据本身既作为输入，又用来构造学习目标**的方式，就是**自监督学习**。

- **自监督学习**：从原始数据中自动构造预测目标，不需要人工标签，但训练依然存在明确损失函数。

## 10-2 预训练、下游任务、微调与迁移学习
我们回到工厂日志的例子。上一节说，我们可以用"遮住一个词→让模型猜原词"的方式，不用人工打标签就能训练模型。现在问题来了：费这么大劲训练出来的模型，到底有什么用？
### 先搞懂“表示”是什么
模型在猜词的过程中，需要把每个词 (比如“电机”“温度”) 变成一组数字，比如 $(0.3, -1.2, 0.8, \ldots)$。为什么要变成数字？因为计算机做计算只能处理数字，不能直接处理文字。
这组数字就是**表示**——它把"温度"这个词的含义，用一组数字编码保存下来。经过大量日志训练之后，模型学到的表示会包含很多有用的信息：比如"温度"和"升高"经常一起出现，"电机"和"故障"有关系，等等。
关键是：这些表示不只是猜词有用，做别的事情也有用。
### 预训练：先学"基本功"
我们用"遮词猜词"这个任务，在海量无标签日志上训练模型，让它学会把词句变成好的表示。这个阶段就叫**预训练**。
你可以把它理解为：让模型先读大量书籍，积累语言常识，但还没教它具体干什么活。

- **预训练**：在通用任务上训练模型，让它学到可复用的表示和参数。

### 分类头：接一个小模块干具体的活
预训练完的模型擅长"表示词句"，但它不会直接输出"正常"或"故障"。怎么办？
很简单——在模型后面**接一个小型模块**（通常就是几层简单的计算），这个模块接收模型输出的表示，然后输出"正常/故障"的判断。这个小型模块就叫**分类头**。
打个比方：预训练好的模型像一个读了大量书的人，知识丰富但没受过专业训练；分类头就像给他加一个"速成培训班"，教他把知识转化成具体的判断。
故障分类就是我们最终想解决的问题，叫做**下游任务**。

- **分类头**：接在预训练模型后面的小型模块，把表示转换成具体任务的预测结果。
- **下游任务**：最终要解决的问题，比如判断日志是"正常"还是"故障"。

### 微调 vs 特征提取：两种适配方式
现在有了少量带标签的日志（标注了"正常"或"故障"），怎么让模型适配下游任务？有两种常见做法：
**方式一：微调**
拿少量带标签的日志，不仅训练新接的分类头，还**继续调整预训练模型本身的参数**。相当于让模型在"速成班"学习的同时，也微调一下自己脑子里的知识。这种方式通常效果更好，但需要更多数据和计算量。
**方式二：特征提取式适配**
冻结预训练模型的参数（不让它变），**只训练新接的分类头**。相当于模型脑子里的知识固定不动，只训练那个"速成培训班"。这种方式省资源，适合标签很少的情况。

- **微调**：从预训练参数出发，为下游任务更新全部或部分参数。
- **特征提取式适配**：冻结预训练模型，只训练新接的分类头。

### 迁移学习：旧知识能不能帮新任务？
预训练模型在日志上学会的表示，能不能帮到故障分类？也许能（因为"温度""升高"这些词的表示包含了有用信息），但**不能想当然**，必须在下游任务的验证数据上检验效果。
这种"把一个任务上学到的知识，用到另一个任务上"的思路，就是**迁移学习**关心的问题。

- **迁移学习**：研究旧任务学到的知识能否帮助新任务，效果需要在目标任务的数据上验证。

### 半监督：另一个角度的分类
最后澄清一个容易混淆的点。如果故障分类这个任务，同时用到少量有标签日志 + 大量无标签日志，这叫**半监督学习**。
注意，半监督和自监督**不是互斥的**：
- 自监督说的是"怎么造训练目标"（用数据自身构造，不用人工标签）
- 半监督说的是"目标任务用了哪些数据"（同时用有标签和无标签数据）

一个方案可以既是自监督（用遮词猜词造目标），又是半监督（最终分类任务同时用有标签和无标签数据）。它们是从不同角度描述同一件事。

**一句话串起来**：先用遮词猜词在大量无标签日志上**预训练**，学到好的**表示**；然后在后面接一个**分类头**，用少量标签做**微调**（或特征提取），去完成故障分类这个**下游任务**；旧知识管不管用，靠**迁移学习**的思路去验证。
## 10-3 BERT：像做完形填空一样学语言
先看视频 https://www.bilibili.com/video/BV1YfCLBgEnG?vd_source=7b1a469c7b722160938fd20dc1894993
我们继续用工厂日志的例子。上一节说了，我们可以把"温度"遮住，让模型根据前后文猜出"温度"。这种"完形填空"式的训练，就是 **BERT** 的核心思想。
### BERT 能同时看左边和右边
假设输入是："电机、MASK、升高"。BERT 在猜 MASK 是什么的时候，**既能看左边的"电机"，也能看右边的"升高"**。这种左右两边都能看的特性，叫做**双向**。
BERT 的内部结构叫做 Transformer 编码器，它有一种机制 (叫注意力)，让每个位置都能读取其他位置的信息。所以"升高"这个词的信息可以传到 MASK 位置，帮助模型判断中间应该是"温度"。
这种"遮住一些词，让模型猜原词"的任务，叫做**掩码语言建模（MLM）**。
MASK 就是一个特殊标记，意思是"这里原本有个词，你猜猜是什么"。
### 原始 BERT 的"小套路"
你可能会想：模型会不会偷懒，看到 MASK 就知道这里要猜？原始 BERT 设计了一个小规则来防止模型偷懒：
从所有词里选出大约 **15%** 的位置作为预测目标。在被选中的位置里：
- **80%** 替换成 MASK
- **10%** 替换成随机词（比如把"温度"换成"苹果"）
- **10%** 保留原词不动

所以真正被替换成 MASK 的位置，大约只占全部词元的 **12%**（15% × 80% ≈ 12%），不是 15%。这个细节很容易搞错。
### 下一句预测（NSP）
原始 BERT 还加了一个辅助任务：给模型两段文本，问它"后一段是不是前一段在原文里的真实后续？"比如：

> 段落A："电机温度升高。" 段落B："请立即停机检查。" → 可能是真实后续 ✓
> 段落A："电机温度升高。" 段落B："今天天气很好。" → 不是真实后续 ✗

这叫**下一句预测（NSP）**。注意，它**不是**预测"下一个词是什么"，而是判断两段话是否前后衔接。而且，不是所有 BERT 的改进版本都保留了这个任务。

- **BERT**：像做完形填空，可以同时看左右两边的文字来猜被遮住的词。
- **掩码语言建模（MLM）**：遮住部分输入，让模型猜被遮住的原词。
- **双向**：预测一个词时，左右两边的上下文都能利用。
- **下一句预测（NSP）**：判断两段文本是否是原文中的前后关系，是原始 BERT 的辅助任务。

## 10-4 GPT：像续写故事一样生成文字
先看视频 https://www.bilibili.com/video/BV1UjCuB1EsL?vd_source=7b1a469c7b722160938fd20dc1894993
BERT 是"完形填空"，那如果我们想让模型**续写日志**呢？比如给定"电机、温度"，让模型接着写出"升高"？这就轮到 **GPT** 出场了。
### GPT 只能看前面，不能偷看后面
GPT 的任务是：根据已有的文字（前缀），预测下一个词。比如输入"电机、温度"，模型输出"升高"。
关键在于：预测"升高"的时候，模型**只能看"电机"和"温度"**，**绝对不能看"升高"本身**（因为"升高"正是它要猜的答案）。这种"只能看历史、不能看未来"的限制，叫做**因果**。GPT 的内部结构叫做因果解码器，它的注意力机制被设计成只能读取当前位置之前的词。
这和 BERT 正好相反：BERT 猜中间的词时可以看两边，GPT 猜下一个词时只能看前面。
### 怎么生成一整段话？
生成的时候，GPT 用一种很简单的方法：把刚预测出来的词接回输入，继续预测下一个。比如：
1. 输入"电机、温度" → 输出"升高"
2. 把"升高"接回去，输入变成"电机、温度、升高" → 输出"请"
3. 再接回去 → 输出"停机"
4. 以此类推……

这样就能一段一段地续写下去。这种"用自己生成的词作为下一步输入"的方式，叫做**自回归生成**。
### BERT 和 GPT 的区别一句话总结

| | BERT | GPT |
|---|---|---|
| 做什么 | 完形填空 | 续写故事 |
| 能看什么 | 左右两边都能看 | 只能看前面的 |
| 典型用途 | 理解文字（分类、问答） | 生成文字（续写、对话） |

但要注意：这只是**典型用途**，不是"能力禁令"。BERT 也能做生成类任务，GPT 也能做理解类任务，只是它们各自更擅长不同方向。
- **GPT**：根据已有前缀预测下一个词，只能看历史，不能看未来。
- **自回归生成**：把刚生成的词接回输入，循环预测下一个词。

## 10-5 自编码器：学会"压缩还原"
前面讲的 BERT 和 GPT 都是处理文字的。现在我们换一个场景：工厂的传感器每秒钟会输出一组读数，比如四维数据 $x=(1,2,3,4)$，分别代表四个传感器的数值。
我们想让模型学会：看到一组读数，能把它**压缩**成更短的信息，再从短信息**还原**回原来的读数。这就是**自编码器（AE）**。
### 编码和解码
自编码器的流程分两步：
$$x\xrightarrow{\ f_\theta\ }h\xrightarrow{\ g_\phi\ }\hat x$$
第一步叫**编码**：编码器 $f_\theta$ 把输入 $x=(1,2,3,4)$ 变成中间表示 $h$。$h$ 的维度通常比 $x$ 短，相当于把信息压缩了。
第二步叫**解码**：解码器 $g_\phi$ 把 $h$ 还原成 $\hat x$。$\hat x$ 叫做**重构输入**，是模型"凭记忆还原"出来的结果。
$\theta$ 和 $\phi$ 分别是编码器和解码器需要学习的参数。
### 用重构误差来训练
假设模型还原出来的结果是 $\hat x=(1,1,3,2)$。我们怎么评价还原得好不好？用**逐维均方误差**：
$$r(x)=\frac14\sum_{j=1}^4(x_j-\hat x_j)^2
=\frac{(1-1)^2+(2-1)^2+(3-3)^2+(4-2)^2}{4}
=\frac{0+1+0+4}{4}=\frac54$$
这里 $j$ 是传感器分量的编号（第1个、第2个……）。训练的时候同时调整 $\theta$ 和 $\phi$，让 $r(x)$ 越来越小——也就是让还原结果越来越接近原始输入。
### 为什么要"压缩"？
如果我们让 $h$ 的维度小于 4（比如只有 2 个数），就形成了一个**低维瓶颈**。瓶颈的作用是：强迫模型不能简单地"抄作业"，必须学会提取输入中最重要的信息，丢掉不重要的细节。就像你把一本书缩写成摘要——摘要比原书短，但必须保留核心内容。
不过要注意：不是所有自编码器都必须用低维瓶颈，这只是最常见的一种做法。

- **自编码器（AE）**：由编码器和解码器组成，目标是让输出尽可能还原输入。
- **编码器**：把输入压缩成中间表示 $h=f_\theta(x)$。
- **解码器**：把中间表示还原成重构输入 $\hat x=g_\phi(h)$。
- **瓶颈**：限制中间表示的维度，迫使模型学习压缩后的核心信息。
- **重构误差**：衡量还原结果和原始输入的差距，训练目标是让它变小。

## 10-6 去噪自编码器：从"破损照片"还原原图
普通自编码器是直接把原图压缩再还原。但如果我们想让模型更鲁棒呢？
**去噪自编码器**的思路是：先给输入加点噪声（比如把 $(1,2,3,4)$ 随机改成 $(1,9,3,4)$），得到带噪版本 $\widetilde x$。然后把 $\widetilde x$ 喂给编码器，最终要求解码器还原出**干净的原始输入** $(1,2,3,4)$，而不是还原那个带噪的版本。
流程是：
$$\widetilde x\xrightarrow{\ f_\theta\ }h\xrightarrow{\ g_\phi\ }\hat x$$
损失函数比较的是 $\hat x$ 和干净的 $x$，不是和 $\widetilde x$ 比。
这样做的好处是：模型被迫学会"去噪"，也就是从混乱的输入中提取出真正的结构信息。这比单纯复制输入更有用。

> 提醒：编码器和解码器只是功能角色（一个负责压缩，一个负责还原），不要求一定用某种特定结构。普通自编码器也不保证你随便给一个随机的中间向量，就能生成合理的输出。

- **去噪自编码器**：输入是加了噪声的数据，但要求还原出干净的原始数据。

## 10-7 用自编码器检测设备故障
现在到了最关键的应用：怎么用自编码器判断设备是否异常？
### 核心思路
我们用**正常设备的传感器数据**训练自编码器。训练好后，模型对正常数据的重构误差应该很小（因为它见过很多正常数据，知道怎么还原）。
然后，来了一条新数据，我们计算它的重构误差 $r(x)$：
- 如果 $r(x)$ 很小 → 说明这条数据和正常数据很像，模型能很好地还原 → **大概率是正常的**
- 如果 $r(x)$ 很大 → 说明这条数据和正常数据差别很大，模型"不认识"，还原不好 → **可能是异常的**
### 设定阈值
我们需要一个**阈值** $\tau$ 来划一条线。规则是：
$$r(x)>\tau\Rightarrow\text{报警（判为异常）},\qquad r(x)\le\tau\Rightarrow\text{不报警（判为正常）}$$
注意是**严格大于**才报警。比如 $\tau=1$，前面算出来 $r(x)=5/4=1.25$，因为 $1.25>1$，所以**报警**。如果 $r(x)=1$，刚好等于阈值，**不报警**。
### 阈值选多低？误报和漏报的权衡
降低阈值（比如从 1 降到 0.5）会发生什么？
- 更多样本会被判为异常 → **漏报减少**（原本漏掉的异常现在能抓到了）
- 但 **误报增加**（一些正常的样本也会被误判为异常）

反过来，提高阈值 → 误报减少，但漏报增加。
所以阈值不是随便选的，要根据验证数据和业务需求来定。比如工厂宁愿多检查几次误报，也不能放过真正的故障，那就选低一点的阈值。

> 重要：阈值**不能用测试集的答案来反复调整**。测试集是最后独立检验用的，就像期末考试不能提前看答案。

### 自编码器不是万能的
最后要清楚一个边界：
- 有些异常碰巧也能被模型很好地重构（比如异常模式和正常模式很接近）
- 正常工况发生变化（比如设备正常升级），也可能产生很大的重构误差

所以，**重构误差大只是"异常线索"，不是"一定故障"的铁证**。它给你一个警报，最终判断还需要人工或其他手段确认。

- **异常分数**：自编码器的重构误差，用来衡量一条数据是否异常。
- **误报**：正常样本被误判为异常（虚惊一场）。
- **漏报**：异常样本没被检测出来（漏网之鱼）。
- **阈值选择**：根据验证数据和业务需求确定，不能用测试标签反复调。
