# 5 微分中值定理及其应用
## 5-1 定义
### 5-1-1 极值、最值、待定型
- **极大值**、**极小值**、**极大值点**、**极小值点**、**极值**、**极值点**
    - 若函数 $f(x)$ 在 $(a,b)$ 上有定义，$x_0 \in (a,b)$ ，如果存在点 $x_0$ 的某一个邻域 $O(x_0,\delta) \subset (a,b)$ 使得 $f(x) \le f(x_0),\ x\in O(x_0,\delta)$，则称 $x_0$ 是 $f(x)$ 的一个**极大值点**，$f(x_0)$ 称为相应的**极大值** 
    - 若函数 $f(x)$ 在 $(a,b)$ 上有定义，$x_0 \in (a,b)$ ，如果存在点 $x_0$ 的某一个邻域 $O(x_0,\delta) \subset (a,b)$ 使得 $f(x) \ge f(x_0),\ x\in O(x_0,\delta)$，则称 $x_0$ 是 $f(x)$ 的一个**极小值点**，$f(x_0)$ 称为相应的**极小值** 
    - 极大值和极小值统称为**极值**，极大值点和极小值点统称为**极值点** 
- **驻点**：若 $f'(x_0)=0$，则称点 $x_0$ 为 $f(x)$ 的驻点。
      容易发现，若 $f(x)$ 在极值点处可导，则该极值点必为驻点；但驻点不一定是极值点。
- **最值**、**最值点**：函数的最大值和最小值，统称为函数的**最值**，使函数取到最大值（或最小值）的点称为函数的**最大值点**（或**最小值点**），最大值点或最小值点统称为**最值点** 
    **闭区间上连续函数最值的求法**：
    - 找出 $f(x)$ 在 $(a,b)$ 内所有的驻点和导数不存在的点，记为 $x_1, x_2, \cdots, x_n$ 
    - 计算 $f(a),f(b),f(x_k),\ k=1,2,\cdots, n$ 
    - 最大值 $M = \max\{ f(a),f(b),f(x_1),\cdots, f(x_k) \}$，最小值 $m = \min\{ f(a),f(b),f(x_1),\cdots, f(x_k) \}$ 
- $\dfrac 00$ **待定型**：计算分式函数的极限时，若分子、分母的极限都是 $0$，则称这种类型的极限为 $\dfrac 00$ **待定型**，简称 $\dfrac 00$ **型** 
- $\dfrac \infty \infty$ **待定型**：计算分式函数的极限时，若分子、分母都趋于 $\infty$，则称这种类型的极限为 $\dfrac \infty\infty$ **待定型**，简称 $\dfrac \infty\infty$ **型** 
### 5-1-2 凸函数、拐点
- **下凸函数**：设函数 $f(x)$ 在区间 $I$ 上有定义，若对任意 $x_1, x_2 \in I$ 和 $\lambda \in (0,1)$ 都有 $f(\lambda x_1 + (1-\lambda)x_2) \le \lambda f(x_1) + (1-\lambda)f(x_2)$，则称 $f(x)$ 是区间 $I$ 上的**下凸函数**，或简称函数 $f(x)$ 在区间 $I$ 上是**下凸**。
- **上凸函数**：设函数 $f(x)$ 在区间 $I$ 上有定义，若对任意 $x_1, x_2 \in I$ 和 $\lambda \in (0,1)$ 都有 $f(\lambda x_1 + (1-\lambda)x_2) \ge \lambda f(x_1) + (1-\lambda)f(x_2)$，则称 $f(x)$ 是区间 $I$ 上的**上凸函数**，或简称函数 $f(x)$ 在区间 $I$ 上是**上凸**。
- **严格下凸函数**：设函数 $f(x)$ 在区间 $I$ 上有定义，若对任意 $x_1, x_2 \in I$ 和 $\lambda \in (0,1)$ 都有 $f(\lambda x_1 + (1-\lambda)x_2) < \lambda f(x_1) + (1-\lambda)f(x_2)$，则称 $f(x)$ 是区间 $I$ 上的**严格下凸函数**，或简称函数 $f(x)$ 在区间 $I$ 上是**严格下凸**。
- **严格上凸函数**：设函数 $f(x)$ 在区间 $I$ 上有定义，若对任意 $x_1, x_2 \in I$ 和 $\lambda \in (0,1)$ 都有 $f(\lambda x_1 + (1-\lambda)x_2) > \lambda f(x_1) + (1-\lambda)f(x_2)$，则称 $f(x)$ 是区间 $I$ 上的**严格上凸函数**，或简称函数 $f(x)$ 在区间 $I$ 上是**严格上凸**。
> **为何如此定义下凸函数？** 
> 曲线 $y=f(x)$ 在区间 $I$ 上下凸的特性是：曲线 $y=f(x)$ 上任意两点间的弧段总是位于这两点间的连线的下方，即 $\forall\ x_1,x_2\in I$ 且 $x_1<x_2$，曲线 $y=f(x)$ 上任意两点 $A(x_1,f(x_1)),\ B(x_2,f(x_2))$ 之间的弧段 $\overset{\LARGE\frown}{AB}$ 位于弦 $\overline{AB}$ 的下方。
> 弦所在直线方程为 $g(x) = f(x_1) + \dfrac{f(x_2)-f(x_1)}{x_2-x_1}(x-x_1)$ 
> $x_1$ 与 $x_2$ 之间的任意点可以表示为 $x=\lambda x_1 + (1-\lambda)x_2,\ 0<\lambda<1$ 
> 因此弦在曲线的上方可以用分析语言表示为 $f(\lambda x_1 + (1-\lambda)x_2) \le g(\lambda x_1 + (1-\lambda)x_2)$ 
> 整理得 $\boxed{f(\lambda x_1 + (1-\lambda)x_2) \le \lambda f(x_1) + (1-\lambda)f(x_2)}$ 
> 这启发我们给出函数凸性的概念。
> **拐点**：设函数 $f(x)$ 在 $x_0$ 处连续，若曲线 $y=f(x)$ 在点 $(x_0,f(x_0))$ 的近旁两侧分别为上凸和下凸，则称点 $(x_0, f(x_0))$ 为曲线 $y=f(x)$ 的**拐点**
>  从定义可知，拐点是曲线 $y=f(x)$ 的上凸和下凸的分界点。
### 5-1-3 渐近线
- **非垂直渐近线**：若曲线 $C:y=f(x)$ 上的动点 $P$ 到某一固定直线 $L:y=kx+b$ 的距离在 $x\rightarrow +\infty$ 或 $x\rightarrow -\infty$ 时无限趋于零，则称直线 $L$ 是曲线 $C$ 的一条**非垂直渐近线** 
    - **水平渐近线**：当 $k=0$ 时，直线 $y=b$ 称为曲线 $y=f(x)$ 的一条**水平渐近线** 
            若 $\lim\limits_{x\rightarrow \infty} f(x) = A$ 或 $\lim\limits_{x\rightarrow -\infty} = A$，则直线 $y=A$ 是曲线 $y=f(x)$ 的一条水平渐近线
    - **斜渐近线**：当 $k\not= 0$ 时，直线 $y=kx+b$ 称为曲线 $y=f(x)$ 的一条**斜渐近线** 
            若曲线有斜渐近线 $y=kx+b$，可知曲线 $y=f(x)$ 上的点 $(x, f(x))$ 到直线 $y=kx+b$ 的距离为 $\dfrac{|f(x)-kx-b|}{\sqrt{1+k^2}}$ 
            根据渐近线定义，有 $\lim\limits_{x\rightarrow + \infty} \dfrac{|f(x)-kx-b|}{\sqrt{1+k^2}} = 0$ 或 $\lim\limits_{x\rightarrow - \infty} \dfrac{|f(x)-kx-b|}{\sqrt{1+k^2}} = 0$ 
            这等价于 $\lim\limits_{x\rightarrow +\infty} (f(x) - kx - b) = 0$ 或 $\lim\limits_{x\rightarrow -\infty} (f(x) - kx - b) = 0$ 
            因此：$k = \lim\limits_{x\rightarrow +\infty} \dfrac{f(x)}x$ 或 $k = \lim\limits_{x\rightarrow -\infty} \dfrac{f(x)}x$，$b = \lim\limits_{x\rightarrow +\infty} (f(x) - kx)$ 或 $b = \lim\limits_{x\rightarrow -\infty} (f(x) - kx)$ 
    - **非垂直渐近线**包含**水平渐近线**与**斜渐近线** 
- **垂直渐近线**：若 $\lim\limits_{x\rightarrow x_0+} f(x) = \infty$ 或 $\lim\limits_{x\rightarrow x_0-} f(x) = \infty$，则称直线 $x=x_0$ 是曲线 $y=f(x)$ 的一条**垂直渐近线** 
### 5-1-4 其他
- **绝对误差**：近似值与准确值的差的绝对值称为**绝对误差** 
## 5-2 性质
- **函数的单调性**：设函数 $f(x)$ 在区间 $I$ 内可导，则：
    - $f(x)$ 在区间 $I$ 内单调增加 $\iff f'(x) \ge 0,\ \forall\ x \in I$. 特别地，当 $f'(x)>0,\ \forall\ x\in I$ 时，有 $f(x)$ 在区间 $I$ 内严格单调增加
		- *证明过程* 
		    - **充分性** 
				设 $x_1,x_2$ 是区间 $I$ 内任意两点，不妨设 $x_1 < x_2$
				由拉格朗日中值定理，有 $f(x_2)-f(x_1) = f'(\xi)(x_2-x_1),\ x_1 < \xi < x_2$
				若 $f'(x) \ge 0,\ \forall\ x\in I$，则 $f(x_2) \ge f(x_1)$，这表明 $f(x)$ 在区间 $I$ 内单调增加。
				若 $f'(x) > 0,\ \forall\ x\in I$，则 $f(x_2) > f(x_1)$，这表明 $f(x)$ 在区间 $I$ 内严格单调增加。
			- **必要性** 
				设 $f(x)$ 在区间 $I$ 内单调递增且 $x$ 是区间 $I$ 中任意一点，则对于任意 $x' \in I\ (x'\not=x)$ 成立 $\dfrac{f(x')-f(x)}{x'-x}\ge 0$ 
				令 $x' \rightarrow x$ 得到 $f'(x)\ge 0\ (x\in I)$ 
    - $f(x)$ 在区间 $I$ 内单调减少 $\iff f'(x) \le 0,\ \forall\ x \in I$. 特别地，当 $f'(x)<0,\ \forall\ x\in I$ 时，有 $f(x)$ 在区间 $I$ 内严格单调减少。
    注意，若函数 $f(x)$ 在区间 $I$ 中除有限个点外，都有 $f'(x)>0$，则函数 $f(x)$ 在区间 $I$ 中仍严格单调增加。
    因此，$f'(x)>0,\ \forall\ x\in I$ 是函数 $f(x)$ 在区间 $I$ 中严格单调增加的充分条件，而非必要条件。
- **函数的极值** 
	- 设 $f(x)$ 在点 $x_0$ 的某一邻域中有定义，且在点 $x_0$ 处连续，在某去心邻域 $O(x_0,\delta) \backslash \{x_0\}$ 内可导，则：
	    - 若当 $x_0-\delta < x < x_0$ 时有 $f'(x) \ge 0$，而当 $x_0 < x < x_0 + \delta$ 时有 $f'(x) \le 0$，则 $x_0$ 是 $f(x)$ 的极大值点
	    - 若当 $x_0-\delta < x < x_0$ 时有 $f'(x) \le 0$，而当 $x_0 < x < x_0 + \delta$ 时有 $f'(x) \ge 0$，则 $x_0$ 是 $f(x)$ 的极小值点
	    - 若 $f'(x)$ 在 $(x_0-\delta, x_0)$ 与 $(x_0, x_0+\delta)$ 上不变号，则 $x_0$ 不是 $f(x)$ 的极值点
	- 设 $f(x)$ 在点 $x_0$ 的某一邻域中有定义，且在点 $x_0$ 处连续，$f'(x_0)=0$，且 $f(x)$ 在 $x_0$ 处二阶可导，则：
	    - 若 $f''(x_0)>0$，则 $x_0$ 是 $f(x)$ 的极小值点
	    - 若 $f''(x_0)<0$，则 $x_0$ 是 $f(x)$ 的极大值点
	    - 若 $f''(x_0) = 0$，则 $x_0$ 可能是 $f(x)$ 的极值点，也可能不是 $f(x)$ 的极值点
	- 若函数 $f(x)$ 在 $x_0$ 处 $n$ 阶可导，$f'(x_0) = \cdots = f^{(n-1)}(x_0) = 0$ 且 $f^{(n)}(x)\not=0$，则：
	    - 当 $n$ 为奇数时，$x_0$ 不是极值点
	    - 当 $n$ 为偶数且 $f^{(n)}(x_0)>0$ 时，$x_0$ 是极小值点
	    - 当 $n$ 为偶数且 $f^{(n)}(x_0)<0$ 时，$x_0$ 是极大值点

- 函数 $f(x)$ 为区间 $I$ 上的下凸函数 $\iff$ 对 $I$ 中任意三点 $x_1<x_2<x_3$ 有 $\dfrac{f(x_2)-f(x_1)}{x_2-x_1} \le \dfrac{f(x_3)-f(x_2)}{x_3-x_2}$ 
	- *证明过程* 
		由于：
		$\begin{aligned} &\dfrac{f(x_2)-f(x_1)}{x_2-x_1} \le \dfrac{f(x_3)-f(x_2)}{x_3-x_2} \\ \iff& (x_3-x_2)(f(x_2)-f(x_1)) \le (x_2-x_1)(f(x_3)-f(x_2)) \\ \iff& (x_3-x_1)f(x_2) \le (x_3-x_2)f(x_1) + (x_2-x_1)f(x_3) \\ \iff& f(x_2) \le \dfrac{x_3-x_2}{x_3-x_1}f(x_1) + \dfrac{x_2-x_1}{x_3-x_1}f(x_3) \end{aligned}$ 
		令 $\lambda = \dfrac{x_3-x_2}{x_3-x_1}$，则 $0<\lambda < 1$ 且 $1-\lambda = \dfrac{x_2-x_1}{x_3-x_1},\ x_2 = \lambda x_1 + (1-\lambda)x_3$，代入上式得：
		$f(\lambda x_1 + (1-\lambda)x_3) \le \lambda f(x_1) + (1-\lambda)f(x_3)$，证毕！
    - **几何意义**：任取 $x_1 < x_2 < x_3$，对应于曲线上三点 $P_i(x_i,f(x_i)),\ i=1,2,3$，则 $f(x)$ 为区间 $I$ 上得下凸函数当且仅当 $P_1P_2$ 的斜率小于或等于 $P_2P$ 的斜率
- **凸性**：设函数 $f(x)$ 在 $[a,b]$ 上连续，在 $(a,b)$ 内可导，则 $f(x)$ 在 $[a,b]$ 为下凸函数 $\iff$ $f'(x)$ 在 $(a,b)$ 上单调增加
	- *证明过程* 
		- **充分性** 
			对 $[a,b]$ 中任意三点 $x_1,x_2,x_3$，不妨设 $x_1 < x_2 < x_3$，
			利用拉格朗日中值定理，有 $\begin{cases} \dfrac{f(x_2)-f(x_1)}{x_2-x_1} = f'(\xi_1),\quad\xi_1\in(x_1,x_2) \\ \dfrac{f(x_3)-f(x_2)}{x_3-x_2} = f'(\xi_2),\quad\xi_2\in(x_2,x_3) \end{cases}$ 
			又 $\xi_1 < \xi_2$，而 $f'(x)$ 在区间 $[a,b]$ 上单调增加，所以 $f'(\xi_1) \le f'(\xi_2)$ 
			即 $\dfrac{f(x_2)-f(x_1)}{x_2-x_1} \le \dfrac{f(x_3)-f(x_2)}{x_3-x_2}$，则 $f(x)$ 为 $[a,b]$ 上的下凸函数。
		- **必要性**
			对任意 $x_1,x_2 \in (a,b),\ x_1 < x_2$，下证：$f'(x_1) \le f'(x_2)$ 
		     取 $h>0$，使得 $x_1-h,\ x_2 + h \in (a,b)$，则有 $\dfrac{f(x_1)-f(x_1-h)}{h} \le \dfrac{f(x_2)-f(x_1)}{x_2-x_1} \le \dfrac{f(x_2+h)-f(x_2)}{h}$ 
		     令 $h\rightarrow 0+$，得到 $f'(x_1) \le \dfrac{f(x_2)-f(x_1)}{x_2-x_1} \le f'(x_2)$，这表明导函数 $f'(x)$ 在 $[a,b]$ 上单调增加。
		综上证毕！
    - **推论（二阶导数与凸性的关系）**：设函数 $f(x)$ 在区间 $I$ 上二阶可导，则 $f(x)$ 在区间 $I$ 上是下凸函数 $\iff$ 对于任意 $x\in I$ 有 $f''(x)\ge 0$。特别地，若对于任意 $x\in I$ 有 $f''(x)>0$，则 $f(x)$ 在 $I$ 上是严格下凸函数。
	    - *证明过程* 
		    **前推后**：由于 $f(x)$ 在 $I$ 上是下凸函数，由定义可以推出，对于任意 $x\in I$ 和 $\Delta x > 0$，若 $x+\Delta x$ 和 $x-\Delta x$ 都属于 $I$，取 $\lambda =\dfrac 12$则有：
		    $\dfrac{f(x+\Delta x)+f(x-\Delta x)}{2} \ge f\left( \dfrac 12(x+\Delta x) + \dfrac 12(x-\Delta x) \right) = f(x)$，所以 $f(x+\Delta x) - f(x) \ge f(x) - f(x-\Delta x)$ 
		    对于任意 $x_1,x_2\in I$，不妨设 $x_1<x_2$，令 $\Delta x_n = \dfrac{x_2-x_1}{n}$，反复利用上式，就得到：
		    $\begin{aligned}f(x_2)-f(x_2-\Delta x_n) \ge& f(x_2-\Delta x_n) - f(x_2-2\Delta x_n) \ge f(x_2-2\Delta x_n) - f(x_2-3\Delta x_n) \ge \cdots \\ \ge& f(x_2-(n-1)\Delta x_n)-f(x_2-n\Delta x_n) = f(x_1+\Delta x_n) - f(x_1)\end{aligned}$ 
		    即 $f(x_2) - f(x_2-\Delta x_n) \ge f(x_1 + \Delta x_n) - f(x_1)$，即 $\dfrac{f(x_2+(-\Delta x_n)) - f(x_2)}{(-\Delta x_n)} \ge \dfrac{f(x_1+\Delta x_n)-f(x_1)}{\Delta x_n}$ 
		    由于 $f(x)$ 在 $x_1$ 和 $x_2$ 可导，令 $n\rightarrow\infty$，则 $\Delta x_n\rightarrow 0$，便得到 $f'(x_2) \ge f'(x_1)$，即 $f'(x)$ 在 $I$ 上单调增加，因此 $f''(x)\ge 0,\ x\in I$ 
		    **后推前**：若在 $I$ 上 $f''(x)\ge 0$，则 $f'(x)$ 在 $I$ 上单调增加。
		    对 $I$ 上任意两点 $x_1, x_2$（不妨设 $x_1<x_2$）及 $\lambda \in(0,1)$，取 $x_0 = \lambda x_1 + (1-\lambda)x_2$，那么 $x_1<x_0<x_2$，且有 $\begin{cases} x_1-x_0 = (1-\lambda)(x_1-x_2) \\ x_2-x_0 = \lambda(x_2-x_1) \end{cases}$ 
		    在 $[x_1,x_0]$ 和 $[x_0,x_2]$ 上分别应用 Lagrange 中值定理，则存在 $\eta_1\in(x_1,x_0)$ 和 $\eta_2\in(x_0,x_2)$ 使得 $\begin{cases} f(x_1)=f(x_0)+f'(\eta_1)(x_1-x_0) \\ f(x_2)=f(x_0)+f'(\eta_2)(x_2-x_0) \end{cases}$ 
		    因此利用 $f'(x)$ 在 $I$ 上的单调增加性质得 $\begin{cases} f(x_1) \ge f(x_0) + f'(x_0)(x_1-x_0) = f(x_0) + (1-\lambda) f'(x_0)(x_1-x_2) \\ f(x_2) \ge f(x_0) + f'(x_0)(x_2-x_0) = f(x_0) + \lambda f'(x_0)(x_2-x_1) \end{cases}$ 
		    分别用 $\lambda$ 和 $1-\lambda$ 乘以上两式并相加得到：$\lambda f(x_1) + (1-\lambda)f(x_2) \ge f(x_0)=f(\lambda x_1 + (1-\lambda)x_2)$ 
		    由定义，$f(x)$ 在 $I$ 上是下凸函数。
- 若函数 $f(x)$ 在区间 $I$ 上连续，$(x_0-\delta,\ x_0 + \delta) \subset I$，且 $f(x)$ 在 $(x_0-\delta, x_0)$ 与 $(x_0, x_0 + \delta)$ 上二阶可导。
    - 若 $f''(x)$ 在 $(x_0-\delta, x_0)$ 与 $(x_0, x_0 + \delta)$ 上符号相反，则 $(x_0,f(x_0))$ 是曲线 $y=f(x)$ 的拐点
    - 若 $f''(x)$ 在 $(x_0-\delta, x_0)$ 与 $(x_0, x_0 + \delta)$ 上符号相同，则 $(x_0,f(x_0))$ 不是曲线 $y=f(x)$ 的拐点
- 设 $f(x)$ 在 $(x_0-\delta, x_0+\delta)$ 上二阶可导，若 $(x_0, f(x_0))$ 为曲线 $y=f(x)$ 的拐点，则 $f''(x_0) = 0$ 
	- *证明过程*
		由于点 $(x_0,f(x_0))$ 是曲线 $y=f(x)$ 的拐点，不妨设曲线 $y=f(x)$ 在 $(x_0-\delta, x_0)$ 上是下凸的，在 $(x_0, x_0+\delta)$ 上是上凸的。
		由 $f(x)$ 二阶可导，以及二阶导数与凸性的关系，可知在 $(x_0-\delta,x_0)$ 上 $f''(x_0) \ge 0$，在 $(x_0, x_0+\delta)$ 上 $f''(x_0)\le 0$ 
		换言之，$f'(x)$ 在 $(x_0-\delta, x_0)$ 上单调增加，而在 $(x_0, x_0+\delta)$ 上单调递减，即 $x_0$ 点是 $f'(x)$ 的极大值点。
		再由 $f''(x_0)$ 的存在性与费马引理，得到 $f''(x_0) = 0$，证毕！
	- 注意：这里给出的是二阶可导函数曲线的拐点所满足的必要条件，而非充分条件。如：$y=x^4$ 上的 $(0,0)$ 点满足条件 $f''(0)=0$，但它不是拐点。
	- 注意：由曲线 $y=x^{\frac 13}$ 可知，即使 $f''(x)$ 在 $x_0$ 点不存在，点 $(x_0,f(x_0))$ 也可能是曲线 $y=f(x)$ 的拐点。
	- 注意：当我们通过对 $f(x)$ 求二阶导数来确定拐点的话，既要考虑满足 $f''(x)=0$ 的点，又要考虑 $f''(x)$ 不存在的点
	- 这个性质说明：若 $(x_0,f(x_0))$ 为曲线 $y=f(x)$ 的拐点，则 $f''(x_0) = 0$ 或者 $f''(x_0)$ 不存在。

## 5-3 定理
### 5-3-1 微分中值定理
- **费马引理（Fermat 引理）**：若函数 $f(x)$ 在点 $x_0$ 处可导，且 $x_0$ 是 $f(x)$ 的极值点，则 $f'(x_0) = 0$ 
	- *证明过程* 
		不妨设 $x_0$ 是 $f(x)$ 的极大值点。根据极值的定义，必存在 $\delta > 0$，使得 $f(x) \le f(x_0),\ \forall\ x \in O(x_0,\delta)$ 
		由于 $f(x)$ 在点 $x_0$ 处可导，所以 $f'(x_0) = \lim\limits_{x\rightarrow x_0}\dfrac{f(x)-f(x_0)}{x-x_0} = \lim\limits_{x\rightarrow x_0+}\dfrac{f(x)-f(x_0)}{x-x_0} = \lim\limits_{x\rightarrow x_0-}\dfrac{f(x)-f(x_0)}{x-x_0}$ 
		- 当 $x>x_0$ 时，有 $\dfrac{f(x)-f(x_0)}{x-x_0} \le 0$，令 $x\rightarrow x_0+$，得到 $f'(x_0) = \lim\limits_{x\rightarrow x_0+} \dfrac{f(x)-f(x_0)}{x-x_0} \le 0$ 
		- 当 $x<x_0$ 时，有 $\dfrac{f(x)-f(x_0)}{x-x_0} \ge 0$，令 $x\rightarrow x_0-$，得到 $f'(x_0) = \lim\limits_{x\rightarrow x_0-} \dfrac{f(x)-f(x_0)}{x-x_0} \ge 0$ 
		综上 $f'(x_0)=0$ 
- **罗尔定理（Rolle 定理）**：若函数 $f(x)$ 在闭区间 $[a,b]$ 上连续，在 $(a,b)$ 内可导，且 $f(a) = f(b)$，则在 $(a,b)$ 内至少存在一点 $\xi$，使得 $f'(\xi)=0$ 
	- *证明过程* 
		由于 $f(x)$ 在 $[a,b]$ 上连续，所以 $f(x)$ 在 $[a,b]$ 上必有最大值 $M$ 和最小值 $m$，于是存在 $\xi, \eta \in [a,b]$ 使得 $f(\xi) = M, f(\eta) = m$，这样只有两种可能情形：
		- 若 $M=m$，此时 $f(x)$ 在 $[a,b]$ 上为常数函数，因此对任取 $\xi \in(a,b)$，都有 $f'(\xi)=0$ 
		- 若 $M>m$，由于 $f(a)=f(b)$，所以 $M,m$ 至少有一个不等于 $f(a)$，不妨设 $M\not= f(a)$，这表明最大值在开区间 $(a,b)$ 内，此时最大值也是极大值，即 $\xi \in (a,b)$ 为一个极大值点，由**费马定理**可知 $f'(\xi)=0$ 
		综上证毕。
- **拉格朗日中值定理（Lagrange 中值定理）**：若函数 $f(x)$ 在闭区间 $[a,b]$ 上连续，在 $(a,b)$ 内可导，则在 $(a,b)$ 内至少存在一点 $\xi$，使得 $f'(\xi) = \dfrac{f(b)-f(a)}{b-a}$ 
      可见，拉格朗日中值定理是罗尔定理的推广。
	- *证明过程*
		**法 1** 
		过两点 $A(a,f(a))$ 和 $B(b,f(b))$ 的割线 $AB$ 的方程为 $y=f(a) + \dfrac{f(b)-f(a)}{b-a}(x-a)$ 
		设辅助函数 $\varphi(x)$ 是函数 $f(x)$ 与割线 $AB$ 的纵坐标之差，即 $\varphi(x) = f(x) - f(a) - \dfrac{f(b)-f(a)}{b-a}(x-a)$ 
		由于 $f(x)$ 在闭区间 $[a,b]$ 上连续，在 $(a,b)$ 内可导，所以 $\varphi(x)$ 也在闭区间 $[a,b]$ 上连续，在 $(a,b)$ 内可导，并且有 $\varphi(a) = \varphi(b)$ 
		由罗尔定理，至少存在一点 $\xi \in (a,b)$ 使得 $\varphi'(\xi) = 0$ 
		而 $\varphi'(x) = f'(x) - \dfrac{f(b)-f(a)}{b-a}$，由 $\varphi'(\xi)=0$ 得到 $f'(\xi) = \dfrac{f(b)-f(a)}{b-a}$ 
		因为不论 $a < b$ 或 $a>b$，比值 $\dfrac{f(b)-f(a)}{b-a}$ 不变，所以定理的结论对 $a<b$ 或 $a>b$ 都成立。
		**法 2** 
		构造 $\psi(x) = \begin{vmatrix} x&f(x)&1 \\ a&f(a)&1 \\ b&f(b)&1 \end{vmatrix}$，则 $\psi'(x) = \begin{vmatrix} a&f'(x)&0 \\ a&f(a)&1 \\ b&f(b)&1 \end{vmatrix} = f'(x)(b-a)-[f(b)-f(a)] = 0$ 
		显然 $\psi(a) = \psi(b) = 0$，且满足 Rolle 定理条件。
		由 Rolle 定理，在 $(a,b)$ 内存在一点 $\xi$ 使得 $\psi'(\xi)=f'(\xi)(b-a)-[f(b)-f(a)]=0$，所以 Lagrange 中值定理证毕！
		其中 $\psi(x)$ 的**几何意义**为以 $(x,f(x)),(a,f(a)),(b,f(b))$ 为顶点的三角形如果顶点逆时针排列，则 $\psi(x)$ 就是三角形面积的两倍，否则 $-\psi(x)$ 就是三角形面积的两倍
	- 定理中的公式也可以写成 $f(b)-f(a) = f'(\xi)(b-a), \ \xi \in (a,b)$，通常称为**拉格朗日中值公式**。
	- 由于 $\xi \in (a,b)$，令 $\theta = \dfrac{\xi - a}{b-a}$，则 $0<\theta < 1$，这时 $\xi = a + \theta(b-a)$，所以拉格朗日中值公式也可以写成 $f(b)-f(a) = f'(a+\theta(b-a))(b-a),\ \theta\in(0,1)$ 
	- 若记 $a$ 为 $x$，$b-a$ 为 $\Delta x$，则上式又可以表示为 $f(x+\Delta x) - f(x) = f'(x+\theta\Delta x) \Delta x, \ \theta \in (0,1)$. 这个公式即为 $\Delta y = f'(x+\theta\Delta x)\Delta x$，它给出了自变量、因变量的差分和函数的导数值的精确关系（可与 $\Delta y = f'(x)\Delta x + o(\Delta x)$ 进行比较）
	- **推论 1**：若函数 $f(x)$ 在 $(a,b)$ 内可导，且 $f'(x) \equiv 0,\ \forall\ x\in (a,b)$，则 $f(x)$ 在 $(a,b)$ 上恒为常数
	    - *证明过程* 
		    设 $x_1, x_2\ (x_1<x_2)$ 是区间 $(a,b)$ 中任意两点，在 $[x_1,x_2]$ 上应用 Lagrange 中值定理，则存在 $\xi \in (x_1, x_2) \subset (a,b)$ 使得 $f(x_2)-f(x_1) = f'(\xi)(x_2 - x_1)$，由 $f'(\xi)=0$ 有 $f(x_1)=f(x_2)$ 
		    由 $x_1,x_2$ 的任意性，就得到 $f(x)=C,\ x\in(a,b)$ 
	- **推论 2**：若函数 $f(x),g(x)$ 在 $(a,b)$ 内可导，且 $f'(x) = g'(x),\ \forall\ x\in(a,b)$，则对任意 $x\in (a,b)$，有 $f(x) = g(x) + C$，其中 $C$ 为常数
- **柯西中值定理**：若函数 $f(x),g(x)$ 在闭区间 $[a,b]$ 上连续，在 $(a,b)$ 内可导，且 $\forall\ x\in(a,b)$ 有 $g'(x)\not=0$，则至少存在一点 $\xi \in (a,b)$，使得 $\dfrac{f'(\xi)}{g'(\xi)} = \dfrac{f(b)-f(a)}{g(b)-g(a)}$ 
      可见，柯西中值定理是拉格朗日中值定理的推广。
	- *证明过程* 
		**法 1** 
		由 $\forall\ x\in(a,b),\ g'(x) \not= 0$ 可知 $g(a)\not=g(b)$，作辅助函数 $\varphi(x) = f(x) - f(a) - \dfrac{f(b)-f(a)}{g(b)-g(a)}(g(x)-g(a))$ 
		由定理的条件，有 $\varphi(x)$ 也在闭区间 $[a,b]$ 上连续，在 $(a,b)$ 上可导，并且有 $\varphi(a) = \varphi(b)$ 
		由罗尔定理，至少存在一点 $\xi\in(a,b)$，使得 $\varphi'(\xi) = 0$ 
		而 $\varphi'(x) = f'(x) - \dfrac{f(b)-f(a)}{g(b)-g(a)}g'(x)$，由 $\varphi'(\xi)=0$ 得到 $\dfrac{f'(\xi)}{g'(\xi)} = \dfrac{f(b)-f(a)}{g(b)-g(a)}$，证毕！
		其中 $\varphi(t)$ 的**几何意义**为：参数方程 $\begin{cases} x=g(t) \\ y=f(t) \end{cases}$ 所表示的曲线上点的纵坐标与联结点 $(g(a),f(a))$ 和点 $(g(b),f(b))$ 的直线段上点的纵坐标之差。
		**法 2** 
		由闭区间上连续函数的性质，且 $g(x)$ 在 $[a,b]$ 上连续，在 $(a,b)$ 上可导，且导函数恒不为零，可用反证法容易证明：$g(x)$ 在 $[a,b]$ 上严格单调，不妨设 $g(x)$ 严格单调增加
		记 $g(a) = \alpha,\ g(b) = \beta$，由**反函数存在定理**和**反函数导数存在定理**，在 $[\alpha, \beta]$ 上存在 $y=g(x)$ 的反函数 $x=g^{-1}(y)$，$g^{-1}(y)$ 在 $[\alpha, \beta]$ 上连续，在 $(\alpha, \beta)$ 上可导，且 $[g^{-1}(y)]' = \dfrac 1{g'(x)}$，且 $g^{-1}(y)$ 在 $[\alpha, \beta]$ 上也是严格单调增加的
		构造 $[\alpha, \beta]$ 上的辅助函数 $F(y) = f(g^{-1}(y))$，由定理条件和上述讨论，可知 $F(y)$ 在 $[\alpha, \beta]$ 上满足 **Lagrange 中值定理**的 2 个条件（闭区间连续、开区间可导），故存在 $\eta \in(\alpha, \beta)$ 使得 ${\color{blue}F'(\eta)} = \dfrac{F(\beta)-F(\alpha)}{\beta-\alpha} = \dfrac{f(g^{-1}(\beta)) - f(g^{-1}(\alpha))}{\beta - \alpha} = {\color{blue}\dfrac{f(b)-(a)}{g(b)-g(a)}}$ 
		由 $g(x)$ 和 $g^{-1}(x)$ 的关系， 在 $(a,b)$ 中一定存在一点 $\xi$，满足 $g(\xi) = \eta$（即 $\xi = g^{-1}(\eta)$），则：
		${\color{blue}F'(\eta)} = \left.[f(g^{-1}(y))]'\ \right|_{y=\eta} = \left.\{ f'(g^{-1}(y)) \cdot [g^{-1}(y)]' \}\ \right|_{y=\eta} = \left.\left\{ f'(x) \cdot \dfrac 1{g'(x)} \right\}\ \right|_{x=g^{-1}(\eta)=\xi} = {\color{blue}\dfrac{f'(\xi)}{g'(\xi)}}$ 
		由蓝色式子可知：$\dfrac{f'(\xi)}{g'(\xi)} = \dfrac{f(b)-f(a)}{g(b)-g(a)}$，证毕！
		**法 3** 
		构造函数 $\psi(x) = \begin{vmatrix} g(x)&f(x)&1 \\ g(a)&f(a)&1 \\ g(b)&f(b)&1 \end{vmatrix}$，则 $\psi'(x) = \begin{vmatrix} g'(x)&f'(x)&0 \\ g(a)&f(a)&1 \\ g(b)&f(b)&1 \end{vmatrix} = g'(x)[f(a)-f(b)] - f'(x)[g(a)-g(b)]$ 
		由于 $\psi(a)=\psi(b)=0$，应用 Rolle 定理，必存在 $\xi\in (a,b)$ 使得 $\psi'(\xi) = g'(\xi)[f(a)-f(b)]-f'(\xi)[g(a)-g(b)]=0$ 
		于是 Cauchy 中值定理成立
		其中 $\psi(x)$ 的**几何意义**：其绝对值等于由 $(g(x),f(x)),\ (g(a),f(a)),\ (g(b),f(b))$ 为顶点的三角形面积的两倍。如果三顶点按照逆时针方向排列，则 $\psi(x)$ 的符号为正，否则为负。
    - 柯西中值定理也常写成 $\dfrac{f(b)-f(a)}{g(b)-g(a)} = \dfrac{f'(a+\theta(b-a))}{g'(a+\theta(b-a))}$，其中 $0 < \theta < 1$，但我们不要求 $b>a$ 
- **微分中值定理**：对于罗尔定理、拉格朗日中值定理、柯西中值定理，前一个定理都是后一个定理的特例，它们统称为“**微分中值定理**”
    这三个定理的共同特征是：
    - 对所研究的函数，要求在闭区间 $[a,b]$ 上连续，在 $(a,b)$ 内可导
    - 在结论中都断言在开区间 $(a,b)$ 内至少存在一点 $\xi$，定理只是说明这种点的“存在性”，但这种点到底有多少个以及在什么位置，定理都没有给出。除了一些比较简单的函数，一般都很难精确求出 $\xi$ 的值。
    - 三个中值定理各自适合不同的场合，是我们利用导数研究函数性态的强有力的工具。
- **Darboux 定理**：设 $f(x)$ 在 $(a,b)$ 上可导，$x_1, x_2 \in(a,b)$。如果 $f'(x_1)\cdot f'(x_2) < 0$，证明在 $x_1$ 和 $x_2$ 之间至少存在一点 $\xi$，使得 $f'(\xi)=0$ 
	- *证明过程* 
		显然 $x_1\not= x_2$，不妨设 $x_1<x_2$，以及 $f'(x_1)>0,\ f'(x_2)<0$ 
		则有：$f'(x_1) = \lim\limits_{x\rightarrow x_1} \dfrac{f(x)-f(x_1)}{x-x_1} > 0$，根据保序性，可知存在 $\delta >0$，使得对于任意 $x(-\delta<x-x_1<\delta)$ 有 $\dfrac{f(x)-f(x_1)}{x-x_1}>0$，任取一个 $x_3$ 满足 $<x_1<x_3<x_1+\delta$，则有 $f(x_3)>f(x_1)$，即存在 $x_3$ 使得 $x_1<x_3$ 且 $f(x_1)<f(x_3)$ 
		同理可证存在 $x_4$ 使得 $x_4<x_2$ 且 $f(x_2)<f(x_4)$ 
		因此 $x_1,x_2$ 都不是 $f(x)$ 的最大值点，于是 $f(x)$ 在 $[x_1,x_2]$ 的最大值点 $\xi \in (x_1,x_2)$ 且 $f'(\xi)=0$ 
		其余情况同理可证
### 5-3-2 洛必达法则（L'Hospital 法则）
- （$\dfrac 00$ **型**）若 $f(x),g(x)$ 满足：
	1. $f(x),g(x)$ 在 $(a,a+\delta]$ 内可导（$\delta$ 是某个正数），且 $g'(x)\not=0$
	2. $\lim\limits_{x\rightarrow a+} f(x) = \lim\limits_{x\rightarrow a+} g(x) = 0$
	3. $\lim\limits_{x\rightarrow a+} \dfrac{f'(x)}{g'(x)} = A$（可以是有限数或 $\infty,\ +\infty,\ -\infty$）
	则 $\lim\limits_{x\rightarrow a+} \dfrac{f(x)}{g(x)} = \lim\limits_{x\rightarrow a+} \dfrac{f'(x)}{g'(x)} = A$ 
	（注 $x\rightarrow a-,\ a,\ \infty,\ +\infty,\ -\infty$ 时也成立）
	- *证明过程*（只详细证明 $x\rightarrow a+$ 和 $x\rightarrow +\infty$ 的情形）
		- 当 $x\rightarrow a+$ 时
		      由于函数在 $x=a$ 处的取值与 $x\rightarrow a+$ 时的极限无关，故可以补充定义 $f(a)=g(a) = 0$，使得 $f(x)$ 与 $g(x)$ 在 $[a,a+\delta]$ 上连续。这样，经补充定义后的函数 $f(x)$ 和 $g(x)$ 在 $(a,a+\delta)$ 上满足 Cauchy 中值定理的条件
		      当 $x\in(a, a+\delta)$ 时，便可对函数 $f(x)$ 与 $g(x)$ 在区间 $[a,x]$ 上应用柯西中值定理，则存在 $a<\xi < x$ 使得 $\dfrac{f(x)}{g(x)} = \dfrac{f(x)-f(a)}{g(x)-g(a)} = \dfrac{f'(\xi)}{g'(\xi)}$ 
		      当 $x\rightarrow a+$ 时，有 $\xi \rightarrow a+$，由于 $\lim\limits_{x\rightarrow a+} \dfrac{f(x)}{g(x)}$ 存在，两端令 $x\rightarrow a+$，则有：
		      $\lim\limits_{x\rightarrow a+} \dfrac{f(x)}{g(x)} = \lim\limits_{\xi\rightarrow a+} \dfrac{f'(\xi)}{g'(\xi)} = \lim\limits_{x\rightarrow a+} \dfrac{f'(x)}{g'(x)} = A$，证毕！
		      $x\rightarrow a-,\ a$ 时类似可证，这里略。
		- 当 $x\rightarrow +\infty$ 时
		      作变量代换 $x=\dfrac 1t$，则当 $x\rightarrow +\infty$ 时，有 $t\rightarrow +0$，于是
		      $\lim\limits_{x\rightarrow +\infty} \dfrac{f(x)}{g(x)} = \lim\limits_{t\rightarrow 0+} \dfrac{f\left( \dfrac 1t \right)}{g\left( \dfrac 1t \right)} = \lim\limits_{t\rightarrow 0+} \dfrac{f'\left( \dfrac 1t \right)\left( -\dfrac 1{t^2} \right)}{g'\left( \dfrac 1t \right)\left( -\dfrac 1{t^2} \right)} = \lim\limits_{t\rightarrow 0+} \dfrac{f'\left( \dfrac 1t \right)}{g'\left( \dfrac 1t \right)} = \lim\limits_{x\rightarrow +\infty} \dfrac{f'(x)}{g'(x)} = A$，证毕！
		      $x\rightarrow -\infty,\ \infty$ 时类似可证，这里略。
- （$\dfrac \infty \infty$ **型**）若 $f(x),g(x)$ 满足：
	1. $f(x),g(x)$ 在 $(a,a+\delta]$ 内可导（$\delta$ 是某个正数），且 $g'(x)\not=0$ 
	2. $\lim\limits_{x\rightarrow a+} g(x) = \infty$ 
	3. $\lim\limits_{x\rightarrow a+} \dfrac{f'(x)}{g'(x)} = A$（可以是有限数或 $\infty,\ +\infty,\ -\infty$）
	则 $\lim\limits_{x\rightarrow a+} \dfrac{f(x)}{g(x)} = \lim\limits_{x\rightarrow a+} \dfrac{f'(x)}{g'(x)} = A$ 
	（注 $x\rightarrow a-,\ a,\ \infty,\ +\infty,\ -\infty$ 时也成立）
	- *证明过程*（只详细证明 $x\rightarrow a+$ 且 $A$ 为有限数的情形）
		我们只对 $A$ 为有限数的情形来证明
		设 $x_0$ 是 $(a,a+\delta]$ 内任意一个固定的点，当 $x\not= x_0$ 时，有
		$\begin{aligned} \dfrac{f(x)}{g(x)} &= \dfrac{f(x)-f(x_0)}{g(x)} + \dfrac{f(x_0)}{g(x)} \\ &= \dfrac{g(x)-g(x_0)}{g(x)} \cdot \dfrac{f(x)-f(x_0)}{g(x)-g(x_0)} + \dfrac{f(x_0)}{g(x)} \\ &= \left[ 1 - \dfrac{g(x_0)}{g(x)} \right] \dfrac{f(x)-f(x_0)}{g(x)-g(x_0)} + \dfrac{f(x_0)}{g(x)} \end{aligned}$ 
		而 $A = \left[ 1 - \dfrac{g(x_0)}{g(x)} \right]A + \dfrac{g(x_0)}{g(x)}A$，于是
		$\dfrac{f(x)}{g(x)} - A = \left[ 1 - \dfrac{g(x_0)}{g(x)} \right] \cdot \left[ \dfrac{f(x)-f(x_0)}{g(x) - g(x_0)} - A \right] + \dfrac{f(x_0) - Ag(x_0)}{g(x)}$ 
		从而 $\left|\dfrac{f(x)}{g(x)} - A\right| \le \left| 1 - \dfrac{g(x_0)}{g(x)} \right| \cdot \left| \dfrac{f(x)-f(x_0)}{g(x) - g(x_0)} - A \right| + \left| \dfrac{f(x_0) - Ag(x_0)}{g(x)}\right|$ 
		因为 $\lim\limits_{x\rightarrow a+} \dfrac{f'(x)}{g'(x)} = A$，所以 $\forall\ \varepsilon>0,\ \exists\ \eta>0$，不妨设 $0<\eta < \delta$，当 $a < x < a + \eta$ 时，有 $\left| \dfrac{f'(x)}{g'(x)} - A \right| < \varepsilon$ 
		取定 $x_0 = a+\eta$，由柯西中值定理，对任意 $a < x < x_0$，存在 $\xi \in (x, x_0)$，使得 $\left| \dfrac{f(x)-f(x_0)}{g(x)-g(x_0)} - A \right| = \left| \dfrac{f'(\xi)}{g'(\xi)} - A \right| < \varepsilon$ 
		又由于 $\lim\limits_{x\rightarrow a+} g(x) = \infty$，所以 $\lim\limits_{x\rightarrow a+} \left( 1 - \dfrac{g(x_0)}{g(x)} \right) = 1,\ \lim\limits_{x\rightarrow a+} \dfrac{f(x_0)-Ag(x_0)}{g(x)} = 0$ 
		由极限存在的局部有界性知：当 $x \rightarrow a+$ 时，表达式
		$\left| \dfrac{f(x)}{g(x)} - A\right|  \le \left|  1 - \dfrac{g(x_0)}{g(x)} \right|  \cdot \left|  \dfrac{f(x)-f(x_0)}{g(x) - g(x_0)} - A \right|  + \left|  \dfrac{f(x_0) - Ag(x_0)}{g(x)}\right|$ 中，右边两项都可以任意小，这样就证明了 $\lim\limits_{x\rightarrow a+} \dfrac{f(x)}{g(x)} = A$ 
		证毕！
		（注：$x\rightarrow a-,\ a,\ +\infty,\ -\infty,\ \infty$ 和 $A$ 为 $\infty,\ +\infty,\ -\infty$ 时，上述定理的结论仍然成立）
	- 注意：定理的证明只用到条件 $\lim\limits_{x\rightarrow a+} g(x) = \infty$，对 $f(x)$ 的变化趋势没有任何要求。即当 $x\rightarrow a+$ 时，无论 $f(x)$ 有无极限、有界或无界，只要 $\lim\limits_{x\rightarrow a+} \dfrac{f'(x)}{g'(x)}$ 存在，定理的结论仍然成立，所以尽管习惯上大家将它称作“$\dfrac{\infty}{\infty}$ 型”，但实际上其应用范围为 “$\dfrac{*}{\infty}$ 型”，“$*$” 可以是任意变化类型。
- 注意：当 $\lim\limits_{x\rightarrow a^+} \dfrac{f(x)}{g(x)}$ 不是 $\dfrac 00$ 型或 $\dfrac{*}{\infty}$ 型时，不能使用 L'Hospital 法则，否则将会造成错误。
- 注意：L'Hospital 法则只告诉我们，对于 $\dfrac 00$ 型或 $\dfrac{*}{\infty}$ 型，当 $\lim\limits_{x\rightarrow a^+} \dfrac{f'(x)}{g'(x)}$ 存在时，它的值等于 $\lim\limits_{x\rightarrow a^+}\dfrac{f(x)}{g(x)}$。但 $\lim\limits_{x\rightarrow a^+} \dfrac{f'(x)}{g'(x)}$ 不存在时并不表示 $\lim\limits_{x\rightarrow a^+} \dfrac{f(x)}{g(x)}$ 本身存在或者不存在，它仅仅意味着，此时不能使用 L'Hospital 法则，而应改用其他方法来讨论 $\lim\limits_{x\rightarrow a^+}\dfrac{f(x)}{g(x)}$ 
### 5-3-3 泰勒公式（Taylor 公式）
有两类多项式的逼近问题：一类是研究在一点的充分小的邻域内的逼近问题；另一类是研究在一个区间上的逼近问题

- $n$ **次泰勒多项式**：设函数 $f(x)$ 在 $x_0$ 点处有 $n$ 阶导数，我们把多项式 $P_n(x) = f(x_0) + f'(x_0)(x-x_0) + \dfrac{f''(x_0)}{2!}(x-x_0)^2 + \cdots + \dfrac{f^{(n)}(x_0)}{n!}(x-x_0)^n =\sum\limits_{k=0}^n \dfrac{f^{(k)}(x_0)}{k!}(x-x_0)^k$ 称为 $f(x)$ 在 $x_0$ 处的 $n$ **次泰勒多项式** 
- **带佩亚诺（Peano）余项的泰勒公式**：若函数 $f(x)$ 在 $x_0$ 处有 $n$ 阶导数，即 $f^{(n)}(x_0)$ 存在，则当 $x\rightarrow x_0$ 时，有：
      $f(x) = f(x_0) + f'(x_0)(x-x_0) + \dfrac{f''(x_0)}{2!}(x-x_0)^2 + \cdots + \dfrac{f^{(n)}(x_0)}{n!}(x-x_0)^n + o((x-x_0)^n)$ 
      即 $f(x) = \sum\limits_{k=0}^n \dfrac{f^{(k)}(x_0)}{k!}(x-x_0)^k + o((x-x_0)^n)$。我们把 $f(x) = \sum\limits_{k=0}^n \dfrac{f^{(k)}(x_0)}{k!}(x-x_0)^k + o((x-x_0)^n)$ 称为函数 $f(x)$ 在 $x_0$ 处的**带佩亚诺余项的泰勒公式** 
    - *证明过程*
		令 $r_n(x) = f(x) - \sum\limits_{k=0}^n \dfrac{f^{(k)}(x_0)}{k!}(x-x_0)^k$，只需证明 $r_n(x) = o((x-x_0)^n)\ (x\rightarrow x_0)$，即证 $\lim\limits_{x\rightarrow x_0} \dfrac{r_n(x)}{(x-x_0)^n} = 0$ 
		由于 $r_n^{(j)}(x) = f^{(j)}(x) - \sum\limits_{k=j}^n \dfrac{f^{(k)}(x_0)}{k!} \cdot \dfrac{k!}{(k-j)!} (x-x_0)^{k-j} = f^{(j)}(x) - \sum\limits_{k=j}^n \dfrac{f^{(k)}(x_0)}{(k-j)!} (x-x_0)^{k-j},\ (j=1,2,\cdots, n-1)$ 
		显然 $r_n(x_0) = r_n'(x_0) = r_n''(x_0) = \cdots = r_n^{(n-1)}(x_0) = 0$，应用 $n-1$ 次洛必达法则：
		$\begin{aligned} \lim\limits_{x\rightarrow x_0} \dfrac{r_n(x)}{(x-x_0)^n} &= \lim\limits_{x\rightarrow x_0} \dfrac{r_n'(x)}{n(x-x_0)^{n-1}} = \lim\limits_{x\rightarrow x_0} \dfrac{r_n''(x)}{n(n-1)(x-x_0)^{n-2}} = \cdots \\ &= \dfrac{r_n^{(n-1)}(x)}{n(n-1)\cdots 2(x-x_0)} \\ &= \dfrac{1}{n!} \lim\limits_{x\rightarrow x_0} \left[ \dfrac{f^{(n-1)}(x) - f^{(n-1)}(x_0) - f^{(n)}(x_0)(x-x_0)}{x-x_0} \right] \\ &= \dfrac{1}{n!} \left[ \lim\limits_{x\rightarrow x_0} \dfrac{f^{(n-1)}(x)-f^{(n-1)}(x_0)}{x-x_0} - f^{(n)}(x_0) \right] \\ &= \dfrac{1}{n!} [f^{(n)}(x) - f^{(n)}(x)] = 0 \end{aligned}$ 
		故 $r_n(x) = o((x-x_0)^n)\ (x\rightarrow x_0)$，证毕！
		思考：为何不能直接用 n 次洛必达？
    - **泰勒公式的余项**：我们设 $\begin{cases} P_n(x) =\sum\limits_{k=0}^n \dfrac{f^{(k)}(x_0)}{k!}(x-x_0)^k \\ r_n(x) = o((x-x_0)^n) \end{cases}$，则 $r_n(x) = f(x) - P_n(x)$ 称为**佩亚诺余项** 
    - 值得指出的是，若函数 $f(x)$ 在 $x_0$ 处有 $n$ 阶导数，且在点 $x_0$ 附近成立 $f(x) = \sum\limits_{k=0}^n a_k(x-x_0)^k + o((x-x_0)^n)$，则必有 $a_k = \dfrac{f^{(k)}(x_0)}{k!},\ (k=0,1,2,\cdots,n)$。该结果表明：函数的泰勒公式是唯一的（点我看证明过程）
    - **定理**：若函数 $f(x)$ 在 $x_0$ 的某邻域内有 $n+1$ 阶导数，则它的 $n+1$ 次泰勒多项式的导数就是 $f'(x)$ 的 $n$ 次泰勒多项式（点我看证明过程）
- **带拉格朗日（Lagrange）余项的泰勒公式**：设函数 $f(x)$ 在 $[a,b]$ 上具有 $n$ 阶连续导数，在开区间 $(a,b)$ 内有 $n+1$ 阶导数，$x_0$ 为 $[a,b]$ 内的一个定点，则对任意 $x\in [a,b]$ 有 $f(x) = f(x_0) + f'(x_0)(x-x_0) + \dfrac{f''(x_0)}{2!}(x-x_0)^2 + \cdots + \dfrac{f^{(n)}(x_0)}{n!}(x-x_0)^n + r_n(x) =\sum\limits_{k=0}^n \dfrac{f^{(k)}(x_0)}{k!}(x-x_0)^k + r_n(x)$，其中 $r_n(x) = \dfrac{f^{(n+1)}(\xi)}{(n+1)!}(x-x_0)^{n+1}$，$\xi$ 在 $x_0$ 和 $x$ 之间。
	- 上述公式称为 $f(x)$ 在 $x_0$ 处的**带拉格朗日余项的泰勒公式**，$r_n(x)$ 称为**拉格朗日余项** 
    - *证明过程* 
		作辅助函数 $F(t) = f(x) - \sum\limits_{k=0}^n \dfrac{f^{(k)}(t)}{k!}(x-t)^k$ 和 $G(t) = (x-t)^{n+1}$（注意这是关于 $t$ 的函数，这里的 $x$ 为一个常数）则有：
		$F(x)=G(x)=0$ 
		$\begin{aligned} F'(t) =& -\sum\limits_{k=0}^n \dfrac{f^{(k+1)}(t)}{k!} (x-t)^k + \sum\limits_{k=0}^n \dfrac{f^{(k)}(t)}{k!}k(x-t)^{k-1} = -\sum\limits_{k=0}^n \dfrac{f^{(k+1)}(t)}{k!} (x-t)^k + \sum\limits_{k=1}^n \dfrac{f^{(k)}(t)}{k!}k(x-t)^{k-1} \\ =& -\sum\limits_{k=0}^n \dfrac{f^{(k+1)}(t)}{k!} (x-t)^k + \sum\limits_{k=1}^n \dfrac{f^{(k)}(t)}{(k-1)!}(x-t)^{k-1} = -\sum\limits_{k=0}^n \dfrac{f^{(k+1)}(t)}{k!} (x-t)^k + \sum\limits_{k=0}^{n-1} \dfrac{f^{(k+1)}(t)}{k!}(x-t)^k \\ =& -\dfrac{f^{(n+1)}(t)}{n!} (x-t)^n \end{aligned}$ 
		$G'(t) = -(n+1)(x-t)^n$ 
		$F(t), G(t)$ 在区间 $[x_0,x]$（或 $[x,x_0]$）上连续，在区间 $(x_0,x)$（或 $(x,x_0)$）上可导
		$\forall\ t \in (x_0, x)$ 或 $(x, x_0)$ 有 $G'(t) \not= 0$ 
		综上 $F(t), G(t)$ 在区间 $[x_0,x]$（或 $[x,x_0]$）上满足**柯西中值定理**的条件，且 $\begin{cases} F(x) = G(x) = 0,\\ F'(t) = -\dfrac{f^{(n+1)}(t)}{n!}(x-t)^n \\ G'(t) = -(n+1)(x-t)^n \end{cases}$ 
		于是 $\dfrac{F(x_0)}{G(x_0)} = \dfrac{F(x_0) - F(x)}{G(x_0) - G(x)} = \dfrac{F'(\xi)}{G'(\xi)} = \dfrac{f^{(n+1)}(\xi)}{(n+1)!}$，由此得到 $f(x) = \sum\limits_{k=0}^n \dfrac{f^{(k)}(x_0)}{k!}(x-x_0)^k + \dfrac{f^{(n+1)}(\xi)}{(n+1)!}(x-x_0)^{n+1}$，证毕！
    - 拉格朗日余项 $r_n(x)$ 中 $\xi$ 经常写为 $\xi = x_0 + \theta(x-x_0)$，其中 $0<\theta < 1$ 
	- $n=0$ 时，带拉格朗日余项的泰勒公式变为 $f(x) = f(x_0) + f'(\xi)(x-x_0)$，$\xi$ 在 $x_0$ 和 $x$ 之间，这正是拉格朗日中值定理的结果。因此，带拉格朗日余项的泰勒公式可以看成拉格朗日中值定理的推广。
	- **定理**：设 $f(x)$ 在 $x_0$ 的某个邻域有 $n+2$ 阶导数存在，则它的 $n+1$ 次泰勒多项式的导数恰为 $f'(x)$ 的 $n$ 次 Taylor 多项式
- 实际应用中，我们经常将
	- 带 Lagrange 余项的 Taylor 公式写成 $f(x+\Delta x) = f(x) + f'(x)\Delta x + \dfrac{f''(x)}{2!}\Delta x^2 + \cdots + \dfrac{f^{(n)}(x)}{n!}\Delta x^n + \dfrac{f^{(n+1)}(x+\theta\Delta x)}{(n+1)!}\Delta x^{n+1}\ \theta \in (0,1)$ 
	- 带 Peano 余项的 Taylor 公式写成 $f(x+\Delta x) = f(x) + f'(x)\Delta x + \dfrac{f''(x)}{2!}\Delta x^2 + \cdots + \dfrac{f^{(n)}(x)}{n!}\Delta x^n + o(\Delta x^n)$ 
- 设 $f(x)$ 在 $[0,1]$ 上具有二阶导数，且 $[0,1]$ 上成立 $|f(x)| \le A,\ |f''(x)| \le B$，则 $|f'(x)| \le 2A + \dfrac 12B,\ x\in[0,1]$

### 5-3-4 插值多项式
- 设函数 $f(x)$ 在 $[a,b]$ 上的 $m+1$ 个互异点 $x_0, x_1, \cdots, x_m$ 上的函数值和若干阶导数值 $f^{(j)}(x_i)\ (i=0,1,2,\cdots, m,\ j=0,1,\cdots, n_i-1)$ 是已知的，记 $\sum\limits_{i=0}^m n_i = n+1$。若存在一个 $n$ 次多项式 $p_n(x)$，满足如下的**插值条件**：$p_n^{(j)}(x_i) = f^{(j)}(x_i)\ (i=0,1,2,\cdots, m,\ j=0,1,2,\cdots, n_i-1)$，则称 $p_n(x)$ 是 $f(x)$ 在 $[a,b]$ 上关于**插值节点**（一般简称节点）$x_0,x_1,\cdots, x_m$ 的 $n$ **次插值多项式**，而 $r_n(x) = f(x) - p_n(x)$ 称为**插值余项** 
      可知 $n_i$ 表示在点 $x_i$ 出所知道的值的个数，令 $m_j$ 表示已知 $j$ 阶导数值的点的个数，则有：
    - 当 $\max\{n_i\} \le j \le n+1$ 时，$m_j=0$ 
    - $\sum\limits_{j=0}^{n+1} m_j = \sum\limits_{i=0}^m n_i = n + 1$ 
      **定理**：满足上述插值条件的插值多项式存在且唯一（通过**代数基本定理**即可证明）
- **引理**：设函数 $g(x)$ 在 $[a,b]$ 上连续，在 $(a,b)$ 上可导，在 $[a,b]$ 上的 $l_0$ 个不同的点上有 $g(x)=0$，同时在其中的 $l_1$ 个点上有 $g'(x)=0$，则 $g'(x)$ 在 $[a,b]$ 内至少有 $l_0+ l_1 - 1$ 个不同的零点。（由罗尔定理很容易证明）
- **插值多项式的余项定理**：设 $f(x)$ 在 $[a,b]$ 上具有 $n$ 阶连续导数，在 $(a,b)$ 上有 $n+1$ 阶导数，且 $f(x)$ 在 $[a,b]$ 上的 $m+1$ 个互异点 $x_0, x_1, \cdots, x_m$ 上的函数值和若干阶导数值 $f^{(j)}(x_i)\ \left(i=0,1,2,\cdots, m,\ j=0,1,\cdots,n_i+1,\ \sum\limits_{i=0}^m n_i = n+1 \right)$ 是已知的，则对于任意 $x \in [a,b]$，上述插值问题有余项估计 $r_n(x) = f(x) - p_n(x) = \dfrac{f^{(n+1)}(\xi)}{(n+1)!} \prod\limits_{i=0}^m (x-x_i)^{n_i}$，这里 $\xi$ 是介于 $x_{\min} = \min(x_0, x_1, \cdots, x_m, x)$ 和 $x_{\max} = \max(x_0, x_1, \cdots, x_m, x)$ 之间的一个数（一般依赖于 $x$）
    - *证明过程* 
		设 $x$ 是 $[a,b]$ 中任一给定值
		当 $x$ 恰为某个插值节点时，则余项估计式两端 $f(x) - p_n(x) = \dfrac{f^{(n+1)}(\xi)}{(n+1)!} \prod\limits_{i=0}^m (x-x_i)^{n_i} = 0$，结论成立
		设 $x \not= x_i\ (i=0,1,2,\cdots, m)$，记 $n+1$ 次多项式 $\omega(t) = \prod\limits_{i=0}^m (t-x_i)^{n_i}$，并作辅助函数 $\varphi(t) = f(t) - p_n(t) - \dfrac{\omega_{n+1}(t)}{\omega_{n+1}(x)} (f(x) - p_n(x))$ 
		则有：$\begin{cases} \varphi^{(j)}(x_i) = f^{(j)}(x_i) - p_n^{(j)}(x_i) - \dfrac{\omega_{n+1}^{(j)}(x_i)}{\omega_{n+1}(x)}(f(x)-p_n(x)) = 0 \\ \varphi(x) = f(x) - p_n(x) - \dfrac{\omega_{n+1}(x)}{\omega_{n+1}(x)}(f(x)-p_n(x)) = 0 \end{cases}$，故使 $\varphi(t)=0$ 的点至少为 $m_0+1$ 个，使 $\varphi^{(j)}(t) = 0$ 的点的个数至少为 $m_j,\ (j=1,\cdots,n+1)$ 
		则在区间 $[x_{\min}, x_{\max}]$ 内，$\varphi'(t)$ 至少有 $m_0+m_1$ 个互异的零点，$\varphi''(t)$ 至少有 $m_0+m_1+m_2-1$ 个互异的零点……用数学归纳法容易证明，当 $j \le n+1$ 时，在区间 $[x_{\min}, x_{\max}] \subset [a,b]$ 内，$\varphi^{(j)}(t)$ 至少有 $\sum\limits_{l=0}^j m_l - j + 1$ 个互异的零点
		当 $j=n+1$ 时，$\sum\limits_{l=0}^{n+1} m_l - (n+1) + 1 = \sum\limits_{l=0}^{n+1} m_l - n = (n+1)-n = 1$，所以，至少应有 $1$ 个点 $\xi \in (x_{\min}, x_{\max})$ 使得 $\varphi^{(n+1)}(\xi) = 0$（请思考为什么这一点必定属于开区间）
		因为 $p_n(t)$ 是 $n$ 次多项式，所以 $p_n^{(n+1)}(t) = 0$，而 $\omega_{n+1}(t)$ 是 $n+1$ 次的首一多项式，因此 $\omega_{n+1}^{(n+1)}(t) = (n+1)!$，于是：
		$0 = \varphi^{(n+1)}(\xi) = f^{(n+1)}(\xi) - \dfrac{(n+1)!}{\omega_{m+1}(x)}(f(x)-p_n(x))$ 
		故 $r_n(x) = f(x) - p_n(x) = \dfrac{f^{(n+1)}(\xi)}{(n+1)!} \omega_{n+1}(x) = \dfrac{f^{(n+1)}(\xi)}{(n+1)!}\prod\limits_{i=0}^m (x-x_i)^{n_i}$ 
- **Lagrange 插值多项式** 
      这是一个常用的插值多项式，满足 $n_0 = n_1 = \cdots = n_m = 1,\ m=n$ 
      此时，$n+1$ 个插值条件均为函数值，即 $p_n(x_i) = f(x_i),\ \quad i=0,1,2,\cdots, n$ 
      可知它的插值余项为 $r_n(x) = \dfrac{f^{(n+1)}(\xi)}{(n+1)!} \prod\limits_{i=0}^m (x-x_i), \quad \xi\in(x_{\min}, x_{\max})$ 
      下面我们用**基函数法**来具体构造 $p_n(x)$：如果能够找到一组 $n$ 次多项式 $q_k(x),\ k=0,1,2\cdots, n$ 满足 $q_k(x_i) = \delta_{ik}$，这里 $\delta_{ik} = \begin{cases} 0 & i\not= k \\ 1 & i=k \end{cases}$ 称为 **Kronecker 记号**。则容易验证 $p_n(x) = \sum\limits_{k=0}^n f(x_k)q_k(x)$ 就是满足条件的插值多项式（可知是唯一的），其中函数 $\{q_k(x)\}_{k=0}^n$ 称为**基函数** 
      根据**插值多项式的余项定理**的证明过程中定义的 $n+1$ 次多项式 $\omega_{n+1}(x)$ 以及插值条件，基函数 $\{q_k(x)\}_{k=0}^n$ 可取为 $q_k(x) = \dfrac{\omega_{n+1}(x)}{(x-x_k)\omega'_{n+1}(x_k)} = \dfrac{\prod\limits_{\substack{i=0\\i\not= k}}^n(x-x_i)}{\prod\limits_{\substack{i=0\\i\not= k}}^n(x_k-x_i)},\quad k=0,1,2,\cdots, n$ 
      于是我们就得到了 $f(x)$ 的 $n$ 次插值多项式 $p_n(x) = \sum\limits_{k=0}^n \left[ f(x_k) \prod\limits_{\substack{i=0\\i\not= k}}^n \dfrac{(x-x_i)}{(x_k-x_i)} \right]$，这被称为 **Lagrange 插值多项式**。
- **Taylor 公式** 
      这是一个常用的插值多项式，满足 $n_0 = n + 1, m = 0$ 
      此时，插值节点只剩下一个 $x_0$，而 $n+1$ 个插值条件成了这一点上的函数值与各阶导数值，即 $p_n(x)$ 满足 $p_n^{(j)}(x_0) = f^{(j)}(x_0), \quad j=0,1,2,\cdots, n$ 
      考虑 $k$ 次多项式 $q_k(x) = \dfrac{(x-x_0)^k}{k!}, \quad k=0,1,2,\cdots, n$，则显然有 $q_k^{(j)}(x_0) = \delta_{jk}$，于是它们构成了一组基函数，作 $p_n(x) = \sum\limits_{k=0}^n f^{(k)}(x_0)q_k(x)$，易知 $p_n(x)$ 就是满足条件的插项多项式
      代入 $f(x) = p_n(x) + r_n(x)$ 可以得到**带 Lagrange 余项的 Taylor 公式**：
      $f(x) = f(x_0) + f'(x_0)(x-x_0) + \dfrac{f''(x_0)}{2!}(x-x_0)^2 + \cdots + \dfrac{f^{(n)}(x_0)}{n!}(x-x_0)^n + r_n(x) =\sum\limits_{k=0}^n \dfrac{f^{(k)}(x_0)}{k!}(x-x_0)^k + r_n(x)$，其中 $r_n(x) = \dfrac{f^{(n+1)}(\xi)}{(n+1)!}(x-x_0)^{n+1}$，$\xi$ 在 $x_0$ 和 $x$ 之间。
### 5-3-5 其他
- **詹森（Jensen）不等式** 
    - 设 $f(x)$ 为区间 $I$ 的下凸函数，则对于任意的 $x_1,x_2,\cdots,x_n \in I$ 和任意的 $\sum\limits_{i=1}^n \lambda_i = 1\quad (\lambda_i > 0)$，有 $f\left( \sum\limits_{i=1}^n \lambda_i x_i \right) \le \sum\limits_{i=1}^n \lambda_if(x_i)$，特别地，取 $\lambda_i = \dfrac 1n,\ i=1,2,\cdots, n$，得到 $f\left( \sum\limits_{i=1}^n \dfrac 1n x_i \right) \le \sum\limits_{i=1}^n \dfrac 1n f(x_i)$ 
	    - *证明过程* 
		    $k=2$ 时，由下凸函数定义可知 Jensen 不等式成立，现在假设当 $k=n-1$ 时 Jensen 不等式成立，则当 $k=n$ 时：
		    $\begin{aligned} f\left(\sum\limits_{i=1}^n \lambda_ix_i\right) =& f\left( \sum\limits_{i=1}^{n-1} \lambda_i x_i + \lambda_nx_n \right) = f\left( \left( \sum\limits_{i=1}^{n-1}\lambda_i \right) \cdot \dfrac{\sum\limits_{i=1}^{n-1}\lambda_i x_i}{\sum\limits_{i=1}^{n-1}\lambda_i} + \lambda_nx_n \right) \\ \le& \left(\sum\limits_{i=1}^{n-1}\lambda_i \right) f\left( \dfrac{\sum\limits_{i=1}^{n-1}\lambda_ix_i}{\sum\limits_{i=1}^{n-1}\lambda_i} \right) +\lambda_nf(x_n) \le \left( \sum\limits_{i=1}^{n-1}\lambda_i \right) \sum\limits_{i=1}^{n-1} \left( \dfrac{\lambda_i}{\sum\limits_{i=1}^{n-1}\lambda_i} f(x_i) \right) + \lambda_nf(x_n) \\ =&\sum_{i=1}^{n-1} \lambda_if(x_i) + \lambda_nf(x_n) = \sum_{i=1}^n \lambda_if(x_i) \end{aligned}$ 
		    由数学归纳法可知，Jensen 不等式 $f\left( \sum\limits_{i=1}^n \lambda_i x_i \right) \le \sum\limits_{i=1}^n \lambda_if(x_i)$ 对一切正整数 $n$ 成立
    - 设 $f(x)$ 为区间 $I$ 的上凸函数，则对于任意的 $x_1,x_2,\cdots,x_n \in I$ 和任意的 $\sum\limits_{i=1}^n \lambda_i = 1\quad (\lambda_i > 0)$，有 $f\left( \sum\limits_{i=1}^n \lambda_i x_i \right) \ge \sum\limits_{i=1}^n \lambda_if(x_i)$，特别地，取 $\lambda_i = \dfrac 1n,\ i=1,2,\cdots, n$，得到 $f\left( \sum\limits_{i=1}^n \dfrac 1n x_i \right) \ge \sum\limits_{i=1}^n \dfrac 1n f(x_i)$ 
	    - *证明过程* 
		    $k=2$ 时，由上凸函数定义可知 Jensen 不等式成立，现在假设当 $k=n-1$ 时 Jensen 不等式成立，则当 $k=n$ 时：
		    $\begin{aligned} f\left(\sum\limits_{i=1}^n \lambda_ix_i\right) =& f\left( \sum\limits_{i=1}^{n-1} \lambda_i x_i + \lambda_nx_n \right) = f\left( \left( \sum\limits_{i=1}^{n-1}\lambda_i \right) \cdot \dfrac{\sum\limits_{i=1}^{n-1}\lambda_i x_i}{\sum\limits_{i=1}^{n-1}\lambda_i} + \lambda_nx_n \right) \\ \ge& \left(\sum\limits_{i=1}^{n-1}\lambda_i \right) f\left( \dfrac{\sum\limits_{i=1}^{n-1}\lambda_ix_i}{\sum\limits_{i=1}^{n-1}\lambda_i} \right) +\lambda_nf(x_n) \ge \left( \sum\limits_{i=1}^{n-1}\lambda_i \right) \sum\limits_{i=1}^{n-1} \left( \dfrac{\lambda_i}{\sum\limits_{i=1}^{n-1}\lambda_i} f(x_i) \right) + \lambda_nf(x_n) \\ =&\sum_{i=1}^{n-1} \lambda_if(x_i) + \lambda_nf(x_n) = \sum_{i=1}^n \lambda_if(x_i) \end{aligned}$ 
		    由数学归纳法可知，Jensen 不等式 $f\left( \sum\limits_{i=1}^n \lambda_i x_i \right) \ge \sum\limits_{i=1}^n \lambda_if(x_i)$ 对一切正整数 $n$ 成立
## 5-4 应用
### 5-4-1 泰勒公式的应用
- **麦克劳林（Maclaurin）公式**：考虑函数 $f(x)$ 在 $x=0$ 处的 Taylor 公式，即 $f(x) = f(0) + f'(0)x + \dfrac{f''(0)}{2!}x^2 + \cdots + \dfrac{f^{(n)}(0)}{n!}x^n + r_n(x)$，其中 $r_n(x)$ 有 Peano 余项与 Lagrange 余项两种表示形式，即有 $r_n(x) = o(x^n)$ 或 $r_n(x) = \dfrac{f^{(n+1)}(\theta x)}{(n+1)!} x^{n+1},\ \theta \in (0,1)$。函数 $f(x)$ 在 $x=0$ 处的 Taylor 公式又称为函数 $f(x)$ 的 **Maclaurin 公式** 
- 泰勒公式还可以用来近似计算、求极限、证明不等式、求曲线的渐近方程、外推等
- **近似计算**：必须注意，Taylor 公式只是一种局部性质，因此在用它进行近似计算时，$x$ 不能远离 $x_0$，否则效果会比较差
- **外推**：**外推**是一种通过将精度较低的近似值进行适当组合，产生精度较高的近似值的方法，它的基础是 Taylor 公式。
    **外推的原理简述** 
    若对于某个值 $a$，按参数 $h$ 算出的近似值 $a_1(h)$ 可以展开成 $a_1(h) = a + c_1h + c_2h^2 + c_3h^3 + \cdots$（这里无需在意 $c_i$ 的具体形式）
    按参数 $\dfrac h2$ 算出的近似值 $a_1 \left( \dfrac h2 \right) = a + \dfrac 12 c_1h + \dfrac 14 c_2h^2 + \dfrac 18 c_3h^3$ 
    可知 $a_1(h),\ a_1\left( \dfrac h2 \right)$ 与准确值 $a$ 的误差都是 $O(h)$ 阶的。
    则可以得到： $a_2(h) = \dfrac {2a_1\left(\dfrac h2\right) - a_1(h)}{2-1} = a + d_2h^2 + d_3h^3 + \cdots$ 
    故：对两个 $O(h)$ 阶的近似值化了少量几步四则运算进行组合之后，却得到了具有 $O(h^2)$ 阶的近似值 $a_2(h)$，这样的过程就称为**外推** 
    这样的外推可以进行很多次，如进行 $k-1$ 步，直到 $a_k(h) = \dfrac{2^{k-1}a_{k-1}\left(\dfrac h2\right) - a_{k-1}(h)}{2^{k-1}-1} = a + O(h^k)$ 满足预先给定的精度。
    外推方法能够以较小的代价获得高精度的结果，是一种非常重要的近似计算技术。
### 5-4-2 函数作图
函数作图的过程一般可分为以下几个步骤：
1. 考察函数 $f(x)$ 的**定义域**及其在定义域内的**连续性**，找出函数的**不连续点**，并以这些点作为分点，将定义域分成若干个区间，使函数在每个区间上**连续**。
2. 计算 $f'(x)$，找出 $f(x)$ 的**驻点**与**导数不存在的点**，从而求出 $f(x)$ 的**极值点**与**极值**，并以这些点为分点，对区间进行再划分，使函数在每个区间上保持**单调**。
3. 计算 $f''(x)$，找出所有**使** $f''(x)=0$ **的点**与**使** $f''(x)$ **不存在的点**，从而求出 $f(x)$ 的**拐点**，并以这些点为分点，继续对区间进行再划分，使函数在每个区间上保持固定的**凸性**。
4. 对前三个步骤所得到的结果列出表格，在表格中标出函数在每个分点上的函数值（如果有定义的话），以及函数在每个区间上的单调性与凸性。
5. 求出曲线 $y=f(x)$ 的**渐近线**，包括水平渐近线、垂直渐近线和斜渐近线。
注意：在作图之前，应该先考察函数的几何性质奇偶性、周期性等，如 $f(x)$ 是奇函数或偶函数，那么只要画出一般图形，而另一半可通过对称画出；对于周期函数，只要画出一个周期的图形就可以了，而其余部分可通过周期延拓画出。
### 5-4-3 最大利润原理
对产品从生产到销售的过程进行经济核算时，至少要涉及三个方面的问题：**成本**、**收益**、**利润** 
设产量为 $Q$，则总成本 $C(Q)$ 一般可以表示成两部分的和 $C(Q) = f + v(Q) \cdot Q$ 
- $f>0$ 称为**固定成本**，一般可以认为与产量的大小无关
- $v(Q) \cdot Q$ 称为**可变成本**，$v(Q)$ 是一个正值函数，表示在总共生产 $Q$ 件产品的情况下，每生产一件的可变成本，最简单的情形是 $v(Q)=v=\text{正常数}$ 
- $C(Q)$ 的导数 $C'(Q)$ 称为**边际成本**，其经济学意义是在总共生产 $Q$ 间产品的情况下，生产第 $Q$ 件产品的成本
- **总收益** $E(Q) = p(Q) \cdot Q$ 是指把 $Q$ 件产品销售出去后得到的收入，这里 $p(Q)$ 称为**价格函数**，表示在总共生产 $Q$ 件产品的情况下，每件产品的销售价格。一般来说，生产量越大，每件产品的价格就越便宜，因此 $p(Q)$ 是 $Q$ 的单调减少函数。
- $E(Q)$ 的导数 $E'(Q)$ 相应地称为**边际收益**，其经济学意义是在总共生产销售了 $Q$ 件产品地情况下，销售出第 $Q$ 件产品所得到的收入
- 总收益减去总成本便是**总利润**。将**利润函数**记为 $P(Q)$，则 $P(Q) = E(Q) - C(Q)$ 
- 当 $E(Q)$ 和 $C(Q)$ 二阶可导时，就可以得到经济学中的**最大利润原理**：当且仅当边际成本与边际收益相等，并且边际成本的变化率大于边际收益的变化率时，可取得最大利润。
      更严格地讲：当且仅当 $P'(Q)=0$ 且 $P''(Q)<0$ 时，$P(Q)$ 有最大值
