# 2 数列极限
## 2-1 定义
- **封闭的**：若一个集合中的任意两个元素进行了某种运算后，所得的结果仍属于这个集合，我们称该集合对这种运算是**封闭的**。
- **整数点**、**离散性**：整数集合 $\mathbb Z$ 的每一个元素都能在数轴上找到自己的对应点，这些点称为**整数点**，因为它们之间的最小间隔为 1，我们称整数系 $\mathbb Z$ 具有**离散性**。
- **有理点**、**稠密性**：有理数集合 $\mathbb Q$ 的每一个元素 $\dfrac qp\ (p\in \mathbb{N^+},\ q\in\mathbb{Z})$ 也都能在这坐标轴上找到自己的对应点，这些点称为**有理点**。容易知道，在坐标轴的任意一段长度大于 0 的线段上，总存在无穷多个有理点。换句话说，在坐标轴上不存在有理点的“真空”地带，我们称有理数系 $\mathbb Q$ 具有**稠密性**。
- **无理点**、**连续性**：全体无理数对应的点（称为**无理点**）确实填满了有理点在坐标轴上的所有“空隙”，即实数铺满了整个数轴。这样，每个实数都可以在坐标轴上找到自己的对应点，而坐标轴上的每个点又可以通过自己的坐标表示唯一一个实数。实数集合的这一性质被称为实数系 $\mathbb R$ 的**连续性**。 为了强调实数系所特有的这种连续性，$\mathbb R$ 又被称为**实数连续统**，而那条表示实数全体的坐标轴又称为**数轴**。 后面的“确界存在定理”就是实数系连续性的分析学表述之一。
- **实数系的完备性**：由实数构成的基本数列 $\{x_n\}$ 必存在实数极限，这一性质称为实数系的**完备性** 
- **最大数**、**最小数**：设 $S$ 是一个数集
    - 如果 $\exists\ \xi\in S, \text{ s.t. } \forall\ x\in S,\ x\le\xi$，则称 $\xi$ 是数集 $S$ 的**最大数**，记为 $\xi = \max S$         
    - 如果 $\exists\ \eta\in S, \text{ s.t. } \forall\ x\in S,\ x\ge\eta$，则称 $\eta$ 是数集 $S$ 的**最小数**，记为 $\eta = \min S$ 
- **上界**、**下界**、**有界集**、**上确界**、**下确界**：设 $S$ 是一个非空数集：
    - 如果 $\exists\ M \in \mathbb R, \text{ s.t. } \forall\ x\in S,\ x \le M$，则称 $M$ 是 $S$ 的一个**上界**。
    - 如果 $\exists\ m \in \mathbb R, \text{ s.t. } \forall\ x\in S,\ x \ge m$，则称 $m$ 是 $S$ 的一个**下界**。
    - 当数集 $S$ 既有上界又有下界时，称 $S$ 为**有界集**。
            显然：$S\text{ 为有界集} \iff \exists\ X>0,\text{ s.t. } \forall\ x\in S,\ |x|\le X$ 
    - 设数集 $S$ 有上界，记 $U$ 为 $S$ 的上界全体所组成的集合，可证 $U$ 有最小数 $\beta$，则 $\beta$ 就为数集 $S$ 的**上确界**，即最小上界，记为 $\beta = \sup S$，上确界 $\beta$ 满足下述两个性质：
        - $\beta$ 是数集 $S$ 的上界：$\forall\ x\in S,\ x\le\beta$ 
        - 任何小于 $\beta$ 的数不是数集 $S$ 的上界：$\forall\ \varepsilon > 0,\ \exists\ x\in S, \text{ s.t. } x>\beta-\varepsilon$ 
    - 设数集 $S$ 有下界，记 $L$ 为 $S$ 的下界全体所组成的集合，可证 $L$ 有最大数 $\alpha$，则 $\alpha$ 就为数集 $S$ 的**下确界**，即最大下界，记为 $\alpha = \inf S$，下确界 $\alpha$ 满足下述两个性质：
        - $\alpha$ 是数集 $S$ 的下界：$\forall\ x\in S,\ x\ge\alpha$ 
        - 任何大于 $\alpha$ 的数不是数集 $S$ 的下界：$\forall\ \varepsilon > 0,\ \exists\ x\in S, \text{ s.t. } x<\alpha+\varepsilon$ 
- **数列**、**通项**：**数列**是指按正整数编了号的一串数：$x_1,x_2,\cdots,x_n,\cdots$，通常表示成 $\{x_n\}$，其中 $x_n$ 称为该数列的**通项**。第一项是 $x_1$，第二项是 $x_2$……第 $n$ 项是 $x_n$，等等。
- **极限**、**收敛**、**发散**：设 $\{x_n\}$ 是一给定数列，$a$ 是一个实常数。如果对于任意给定的 $\varepsilon > 0$，可以找到正整数 $N$，使得当 $n>N$ 时，成立 $|x_n-a|<\varepsilon$，则称数列 $\{x_n\}$ **收敛于** $a$（或 $a$ 是数列 $\{x_n\}$ 的**极限**），记为 $\lim\limits_{n\rightarrow \infty} x_n = a$，有时也记为 $x_n\rightarrow a\ (n\rightarrow \infty)$ 
      符号表述：$\forall\ \varepsilon > 0,\ \exists\ N,\ \forall\ n>N:\ |x_n-a| < \varepsilon$ 
      如果不存在实数 $a$，使 $\{x_n\}$ 收敛于 $a$，则称数列 $\{x_n\}$ **发散**。
- **邻域**：以 $a$ 为中心，$\varepsilon$为半径的一个开区间 $(a-\varepsilon, a+\varepsilon)$，称它为点 $a$ 的 $\varepsilon$ **邻域**，记为 $O(a,\varepsilon)$，即 $O(a,\varepsilon) = \{x \mid a-\varepsilon < x < a + \varepsilon\}$ 
- **无穷小量**：我们称极限为 $0$ 的数列为**无穷小量**。
- **有界数列**：一个数列若既有上界又有下界，则称之为**有界数列**。
      **有界数列的一个等价定义**：存在正实数 $X$，是数列的所有项都满足 $|x_n|  \le X,\ n=1,2,3,\cdots$ 
- **无穷大量**：对于任意给定的 $G>0$，可以找到正整数 $N$，使得当 $n>N$ 时成立 $|x_n|>G$，则称数列 $\{x_n\}$ 是**无穷大量**，记为 $\lim\limits_{n\rightarrow\infty} x_n = \infty$ 
      符号表述：$\forall\ G>0,\ \exists\ N,\ \forall\ n>N:\ |x_n|>G$ 
- **正、负、定号无穷大量**：如果无穷大量 $\{x_n\}$ 从某一项开始都是正的，则称其为**正无穷大量**。如果无穷大量 $\{x_n\}$ 从某一项开始都是负的，则称其为**负无穷大量**。正无穷大量和负无穷大量统称为**定号无穷大量**。
- **待定型**：若分别以 $+\infty,\ -\infty,\ \infty,\ 0$ 分别表示正无穷大量、负无穷大量、无穷大量、无穷小量，则易知 $\infty \pm \infty,\ (+\infty)-(+\infty),\ (+\infty) + (-\infty),\ 0 \cdot \infty,\ \dfrac 00,\ \dfrac{\infty}{\infty}$ 等极限，其结果可以是无穷小量，或非零极限，或无穷大量，也可以没有极限，我们称这种类型的极限为**待定型**。
- **单调增加数列**、**严格单调增加数列**：如果数列 $\{x_n\}$ 满足 $x_n \le x_{n+1},\ n=1,2,3,\cdots$，则称 $\{x_n\}$ 为**单调增加数列**；若进一步满足 $x_n < x_{n+1},\ n=1,2,3,\cdots$，则称 $\{x_n\}$ 为**严格单调增加数列**。
	- **注意**：因为数列前面有限项的变化不会影响它的收敛性，所以下面我们谈到单调数列的场合，都可以将“从某一项开始为单调的数列”统统包括在内。
- **单调减少数列**、**严格单调减少数列**：如果数列 $\{x_n\}$ 满足 $x_n \ge x_{n+1},\ n=1,2,3,\cdots$，则称 $\{x_n\}$ 为**单调减少数列**；若进一步满足 $x_n > x_{n+1},\ n=1,2,3,\cdots$，则称 $\{x_n\}$ 为**严格单调减少数列**。
	- **注意**：因为数列前面有限项的变化不会影响它的收敛性，所以下面我们谈到单调数列的场合，都可以将“从某一项开始为单调的数列”统统包括在内。
- $\pi$：定义 $\pi = \lim\limits_{n\rightarrow\infty} n\sin\dfrac{180^\circ}{n}$ 
	- *证明 $\lim\limits_{n\rightarrow\infty} n\sin\dfrac{180^\circ}{n}$ 收敛* 
		令 $L_n = n\sin\dfrac{180^\circ}{n}$ 
		令 $t = \dfrac{180^\circ}{n(n+1)}$，当 $n\ge 3$ 时，$nt \le 45^\circ$ 
		于是 $\tan nt = \dfrac{\tan(n-1)t + \tan t}{1 - \tan(n-1)t\tan t} \ge \tan(n-1)t + \tan t$，同理可得 $\tan(n-1)t \ge \tan(n-2)t + \tan t$ 
		往复下去，得到 $\tan nt \ge n\tan t$（$n\ge 3$）
		从而 $\sin(n+1)t = \sin nt\cos t + \cos nt\sin t = \sin nt\cos t\left( 1 + \dfrac{\tan t}{\tan nt} \right) \le \dfrac{n+1}n \sin nt$，即 $\sin\dfrac{180^\circ}{n} \le \dfrac{n+1}n \sin \dfrac{180^\circ}{n+1}$ 
		所以 $L_n = n\sin\dfrac{180^\circ}{n} \le (n+1)\sin\dfrac{180^\circ}{n+1}=L_{n+1}$ 
		而对于单位圆内正 $n$ 边形的面积 $S_n = \dfrac 12 n\sin\dfrac{360^\circ}{n} =n\sin\dfrac{180^\circ}{n}\cos\dfrac{180^\circ}{n} < 2\times 2 = 4$，也就有 $n\sin\dfrac{180^\circ}{n}\cos\dfrac{180^\circ}{n} < 4$ 
		因此 $L_n = n\sin\dfrac{180^\circ}{n} < \dfrac{4}{\cos\dfrac{180^\circ}{n}} \le \dfrac{4}{\cos60^\circ}=8$ 
		因此 $\{L_n\}$ 单调增加且有上界，根据单调有界数列收敛定理，$n\sin\dfrac{180^\circ}{n}$ 收敛。将这个极限用希腊字母 $\pi$ 来记，就有 $\lim\limits_{n\rightarrow\infty}n\sin\dfrac{180^\circ}{n} =\pi$ 
- $e$：定义 $e = \lim\limits_{n\rightarrow\infty} \left(1+\dfrac 1n \right)^n = \lim\limits_{n\rightarrow\infty} \left( 1 + \dfrac 1n \right)^{n+1}$ 
	- *证明 $\lim\limits_{n\rightarrow\infty} \left(1+\dfrac 1n \right)^n, \lim\limits_{n\rightarrow\infty} \left( 1 + \dfrac 1n \right)^{n+1}$ 收敛且具有相同极限* 
		记 $x_n = \left( 1 + \dfrac 1n \right)^n,\ y_n = \left( 1 + \dfrac 1n \right)^{n+1}$，利用平均值不等式 $\prod\limits_{i=1}^n a_i \le \left(\dfrac 1n \sum\limits_{i=1}^n a_i\right)^n\ (a_k>0,\ k=1,2,\cdots, n)$ 得到：
		$\begin{cases}x_n = \left(1+\dfrac 1n\right)^n \cdot 1 < \left[ \dfrac{n\left(1+\dfrac{1}{n}\right)+1}{n+1}\right]^{n+1} = \left(1 +\dfrac 1{n+1}\right)^{n+1} = x_{n+1}  \\ \dfrac 1{y_n} = \left(\dfrac{n}{n+1}\right)^{n+1} \cdot 1 < \left[\dfrac{(n+1)\dfrac{n}{n+1}+1}{n+2}\right]^{n+2} = \left(\dfrac{n+1}{n+2}\right)^{n+2} = \dfrac 1{y_{n+1}}   \end{cases}$（思考为什么是严格小于）
		因此，$\{x_n\}$ 单调增加，$\{y_n\}$ 单调减少，又因为 $2 = x_1 \le x_n < y_n \le y_1 = 4$，根据**单调有界数列收敛定理**，可知 $\{x_n\},\ \{y_n\}$ 都收敛
		又因为 $y_n = x_n\left(1+\dfrac 1n\right)$，所以它们具有相同的极限。
		习惯上用字母 $e$ 来表示这一极限，即 $e = \lim\limits_{n\rightarrow\infty} \left(1+\dfrac 1n \right)^n = \lim\limits_{n\rightarrow\infty} \left( 1 + \dfrac 1n \right)^{n+1}$ 
	- $e=2.718281828459\cdots$ 是一个无理数
	- **自然对数**：以 $e$ 为底的对数称为**自然对数**，通常记为 $\ln x$ 
- **Euler 常数**：记 $b_n = 1 + \dfrac 12 + \dfrac 13 + \cdots + \dfrac 1n - \ln n$，可证 $\{b_n\}$ 收敛，且 $\{b_n\}$ 的极限 $\gamma = 0.57721566490\cdots$ 称为 **Euler 常数** 
	- *证明 $\{b_n\}$ 收敛* 
		由 $\left(1 + \dfrac 1n\right)^n < e < \left(1 + \dfrac 1n\right)^{n+1}$ 得到 $\dfrac 1{n+1} < \ln\dfrac{n+1}{n} < \dfrac 1n$ 
		由 $\dfrac 1{n+1} < \ln\dfrac{n+1}n$ 得到 $b_{n+1} - b_n = \dfrac 1{n+1} - \ln\dfrac{n+1}n < 0$ 
		由 $\ln\dfrac{n+1}n < \dfrac 1n$ 得到 $b_n = 1 + \dfrac 12 + \dfrac 13 + \cdots + \dfrac 1n - \ln n > \ln\dfrac 21 + \ln\dfrac 32 + \ln\dfrac 43 + \cdots + \ln\dfrac{n+1}n - \ln n = \ln(n+1) - \ln n > 0$ 
		故 $\{b_n\}$ 单调减少有下界，从而收敛。
	- 实践表明，$b_n = 1 + \dfrac 12 + \dfrac 13 + \cdots + \dfrac 1n - \ln n$ 在做题中是一个非常重要的数列，且 $\lim\limits_{n\rightarrow\infty}b_n = \gamma$ 可以直接用，根据这个性质可以通过引入 $b_n,b_{2n}$ 再进行作差表示 $b_{2n}-b_n$ 的方法来证明 $\lim\limits_{n\rightarrow\infty}\left( \dfrac 1{n+1} + \dfrac 1{n+2} + \cdots + \dfrac 1{2n} \right) = \ln 2$ 和 $\lim\limits_{n\rightarrow\infty} \left[ 1 - \dfrac 12 + \dfrac 13 - \cdots + (-1)^{n+1}\dfrac 1n \right] = \ln 2$ 等
- **闭区间套**：如果一列闭区间 $\{[a_n,b_n]\}$ 满足条件
    - $[a_{n+1},b_{n+1}] \subset [a_n,b_n],\ n=1,2,3,\cdots$ 
    - $\lim\limits_{n\rightarrow\infty} (b_n-a_n) = 0$ 
	则称这列闭区间形成一个**闭区间套** 
- **子列**：设 $\{x_n\}$ 是一个数列，而 $n_1,n_2,\cdots,n_k,\cdots$ 是一列严格单调增加的正整数，则 $x_{n_1},x_{n_2},\cdots,x_{n_k},\cdots$ 也形成一个数列，称为数列 $\{x_n\}$ 的**子列**，记为 $\{x_{n_k}\}$ 
      这里，下标 $n_k$ 表示子列中的第 $k$ 项恰好是原数列中的第 $n_k$ 项。显然有 $n_k \ge k,\ k\in \mathbb N^+$ 和 $n_j \ge n_k,\ j \ge k,\ j,k\in \mathbb N^+$ 
- **基本数列**：如果数列 $\{x_n\}$ 具有以下特性：对于任意给定的 $\varepsilon>0$，存在正整数 $N$ 使得当 $n,m>N$ 时成立 $|x_n-x_m|< \varepsilon$，则称数列 $\{x_n\}$ 是一个**基本数列** 
      符号表述：$\forall\ \varepsilon > 0,\ \exists\ N,\ \forall\ m,n>N: |x_m-x_n|<\varepsilon$  
## 2-2 性质
### 2-2-1 数列极限的性质
- **极限的唯一性**：收敛数列的极限必唯一
	- *证明过程* 
		设 $\lim\limits_{n\rightarrow\infty} x_n = a,\ \lim\limits_{n\rightarrow\infty} x_n = b$，由定义可知 $\forall\ \varepsilon>0, \begin{cases} \exists\ N_1,\ \forall\ n>N_1:|x_n-a|<\dfrac \varepsilon 2\\ \exists\ N_2,\ \forall\ n>N_2:|x_n-b|<\dfrac \varepsilon 2 \end{cases}$，取 $N = \max(N_1,N_2)$，则 $\forall\ n>N$ 有 $|a-b|= |a-x_n+x_n-b| \le |x_n-a| + |x_n-b|<\varepsilon$，由于 $\varepsilon$ 可以任意接近于零，故 $a=b$，故极限唯一。
- **数列的有界性**：收敛数列必有界
	- *证明过程* 
		设 $\lim\limits_{n\rightarrow\infty} x_n = a$，则 $\forall\ \varepsilon>0,\ \exists\ N,\ \forall\ n>N:|x_n-a| < \varepsilon$，也就是 $a-\varepsilon < x_n < a+\varepsilon$，由于 $\varepsilon$ 可以任取，不妨取 $\varepsilon = 114$，那么 $a-114 < x_n < a + 114$，取 $M = \max(x_1,x_2,\cdots,x_N,a+114),\ m = \min(x_1,x_2,\cdots,x_N,a-114)$，显然有 $m\le x_n \le M$，故有界。
- **数列的保序性**：设数列 $\{x_n\},\{y_n\}$ 均收敛，若 $\lim\limits_{n\rightarrow \infty} x_n = a,\ \lim\limits_{n\rightarrow \infty} y_n = b$ 且 $a<b$，则存在正整数 $N$，当 $n>N$ 时，成立 $x_n<y_n$ 
	- *证明过程* 
		由题可知 $\forall\ \varepsilon>0, \begin{cases} \exists\ N_1,\ \forall\ n>N_1,\ |x_n-a|<\varepsilon\\ \exists\ N_2,\ \forall\ n>N_2,\ |y_n-b|<\varepsilon \end{cases}$，取 $\varepsilon = \dfrac{b-a}2$，则有 $\begin{cases} \dfrac {3a-b}2 < x_n < \dfrac{a+b}2 \\ \dfrac {a+b}2 < y_n < \dfrac{3b-a}2 \\ \end{cases}$，所以 $x_n<y_n$，证毕！
    - **推论 1**：若 $\lim\limits_{n\rightarrow \infty} y_n = b > 0$，则存在正整数 $N$，$\forall\ n>N:\ y_n>\dfrac b2 > 0$ 
    - **推论 2**：若 $\lim\limits_{n\rightarrow \infty} y_n = b < 0$，则存在正整数 $N$，$\forall\ n>N:\ y_n < \dfrac b2 < 0$ 
    - **推论 3**：若 $\lim\limits_{n\rightarrow \infty} y_n = b \not= 0$，则存在正整数 $N$，$\forall\ n>N:\ |y_n| > \dfrac {|b|}2 > 0$ 
    - **推论 4**：若数列 $\{y_n\}$ 收敛且极限不为 $0$，则当 $n$ 充分大时，$y_n$ 与 $0$ 的距离不能任意小。
    - **推论 5**：若 $\lim\limits_{n\rightarrow \infty} x_n = a,\ \lim\limits_{n\rightarrow \infty} y_n = b$，且 $\exists\ N,\ \forall\ n>N:x_n\le y_n$，则 $a\le b$ 
	    - *证明过程* 
		    反证法，假设 $a>b$ 
		    由题可知 $\forall\ \varepsilon>0, \begin{cases} \exists\ N_1,\ \forall\ n>N_1,\ |x_n-a|<\varepsilon\\ \exists\ N_2,\ \forall\ n>N_2,\ |y_n-b|<\varepsilon \end{cases}$，取 $\varepsilon = \dfrac{a-b}2$，则有 $\begin{cases} x_n > \dfrac{a+b}2 \\ y_n < \dfrac{a+b}2 \end{cases}$，故 $x_n > y_n$，这与 $x_n \le y_n$ 矛盾，故假设不成立，故 $a \le b$，证毕！
- **极限的夹逼性**：若三个数列 $\{x_n\},\{y_n\},\{z_n\}$ 从某项开始成立 $x_n \le y_n \le z_n,\ n > N_0$，且 $\lim\limits_{n\rightarrow \infty} x_n = \lim\limits_{n\rightarrow \infty} z_n = a$，则 $\lim\limits_{n\rightarrow\infty} y_n = a$ 
	- *证明过程* 
		由已知：$\forall\ \varepsilon>0, \begin{cases} \exists\ N_1,\ \forall\ n>N_1,\ |x_n-a|<\varepsilon\\ \exists\ N_2,\ \forall\ n>N_2,\ |z_n-a|<\varepsilon \end{cases}$，取 $N = \max(N_0,N_1,N_2)$，则 $\forall\ n>N$ 有 $\begin{cases}a-\varepsilon<x_n\\ x_n\le y_n \le z_n \\ z_n<a+\varepsilon\end{cases}\Rightarrow a-\varepsilon < y_n < a + \varepsilon$，即 $|y_n - a| < \varepsilon$，故 $\lim\limits_{n\rightarrow\infty} y_n = a$ 
### 2-2-2 数列极限的四则运算
设 $\lim\limits_{n\rightarrow\infty} x_n=a,\ \lim\limits_{n\rightarrow\infty} y_n=b$，则
- $\lim\limits_{n\rightarrow\infty}(\alpha x_n + \beta y_n) = \alpha a + \beta b$（$\alpha, \beta$ 是常数）
	- *证明过程* 
		由于
		$\begin{aligned} &|\alpha x_n + \beta y_n - (\alpha a + \beta b)| = |\alpha(x_n-a)|+|\beta(y_n-b)| \\ \le& |\alpha| |x_n-a| + |\beta||y_n-b| \\ <& (|\alpha|+|\beta|)\varepsilon \end{aligned}$ 
		故 $\lim\limits_{n\rightarrow\infty}(\alpha x_n + \beta y_n) = \alpha a + \beta b$（$\alpha, \beta$ 是常数）
- $\lim\limits_{n\rightarrow\infty} (x_ny_n) = ab$ 
	- *证明过程* 
		由于 $\{y_n\}$ 收敛，故必有界，不妨设 $|y_n| \le M$，则有：
	    $\begin{aligned}&|x_ny_n - ab| \\ =& |x_ny_n - ay_n + ay_n - ab| = |y_n(x_n-a)|+|a(y_n-b)| \\ \le& |y_n||x_n-a| + |a||y_n-b| \le M|x_n-a| + |a||y_n-b| \\ <& (M+|a|)\varepsilon \end{aligned}$ 
	    故 $\lim\limits_{n\rightarrow\infty} (x_ny_n) = ab$ 
- $\lim\limits_{n\rightarrow\infty} \left( \dfrac{x_n}{y_n} \right) = \dfrac ab \ (b\not= 0)$ 
	- *证明过程*
		由数列的保序性可知：$\exists\ N_0,\ \forall\ n>N_0,\ |y_n| > \dfrac {|b|}2$，则有：
	    $\begin{aligned}&\left| \dfrac{x_n}{y_n} - \dfrac ab \right| = \left| \dfrac{bx_n-ay_n}{by_n} \right| = \dfrac{|bx_n-ab+ab-ay_n|}{|by_n|} \\ \le& \dfrac{|b||x_n-a|+|a||y_n-b|}{|by_n|} < \dfrac{2(|a|+|b|)}{|b|^2}\varepsilon\end{aligned}$ 
	    故 $\lim\limits_{n\rightarrow\infty} \left( \dfrac{x_n}{y_n} \right) = \dfrac ab \ (b\not= 0)$ 
**注意**：数列极限的四则运算只能推广到有限个数列的情况，而不能随意推广到无限个数列或不定个数的数列上去。
### 2-2-3 无穷大量的运算性质
- 设 $x_n \not= 0$，则 $\{x_n\}$ 是无穷大量 $\iff$ $\left\{ \dfrac 1{x_n} \right\}$ 是无穷小量
	- *证明过程* 
		前推后：$\forall\ \varepsilon>0$，取 $G = \dfrac 1 \varepsilon > 0$，于是 $\exists\ N,\ \forall\ n>N:|x_n|>G = \dfrac 1 \varepsilon$，于是 $\left| \dfrac 1 {x_n} \right| < \varepsilon$，所以 $\left\{ \dfrac 1{x_n} \right\}$ 是无穷小量
		后推前：$\forall\ G>0$，取 $\varepsilon = \dfrac 1G > 0$，那么 $\exists\ N,\ \forall\ n>N: \left| \dfrac{1}{x_n} \right| < \varepsilon = \dfrac 1G$，于是 $|x_n|>G$，所以 $\{x_n\}$ 是无穷大量
		综上，$\{x_n\}$ 是无穷大量 $\iff$ $\left\{ \dfrac 1{x_n} \right\}$ 是无穷小量
- 设 $\{x_n\}$ 是无穷大量，$|y_n| \ge \delta > 0$，则 $\{x_ny_n\}$ 是无穷大量
	- *证明过程* 
		因为 $\{x_n\}$ 是无穷大量，所以 $\forall\ G>0,\ \exists\ N,\ \forall\ n>N:|x_n| > \dfrac G \delta \ge \dfrac{G}{|y_n|}$，故 $|x_ny_n| \ge G > \dfrac G2$，故 $\{x_ny_n\}$ 是无穷大量
- 设 $\{x_n\}$ 是无穷大量，$\lim\limits_{n\rightarrow\infty} y_n = b \not= 0$，则 $\{x_ny_n\},\ \left\{ \dfrac{x_n}{y_n} \right\}$ 都是无穷大量
	- *证明过程* 
		由 $\lim\limits_{n\rightarrow\infty} y_n = b \not= 0$ 可知 $\exists\ N',\ \forall\ n>N':\dfrac{|b|}{2} \le |y_n| \le 2|b|$ 
		由于 $\{x_n\}$ 是无穷大量，所以 $\forall\ G>0,\ \exists\ N'',\ \forall\ n>N''$ 成立 $|x_n| > \max\left\{\dfrac{2G}{|b|}, 2|b|G\right\}$ 
		取 $N = \max\{N', N''\}$，则 $\forall\ n>N:|x_ny_n|>G,\ \left|\dfrac{x_n}{y_n}\right|>G$，故 $\{x_ny_n\},\ \left\{\dfrac{x_n}{y_n}\right\}$ 都是无穷大量
### 2-2-4 子列相关性质
- 若数列 $\{x_n\}$ 收敛于 $a$，则它的任何子列 $\{x_{n_k}\}$ 也收敛于 $a$，即 $\lim\limits_{n\rightarrow\infty} x_n = a \Rightarrow \lim\limits_{k\rightarrow\infty} x_{n_k} = a$ 
	- *证明过程* 
		由题：$\forall\ \varepsilon>0,\ \exists\ N,\ \forall\ n>N:|x_n-a|<\varepsilon$，取 $K=N$，则 $\forall\ k>K,\ n_k\ge k > N$，故有 $|x_{n_k}-a|<\varepsilon$，故 $\{x_{n_k}\}$ 也收敛于 $a$，证毕！
- 若存在数列 $\{x_n\}$ 的两个子列 $\{x_{n_k}^{(1)}\}$ 与 $\{x_{n_k}^{(2)}\}$，分别收敛于不同的极限，则数列 $\{x_n\}$ 必定发散
	- *证明过程* 
		反证法，假设 $\lim\limits_{n\rightarrow\infty} x_n = a$，则 $\lim\limits_{k\rightarrow\infty} x_{n_k}^{(1)} = \lim\limits_{k\rightarrow\infty} x_{n_k}^{(2)} = a$，这与题意矛盾，故假设不成立，故 $\{x_n\}$ 发散
- 若 $\{x_n\}$ 是一个无界数列，则存在子列 $\{x_{n_k}\}$ 使得 $\lim\limits_{k\rightarrow\infty} x_{n_k} = \infty$ 
	- *证明过程* 
		由于 $\{x_n\}$ 无界，因此对于任意 $M>0$，$\{x_n\}$ 中必存在无穷多个 $x_n$ 满足 $|x_n|>M$ 
		令 $M_1=1$，则存在 $x_{n_1}$ 使得 $|x_{n_1}|>1$ 
		令 $M_2 = 2$，因为在 $\{x_n\}$ 中由无穷多项满足 $|x_n|>2$，可以取到排在 $x_{n_1}$ 之后的 $x_{n_2},\ n_2>n_1$，使得 $|x_{n_2}|>2$ 
		令 $M_3 = 3$，因为在 $\{x_n\}$ 中由无穷多项满足 $|x_n|>3$，可以取到排在 $x_{n_2}$ 之后的 $x_{n_3},\ n_3>n_2$，使得 $|x_{n_3}|>3$ 
		这样做下去便得到 $\{x_n\}$ 的一个子列 $\{x_{n_k}\}$ 满足 $|x_{n_k}| > k$ 
		由定义，$\lim\limits_{k\rightarrow\infty} x_{n_k} = \infty$ 
## 2-3 定理
- **确界存在定理——实数系连续性定理**：非空有上界的数集必有上确界，非空有下界的数集必有下确界。
	- *证明过程* 
		任何一个实数 $x$ 可以表示成 $x=[x]+(x)$，其中 $[x]$ 表示 $x$ 的整数部分，$(x)$ 表示 $x$ 的非负小数部分。我们将 $(x)$ 表示成无限小数的形式：$(x)=0.a_1a_2\cdots a_n \cdots$ 
		其中 $a_1, a_2, \cdots, a_n, \cdots$ 中的每一个都是数字 $0,1,2,\cdots, 9$ 中的一个，若 $(x)$ 是有限小数，则再后面接上无限个 $0$。这称为**实数的无限小数表示**。
		注意无限小数 $0.a_1a_2\cdots a_p000\cdots\ (a_p\not=0)$ 与无限小数 $0.a_1 a_2\cdots (a_p-1)999\cdots$ 是相等的，为了保持表示的唯一性，我们约定在 $(x)$ 的无限小数表示中不出现后者。这样，任何一个实数集合 $S$ 就可以由一个确定的无限小数的集合来表示：$\{a_0 + 0.a_1 a_2 \cdots a_n \cdots \mid a_0 = [x],\ 0.a_1 a_2 \cdots a_n \cdots = (x),\ x\in S\}$ 
		设数集 $S$ 有上界
		则可令 $S$ 中元素的整数部分的最大者为 $\alpha_0$（$\alpha_0$ 一定存在，否则的话，$S$ 就不可能有上界），并记 $S_0 = \{x \mid x \in S \text{ 并且 } [x] = \alpha_0 \}$，显然 $S_0$ 不是空集，并且对于任意 $x\in S$，只要 $x\not\in S_0$，就有 $x<\alpha_0$ 
		再考虑数集 $S_0$ 中元素的无限小数表示中第一位小数的数字，令它们的最大者为 $\alpha_1$，并记 $S_1 = \{x \mid x \in S_0 \text{ 并且 } x \text{ 的第一位小数为 }\alpha_1 \}$，显然 $S_1$ 不是空集，并且对于任意 $x\in S$，只要 $x\not\in S_1$，就有 $x < \alpha_0 + 0.\alpha_1$ 
		再考虑数集 $S_1$ 中元素的无限小数表示中第二位小数的数字，令它们的最大者为 $\alpha_2$，并记 $S_2 = \{x \mid x \in S_1 \text{ 并且 } x \text{ 的第二位小数为 }\alpha_2 \}$，显然 $S_2$ 不是空集，并且对于任意 $x\in S$，只要 $x\not\in S_2$，就有 $x < \alpha_0 + 0.\alpha_1\alpha_2$ 
		一般地，考察数集 $S_{n-1}$ 中元素的无限小数表示中第 $n$ 为小数的数字，令它们中的最大者为 $\alpha_n$，并记 $S_n = \{x \mid x \in S_{n-1} \text{ 并且 } x \text{ 的第 n 位小数为 }\alpha_n \}$，显然 $S_n$ 不是空集，并且对于任意 $x\in S$，只要 $x\not\in S_n$，就有 $x<\alpha_0 + 0.\alpha_1\alpha_2\cdots\alpha_n$ 
		不断做下去，我们得到一列非空数集 $S \supset S_0 \supset S_1 \cdots \supset S_n \supset \cdots$ 和一列数 $\alpha_0,\alpha_1,\alpha_2,\cdots\alpha_n,\cdots$ 满足 $a_0\in \mathbb Z,\ a_k\in\{0,1,2,\cdots,9\},\ k\in\mathbb N^+$ 
		令 $\beta = \alpha_0 + 0.\alpha_1\alpha_2\cdots\alpha_n\cdots$，下面我们分两步证明 $\beta$ 就是数集 $S$ 的上确界。
		1. 设 $x\in S$，则或者存在整数 $n_0\ge 0$，使得 $x\not\in S_{n_0}$，或者对任何整数 $n\ge 0$ 有 $x\in S_n$ 
			- 若 $x\not\in S_{n_0}$，便有 $x<\alpha_0 + 0.\alpha_1\alpha_2\cdots\alpha_{n_0}\le\beta$ 
			- 若 $x\in S_n\ (\forall\ n\in\mathbb N)$，由 $S_n$ 的定义并逐个比较 $x$ 与 $\beta$ 的整数部分及每一位小数，即知 $x=\beta$ 
			所以对于任意的 $x\in S$，由 $x\le \beta$，即 $\beta$ 是数集 $S$ 的上界
		2. 对于任意给定的 $\varepsilon>0$，只要将自然数 $n_0$ 取得充分大，便有 $\dfrac 1{10^{n_0}} < \varepsilon$，取 $x_0 \in S_{n_0}$，则 $\beta$ 与 $x_0$ 的整数部分及前 $n_0$ 为小数是相同的，所以 $\beta-x_0 \le \dfrac{1}{10^{n_0}} < \varepsilon$，即 $x_0 > \beta - \varepsilon$，即任何小于 $\beta$ 的数 $\beta-\varepsilon$ 不是数集 $S$ 的上界。
		故 $\beta$ 是 $S$ 的上确界。
		同理可证非空有下界数集必有下确界。
- **Stolz 定理**：设 $\{y_n\}$ 是严格单调增加的正无穷大量，且 $\lim\limits_{n\rightarrow\infty} \dfrac{x_n-x_{n-1}}{y_n- y_{n-1}} = a$（$a$ 可以为有限量，$+\infty$ 与 $-\infty$，但不可以为 $\infty$），则 $\lim\limits_{n\rightarrow\infty} \dfrac{x_n}{y_n} = a$ 
	- *证明过程* 
		先考虑 $a=0$ 的情况。由 $\lim\limits_{n\rightarrow\infty} \dfrac{x_n-x_{n-1}}{y_n-y_{n-1}} = 0$，根据极限定义可知 $\forall\ \varepsilon>0,\ \exists\ N_1,\ \forall\ n>N_1:|x_n-x_{n-1}|<\varepsilon(y_n-y_{n-1})$ 
		由于 $\{y_n\}$ 是正无穷大量，显然可要求 $y_{N_1}>0$，于是：
		$\begin{aligned} &|x_n-x_{N_1}| \le |x_n-x_{n-1}| + |x_{n-1}-x_{n-2}| + \cdots + |x_{N_1+1}-x_{N_1}| \\ <&\varepsilon(y_n-y_{n-1}) + \varepsilon(y_{n-1}-y_{n-2}) + \cdots + \varepsilon(y_{N_1+1}-y_{N_1}) = \varepsilon(y_n-y_{N_1}) \end{aligned}$ 
		不等式两边同时除以 $y_n$ 得到 $\left| \dfrac{x_n}{y_n} - \dfrac{x_{N_1}}{y_n} \right| \le \varepsilon\left(1-\dfrac{y_{N_1}}{y_n}\right) < \varepsilon$ 
		对于固定的 $N_1$，又可以取到 $N>N_1$，使得 $\forall\ n>N:\left| \dfrac{x_{N_1}}{y_n} \right| < \varepsilon$，从而 $\left| \dfrac{x_n}{y_n} \right|<\varepsilon+\left| \dfrac{x_{N_1}}{y_n} \right| < 2\varepsilon$，故 $\lim\limits_{n\rightarrow\infty}\dfrac{x_n}{y_n} = 0$ 
		当 $a$ 是非零有限数时，令 $x_n' = x_n - ay_n$，于是由 $\lim\limits_{n\rightarrow\infty}\dfrac{x_n'-x_{n-1}'}{y_n-y_{n-1}} = \lim\limits_{n\rightarrow\infty}\dfrac{x_n-x_{n-1}}{y_n-y_{n-1}}-a=0$，得到 $\lim\limits_{n\rightarrow\infty} \dfrac{x_n'}{y_n} = 0$，从而 $\lim\limits_{n\rightarrow\infty} \dfrac{x_n}{y_n} = \lim\limits_{n\rightarrow\infty}\dfrac{x_n'}{y_n}+a=a$ 
		对于 $a=+\infty$ 的情况，$\forall\ G>0,\ \exists\ N,\ \forall\ n>N:\dfrac{x_n-x_{n-1}}{y_n-y_{n-1}} > G$，取 $G=1$，则 $x_n-x_{n-1} > y_n-y_{n-1}>0$，这说明 $\{x_n\}$ 严格单调增加，并且从 $x_n-x_N = (x_n-x_{n-1}) + (x_{n-1}-x_{n-2}) + \cdots + (x_{N+1} - x_N) >y_n-y_N$ 及 $\{y_n\}$ 是正无穷大量，可知 $\{x_n\}$ 是正无穷大量。
		故 $\{x_n\}$ 是严格单调增加的正无穷大量，故 $\lim\limits_{n\rightarrow\infty} \dfrac{x_n-x_{n-1}}{y_n- y_{n-1}} = +\infty \Rightarrow \lim\limits_{n\rightarrow\infty} \dfrac{y_n- y_{n-1}}{x_n-x_{n-1}} = 0 \Rightarrow \lim\limits_{n\rightarrow\infty} \dfrac{y_n}{x_n} = 0 \Rightarrow \lim\limits_{n\rightarrow\infty} \dfrac{x_n}{y_n} = +\infty$  
		对于 $a=-\infty$ 的情况，证明方法类同。
- **单调有界数列收敛定理**：单调有界数列必定收敛。
	- *证明过程* 
		设 $\{x_n\}$ 单调增加且有上界，根据**确界存在定理**，由 $\{x_n\}$ 构成的数集必有上确界 $\beta$，满足：
	    1. $\forall\ n\in \mathbb N^*: x_n \le \beta$ 
	    2. $\forall\ \varepsilon>0,\ \exists\ x_{n_0}:x_{n_0} > \beta - \varepsilon$ 
		取 $N=n_0$，则 $\forall\ n>N: \beta - \varepsilon < x_{n_0} \le x_n \le \beta < \beta + \varepsilon$，故 $|x_n-\beta| <\varepsilon$，故 $\lim\limits_{n\rightarrow\infty} x_n = \beta$ 
		单调递减类似，略。
- **闭区间套定理**：如果 $\{[a_n,b_n]\}$ 形成一个闭区间套，则存在唯一的实数 $\xi$ 属于所有的闭区间 $[a_n,b_n]$ 且 $\xi = \lim\limits_{n\rightarrow\infty} a_n = \lim\limits_{n\rightarrow\infty} b_n$ 
	- *证明过程* 
		由闭区间套的条件，可知 $a_1 \le \cdots \le a_{n-1} \le a_n < b_n \le b_{n-1} \le \cdots \le b_1$，故 $\{a_n\}$ 单调增加且有上界 $b_1$，$\{b_n\}$ 单调减少且有下界 $a_1$，由**单调有界数列收敛定理**可知，$\{a_n\},\ \{b_n\}$ 都收敛。
		设 $\lim\limits_{n\rightarrow\infty} a_n = \xi$，则 $\lim\limits_{n\rightarrow\infty} b_n = \lim\limits_{n\rightarrow\infty} (b_n-a_n+a_n) = \lim\limits_{n\rightarrow\infty} (b_n-a_n) + \lim\limits_{n\rightarrow\infty} {a_n} = \xi$ 
		由于 $\xi$ 是 $\{a_n\}$ 所构成的数集的上确界，也是 $\{b_n\}$ 所构成的数集的下确界，于是有 $a_n \le \xi \le b_n,\ n=1,2,\cdots$ 
		下证唯一性：假设另有实数 $\xi'$ 属于所有的闭区间 $[a_n,b_n]$，则也有 $a_n \le \xi' \le b_n,\ n=1,2,\cdots$，由极限夹逼性可知：$\xi' = \lim\limits_{n\rightarrow\infty} a_n = \lim\limits_{n\rightarrow\infty} b_n = \xi$，故是唯一的。
		综上证毕！
- 实数集 $\mathbb R$ 是不可列集
	- *证明过程* 
		反证法，假设实数集 $\mathbb R$ 是可列集，即可以找到一种排列的规则，使 $\mathbb R = \{x_1, x_2, \cdots, x_n, \cdots\}$ 
		先取闭区间 $[a_1, b_1]$，使 $x_1 \not\in [a_1, b_1]$，这总是可以做到的。
		然后将 $[a_1,b_1]$ 三等分，则在闭区间 $\left[a_1,\dfrac{2a_1+b_1}{3}\right],\ \left[ \dfrac{2a_1 + b_1}{3}, \dfrac{a_1 + 2b_1}{3} \right],\ \left[ \dfrac{a_1 + 2b_1}{3}, b_1 \right]$ 中，至少有一个不含有 $x_2$，把它记为 $[a_2,b_2]$ 
		然后将 $[a_2,b_2]$ 三等分，则在闭区间 $\left[a_2,\dfrac{2a_2+b_2}{3}\right],\ \left[ \dfrac{2a_2 + b_2}{3}, \dfrac{a_2 + 2b_2}{3} \right],\ \left[ \dfrac{a_2 + 2b_2}{3}, b_2 \right]$ 中，至少有一个不含有 $x_3$，把它记为 $[a_3,b_3]$ 
		然后将 $[a_3,b_3]$ 三等分，则在闭区间 $\left[a_3,\dfrac{2a_3+b_3}{3}\right],\ \left[ \dfrac{2a_3 + b_3}{3}, \dfrac{a_3 + 2b_3}{3} \right],\ \left[ \dfrac{a_3 + 2b_3}{3}, b_3 \right]$ 中，至少有一个不含有 $x_4$，把它记为 $[a_4,b_4]$ 
		这样的步骤可以一直做下去，于是得到一个闭区间套 $\{[a_n,b_n]\}$ 满足 $x_n \not\in [a_n,b_n],\ n=1,2,3,\cdots$ 
		由**闭区间套定理**，存在唯一的实数 $\xi$ 属于所有的闭区间 $[a_n,b_n]$，换言之，$\xi \not=x_n\ (n=1,2,3,\cdots)$，这就与集合 $\{x_1,x_2,\cdots,x_n,\cdots\}$ 表示实数集 $\mathbb R$ 产生矛盾，故假设不成立，$\mathbb R$ 不可列
- **Bolzano-Weierstrass 定理**：有界数列必有收敛子列。（这个定理又称为致密性定理、列紧性定理）
	- *证明过程* 
		设数列 $\{x_n\}$ 有界，于是存在实数 $a_1,b_1$，成立 $a_1 \le x_n \le b_1,\ n=1,2,3,\cdots$ 
		将闭区间 $[a_1,b_1]$ 等分成两个小区间 $\left[ a_1, \dfrac{a_1+b_1}2 \right],\ \left[ \dfrac{a_1+b_1}2, b_1 \right]$，则其中至少有一个区间含有数列 $\{x_n\}$ 的无穷多项，把它记为 $[a_2,b_2]$ 
		将闭区间 $[a_2,b_2]$ 等分成两个小区间 $\left[ a_2, \dfrac{a_2+b_2}2 \right],\ \left[ \dfrac{a_2+b_2}2, b_2 \right]$，则其中至少有一个区间含有数列 $\{x_n\}$ 的无穷多项，把它记为 $[a_3,b_3]$ 
		这个步骤一直做下去，于是得到一个闭区间套 $\{[a_k,b_k]\}$，其中每一个闭区间 $[a_k,b_k]$ 中都含有数列 $\{x_n\}$ 的无穷多项。
		根据**闭区间套定理**，存在实数 $\xi \text{ s.f. } \xi = \lim\limits_{k\rightarrow\infty} a_k = \lim\limits_{k\rightarrow\infty} b_k$ 
		下证数列 $\{x_n\}$ 必有一子列收敛于 $\xi$：
		首先在 $[a_1,b_1]$ 种选取 $\{x_n\}$ 中某一项，记为 $x_{n_1}$ 
		然后，因为 $[a_2,b_2]$ 中含有 $\{x_n\}$ 中无穷多项，可以选在 $\{x_n\}$ 中取位于 $x_{n_1}$ 后的某一项，记它为 $x_{n_2},\ n_2>n_1$ 
		继续这样做，在选取 $x_{n_k} \in [a_k,b_k]$ 后，因为 $[a_{k+1}, b_{k+1}]$ 中仍含有 $\{x_n\}$ 中的无穷多项，可以选取位于 $x_{n_k}$ 后的某一项，记它为 $x_{n_{k+1}},\ n_{k+1} > n_k$ 
		这样就得到了数列 $\{x_n\}$ 的一个子列 $\{x_{n_k}\}$ 满足 $a_k \le x_{n_k} \le b_k,\ k=1,2,3,\cdots$ 
		由于 $\lim\limits_{k\rightarrow\infty} a_k = \lim\limits_{k\rightarrow\infty} b_k = \xi$，利用极限的夹逼性，得到 $\lim\limits_{k\rightarrow\infty} x_{n_k} = \xi$ 
- **Cauchy 收敛原理——实数系完备性定理**：$\{x_n\}$ 收敛 $\iff$ $\{x_n\}$ 是基本数列
	- *证明过程* 
		前推后：设 $\lim\limits_{n\rightarrow\infty} x_n = a$，那么 $\forall\ \varepsilon > 0,\ \exists\ N,\ \forall\ n,m>N:|x_n-a| < \dfrac \varepsilon 2,\ |x_m - a| < \dfrac \varepsilon 2$，于是 $|x_m-x_n| = |x_m-a+a-x_n| \le |x_m-a| + |x_n-a| < \varepsilon$，故 $\{x_n\}$ 是基本数列
		后推前：先证明基本数列必有界，取 $\varepsilon_0 = 114514$，因为 $\{x_n\}$ 是基本数列，故 $\exists\ N_0,\ \forall\ n>N_0: |x_n - x_{N_0 + 1}| < 114514$，令 $M = \max( x_1 ,  x_2 , \cdots,  x_{N_0} ,  x_{N_0+1}  + 114514)$，则对于一切 $n$，有 $|x_n| \le M$，故基本数列必有界。
		由 **Bolzano-Weierstrass 定理**，$\{x_n\}$ 必有收敛子列 $\{x_{n_k}\}$ 满足 $\lim\limits_{k\rightarrow\infty} x_{n_k} = \xi$ 
		因为 $\{x_n\}$ 是基本数列，所以 $\forall\ \varepsilon>0,\ \exists\ N,\ \forall\ n,m>N: |x_n-x_m| < \dfrac \varepsilon 2$ 
		取 $x_m = x_{n_k}$，并使 $k$ 充分大直至满足 $n_k>N$，并且令 $k\rightarrow\infty$，于是得到 $|x_n-\xi| \le \dfrac \varepsilon 2 < \varepsilon$，故 $\lim\limits_{n\rightarrow\infty} x_n = \xi$，故数列 $\{x_n\}$ 收敛，证毕！
	- Cauchy 收敛原理表明，由实数构成的基本数列 $\{x_n\}$ 必存在实数极限，这一性质被称为实数系的**完备性**。
	- 值得注意的是，有理数集不具有完备性。例如 $\left\{\left(1+\dfrac 1n\right)^n\right\}$ 是由有理数构成的基本数列，在学习微分后可以严谨证明，其极限 $e$ 并不是有理数。
- 实数系的完备性 $\iff$ 实数系的连续性
	- *证明过程* 
		- 实数系的连续性 $\Rightarrow$ 实数系的完备性
			根据分析前面的定理证明，有逻辑推理关系：$\text{确界存在定理}\Rightarrow\text{单调有界数列收敛定理}\Rightarrow\text{闭区间套定理}\Rightarrow\text{Bolzano-Weierstrass 定理}\Rightarrow\text{Cauchy 收敛原理}$ 
			故实数系的连续性 $\Rightarrow$ 实数系的完备性，证毕！
		- 实数系的完备性 $\Rightarrow$ 实数系的连续性
			可从 $\text{Cauchy 收敛原理} \Rightarrow \text{闭区间套定理} \Rightarrow \text{确界存在定理}$ 进行证明
			1. $\text{Cauchy 收敛原理} \Rightarrow \text{闭区间套定理}$ 
				设 $\{[a_n,b_n]\}$ 是一系列闭区间，满足条件
				- $[a_{n+1}, b_{n+1}] \subset [a_n, b_n],\ n=1,2,3,\cdots$ 
				- $\lim\limits_{n\rightarrow\infty}(b_n-a_n) = 0$ 
				设 $m>n$，则 $0 \le a_m - a_n < b_n - a_n \rightarrow 0\ (n\rightarrow \infty)$，故数列 $\{a_n\}$ 是一个基本数列，从而有 $\lim\limits_{n\rightarrow\infty}a_n=\xi$ 
				并由此得到 $\lim\limits_{n\rightarrow\infty} b_n = \lim\limits_{n\rightarrow\infty}(b_n-a_n) + \lim\limits_{n\rightarrow\infty} a_n = \xi$ 
				由于 $\{a_n\}$ 单调增加，$\{b_n\}$ 单调减少，可以知道 $\xi$ 是属于所有闭区间 $[a_n,b_n]$ 的实数。
				下证唯一性：假设另有实数 $\xi'$ 属于所有的闭区间 $[a_n,b_n]$，则也有 $a_n \le \xi' \le b_n,\ n=1,2,\cdots$，由极限夹逼性可知：$\xi' = \lim\limits_{n\rightarrow\infty} a_n = \lim\limits_{n\rightarrow\infty} b_n = \xi$，故是唯一的。
			2. $\text{闭区间套定理} \Rightarrow \text{确界存在定理}$ 
				设 $S$ 是非空有上界的实数集合，又设 $T$ 是由 $S$ 的所有上界所组成的集合，现证 $T$ 含有最小数，即 $S$ 有上确界。
				取 $a_1\not\in T,\ b_1 \in T$，显然 $a_1 < b_1$，现按下述的规则依次构造一列闭区间：
				$[a_2,b_2] = \begin{cases} \left[ a_1, \dfrac{a_1+b_1}{2} \right] & \dfrac{a_1+b_1}2 \in T \\ \left[ \dfrac{a_1+b_1}{2}, b_1 \right] & \dfrac{a_1+b_1}2 \not\in T \end{cases},\ [a_3,b_3] = \begin{cases} \left[ a_2, \dfrac{a_2+b_2}{2} \right] & \dfrac{a_2+b_2}2 \in T \\ \left[ \dfrac{a_2+b_2}{2}, b_2 \right] & \dfrac{a_2+b_2}2 \not\in T \end{cases},\ \cdots$ 
				由此得到一个闭区间套 $\{[a_n,b_n]\}$ 满足 $a_n \not\in T,\ b_n \in T,\ n=1,2,3,\cdots$ 
				由闭区间套定理，存在唯一实数 $\xi$ 属于所有的闭区间 $[a_n,b_n]$，且 $\lim\limits_{n\rightarrow\infty} a_n = \lim\limits_{n\rightarrow\infty} b_n = \xi$ 
				现在只需说明 $\xi$ 是集合 $T$ 的最小数，也就是集合 $S$ 的上确界。
				若 $\xi \not\in T$，即 $\xi$ 不是集合 $S$ 的上界，则存在 $x\in S$，使得 $\xi < x$。由 $\lim\limits_{n\rightarrow\infty} b_n = \xi$，可知当 $n$ 充分大时，成立 $b_n<x$，这就与 $b_n\in T$ 发生矛盾，所以 $\xi \in T$ 
				若存在 $\eta \in T$，使得 $\eta < \xi$，则由 $\lim\limits_{n\rightarrow\infty} a_n = \xi$，可知当 $n$ 充分大时，成立 $\eta < a_n$。由于 $a_n \not\in T$，于是存在 $y\in S$，使得 $\eta < a_n < y$，这就与 $\eta \in T$ 发生矛盾。从而得出 $\xi$ 是集合 $S$ 的上确界的结论。确界存在定理得证。
- **实数系的基本定理**：由于上述五个定理是等价的，即从其中任何一个定理出发都可以推断出其他的定理，所以，这五个定理中的每一个都可以称为是**实数系的基本定理**。
