# 7 无约束问题算法 (V)
## 7-1 坐标轮换发及其改进
- **坐标轮换法**、**原始 Powell 算法**的*基本思想*、**加速方向** 
	设 $e^{(i)}\ (i=0,1,\cdots,n-1)$ 是坐标轴方向
	所谓**坐标轮换法**就是从初始点 $x^{(0)}$ 出发，依次沿坐标轴的方向进行线性搜索，得点 $x^{(i)}\ (i=1,2,\cdots,n)$ 
	再以 $x(0) := x(n)$ 为初始点，重复上述过程。直至得到问题的解。
	该算法的实现过程如下图所示
	![[Pasted image 20260410100041.png|350]]
	由上图可以看出，坐标轮换法的效率很低。类似于采用精确线性搜索的最速下降法，坐标轮换法相邻两次搜索方向相互垂直。因此，算法的收敛速度慢。
	为提高算法的效率，我们对坐标轮换法加以改进。
	如上图所示，在沿坐标轴进行一轮搜索之后，产生了一个方向 $d^{(n)} \triangleq x^{(n)} - x^{(0)}$，称之为**加速方向** 
	若从 $x^{(n)}$ 出发，沿加速方向再搜索一次，则算法的效率可得到改善。
	按这种方式对坐标轮换法进行改进后产生的算法称为**原始 Powell 算法**。其步骤如下：
- **算法 7.1** (**原始 Powell 算法**)
	- *第 1 步*：给定 $n$ 个线性无关向量 $d^{(i)}\ (i = 0,1,\cdots,n-1)$，取初始点 $x^{(0)} \in \mathbb{R}^n$，精度 $\varepsilon > 0$。令 $k := 0$ 
	- *第 2 步*：从 $x^{(0)}$ 出发，依次沿 $d^{(0)}, d^{(1)}, \cdots, d^{(n-1)}$ 进行精确线性搜索得 $x^{(1)},\ x^{(2)}, \cdots, x^{(n)}$，即 $x^{(i+1)} = x^{(i)} + \alpha_i d^{(i)},\ (i = 0, 1, \cdots, n-1)$，其中步长 $\alpha_i$ 由精确线性搜索得到，即 $\alpha_i$ 是下面的一维最优化问题的解：$\min\limits_{\alpha \in \mathbb{R}} f\left(x^{(i)} + \alpha d^{(i)}\right)$ 
	- *第 3 步* (**加速搜索**)：令 $d^{(n)} = x^{(n)} - x^{(0)}$，若 $\|d^{(n)}\| \leqslant \varepsilon$，则得解 $x^{(n)}$。否则，从 $x^{(n)}$ 出发，沿 $d^{(n)}$ 进行精确线性搜索确定步长 $\alpha_n$。令 $x^{(n+1)} = x^{(n)} + \alpha_n d^{(n)}$ 
	- *第 4 步*：令 $d^{(i)} := d^{(i+1)}\ (i = 0, 1, \cdots, n-1)$，$x^{(0)} := x^{(n+1)}$，$k := k + 1$。转*第 2 步* 
- *算法 7.1 注意*：原始 Powell 算法中，方向 $d^{(i)}$ 一般不能保证是函数 $f$ 在 $x^{(i)}$ 处的下降方向。因此，精确线性搜索 $\min\limits_{\alpha \in \mathbb{R}} f\left(x^{(i)} + \alpha d^{(i)}\right)$ 在整个实数轴 $\mathbb{R}$ 上进行。因而，算法产生的步长 $\alpha_i$ 可能为负值。
- **定理 7.1.1**：设 $Q \in \mathbb{R}^{n \times n}$ 对称正定，$q \in \mathbb{R}^n$。则**算法 7.1** 用于求解问题 $\min f(x) = \dfrac{1}{2} x^\mathrm{T} Q x + q^\mathrm{T} x$ 时产生的加速方向关于 $Q$ 两两共轭。
	- *证明过程* 
		**算法 7.1** 的计算过程如下表
		![[Pasted image 20260410101316.png|500]]
		下面对 $m$ 用归纳法证明定理
		当 $m=2$ 时，算法产生两个加速方向：$d^{(n)}$ 和 $d^{(n+1)}$ 
		我们需证明 $d^{(n+1)\mathrm{T}} Q d^{(n)} = 0$，或等价地证明 $\left(x^{(2n+1)} - x^{(n+1)}\right)^{\mathrm{T}} Q d^{(n)} = 0$ 
		由于 $\nabla f(x) = Qx + q$，上式可等价地写为 $\left[\nabla f\left(x^{(2n+1)}\right) - \nabla f\left(x^{(n+1)}\right)\right]^{\mathrm{T}} d^{(n)} = 0$ 
		注意到 $x^{(2n+1)}$ 由 $x^{(2n)}$ 沿 $d^{(n)}$ 精确线性搜索得到，$x^{(n+1)}$ 由 $x^{(n)}$ 沿 $d^{(n)}$ 精确线性搜索得到，故有 $\nabla f\left(x^{(2n+1)}\right)^{\mathrm{T}} d^{(n)} = 0,\ \nabla f\left(x^{(n+1)}\right)^{\mathrm{T}} d^{(n)} = 0$ 
		两式相减即得 $\left[\nabla f\left(x^{(2n+1)}\right) - \nabla f\left(x^{(n+1)}\right)\right]^{\mathrm{T}} d^{(n)} = 0$，即定理对 $m=2$ 成立
		设定理对 $m=t$ 成立 (此时**算法 7.1** 产生的加速方向为 $d^{(n)}, d^{(n+1)}, \cdots, d^{(n+t-1)}$)，即 $d^{(n+i)\mathrm{T}} Q d^{(n+j)} = 0,\ (0 \leqslant i < j \leqslant t-1)$ 
		我们证明定理对 $m = t + 1$ 成立 (此时**算法 7.1** 产生的加速方向为 $d^{(n)}, d^{(n+1)}, \cdots, d^{(n+t-1)}, d^{(n+t)}$)，即证 $d^{(n+i)\mathrm{T}} Q d^{(n+t)} = 0,\ (i = 0, 1, \cdots, t-1)$ 
		记第 $t + 1$ 轮迭代产生的迭代点和方向依次为
		$$
		y^{(0)} \xrightarrow[\tilde d^{(0)}]{\tilde{\alpha}_0} y^{(1)} \xrightarrow[\tilde d^{(1)}]{\tilde{\alpha}_1} \cdots \xrightarrow[\tilde d^{(n-2)}]{\tilde{\alpha}_{n-2}} y^{(n-1)} \xrightarrow[\tilde d^{(n-1)}]{\tilde{\alpha}_{n-1}} y^{(n)},\ \tilde{d}^{(n)} = y^{(n)} - y^{(0)}
		$$
		其中 $y^{(i)} = x^{(t(n+1)+i)} \ (i = 0, 1, \cdots, n)$，$\tilde{d}^{(i)} = d^{(t+i)} \ (i = 0, 1, \cdots, n)$ 
		利用 $\nabla f$ 的表达式，共轭关系 $d^{(n+i)\mathrm{T}} Q d^{(n+j)} = 0,\ (0 \leqslant i < j \leqslant t-1)$ 和 $d^{(n+i)\mathrm{T}} Q d^{(n+t)} = 0,\ (i = 0, 1, \cdots, t-1)$ 可分别等价地写成 $\tilde{d}^{(n-t+i)\mathrm{T}} Q \tilde{d}^{(n-t+j)} = 0,\ (0 \leqslant i < j \leqslant t-1)$ 和 $d^{(n+i)\mathrm{T}} Q d^{(n+t)} = \left[\nabla f\left(y^{(n)}\right) - \nabla f\left(y^{(0)}\right)\right]^{\mathrm{T}} \tilde{d}^{(n-t+i)} = 0,\ (i = 0, 1, \cdots, t-1)$ 
		利用归纳假设 $\tilde{d}^{(n-t+i)\mathrm{T}} Q \tilde{d}^{(n-t+j)} = 0,\ (0 \leqslant i < j \leqslant t-1)$，$\nabla f$ 的表达式以及精确线性搜索条件可得对任何 $0 \leqslant i \leqslant t - 1$ 有：
		$$
		\begin{aligned}
		\nabla f\left(y^{(n)}\right)^{\mathrm{T}} \tilde{d}^{(n-t+i)} &= \sum_{j=n-t+i+1}^{n-1} \left[\nabla f\left(y^{(j+1)}\right) - \nabla f\left(y^{(j)}\right)\right]^{\mathrm{T}} \tilde{d}^{(n-t+i)} \\
		&\quad + \nabla f\left(y^{(n-t+i+1)}\right)^{\mathrm{T}} \tilde{d}^{(n-t+i)} \\
		&= \sum_{j=n-t+i+1}^{n-1} \tilde{\alpha}_j \tilde d^{(j)\mathrm{T}} Q \tilde{d}^{(n-t+i)} = 0
		\end{aligned}
		$$
		其中，$\tilde{\alpha}_j$ 表示由 $y^{(j)}$ 出发沿 $\tilde{d}^{(j)}$ 精确线性搜索得到的步长。
		另一方面，$y^{(0)} = x^{(t(n+1))}$ 作为第 $t$ 轮搜索的终点，其产生过程如下：
		$$
		x^{((t-1)(n+1))} := \bar{y}^{(0)} \xrightarrow[\tilde d^{(0)}]{\bar{\alpha}_0} \bar{y}^{(1)} \xrightarrow[\tilde d^{(1)}]{\bar{\alpha}_1} \cdots \xrightarrow[\tilde d^{(n-2)}=\tilde d^{(n-3)}]{\bar{\alpha}_{n-2}} \bar{y}^{(n-1)} \xrightarrow[\tilde d^{(n-1)}=\tilde d^{(n-2)}]{\bar{\alpha}_{n-1}} \bar{y}^{(n)} \xrightarrow[\tilde d^{(n)}=\tilde d^{(n-1)}]{\bar{\alpha}_n} \bar{y}^{(n+1)} = y^{(0)}
		$$
		类似于前面的推导可得：对任何 $0 \leqslant i \leqslant t - 1$，$\nabla f\left(y^{(0)}\right)^{\mathrm{T}} \tilde{d}^{(n-t+i)} = \nabla f\left(\bar{y}^{(n+1)}\right)^{\mathrm{T}} \tilde{d}^{(n-t+i-1)} = 0$ 
		上式以及 $\nabla f\left(y^{(n)}\right)^{\mathrm{T}} \tilde{d}^{(n-t+i)}=0$ 包含了$d^{(n+i)\mathrm{T}} Q d^{(n+t)} = \left[\nabla f\left(y^{(n)}\right) - \nabla f\left(y^{(0)}\right)\right]^{\mathrm{T}} \tilde{d}^{(n-t+i)} = 0,\ (i = 0, 1, \cdots, t-1)$ 
		或等价地，$d^{(n+i)\mathrm{T}} Q d^{(n+t)} = 0,\ (i = 0, 1, \cdots, t-1)$ 成立。
		由归纳原理，定理成立，证毕！
- *优点*：若每轮迭代的前 $n$ 个方向线性无关，则**算法 7.1** 用于二次函数极小化问题的求解时产生的加速方向关于二次函数的 Hessian 矩阵相互共轭。从而，算法具有二次终止性。
- *缺点*：但当迭代方向线性相关时，**算法 7.1** 产生的点列可能不收敛于问题的解。这是原始 Powell 算法的一个缺陷。因此，有必要对**算法 7.1** 加以改进。
## 7-2 Powell 直接法
- *前置分析* 
	原始 Powell 算法中，若在某一轮次的 $n$ 个搜索方向线性相关，则算法产生的点列可能不收敛于问题的解。
	为了克服原始 Powell 算法的这一缺陷，有必要在算法中引入某种技术，使得算法在每一轮次的 $n$ 个搜索方向均线性无关。
	设在初始步给定初始点 $x^{(0)}$ 和 $n$ 个线性无关的方向 $d^{(0)}, d^{(1)}, \cdots, d^{(n-1)}$ 
	从初始点 $x^{(0)}$ 出发，依次沿这些方向进行搜索后得点 $x^{(1)}, x^{(2)}, \cdots, x^{(n)}$，并产生一个加速方向 $d^{(n)} = x^{(n)} - x^{(0)}$ 
	原始 Powell 算法中用 $d^{(n)}$ 替代 $d^{(0)}$ 的方式确定下一轮搜索方向，即下一轮的搜索方向组为 $d^{(1)}, d^{(2)}, \cdots, d^{(n)}$。这种自然的替换方式忽略了向量组 $d^{(1)}, d^{(2)}, \cdots, d^{(n)}$ 可能出现线性相关的情况。
	为了避免出现下一轮搜索方向组线性相关，当向量组 $d^{(1)}, d^{(2)}, \cdots, d^{(n)}$ 线性相关时，可考虑用 $d^{(n)}$ 替换 $d^{(0)}, d^{(1)}, \cdots, d^{(n-1)}$ 中的某个向量 $d^{(t)} (0 \leqslant t < n)$，使得向量组 $d^{(i)} (i = 0, 1, \cdots, n, i \neq t)$ 线性无关。进而，将此向量组作为下一轮的搜索方向组。
	若 $d^{(n)}$ 替换向量组 $d^{(0)}, d^{(1)}, \cdots, d^{(n-1)}$ 中的任何向量后产生的向量组均线性相关，则用同样的向量组（即 $d^{(n)}$ 不替换向量组 $d^{(0)}, d^{(1)}, \cdots, d^{(n-1)}$ 中的任何向量）作为下一轮搜索方向组。
	显然，利用上面的方式确定下一轮计算的搜索方向必定线性无关。
	为了实现上面的过程，我们需要给出一个替换准则，即在什么条件下用 $d^{(n)}$ 替换 $d^{(t)} (0 \leqslant t \leqslant n-1)$，在什么条件下，$d^{(n)}$ 不替换向量组 $d^{(0)}, d^{(1)}, \cdots, d^{(n-1)}$ 中的任何向量。
	为此，我们先引入正交程度和共轭程度的概念。
- **定理 7.2.1**：设 $p^{(1)}, p^{(2)}, \cdots, p^{(n)}$ 是 $\mathbb{R}^n$ 中单位向量。记 $D \triangleq D(p^{(1)}, p^{(2)}, \cdots, p^{(n)}) = (p^{(1)}, p^{(2)}, \cdots, p^{(n)})$，则 $|\det(D)| \leqslant 1$，而且，等式成立当且仅当 $p^{(1)}, p^{(2)}, \cdots, p^{(n)}$ 相互正交。
	- *证明过程* 
		若向量组 $p^{(1)}, p^{(2)}, \cdots, p^{(n)}$ 线性相关，则 $\det(D) = 0$，此时 $|\det(D)| \leqslant 1$ 成立
		现设向量组 $p^{(1)}, p^{(2)}, \cdots, p^{(n)}$ 线性无关，令 $A = D^{\mathrm{T}} D = \begin{pmatrix} p^{(1)\mathrm{T}} p^{(1)} & \cdots & p^{(1)\mathrm{T}} p^{(n)} \\ \vdots & & \vdots \\ p^{(n)\mathrm{T}} p^{(1)} & \cdots & p^{(n)\mathrm{T}} p^{(n)} \end{pmatrix}$ 
		由于向量组 $p^{(1)}, p^{(2)}, \cdots, p^{(n)}$ 线性无关，因此 $A$ 对称正定
		记 $\lambda_i (i = 1, 2, \cdots, n)$ 表示 $A$ 的特征值，则 $[\det(D)]^2 = \det(A) = \prod\limits_{i=1}^n \lambda_i \leqslant \left( \dfrac{1}{n} \sum\limits_{i=1}^n \lambda_i \right)^n = \left[ \dfrac{1}{n} \mathrm{tr}(A) \right]^n = \left( \dfrac{1}{n} \sum\limits_{i=1}^n p^{(i)\mathrm{T}} p^{(i)} \right)^n = 1$，故得 $|\det(D)| \leqslant 1$ 
		而且，由几何不等式中等号成立的充要条件知 $|\det(D)| \leqslant 1$ 成立等式的充要条件是 $\lambda_i = \lambda_j (\forall i,j = 1,2,\cdots,n)$，或等价地，$A$ 的所有特征值都是 1。
		但 $A$ 对称，因此，$A = I$ 为单位矩阵。
		或等价地，向量组 $p^{(1)}, p^{(2)}, \cdots, p^{(n)}$ 相互正交。
		证毕！
	- 从该定理可以给出**正交程度**的定义
- **正交程度**：对 $\mathbb{R}^n$ 中非零向量组 $p^{(1)}, p^{(2)}, \cdots, p^{(n)}$，行列式 $D(p^{(1)}/\|p^{(1)}\|, p^{(2)}/\|p^{(2)}\|, \cdots, p^{(n)}/\|p^{(n)}\|)$ 的绝对值 $\delta(p^{(1)}, p^{(2)}, \cdots, p^{(n)}) \triangleq \left| \det\left( \dfrac{p^{(1)}}{\|p^{(1)}\|}, \dfrac{p^{(2)}}{\|p^{(2)}\|}, \cdots, \dfrac{p^{(n)}}{\|p^{(n)}\|} \right) \right|$ 的大小反映了向量组 $p^{(1)}, p^{(2)}, \cdots, p^{(n)}$ 之间的正交程度。我们称 $\delta(p^{(1)}, p^{(2)}, \cdots, p^{(n)})$ 为非零向量组 $p^{(1)}, p^{(2)}, \cdots, p^{(n)}$ 的**正交程度** 
	- 类似地，可引入共轭程度的概念。
- **共轭程度** 
	设 $A \in \mathbb{R}^{n \times n}$ 对称正定。对 $\mathbb{R}^n$ 中的非零向量组 $p^{(1)}, p^{(2)}, \cdots, p^{(n)}$，令 $q^{(i)} = A^{1/2} p^{(i)}$ 
	显然，$q^{(i)}$ 与 $q^{(j)}$ 正交当且仅当 $p^{(i)}$ 与 $p^{(j)}$ 关于 $A$ 相互共轭
	因此，向量组 $p^{(1)}, p^{(2)}, \cdots, p^{(n)}$ 关于 $A$ 的共轭性等价于向量组 $q^{(1)}, q^{(2)}, \cdots, q^{(n)}$ 的正交性。
	在此基础上，我们可定义向量组 $p^{(1)}, p^{(2)}, \cdots, p^{(n)}$ 关于矩阵 $A$ 的**共轭程度**为向量组 $q^{(1)}, q^{(2)}, \cdots, q^{(n)}$ 的正交程度，即 $p^{(1)}, p^{(2)}, \cdots, p^{(n)}$ 关于矩阵 $A$ 的共轭程度为
	$$
	\begin{aligned}
	\Delta(p^{(1)}, p^{(2)}, \cdots, p^{(n)}) \triangleq & \left| \det\left( \frac{q^{(1)}}{\|q^{(1)}\|}, \frac{q^{(2)}}{\|q^{(2)}\|}, \cdots, \frac{q^{(n)}}{\|q^{(n)}\|} \right) \right| \\
	=& \left| \det A^{1/2} \right| \left| \det\left( \frac{p^{(1)}}{\|A^{1/2} p^{(1)}\|}, \frac{p^{(2)}}{\|A^{1/2} p^{(2)}\|}, \cdots, \frac{p^{(n)}}{\|A^{1/2} p^{(n)}\|} \right) \right|
	\end{aligned}
	$$
- **定理 7.2.2**：设 $A \in \mathbb R^{n \times n}$ 对称正定，$p^{(1)}, p^{(2)}, \cdots, p^{(n)}$ 是 $\mathbb R^n$ 中向量组。则 $\Delta(p^{(1)}, p^{(2)}, \cdots, p^{(n)}) \leqslant 1$，而且等式成立当且仅当 $p^{(1)}, p^{(2)}, \cdots, p^{(n)}$ 关于矩阵 $A$ 相互共轭。
	- 利用**定理 7.2.1**，容易证明该定理
- **Powell 直接法**的*理论基础* 
	利用**定理 7.2.2**，我们可以确定用 $d^{(n)}$ 替换 $d^{(0)}, d^{(1)} \cdots, d^{(n-1)}$ 中某个向量的准则。
	考察求解如下二次函数极小值问题的原始 Powell 算法：$\min f(x) = \dfrac{1}{2} x^{\mathrm{T}} Q x + q^{\mathrm{T}} x$，其中 $Q$ 对称正定。
	设算法在某一轮产生的点列以及相应的 (线性无关) 搜索方向分别为 $y^{(0)}, y^{(1)}, \cdots, y^{(n)}$ 和 $d^{(0)}, d^{(1)} \cdots, d^{(n-1)}$ 
	在该轮搜索完毕后产生加速方向 $d^{(n)} = y^{(n)} - y^{(0)}$。此时，共有 $n+1$ 个方向：$d^{(0)}, d^{(1)}, \cdots, d^{(n)}$。
	我们在此 $n+1$ 个方向中选择 $n$ 个方向作为下一轮的搜索方向组。
	确定搜索方向组的一个原则是该方向组必须线性无关。
	我们可在方向组 $d^{(0)}, d^{(1)}, \cdots, d^{(n)}$ 中选择 $n$ 个向量，使得该 $n$ 个向量构成的向量组关于矩阵 $Q$ 的共轭程度最大。
	令 $\tilde{d}^{(i)} = \|Q^{1/2} d^{(i)}\|^{-1} d^{(i)} (i = 0, 1, \cdots, n)$，$D_i = (\tilde{d}^{(0)}, \cdots, \tilde{d}^{(i-1)}, \tilde{d}^{(i+1)}, \cdots, \tilde{d}^{(n)}),\ (i = 0, 1, \cdots, n-1)$，$D = (\tilde{d}^{(0)}, d^{(1)}, \cdots, d^{(n-1)})$ 
	因此，由 $\begin{aligned} &\Delta(p^{(1)}, p^{(2)}, \cdots, p^{(n)}) \triangleq  \left| \det\left( \frac{q^{(1)}}{\|q^{(1)}\|}, \frac{q^{(2)}}{\|q^{(2)}\|}, \cdots, \frac{q^{(n)}}{\|q^{(n)}\|} \right) \right| \\ =& \left| \det A^{1/2} \right| \left| \det\left( \frac{p^{(1)}}{\|A^{1/2} p^{(1)}\|}, \frac{p^{(2)}}{\|A^{1/2} p^{(2)}\|}, \cdots, \frac{p^{(n)}}{\|A^{1/2} p^{(n)}\|} \right) \right| \end{aligned}$，用 $d^{(n)}$ 替换某个 $d^{(t)},\ 0 \leqslant t \leqslant n-1$ 的条件是下面的不等式成立：$|\det(D)| < \max\{|\det(D_i)| \mid i = 0, 1, \cdots, n-1\} = |\det(D_t)|$ 
	反之，若上式不成立，即 $|\det(D)| \geqslant \max\{|\det(D_i)| \mid i = 0, 1, \cdots, n-1\}$，则无需替换，即下一轮的搜索方向组仍然是 $d^{(i)} (i = 0, 1, \cdots, n-1)$ 
	下面，我们确定使得 $|\det(D_t)|$ 取到最大的下标 $t$，即 $|\det(D_t)| = \max\{|\det(D_i)| \mid i = 0, 1, \cdots, n-1\}$ 
	注意到 $y^{(n)} = y^{(n-1)} + \tilde{\alpha}_{n-1} \tilde{d}^{(n-1)} = y^{(n-2)} + \tilde{\alpha}_{n-2} \tilde{d}^{(n-2)} + \tilde{\alpha}_{n-1} \tilde{d}^{(n-1)} = \cdots = y^{(0)} + \sum\limits_{i=0}^{n-1} \tilde{\alpha}_i \tilde{d}^{(i)}$，其中 $\tilde{\alpha}_i$ 表示从 $y^{(i)}$ 出发，沿方向 $\tilde{d}^{(i)}$ 进行精确线性搜索得到的步长。
	该轮搜索产生的加速方向为 $d^{(n)} = y^{(n)} - y^{(0)} = \sum\limits_{i=0}^{n-1} \tilde{\alpha}_i \tilde{d}^{(i)}$ 
	由此得 $\tilde{d}^{(n)} = \|Q^{1/2} d^{(n)}\|^{-1} d^{(n)} = \|Q^{1/2} (y^{(n)} - y^{(0)})\|^{-1} \sum\limits_{i=0}^{n-1} \tilde{\alpha}_i \tilde{d}^{(i)} \triangleq \beta^{-1} \sum\limits_{i=0}^{n-1} \tilde{\alpha}_i \tilde{d}^{(i)}$ 
	利用行列式的性质得 $|\det(D_i)| = \beta^{-1} |\tilde{\alpha}_i| |\det(D)|$ 
	由于 $\beta > 0$ 与 $i$ 无关，因此使 $|\det(D_i)|$ 取到最大等价于使 $\tilde{\alpha}_i$ 的绝对值取到最大。
	由于 $f$ 是二次函数，我们有
	$$
	\begin{aligned}
	f(y^{(i)}) &= f(y^{(i+1)}) + \nabla f(y^{(i+1)})^{\mathrm{T}} (y^{(i)} - y^{(i+1)}) + \frac{1}{2} (y^{(i)} - y^{(i+1)})^{\mathrm{T}} Q (y^{(i)} - y^{(i+1)}) \\
	&= f(y^{(i+1)}) - \tilde{\alpha}_i \nabla f(y^{(i+1)})^{\mathrm{T}} \tilde{d}^{(i)} + \frac{1}{2} \tilde{\alpha}_i^2 \tilde{d}^{(i)\mathrm{T}} Q \tilde{d}^{(i)} \\
	&= f(y^{(i+1)}) + \frac{1}{2} \tilde{\alpha}_i^2
	\end{aligned}
	$$
	因此，使得 $|\det(D_t)| = \max\{|\det(D_i)| \mid i = 0, 1, \cdots, n-1\}$ 成立的下标 $t$ 与使得下式成立的下标 $t$ 相同：$f(y^{(t)}) - f(y^{(t+1)}) = \max\limits_{0 \leqslant i \leqslant n-1} \{ f(y^{(i)}) - f(y^{(i+1)}) \}$，即 $t$ 为达到最大下降量的下标。
	下面我们导出使得不等式 $|\det(D)| \geqslant \max\{|\det(D_i)| \mid i = 0, 1, \cdots, n-1\}$，即 $|\det(D_t)| \leqslant |\det(D)|$ 成立的条件。
	由 $|\det(D_i)| = \beta^{-1} |\tilde{\alpha}_i| |\det(D)|$，上式等价于 $\beta^{-1} |\tilde{\alpha}_t| \leqslant 1$ 
	利用 $f(y^{(i)})= f(y^{(i+1)}) + \dfrac{1}{2} \tilde{\alpha}_i^2$，可等价地得到 $\beta^2 \geqslant \tilde{\alpha}_t^2 = 2[f(y^{(t)}) - f(y^{(t+1)})]$ 
	由 $\beta$ 的定义得
	$$
	\begin{aligned}
	\beta^2 &= \|Q^{1/2} d^{(n)}\|^2 = (d^{(n)})^{\mathrm{T}} Q d^{(n)} = (y^{(n)} - y^{(0)})^{\mathrm{T}} Q (y^{(n)} - y^{(0)}) \\
	&= \nabla f(y^{(n)})^{\mathrm{T}} (y^{(0)} - y^{(n)}) + \frac{1}{2} (y^{(0)} - y^{(n)})^{\mathrm{T}} Q (y^{(0)} - y^{(n)}) \\
	&\quad + \nabla f(y^{(n)})^{\mathrm{T}} (y^{(n)} - y^{(0)}) + \frac{1}{2} (y^{(n)} - y^{(0)})^{\mathrm{T}} Q (y^{(n)} - y^{(0)}) \\
	&= f(y^{(0)}) - f(y^{(n)}) + f(2y^{(n)} - y^{(0)}) - f(y^{(n)}) \\
	&= f(y^{(0)}) - 2f(y^{(n)}) + f(2y^{(n)} - y^{(0)})
	\end{aligned}
	$$
	其中第三个等式由 $f(y^{(0)})$ 和 $f(2y^{(n)} - y^{(0)})$ 在 $y^{(n)}$ 处作 Taylor 展开得到。
	由此得 $|\det(D)| \geqslant \max\{|\det(D_i)| \mid i = 0, 1, \cdots, n-1\}$ 成立等价于：$f(y^{(0)}) - 2f(y^{(n)}) + f(2y^{(n)} - y^{(0)}) \geqslant 2(f(y^{(t)}) - f(y^{(t+1)}))$ 
	上式即为 $d^{(n)}$ 不替换 $d^{(i)},\ i = 0, 1, \cdots, n-1$ 中任何一个方向的条件。
	在上面的基础上，我们给出 Powell 直接法的步骤如下
- **算法 7.2** (**Powell 直接法**)
	- *第 1 步*：取初始点 $x^{(0)} \in R^n$，精度 $\varepsilon > 0$。给定 $n$ 个线性无关向量 $d^{(i)} (i = 0, 1, \cdots, n-1)$。令 $k := 0$。
	- *第 2 步*：从 $x^{(0)}$ 出发，依次沿 $d^{(0)}, d^{(1)}, \cdots, d^{(n-1)}$ 进行精确线性搜索得 $x^{(1)}, x^{(2)}, \cdots, x^{(n)}$，即 $f(x^{(i)} + \alpha_i d^{(i)}) = \min_{\alpha \in R} f(x^{(i)} + \alpha d^{(i)}),\ x^{(i+1)} = x^{(i)} + \alpha_i d^{(i)},\ (i = 0, 1, \cdots, n-1)$ 
	- *第 3 步*：令 $d^{(n)} = x^{(n)} - x^{(0)}$。若 $\|d^{(n)}\| \leqslant \varepsilon$，则得解 $x^{(n)}$。否则，从 $x^{(n)}$ 出发，沿 $d^{(n)}$ 进行精确线性搜索得 $x^{(n+1)}$。
	- *第 4 步*：由 $f(y^{(t)}) - f(y^{(t+1)}) = \max\limits_{0 \leqslant i \leqslant n-1} \{ f(y^{(i)}) - f(y^{(i+1)}) \}$ 计算最大下降量所确定的指标 $t$ 
	- *第 5 步*：若 $f(y^{(0)}) - 2f(y^{(n)}) + f(2y^{(n)} - y^{(0)}) \geqslant 2(f(y^{(t)}) - f(y^{(t+1)}))$ 成立，则 $x^{(0)} := x^{(n)}$，$k := k + 1$。转*第 2 步* 
	- *第 6 步*：令 $d^{(t+i)} := d^{(t+i+1)} (i = 0, 1, \cdots, n-t-1)$，$x^{(0)} := x^{(n+1)}$，$k := k + 1$。转*第 2 步* 
- **定理 7.2.3**：设 $f$ 是连续可微的一致凸函数，并设水平集 $\Omega(x^{(0)}) = \{ x \mid f(x) \leqslant f(x^{(0)}) \}$ 有界，则**算法 7.2** 产生的点列 $\{ x^{(k)} \}$ 收敛于 $f$ 在 $\Omega(x^{(0)})$ 中的唯一极小值点。
	- 该定理为**算法 7.2** 的收敛性定理
## 7-3 轴向搜索法
- **轴向搜索法** (**Hooke-Jeeves 算法**)：**轴向搜索法**由 Hooke-Jeeves 提出，故又称为 **Hooke-Jeeves 算法** 
- **轴向搜索法**的*基本思想* 
	是从某个初始点 $x^{(0)}$ 出发，采用固定步长 $\delta > 0$，依次沿坐标轴 $e^{(i)}(i = 0, 1, \cdots, n-1)$ 的正向或反向进行试探，产生点列 $y^{(1)},\ y^{(2)},\ \cdots,\ y^{(n)}$ 
	若 $f(y^{(n)}) < f(x^{(0)})$ 则称该轮试探成功。
	若试探成功，则算法转入下一轮试探，即从 $x^{(1)} = y^{(n)}$ 出发，采用固定步长 $\delta > 0$，再依次沿坐标轴 $e^{(i)}(i = 0, 1, \cdots, n-1)$ 的正向或反向进行试探。
	若试探不成功，即 $f(y^{(n)}) \geqslant f(x^{(0)})$，则缩小试探步长 $\delta$，即令 $\delta := \beta\delta$，其中 $\beta \in (0, 1)$，重新进行试探。
	重复上述过程，直至该轮试探成功。
	算法的细节如下：
	从初始点 $x^{(0)}$ 出发，沿坐标轴 $e^{(0)}$（的正方向）进行试探得点 $y^{(1)} = x^{(0)} + \delta e^{(0)}$。
	若 $f(y^{(1)}) < f(x^{(0)})$ 不成立，则从 $x^{(0)}$ 出发沿 $e^{(0)}$ 的反方向重新试探得点 $y^{(1)} = x^{(0)} - \delta e^{(0)}$。
	若 $f(y^{(1)}) < f(x^{(0)})$ 仍不成立，则再重新赋值 $y^{(1)} = x^{(0)}$。
	然后，从 $y^{(1)}$ 出发沿 $e^{(1)}$ 的正方向或负方向得新的试探点 $y^{(2)} = y^{(1)} \pm \delta \mathrm{e}^{(1)}$ 
	重复上述过程直至沿所有坐标的正方向或反方向都进行了一次试探。
	此时，得点列 $y^{(1)},\ y^{(2)},\ \cdots,\ y^{(n)}$ 
	若 $f(y^{(1)}) < f(x^{(0)})$ 成立，则该轮试探成功。令 $x^{(0)} := y^{(n)}$，转入下一轮试探。
	若 $f(y^{(1)}) < f(x^{(0)})$ 不成立，则令 $\delta := \beta\delta$，其中 $\beta \in (0,1)$。从初始点 $x^{(0)}$ 出发，重复上述试探过程，得新的点列 $y^{(1)},\ y^{(2)},\ \cdots,\ y^{(n)}$ 
	若 $f(y^{(1)}) < f(x^{(0)})$ 仍不成立，则再令 $\delta := \beta\delta$。重复上述试探过程，直至该轮试探成功。
- **算法 7.3** (**轴向搜索法**)
	- *第 1 步*：取初始点 $x^{(0)} \in \mathbb{R}^n$，初始步长 $\delta > 0$，步长缩减因子 $\beta \in (0,1)$，步长加速因子 $\alpha \geq 0$，精度 $\varepsilon > 0$。给定 $n$ 个坐标轴向量 $\mathrm{e}^{(i)} (i = 0, 1, \cdots, n-1)$。令 $y^{(0)} := x^{(0)}$，$k := 0$，$j := 0$。
	- *第 2 步*：若 $f(y^{(j)} + \delta \mathrm{e}^{(j)}) < f(y^{(j)})$，则令 $y^{(j+1)} = y^{(j)} + \delta \mathrm{e}^{(j)}$，转*第 4 步*。否则，转*第 3 步* 
	- *第 3 步*：若 $f(y^{(j)} - \delta \mathrm{e}^{(j)}) < f(y^{(j)})$，则令 $y^{(j+1)} = y^{(j)} - \delta \mathrm{e}^{(j)}$，转*第 4 步*。否则，令 $y^{(j+1)} := y^{(j)}$，转*第 3 步* 
	- *第 4 步*：若 $j < n-1$，令 $j := j+1$ 并转*第 2 步*。否则，转*第 5 步* 
	- *第 5 步*：若 $f(y^{(n)}) < f(x^{(k)})$，令 $x^{(k+1)} := y^{(n)},\ y^{(0)} := x^{(k+1)} + \alpha(x^{(k+1)} - x^{(k)}), \ (k := k+1,\ j := 0)$，并转*第 2 步*。否则，转*第 6 步* 
	- *第 6 步*：若 $\delta \leq \varepsilon$，则得解 $x^{(k)}$。否则，令 $\delta := \beta\delta,\ y^{(0)} := x^{(k)}, \ x^{(k+1)} := x^{(k)},\ (k := k+1,\ j := 0)$，转*第 2 步*
