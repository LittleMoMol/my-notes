# 线性项
线性项直接把系数拿出来，二次型多一个 2
- $\nabla (a^T x) = a$ 
- $\nabla (x^T a) = a$ 
- $\nabla(x^Tx) = 2x$ 
# 二次型
- $\nabla \left( x^T A x \right) = (A+A^T)x$ 
# 链式法则
- $\nabla_x f(\boldsymbol r(x)) = \boldsymbol r'(x)^T \nabla_{\boldsymbol r} f(\boldsymbol r(x))$ 
# 仿射组合
- $\nabla(Ax) = A$ 
- $\nabla(x^T A) = A$ 
- $\nabla (a^TAx) = A^Ta$
