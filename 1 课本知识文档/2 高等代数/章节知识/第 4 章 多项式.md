# 4 多项式
## 4-1 定义与性质
### 4-1-1 数域
- **代数性质**：关于数的加、减、乘、除等运算的性质通常称为数的**代数性质**。
- **封闭的**：如果数的集合 $P$ 中任意两个数做某一运算的结果仍在 $P$ 中，我们就说数集 $P$ 对这个运算是**封闭的**。
- **数域**：设 $P$ 是由一些复数组成的集合，其中包括 $0$ 与 $1$。如果 $P$ 中任意两个数（这两个数也可以相同）的和、差、积、商（除数不为 $0$）仍然是 $P$ 中的数，那么 $P$ 就称为一个**数域**。
	**另一种等价定义**：如果一个包含 $0,1$ 在内的数集 $P$ 对于加法、减法、乘法与除法（除数不为 $0$）是封闭的，那么 $P$ 就称为一个**数域**。
    易知，所有的数域都包含有理数域作为它的一部分。
### 4-1-2 一元多项式的概念与运算
- **数域** $P$ **上的一元多项式**：设 $x$ 是一个符号（或称文字），设 $n$ 是一非负整数，形式表达式 $a_nx^n + a_{n-1}x^{n-1} + \cdots + a_0$，其中 $a_0,a_1,\cdots,a_n$ 全属于数域 $P$，称为**系数在数域** $P$ **中的一个一元多项式**，或者简称为**数域** $P$ **上的一元多项式**。
- $k$ **次项**、**系数**：多项式 $a_nx^n + a_{n-1}x^{n-1} + \cdots + a_0$ 中，$a_kx^k$ 称为 $k$ **次项**，$a_k$ 称为 $k$ 次项的**系数**。
- **相等**：如果在多项式 $f(x)$ 与 $g(x)$ 中，除去系数为零的项外，同次项的系数全相等，那么 $f(x)$ 与 $g(x)$ 就称为**相等**，记为 $f(x)=g(x)$ 
- **零多项式**：系数全为零的多项式称为**零多项式**，记为 $0$ 
- **首项**、**首项系数**、**次数**：在 $a_nx^n + a_{n-1}x^{n-1} + \cdots + a_0$ 中，如果 $a_n\not= 0$，那么 $a_nx^n$ 就称为多项式 $a_nx^n + a_{n-1}x^{n-1} + \cdots + a_0$ 的**首项**，$a_n$ 称为**首项系数**，$n$ 称为多项式 $a_nx^n + a_{n-1}x^{n-1} + \cdots + a_0$ 的**次数**。零多项式是唯一不定义次数的多项式（或说其次数为 $-\infty$），多项式 $f(x)$ 的次数记为 $\deg(f(x))$ 或 $\partial(f(x))$ 
- **一元多项式环**：所有系数在数域 $P$ 中的一元多项式的全体，称为数域 $P$ 上的**一元多项式环**，记为 $P[x]$，$P$ 称为 $P[x]$ 的**系数域**。
- **多项式的加法和乘法**：两个多项式 $f(x)= \sum\limits_{i=0}^n a_ix^i,\ g(x)= \sum\limits_{j=0}^m a_jx^j$，若 $n\ge m$，为了方便起见，在 $g(x)$ 中令 $b_n = b_{n-1} = \cdots = b_{m+1} = 0$，那么
    1. $f(x)$ 与 $g(x)$ 的和为：$f(x)+g(x) = \sum\limits_{i=0}^n (a_i+b_i)x^i$ 
    2. $f(x)$ 与 $g(x)$ 的乘积为：$f(x)g(x) = \sum\limits_{s=0}^{m+n} \left( \sum\limits_{i+j=s} a_ib_j \right)x^s$ 
      显然，数域 $P$ 上的两个多项式经过加、减、乘等运算后，所得结果仍然是数域 $P$ 上的多项式。
- **多项式的加法和乘法的性质**：
    1. $\deg(f(x) \pm g(x)) \le \max(\deg(f(x)), \deg(g(x)))$ 
    2. $f(x)\not= 0,\ g(x) \not= 0 \Rightarrow f(x)g(x)\not= 0$，并且 $\deg(f(x)g(x)) = \deg(f(x)) + \deg(g(x))$ 
    3. 多项式乘积的首项系数就等于它的因子首项系数的乘积。
- **多项式运算规律**：
    1. 加法交换律：$f(x)+g(x)=g(x)+f(x)$ 
    2. 加法结合律：$(f(x)+g(x))+h(x) = f(x) + (g(x)+h(x))$ 
    3. 乘法交换律：$f(x)g(x)=g(x)f(x)$ 
    4. 乘法对加法的分配律：$f(x)(g(x)+h(x)) = f(x)g(x) + f(x)h(x)$ 
    5. 乘法消去律：如果 $f(x)g(x)=f(x)h(x)$ 且 $f(x) \not= 0$，那么 $g(x)=h(x)$ 
### 4-1-3 一元多项式之间的关系
- **带余除法**、**商式**、**余式**：对于 $P[x]$ 中任意两个多项式 $f(x)$ 与 $g(x)$，其中 $g(x)\not= 0$，一定存在 $q(x),r(x) \in P[x]$ 使得 $f(x)=q(x)g(x)+r(x)$ 成立，其中满足 $\deg(r(x)) < \deg(g(x))$ 或 $r(x)=0$，并且这样的 $q(x),r(x)$ 是唯一决定的。
      带余除法中所得的 $q(x)$ 通常称为 $g(x)$ 除 $f(x)$ 的**商式**，简称**商**；$r(x)$ 称为 $g(x)$ 除 $f(x)$ 的**余式**，简称**余**。
- **整除**、**因式**、**倍式**：如果有数域 $P$ 上的多项式 $h(x)$ 使等式 $f(x)=g(x)h(x)$ 成立，则称数域 $P$ 上的多项式 $g(x)$ **整除** $f(x)$。我们用 $g(x) \mid f(x)$ 表示 $g(x)$ 整除 $f(x)$，用 $g(x) \nmid f(x)$ 表示 $g(x)$ 不能整除 $f(x)$ 
      当 $g(x) \mid f(x)$ 时，$g(x)$ 就称为 $f(x)$ 的**因式**，$f(x)$ 称为 $g(x)$ 的**倍式**。
      当 $g(x)\not=0$ 时，带余除法给出了整除性的一个判别法。
- **组合**：通常 $\sum\limits_{i=1}^r u_i(x)g_i(x)$ 称为多项式 $g_1(x),g_2(x),\cdots,g_r(x)$ 的一个**组合**。
- **整除的常用性质** 
    1. 对于数域 $P$ 上的任意两个多项式 $f(x),g(x)$，其中 $g(x)\not=0$，则 $g(x)\mid f(x) \iff g(x)$ 除 $f(x)$ 的余式为零。
    2. $\forall\ a \in P,\ a\not=0,\ \forall\ f(x) \subset P[x],\ f(x)\not=0$ 有 $af(x) \mid f(x)$ 
    3. 若 $f(x) \mid g(x),\ g(x) \mid f(x)$，那么 $f(x)=cg(x)$，其中 $c$ 为非零常数
    4. 整除的传递性：若 $f(x) \mid g(x),\ g(x) \mid h(x)$，那么 $f(x) \mid h(x)$ 
    5. 若 $f(x) \mid g(x)$，则 $\deg f(x) \le \deg g(x)$ 或 $g(x)=0$ 
    6. 若 $f(x) \mid g(x)$ 且 $\deg f(x) > \deg g(x)$，则 $g(x)=0$ 
    7. 若 $f(x) \mid g_1(x),\ f(x) \mid g_2(x)$，则 $\forall\ h_1(x),h_2(x) \in p[x]$ 有 $f(x) \mid (h_1(x)g_1(x) + h_2(x)g_2(x))$ 
    8. 若 $f(x) \mid g_i(x)\quad \forall\ 1\le i\le s$，则 $\forall\ h_i(x) \in P[x]$ 有 $f(x) \mid \sum\limits_{i=1}^s h_i(x)g_i(x)$ 
    9. 两个多项式之间的整除关系不因为系数域的扩大而改变。
- **最大公因式**：设 $f(x),g(x)$ 是 $P[x]$ 中两个多项式，$P[x]$ 中多项式 $d(x)$ 称为 $f(x),g(x)$ 的一个**最大公因式**，如果它满足下面两个条件：
    1. $d(x)$ 是 $f(x),g(x)$ 的公因式
    2. $f(x),g(x)$ 的公因式全是 $d(x)$ 的因式
	由定义可以看出：两个多项式的最大公因式在可以相差一个非零常数倍的意义下使唯一确定的。
    由于两个不全为零的多项式的最大公因式总是一个非零多项式，故我们用 $(f(x),g(x))$ **来表示首项系数为 1 的那个最大公因式**。
- **最大公因式扩充定义**：设 $f_1(x),f_2(x),\cdots,f_s(x)\ (s\ge 2)$ 是 $P[x]$ 中 $s$ 个多项式，$P[x]$ 中多项式 $d(x)$ 称为 $f_1(x),f_2(x),\cdots,f_s(x)\ (s\ge 2)$ 的一个**最大公因式**，如果它满足下面两个条件：
    1. $d(x) \mid f_i(x),\ i=1,2,\cdots,s$
    2. 如果 $\varphi(x) \mid f_i(x),\ i=1,2,\cdots,s$，那么 $\varphi(x) \mid d(x)$ 
    由定义可以看出：$s$ 个多项式的最大公因式在可以相差一个非零常数倍的意义下是唯一确定的。
	由于 $s$ 个不全为零的多项式的最大公因式总是一个非零多项式，故我们用 $(f_1(x),f_2(x),\cdots,f_s(x))$ **来表示首项系数为 1 的那个最大公因式**。
    有性质：$(f_1(x),f_2(x),f_3(x)) = ((f_1(x),f_2(x)),f_3(x))$ 
- **互素的**：$P[x]$ 中两个多项式 $f(x),g(x)$ 满足 $(f(x),g(x))=1$，则称 $f(x),g(x)$ 为**互素的**（也称**互质的**）
- **互素的扩充定义**：$P[x]$ 中 $s$ 个多项式 $f_1(x),f_2(x),\cdots,f_s(x)\ (s\ge 2)$ 满足 $(f_1(x),f_2(x),\cdots,f_s(x))=1$，则称 $f_1(x),f_2(x),\cdots,f_s(x)\ (s\ge 2)$ 为**互素的**（也称**互质的**）
- **最大公因式的常用性质** 
    1. 如果 $(f(x),g(x))=1$ 且 $f(x) \mid g(x)h(x)$，则 $f(x) \mid h(x)$ 
        **推论**：如果 $(f(x),g_i(x))=1,\ \forall\ 1\le i \le s$ 且 $f(x) \mid h(x)\prod\limits_{i=1}^s g_i(x)$，则 $f(x) \mid h(x)$ 
    2. 如果 $f_1(x) \mid g(x),\ f_2(x) \mid g(x)$ 且 $(f_1(x),f_2(x))=1$，那么 $f_1(x)f_2(x) \mid g(x)$ 
        **推论**：如果 $f_i(x) \mid g(x),\ \forall\ 1\le i \le s$ 且 $(f_1(x),f_2(x),\cdots,f_s(x)) = 1$，那么 $\prod\limits_{i=1}^s f_i(x) \mid g(x)$ 
    3. 如果 $(f_1(x),g(x))=1$ 且 $(f_2(x),g(x))=1$，则 $(f_1(x)f_2(x),g(x))=1$ 
        **推论**：如果 $(f_i(x),g(x))=1,\ \forall\ 1\le i \le s$，则 $\left( \prod\limits_{i=1}^s f_i(x),g(x) \right)=1$ 
- **不可约多项式**：对于数域 $P$ 上次数 $\ge 1$ 的多项式 $p(x)$，如果它能表成数域 $P$ 上的两个次数比 $p(x)$ 的次数低的多项式的乘积，则称 $p(x)$ 为域 $P$ 上的**不可约多项式**。
	- **注意**：一个多项式是否不可约是依赖于系数域的！
- **不可约多项式的性质**
    1. 不可约多项式 $p(x)$ 与任一多项式 $f(x)$ 之间只可能有两种关系，或者 $p(x) \mid f(x)$，或者 $(p(x),f(x))=1$ 
    2. 如果 $p(x)$ 是一个不可约多项式，那么对于任意的两个多项式 $f(x),g(x)$，若 $p(x) \mid f(x)g(x)$，则一定有 $p(x) \mid f(x)$ 或 $p(x) \mid g(x)$ 
            **推论**：如果不可约多项式 $p(x)$ 整除一些多项式 $f_1(x),f_2(x),\cdots,f_s(x)$ 的乘积 $\prod\limits_{i=1}^s f_i(x)$，那么 $p(x)$ 一定整除这些多项式之中的一个。
- **分解式**：数域 $P$ 上每一个次数 $\ge 1$ 的多项式 $f(x)$ 写成 $f(x) = p_1(x)p_2(x) \cdots p_s(x)$ 的形式，其中 $\forall\ 1 \le i \le s,\ p_i(x)$ 均为不可约多项式。
- **标准分解式**：在多项式 $f(x)$ 的分解式中，可以把每一个不可约因式的首项系数提出来，使它们称为首项系数为 $1$ 的多项式，再把相同的不可约因式合并，于是 $f(x)$ 的分解式称为 $f(x) = c\prod\limits_{i=1}^s p_i^{r_i}(x)$，其中 $c$ 是 $f(x)$ 的首项系数，$p_i(x)\ (i=1,2,\cdots,s)$ 是不同的首项系数为 $1$ 的不可约多项式，而 $r_i\ (i=1,2,\cdots,s)$ 是正整数，这种分解式称为**标准分解式**。
- $k$ **重因式**：不可约多项式 $p(x)$ 称为多项式 $f(x)$ 的 $k$ **重因式**，如果 $p^k(x) \mid f(x)$ 且 $p^{k+1}(x) \nmid f(x)$ 
    1. 如果 $k=0$，那么 $p(x)$ 根本不是 $f(x)$ 的因式
    2. **单因式**：如果 $k=1$，那么 $p(x)$ 称为 $f(x)$ 的**单因式** 
    3. **重因式**：如果 $k>1$，那么 $p(x)$ 称为 $f(x)$ 的**重因式** 
    显然，如果 $f(x)$ 的标准分解式为 $f(x) = c\prod\limits_{i=1}^s p_1^{r_1}(x)$，那么：
    - $p_1(x), p_2(x),\cdots, p_s(x)$分别是 $f(x)$ 的 $r_1$ 重、$r_2$ 重、……、$r_s$ 重因式
    - 指数 $r_i=1$ 的那些不可约因式是单因式；指数 $r_i>1$ 的那些不可约因式是重因式
    因为没有一般的方法来求一个多项式的标准分解式，判别有没有重因式的问题就需要另外的方法解决
- **微商**：规定多项式 $f(x) = a_nx^n + a_{n-1}x^{n-1} + \cdots + a_1x + a_0$ 的**微商**（也是**导数**）是 $f'(x) = a_nnx^{n-1} + a_{n-1}(n-1)x^{n-2} + \cdots a_1$ 
    这种规定来源于数学分析，但我们目前只把它当作是一个形式的定义。
    同样可定义**高阶微商**的概念：
    **一阶微商**：微商 $f'(x)$ 称为 $f(x)$ 的**一阶微商** 
    **二阶微商**：$f'(x)$ 的微商 $f''(x)$ 称为 $f(x)$ 的**二阶微商** 
    $k$ **阶微商**：$f^{(k-1)}(x)$ 的微商 $f^{(k)}(x)$ 称为 $f(x)$ 的 $k$ **阶微商** 
- **关于多项式微商的基本公式**：
    1. $(f(x)+g(x))' = f'(x) + g'(x)$ 
    2. $(cf(x))' = cf'(x)$ 
    3. $(f(x)g(x))' = f'(x)g(x) + f(x)g'(x)$ 
    4. $(f^m(x))' = mf^{m-1}(x)f'(x)$ 
- **微商的性质**：如果不可约多项式 $p(x)$ 是 $f(x)$ 的 $k$ 重因式 $(k\ge 1)$，那么它是微商 $f'(x)$ 的 $k-1$ 重因式。
	- *证明过程* 
		由题意，$f(x)$ 可以分解为 $f(x) = p^k(x)g(x)$，且 $p(x) \nmid g(x)$ 
		因此 $f'(x) = p^{k-1}(x)(kg(x)p'(x) + p(x)g'(x))$，故 $p^{k-1}(x) \mid f'(x)$，那么只需证明 $p^k(x) \nmid f'(x)$ 即可。
		$p(x)$ 整除 $p(x)g'(x)$ 但不能整除 $kg(x)p'(x)$，故 $p^k(x) \nmid p^{k-1}(x)(kg(x)p'(x) + p(x)g'(x))$，故 $p^k(x) \nmid f'(x)$ 
		综上 $p^{k-1}(x) \mid f'(x)$ 且 $p^k(x) \nmid f'(x)$，证毕！
    - **推论 1**：如果不可约多项式 $p(x)$ 是 $f(x)$ 的 $k$ 重因式 $(k\ge 1)$，那么 $p(x)$ 是 $f(x), f'(x),\cdots,f^{(k-1)}(x)$ 的因式，但不是 $f^{(k)}(x)$ 的因式
	- **推论 2**：不可约多项式 $p(x)$ 是 $f(x)$ 的重因式 $\iff$ $p(x)$ 是 $f(x)$ 与 $f'(x)$ 的公因式
	- **推论 3**：多项式 $f(x)$ 没有重因式 $\iff$ $(f(x),f'(x))=1$ 
        - 这个推论表明，判别一个多项式有没有重因式，可以通过代数运算——**辗转相除法**来解决
        - 有些时候，特别是在讨论与解方程组有关的问题时，我们常常希望所考虑的多项式没有重因式。为达到目的，我们可以这样做：
	        设 $f(x)$ 具有标准分解式 $f(x) = c \prod\limits_{i=1}^s p_i^{r_i}(x)$，那么 $f(x)$ 与 $f'(x)$ 的最大公因式必须具有标准分解式 $p_1^{r_1-1}(x)p_2^{r_2-1}(x)\cdots p_s^{r_s-1}(x)$，于是 $\dfrac{f(x)}{(f(x),f'(x))} = c\prod\limits_{i=1}^s p_i(x)$ 
	        $\dfrac{f(x)}{(f(x),f'(x))} = c\prod\limits_{i=1}^s p_i(x)$ 这是一个没有重因式的多项式，但是它与 $f(x)$ 具有完全相同的不可约因式。因此，这是一个去掉因式重数的有效办法。
### 4-1-4 多项式函数
- **多项式函数**：设 $f(x) = a_nx^n + a_{n-1}x^{n-1} + \cdots + a_1x + a_0$ 是 $P[x]$ 中的多项式，$\alpha$ 是 $P$ 中的一个数，在 $f(x) = a_nx^n + a_{n-1}x^{n-1} + \cdots + a_1x + a_0$ 中用 $\alpha$ 代 $x$ 所得的数 $a_n\alpha^n + a_{n-1}\alpha^{n-1} + \cdots + a_1\alpha + a_0$ 称为 $f(x)$ **当** $x=\alpha$ **时的值**，记为 $f(\alpha)$。这样一来，多项式 $f(x)$ 就定义了一个数域 $P$ 上的函数。可以由一个多项式来定义的函数称为数域 $P$ 上的**多项式函数**。当 $P$ 是实数域时，这就是数学分析中所讨论的多项式函数。
- **根**（**零点**）：如果 $f(x)$ 在 $x=\alpha$ 时函数值 $f(\alpha)=0$，那么 $\alpha$ 就称为 $f(x)$ 的一个**根**或**零点** 
- $k$ **重根**：如果 $x-\alpha$ 是 $f(x)$ 的 $k$ 重因式，那么 $\alpha$ 称为 $f(x)$ 的 $k$ **重根** 
    - **单根**：当 $k=1$ 时，$\alpha$ 称为**单根** 
    - **重根**：当 $k>1$ 时，$\alpha$ 称为**重根** 
### 4-1-5 多项式与矩阵结合
- 若 $f(x) = a_nx^n + a_{n-1}x^{n-1} + \cdots + a_1x + a_0$ 是 $P[x]$ 中的多项式，$\boldsymbol A$ 为对角矩阵，$\boldsymbol A \in M_n(P)$，$\boldsymbol A = \begin{pmatrix} \lambda_1 \\ & \lambda_2 \\ && \ddots \\ &&& \lambda_n \end{pmatrix}$，则 $f(\boldsymbol A) = a_n\boldsymbol A^n + a_{n-1}\boldsymbol A^{n-1} + \cdots + a_1\boldsymbol A + a_0\boldsymbol E = \begin{pmatrix} f(\lambda_1) \\ & f(\lambda_2) \\ && \ddots \\ &&& f(\lambda_n) \end{pmatrix}$ 
### 4-1-6 特定数域上的多项式
1. 如果 $\alpha$ 是实系数多项式 $f(x)$ 的复根，那么 $\alpha$ 的共轭数 $\overline{\alpha}$ 也是 $f(x)$ 的根
	- *证明过程* 
		设 $f(x) = a_nx^n + a_{n-1}x^{n-1} + \cdots + a_0$，其中 $a_0, a_1, \cdots, a_n$ 是实数
		由已知 $f(\alpha) = a_n\alpha^n + a_{n-1}\alpha^{n-1} + \cdots a_0 = 0$ 
		两边取共轭数，有 $0=\overline{f(\alpha)} = a_n\overline{\alpha^n} + a_{n-1}\overline{\alpha^{n-1}} + \cdots + a_0 = f(\overline \alpha)$ 
		即 $f(\overline\alpha) = 0$，$\overline \alpha$ 也就是 $f(x)$ 的根，证毕！
2. 每个次数 $\ge 1$ 的有理系数多项式都能唯一地分解成不可约的有理系数多项式的乘积
3. **本原多项式**：如果一个非零的整系数多项式 $g(x) = b_nx^n + b_{n-1}x^{n-1} + \cdots + b_0$ 的系数 $b_n, b_{n-1}, \cdots , b_0$ 没有异于 $\pm 1$ 的公因子，也就是说，它们是互素的，它就称为一个**本原多项式**。
    - 任何一个非零的有理系数多项式 $f(x)$ 都可以表示成一个有理数 $r$ 与一个本原多项式 $g(x)$ 的乘积，即 $f(x) = rg(x)$ 
        可以证明这种表示法除了差一个正负号是唯一的。即，如果 $f(x) = rg(x) = r_1g_1(x)$，则必有 $r = \pm r_1,\ g(x) = \pm g_1(x)$ 
	- **高斯引理**：两个本原多项式的乘积还是本原多项式
	    - *证明过程* 
		    设 $f(x) = a_nx^n + a_{n-1}x^{n-1} + \cdots + a_0,\ g(x) = b_mx^m + b_{m-1}x^{m-1} + \cdots + b_0$ 是两个本原多项式，而 $h(x) = f(x)g(x) = d_{n+m}x^{n+m} + d_{n+m-a}x^{n+m-1} + \cdots + d_0$ 是它们的乘积。
			反证法，假设 $h(x)$ 不是本原的，即 $h(x)$ 的系数 $d_{n+m}, d_{n+m-1}, \cdots, d_0$ 有一异于 $\pm 1$ 的公因子，即有一个素数 $p$ 能整除 $h(x)$ 的每一个系数。
			- 由于 $f(x)$ 是本原的，故 $p$ 不能同时整除 $f(x)$ 的每一个系数。令 $a_i$ 是第一个不能被 $p$ 整除的系数，即 $p \mid a_0, \cdots, p \mid a_{i-1},\ p \nmid a_i$ 
			- 由于 $g(x)$ 是本原的，故 $p$ 不能同时整除 $g(x)$ 的每一个系数。令 $b_j$ 是第一个不能被 $p$ 整除的系数，即 $p \mid b_0, \cdots, p \mid b_{i-1},\ p \nmid b_j$ 
			而我们看 $h(x)$ 的系数 $d_{i+j}$，由乘积定义 $d_{i+j} = a_ib_j + \sum\limits_{k=1}^{\min(n-i,j)} a_{i+k}b_{j-k} + \sum\limits_{k=1}^{\min(i,m-j)} a_{i-k}b_{j+k}$ 
			由于 $p \mid d_{i+j},\quad p\ \left|\ \sum\limits_{k=1}^{\min(n-i,j)} a_{i+k}b_{j-k} \right.,\quad p\ \left|\ \sum\limits_{k=1}^{\min(i,m-j)} a_{i-k}b_{j+k}\right.$，故 $p \mid a_ib_j$ 
			这与 $p \nmid a_i$ 且 $p \nmid b_j$ 矛盾，故假设不成立。
			故 $h(x)$ 是本原多项式，证毕！
## 4-2 定理与推论
- **定理**：设 $\mathbb K, \mathbb L$ 是两个数域，则：$\mathbb K \cup \mathbb L$ 为数域等价于 $\mathbb K \subset \mathbb L$ 或 $\mathbb L \subset \mathbb K$ 
- **定理**：如果有等式 $f(x)=q(x)g(x)+r(x)$ 成立，那么 $f(x),g(x)$ 和 $g(x),r(x)$ 有相同的公因式。
	- *证明过程* 
		- 一方面：对于任意一个 $g(x),r(x)$ 的公因式 $\varphi(x)$，有 $\varphi(x) \mid g(x),\ \varphi(x) \mid r(x)$，则有 $\varphi(x) \mid q(x)g(x)+r(x)$，即 $\varphi(x) \mid f(x)$ 
		    也就是：$\varphi(x) \mid g(x),\ \varphi(x) \mid r(x) \Rightarrow \varphi(x) \mid f(x),\ \varphi(x) \mid g(x)$ 
		- 一方面：对于任意一个 $f(x),g(x)$ 的公因式 $\varphi(x)$，有 $\varphi(x) \mid f(x),\ \varphi(x) \mid g(x)$，则有 $\varphi(x) \mid f(x)-q(x)g(x)$，即 $\varphi(x) \mid r(x)$ 
		    也就是：$\varphi(x) \mid f(x),\ \varphi(x) \mid g(x) \Rightarrow \varphi(x) \mid g(x),\ \varphi(x) \mid r(x)$ 
		- 综上所述：$\varphi(x) \mid f(x),\ \varphi(x) \mid g(x) \iff \varphi(x) \mid g(x),\ \varphi(x) \mid r(x)$，也就是说 $f(x),g(x)$ 和 $g(x),r(x)$ 有相同的公因式，证毕！
    - 这个定理告诉我们 $(f(x),g(x)) = (g(x),r(x))$，如果记 $r(x) = f(x)\bmod g(x)$，则有 $(f(x),g(x)) = (g(x),f(x)\bmod g(x))$ 
	- 如果我们要求 $(f(x),g(x))$，那么只需要求 $(g(x),r(x))$，而 $\deg f(x) > \deg r(x)$，故我们实现了降低次数。通过**辗转相除**的思想，反复递归套用 $(f(x),g(x)) = (g(x),r(x))$，直到某一次的 $r(x)=0$，此时的 $g(x)$ 化为首项系数为 1 后就是所求的最大公因式。
- **多项式意义下的裴蜀定理**：对于 $P[x]$ 中任意两个多项式 $f(x),g(x)$，则在 $P[x]$ 中存在一个 $f(x),g(x)$ 的最大公因式 $d(x)$，使 $d(x)=u(x)f(x)+v(x)g(x)$ 
	- *证明过程* 
		如果 $f(x),g(x)$ 中有一个为零，那么 $f(x),g(x)$ 中非零的那个多项式就是 $f(x),g(x)$ 的一个最大公因式，化为首一后即为 $(f(x),g(x))$ 
		现在来看 $f(x),g(x)$ 都不为零的情况
		- 用 $g(x)$ 除 $f(x)$，得到商 $q_1(x)$，余式 $r_1(x)$ 
		- 如果 $r_1(x)=0$ 停止，否则用 $r_1(x)$ 除 $g(x)$ 得到商 $q_2(x)$，余式 $r_2(x)$ 
		- 如果 $r_2(x)=0$ 停止，否则用 $r_2(x)$ 除 $r_1(x)$ 得到商 $q_3(x)$，余式 $r_3(x)$ 
		- 如果 $r_3(x)=0$ 停止，否则用 $r_3(x)$ 除 $r_2(x)$ 得到商 $q_4(x)$，余式 $r_4(x)$ 
		- ……
		- 辗转相除下去，所得余式次数不断降低，即 $\deg g(x) > \deg r_1(x) > \deg r_2(x)>\cdots$，最后必然存在一个余式 $r_{s+1}(x)=0$ 
		- 这里多说一句，我们这个过程其实是反复地在降次的同时不改变最大公因式，原理如下：
		      $(f(x),g(x)) = (g(x),r_1(x)) = (r_1(x),r_2(x)) = (r_2(x),r_3(x)) = \cdots = (r_{s-1}(x), r_s(x)) = (r_s(x), r_{s+1}(x)) = (r_s(x), 0) = r_s(x)$ 
		于是就有：$\begin{cases} f(x) = q_1(x)g(x)+r_1(x) \\ g(x) = q_2(x)r_1(x)+r_2(x) \\ r_i(x) = q_{i+2}(x)r_{i+1}(x) + r_{i+2}(x) \quad \forall\ i=1,2,\cdots ,s-2 \\ r_{s-1}(x) = q_{s+1}(x)r_s(x) + 0 \end{cases}$，由前面知识可以知道 $d(x) = r_s(x)$ 
		将所知方程转化一下，变为：$\begin{cases} f(x) - q_1(x)g(x)=r_1(x) \\ g(x) - q_2(x)r_1(x)=r_2(x) \\ r_i(x) - q_{i+2}(x)r_{i+1}(x) = r_{i+2}(x) \quad \forall\ i=1,2,\cdots ,s-3 \\ r_{s-2}(x) - q_{s}(x)r_{s-1}(x) = r(s) \\ r_{s-1}(x) - q_{s+1}(x)r_s(x) = 0 \end{cases}$，从倒数第二个式子往上，保留 $r_s(x)$ 的同时反复回带消去 $r_i(x)\ i=1,2,\cdots s-1$ 得到 $r_s(x) = u(x)f(x)+v(x)g(x)$ 
		而我们知道 $r_s(x) = d(x)$，故 $d(x) = u(x)f(x)+v(x)g(x)$，证毕！
    - **推论 1**：对于 $P[x]$ 中任意 $s$ 个多项式 $f_i(x),\ \forall\ 1\le i \le s$，则在 $P[x]$ 中存在一个 $f_i(x),\ \forall\ 1\le i \le s$ 的最大公因式 $d(x)$，使 $d(x) = \sum\limits_{i=1}^s u_i(x)f_i(x)$ 
    - **推论 2**：$P[x]$ 中两个多项式 $f(x),g(x)$ 互素 $\iff$ 有 $P[x]$ 中的多项式 $u(x),v(x)$ 使 $u(x)f(x)+v(x)g(x)=1$ 
- **因式分解及唯一性定理**：数域 $P$ 上每一个次数 $\ge 1$ 的多项式 $f(x)$ 都可以唯一地分解成数域 $P$ 上一些不可约多项式的乘积。
	这里的“唯一”是指：若有两个分解式 $f(x) = p_1(x)p_2(x) \cdots p_s(x) = q_1(x)q_2(x)\cdots q_t(x)$，那么必有 $s=t$，并且适当排列因式次序后有 $p_i(x) = c_iq_i(x),\ i=1,2,\cdots,s$，其中 $c_i\ (i=1,2,\cdots,s)$ 是一些非零常数
    应该指出，因式分解定理虽然在理论上有其基本重要性，但是它并没有给出一个具体的分解多项式的方法。
    实际上，对于一般的情形，普遍可行的分解多项式的方法是不存在的。
    - **推论 1**：若 $f(x) = a_m \prod\limits_{i=1}^s p_i^{r_i}(x)$（$p_i(x)$ 首一不可约，$r_i\ge 1,\ r_i \in \mathbb Z$），$g(x) = b_m h(x) \prod\limits_{i=1}^s p_i^{t_i}(x)$（$t_i\ge 1,\ t_i \in \mathbb Z$），且 $\forall\ 1\le i \le s,\ (h(x),p_i(x)) = 1$，那么 $f(x) \mid g(x) \iff \forall\ 1 \le i \le s,\ r_i \le t_i$ 
	- **推论 2**：若 $f(x) = a_m \prod\limits_{i=1}^s p_i^{r_i}(x)$（$p_i(x)$ 首一不可约、互不相同且 $r_i\ge 0,\ r_i \in \mathbb Z$），$h(x) = c_p \prod\limits_{i=1}^s p_i^{m_i}(x)$（$m_i\ge 1,\ m_i \in \mathbb Z$），则 $(f(x), h(x)) = \prod\limits_{i=1}^s p_i^{\min(r_i,m_i)}(x)$ 
- **中国剩余定理（弱化版）**：设 $p_1(x), p_2(x),\cdots, p_s(x)$ 是不同的不可约多项式，令 $p(x) = \prod\limits_{i=1}^n p_i(x),\ P_i(x) = \dfrac{p(x)}{p_i(x)}$，$h_i(x)$ 是同余方程 $h_i(x)P_i(x) \equiv 1 \pmod {p_i(x)}$ 的一个解，则对于 $\forall\ a_1(x),a_2(x),\cdots,a_s(x) \in P[x]$，则 $\exists\ f(x)$ 使得方程组 $\begin{cases} f(x) \equiv a_1(x) \pmod {p_1(x)} \\ f(x) \equiv a_2(x) \pmod {p_2(x)} \\ \cdots\\ f(x) \equiv a_s(x) \pmod {p_s(x)} \\ \end{cases}$ 有解 ，解为 $f(x) = \sum\limits_{i=1}^n a_i(x)h_i(x)P_i(x)$ 
	- *证明过程* 
		- 首先我们证明一定存在这样的 $h_i(x)$
		      若 $h_i(x)P_i(x) \equiv 1 \pmod {p_i(x)}$ ，则 $h_i(x)P_i(x)-1 \equiv 0 \pmod {p_i(x)}$，则 $p_i(x) \mid h_i(x)P_i(x) - 1$，也就是 $\exists\ k_i(x)$ 使得 $h_i(x)P_i(x) - 1 = k_i(x)p_i(x)$，所以我们只需要证，存在 $h_i(x),\ k_i(x)$ 使得 $h_i(x)P_i(x) - k_i(x)p_i(x) = 1$ 
		      由于 $(P_i(x),\ p_i(x)) = 1$，故存在 $u_i(x),v_i(x)$ 使得 $u_i(x)P_i(x) + v_i(x)p_i(x) = 1$，取 $h_i(x) = u_i(x),\ k_i(x) = -v_i(x)$ 即可
		      证毕！
		- 再来证明解 $f(x) = \sum\limits_{i=1}^n a_i(x)h_i(x)P_i(x)$ 合法
		      由于 $P_i(x) = \dfrac{p(x)}{p_i(x)}$ 是除 $p_i(x)$ 之外所有_模数？_ 的倍数，所以 $\forall\ k\not=i,\ a_i(x)P_i(x)h_i(x) \equiv 0 \pmod {p_k(x)}$，又因为 $a_i(x)P_i(x)h_i(x) \equiv a_i(x) \pmod {p_i(x)}$，所以代入 $f(x) = \sum\limits_{i=1}^n a_i(x)h_i(x)P_i(x)$，原方程组成立，证毕。
		综上，多项式意义下的中国剩余定理（弱化版）得证！
	- 在整数的世界里，也有**中国剩余定理（弱化版）**：设 $m_1,m_2,\cdots,m_n$ 是素数，$m = \prod\limits_{i=1}^n m_i,\ M_i = \dfrac{m}{m_i}$，$t_i$ 是线性同余方程 $M_it_i \equiv 1 \pmod {m_i}$ 的一个解。则对于任意的 $n$ 个整数 $a_1,a_2,\cdots,a_n$，方程组 $\begin{cases} x \equiv a_1 \pmod {m_1} \\ x \equiv a_2 \pmod {m_2} \\ \cdots\\ x \equiv a_2 \pmod {m_2} \\ \end{cases}$ 有整数解，解为 $x=\sum\limits_{i=1}^n a_iM_it_i$ 
	    - *证明过程* 
		    首先由费马小定理可知一定存在这样的 $t_i$ 
		    又因为 $M_i = \dfrac{m}{m_i}$ 是除 $m_i$ 之外所有模数的倍数，所以 $\forall\ k\not=i,\ a_iM_it_i \equiv 0 \pmod {m_k}$，又因为 $a_iM_it_i \equiv a_i \pmod {m_i}$，所以代入 $x=\sum\limits_{i=1}^n a_iM_it_i$，原方程组成立，证毕。
- **余数定理**：用一次多项式 $x-\alpha$ 去除多项式 $f(x)$，所得的余式是一个常数，这个常数等于函数值 $f(\alpha)$ 
	- *证明过程* 
		用 $x-\alpha$ 去除 $f(x)$，设商为 $q(x)$，余式为一常数 $c$，于是 $f(x) = (x-\alpha)q(x) + c$ 
		以 $\alpha$ 代 $x$，得 $f(\alpha) = c$，证毕！
    - **推论**：$\alpha$ 是 $f(x)$ 的根 $\iff$ $(x-\alpha) \mid f(x)$ 
- **定理**：$P[x]$ 中的 $n$ 次多项式 $(n\ge 0)$ 在数域 $P$ 中的根不可能多于 $n$ 个，重根按重数计算。
	- *证明过程* 
		对于零次多项式，定理显然成立。
		设 $f(x)$ 是一个次数 $>0$ 的多项式，把 $f(x)$ 分解称不可约多项式的乘积。
		由 $\alpha$ 是 $f(x)$ 的根 $\iff$ $(x-\alpha) \mid f(x)$ 和根的重数的定义，显然 $f(x)$ 在数域 $P$ 中根的个数等于分解式中一次因式的个数，这个数目当然不超过 $n$，证毕！
    我们知道，每个多项式函数都可以由一个多项式来定义，不同的多项式会不会定义出相同的函数呢？即问：是否有可能 $f(x) \not= g(x)$，而对于 $P$ 中的所有数 $\alpha$ 都有 $f(\alpha) = g(\alpha)$？
    该定理告诉我们这是不可能的。
- **定理**：如果多项式 $f(x),g(x)$ 的次数都不超过 $n$，而它们对 $n+1$ 个不同的数 $\alpha_1,\alpha_2,\cdots,\alpha_{n+1}$ 有相同的值，即 $f(\alpha_i) = g(\alpha_i)\ (i=1,2,\cdots,n+1)$，那么 $f(x)=g(x)$ 
	- *证明过程* 
		由定理的条件，有 $f(\alpha_i) - g(\alpha_i) = 0,\ (i=1,2,\cdots,n+1)$，这就是说，多项式 $h(x) = f(x) - g(x)$ 有 $n+1$ 个不同的根
		如果 $h(x) \not= 0$，那么 $h(x)$ 就是一个次数不超过 $n$ 的多项式，便不可能有 $n+1$ 个根。
		因此 $h(x)=0$，即 $f(x) = g(x)$，证毕！
    - 因为数域 $P$ 中有无穷多个数，所以这个定理说明了，不同的多项式定义的函数也不相同。如果两个多项式定义相同的函数，就称为**恒等**。
    - 上面的结论表明，多项式的恒等与多项式相等实际上是一致的。换句话说，数域上的多项式既可以作为形式表达式来处理，也可以作为函数来处理。但考虑到今后的应用与推广，把多项式看成形式表达式要方便些。
- **拉格朗日插值**：给定互不相同的 $a_1,\cdots,a_n \in P$，任给 $b_1,\cdots,b_n \in P$，则存在唯一的多项式 $f(x) \in P[x]$ 满足 $\begin{cases} \deg f(x) < n \\ f(a_i) = b_i\ (\forall\ 1 \le i \le n) \end{cases}$，该多项式 $f(x) = \sum\limits_{i=1}^{n} b_i \prod\limits_{j=1,j\not=i}^{n} \dfrac{x-a_j}{a_i-a_j}$ 
      （证明方法有两种：法一为解线性方程组 + 范德蒙德行列式；法二为直接构造再代入验证。不写过程了）
- **代数基本定理**：每个次数 $\ge 1$ 的复系数多项式在复数域中有一根
	- **等价叙述**：每个次数 $\ge 1$ 的复系数多项式，在复数域上一定有一个一次因式
	- 可知，在复数域上所有次数大于等于 1 的多项式全是可约的，不可约多项式只有一次多项式。
- **复系数多项式因式分解定理**：每个次数 $\ge 1$ 的复系数多项式在复数域上都可以唯一地分解成一次因式的乘积。
    - 因此，复系数多项式具有**标准分解式** $f(x) = a_n \prod\limits_{k=1}^s (x-\alpha_k)^{l_k}$，其中 $\alpha_k$ 是不同的复数，$l_k$ 是正整数。
    - 标准分解式说明了：每个 $n$ 次复系数多项式恰有 $n$ 个复根（重根按重数计算）
- **实系数多项式因式分解定理**：每个次数 $\ge 1$ 的实系数多项式在实数域上都可以唯一地分解成一次因式与二次不可约因式的乘积
	- *证明过程* 
		假设定理对次数 $<n$ 的多项式已经证明。
		设 $f(x)$ 是 $n$ 次实系数多项式，由代数基本定理，$f(x)$ 有一复根 $\alpha$ 
		- 如果 $\alpha$ 是实数，那么 $f(x) = (x-\alpha) f_1(x)$，其中 $f_1(x)$ 是 $n-1$ 次实系数多项式。
		- 如果 $\alpha$ 不是实数，那么 $\overline{\alpha}$ 也是 $f(x)$ 的根，且 $\overline{\alpha} \not= \alpha$，于是 $f(x) = (x-\alpha)(x-\overline\alpha)f_2(x)$ 
		    而 $(x-\alpha)(x-\overline\alpha) = x^2 - (\alpha + \overline\alpha)x + \alpha\overline\alpha$ 是一个实系数二次不可约多项式，从而 $f_2(x)$ 是 $n-2$ 次实系数多项式。
		由归纳假设，$f_1(x)$ 或 $f_2(x)$ 可以分解成一次与二次不可约多项式的乘积，因之 $f(x)$ 也可以如此分解。
    - 因此，实系数多项式具有标准分解式 $f(x) = a_n \prod\limits_{i=1}^s (x-c_i)^{l_i} \prod\limits_{i=1}^r (x^2+p_ix+q_i)^{k_i}$，其中所有的 $c_i,p_i,q_i$ 全是实数，$l_i,\ k_i$ 是正整数，并且 $x^2 + p_1x + q_i$ 是不可约的，也就是适合条件 $p_i^2 - 4q_i < 0,\ i=1,2,\cdots,r$ 
- 如果一非零的整系数多项式能够分解成两个次数较低的有理系数多项式的乘积，那么它一定能分解成两个次数较低的整系数多项式的乘积
	- *证明过程* 
		设整系数多项式 $f(x)$ 有分解式 $f(x) = g(x)h(x)$，其中 $g(x), h(x)$ 是有理系数多项式，且 $\deg g(x) < \deg f(x),\ \deg h(x) < \deg f(x)$ 
		令 $f(x) = af_1(x),\ g(x) = rg_1(x),\ h(x) = sh_1(x)$，其中 $f_1(x), g_1(x), h_1(x)$ 都是本原多项式，$a$ 是整数，$r,s$ 是有理数。
		于是就有：$af_1(x) = rsg_1(x)h_1(x)$ 
		由高斯引理，$g_1(x)h_1(x)$ 也是本原多项式，由于表示法除了差一个正负号是唯一的，故 $rs = \pm a$ 
		也就是说 $rs$ 是一个整数，故 $f(x) = (rsg_1(x))h_1(x)$，这里 $rsg_1(x)$ 与 $h_1(x)$ 都是整系数多项式，且次数都低于 $f(x)$ 的次数。
	- **推论**：设 $f(x),g(x)$ 是整系数多项式，且 $g(x)$ 是本原的，如果 $f(x) = g(x)h(x)$，其中 $h(x)$ 是有理系数多项式，那么 $h(x)$ 一定是整系数的
	- 这个推论提供了一个求整系数多项式的全部有理根的方法。
- 设 $f(x) = a_nx^n + a_{n-1}x^{n-1} + \cdots + a_0$ 是一个整系数多项式，而 $\dfrac rs$ 是它的一个有理根，其中 $r,s$ 互素，那么必有 $s \mid a_n,\ r\mid a_0$。特别地，如果 $f(x)$ 的首项系数 $a_n = 1$，那么 $f(x)$ 的有理根都是整根，而且是 $a_0$ 的因子
	- *证明过程* 
		因为 $\dfrac rs$ 是 $f(x)$ 的一个有理根，因此在有理数域上 $\left. \left(x - \dfrac rs \right)\ \right|\ f(x)$，从而 $(sx-r) \mid f(x)$ 
		因为 $r,s$ 互素，所以 $sx-r$ 是一个本原多项式。
		根据之前得到过的推论，可知 $f(x) = (sx-r)(b_{n-1}x^{n-1} + \cdots + b_0)$，其中 $b_{n-1}, \cdots, b_0$ 都是整数。
		比较两边系数可得 $a_n = sb_{n-1},\ a_0 = -rb_0$ ，因此 $s \mid a_n,\ r \mid a_0$，证毕！
- **艾森斯坦（Eisenstein）判别法**：设 $f(x) = a_nx^n + a_{n-1}x^{n-1} + \cdots a+ a_0$ 是一个整系数多项式。如果有一个素数 $p$，使得：$p \nmid a_n$ 且 $p \mid a_{n-1}, a_{n-2}, \cdots, a_0$ 且 $p^2 \nmid a_0$，那么 $f(x)$ 在有理数域上是不可约的
	- *证明过程* 
		如果 $f(x)$ 在有理数域上可约，那么可知 $f(x)$ 可以分解成两个次数较低的整系数多项式的乘积：$f(x) = (b_lx^l + b_{l-1}x^{l-1} + \cdots + b_0) (c_mx^m + c_{m-1}x^{m-1} + \cdots + c_0), \quad l, m<n \text{ 且 } l+m=n$ 
		于是 $a_n = b_lc_m,\ a_0 = b_0c_0$ 
		- 一方面：因为 $p \mid a_0$，所以 $p$ 能整除 $b_0$ 或 $c_0$，但是 $p^2 \nmid a_0$，所以 $p$ 不能同时整除 $b_0$ 及 $c_0$，因此不妨假设 $p \mid b_0$ 但 $p\nmid c_0$ 
		- 另一方面，因为 $p \nmid a_n$，所以 $p \nmid b_l$，假设 $b_0, b_1, \cdots b_l$ 中第一个不能被 $p$ 整除的是 $b_k$ 
		比较 $f(x)$ 中的 $x^k$ 的系数，得等式 $a_k = b_kc_0 + b_{k-1}c_1 + \cdots + b_0c_k$，式中 $a_k, b_{k-1}, \cdots, b_0$ 都能被 $p$ 整除，所以 $b_kc_0$ 也必定能被 $p$ 整除。
		但是 $p$ 是一个素数，所以 $b_k$ 与 $c_0$ 中至少有一个能被 $p$ 整除，这是一个矛盾。
    - 由该定理可知：对于任意的 $n$，多项式 $x^n + 2$ 在有理数域上是不可约的。由此可见，在有理数域上，存在任意次数的不可约多项式。
## 4-3 补充性质、定理
- 如果多项式 $f_1(x), f_2(x)$ 都与 $g_1(x), g_2(x)$ 互素，则 $(f_1(x)g_1(x), f_2(x)g_2(x))= (f_1(x), f_2(x)) \cdot (g_1(x), g_2(x))$ 
	- *证明过程* 
		令 $d(x) = (f_1(x)g_1(x), f_2(x)g_2(x)),\ d_1(x) = (f_1(x), f_2(x)),\ d_2(x) = (g_1(x), g_2(x))$ 
		*只需证明 $d_1(x)d_2(x) \mid d(x)$ 和 $d(x) \mid d_1(x)d_2(x)$ 即可* 
		一方面：
		显然 $d_1(x) \mid d(x),\ d_2(x) \mid d(x)$ 
		由于 $(f_1(x), g_1(x)) = 1$，故 $(d_1(x), d_2(x)) = 1$，因此 $d_1(x)d_2(x) \mid d(x)$ 
		另一方面：
		由于 $d(x) \mid f_1(x)g_1(x)$，可令 $d(x) = f(x)g(x)$，其中 $f(x) \mid f_1(x),\ g(x) \mid g_1(x)$ 
		由于 $(f_1(x), g_2(x)) = 1$，故 $(f(x), g_2(x))=1$ 
		由 $f(x) \mid d(x),\ d(x) \mid f_2(x)g_2(x)$ 得 $f(x)\mid f_2(x)g_2(x)$，再由 $(f(x), g_2(x))=1$ 得 $f(x) \mid f_2(x)$，因此 $f(x) \mid d_1(x)$ 
		同理 $g(x) \mid d_2(x)$，所以 $d(x) \mid d_1(x)d_2(x)$ 
		于是 $d(x) = d_1(x)d_2(x)$
