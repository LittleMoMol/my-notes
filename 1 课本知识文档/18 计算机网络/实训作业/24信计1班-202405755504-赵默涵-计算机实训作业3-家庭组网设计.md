## 2 需求分析
**场景**：三口之家，约 90㎡ 三室一厅，承重墙较多。

|成员|主要终端|需求|
|---|---|---|
|父亲|手机、办公笔记本|视频会议稳定|
|母亲|手机、智能电视|高清视频流畅|
|学生|台式机、手机、平板|游戏低延迟、下载快|
|公共|NAS、打印机、摄像头×4、智能插座/音箱×10|稳定接入|

- 终端约 **22 台**（有线 5，无线 17）
- 接入带宽：**1000 Mbps 光纤**，实测 ≥900 Mbps 为合格
- 内网传输要求跑满千兆（≥900 Mbps）
- 智能家居需隔离，访客需独立网络且禁止访问内网
- 单台路由覆盖不足，采用**主路由 + 2 台 AP 有线回程**
## 3 网络拓扑设计

                    │   互联网 ISP   │  
                    └──────┬───────┘  
                           │ 光纤  
                    ┌──────┴───────┐  
                    │   光猫(桥接)  │  
                    └──────┬───────┘  
                           │ Cat6 网线  
              ┌────────────┴────────────┐  
              │  主路由(拨号/NAT/DHCP)   │  
              │   PPPoE + VLAN 子接口    │  
              └────────────┬────────────┘  
                           │ Cat6 网线  
              ┌────────────┴────────────┐

              └──┬─────┬─────┬─────┬─-──┘  
                 │     │     │     │

          │台式机 │ │ NAS │ │打印│ │PoE交换机│  
          │(有线) │ │(有线)│ │机  │ └───┬────┘  
          └───────┘ └─────┘ └────┘     │ 摄像头×4  
              ┌──────────────────────────────┐  
              │  交换机 Trunk 口 → AP1 / AP2  │  
              │  AP1(客厅)   AP2(主卧)        │  
              │  多 SSID 映射不同 VLAN         │  
              └──────────────────────────────┘

**组网要点**：
- 光猫设为**桥接模式**，仅做光电转换，主路由完成 PPPoE 拨号与 NAT
- 避免双重 NAT，NAT 性能更高，端口映射更直接
- AP 采用**有线回程**，无线回程会因共享带宽导致内网降速

## 8 故障排查
**故障一：桥接后拨号失败**
- 原因：光猫桥接 VLAN ID 未正确填写
- 解决：登录光猫截图保存原 INTERNET 的 VLAN ID，在路由器对照填入

**故障二：副路由下设备获取错误 IP**
- 原因：副路由未设 AP 模式，DHCP 与主路由冲突
- 解决：改为纯 AP 模式，关闭副路由 DHCP

**故障三：AP 无线回程导致内网仅 300 Mbps**
- 原因：5 GHz 无线回程带宽被上下行共享，受墙体衰减
- 解决：改为网线有线回程，恢复至 942 Mbps

## 9 优化建议
1. **升级 2.5G 内网**：NAS 网卡与交换机换 2.5GbE，吞吐可达 2.3 Gbps
2. **部署 WireGuard VPN**：在外安全访问家庭内网
3. **配置 AdGuard Home**：NAS 上部署 DNS 广告拦截
4. **添加 UPS**：防止意外断电损坏 NAS 磁盘
5. **定期固件升级**：修补安全漏洞
