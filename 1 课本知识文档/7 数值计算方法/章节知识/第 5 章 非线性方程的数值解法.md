# 5 非线性方程的数值解法
## 5-0 前言
- **非线性方程的数值解法**：即方程 $f(x) = 0$ 的数值解法，这里 $x \in \mathbb{R},\ f \in C[a, b]$ 
- *问题引入*：本章只考虑多项式方程实数根的问题，即数值求解多项式方程 $p_{n}(x) = 0$，其中 $p_{n}(x) = a_{n} x^{n} + a_{n-1} x^{n-1} + \cdots + a_{1} x + a_{0}$，设系数 $a_{n}, a_{n-1}, \cdots, a_{0}$ 均为实数，且 $a_{n} \neq 0$ 
- **零点**：方程 $f(x) = 0$ 的根 $x^{*}$ 又称 $f$ 的**零点** 
	- *零点求解的困难性*：对于一般给定的 $f$，$x^{*}$ 是难以用公式表示的。即使对于多项式的情形，大家熟知 $n = 1, 2$ 时的方程求根公式，$n = 3, 4$ 的求解公式可在数学手册上查到，但对于 $n \geqslant 5$ 的情形，是不能用公式表示方程的根的。
	- *只能求近似解*：所以，求方程的根要用数值方法，即给出达到一定精确度的近似根的方法。
- **$m$ 重零点**、**$m$ 重根**：对于多项式方程，有单根和重根的概念，这可推广到方程 $f(x) = 0$。设 $f(x)$ 可分解为 $f(x) = (x - x^{*})^{m} g(x)$，其中 $m$ 为正整数，$g$ 满足 $g(x^{*}) \neq 0$。显然 $x^{*}$ 是 $f$ 的零点。称 $x^{*}$ 是 $f$ 的 **$m$ 重零点**，或称 $x^{*}$ 是方程 $f(x) = 0$ 的 **$m$ 重根** 
	- 若 $g$ 充分光滑，$x^{*}$ 是 $f$ 的 $m$ 重零点，则有 $f\left( x^{*} \right) = f^{\prime}\left( x^{*} \right) = \cdots = f^{(m-1)}\left( x^{*} \right) = 0,\ f^{(m)}\left( x^{*} \right) \neq 0$ 
- *注意*：方程 $f(x)=0$ 的根可能有多个，本章所讨论的方法都是逐个求出根。
- **有根区间**：一般来说，设在区间 $[a,b]$ 上方程有一个根，$[a,b]$ 就称为方程的一个**有根区间** 
	- 如果在 $[a,b]$ 上方程有且只有一个根，则 $[a,b]$ 把方程的根隔离出来了。这时若能把有根区间不断缩小，便可逐步得出根的近似值。
- *思想*：把方程的根隔离出来，要根据函数 $f$ 的性质来进行，包括一些试算。例如，若知道 $f(a)f(b)<0$，由 $f$ 连续性，$[a,b]$ 一定是一个有根区间。要找出方程的所有实根，往往要进行所谓“根的搜索”，即用各种方法找出若干个有根区间，然后再用各种方法在各有根区间上求出各个根的近似值，本章的侧重点在后者。
## 5-1 二分法
### 5-1-1 二分算法
- **二分法**：求解方程 $f(x)=0$ 一种简便的方法就是**二分法**。
- *二分法的具体步骤* 
	设已找到有根区间 $[a,b]$ 满足 $f(a) f(b) < 0$，并且 $f(x)=0$ 在 $[a,b]$ 上只有一个根。下面用简单的方法形成有根区间的序列。
	先设 $a_{1}=a$，$b_{1}=b$，即 $[a_{1},b_{1}]=[a,b]$，对于一般的区间 $[a_{n},b_{n}]$，设其中点为 $x_{n}=\dfrac{a_{n}+b_{n}}{2}$ 
	若 $f(x_{n})=0$，则 $x_{n}$ 即为所求，否则，检验 $f(x_{n})$ 的符号，若它与 $f(a_{n})$ 同号，就取 $a_{n+1}=x_{n},\ b_{n+1}=b_{n}$；反之，取 $a_{n+1}=a_{n},\ b_{n+1}=x_{n}$。这样必有 $f(a_{n+1})f(b_{n+1})<0$，所以 $[a_{n+1},b_{n+1}]$ 就是新的有根区间。
	继续上述过程，最后加上规定的误差要求，即可
- *二分法的图示*
	![[Pasted image 20260215102431.png|200]]
- **二分算法**：设 $\varepsilon$ 为根的容许误差，$\delta$ 为函数值的容许误差，$n=1,\ a_1=a,\ b_1=b$ 
	1. 令 $x_n = (a_n+b_n)/2$ 
	2. 若 $|f(x_n)|\le \delta$ 或 $b_n - x_n\le \varepsilon$，则输出 $x_n$，停止
	3. 若 $f(a_{n}) f(x_{n}) > 0$，则令 $a_{n+1} = x_{n}, b_{n+1} = b_{n}$；否则令 $a_{n+1} = a_{n}, b_{n+1} = x_{n}$ 
	4. $n := n+1$，转向步骤 1
	- *注*：该算法中第 2 步中 $b_{n} - x_{n} \leqslant \varepsilon$ 的判别，可用 $\left| x_{n} - x_{n-1} \right| < \varepsilon$ 或相对误差 $\left| x_{n} - x_{n-1} \right| / \left| x_{n} \right| < \varepsilon$ 来代替。
- *注*：算法得到的 $x_{n} = \dfrac{a_{n} + b_{n}}{2}$ 一定收敛到方程的根
- *注*：用二分法求方程的根，需先确定初始区间 $[a, b]$，使 $f(a)$ 与 $f(b)$ 异号。一般可用画函数图像或列表格的办法来确定初始区间。
### 5-1-2 误差估计
- **定理 1**：设 $f \in C[a, b]$，$f(a) f(b) < 0$，则二分算法产生的序列 $\{x_{n}\}$ 满足 $\left| x_{n} - x^{*} \right| \leqslant \dfrac{b - a}{2^{n}}$，其中 $x^{*} \in (a, b)$ 为 $f(x)=0$ 的根
	- *证明过程* 
		因为 $[a_{n}, b_{n}]$ 由 $[a_{n-1}, b_{n-1}]$ 一分为二得到，所以对 $n \geqslant 1$，区间长度 $b_{n} - a_{n} = \dfrac{b_{n-1} - a_{n-1}}{2} = \cdots = \dfrac{b - a}{2^{n-1}}$ 
		而 $x^{*} \in [a_{n}, b_{n}]$，且 $x_{n} = (a_{n} + b_{n}) / 2$，所以 $\left| x_{n} - x^{*} \right| \le \dfrac{b_{n} - a_{n}}{2} = \dfrac{b - a}{2^{n}}$ 
	- 该定理保证了 $n \to \infty$ 时有 $x_{n} \to x^{*}$，而且给出了误差估计式
### 5-1-3 二分法的优缺点
- *优点*：方法及相应程序简单，且对函数 $f(x)$ 的性质要求不高，只要连续即可
- *缺点*：二分法只能用于求实函数方程 $f(x)=0$ 的实根，不能用于求复根和偶数重根。
- *缺点*：如果 $f$ 有二重根 $x^*$ 或有相近的两个零点，那么即使区间 $[x_0, x_1]$ 包含了 $f$ 的零点，条件 $f(x_0)f(x_1)<0$ 也不成立
## 5-2 简单迭代法
给定方程 $f(x) = 0$，在实际应用中往往采用迭代方法求其满足一定精度的近似根
### 5-2-1 不动点迭代法
- *准备工作*：将方程 $f(x)=0$ 化为等价的形式 $x=\varphi(x)$ 
	- 可通过不同的途径将方程 $f(x)=0$ 化成 $x=\varphi(x)$ 的形式，如令 $\varphi(x) = x - f(x)$，也可用更复杂的方法
- **不动点**：若 $x^{*}$ 满足 $f(x^{*}) = 0$，则 $x^{*}$ 也满足 $x^{*} = \varphi(x^{*})$，反之亦然。称 $x^{*}$ 是函数 $\varphi(x)$ 的一个**不动点**，即映射关系 $\varphi$ 将 $x^{*}$ 映射到 $x^{*}$ 自身。
	- 求 $f(x)$ 的零点问题就等价地化为求 $\varphi$ 的不动点问题。
- **不动点迭代法**（**简单迭代法**、**逐次逼近迭代法**）、**迭代函数**：选择一个初始近似值 $x_{0}$，然后按以下公式迭代计算：$\boxed{x_{k+1} = \varphi(x_{k}),\ k = 0, 1, 2, \cdots\quad (*)}$，称迭代式 $(*)$ 为**不动点迭代法**（也称**简单迭代法**或**逐次逼近法**），$\varphi$ 为**迭代函数** 
	- 若式 $(*)$ 产生的序列 $\{x_{k}\}$ 收敛到 $x^{*}$，则 $x^{*}$ 就是 $\varphi$ 的不动点，即 $f$ 的零点。
- *例子*：已知方程 $x^{3} + 4x^{2} - 10 = 0$ 在 $[1,2]$ 上有一个根，可以用不同的代数运算得到不同形式的方程 $x=\varphi(x)$ 
	- *方法 1*：$x = x - x^{3} - 4x^{2} + 10$，即 $\varphi_{1}(x) = x - x^{3} - 4x^{2} + 10$ 
	- *方法 2*：原方程写成 $4x^{2} = 10 - x^{3}$，考虑到所求根为正根，化成 $x = \dfrac{1}{2}(10 - x^{3})^{1/2}$，即 $\varphi_{2}(x) = \dfrac{1}{2}(10 - x^{3})^{1/2}$ 
	- *方法 3*：原方程写成 $x^{2} = \dfrac{10}{x} - 4x$，化成 $x = \left( \dfrac{10}{x} - 4x \right)^{1/2}$，即 $\varphi_{3}(x) = \left(10/x - 4x\right)^{1/2}$ 
	- *方法 4*：化成 $x = (10/(4+x))^{1/2}$，即 $\varphi_{4}(x) = (10/(4+x))^{1/2}$ 
	- *方法 5*：化成 $x = x - \dfrac{x^{3} + 4x^{2} - 10}{3x^{2} + 8x}$，即 $\varphi_{5}(x) = x - \dfrac{x^{3} + 4x^{2} - 10}{3x^{2} + 8x}$。注意在 $[1,2]$ 上，$f'(x) = 3x^2 + 8x>0$，此时 $\varphi_5(x) = x - \dfrac{f(x)}{f'(x)}$。易验证，$f(x)=0$ 与 $x=\varphi_5(x)$ 是等价的
	- 取 $x_0=1.5$，上面 5 种方法迭代结算结果如下

- 用迭代法 $(*)$ 求方程 $f(x) = 0$ 的根的近似解，需要讨论如下问题：
	1. 如何选取合适的迭代函数 $\varphi(x)$？
	2. 迭代函数 $\varphi(x)$ 应满足什么条件，序列 $\{x_{k}\}$ 才收敛？
	3. 怎样加速序列 $\{x_{k}\}$ 的收敛？
### 5-2-2 不动点迭代法的一般理论
- **不动点定理** (**定理 2**)：设 $\varphi(x) \in C[a, b]$，且 $a \le \varphi(x) \le b$ 对一切 $x \in [a, b]$ 成立，则 $\varphi$ 在 $[a, b]$ 上一定有不动点。进一步假设 $\varphi \in C^{1}[a, b]$，且存在常数 $0 < L < 1$，使对 $\forall\ x \in [a, b]$，成立 $|\varphi^{\prime}(x)| \le L$，则 $\varphi$ 在 $[a, b]$ 上的不动点是唯一的
	- *证明过程* 
		*第 1 步*：证明第一个结论
		因 $\varphi \in C[a,b]$，且当 $x \in [a,b]$ 时 $a \leqslant \varphi(x) \leqslant b$，作辅助函数 $\psi(x) = \varphi(x) - x$ 
		则 $\psi(x) \in C[a,b]$，且 $\psi(a) = \varphi(a) - a \geqslant 0,\ \psi(b) = \varphi(b) - b \leqslant 0$ 
		当 $\psi(a) = 0$ 或 $\psi(b) = 0$ 成立时，则 $\varphi(a) = a$ 或 $\varphi(b) = b$，$a$ 或 $b$ 就是 $\varphi$ 的不动点
		若 $\psi(a) > 0$，$\psi(b) < 0$ 成立时，根据连续函数的性质，一定存在 $x^{*} \in (a,b)$，使 $\psi(x^{*}) = 0$，即 $\varphi(x^{*}) = x^{*}$，$x^{*}$ 就是 $\varphi$ 的不动点。
		*第 2 步*：证明第二个结论
		设 $\varphi \in C^{1}[a,b]$ 且满足 $|\varphi^{\prime}(x)| \le L$ 
		若 $\varphi$ 有两个不同的不动点 $x_{1}^{*}, x_{2}^{*} \in [a,b]$，则由微分中值定理可知
		$$
		\begin{aligned}
		\left| x_{1}^{*} - x_{2}^{*} \right| &= \left| \varphi(x_{1}^{*}) - \varphi(x_{2}^{*}) \right| = \left| \varphi^{\prime}(\xi) (x_{1}^{*} - x_{2}^{*}) \right| \\
		&\leqslant L \left| x_{1}^{*} - x_{2}^{*} \right| < \left| x_{1}^{*} - x_{2}^{*} \right|
		\end{aligned}
		$$
		引出矛盾。故 $\varphi$ 的不动点只能是唯一的，证毕！
	- 该定理给出了不动点存在唯一的充分条件
- **自身上的一个映射**、**压缩映射**、**Lipschitz (利普希茨) 常数**：若 $\varphi(x)$ 为定义在区间 $I=[a,b]$ 上的函数，且 $\forall\ x \in I$，均有 $\varphi(x) \in I$，称 $\varphi(x)$ 为 $I$ **自身上的一个映射**。若 $\varphi(x)$ 为 $I$ 自身上的映射，且存在 $0 < L < 1$，当 $x_{1},x_{2} \in I$ 时，有 $|\varphi(x_{1})-\varphi(x_{2})| \leqslant L|x_{1}-x_{2}|$，则称 $\varphi(x)$ 为 $I$ 上的一个**压缩映射**，$L$ 为 **Lipschitz (利普希茨) 常数**。
	- **性质 1**：若 $\varphi(x)$ 为 $I$ 上的压缩映射，则 $\varphi$ 必为 $I$ 上的连续函数
	- **性质 2**：若 $\varphi(x)$ 为 $I$ 自身上的映射，$\varphi(x) \in C^{1}(I)$，且 $|\varphi^{\prime}(x)| \leqslant L < 1$，则 $\varphi(x)$ 必是 $I$ 上的一个压缩映射。
	- 这样，读者很容易将**不动点定理**用 $I$ 上的自身映射和压缩映射概念叙述出来。
	- 压缩映射、不动点原理在许多领域中都能用到。
- **定理 3** 
	设 $\varphi \in C[a,b] \cap C^{1}(a,b)$，且满足
	(1) $a \leqslant \varphi(x) \leqslant b$ 对一切 $x \in [a,b]$ 成立
	(2) 存在常数 $0 < L < 1$，使 $|\varphi^{\prime}(x)| \leqslant L$ 对一切 $x \in (a,b)$ 成立
	则有如下结论：
	(1) 对任何的 $x_{0} \in [a,b]$，由式 $\boxed{x_{k+1} = \varphi(x_{k}),\ k = 0, 1, 2, \cdots\quad (*)}$ 产生的序列 $\{x_{k}\}$ 必收敛到 $\varphi$ 的不动点 $x^{*}$ 
	(2) $\{x_{k}\}$ 有误差估计 $|x_{k} - x^{*}| \leqslant \dfrac{1}{1 - L} |x_{k+1} - x_{k}|$ 和 $|x_{k} - x^{*}| \leqslant \dfrac{L^{k}}{1 - L} |x_{1} - x_{0}|$ 
	- *证明过程* 
		*第 1 步*：证明结论 (1)
		在本定理的条件下，由**不动点定理**保证了 $\varphi$ 存在唯一的不动点 $x^{*} \in [a, b]$ 
		由条件 (1)，$(*)$ 产生的 $x_{k} (= \varphi(x_{k-1}))$ 必满足 $x_{k} \in [a, b],\ k = 0, 1, 2, \cdots$ 
		再由条件 (2) 可得 $|x_{k} - x^{*}| = |\varphi(x_{k-1}) - \varphi(x^{*})| = |\varphi^{\prime}(\xi)| \cdot |x_{k-1} - x^{*}| \leqslant L |x_{k-1} - x^{*}|,\ k = 1, 2, \cdots$，其中 $\xi$ 介于 $x_{k-1}$ 与 $x^{*}$ 之间，故 $\xi \in (a, b)$ 
		反复利用以上不等式，得 $|x_{k} - x^{*}| \leqslant L |x_{k-1} - x^{*}| \leqslant L^{2} |x_{k-2} - x^{*}| \leqslant \cdots \leqslant L^{k} |x_{0} - x^{*}|,\ k = 0, 1, 2, \cdots$ 
		因 $L < 1$，$|x_0 - x^{*}|$ 与 $k$ 无关，故 $\lim\limits_{k \to \infty} (x_k - x^{*}) = 0$，即 $\{x_k\}$ 收敛于 $x^{*}$ 
		*第 2 步*：证明结论 (2)
		估计不等式 $|x_{k} - x^{*}| \leqslant \dfrac{1}{1 - L} |x_{k+1} - x_{k}|$ 和 $|x_{k} - x^{*}| \leqslant \dfrac{L^{k}}{1 - L} |x_{1} - x_{0}|$  
		由于 $\begin{aligned} |x_{k+1} - x_k| = |\varphi(x_k) - \varphi(x_{k-1})| = |\varphi^{\prime}(\xi)| \cdot |x_k - x_{k-1}|  \leq L |x_k - x_{k-1}|,\ k = 1, 2, \cdots \end{aligned}$，其中 $\xi$ 介于 $x_k$ 与 $x_{k-1}$ 之间，故 $\xi \in [a, b]$，于是
		$$
		\begin{aligned}
		|x_{k+1} - x_k| &= |(x_{k+1} - x^{*}) + (x^{*} - x_k)| \\
		&\geq |x_k - x^{*}| - |x_{k+1} - x^{*}| \\
		&\geq |x_k - x^{*}| - L |x_k - x^{*}| \\
		&= (1 - L) |x_k - x^{*}|
		\end{aligned}
		$$
		从而 $|x_k - x^{*}| \leq \dfrac{1}{1 - L} |x_{k+1} - x_k|,\ k = 0, 1, 2, \cdots$ 
		利用上述式子，可得 $|x_k - x^{*}| \leq \dfrac{1}{1 - L} |x_{k+1} - x_k| \leq \dfrac{L}{1 - L} |x_k - x_{k-1}| \leq \cdots \leq \dfrac{L^k}{1 - L} |x_1 - x_0|$ 
		综上证毕！
	- 该定理给出了在不动点存在唯一的情况下 $(*)$ 收敛的一个充分条件
	- 由 $|x_{k} - x^{*}| \leqslant \dfrac{L^{k}}{1 - L} |x_{1} - x_{0}|$ 知，$x_1 - x_0$ 与 $k$ 是无关的，若 $L \approx 1$，则 $x_k$ 必然收敛慢；若 $L \ll 1$，则收敛快。若给定了 $x_0$（从而定出 $x_1$）及误差 $\varepsilon$，由 $|x_{k} - x^{*}| \leqslant \dfrac{L^{k}}{1 - L} |x_{1} - x_{0}|$ 可估计出所需迭代次数。当然，这样的估计和所确定的 $L$ 有关
	- 利用该定理分析 $[a,b]$ 上迭代过程的收敛性是比较困难的。
	- **全局收敛性**：定理给出的是 $[a,b]$ 上的收敛性，称之为**全局收敛性**。

### 5-2-3 局部收敛性和收敛阶
- **局部收敛**：若存在 $\varphi$ 的不动点 $x^*$ 的一个闭邻域 $N(x^*) = [x^* - \delta, x^* + \delta]\ (\delta >0)$，对任意的 $x_0\in N(x^*)$，$\boxed{x_{k+1} = \varphi(x_k),\ k=0,1,2,\cdots\quad (*)}$ 产生的序列 $\{x_k\}$ 均收敛于 $x^*$，就称求 $x^*$ 的迭代法 $(*)$ **局部收敛** 
	- 由于讨论 $[a,b]$ 上的全局收敛性比较困难，下面转向讨论在 $x^*$ 附近的收敛性
- **定理 4**：设 $x^*$ 为 $\varphi$ 的不动点，$\varphi'(x)$ 在 $x^*$ 的某邻域连续，且 $|\varphi'(x^*)| \le L < 1$，则迭代法 $(*)$ 局部收敛
	- *证明过程* 
		因 $\varphi'(x)$ 连续，所以对任意的 $\varepsilon \in (0,1-L)$，存在 $x^{*}$ 的一个邻域 $N(x^{*}) = [x^{*} - \delta, x^{*} + \delta]$，在其上 $|\varphi'(x)| \le L + \varepsilon < 1$，且有 $|\varphi(x) - x^{*}| = |\varphi(x) - \varphi(x^{*})| \le (L + \varepsilon) |x - x^{*}| < \delta$ 
		即对一切 $x \in N(x^{*})$，有 $x^{*} - \delta < \varphi(x) < x^{*} + \delta$ 
		根据**定理 3**，迭代法 $(*)$ 对任意 $x_{0} \in N(x^{*})$ 收敛，这就证明了式 $(*)$ 的局部收敛性
- 下面讨论迭代法的阶，这是度量一种迭代法收敛快慢的标志。
- **$p$ 阶收敛**、**渐进误差常数**：设序列 $\{x_{k}\}$ 收敛到 $x^{*}$，记 $e_{k} = x_{k} - x^{*}$，若存在实数 $p \ge 1$ 及非零常数 $c > 0$，使 $\lim\limits_{k \to \infty} \dfrac{|e_{k+1}|}{|e_{k}|^{p}} = c$，则称序列 $\{x_{k}\}$ 是 **$p$ 阶收敛**的，$c$ 称为**渐近误差常数** 
	- **线性收敛**：当 $p = 1$ 且 $0 < c < 1$ 时，$\{x_{k}\}$ 称为**线性收敛**的
	- **超线性收敛**：$p > 1$ 称为**超线性收敛**
	- **平方收敛** (**二次收敛**)：$p = 2$ 时称为**平方收敛**或**二次收敛** 
	- **$p$ 阶收敛**：如果由迭代过程 $(*)$ 产生的序列 $\{x_{k}\}$ 是 $p$ 阶收敛的，则称迭代式 $(*)$ 是 **$p$ 阶收敛**的
	- $p$ 的大小反映了迭代法收敛的快慢。$p$ 越大，$\{x_{k}\}$ 收敛于 $x^{*}$ 就越快。
	- 迭代法的**收敛阶**是对迭代法收敛速度的一种度量。
- *结论*：要想得到超线性收敛的方法，$(*)$ 中的 $\varphi$ 必须满足 $\varphi'(x^{*}) = 0$ 
	- *推导过程* 
		设迭代法 $(*)$ 中 $\varphi$ 满足**定理 3** 或**定理 4** 的条件，则 $\lim\limits_{k \to \infty} x_{k} = x^{*}$ 
		再设在 $[a,b]$ 或 $x^{*}$ 的邻域内 $\varphi'(x) \neq 0$ 
		利用 $e_{k+1} = x_{k+1} - x^{*} = \varphi(x_{k}) - \varphi(x^{*}) = \varphi'(\xi) e_{k}$，其中 $\xi$ 介于 $x_{k}$ 与 $x^{*}$ 之间
		若取 $x_{0} \neq x^{*}$，必有 $e_{0} \neq 0$，从而当 $k \to \infty$ 时，$e_{k} \neq 0$，由 $\varphi'(x)$ 的连续性得 $\lim\limits_{k \to \infty} \dfrac{|e_{k+1}|}{|e_{k}|} = |\varphi'(x^{*})| \neq 0$ 
		所以这种情况下迭代是线性收敛的。
		故要想得到超线性收敛的方法，$(*)$ 中的 $\varphi$ 必须满足 $\varphi'(x^{*}) = 0$ 
- **定理 5**：设迭代式 $(*)$ 的迭代函数 $\varphi$ 的高阶导数 $\varphi^{(p)} (p > 1)$ 在不动点 $x^{*}$ 的邻域内连续，则式 $(*)$ 是 $p$ 阶收敛 $\iff$ $\varphi(x^{*}) = x^{*},\ \varphi^{(l)}(x^{*}) = 0, \ l = 1,2,\cdots, p-1,\ \varphi^{(p)}(x^{*}) \neq 0$。在此基础上有 $\lim\limits_{k \to \infty} \dfrac{e_{k+1}}{e_{k}^{p}} = \dfrac{1}{p!} \varphi^{(p)}\left( x^{*} \right) \neq 0$ 
	- *证明过程* 
		*充分性* 
		对 $p>1$，因 $\varphi^{\prime}\left( x^{*} \right)=0$，**定理 4** 保证了式 $(*)$ 的局部收敛性（收敛于 $x^{*}$）
		取充分接近 $x^{*}$ 的初值 $x_{0} \neq x^{*}$，可验证 $x_{k} \neq x^{*},\ k=1,2,\cdots$ 
		由 Taylor 展开式
		$$
		\begin{aligned}
		\varphi\left( x_{k} \right) &= \varphi\left( x^{*} \right) + \varphi^{\prime}\left( x^{*} \right) \left( x_{k} - x^{*} \right) + \cdots \\
		&\quad + \dfrac{1}{(p-1)!} \varphi^{(p-1)}\left( x^{*} \right) \left( x_{k} - x^{*} \right)^{p-1} + \dfrac{1}{p!} \varphi^{(p)}(\xi) \left( x_{k} - x^{*} \right)^{p}
		\end{aligned}
		$$
		其中 $\xi$ 介于 $x_{k}$ 与 $x^{*}$ 之间。再利用条件 $\varphi(x^{*}) = x^{*},\ \varphi^{(l)}(x^{*}) = 0, \ l = 1,2,\cdots, p-1,\ \varphi^{(p)}(x^{*}) \neq 0$，得 $x_{k+1} - x^{*} = \dfrac{1}{p!} \varphi^{(p)}(\xi) \left( x_{k} - x^{*} \right)^{p}$ 
		由 $\varphi^{(p)}$ 的连续性及 $e_{k}$ 的定义，就得 $\lim\limits_{k \to \infty} \dfrac{e_{k+1}}{e_{k}^{p}} = \dfrac{1}{p!} \varphi^{(p)}\left( x^{*} \right) \neq 0$ 
		*必要性* 
		设 $(*)$ 是 $p$ 阶收敛的，则有 $\lim\limits_{k \to \infty} x_{k} = x^{*}$，也就是 $\lim\limits_{k \to \infty} e_{k} = 0$，由 $\varphi$ 的连续性即得 $x^{*} = \varphi\left( x^{*} \right)$ 
		现用反证法证明 $\varphi^{(l)}\left( x^{*} \right) = 0$，$l=1,2,\cdots, p-1$，$\varphi^{(p)}\left( x^{*} \right) \neq 0$ 
		若不成立，则必有最小正整数 $p_{0}$，使 $\varphi^{(l)}\left( x^{*} \right) = 0,\ l=1,2,\cdots, p_{0}-1,\ \varphi^{(p_{0})}\left( x^{*} \right) \neq 0$，其中 $p_{0} \neq p$ 
		不妨先考虑 $p_{0} \le p-1$ 的情况，由已证明的充分条件知，迭代式 $(*)$ 是 $p_{0}$ 阶收敛的，即有 $\lim\limits_{k \to \infty} \dfrac{e_{k+1}}{e_{k}^{p_{0}}} = \dfrac{1}{p_{0}!} \varphi^{(p_{0})}(x^{*}),\ p_{0} \le p-1$ 
		显然 $\dfrac{e_{k+1}}{e_{k}^{p}} = \dfrac{e_{k+1}}{e_{k}^{p_{0}}} \cdot \dfrac{1}{e_{k}^{p-p_{0}}}$ 极限不存在，与 $\{x_{k}\}$ 是 $p$ 阶收敛的假设矛盾。
		对于 $p_{0} \ge p+1$ 的情况也同样可引出矛盾
		因此必有 $p_{0}=p$ 
		综上证毕！
- *直观展示*：一阶和二阶方法迭代步数的差别
	设有两个迭代序列 $\{x_{k}\}$ 和 $\{\widetilde{x}_{k}\}$，且 $\{x_{k}\}$ 为线性收敛的，$\{\widetilde{x}_{k}\}$ 为平方收敛的，且有 $\lim\limits_{k \to \infty} \dfrac{|e_{k+1}|}{|e_{k}|} = c,\ 0 < c < 1$，$\lim\limits_{k \to \infty} \dfrac{|\widetilde{e}_{k+1}|}{|\widetilde{e}_{k}|^{2}} = \widetilde{c}, \ \widetilde{c} > 0,\ |\widetilde{c} \cdot e_{0}| < 1$ 
	则当 $k$ 充分大时，有
	$$
	\begin{aligned}
	&\left| e_{k+1} \right| \approx c \cdot \left| e_{k} \right| \approx c^{2} \left| e_{k-1} \right| \approx \cdots \approx c^{k+1} \left| e_{0} \right| \\
	&\left| \widetilde{e}_{k+1} \right| \approx \widetilde{c} \cdot \left| \widetilde{e}_{k} \right|^{2} \approx \widetilde{c} \cdot \widetilde{c}^{2} \left| \widetilde{e}_{k-1} \right|^{4} \approx \cdots \approx \widetilde{c}^{\left( 2^{k+1} - 1 \right)} \left| \widetilde{e}_{0} \right|^{2^{k+1}} = \left( \widetilde{c} \cdot \left| \widetilde{e}_{0} \right| \right)^{2^{k+1} - 1} \left| \widetilde{e}_{0} \right|
	\end{aligned}
	$$
	若 $\left| e_{0} \right| = \left| \widetilde{e}_{0} \right| = 1$，$c = \widetilde{c} = 0.75$，欲使误差小于 $10^{-8}$ 
	则对于线性收敛的 $\{ x_{k} \}$，由 $(0.75)^{k+1} \leqslant 10^{-8}$，可得 $k+1 \geqslant \dfrac{-8}{\lg 0.75} \approx 64$，因此大约需要 63 次迭代
	而对于的 $\{ \widetilde{x}_{k} \}$，由 $(0.75)^{2^{k+1} - 1} \leqslant 10^{-8}$，可得 $2^{k+1} \geqslant \dfrac{-8}{\lg 0.75} + 1 \approx 65,\ k \geqslant 5.02$，大约需要 6 次迭代
	可见平方收敛序列的收敛速度要快得多。
- *注*：本节只是就求方程 $f(x)=0$ 的实根来讨论，但类似的结果完全可以推广到求方程 $f(x)=0$ 的复数根。也就是说，不动点迭代法 $(*)$ 可以用于求方程 $f(x)=0$ 的复数根，这时 $x_{0}$ 是复平面上有根区域内的一点，$\{ x_{k} \}$ 是复数序列。
- *讨论 $|x_{k} - x^{*}| \leqslant \dfrac{1}{1 - L} |x_{k+1} - x_{k}|\ (1)$、$|x_{k} - x^{*}| \leqslant \dfrac{L^{k}}{1 - L} |x_{1} - x_{0}|\ (2)$、$|x_{k} - x^{*}| \leqslant L |x_{k-1} - x^{*}|\ (3)$ 的用途*
	- 由 $(2)$ 或 $(3)$ 看出，数 $L$ 越小，那么迭代序列 $\{x_{k}\}$ 收敛越快
	- 对于给定的允许误差 $\varepsilon(<1)$，当相邻两次迭代值之差满足 $\left|x_{k+1} - x_{k}\right| \leqslant \varepsilon$ 时，按 $(1)$，近似解 $x_{k}$ 与准确解 $x^{*}$ 的误差限为 $\dfrac{\varepsilon}{1 - L}$，即 $\left|x^{*} - x_{k}\right| \leqslant \dfrac{\varepsilon}{1 - L}$。因此当计算机算题时，由于精确解是未知的，可以借助于 $\left|x_{k+1} - x_{k}\right| \leqslant \varepsilon$ 来控制迭代结果的精度。
	- 类似地，$(2)$ 或 $(3)$ 可以用来粗略估算为使近似解达到一定精度 $\varepsilon$ 所需要的迭代次数。事实上，对不等式 $\left|x^{*} - x_{k}\right| \leqslant L^{k} \left|x^{*} - x_{0}\right| \leqslant L^{k} \delta \leqslant \varepsilon\ (\text{假如 } \left|x^{*} - x_{0}\right| \leqslant \delta)$ 与 $\left|x^{*} - x_{k}\right| \leqslant \dfrac{L^{k}}{1 - L} \left|x_{1} - x_{0}\right| \leqslant \varepsilon$，取对数后分别解出 $k \geqslant \dfrac{\ln \varepsilon - \ln \delta}{\ln L}$ 与 $k \geqslant \dfrac{\ln \varepsilon - \ln \dfrac{|x_{1} - x_{0}|}{1 - L}}{\ln L}$。这就是说，所需要的迭代次数可取为满足上述两式之一的最小自然数 $k$ 
## 5-3 Newton 类迭代方法
### 5-3-1 方法及计算公式
- 用迭代法求解方程 $f(x) = 0$，关键在于选择迭代函数 $\varphi(x)$，使相应的迭代过程 $x_{n+1} = \varphi(x_n)$ 收敛于 $f(x) = 0$ 的根 $\alpha$ 
- **Newton 迭代法** 
	选择迭代函数：设 $f(x)$ 于 $\alpha$ 的近旁二次连续可微，在 $\alpha$ 的邻域内取初始值 $x_0$，关于 $x_0$ 作 $f(x)$ 的 Taylor 展开，有 $f(x) = f(x_0) + f'(x_0)(x - x_0) + \dfrac{f''(\xi_0)}{2!}(x - x_0)^2$，其中 $\xi_0$ 在 $x$ 与 $x_0$ 之间
	于是 $0 = f(\alpha) = f(x_0) + f'(x_0)(\alpha - x_0) + \dfrac{f''(\xi_0)}{2!}(\alpha - x_0)^2$，若将上式含有 $(\alpha - x_0)^2$ 项忽略不计并设 $f'(x_0) \ne 0$ 便得到 $\alpha$ 的进一步近似值 $x_1$：$x_1 = x_0 - \dfrac{f(x_0)}{f'(x_0)}$ 
	一般地，得到迭代序列 $\boxed{x_{n+1} = x_n - \dfrac{f(x_n)}{f'(x_n)},\ n = 0, 1, 2, \cdots\quad (*)}$ 
	迭代过程 $(*)$ 称为求解 $f(x) = 0$ 的 **Newton 迭代法** 
- *Newton 的几何意义*、**切线法**：如下图，函数 $f(x)=0$ 的根 $p$ 是曲线 $y=f(x)$ 与 $x$ 轴的交点的横坐标。过点 $M_k(x_k, f(x_k))$ 作曲线的切点 $T_k$，则切线方程为 $y=f(x_k) + f'(x_k)(x-x_k)$，切线 $T_k$ 与 $x$ 轴的交点的横坐标为 $x_{k+1} = x_k - \dfrac{f(x_k)}{f'(x_k)}$，因此 Newton 法又称为**切线法** 
	![[Pasted image 20260222151521.png|300]]
- **算法**：用 Newton 法求方程 $f(x) = 0$ 的一个解。设初始值为 $x_0$；误差容限为 TOL；最大迭代次数 $m$。计算近似解 $p$ 或输出失败信息。
	1. $p_0 := x_0$ 
	2. 对 $i = 1, 2, \cdots, m$ 进行步骤 3 和步骤 4
	3. $p := p_0 - \dfrac{f(p_0)}{f'(p_0)}$ 
	4. 若 $|p - p_0| < \text{TOL}$，则输出 $p$，停机；否则 $p_0 := p$ 
	5. 输出 ("Method failed")，停机。
	- *注*：在步骤 4 中的迭代终止标准也可用 $\dfrac{|p - p_0|}{|p|} < \text{TOL}$ 或者 $\dfrac{|p - p_0|}{|p|} < \text{TOL} \ \text{且} \ |f(p)| < \text{TOL}$ 
- **定理 6**：假设函数 $f(x)$ 有 $m(>2)$ 阶连续导数，$p$ 是方程 $f(x) = 0$ 的单根，则当 $x_0$ 充分接近于 $p$ 时，Newton 法收敛，且至少为二阶收敛。
	- *证明过程* 
		令 $g(x) = x - \dfrac{f(x)}{f'(x)}$ 
		由于假设 $f(x)$ 有 $m(>2)$ 阶连续导数，因此有 $g'(x) = 1 - \dfrac{f'(x)f'(x) - f(x)f''(x)}{[f'(x)]^2} = \dfrac{f(x)f''(x)}{[f'(x)]^2}$ 
		而 $p$ 是 $f(x)$ 的单重零点，即有 $f(p) = 0, f'(p) \ne 0$，从而 $g'(p) = 0$，且存在 $r > 0$，使得对一切 $x \in [p-r, p+r]$，有 $f'(x) \ne 0$ 
		因此，$g'(x), g''(x)$ 在 $[p-r, p+r]$ 上连续。
		由 5-2 **定理 5** 知，当初始值 $x_0$ 充分接近于 $p$ 时，由 Newton 法 $(*)$ 产生的迭代序列 $\{x_k\}$ 收敛于 $p$，且收敛阶数至少为 2
		证毕！
	- 该定理为 Newton 法的局部收敛性定理
	- 该定理表明：当初始值充分接近于方程的根时，Newton 法收敛得较快。
- 在实际应用中，有的实际问题本身可以提供接近于根的初始值，但有的问题却难以确定接近于根的初始值。关于初始值的选取，有下面的定理。
- **定理 7**：设函数 $f(x)$ 在有限区间 $[a, b]$ 上存在二阶导数，且满足条件：
	(1) $f(a)f(b) < 0$ 
	(2) $f'(x) \ne 0, x \in [a, b]$，$f''(x)$ 在 $[a, b]$ 上不变号
	(3) $\left| \dfrac{f(a)}{f'(a)} \right| < b - a,\ \left| \dfrac{f(b)}{f'(b)} \right| < b - a$ 
	则 Newton 法 $(*)$ 对任意的初始值 $x_0 \in [a, b]$ 都收敛于方程 $f(x) = 0$ 的唯一解 $p$，且收敛阶数为 2
- *定理 7 的直观理解*：在**定理 7** 中，条件 (1) 保证方程 $f(x) = 0$ 在 $(a, b)$ 内至少有一个根。条件 (2) 表明函数 $f(x)$ 不是严格单调增大 ($f' > 0$) 就是严格单调减小 ($f' < 0$)，因而 $f(x) = 0$ 在 $(a, b)$ 内有唯一根；同时，$f(x)$ 的图形不是凹向上 ($f'' > 0$) 就是凹向下 ($f'' < 0$)。条件 (3) 保证，当 $x \in [a, b]$ 时，Newton 序列 $\{x_k\}$ 在 $(a, b)$ 中。例如，从下图看到，取 $x_0 = a$ 或 $x_0 = b$ 时，Newton 序列 $x_1, x_2, \cdots, x_k, \cdots$ 为单调增大，且有上界，因而收敛。

### 5-3-2 Newton 法应用举例
- *计算开平方值*：对于给定正数 $C$，应用 Newton 法解二次方程 $x^2 - C = 0$，可导出求开平方值 $\sqrt{C}$ 的计算程序 $x_{k+1} = \dfrac{1}{2} \left( x_k + \dfrac{C}{x_k} \right)$ 
- **性质**：迭代公式 $x_{k+1} = \dfrac{1}{2} \left( x_k + \dfrac{C}{x_k} \right)$ 对于任意初始值 $x_0 > 0$ 都是收敛的。
	- *证明过程* 
		对 $x_{k+1} = \dfrac{1}{2} \left( x_k + \dfrac{C}{x_k} \right)$ 施行配方，易知 $x_{k+1} - \sqrt{C} = \dfrac{1}{2x_k} (x_k - \sqrt{C})^2$ 和 $x_{k+1} + \sqrt{C} = \dfrac{1}{2x_k} (x_k + \sqrt{C})^2$ 
		以上两式相除得到 $\dfrac{x_{k+1} - \sqrt{C}}{x_{k+1} + \sqrt{C}} = \left( \dfrac{x_k - \sqrt{C}}{x_k + \sqrt{C}} \right)^2$ 
		据此反复递推有 $\dfrac{x_k - \sqrt{C}}{x_k + \sqrt{C}} = \left( \dfrac{x_0 - \sqrt{C}}{x_0 + \sqrt{C}} \right)^{2^k}$ 
		记 $q = \dfrac{x_0 - \sqrt{C}}{x_0 + \sqrt{C}}$，整理上式，得 $x_k - \sqrt{C} = 2\sqrt{C} \dfrac{q^{2^k}}{1 - q^{2^k}}$ 
		对任意 $x_0 > 0$，总有 $|q| < 1$，故由上式推知，当 $k \to \infty$ 时 $x_k \to \sqrt{C}$，即迭代过程恒收敛
		证毕！
### 5-3-3 修改的 Newton 迭代法
- **简化的 Newton 方法**、**修改的 Newton 迭代法**：应用 Newton 迭代公式 $(*)$ 每一步需要计算 $f'(x_n)$。如果所遇到的问题 $f'(x)$ 很难计算，工作量将是很大的。为了避免计算导数值，可将 $f'(x_n)$ 取为某个定点处的值，如 $f'(x_0)$。这时迭代法为 $x_{n+1} = x_n - \dfrac{f(x_n)}{f'(x_0)},\ n = 0, 1, 2, \cdots$，它称为**简化的 Newton 方法**或**修改的 Newton 迭代法**。迭代函数为 $\varphi(x) = x - \dfrac{f(x)}{f'(x_0)}$ 
	- *几何意义*：用过点 $(x_n, f(x_n))$ 且斜率为 $f'(x_0)$ 的直线 $y - f(x_n) = f'(x_0)(x - x_n)$ 来代替曲线，取该直线与 $x$ 轴交点的横坐标 $x_{n+1}$ 作为 $\alpha$ 的新的近似值（如下图）

	- 可以证明，在一定条件下简化的 Newton 迭代法是局部收敛的
### 5-3-4 $m$ 重根的处理
- 设 $\alpha$ 为 $f(x)$ 的 $m$ 重根 ($m \ge 2$)。这时若利用 Newton 迭代法计算 $f(x) = 0$ 的根 $\alpha$ 的近似值时，迭代过程收敛速度就要减慢，因而为了达到较高的收敛速度，Newton 迭代法 $(*)$ 必须作适当的修改
- *结论 1*：Newton 迭代法只是线性收敛的
	- *推导过程* 
		由于 $\alpha$ 为 $f(x) = 0$ 的 $m$ 重根，此时有 $f(\alpha) = f'(\alpha) = \cdots = f^{(m-1)}(\alpha) = 0,\ f^{(m)}(\alpha) \ne 0$ 
		考察 $(*)$ 的迭代函数 $\varphi(x) = x - f(x)/f'(x)$，显然 $\varphi(\alpha) = \alpha$ 
		为了计算 $\varphi'(\alpha)$，令 $x = \alpha + h$，则由 Taylor 公式有
		$$
		\begin{aligned}
		\varphi(\alpha + h) &= \alpha + h - \frac{f(\alpha + h)}{f'(\alpha + h)} \\
		&= \alpha + h - \frac{f^{(m)}(\alpha)h^m/m! + O(h^{m+1})}{f^{(m)}(\alpha)h^{m-1}/(m-1)! + O(h^m)} \\
		&= \alpha + h - \frac{1}{m}h + O(h^2) \\
		&= \alpha + \left( 1 - \frac{1}{m} \right)h + O(h^2)
		\end{aligned}
		$$
		因此
		$$
		\begin{aligned}
		\varphi'(\alpha) &= \lim_{h \to 0} \frac{\varphi(\alpha + h) - \varphi(\alpha)}{h} \\
		&= \lim_{h \to 0} \frac{\alpha + (1 - 1/m)h + O(h^2) - \alpha}{h} \\
		&= 1 - \frac{1}{m}
		\end{aligned}
		$$
		即若 $m \ge 2$，则 $\varphi'(\alpha) = 1 - 1/m > 0$，且 $|\varphi'(\alpha)| < 1$，所以 Newton 方法只是线性收敛的。
- *结论 2*：若取 $\varphi(x) = x - m f(x)/f'(x)$，从以上分析可得 $\varphi'(\alpha) = 0$，由此得到平方收敛的修改的 Newton 方法：$x_{n+1} = x_n - m \dfrac{f(x_n)}{f'(x_n)}$ 
	- 该方法要预先知道 $\alpha$ 的重数。但在非单根的情况下，一般不知道重数 $m$ 
- *结论 3*：可采用如下修改 Newton 方法计算 $f(x) = 0$ 的重根。由于 $\alpha$ 为 $f(x)$ 的 $m$ 重根，这时 $f(x) = (x - \alpha)^m g(x)$。假设 $g(x)$ 充分可微，且 $g(\alpha) \ne 0$。记 $u(x) = f(x)/f'(x)$，若 $\alpha$ 为 $f(x)$ 的 $m$ 重根，则 $u(x) = \dfrac{(x - \alpha)g(x)}{mg(x) + (x - \alpha)g'(x)}$，故 $\alpha$ 为 $u(x)$ 的单重零点。这时 Newton 方法修改为 $x_{n+1} = x_n - \dfrac{u(x_n)}{u'(x_n)} = x_n - \dfrac{f(x_n)f'(x_n)}{[f'(x_n)]^2 - f(x_n)f''(x_n)}$ 
	- 如果迭代函数 $g(x) = x - \dfrac{f(x)f'(x)}{[f(x)]^2 - f(x)f''(x)}$ 具有所需的连续性条件，那么无论根重数为多少，这个方法至少是二阶收敛的。
	- 理论上，这个方法的缺点是增加二阶导数 $f''(x)$ 的计算以及迭代过程中的计算更复杂。但是，实际上重根的出现将产生严重的舍入误差问题。
### 5-3-5 Newton 下山法
- *下山法的作用*：Newton 方法的单调收敛定理告诉我们，为了保证迭代序列 $\{x_n\}$ 收敛，在假设条件下可利用条件 $x_0 \in [a, b]$ 与 $f(x_0)f''(x_0) \ge 0$ 来选取初始值 $x_0$，但对某些问题，这些条件，尤其是区间 $[a, b]$ 难以检验，这时可应用下山法来扩大初始值的选取范围。
- **下山因子**：下山法实际上是 Newton 方法的一种修正，即在迭代格式 $(*)$ 中引入一个因子 $\lambda$，将迭代格式变为 $\boxed{x_{n+1} = x_n - \lambda \dfrac{f(x_n)}{f'(x_n)}\quad (**)}$，其中 $\lambda$ 称为**下山因子** 
	- 选择下山因子 $\lambda$ 的原则是使得 $|f(x_{n+1})| < |f(x_n)|,\ n = 0, 1, 2, \cdots$ 成立，即 $f(x)$ 的绝对值变小
- 在整个计算过程中，下山因子 $\lambda$ 是变化的，一般可以按如下办法进行：
	- 首先取 $\lambda = 1$，用式 $(**)$，由初始值 $x_0$ 算出 $x_1$ 
	- 如果 $|f(x_1)| < |f(x_0)|$，则可以将 $\lambda$ 扩大一倍，应用 $x_1$ 按照式 $(**)$（取 $n=1$）计算 $x_2$；如果 $|f(x_1)| \ge |f(x_0)|$，逐次地将 $\lambda$ 减半，直到条件 $|f(x_1)| < |f(x_0)|$ 满足为止，并利用最后算出的 $x_1$ 进行下一步迭代。
	- 照此进行下去。这种做法保证每次迭代都使 $|f(x_n)|$ 的值严格下降，同时在下降的前提下尽可能增大下山因子 $\lambda$ 
	- 这种做法扩大了初始值的选取范围，并使得迭代序列有比较快的收敛速度。
## 5-4 非线性方程组
### 5-4-1 不动点迭代法及例题
- *符号假设*：这里考虑方程组 $\begin{cases} f_1(x_1, x_2, \cdots, x_m) = 0 \\ f_2(x_1, x_2, \cdots, x_m) = 0 \\ \cdots \cdots \\ f_m(x_1, x_2, \cdots, x_m) = 0 \end{cases}\quad(*)$，其中 $f_1, f_2, \cdots, f_m$ 为 $x_1, x_2, \cdots, x_m$ 的连续函数。
	- 用向量的记号，记 $x = (x_1, x_2, \cdots, x_m)^{\mathrm{T}},\ x \in \mathbb{R}^m$，$(*)$ 中的每个方程可写成 $f_i(x) = 0,\ i = 1, 2, \cdots, m$ 
	- 再引入向量函数 $F$：$F(x) = (f_1(x), f_2(x), \cdots, f_m(x))^{\mathrm{T}}$，$(*)$ 就可写成 $F(x) = 0$ 
- *符号假设*：设数量函数 $f_i$ 和向量函数 $F$ 定义在 $D \subset \mathbb{R}^m$，记向量函数 $F(x) = (f_1(x), f_2(x), \cdots, f_m(x))^{\mathrm{T}}$；规定 $x_0 \in D,\ \lim\limits_{x \to x_0} f_i(x) = A_i$ 是指对任意的 $\varepsilon > 0$，存在实数 $\delta > 0$，使对任意满足 $0 < \|x - x_0\| < \delta$ 的 $x \in D$，有 $|f_i(x) - A_i| < \varepsilon$（这里 $\|\cdot\|$ 可取为任一种范数）；规定 $\lim\limits_{x \to x_0} F(x) = A = (A_1, A_2, \cdots, A_m)^{\mathrm{T}}$ 是指 $\lim\limits_{x \to x_0} f_i(x) = A_i,\ i = 1, 2, \cdots, m$ 成立
	- **连续**：若 $\lim\limits_{x \to x_0} f_i(x) = f_i(x_0)$，则称 $f_i$ 在 $x_0 \in D$ **连续** 
	- **连续**：若 $f_i$ 在 $D$ 上每点连续，称 $f_i$ 在 $D$ 上**连续** 
	- **连续**：若 $\lim\limits_{x \to x_0} F(x) = F(x_0)$，称 $F$ 在 $x_0$ **连续** 
	- **连续**：若 $F$ 在 $D$ 上每点连续，称 $F$ 在 $D$ 上**连续** 
- *问题*：现在设 $x^*$ 满足 $F(x^*) = 0$，下面讨论求解 $x^*$ 的方法。
- *方法*：设有与 $F(x)=0$ 等价的方程 $x = \Phi(x)$ 满足 $x^* = \Phi(x^*)$，$x^*$ 就是 $\Phi$ 的不动点。对应 $x = \Phi(x)$ 的不动点迭代法就是 $x^{n+1} = \Phi(x^n)$ 
- **压缩映射原理**(**定理 8**)：在闭域 $D \subset \mathbb{R}^m$ 上，设 $\Phi$ 满足：
	(1) 存在常数 $0 < K < 1$，使对 $D$ 上所有 $x$ 和 $y$ 都有 $\|\Phi(x) - \Phi(y)\| \leqslant K \|x - y\|$ 
	(2) 对所有的 $x \in D$，都有 $\Phi(x) \in D$ 
	则 $\Phi$ 存在唯一的不动点 $x^* \in D$，而且对任意的 $x^0 \in D$，$x = \Phi(x)$ 产生的向量序列 $\{x^n\}$ 收敛到 $x^*$，并有 $\|x^n - x^*\| \leqslant \dfrac{K^n}{1-K} \|x^1 - x^0\|$ 
	- *证明过程* 
		*第 1 步*：构造 $x^*$ 
		因 $x^0 \in D$ 及 $\Phi(x) \in D$，显然对 $n = 0, 1, \cdots$，都有 $x^n \in D$ 
		而且由 $\|\Phi(x) - \Phi(y)\| \leqslant K \|x - y\|$，有 $\|x^n - x^{n-1}\| = \|\Phi(x^{n-1}) - \Phi(x^{n-2})\| \leqslant K \|x^{n-1} - x^{n-2}\|$ 
		因此对任意的 $l > n$，有
		$$
		\begin{aligned}
		\|x^l - x^n\| &\leqslant \|x^l - x^{l-1}\| + \|x^{l-1} - x^{l-2}\| + \cdots + \|x^{n+1} - x^n\| \\
		&\leqslant (K^{l-n} + \cdots + K^2 + K) \|x^n - x^{n-1}\| \\
		&\leqslant \frac{K^n}{1-K} \|x^1 - x^0\|
		\end{aligned}
		$$
		所以当 $n$ 充分大时，$\|x^l - x^n\|$ 可任意小，根据 **Cauchy 定理**，$\{x^n\}$ 必收敛，$\lim\limits_{n \to \infty} x^n = x^*$，且 $x^* \in D$ 
		*第 2 步*：证明 $x^*$ 就是 $\Phi$ 的不动点
		由 $\|\Phi(x) - \Phi(y)\| \leqslant K \|x - y\|$ 有
		$$
		\begin{aligned}
		\|\Phi(x^*) - x^*\| &\leqslant \|\Phi(x^*) - \Phi(x^n)\| + \|\Phi(x^n) - x^*\| \\
		&\leqslant K \|x^* - x^n\| + \|x^{n+1} - x^*\|
		\end{aligned}
		$$
		对任意的 $n \geqslant 0$ 成立
		因 $\|x^* - x^n\| \to 0$，所以可得 $\|\Phi(x^*) - x^*\| = 0$，即 $x^* = \Phi(x^*)$，$x^*$ 是 $\Phi$ 的不动点。
		*第 3 步*：证明 $x^*$ 的唯一性
		若 $\Phi$ 另有一个不动点 $y^*$，则 $\|x^* - y^*\| = \|\Phi(x^*) - \Phi(y^*)\| \leqslant K \|x^* - y^*\|$ 
		因 $0 < K < 1$，所以 $\|x^* - y^*\| = 0$，故 $x^* = y^*$，不动点是唯一的
		*第 4 步*：证明 $\|x^n - x^*\| \leqslant \dfrac{K^n}{1-K} \|x^1 - x^0\|$ 
		由 $\|x^l - x^n\| \leqslant \dfrac{K^n}{1-K} \|x^1 - x^0\|$，因范数的连续性，令 $l \to \infty$ 就得到 $\|x^n - x^*\| \leqslant \dfrac{K^n}{1-K} \|x^1 - x^0\|$ 
		综上证毕！
	- 该定理说明了：关于 $\Phi$ 的不动点的存在性和 $x^{n+1} = \Phi(x^n)$ 迭代的收敛性
	- 该定理中 $\Phi$ 的第一个条件称为 $\Phi$ 的**压缩性质**，所以该定理常称压缩映射原理。
- *符号假设*：设 $\Phi(x) = [\varphi_1(x_1, x_2, \cdots, x_m), \cdots, \varphi_m(x_1, x_2, \cdots, x_m)]^{\mathrm{T}}$，且 $\varphi_1, \cdots, \varphi_m$ 均存在一阶连续偏导数。$\Phi$ 的 Jacobi 矩阵记为 $\Phi'(x) = \begin{bmatrix} \dfrac{\partial \varphi_1}{\partial x_1} & \cdots & \dfrac{\partial \varphi_1}{\partial x_m} \\ \vdots & & \vdots \\ \dfrac{\partial \varphi_m}{\partial x_1} & \cdots & \dfrac{\partial \varphi_m}{\partial x_m} \end{bmatrix}$ 
- *结论*：可以证明，若 $\Phi$ 有不动点 $x^*$，且 $\Phi'$ 连续，$\rho(\Phi'(x^*)) < 1$，则 $x^{n+1} = \Phi(x^n)$ 产生的序列 $\{x^n\}$ 收敛到 $x^*$，这里 $\rho(\Phi'(x^*))$ 是 $\Phi'(x^*)$ 的谱半径。
	- 当存在常数 $0 < K < 1$，使 $\left| \dfrac{\partial \varphi_i(x)}{\partial x_j} \right| \leqslant \dfrac{K}{m},\ x \in D, i, j = 1, \cdots, m$ 成立时，可使 $\Phi'(x^*)$ 的谱半径小于 $1$

### 5-4-2 Newton 迭代法及例题
- *符号假设*：设 $f_j(x_1, x_2, \cdots, x_n), j=1, 2, \cdots, n$ 是 $n$ 个定义在 $n$ 维空间区域 $D$ 上的 $n$ 元二次连续可微函数，并且它的值域也包含在 $D$ 内。
- *问题*：求 $f_j(x_1, x_2, \cdots, x_n) = 0,\ j = 1, 2, \cdots, n$ 的解 $(\zeta_1, \zeta_2, \cdots, \zeta_n)$ 
- *结论 1* (**标准 Newton 法**)：解决上述问题可使用 Newton 法的迭代公式 $\boxed{x^{k+1} = x^k - J^{-1}(x^k) f(x^k),\ k = 0, 1, \cdots\quad (1)}$，其中 $J$ 为函数 $f_1, f_2, \cdots, f_n$ 对未知数的 Jacobi 矩阵，$x$ 为 $n$ 维向量
	- *推导过程* 
		和单个一元函数方程的 Newton 法一样，把 $f_j$ 在点 $(\zeta_1, \zeta_2, \cdots, \zeta_n)$ 附近一点 $(x_1^0, x_2^0, \cdots, x_n^0)$ 展开：$f_j(x_1, x_2, \cdots, x_n) = f_j(x_1^0, x_2^0, \cdots, x_n^0) + \sum\limits_{k=1}^{n} (x_k - x_k^0) \dfrac{\partial}{\partial x_k} f_j(x_1^0, x_2^0, \cdots, x_n^0) + R_j\quad (*)$，其中 $R_j = \dfrac{1}{2} \sum\limits_{l,k=1}^{n} (x_l - x_l^0)(x_k - x_k^0) \dfrac{\partial^2}{\partial x_l \partial x_k} f_j(\xi_1, \xi_2, \cdots, \xi_n),\ j = 1, 2, \cdots, n$，且 $\xi_j$ 在 $x_j$ 与 $x_j^0$ 之间，$j = 1, 2, \cdots, n$ 
		忽略 $(*)$ 中的余项 $R_j$，得到一个线性方程组 $f_j(x_1^0, x_2^0, \cdots, x_n^0) + \sum\limits_{k=1}^{n} (x_k - x_k^0) \dfrac{\partial}{\partial x_k} f_j(x_1^0, x_2^0, \cdots, x_n^0) = 0,\ j = 1, 2, \cdots, n\quad (**)$ 
		这组线性方程的解 $x_1^1, x_2^1, \cdots, x_n^1$，自然不能就是 $\zeta_1, \zeta_2, \cdots, \zeta_n$，而只能是它的近似值。
		$(**)$ 中未知数 $x_1, x_2, \cdots, x_n$ 的系数矩阵就是函数 $f_1, f_2, \cdots, f_n$ 对未知数的 Jacobi 矩阵
		$$
		J(x) = J(x_1, x_2, \cdots, x_n) = \begin{bmatrix}
		\dfrac{\partial f_1}{\partial x_1} & \dfrac{\partial f_1}{\partial x_2} & \cdots & \dfrac{\partial f_1}{\partial x_n} \\
		\dfrac{\partial f_2}{\partial x_1} & \dfrac{\partial f_2}{\partial x_2} & \cdots & \dfrac{\partial f_2}{\partial x_n} \\
		\vdots & \vdots & & \vdots \\
		\dfrac{\partial f_n}{\partial x_1} & \dfrac{\partial f_n}{\partial x_2} & \cdots & \dfrac{\partial f_n}{\partial x_n}
		\end{bmatrix}
		$$
		令 $f = (f_1, f_2, \cdots, f_n)^{\mathrm{T}}$，$x = (x_1, x_2, \cdots, x_n)^{\mathrm{T}}$，$x^0 = (x_1^0, x_2^0, \cdots, x_n^0)^{\mathrm{T}}$，则 $(**)$ 可写成 $f(x^0) + J(x^0)(x - x^0) = 0\quad (***)$ 
		而余项 $R = (R_1, R_2, \cdots, R_n)^{\mathrm{T}}$ 的分量 $R_j$ 是二次型 $R_j = \dfrac{1}{2} (x - x^0)^{\mathrm{T}} H_j(\xi) (x - x^0)$，其中 $H_j = \left[ \dfrac{\partial^2 f_i}{\partial x_l \partial x_k} \right],\ l, k = 1, 2, \cdots, n$ 
		$(***)$ 的解为 $x^1 = x^0 - J^{-1}(x^0) f(x^0)$ 
		重复这一步骤，则得到 Newton 法的迭代公式 $x^{k+1} = x^k - J^{-1}(x^k) f(x^k),\ k = 0, 1, \cdots$ 
	- Newton 法的重要性在于对 $f$ 加某些比较自然的条件后，若 $x^k$ 充分接近 $\zeta$，则可得到平方收敛的估计 $\left\| x^{k+1} - \zeta \right\| \leqslant C \left\| x^k - \zeta \right\|^2$ 
	- *改进*：Newton 法的平方收敛性较为吸引人，但每作一次迭代，都要求矩阵 $J(x^k)$ 的逆矩阵，工作量很大。若写成 $J(x^k)(x^{k+1} - x^k) = -f(x^k)$，则每次迭代解一次线性方程组，工作量可减小一些。
	- *注*：不论怎样，求矩阵 $J$ 时，先要求出它的 $n^2$ 个元素 $\dfrac{\partial f_j}{\partial x_l}$，通常以差商 $\dfrac{\partial f_j(x^k)}{\partial x_l} \approx \{ f_j(x_1^k, \cdots, x_{l-1}^k, x_l^k + h_{jl}^k, x_{l+1}^k, \cdots, x_n^k) - f_j(x^k) \} / h_{jl}^k$ 或以 $\begin{aligned} \dfrac{\partial f_j(x^k)}{\partial x_l} \approx &\{ f_j(x_1^k + h_{j1}^k, \cdots, x_{l-1}^k + h_{j,l-1}^k, x_l^k + h_{jl}^k, x_{l+1}^k, \cdots, x_n^k) \\ &- f_j(x_1^k + h_{j1}^k, \cdots, x_{l-1}^k + h_{j,l-1}^k, x_l^k, \cdots, x_n^k) \} / h_{jl}^k \end{aligned}$ 来代替，这里的 $h_{jl}^k$ 都是适当的参数，还可以取 $h_{jl}^k$ 为与 $j, l$ 无关的常数
- *结论 2* (**离散 Newton 法**)：记所用 $\dfrac{\partial f_j}{\partial x_l}$ 的近似为 $\Delta_{jl}(x, h)$（并记矩阵 $\Delta_{jl}(x, h) \equiv J(x, h)$），则有“离散的 Newton 法”$\boxed{x^{k+1} = x^k - J^{-1}(x^k, h^k) f(x^k),\ k = 0, 1, 2, \cdots\quad (2)}$ 
	- 如果矩阵 $(h_{jl}^k)$ 的元素为常数 $h$，则迭代法 $(2)$ 只有线性收敛；所以要达到平方收敛，必须取 $h_{jl}^k$ 使 $\lim\limits_{k \to \infty} h_{jl}^k = 0$ 
- *注意*：对任何一种迭代方法，都希望它的剩余量的范数是递减的，即 $\| f(x^{k+1}) \| \leqslant \| f(x^k) \|,\ k = 0, 1, 2, \cdots$ 
	- Newton 法并不一定如此，即使是单个方程，$\| f(x^{k+1}) \| \leqslant \| f(x^k) \|$ 也不一定成立
- *结论 3* (**阻尼 Newton 法**)：通常可加一个修正因子 $\omega_k > 0$，把 $(1)$ 改成 $\boxed{x^{k+1} = x^k - \omega_k J^{-1}(x^k) f(x^k),\ k = 0, 1, 2, \cdots\quad (3)}$，并选 $\omega_k$ 使 $\| f(x^{k+1}) \| \leqslant \| f(x^k) \|$ 成立。此时 $(3)$ 亦称**阻尼 Newton 法** 
- *结论 4* (**处理奇异 Jacobi 矩阵的修正方法**)：当 $J(x^k)$ 或 $J(x^k, h^k)$ 是奇异矩阵时，$(1)$ 可改成 $\boxed{x^{k+1} = x^k - [J(x^k) + \mu_k I]^{-1} f(x^k),\ k = 0, 1, 2, \cdots\quad (4)}$，其中 $I$ 是单位矩阵，取 $\mu_k$ 使得 $J(x^k) + \mu_k I$ 非奇异并保证剩余量范数递减。
- *结论 5* (**简化 Newton 法**)：还有一种简化 Newton 法，即 $J(x)$ 恒取成 $J(x^0)$，此时 $\boxed{x^{k+1} = x^k - J^{-1}(x^0) f(x^k),\ k = 0, 1, 2, \cdots\quad (5)}$ 
	- 比这更接近 Newton 法而又节省工作量的是求一次 $J^{-1}(x^k)$ 后，连续作几步迭代再更换新的 $J^{-1}(x^k)$。用式子表示，可写成 $x^{k+1} = x^k - J^{-1}(x^{p(k)}) f(x^k),\ k = 0, 1, 2, \cdots$，其中 $p(k) < k$ 是正整数，且当 $k \to \infty$ 时 $p(k) \to \infty$
