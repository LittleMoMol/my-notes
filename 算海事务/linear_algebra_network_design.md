# 高等代数知识网络设计 v1.0
- **设计理念**：以“研究对象”和“研究工具”为双重主线，构建从具体计算到抽象结构的层次化知识网络。顶层模块应具有逻辑上的包含、衍生或对偶关系，为下一层更细颗粒度 (如特征值、二次型等) 的知识点预留位置。
## 一、顶层核心模块设计
经过对高等代数课程体系的回顾，在本设计选定的宏观颗粒度下，我们确立以下五个核心知识模块，作为整个知识网络的“地基”：
1. **数系与多项式** (**number_systems_and_polynomials**)
    - **定位**：代数运算的基石。为后续所有模块提供最基本的运算规则 (域、交换环) 和基础代数对象。
    - **包含关系**：本模块是后续所有模块的“公理”或“系数”来源。例如，线性方程组系数来自数域，矩阵元素来自数域，线性变换的矩阵表示依赖于基域。
    - **未来细化点**：整除理论、因式分解、最大公因式、多项式根、复数域与实数域的特性、艾森斯坦判别法等。这些是“数系与多项式”模块下的子知识点。
2. **矩阵与行列式** (**matrices_and_determinants**)
    - **定位**：代数的“计算核心”与“量化工具”。矩阵是描述有限维线性现象的通用计算语言，行列式是矩阵的一个关键数值不变量。
    - **核心关系**：
        - 描述线性方程组：增广矩阵、系数矩阵。
        - 表示线性变换：给定基下，线性变换与矩阵一一对应。
        - 执行向量坐标变换：过渡矩阵。
    - **未来细化点**：矩阵的运算（加、乘、逆、转置、分块）、各类特殊矩阵（对角、三角、对称、正交）、行列式的定义与性质、拉普拉斯展开、克莱姆法则、初等矩阵。$\lambda$-矩阵、若尔当标准型本质上是矩阵模块的深化，可置于其下。
3. **向量与向量空间** (**vectors_and_vector_spaces**)
    - **定位**：代数的“几何对象”与“舞台”。向量是构成空间的基本元素，向量空间（线性空间）定义了研究这些元素的舞台和规则（加法和数乘封闭性）。
    - **核心关系**：
        - 构成矩阵：一组向量可排列为矩阵的列或行。
        - 生成了空间：向量的线性组合张成子空间。
        - 是线性变换的作用对象：线性变换将一个向量映射为另一个向量。
    - **未来细化点**：线性相关/无关、向量的线性表示、向量空间的定义与例子、子空间、基、维数、坐标。这些是“向量与向量空间”模块下的子知识点
4. **线性映射与线性变换** (**linear_mappings_and_linear_transformations**)
    - **定位**：代数的“动态过程”与“结构映射”。研究向量空间之间保持线性结构的映射。这是连接具体计算（矩阵）和抽象空间（向量空间）的桥梁。
    - **核心关系**：
        - 矩阵是其表示：在选定基下，线性变换对应唯一矩阵。
        - 其核与像是子空间：刻画了映射的结构。
        - 特征问题：寻找变换下方向不变的向量（特征向量）。
    - **未来细化点**：线性映射的定义与性质、值域与核、秩-零化度定理、同构定理、特征值与特征向量、对角化条件。这些是“线性变换”模块的子知识点。
5. **内积与欧几里得空间** (**inner_products_and_euclidean_spaces**)
    - **定位**：赋予“几何度量”的代数结构。在向量空间的基础上增加“长度”和“角度”的概念，将几何直观代数化。
    - **核心关系**：
        - 是向量空间的增强：任何欧氏空间首先是一个向量空间。
        - 诱导出标准正交基：使得度量和计算大大简化。
        - 与特殊矩阵关联：正交变换对应正交矩阵，对称变换对应对称矩阵。
    - **未来细化点**：内积的定义与性质、长度与夹角、柯西-施瓦茨不等式、标准正交基、施密特正交化、正交补、正交变换与对称变换。二次型（及其标准化、正定性）可以视作对称矩阵在欧氏空间背景下的一个核心应用，可归于此模块或作为矩阵模块的延伸。
## 二、对 `knowledge_network` 编写的具体指导建议
- `knowledge_network` 应该具有本 design 提出的五个核心知识点，并重点刻画知识之间的联系
- 五个核心知识点：
	- **数系与多项式** (**number_systems_and_polynomials**)
	- **矩阵与行列式** (**matrices_and_determinants**)
	- **向量与向量空间** (**vectors_and_vector_spaces**)
	- **线性映射与线性变换** (**linear_mappings_and_linear_transformations**)
	- **内积与欧几里得空间** (**inner_products_and_euclidean_spaces**)
- 颗粒度控制：暂时无需展开“未来细化点”内部更细节的内容。`knowledge_network` 任务是建立一级节点 (上述 5 个) 的清晰拓扑
