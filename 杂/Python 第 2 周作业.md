# 第 2 题
- *问题*：Python中一切皆为对象，“对象”的定义是什么？核心特性是什么？有什么优势？
	- *解答* 
		在 Python 中，**对象**是数据和操作的封装体。所有变量、函数、类、模块、甚至类型本身都是对象
		**核心特性** 
		- **一切皆对象**：数字、字符串、函数、类、模块等都是对象，可被赋值、传递、作为参数或返回值。
		- **可调用性**：函数和方法都是可调用的对象；类也是可调用的对象
		- **可继承、可扩展**：支持面向对象编程的继承和多态
		- **动态绑定**：属性和方法可以在运行时动态添加或修改
		
		**优势**
		- **统一的数据模型**：简化编程模型，减少类型转换和边界检查。
		- **高度灵活**：函数可作为参数、返回值，支持高阶函数、装饰器等高级特性。
		- **易于维护和复用**：面向对象的封装和继承机制便于代码组织和重用。
		- **与 C/C++ 等语言集成方便**：可通过 C 扩展或 Cython 等方式嵌入高性能模块。
# 第 3 题
- *问题*：Python中的动态类型系统的含义是什么？优缺点是什么？
	- *解答* 
		**含义**：动态类型系统是指在程序运行时才确定变量的类型，变量在声明时不需要指定类型，其类型由赋值决定。如：
		```
		x = 10
		x = "hello"
		```
		类型检查在运行时进行，而非编译时。
		**优点**：开发效率高、灵活性高、避免冗长的类型声明和转换
		**缺点**：运行时错误风险、执行效率较低
# 第 4 题
- *问题*：请列出 5 个以上的 Python 常用标准库和 10 个以上的 Python 扩展库，并说明它的作用。各选取 2 种库，给出调用实例。
## 4-1 常用标准库
1. **math**：提供数学运算函数，如三角函数、对数、幂运算等。
2. **datetime**：处理日期和时间。
3. **json**：编码和解码 JSON 数据。
4. **collections**：提供额外的数据结构，如 `deque`、`Counter`、`defaultdict`等。
5. **random**：生成随机数、随机选择元素等。
## 4-2 常用扩展库
1. **numpy**：科学计算基础库，支持多维数组和矩阵运算。
2. **pandas**：数据分析库，提供 DataFrame 和 Series 数据结构，支持数据清洗、分析、可视化。
3. **matplotlib**：绘图库，用于绘制各种静态、动态、交互式图表。
4. **scikit-learn**：机器学习库，提供分类、回归、聚类等算法。
5. **pytorch**：深度学习框架，用于构建和训练神经网络。
6. **pytest**：单元测试框架，支持自动化测试。
