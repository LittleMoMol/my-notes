# 1 预备知识

1. C++ 在 C 语言代表的**过程性语言**的基础上，添加了类代表的**面向对象语言**和**泛型****编程**。
    
2. 过程性编程试图使问题满足语言，而面向对象编程（OPP）通过设计**类**，试图让语言来满足问题的要求。其理念是设计与问题的本质特性相对应的数据格式。
    
3. OPP 强调的是编程的数据方面，而泛型编程强调的是**独立于特定****数据类型**。
    
4. OPP 提供了高级抽象，C 提供了低级硬件访问，这种能力上的结合使 C++ 广泛传播。
    
5. C++ 是在 C 语言的基础上添加 OPP 特性。
    
6. 程序在可移植性方面有两个障碍：硬件、语言差异。为了解决语言差异，ISO 制定出一个国家标准 ISO/IEC 14882:1998，该标准通常被称为 **C++****98。**
    
      于 2003 年，又发布了 C++ 标准第二版（ISO/IEC 14882:2003），常被称为 **C++03**。由于其为改变语言特性，因此使用 C++98 表示 C++98/C++2003。
    
      ISO 标准委员会于 2011 年 8 月批准了新标准 ISO/IEC 14882:2011，称为 **C++11****。**
    
7. Linux 系统中最常用的编译器为 g++
    
8. **源代码****文件**（即文本文件）经过编译和链接后得到**机器语言文件**，后者构成了**可执行程序**。上述任务通常在 **IDE** 中完成，IDE 提供了用于创建源代码文件的文本编辑器、用于生成可执行文件的编译器和链接器以及其他资源（项目管理、调试功能等）。这些任务也可以在命令行环境中通过调用合适的工具来完成。
    

# 2 开始学习 C++

## 2-1 进入 C++

1. 通常，C++ 程序必须包含一个名为 main() 的函数。
    
2. `#include<iostream>`中的`iostream`之类的文件叫做包含文件（include file）或头文件（header file）
    
3. C 语言传统是：头文件用扩展名 h，将其作为一种通过名称标识文件类型的简单方式。而有些 C 头文件在 C++ 中被重新命名，去掉了扩展名 h，并在文件名称前面加上前缀 c（表明来自 C 语言）
    
4. 命名空间：像`using namespace std;`中的`std`就是一个命名空间。命名空间支持是 C++ 一个特性，旨在让我们编写大型程序以及多个厂商现有的代码组合起来的程序更容易，还有助于组织程序。命名空间能够让厂商将其产品封装在一个叫做命名空间的单元里。本质上，命名空间就是定义了一个范围。类、函数和变量便是 C++ 编译器的标准组件，它们现在都被放置在命名空间`std`中。这意味着在 iostream中 cout 其实是 std::cout，endl 其实是 std::endl。但我们可以通过`using namespace std`这个 using 编辑指令使得 std 命名空间中的所有名称可用，这是一种偷懒做法，在大型项目中是一个潜在的问题。更好的方法是，只使所需的名称可用，如这样：
    
    ```C++
    using std::cout;
    using std::endl;
    using std::cin;
    ```
    
      便可以直接使用 cin、cout、endl，而不必加上 std:: 前缀。
    
5. 对象的长处之一——不用了解对象的内部情况，就可以使用它。只需要知道它的接口，即如何使用它。
    
6. 输出是一个流，即从程序流出的一系列字符。cout 对象表示这种流，其属性是在 iostream 文件中定义的。cout 的对象属性包括一个插入运算符（<<），它可以将右侧的信息插入到流中。与其说程序显示了一条消息，不如说它将一个字符串插入到了输出流中。
    
7. 重载运算符：通过重载，同一个运算符将有不同的含义，编译器通过上下文来确定运算符的含义。C++ 扩展了运算符重载的概念，允许为用户定义的类型重新定义运算符的含义。
    
8. C++ 源码风格：
    
    1. 每条语句占一行。
        
    2. 每个函数都有一个开始花括号和一个结束花括号，这两个花括号各占一行。
        
    3. 函数中的语句都相对于花括号进行缩进。
        
    4. 与函数名称相关的圆括号周围没有空白。
        

## 2-2 C++ 语句

1. C++ 程序是一组函数，而每个函数又是一组语句。
    
2. 声明变量时：`int a`语句提供两项信息：**需要的内存**以及**该内存单元的名称**。编译器负责分配和标记内存的细节。
    
3. 为何变量必须声明？防止拼写错误导致不小心定义了一个新变量而编译器无法捕获。
    
4. C++ 有一项不寻常的特性：可以连续使用赋值运算符。
    
5. cout 可用于数字和字符串，二者有天壤之别。在打印之前，cout 必须将整数形式的数字转换为字符串形式。cout 很聪明，知道某个 int 型变量是一个需要转换的整数。
    
6. cout **可扩展**的，可以重新定义`<<`运算符，使 cout 能够识别和显示所开发的新数据类型。
    
7. 输出时，`<<`运算符将字符插入到输出流中；输入时，cin 使用`>>`运算符从输入流中抽取字符。
    

## 2-3 其他 C++ 语句

**类简介**

- 类是 C++ 中面向对象编程（OPP）的核心概念之一。
    
- C++ 当前之所以如此有吸引力，很大程度上是由于存在大量支持 UNIX，Macintosh 和 Windows 变成的类库。
    
- 类是用户定义的一种数据类型。要定义类，需要描述它**能够表示什么信息**和**可对数据执行哪些操作。**类之于对象，就像类型之于变量。类定义描述的是**数据格式及其用法**，而对象则是**根据数据格式规范创建的实体**。即，类描述了一个数据类型的全部属性（包括可使用它执行的操作），对象是根据这些描述创建的实体。
    
- cout 是一个 ostream 类对象，cin 是一个 istream 类对象。
    
- C++ 提供了两种发送消息的方式：
    
    - 使用类方法（本质上就是函数调用）
        
    - 重新定义运算（cin 和 cout 采用的就是这种方式）
        

## 2-4 函数

- **函数原型**：如 `double sqrt(double);` 等，后有分号，表明它是一个语句（即是一个函数原型，而不是函数头），函数原型只描述函数接口，即描述的是发送给函数的信息和返回的信息。
    
- **函数定义**：定义中包含了函数的代码。
    
- 函数原型描述了函数接口，即函数如何与程序的其他部分交互；参数列表指出了何种信息将被传递给函数；函数类型指出了返回值的类型。有时可以将函数比作一个出入它们的信息所指定的黑盒子。
    
- 库文件中包含了函数的编译代码，而头文件中则包含了原型。
    
- 应在首次使用函数之前提供其原型。
    
- 在有些语言中，有返回值的函数被称为**函数**，无返回值的函数被称为**过程。**但 C++ 与 C 一样，这两种变体都被称为函数。
    
- 将计算机操作系统看作调用程序，因此，`main()` 的返回值并不是返回给程序的其他部分，而是返回给操作系统。通常的约定是，退出值为 0 则意味着程序运行成功，非零则意味着存在问题。
    
- 函数特性：有函数头和函数体、接受一个参数、返回一个值、需要一个原型。
    
- C++ 程序由一个或多个被称为函数的模块组成。程序从 main() 函数开始执行，因此该函数必不可少。函数由函数头和函数体组成。函数头指出函数的返回值的类型和函数期望通过参数传递给它的信息的类型；函数体由一系列位于花括号中的 C++ 语句组成。
    
- 让程序能够访问命名空间 std 的方法有很多，下面是其中的 4 种。
    
    - 将 `using namespace std;` 放在函数定义之前，让文件中所有的函数都能够使用命名空间 std 中所有的元素。
        
    - 将 `using namespace std;` 放在特定的函数定义中，让该函数能够使用命名空间 std 中的所有元素。
        
    - 在特定的函数中使用类似 `using std::cout;` 这样的编译指令，而不是 `using namespace std;`，让该函数能够使用特定的元素，如 cout
        
    - 完全不使用编译指令 using，而在需要使用名称空间 std 中的元素时，使用前缀 `std::`，如下所示：`std::cout << "Hello World!" << std::endl;`
        

# 3 处理数据

## 3-1 简单变量

- 程序找到一块能够存储整数的内存，讲该内存单元标记为你的变量名，它不会告诉你这个值储存在内存的哪一个位置，你可以用 & 运算符来检索定义变量的内心地址。
    
- 变量名的一些规则略，只提一个：以两个下划线打头或以下划线和大写字母打头的名称被保留给实现（编译器及其使用的资源）使用。以一个下划线开头的名称保留给实现，用作全局标识符。
    
- 宽度：描述存储整数时使用的内存量。
    
- 字节（byte）通常指的是 8 位的内存单元。C++ 字节由至少能够容纳实现的基本字符集的相邻位组成，也就是说，可能取值的数目必须等于或超过字符数目。
    
      国际编程可能需要使用更大的字符集，如 Unicode，因此有些实现可能使用 16 位甚至 32 位的字节。有些人使用术语八位组（octet）表示 8 位字节。
    
      字节的含义依赖于实现。
    
- sizeof 运算符返回类型或变量的长度，单位为字节。
    
      对类型名使用 sizeof 运算符时，应将名称放在括号中；但对变量名使用该运算符，括号是可选的。

- 整形字面值
    
    - 整形字面值（常量）是显式地书写的常量。

    - 默认情况下，cout 以十进制格式显示整数，而不管这些整数在程序中是如何书写的，都将以相同的方式存储在计算机中——被存储为二进制数（以 2 为基数）
        
    - iostream 除了提供了控制符 endl 以外，它还提供了控制符 dec、hex、oct，分别用于指示 cout 以十进制、十六进制和八进制格式显示整数。
        
- C++ 如何确定常量的类型
    
    - `cout << 4494 << endl;` 中 4492 被存储为什么类型呢？答案是：除非有理由存储为其他类型，否则 C++ 将整型常量存储为 int 类型
        
    - 后缀是放在数字常量后面的字母，用于表示类型，如：l、L、u、U、ll、LL、uLL、Ull、ull、ULL 等（大小写不区分）
        
    - 对于不带后缀的十进制整数，将使用下面几种类型中能够存储该数的最小类型来表示：int、long 或 long long
        
    - 对于不带后缀的十六进制或八进制整数，将使用下面几种类型中能够存储该数的最小类型来表示：int、unsigned int、long、unsigned long、long long 或 unsigned long long（因为十六进制常用来表示内存地址，而内存地址是没有符号的，因此，unsigned int 比 long 更适合用来表示 16 位的地址）
        
- char 类型：字符和小整数
    
    - char 类型是专门存储字符（如字母和数字）而设计的。编程语言通过使用字母的数值编码解决存储字符这个问题，因此 char 类型是另一种整形，它能够表示目标计算机系统中的所有基本符号——所有字母、数字、标点符号等。实际上，很多系统支持的字符都不超过 128 个，因此用一个字节就可以表示所有的富豪。
        
    - 虽然 char 最常被用来处理字符，但也可以将它用作比 shrot 更小的整形。
        
    - 在美国，最常用的符号集是 ASCII 字符集
