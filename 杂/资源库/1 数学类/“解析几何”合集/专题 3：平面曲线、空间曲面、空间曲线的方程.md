# 0 前置知识

**有向角** $\measuredangle$

在平面上，引进从向量 $\bold a$ 到向量 $\bold b$ 的**有向角**的概念，并记做 $\measuredangle(\bold a, \bold b)$

- 当 $\bold a$ 不平行于 $\bold b$ 时，以向量 $\bold a$ 扫过向量 $\bold a, \bold b$ 之间的夹角 $\angle(\bold a, \bold b)$ 旋转到与向量 $\bold b$ 同方向的位置时
    
    - 如果旋转是逆时针方向的，那么 $\measuredangle(\bold a, \bold b) = \angle(\bold a, \bold b)$
        
    - 如果旋转是逆时针方向的，那么 $\measuredangle(\bold a, \bold b) = -\angle(\bold a, \bold b)$
        
- 当 $\bold a // \bold b$ 时，$\measuredangle(\bold a, \bold b) = \angle(\bold a, \bold b)$
    

有向角的值，常常可推广到 $\le -\pi$ 或 $>\pi$，这时我们认为相差 $2\pi$ 整倍数的值代表同一角，对于有向角还有下面的等式：

- $\measuredangle(\bold a, \bold b) = -\measuredangle(\bold b, \bold a)$
    
- $\measuredangle(\bold a, \bold b) + \measuredangle(\bold b, \bold c) = \measuredangle(\bold a, \bold c)$
    

# 1 平面曲线的方程

## 1-1 理论

**通法**：设未知量，用**向量**求解！

**具体操作**：求一个向量表示方法？先求模长，然后求 $x$ 轴与该向量的有向角，最后用单位圆知识即可。

## 1-2 实践

### 1-2-1 旋轮线（摆线）

**情境**：一个圆在一直线上无滑动地滚动，求圆周上的一点的轨迹（这个轨迹称为**旋轮线**，或称为**摆线**）

![](https://rcndb0nxsbc2.feishu.cn/space/api/box/stream/download/asynccode/?code=YzcxNjVmN2Q3ZDc4NDY2MDVjMzEzODJiNzI0ZGYzNGRfaWFPbHNtSFBSbUM3T1MwUkhqYTRYV3VFWFpkV0ZPeUJfVG9rZW46VXNLbmI4VG45b2dXTFV4NXg5M2NHcmxnbjdmXzE3MzUxMzYyMzI6MTczNTEzOTgzMl9WNA)

如图，开始时 $P$ 恰好在原点，$\overgroup{AP}=\left|\overrightarrow{OA}\right|$，$C$ 为某一时刻的圆心，$A$ 在 $x$ 轴上，圆的半径为 $a$，$\theta = \measuredangle( \overrightarrow{CP}, \overrightarrow{CA})$

易知 $\boldsymbol r = \overrightarrow{OP} = \overrightarrow{OA} + \overrightarrow{AC} + \overrightarrow{CP}$，

- $\overrightarrow{OA} = \left|\overrightarrow{OA}\right|\boldsymbol i = \overgroup{AP} \boldsymbol i = a\theta \boldsymbol i$
    
- $\overrightarrow{AC} = a\boldsymbol j$
    
- 由于 $\measuredangle(\bold i, \overrightarrow{CP}) = -\left( \dfrac \pi 2 + \theta \right)$，故 $\overrightarrow{CP} = \boldsymbol i a \cos\left( -\dfrac \pi 2 - \theta \right) + \boldsymbol j a \sin\left( -\dfrac \pi 2 - \theta \right) = (-a\sin\theta)\boldsymbol i + (-a\cos\theta)\boldsymbol j$
    

综上，$\boldsymbol r = a(\theta - \sin\theta)\boldsymbol i + a(1-\cos\theta)\boldsymbol j$

故$P$ 点的向量式参数方程为 $\boldsymbol r = a(\theta - \sin\theta)\boldsymbol i + a(1-\cos\theta)\boldsymbol j$，坐标式参数方程为 $\begin{cases} x = a(\theta-\sin\theta) \\ y = a(1-\cos\theta) \end{cases}\ (-\infty < \theta < + \infty)$

### 1-2-2 内旋轮线（内摆线）

已知大圆半径为 $a$，小圆半径为 $b$，设大圆不动，而小圆在大圆内无滑动地滚动，动圆周上某一定点 $P$ 地轨迹叫做**内旋轮线**（或称**内摆线**），求内旋轮线的方程

![](https://rcndb0nxsbc2.feishu.cn/space/api/box/stream/download/asynccode/?code=MmEzNzBhNGY2ZTg5MmE5OWI1M2ExNjQ3MjExNjQyODdfN2owSXQzTmxtNlpleWZEYkRyR2xiaFpOdllmUVVSM09fVG9rZW46UTlHcmJ5akU4b2dEaTR4Sk9mRGN0TWFhbkdjXzE3MzUxMzYyMzI6MTczNTEzOTgzMl9WNA)

如图，运动开始时 $P$ 与 $A$ 重合，$\overgroup{PB} = \overgroup{AB}$，$C$ 为圆心，$\theta = \measuredangle( \boldsymbol i, \overrightarrow{OC}),\ \varphi = \measuredangle( \overrightarrow{CP}, \overrightarrow{CB})$

易知，$\boldsymbol r = \overrightarrow{OP} = \overrightarrow{OC} + \overrightarrow{CP}$

- $\overrightarrow{OC} = \boldsymbol i (a-b)\cos\theta + \boldsymbol j (a-b)\sin\theta$
    
- 由于 $b\varphi = a\theta$，故 $\varphi = \dfrac ab \theta$，则 $\measuredangle( \boldsymbol i, \overrightarrow{CP}) = -(\varphi-\theta) = \dfrac{b-a}b \theta$，再由 $\left| \overrightarrow{CP} \right| = b$ 得 $\overrightarrow{CP} = \boldsymbol i b\cos\left(\dfrac{b-a}b \theta\right) + \boldsymbol j b\sin\left(\dfrac{b-a}b \theta\right) = \boldsymbol i b\cos\left(\dfrac{a-b}b \theta\right) - \boldsymbol j b\sin\left(\dfrac{a-b}b \theta\right)$
    

综上，$\boldsymbol r = \left[ (a-b)\cos\theta + b \cos\dfrac{a-b}b \theta \right] \boldsymbol i + \left[ (a-b)\sin\theta - b \sin\dfrac{a-b}b \theta \right] \boldsymbol j$

故 $P$ 的向量式参数方程为 $\boldsymbol r = \left[ (a-b)\cos\theta + b \cos\dfrac{a-b}b \theta \right] \boldsymbol i + \left[ (a-b)\sin\theta - b \sin\dfrac{a-b}b \theta \right] \boldsymbol j$，坐标式参数方程为 $\begin{cases} x=(a-b)\cos\theta + b \cos\dfrac{a-b}b \theta \\ y=(a-b)\sin\theta - b \sin\dfrac{a-b}b \theta \end{cases} (-\infty < \theta < + \infty)$

如图，圆半径 $R$，$\left| \overrightarrow{BP} \right| = \overgroup{BA}$ 且 $\overrightarrow{CP} \perp \overrightarrow{OB}$，$\theta = \measuredangle(\boldsymbol i, \overrightarrow{OB})$，则：

$\boldsymbol r = \overrightarrow{OP} = \overrightarrow{OB} + \overrightarrow{BP}$

- $\overrightarrow{OB} = R(\boldsymbol i \cos\theta + \boldsymbol j \sin\theta)$
    
- $\left| \overrightarrow{BP} \right| = \overgroup{BA} = R\theta$，而 $\measuredangle(\boldsymbol i, \overrightarrow{BP}) = \theta - \dfrac \pi 2$，故 $\overrightarrow{BP} = R\theta(\boldsymbol i\sin\theta - \boldsymbol j\cos\theta)$
    

综上，$\boldsymbol r = R(\cos\theta + \theta\sin\theta)\boldsymbol i + R(\sin\theta - \theta\cos\theta) \boldsymbol j$

故 $P$ 的向量式参数方程为 $\boldsymbol r = R(\cos\theta + \theta\sin\theta)\boldsymbol i + R(\sin\theta - \theta\cos\theta) \boldsymbol j$，坐标式参数方程为 $\begin{cases} x = R(\cos\theta + \theta\sin\theta) \\ y = R(\sin\theta - \theta\cos\theta) \end{cases}$

  

# 2 空间极坐标系、半极坐标系（空间曲面的方程）

## 2-1 球面与球坐标系（极坐标系）

![](https://rcndb0nxsbc2.feishu.cn/space/api/box/stream/download/asynccode/?code=MzFmNzAyYjdjYzJlMDMzZTFmMmFlYTkxNGFkMTFkZWZfNVYzTEdLSU9rdUdjMklMeFo1cnJ1MU5MUnRYUjJwUEpfVG9rZW46SlVvZGJlWlBob1h4M1J4NERiUWNaVGtvbkJiXzE3MzUxMzYyMzI6MTczNTEzOTgzMl9WNA)

半径为 $r$ 的球上任意一点 $M$ 的坐标式参数方程为 $\begin{cases} x = r\cos\theta\cos\varphi \\ y = r\cos\theta\sin\varphi \\ z = r\sin\theta \end{cases} \ \left(-\pi < \varphi \le \pi,\ -\dfrac \pi 2 \le \theta \le \dfrac \pi 2\right)$（可通过 $\boldsymbol r = \overrightarrow{OM} = \overrightarrow{OQ} + \overrightarrow{QP} + \overrightarrow{PM}$ 求解，具体过程略）

下面引入**球坐标系**

当把 $r, \theta, \varphi$ 都看成变量时，可以布满空间中所有的点，具体地，令 $\begin{cases} \left| \overrightarrow{OM} \right| = \rho\ (\rho \ge 0) \\ \angle QOP = \varphi\ (-\pi < \varphi \le \pi) \\ \angle POM = \theta\ \left( -\dfrac \pi 2 \le \theta \le \dfrac \pi 2 \right) \end{cases}$，则 $\begin{cases} x = \rho\cos\theta\cos\varphi \\ y = \rho\cos\theta\sin\varphi \\ z = \rho\sin\theta \end{cases}$，当 $\rho, \theta, \varphi$ 都确定时，$M$ 点的位置就确定了。反过来，$M$ 点的位置确定时，$\rho, \theta, \varphi$ 就都确定了（除去 $z$ 轴）

这样，除去 $z$ 轴上的点，其余的点与有序三数组 $\rho, \varphi, \theta$ 建立了一一对应的关系，这种一一对应的关系叫做**空间点的球坐标系**，或称**空间极坐标系**，并把有序三数组 $\rho, \varphi, \theta$ 叫做**空间点** $M$ **的球坐标**或称**空间极坐标**，记做 $M(\rho, \varphi, \theta)$

此时 $(x,y,z)$ 与 $(\rho, \varphi, \theta)$ 就有了关系：

$\begin{cases} x = \rho\cos\theta\cos\varphi \\ y = \rho\cos\theta\sin\varphi \\ z = \rho\sin\theta \end{cases} \left(\rho \ge 0,\ -\pi < \varphi \le \pi,\ -\dfrac \pi 2 \le \theta\ \le \dfrac \pi 2\right)$ 以及 $\begin{cases} \rho = \sqrt{x^2+y^2+z^2} \\ \cos\varphi = \dfrac{x}{\sqrt{x^2+y^2}},\ \sin\varphi = \dfrac{y}{\sqrt{x^2+y^2}} \\ \theta = \arcsin \dfrac{z}{\sqrt{s^2+y^2+z^2}} \end{cases}$

这样一来：

- $\rho = a$ 表示球面
    
- $\varphi = \alpha\ (\text{常数})$ 表示一个半平面
    
- $\theta = \theta_0\ (\text{常数})$ 表示一个圆锥面（只有一腔）
    

## 2-2 柱面与柱坐标系（半极坐标系）

![](https://rcndb0nxsbc2.feishu.cn/space/api/box/stream/download/asynccode/?code=YjJiMjI5NWU0NmU2NjQ1ODQ1MmZlYzNjMGI5MGZhNThfRVliUlF3a0xFYmFTNEs1WUdpQjQ0YVpGcHpJQnNxQVRfVG9rZW46Q1l5ZGJ5MkR4b3Rka3Z4TXZjb2NhT0llbkFiXzE3MzUxMzYyMzI6MTczNTEzOTgzMl9WNA)

半径为 $R$ 的圆柱上任意一点 $M$ 的坐标式参数方程为 $\begin{cases} x = R\cos\varphi \\ y = R\sin\varphi \\ z = u \end{cases} (-\pi < \varphi \le \pi,\ -\infty < u < + \infty)$（可通过 $\boldsymbol r = \overrightarrow{OM} = \overrightarrow{OQ} + \overrightarrow{QP} + \overrightarrow{PM}$ 求解，具体过程略）

下面引入**柱坐标系**

当把 $R, \varphi, u$ 都看成变量时，可以布满空间中所有的点，具体地，令 $\begin{cases} R = \rho\ (\rho \ge 0) \\ \angle QOP = \varphi\ (-\pi < \varphi \le \pi) \\ z=u\ (-\infty < u < + \infty) \end{cases}$，则 $\begin{cases} x = \rho\cos\varphi \\ y = \rho\sin\varphi \\ z = u \end{cases} \ (\rho \ge 0,\ -\pi < \varphi \le \pi,\ -\infty < i < + \infty)$，当 $\rho, \varphi, u$ 都确定时，$M$ 点的位置就确定了。反过来，$M$ 点的位置确定时，$\rho, \varphi, u$ 就都确定了（除去 $z$ 轴）

这样，除去 $z$ 轴上的点，其余的点与有序三数组 $\rho, \varphi, u$ 建立了一一对应的关系，这种一一对应的关系叫做**空间点的柱坐标系**，或称**空间半极坐标系**，并把有序三数组 $\rho, \varphi, u$ 叫做**空间点** $M$ **的柱坐标**或称**空间半极坐标**，记做 $M(\rho, \varphi, u)$

此时 $(x,y,z)$ 与 $(\rho, \varphi, u)$ 就有了关系：

$\begin{cases} x = \rho\cos\varphi \\ y = \rho\sin\varphi \\ z = u \end{cases} \ (\rho \ge 0,\ -\pi < \varphi \le \pi,\ -\infty < i < + \infty)$ 以及 $\begin{cases} \rho = \sqrt{x^2+y^2} \\ \cos\varphi = \dfrac{x}{\sqrt{x^2+y^2}},\ \sin\varphi = \dfrac{y}{\sqrt{x^2+y^2}} \\ u=z \end{cases}$

这样一来：

- $\rho = a$ 表示一个圆柱面
    
- $\varphi = \alpha\ (\text{常数})$ 表示一个半平面
