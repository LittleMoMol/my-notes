# 答案
1. 设 $S$ 是一个数集
    
      如果 $\exist\ \xi\in S, \text{ s.t. } \forall\ x\in S,\ x\le\xi$，则称 $\xi$ 是数集 $S$ 的**最大数**，记为 $\xi = \max S$
    
      如果 $\exist\ \eta\in S, \text{ s.t. } \forall\ x\in S,\ x\ge\eta$，则称 $\eta$ 是数集 $S$ 的**最小数**，记为 $\eta = \min S$
    
2. 如果 $\exist\ M \in \mathbb R, \text{ s.t. } \forall\ x\in S,\ x \le M$，则称 $M$ 是 $S$ 的一个**上界**。
    
      如果 $\exist\ m \in \mathbb R, \text{ s.t. } \forall\ x\in S,\ x \ge m$，则称 $m$ 是 $S$ 的一个**下界**。
    
      若 $\beta$ 满足 $\forall\ x\in S,\ x\le\beta$ 且 $\forall\ \varepsilon > 0,\ \exist\ x\in S, \text{ s.t. } x>\beta-\varepsilon$，那么 $\beta$ 就为数集 $S$ 的**上确界**，记为 $\beta = \sup S$
    
      若 $\alpha$ 满足 $\forall\ x\in S,\ x\ge\alpha$ 且 $\forall\ \varepsilon > 0,\ \exist\ x\in S, \text{ s.t. } x<\alpha+\varepsilon$，那么 $\alpha$ 就为数集 $S$ 的**下确界**，记为 $\alpha = \inf S$
    
      当数集 $S$ 既有上界又有下界时，称 $S$ 为**有界集**。
    
3. 若 $\exist\ a,\ \forall\ \varepsilon > 0,\ \exist\ N,\ \forall\ n>N:\ |x_n-a| < \varepsilon$，则称数列 $\{x_n\}$ **收敛于** $a$，$a$ 是数列 $\{x_n\}$ 的**极限**。
    
      若不存在这样的 $a$，则称数列 $\{x_n\}$ **发散**。
    
4. 极限为 $0$的数列为**无穷小量**。
    
      若 $\forall\ G>0,\ \exist\ N,\ \forall\ n>N:\ |x_n|>G$，则称数列 $\{x_n\}$ 是**无穷大量**
    
      若 $\forall\ G>0,\ \exist\ N,\ \forall\ n>N:\ x_n>G$，则称数列 $\{x_n\}$ 是**正无穷大量**
    
      若 $\forall\ G>0,\ \exist\ N,\ \forall\ n>N:\ x_n<-G$，则称数列 $\{x_n\}$ 是**负无穷大量**
    
      正无穷大量和负无穷大量统称为**定号无穷大量**。
    
5. 若分别以 $+\infty,\ -\infty,\ \infty,\ 0$ 分别表示正无穷大量、负无穷大量、无穷大量、无穷小量，则易知 $\infty \pm \infty,\ (+\infty)-(+\infty),\ (+\infty) + (-\infty),\ 0 \cdot \infty,\ \dfrac 00,\ \dfrac{\infty}{\infty}$ 等极限，其结果可以是无穷小量，或非零极限，或无穷大量，也可以没有极限，我们称这种类型的极限为**待定型**。
    
6. 如果数列 $\{x_n\}$ 满足 $x_n \le x_{n+1},\ n=1,2,3,\cdots$，则称 $\{x_n\}$ 为**单调增加数列**；若进一步满足 $x_n < x_{n+1},\ n=1,2,3,\cdots$，则称 $\{x_n\}$ 为**严格单调增加数列**。
    
      如果数列 $\{x_n\}$ 满足 $x_n \ge x_{n+1},\ n=1,2,3,\cdots$，则称 $\{x_n\}$ 为**单调减少数列**；若进一步满足 $x_n > x_{n+1},\ n=1,2,3,\cdots$，则称 $\{x_n\}$ 为**严格单调减少数列**。
    
7. $\pi = \lim_{n\rightarrow\infty} n\sin\dfrac{180^\circ}{n}$、$e = \lim_{n\rightarrow\infty} \left(1+\dfrac 1n \right)^n = \lim_{n\rightarrow\infty} \left( 1 + \dfrac 1n \right)^{n+1}$
    
8. 如果一列闭区间 $\{[a_n,b_n]\}$ 满足条件 $[a_{n+1},b_{n+1}] \subset [a_n,b_n],\ n=1,2,3,\cdots$ 且 $\lim_{n\rightarrow\infty} (b_n-a_n) = 0$，则称这列闭区间形成一个**闭区间套**

14. 若 $\forall\ \varepsilon>0,\ \exist\ \delta>0,\ \forall\ x(|x-x_0|<\delta):|f(x)-f(x_0)|<\varepsilon$，则称**函数** $f(x)$ **在点** $x_0$ **连续**，$x_0$ 是函数 $f(x)$ 的**连续点**。
    
15. 若 $\lim_{x\rightarrow x_0^-}f(x) = f(x_0)$，则称函数 $f(x)$ 在 $x_0$ **左连续**。
    
      若 $\lim_{x\rightarrow x_0^+}f(x) = f(x_0)$，则称函数 $f(x)$ 在 $x_0$ **右连续**。
    
      若 $f(x)$ 在 $(a,b)$ 连续，且在左端点 $a$ 右连续，在右端点 $b$ 左连续，则称函数 $f(x)$ 在**闭区间** $[a,b]$ **上连续**。
    
16. **第一类不连续点**：函数 $f(x)$ 在点 $x_0$ 的左右极限都存在但不相等，即 $f(x_0+) \not= f(x_0-)$
    
      **第二类不连续点**：函数 $f(x)$ 在点 $x_0$ 的左右极限中至少有一个不存在。
    
      **第三类不连续点**：函数 $f(x)$ 在点 $x_0$ 的左右极限都存在且相等，但不等于 $f(x_0)$ 或者 $f(x)$ 在点 $x_0$ 无定义。
    
17. 当 $f:X\rightarrow Y$ 是单射，即对任意 $y\in R_f \subset Y$，它的逆像 $x\in X$ 唯一，则存在 $f$ 的逆映射 $f^{-1}: R_f\rightarrow X$，对于函数来说，与之相对应的就是**反函数**。
    
18. 若 $\lim_{x\rightarrow x_0} f(x)=0$，则称当 $x\rightarrow x_0$ 时，$f(x)$ 是**无穷小量**。
    
      若 $\lim_{x\rightarrow x_0} \dfrac{u(x)}{v(x)}=0$，则称当 $x\rightarrow x_0$ 时，$u(x)$ 关于 $v(x)$ 是**高阶无穷小量**，$v(x)$ 关于 $u(x)$ 是**低阶无穷小量**，**记为** $u(x) = o(v(x))\quad (x\rightarrow x_0)$
    
      若存在 $A>0$，当 $x$ 在 $x_0$ 的某个去心邻域中，成立 $\left| \dfrac{u(x)}{v(x)} \right| \le A$，则称当 $x\rightarrow x_0$ 时，$\dfrac{u(x)}{v(x)}$ 是**有界量**，记为 $u(x) = O(v(x))\quad (x\rightarrow 0)$
    
      若又存在 $a>0$，当 $x$ 在 $x_0$ 的某个去心邻域中，成立 $a\le \left| \dfrac{u(x)}{v(x)} \right| \le A$，则称当 $x\rightarrow x_0$ 时，$u(x)$ 与 $v(x)$ 是**同阶无穷小量**。
    
      若 $\lim_{x\rightarrow x_0} \dfrac{u(x)}{v(x)} = 1$，则称当 $x\rightarrow x_0$ 时，$u(x),v(x)$ 是**等价无穷小量**，记为 $u(x) \sim v(x)\quad (x\rightarrow x_0)$

30. **Heine 定理**：$\lim_{x\rightarrow x_0} f(x) = A $ $\iff$ 对于任意满足条件 $\lim_{n\rightarrow \infty} x_n = x_0$ 且 $x_n \not= x_0\ (n=1,2,3,\cdots)$ 的数列 $\{x_n\}$，相应的函数值数列 $\{f(x_n)\}$ 成立 $\lim_{n\rightarrow \infty} f(x_n) = A$
    
31. **Cauchy 收敛原理**：函数极限 $\lim_{x\rightarrow + \infty} f(x)$ 存在且有限 $\iff$ 对于任意给定的 $\varepsilon>0$，存在 $X>0$，使得对一切 $x',x''>X$ 成立 $|f(x')-f(x'')| < \varepsilon$
    
32. **反函数存在性定理**：若函数 $y=f(x),\ x\in D_f$ 是严格单调增加（减少）的，则存在它的反函数 $x=f^{-1}(y),\ y\in R_f$，并且 $f^{-1}(y)$ 也是严格单调增加（减少）的。
    
33. **反函数连续性定理**：设函数 $y=f(x)$ 在闭区间 $[a,b]$ 上连续且严格单调增加，$f(a)=\alpha,\ f(b)=\beta$，则它的反函数 $x=f^{-1}(y)$ 在 $[\alpha,\beta]$ 连续且严格单调增加。
    
34. **复合函数的连续性**：若 $u=g(x)$ 在点 $x_0$ 连续，$g(x_0)=u_0$，又 $y=f(u)$ 在点 $u_0$ 连续，则复合函数 $y=f\circ g(x)$ 在点 $x_0$ 连续。
    
35. **有界性定理**：若函数 $f(x)$ 在闭区间 $[a,b]$ 上连续，则它在 $[a,b]$ 上有界。
    
36. **最值定理**：若函数 $f(x)$ 在闭区间 $[a,b]$ 上连续，则它在 $[a,b]$ 上必能取到最大值与最小值，即存在 $\xi,\eta \in [a,b]$，对于一切 $x \in [a,b]$，成立 $f(\xi) \le f(x) \le f(\eta)$
    
37. **零点存在定理**：若函数 $f(x)$ 在闭区间 $[a,b]$ 连续，且 $f(a)f(b)<0$，则一定存在 $\xi \in (a,b)$，使 $f(\xi) = 0$
    
38. **中间值定理**：若函数 $f(x)$ 在闭区间 $[a,b]$ 上连续，则它一定能取到最大值 $M = \max \{f(x) \mid x \in [a,b]\}$ 和最小值 $m = \min \{f(x) \mid x \in [a,b] \}$ 之间的任何一个值。
    
39. **Cantor 定理**：若函数 $f(x)$ 在闭区间 $[a,b]$ 上连续，则它在 $[a,b]$ 上一致连续。
