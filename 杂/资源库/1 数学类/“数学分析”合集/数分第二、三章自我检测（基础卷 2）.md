# 一、证明题组 1（数列极限的性质）(6pts)
1. 证明：收敛数列必定有界且极限唯一 (1pts)
2. 设数列 $\{x_n\},\{y_n\}$ 均收敛，若 $\lim\limits_{n\rightarrow \infty} x_n = a,\ \lim\limits_{n\rightarrow \infty} y_n = b$ 且 $a<b$，证明：存在正整数 $N$，当 $n>N$ 时，成立 $x_n<y_n$ (1pts)
3. 设 $\lim\limits_{n\rightarrow\infty} x_n=a,\ \lim\limits_{n\rightarrow\infty} y_n=b$，证明：
    1. $\lim\limits_{n\rightarrow\infty}(\alpha x_n + \beta y_n) = \alpha a + \beta b$（$\alpha, \beta$ 是常数）
    2. $\lim\limits_{n\rightarrow\infty} (x_ny_n) = ab$ 
    3. $\lim\limits_{n\rightarrow\infty} \left( \dfrac{x_n}{y_n} \right) = \dfrac ab \ (b\not= 0)$ 
	(3pts)
4. 若三个数列 $\{x_n\},\{y_n\},\{z_n\}$ 从某项开始成立 $x_n \le y_n \le z_n,\ n > N_0$，且 $\lim\limits_{n\rightarrow \infty} x_n = \lim\limits_{n\rightarrow \infty} z_n = a$，求证：$\lim\limits_{n\rightarrow\infty} y_n = a$ (1pts)
# 二、证明题组 2（无穷大量相关性质）(3pts)
5. 已知数列 $\left\{x_n\right\}$ 且 $x_n \not= 0$，求证：$\{x_n\}$ 是无穷大量 $\iff$ $\left\{ \dfrac 1{x_n} \right\}$ 是无穷小量 (1pts)
6. $\{x_n\}$ 是无穷大量，求证：当 $n>N_0$ 时，$|y_n| \ge \delta > 0$ 成立，则 $\{x_ny_n\}$ 是无穷大量 (1pts)
7. $\{x_n\}$ 是无穷大量，求证：$\lim\limits_{n\rightarrow\infty} y_n = b \not= 0$，则 $\{x_ny_n\},\ \left\{ \dfrac{x_n}{y_n} \right\}$ 都是无穷大量 (1pts)
# 三、证明题组 3（子列相关性质）(5pts)
8. 若数列 $\{x_n\}$ 收敛于 $a$，求证：它的任何子列 $\{x_{n_k}\}$ 也收敛于 $a$，即 $\lim\limits_{n\rightarrow\infty} x_n = a \Rightarrow \lim\limits_{k\rightarrow\infty} x_{n_k} = a$(2pts)
9. 若存在数列 $\{x_n\}$ 的两个子列 $\{x_{n_k}^{(1)}\}$ 与 $\{x_{n_k}^{(2)}\}$，分别收敛于不同的极限，求证：数列 $\{x_n\}$ 必定发散 (2pts)
10. 若 $\{x_n\}$ 是一个无界数列，求证：存在子列 $\{x_{n_k}\}$ 使得 $\lim\limits_{k\rightarrow\infty} x_{n_k} = \infty$ (1pts)
# 四、证明题组 4（函数极限的性质）(14pts)
11. 设 $A,B$ 都是函数 $f(x)$ 在点 $x_0$ 的极限，求证：$A=B$ (2pts)
12. 若 $\lim\limits_{x\rightarrow x_0} f(x)=A,\ \lim\limits_{x\rightarrow x_0} g(x)=B$ 且 $A>B$，求证：存在 $\delta>0$，当 $0<|x-x_0|<\delta$ 时，成立 $f(x)>g(x)$ (2pts)
13. 若 $\lim\limits_{x\rightarrow x_0} f(x) = A$，求证：存在 $\delta>0$，使得 $f(x)$ 在 $O(x_0,\delta) \backslash \{x_0\}$ 中有界 (2pts)
14. 若存在 $r>0$，使得当 $0<|x-x_0| 时，成立 $g(x)\le f(x)\le h(x)$，且 $\lim\limits_{x\rightarrow x_0} g(x) = \lim\limits_{x\rightarrow x_0} h(x) = A$，求证：$\lim\limits_{x\rightarrow x_0} f(x) = A$ (2pts)
15. 设 $\lim\limits_{x\rightarrow x_0} f(x) = A,\ \lim\limits_{x\rightarrow x_0} g(x) = B$，证明：
    1. $\lim\limits_{x\rightarrow x_0} (\alpha f(x) + \beta g(x)) = \alpha A + \beta B$（$\alpha,\beta$ 是常数)
    2. $\lim\limits_{x\rightarrow x_0} (f(x)g(x)) = AB$ 
    3. $\lim\limits_{x\rightarrow x_0} \dfrac{f(x)}{g(x)} = \dfrac AB\ (B\not= 0)$ 
    (3pts)
16. 设 $\lim\limits_{x\rightarrow x_0} f(x) = f(x_0),\ \lim\limits_{x\rightarrow x_0} g(x) = g(x_0)$，证明：
    1. $\lim\limits_{x\rightarrow x_0} (\alpha f(x) + \beta g(x)) = \alpha f(x_0) + \beta g(x_0)$（$\alpha,\beta$ 是常数）
    2. $\lim\limits_{x\rightarrow x_0} (f(x)g(x)) = f(x_0)g(x_0)$ 
    3. $\lim\limits_{x\rightarrow x_0} \dfrac{f(x)}{g(x)} = \dfrac{f(x_0)}{g(x_0)}\ (g(x_0)\not=0)$ 
    (3pts)
# 五、证明题组 5 （数列极限相关定理）(32pts)
17. 证明**确界存在定理**：非空有上界的数集必有上确界，非空有下界的数集必有下确界。(4pts)
18. 证明 **Stolz 定理**：设 $\{y_n\}$ 是严格单调增加的正无穷大量，且 $\lim\limits_{n\rightarrow\infty} \dfrac{x_n-x_{n-1}}{y_n- y_{n-1}} = a$（$a$ 可以为有限量，$+\infty$ 与 $-\infty$，但不可以为 $\infty$），则 $\lim\limits_{n\rightarrow\infty} \dfrac{x_n}{y_n} = a$ (4pts)
19. 证明**单调有界数列收敛定理**：单调有界数列必定收敛 (4pts)
20. 证明**闭区间套定理**：如果 $\{[a_n,b_n]\}$ 形成一个闭区间套，则存在唯一的实数 $\xi$ 属于所有的闭区间 $[a_n,b_n]$ 且 $\xi = \lim\limits_{n\rightarrow\infty} a_n = \lim\limits_{n\rightarrow\infty} b_n$(4pts)
21. 证明实数集 $\mathbb R$ 是不可列集。
22. 证明 **Bolzano-Weierstrass 定理**：有界数列必有收敛子列 (4pts)
23. 证明 **Cauchy 收敛原理**：$\{x_n\}$ 收敛 $\iff$ $\{x_n\}$ 是基本数列 (4pts)
24. 请通过 **Cauchy 收敛原理**来证明**闭区间套定理** (4pts)
25. 请通过**闭区间套定理**来证明**确界存在定理** (4pts)
# 六、证明题组 6（函数极限相关定理）(40pts)
26. 证明 **Heine 定理**：$\lim\limits_{x\rightarrow x_0} f(x) = A$ $\iff$ 对于任意满足条件 $\lim\limits_{n\rightarrow \infty} x_n = x_0$ 且 $x_n \not= x_0\ (n=1,2,3,\cdots)$ 的数列 $\{x_n\}$，相应的函数值数列 $\{f(x_n)\}$ 成立 $\lim\limits_{n\rightarrow \infty} f(x_n) = A$ (4pts)
27. 证明 **Cauchy 收敛原理**：函数极限 $\lim\limits_{x\rightarrow + \infty} f(x)$ 存在且有限 $\iff$ 对于任意给定的 $\varepsilon>0$，存在 $X>0$，使得对一切 $x',x''>X$ 成立 $|f(x')-f(x'')| < \varepsilon$ (2pts)
28. 证明**反函数存在性定理**：若函数 $y=f(x),\ x\in D_f$ 是严格单调增加（减少）的，则存在它的反函数 $x=f^{-1}(y),\ y\in R_f$，并且 $f^{-1}(y)$ 也是严格单调增加（减少）的 (2pts)
29. 证明**反函数连续性定理**：设函数 $y=f(x)$ 在闭区间 $[a,b]$ 上连续且严格单调增加，$f(a)=\alpha,\ f(b)=\beta$，则它的反函数 $x=f^{-1}(y)$ 在 $[\alpha,\beta]$ 连续且严格单调增加 (2pts)
30. 证明**复合函数的连续性**：若 $u=g(x)$ 在点 $x_0$ 连续，$g(x_0)=u_0$，又 $y=f(u)$ 在点 $u_0$ 连续，则复合函数 $y=f\circ g(x)$ 在点 $x_0$ 连续 (2pts)
31. 证明：一切初等函数在其定义区间上连续 (6pts)
32. 证明：设 $u(x),v(x),w(x)$ 在 $x_0$ 的某个去心邻域 $U$ 上有定义，且 $\lim\limits_{x\rightarrow x_0} \dfrac{v(x)}{w(x)} = 1$（即 $v(x) \sim w(x)\ (x\rightarrow x_0)$），那么：
    1. 当 $\lim\limits_{x\rightarrow x_0} u(x)w(x) = A$ 时，$\lim\limits_{x\rightarrow x_0} u(x)v(x) = A$
    2. 当 $\lim\limits_{x\rightarrow x_0} \dfrac{u(x)}{v(x)} = A$ 时，$\lim\limits_{x\rightarrow x_0} \dfrac{u(x)}{v(x)} = A$
	(4pts)
33. 对于**闭区间上的连续函数**，证明如下定理：
    1. **有界性定理**：若函数 $f(x)$ 在闭区间 $[a,b]$ 上连续，则它在 $[a,b]$ 上有界。
    2. **最值定理**：若函数 $f(x)$ 在闭区间 $[a,b]$ 上连续，则它在 $[a,b]$ 上必能取到最大值与最小值，即存在 $\xi,\eta \in [a,b]$，对于一切 $x \in [a,b]$，成立 $f(\xi) \le f(x) \le f(\eta)$
    3. **零点存在定理**：若函数 $f(x)$ 在闭区间 $[a,b]$ 连续，且 $f(a)f(b)<0$，则一定存在 $\xi \in (a,b)$，使 $f(\xi) = 0$
    4. **中间值定理**：若函数 $f(x)$ 在闭区间 $[a,b]$ 上连续，则它一定能取到最大值 $M = \max \{f(x) \mid x \in [a,b]\}$ 和最小值 $m = \min \{f(x) \mid x \in [a,b] \}$ 之间的任何一个值。
      (12pts)
34. 证明：设函数 $f(x)$ 在区间 $X$ 上定义，则 $f(x)$ 在 $X$ 上一致连续 $\iff$ 对任何点列 $\{x_n'\}\ (x_n' \in X)$ 和 $\{x_n''\}\ (x_n'' \in X)$，只要满足 $\lim\limits_{n\rightarrow \infty} (x_n' - x_n'') = 0$，就成立 $\lim\limits_{n\rightarrow \infty}(f(x_n') - f_(x_n'')) = 0$ (2pts)
35. 证明 **Cantor 定理**：若函数 $f(x)$ 在闭区间 $[a,b]$ 上连续，则它在 $[a,b]$ 上一致连续 (3pts)
36. 证明：函数 $f(x)$ 在有限开区间 $(a,b)$ 连续，则 $f(x)$ 在 $(a,b)$ 上一致连续 $\iff$ $f(a+),\ f(b-)$ 存在 (1pts)
