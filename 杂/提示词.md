# 课程提示词
1. 多举例子，但要让读者清楚哪些段落是在举例子，哪些是在讲知识，不应混淆，不应无任何征兆与提示直接举例子。
2. 任何公式与结论，如果需要推导，则一定一步一步推导，禁止跳步和倒装。如果不需要推到，那就不应有任何推导的过程。
3. 要有理解过程的铺垫，宁可多写一些字，也要让初学者能够快速学懂，必要时应放一些图片来辅助理解。
4. 一些本应由数学表达承担的定义和推理，不应被自然语言替代。
