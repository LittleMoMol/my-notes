# 第 2 题
- *题目*：描述Python程序的三种执行方式的特点和区别。
- *解答* 
	交互式、脚本式、集成开发环境
	交互式：win+r 输入 cmd，在终端中输入 python 即可进行 python 代码编写，特点是你写一句它输出一句，适合较短的代码
	脚本式：可以在记事本等软件中写代码，再用 python 解释器运行，但是在记事本中写代码还是很不方便的
	集成开发环境：如 vscode 等，给你很好的文本编辑环境和编译命令，使用起来很方便，适合项目开发
