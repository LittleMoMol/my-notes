# 第 4 题思路
对 $s$ 做数学归纳法
$s=1$ 显然成立
假设 $s=k$ 时结论成立，讨论 $f_{k+1}(\boldsymbol\alpha)$ 是否为零
若不为零，命题得证
若为零，构造一个新的 $\boldsymbol\beta$ 使 $f_{k+1}(\boldsymbol\beta)$ 不为零，然后通过 $\boldsymbol\alpha,  \boldsymbol\beta$ 组合出一个新向量使得满足题意

# 第 5 题思路
第 4 题的结论题
**关键点**：$\boldsymbol\alpha_i^{**}\in(V^*)^*$、$\boldsymbol\alpha_i^{**}(f) = f(\boldsymbol\alpha_i)$ 
由第四题结论，应用于其对偶空间上
存在 $f \in V^*$ 使得 $\boldsymbol\alpha_i^{**}(f)\not=0$ 
即 $f(\boldsymbol\alpha_i)\not=0\ (i=1,2,\cdots,n)$ 

# 第 7 题思路
### 第一问
用线性函数定义验证即可
### 第二问
设该映射为 $\varphi$ 
三步走：单射、满射、线性映射
**单射** 
即证当 $\varphi(\boldsymbol\alpha) = \varphi(\boldsymbol\beta)$ 时有 $\boldsymbol\alpha = \boldsymbol\beta$ 
翻译已知：$\forall\ \boldsymbol\gamma\in V$，有 $(\boldsymbol\alpha, \boldsymbol\gamma) = (\boldsymbol\beta, \boldsymbol\gamma)$ 
翻译求证：$(\boldsymbol\alpha - \boldsymbol\beta, \boldsymbol\alpha - \boldsymbol\beta) = 0$ 
构建桥梁即可
**满射** 
即证对于任意的 $f \in V^*$，总存在 $\boldsymbol\alpha\in V$ 使得 $\varphi(\boldsymbol\alpha) = f$ 
设出 $V$ 的基和其对偶基（即 $V^*$ 中的基）
令任意的 $f = l_1f_1 + \cdots + l_nf_n$，再构造 $\boldsymbol\alpha = l_1\boldsymbol\varepsilon_1 + \cdots + l_n\boldsymbol\varepsilon_n$ 
再证明 $\varphi(\boldsymbol\alpha)(\boldsymbol\varepsilon_i) = f(\boldsymbol\varepsilon_i)$ 就可得到 $\varphi(\boldsymbol\alpha) = f$ 
**线性映射** 
证明 $\varphi(\boldsymbol\alpha + \boldsymbol\beta)(\boldsymbol\gamma) = [\varphi(\boldsymbol\alpha) + \varphi(\boldsymbol\beta)](\boldsymbol\gamma)$ 和 $\varphi(k\boldsymbol\alpha) = k\varphi(\boldsymbol\alpha)$ 即可
综上证毕！

# 第 8 题思路
### 第一问
只需证明 $f\mathscr A(\boldsymbol\alpha + \boldsymbol\beta) = f\mathscr A\boldsymbol\alpha + f\mathscr A\boldsymbol\beta$ 和 $f\mathscr A(k\boldsymbol\alpha) = kf\mathscr A\boldsymbol\alpha$ 
### 第二问
$\mathscr A^*$ 已经是变换了，若证明其是线性的，只需证明 $\mathscr A^*(f+g) = \mathscr A^*f + \mathscr A^*g$ 和 $\mathscr A^*(kf) = k\mathscr A^* f$ 
即证明对任意 $\boldsymbol\alpha \in V$ 有 $\mathscr A^*(f+g)(\boldsymbol\alpha) = (\mathscr A^*f + \mathscr A^*g)(\boldsymbol\alpha)$ 和 $(\mathscr A^*(kf))(\boldsymbol\alpha) = k(\mathscr A^* f)(\boldsymbol\alpha)$ 
用 $\mathscr A^*$ 定义得到的性质 $\mathscr A^* f = f\mathscr A$ 来证明就行
### 第三问
即证 $\mathscr A^* (f_1, f_2, \cdots, f_n) = (f_1, f_2, \cdots, f_n) \boldsymbol A'$，只要求 $\mathscr A^* f_i$ 用 $f_i$ 和 $a_{ij}$ 表示就行
而 $\mathscr A^* f_i = f_i\mathscr A$（**关键点**），故转向求 $f_i\mathscr A$ 
发现 $f_i\mathscr A(\boldsymbol\varepsilon_1, \cdots, \boldsymbol\varepsilon_n) = (f_i(\boldsymbol\varepsilon_1), \cdots, f_i(\boldsymbol\varepsilon_n))\boldsymbol A = (a_{i1}, \cdots, a_{in})$ 
故 $(\mathscr A^* f_i)(\boldsymbol\varepsilon_j) = \sum\limits_{l=1}^n a_{il} f_l(\boldsymbol\varepsilon_j)$，故 $\mathscr A^* f_i = (f_1, \cdots, f_n) \begin{pmatrix} a_{i1} \\ \vdots \\ a_{in} \end{pmatrix}$ 
合起来就是 $\mathscr A^* (f_1, f_2, \cdots, f_n) = (f_1, f_2, \cdots, f_n) \boldsymbol A'$ 

# 第 9 题思路
### 第一问
由于 $f_i(\boldsymbol 0) = 0\ (1\le i \le k)$，故 $W$ 非空
再证明对任意 $\boldsymbol\alpha, \boldsymbol\beta$ 有 $\boldsymbol\alpha + \boldsymbol\beta \in W$ 和 $k\boldsymbol\alpha \in W$ 即可
### 第二问
纯纯构造题，难的嘞
发现零化子空间是依赖于线性函数的，所以需要构造
设 $V_1$ 是 $V$ 的任意一个子空间，接下来会构造一组线性函数使得 $V_1$ 是这些线性函数的零化子空间
**基扩充**：去 $V_1$ 的基 $\boldsymbol\varepsilon_1, \cdots, \boldsymbol\varepsilon_r$，再扩充为 $V$ 的一组基 $\boldsymbol\varepsilon_1, \cdots, \boldsymbol\varepsilon_r, \boldsymbol\varepsilon_{r+1}, \cdots, \boldsymbol\varepsilon_n$ 
**构造符合条件的线性函数**：定理 $g_i\in V^*$ 且 $g_i(\boldsymbol\varepsilon_j) = \delta_{ij}\ (i=r+1, \cdots, n;\ j=1,\cdots,n)$，其中 $\delta_{ij} = \begin{cases} 1 & i=j \\ 0 & i\not=j \end{cases}$ 
**验证**：只需验证 $V_1 = \{\boldsymbol\alpha \in V \mid g_{r+1}(\boldsymbol\alpha) = \cdots = g_n(\boldsymbol\alpha) = 0\}$，验证方法就是把 $\boldsymbol\alpha$ 用基表示出来，然后使用性质 $g_i(l_1\boldsymbol\varepsilon_1 + \cdots + l_n\boldsymbol\varepsilon_n) = l_i\ (i=r+1, \cdots, n)$ 计算即可（分类 $\boldsymbol\alpha \in V_1$ 和 $\boldsymbol\alpha \not\in V_1$）

# 第 12 题思路
### 第一问
翻译**对称**：存在 $V$ 的一组基 $\boldsymbol\varepsilon_1,\cdots, \boldsymbol\varepsilon_n$，对任意 $\boldsymbol\alpha = \sum\limits_{i=1}^n x_i\boldsymbol\varepsilon_i,\ \boldsymbol\beta = \sum\limits_{i=1}^n y_i\boldsymbol\varepsilon_i$ 有 $f(\boldsymbol\alpha, \boldsymbol\beta) = x_1y_1 + \cdots + x_ry_r\ (0\le r\le n)$ 
由于题目考虑的是两个相同向量作内积的形式，故考虑 $f(\boldsymbol\alpha, \boldsymbol\alpha) = x_1^2 + \cdots + x_r^2$ 的形式
剩下的就是分类讨论 + 小构造：
$r=0$ 时随便 $\boldsymbol\xi$ 怎么取都满足题意
$r=1$ 时取 $\boldsymbol\xi = \boldsymbol\varepsilon_2$ 
$r>1$ 时取 $\boldsymbol\xi = i\boldsymbol\varepsilon_1 + \boldsymbol\varepsilon_2$ 
### 第二问
构造题
翻译**非退化**：对第一问 $\boldsymbol\alpha,\boldsymbol\beta$ 有 $f(\boldsymbol\alpha, \boldsymbol\beta) = x_1y_1 + \cdots + x_ny_n$ 
构造 $\boldsymbol\xi = \dfrac i{\sqrt 2}\boldsymbol\varepsilon_1 + \dfrac 1{\sqrt 2}\boldsymbol\varepsilon_2,\ \boldsymbol\eta = \dfrac{-i}{\sqrt 2}\boldsymbol\varepsilon_1 + \dfrac 1{\sqrt 2}\boldsymbol\varepsilon_2$ 就满足题意

# 第 14 题思路
- 若 $f$ 限制到 $K$ 上是退化的，则 $\boldsymbol\eta \in K$ 与一切 $\boldsymbol\alpha \in K$ 正交，且 $\boldsymbol\eta \in K + L(\boldsymbol\xi)$，满足题意
- 若 $f$ 限制到 $K$ 上是非退化的且 $f$ 在 $V$ 上对称
	- 则 $f$ 限制到 $K$ 上是对称的、非退化的双线性函数
	- **翻译**：存在 $K$ 的一组基 $\boldsymbol\varepsilon_1, \cdots, \boldsymbol\varepsilon_t$ 使得 $f$ 在此基下度量矩阵为对角矩阵 $\begin{pmatrix} d_1 \\ & d_2 \\ && \ddots \\ &&& d_t \end{pmatrix}$，且 $d_1, \cdots, d_t$ 皆不为零，即 $f(\boldsymbol\varepsilon_i, \boldsymbol\varepsilon_j) = \begin{cases} d_i & i=j \\ 0 & i\not=j \end{cases}\ (1\le i,j \le t)$ 
	- **构造**：设 $f(\boldsymbol\xi, \boldsymbol\varepsilon_i) = c_i\ (i=1,2,\cdots, t)$，构造 $\boldsymbol\eta = \boldsymbol\xi - \dfrac{c_1}{d_1}\boldsymbol\varepsilon_1 - \dfrac{c_2}{d_2}\boldsymbol\varepsilon_2 - \cdots - \dfrac{c_t}{d_t}\boldsymbol\varepsilon_t \in L(\boldsymbol\xi) + K$ 
	- **验证 $\boldsymbol\eta$ 符合题意**：即对任意 $\boldsymbol\alpha = m_1\boldsymbol\varepsilon_1 + \cdots m_t\boldsymbol\varepsilon_t \in K$ 都有 $f(\boldsymbol\eta, \boldsymbol\alpha) = 0$ 
- 若 $f$ 限制到 $K$ 上是非退化的且 $f$ 在 $V$ 上反称
	- 则 $f$ 限制到 $K$ 上是反称的、非退化的双线性函数
	- **翻译**：存在 $K$ 的一组基 $\boldsymbol\varepsilon_1, \boldsymbol\varepsilon_{-1}, \cdots, \boldsymbol\varepsilon_r, \boldsymbol\varepsilon_{-r}$ 使得 $f(\boldsymbol\varepsilon_i, \boldsymbol\varepsilon_j) = \begin{cases} 1 & i+j=0 \\ 0 & i+j\not=0 \end{cases}\ (1\le i \le r, -r\le j \le r)$ 
	- **构造**：设 $f(\boldsymbol\xi, \boldsymbol\varepsilon_i) = c_i\ (i=\pm 1, \cdots, \pm r)$，构造 $\boldsymbol\eta = \boldsymbol\xi - \boldsymbol\alpha \in L(\boldsymbol\xi) + K$，其中 $\boldsymbol\alpha = \sum\limits_{i=1}^r c_i\boldsymbol\varepsilon_{-i} - \sum\limits_{i=-1}^{-r} c_i\boldsymbol\varepsilon_{-i} \in K$ 
	- **验证 $\boldsymbol\eta$ 符合题意**：即对任意 $\boldsymbol\beta = \sum\limits_{i=-r}^r l_i\boldsymbol\varepsilon_i \in K$ 都有 $f(\boldsymbol\eta, \boldsymbol\beta) = 0$ 


# 第 15 题思路
### 第一问
只需证明对于任意 $\boldsymbol\alpha, \boldsymbol\beta \in K^\perp$ 和任意 $k \in P$ 有：$\boldsymbol\alpha + \boldsymbol\beta \in K^\perp,\ k\boldsymbol\alpha \in K^\perp$ 
### 第二问
- **翻译**：只需证明 $K + K^\perp \subset V$ 与 $V \subset K + K^\perp$，第一个显然成立，故只需证 $V\subset K + K^\perp$ 
- 若 $K=V$ 则证毕！
- 若 $K\not=V$ 
	- $K \cap K^\perp = \{\boldsymbol 0\}$ $\Rightarrow$ $f$ 在 $V$ 上是非退化的
	- 由于 $K$ 是真子空间（即 $V \backslash K$ 非空），由上一题结论可知：
		- 对任意 $\boldsymbol\xi \in V\backslash K$，有 $\boldsymbol\alpha \in K$ 使得对任意 $\boldsymbol\beta\in K$ 有 $f(\boldsymbol\xi - \boldsymbol\alpha,\boldsymbol\beta) = 0$，故 $\boldsymbol\xi - \boldsymbol\alpha \in K^\perp$，故 $\boldsymbol\xi \in K + K^\perp$ 
		- 对任意 $\boldsymbol\xi \in K$，显然 $\boldsymbol\xi \in K + K^\perp$ 
- 综上对任意 $\boldsymbol\xi \in V$ 都有 $\boldsymbol\xi \in K+K^\perp$，故 $V \subset K + K^\perp$，故 $V = K + K^\perp$ 
# 第 16 题思路
### 第一问
$f$ 在 $K$ 上非退化 $\Rightarrow$ $K$ 中没有非零向量与 $K$ 中所有元素都正交 $\Rightarrow$ $K\cap K^\perp = \{\boldsymbol0\}$ $\Rightarrow$ $V = K \oplus K^\perp$ 
### 第二问
**关键**：将双线性函数
设 $K$ 和 $K^\perp$ 分别的基，合起来就是 $V$ 的基
表示 $f$ 在 $K$ 的基下的度量矩阵 $\boldsymbol A$，$f$ 在 $K^\perp$ 的基下的度量矩阵 $\boldsymbol B$ 
则 $f$ 在 $V$ 的基下的度量矩阵为 $\boldsymbol C = \begin{pmatrix} \boldsymbol A & \boldsymbol O \\ \boldsymbol O & \boldsymbol B \end{pmatrix}$ 
由于 $\boldsymbol A$ 是非退化的，那么 $\boldsymbol C$ 非退化 $\iff$ $\boldsymbol B$ 非退化
故 $f$ 在 $V$ 上非退化 $\iff$ $f$ 在 $K^\perp$ 上非退化


# 第 17 题思路
### 第一问
设该映射为 $\varphi$，即 $\varphi(\boldsymbol\alpha) = \boldsymbol\alpha^*$ 
证明 $\varphi$ 为同构映射，三步走：线性映射、单射、满射
- **线性映射**：即证 $\varphi(\boldsymbol\alpha + \boldsymbol\beta) = \varphi(\boldsymbol\alpha) + \varphi(\boldsymbol\beta)$ 和 $\varphi(k\boldsymbol\alpha) = k\varphi(\boldsymbol\alpha)$；即证 $\forall\ \boldsymbol\alpha, \boldsymbol\beta, \boldsymbol\gamma \in V$ 都有 $(\boldsymbol\alpha + \boldsymbol\beta)^*(\boldsymbol\gamma) = (\boldsymbol\alpha^* + \boldsymbol\beta^*)(\boldsymbol\gamma)$ 和 $(k\boldsymbol\alpha)^*(\boldsymbol\gamma) = k\boldsymbol\alpha^*(\boldsymbol\gamma)$。代入验证即可
- **满射**：即证对任意 $\boldsymbol\alpha^* \in V^*$，都有 $\boldsymbol\alpha\in V$ 使得 $\varphi(\boldsymbol\alpha) = \boldsymbol\alpha^*$ 
	- **设基**：由于 $f$ 非退化，则有 $V$ 的基 $\boldsymbol\varepsilon_1, \cdots, \boldsymbol\varepsilon_n$ 使 $f$ 的度量矩阵是对角阵 $\begin{pmatrix} d_1 \\ & d_2 \\ && \ddots \\ &&& d_n \end{pmatrix}$ 且 $d_i$ 均不为零
	- **设对应元**：设这组基通过 $\varphi$ 映射在 $V^*$ 中的对应元为 $\boldsymbol\varepsilon_1^*, \cdots, \boldsymbol\varepsilon_n^*$，则 $\boldsymbol\varepsilon_i^*(\boldsymbol\varepsilon_j) = f(\boldsymbol\varepsilon_i, \boldsymbol\varepsilon_j) = d_i\delta_{ij}$ 
	- **证明对应元可以充当一组基**：即证明线性无关，若 $k_1\boldsymbol\varepsilon_1^* + \cdots + k_n\boldsymbol\varepsilon_n^* = \boldsymbol0$，则 $\forall \ i$ 有 $(k_1\boldsymbol\varepsilon_1^* + \cdots + k_n\boldsymbol\varepsilon_n^*)(\boldsymbol\varepsilon_i) = 0$，故 $k_i\boldsymbol\varepsilon_i^* (\boldsymbol\varepsilon_i) = k_id_i=0$，由 $d_i\not=0$ 可知 $k_i=0$，故线性无关，故是 $V^*$ 的基
	- **基表示**：对任意 $\boldsymbol\alpha^* = \lambda_1\boldsymbol\varepsilon_1^* + \cdots + \lambda_n\boldsymbol\varepsilon_n^* \in V^*$ 都有 $\boldsymbol\alpha = \lambda_1\boldsymbol\varepsilon_1 + \cdots + \lambda_n\boldsymbol\varepsilon_n$ 使得 $\varphi(\boldsymbol\alpha) = \boldsymbol\alpha^*$ 
- **单射**：即证 $\boldsymbol 0$ 表示唯一
	- 设 $\varphi(k_1\boldsymbol\varepsilon_1 + \cdots + k_n\boldsymbol\varepsilon_n) = \boldsymbol 0$，则 $k_1\boldsymbol\varepsilon_1^* + \cdots + k_n\boldsymbol\varepsilon_n^* = \boldsymbol 0$，则 $k_1 = \cdots = k_n = 0$，则 $k_1\boldsymbol\varepsilon_1 + \cdots + k_n\boldsymbol\varepsilon_n = \boldsymbol 0$，故只有 $\boldsymbol0$ 满足 $\varphi(\boldsymbol0) = \boldsymbol 0$，故 $\boldsymbol 0$ 表示唯一
### 第二问
- **翻译**：$f(\boldsymbol\varepsilon_i, \boldsymbol\varepsilon_j') = \delta_{ij}$ $\iff$ $f(\boldsymbol\varepsilon_j', \boldsymbol\varepsilon_i) = \delta_{ij}$ $\iff$ $(\boldsymbol\varepsilon_j')^* (\boldsymbol\varepsilon_i) = \delta_{ij}$ $\iff$ $\varphi(\boldsymbol\varepsilon_j')(\boldsymbol\varepsilon_i) = \delta_{ij}$ 
- **引入对偶基**：设 $V$ 的一组基 $\boldsymbol\varepsilon_1, \cdots, \boldsymbol\varepsilon_n$，设 $f_1, \cdots, f_n$ 是这组基的对偶基，有 $f_i(\boldsymbol\varepsilon_j) = \delta_{ij}$ 
- **构造桥梁**：由于 $\varphi$ 是 $V$ 到 $V^*$ 的同构，令 $\boldsymbol\varepsilon_1', \cdots, \boldsymbol\varepsilon_n' \in V$ 使得 $\varphi(\varepsilon_i') = f_i$，则 $\varphi(\boldsymbol\varepsilon_j')(\boldsymbol\varepsilon_i) = \delta_{ij}$ 符合题意
- **验证 $\boldsymbol\varepsilon_1', \cdots, \boldsymbol\varepsilon_n'$ 是一组基**：由于 $\varphi$ 是同构，且 $f_1, \cdots, f_n$ 是 $V^*$ 的基，故 $\varphi^{-1}(f_1), \cdots, \varphi^{-1}(f_n)$ 也是 $V$ 的基，验证完毕
- **唯一性**：因为 $\varphi$ 是单射
### 第三问
- **翻译**：$\boldsymbol\eta_i = \boldsymbol\eta_i'$ $\iff$ $f(\boldsymbol\eta_i, \boldsymbol\eta_j) = \delta_{ij}$ 
- **设基**：由于 $f$ 非退化，则有 $V$ 的基 $\boldsymbol\varepsilon_1, \cdots, \boldsymbol\varepsilon_n$ 使 $f$ 的度量矩阵是对角阵 $\begin{pmatrix} d_1 \\ & d_2 \\ && \ddots \\ &&& d_n \end{pmatrix}$ 且 $d_i$ 均不为零。则 $f(\boldsymbol\varepsilon_i, \boldsymbol\varepsilon_j) = d_i\delta_{ij}$ 
- **构造**：令 $\boldsymbol\eta_i = \dfrac 1{\sqrt{d_i}}\boldsymbol\varepsilon_i$，则 $f(\boldsymbol\eta_i, \boldsymbol\eta_j) = \delta_{ij}$
