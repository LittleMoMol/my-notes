# 1 计算科学范式
## 1-1 三位一体：建模、仿真与分析
- **建模**：将实际问题进行合理抽象的过程，就是**建模** 
- *模型的选择*：离散模型 or 连续模型？
	- *连续模型*、**ODE 模型**：常用平滑的曲线来描述，这引出了经典的**常微分方程 (ODE) ​模型** 
	- *离散模型*、**基于智能体的模型**：这种观点引出了另一种完全不同的建模范式：**​基于智能体的模型** (Agent-Based Model, **ABM**)。在这个模型中，我们模拟每一个“智能体”的行为规则，例如以一定的概率出生、死亡或捕食。整个系统的宏观行为，是从大量个体互动中涌现出来的。
	- *数量宏大时*：两种模型可能会给出相似的预测
	- *数量很少时*：比如在一个孤立的岛屿上只有几只狐狸和几十只兔子，情况就大不相同了。在 ABM 中，由于纯粹的随机性（某只关键的母狐狸可能“运气不好”没抓到兔子而饿死），整个捕食者种群可能会意外灭绝；而 ODE 模型，因为它本质上是确定性的、连续的，完全捕捉不到这种可能性。
	- *模型选择的重要性*：模型的选择本身就是一种科学假设，它可能从根本上改变我们对系统命运 (例如物种是灭绝还是持续存在) 的预测。
- **仿真**：主要研究如何在计算机中模拟现实情况
- **确认**：这个选择过程，即判断我们的数学模型是否充分代表了真实世界，被称为**确认** (Validation)
	- 这是一个充满挑战且永无止境的过程，它要求我们不断地将模型预测与实验数据进行比较
## 1-2 离散化的方法
- **离散化**：将连续的物理定律翻译成计算机能理解的离散语言。这个过程就是**离散化** (Discretization)，也就是“仿真”的核心。
- *几种离散化的方法* 
	- **有限差分法**（Finite Difference Method, **FD**）：这是最直观的方法，它将空间划分成规整的网格，然后用网格点上值的差异来近似导数。它简单直接，但在处理复杂几何形状（比如一个飞机的机翼）时会非常笨拙。
	- **有限元法**（Finite Element Method, **FEM**）：这种方法更加灵活，它将复杂的区域分解成许多小的、简单的几何单元（如三角形或四边形），然后在每个单元上用简单的函数（如线性函数）来近似解。它在处理复杂几何问题时非常强大，广泛应用于结构力学等领域。
	- **有限体积法**（Finite Volume Method, **FV**）：这种方法的美妙之处在于它从物理学的积分形式守恒律​出发。它将区域划分为一个个“控制体积”，并严格要求进出一个体积的通量必须与该体积内物理量的变化相平衡。这种方法天生就能保证物理量的局部守恒​。对于流体力学和许多其他由守恒律主导的问题，有限体积法是一种极其自然和强大的语言。
- *方法的选取*：选择哪种方法，取决于问题的几何形状、物理定律的性质以及我们对解的性质的要求（例如，是否必须严格守恒）。这个选择深刻地影响着我们仿真的准确性和可靠性。
## 1-3 验证的必要
- **验证**：编写代码实现一个复杂的数值方案后，请问代码真的在求解我想要它求解的那个数学模型吗？还是代码里隐藏着一个 bug，导致我实际上在求解一个完全不同的、无意义的方程？**验证**（Verification）​就是在回答这个问题
- **正确**：由于离散化，我们的答案永远不会是完全精确的，它总会包含截断误差​。然而，一个**正确**的程序，其误差行为应该是可预测的。
	- *例子*：对于一个设计为“二阶精度”的方案，当我们将网格尺寸 $\Delta x$ 减半时，误差应该减小到原来的四分之一
	- *注意*：有时候，即使是经过验证的算法，在更级的优化（如**自适应网格加密**（**AMR**)）下也可能出错。AMR 允许我们在需要高分辨率的地方（例如冲击波附近）使用更精细的网格，从而节省计算资源。但这种方法可能会在粗细网格的交界处不经意地破坏守恒律，导致质量或能量的“泄漏”。
- 在计算科学中，每一个优化都必须经过严格的审视，以确保它没有违背底层的物理原理。
## 1-4 验证方法——构造“人造问题”
对于复杂问题，我们通常没有“标准答案”可以参考。那我们就自己创造一个！这就是**制造解方法**（Method of Manufactured Solutions, **MMS**）​的思想。
思路就是：我们自己给出一个输出，然后反推出这个输出对应的输入，再用我们的代码去解决这个“人造问题”（即构造的输入数据），最后比较“人造问题”计算结果与我们构造的输出
## 1-5 验证方法——物理学本身
- 对于那些极其复杂、无法使用制造解的真实科学问题，我们还可以借助物理学本身进行验证
- **守恒律**：据诺特定理，物理世界的每一个连续对称性都对应一个**守恒律​** 
	- 时间平移对称性对应​能量守恒
	- 空间平移对称性对应动量守恒​
	- 旋转对称性对应角动量守恒​
	- 如果我们的模型描述的是一个封闭的、孤立的系统，那么这些量在我们的仿真中也必须是守恒的
- *验证方法* 
	我们可以在仿真过程中持续监控这些理论上的不变量。当然，由于数值误差，它们不会是绝对不变的。但我们可以区分两种不同性质的误差：
	**良性误差**​：源于浮点运算的随机​舍入误差。它像一个醉汉的随机游走，虽然每一步都在晃动，但离起点的距离增长得很慢，其累积效应大致与步数的平方根 $\sqrt K$ ​成正比
	**恶性误差**​：源于代码中的 bug 或算法本身的缺陷。它会产生系统性漂移​，像一艘方向舵卡住的船，稳定地偏离航线。其累积效应与步数 $K$ 成线性关系。
## 1-6 可复现性
- **可复现性**：科学的基石之一是**可复现性**​，如果我重复你的实验，我应该得到相同的结果。
- 要实现真正的可复现性，仅仅分享代码是远远不够的，可能还需要：
	- **数据指纹**​：你用来运行代码的输入数据和我的一样吗？哪怕一个字节的差异都可能导致结果天差地别。解决方案是使用像SHA-256这样的​**加密哈希函数​**为数据文件创建一个唯一的“数字指纹”。
	- **随机种子**​：如果你的模型包含随机性（比如前面提到的 ABM 模型），你需要明确指定所使用的​伪随机数生成器的种子​。同样的种子，产生同样的“随机”序列。
	- **环境快照**​：你用的 Python 是 3.8 还是 3.9？你的 NumPy 库是什么版本？这些细微的差别有时会导致数值结果的差异。一个可复现的工作流必须记录下完整的软件环境。

**模型** 
考虑一个具有 $N$ 个点的一维周期性离散网格上的热方程 (也成为扩散方程)，其连续形式为 $u_t = D u_{xx}$，其中 $u$ 表示一个标量场，$D$ 是扩散系数。使用标准的显式前向欧拉有限差分时间推进法，配合对称三点模板、周期性边界条件和无量纲化参数。将离散状态定义为一个向量 $u\in \mathbb R^N$，并执行一个时间步长
$$
u_i^{\text{new}} = u_i^{\text{old}} + \alpha( u_{i-1}^{\text{old}} - 2u_i^{\text{old}} + u_{i+1}^{\text{old}} )
$$
对所有索引 $i\in \{ 0, 1, \cdots, N-1 \}$ 进行计算，索引采用周期性方式，即 $u_{-1} \equiv u_{N-1}$ 和 $u_N \equiv u_0$。标量 $\alpha \ge 0$ 编码了无量纲化的时间步长和扩散常数。该模型是计算科学中用于研究守恒、对称性和单调性属性的典型实例。

**基本基础和不变量** 
以下不变量源于核心的物理和数学原理，必须用于构建基于属性的测试：
- 空间反射下的对称等变性：定义离散反射算子 $\mathcal R$ 为 $(\mathcal R u)_i = u_{N-1-i}$。由于模板是对称的，因此对反射后的状态执行步进，然后发射结果，这两个操作应该可以交换顺序：$\text{step}(\mathcal Ru) = \mathcal R(\text{step}(u))$ 
- 值域的单调性：对于 $0\le \alpha \le \frac 12$，更新是 $u_{i-1}, u_i, u_{i+1}$ 的一个非负凸组合；因此，离散值域 $R(u) = \max_i u_i - \min_i u_i$ 在步进操作下应该是非增的（即 $R(u^{\text{new}}) \le R(u^{\text{old}})$ ）。这捕捉了扩散的平滑特性。

**测试策略** 
通过生成随机状态 $u$ 并自动检查上述不变量来实施基于属性的测试。对于数值验证，采用容差 $\varepsilon = 10^{-10}$ 并如下定义违规：
- 守恒违规：如果 $| \sum_{i} u_i^{\text{new}} - \sum_i u_i^{\text{old}}| > \varepsilon$ 
- 对称等变性违规：如果 $\max_i | (\text{step}(\mathcal Ru))_i - (\mathcal R (\text{step}(u)))_i | > \varepsilon$ 
 - 单调性违规：如果 $R(u^{\text{new}}) - R(u^{\text{old}}) > \varepsilon$

#### 解答思路
**对于周期性边界的情形** 
$u_i$ 的邻居 $u_{i-1} = u_{(i-1)\pmod N}$、$u_{i+1} = u_{(i+1) \pmod N}$ 
所以 $u_i^{\text{new}} = u_i^{\text{old}} + \alpha( u_{i-1}^{\text{old}} - 2u_i^{\text{old}} + u_{i+1}^{\text{old}} )$ 可用 `np.roll` 函数对 $u$ 进行循环位移，进而高效实现递推式

**对于零边界的情形** 
此时不能使用 `np.roll` 直接实现
我们认为 $u_0$ 的左邻居 $u_{-1} = 0$，以及 $u_{N-1}$ 的右邻居 $u_{N} = 0$，这样我们直接套用公式可以得到：
- 对于内部点 $i\in \{ 1, \cdots, N-2 \}$ 有 $u_i^{\text{new}} = u_i^{\text{old}} + \alpha( u_{i-1}^{\text{old}} - 2u_i^{\text{old}} + u_{i+1}^{\text{old}} )$ 
- 对于 $u_0$ 有 $u_0^{\text{new}} = u_0^{\text{old}} + \alpha(0 - 2u_0^{\text{old}} + u_{1}^{\text{old}} )$ 
- 对于 $u_{N-1}$ 有 $u_{N-1}^{\text{new}} = u_{N-1}^{\text{old}} + \alpha( u_{N-2}^{\text{old}} - 2 u_{N-1}^{\text{old}} + 0)$ 

最后注意特判 $N=1$ 时 $u_0, u_{N-1}$ 为同一点，此时的递推式应为 $u_0^{\text{new}} = u_0^{\text{old}} + \alpha ( 0 - 2 u_0^{\text{old}} + u_1^{\text{old}} )$ 

**总量守恒的推导** 
对于正确的周期性实现，有：$\sum\limits_{i=0}^{N-1} u_i^{\text{new}} = \sum\limits_{i=0}^{N-1} u_i^{\text{old}} + \alpha \sum\limits_{i=0}^{N-1} (u_{i-1}^{\text{old}} - 2 u_i^{\text{old}} + u_{i+1}^{\text{old}})$ 
最后一项在周期性边界下是一个离散的伸缩求和：$\sum\limits_{i=0}^{N-1} (u_{i-1} - 2u_i + u_{i+1}) = \sum u_{i-1} - 2\sum u_i + \sum u_{i+1} = 0$ 
因此 $\sum\limits_{i=0}^{N-1} u_i^{\text{new}} = \sum\limits_{i=0}^{N-1} u_i^{\text{old}}$，故总和是一个不变量

**空间反射下的对称等变性的推导** 
对于正确的周期性实现，在反射状态 $(\mathcal Ru)$ 上索引 $i$ 处的更新取决于 $u_{N-1-(i-1)}, u_{N-1-i}, u_{N-1-(i+1)}$；在原始状态 $u$ 上索引 $N-1-i$ 处的更新取决于 $u_{N-1-i-1}, u_{N-1-i}, u_{N-1-i+1}$ 
由于递推式中 $u_{i-1}, u_{i+1}$ 前的系数相同，所以这两个操作产生相同的结果

 **值域的单调性的推导** 
 对于 $0\le \alpha \le \frac 12$，更新规则是非负系数的凸组合：$u_i^{\text{new}} = \alpha u_{i-1}^{\text{old}} + (1-2\alpha) u_i^{\text{old}} + \alpha u_{i+1}^{\text{old}}$，其中 $\alpha \ge 0$ 且 $(1-2\alpha) \ge 0$，系数之和为 $1$ 
此属性称为**离散极值原理**，它意味着新值 $u_i^{\text{new}}$ 不会超出其贡献的旧值的范围。全局来看，这意味着 $\min(u^{\text{old}}) \le \min(u^{\text{new}})$ 和 $\max(u^{\text{old}}) \le \max(u^{\text{new}})$。因此，值域 $R(u) = \max_i u_i - \min_i u_i$ 必须是非增的：$R(y^{\text{new}}) \le R(u^{\text{old}})$ 
只要 $0\le \alpha \le \frac 12$，此属性对于正确和错误的实现都成立，因为在错误情况下，边界上的更新规则也构成凸组合
当 $\alpha > \frac 12$ 时，预计此属性不成立，这对应于一个物理上和数值上都不稳定的区域。

 **代码解释补充**
1. `rng = np.random.default_rng(seed)` 用于生成一个随机数生成器对象
	该函数是 NumPy 1.17+ 推荐使用的随机数生成方式，相比旧版 `np.random.rand()` 等函数，它更灵活且性能更好
	`seed`是随机种子，用于保证结果可复现。如果 `seed`固定，每次运行生成的随机数序列相同；如果不传 `seed`，则每次结果不同。
2. `rng.uniform(0, 1, size=n)` 生成一个长度为 `n` 的数组，元素是在 `[0, 1)`区间内均匀分布的随机数。
#### 源代码
```python
import numpy as np

def step_correct(u: np.ndarray, alpha: float) -> np.ndarray:
    '''
    执行一次具有周期边界条件的 1 维热方程的时间步长
    '''
    if u.size == 0:
        return np.array([])
    res_u = u + alpha * (np.roll(u, 1) - 2 * u + np.roll(u, -1))
    return res_u

def step_buggy(u: np.ndarray, alpha: float) -> np.ndarray:
    '''
    执行一次具有周期边界条件的 1 维热方程的时间步长
    '''
    n = u.size
    if n == 0:
        return np.array([])

    u_new = np.copy(u)

    # 对内点进行更新
    if n > 2:
        u_new[1:-1] += alpha * (u[:-2] - 2 * u[1:-1] + u[2:])

    # 对边界点进行更新
    if n >= 2: # 左边界和右边界不是一点
        u_new[0] += alpha * (0 - 2 * u[0] + u[1]) # 左边界
        u_new[n-1] += alpha * (u[n-2] - 2 * u[n-1] + 0) # 右边界
    elif n == 1: # 特判：左右边界是同一个点
        u_new[0] += alpha * (0 - 2 * u[0] + 0)

    return u_new

def solve():
    '''
    主函数
    '''
    test_cases = [
        (64, 0.2, 200, 101, "correct", True),
        (64, 0.49, 200, 102, "correct", True),
        (64, 0.6, 200, 103, "correct", False),
        (64, 0.2, 200, 104, "buggy", True),
        (1, 0.2, 50, 105, "correct", True),
        (32, 0.2, 200, 106, "buggy", False)
    ]
    all_results = []
    epsilon = 1e-10

    for n, alpha, t, seed, mode, include_zero in test_cases:
        # 选择是使用周期性边界的函数还是零边界的函数
        step_func = step_correct if mode == 'correct' else step_buggy

        # 生成随机状态
        rng = np.random.default_rng(seed)
        states = [rng.uniform(0, 1, size=n) for _ in range(t)]
        if include_zero:
            states.append(np.zeros(n))

        # 初始化违规计数
        conservation_violations = 0 # 守恒违规计数
        symmetry_violations = 0 # 对称等变性违规计数
        monotonicity_violations = 0 # 单调性违规计数

        # 对每个状态进行迭代
        for u_old in states:
            if u_old.size == 0:
                continue

            # 进行一次时间步长
            u_new = step_func(u_old, alpha)

            # 检验守恒是否违规
            sum_old = np.sum(u_old)
            sum_new = np.sum(u_new)
            if np.abs(sum_new - sum_old) > epsilon:
                conservation_violations += 1

            # 检验对称等变性是否违规
            u_reflected = u_old[::-1]
            lhs = step_func(u_reflected, alpha)
            rhs = u_new[::-1]
            if np.max(np.abs(lhs - rhs)) > epsilon:
                symmetry_violations += 1
            
            # 检验单调性是否违规
            if u_old.size > 0:
                range_old = np.max(u_old) - np.min(u_old)
                range_new = np.max(u_new) - np.min(u_new)
                if range_new - range_old > epsilon:
                    monotonicity_violations += 1
        all_results.append([conservation_violations, symmetry_violations, monotonicity_violations])
    
    print(f"{all_results}")

solve()
```

**问题** 
计算科学范式的一个核心主题是从建模，经过离散化和算法求解，到验证和解释的严谨过程。

**建模和离散化** 
- 在 $[0, 1] \times [0, 1]$ 上使用泊松方程 $\nabla^2 u = -f$，边界条件为 $u=0$，其中 $f$ 表示位于中心 $(0.5, 0.5)$、总强度为 $S=1$ 的点源的离散近似

- 使用从内部节点泰勒展开导出的二阶中心有限差分法来离散化拉普拉斯算子 $\nabla^2 u$；为内部未知量组装一个稀疏线性系统，并将齐次狄利克雷边界值合并进去。
- 通过将整个源强度 $S$ 分配给由每个坐标向下取整 (floor) 确定的单个最近网络节点，来离散地表示点源。具体来说，令 $I_c = \lfloor 0.5(N_x - 1) \rfloor$ 和 $J_c = \lfloor 0.5(N_y - 1) \rfloor$ 为在完整网络索引 $0, \cdots, N_x - 1$ 和 $0, \cdots, N_y - 1$ 中所选源节点的索引。将此节点映射到内部系统中，并将其右端项设为 $S$。每当 $(0.5, 0.5)$ 不恰好是网络节点时，这个向下取整规则就会引入离散化偏差

**对称性量化** 
- 定义镜像算子 $M$，它将离散场绕中心翻转：$M(u)[i, j] = u[N_x - 1 - i, N_y - 1 - j]$，适用于所有网络索引 $(i, j)$。并计算相对不对称度量 $E_{\text{sym}} = \dfrac{\| u-M(u) \|_2}{\| u \|_2}$，其中 $\| \cdot \|_2$ 表示展平的网格场的欧几里得范数
- 令 $(i_\max, j_\max)$ 为计算出的离散场 $u$ 的最大值索引。计算该最大值与物理中心的偏移量 $d_\max = \sqrt{(i_\max h_x - 0.5)^2 + (j_\max h_y - 0.5)^2}$

3. 一个各项异性但中心对齐的网络：$N_x = 81, N_y = 21$，源强度 $S=1$，基于向下取整的最近节点源布置

对于每个测试案例，求解离散线性系统以获得内部场，将其扩展为包含边界零值的完整 $N_x \times N_y$ 网格，计算 $E_{\text{sym}}$ 和 $d_{\max}$，并报告这两个值

#### 解答思路
**问题概要** 
该问题要求在单位方形矩 $\Omega = [0, 1] \times [0, 1]$ 上，对二位泊松方程 $\nabla^2 u = -f$ 进行数值求解，边界条件为齐次狄利克雷条件 $u=0$ (在 $\partial \Omega$ 上)
问题的核心是研究当源项 $f$ 是位于域中心 $(0.5, 0.5)$、强度为 $S=1$ 的点源的离散近似，网格离散化对数值解对称性的影响。

**离散化** 
该域使用笛卡尔网络进行离散化，在 $x$ 方向有 $N_x$ 个点，在 $y$ 方向有 $N_y$ 个点，网络间距为 $h_x = 1/(N_x - 1)$ 和 $h_y = 1 / (N_y - 1)$。在网络点 $(x_i, y_j) = (ih_x, jh_y)$ 处的解值表示为 $u_{i,j}$，其中 $i\in \{0, \cdots, N_x-1 \}$ 且 $j\in \{ 0, \cdots, N_y-1 \}$ 
拉普拉斯算子指的是二阶微分算子，它在二维直角坐标系中定义为：$\nabla^2 u = \dfrac{\partial^2 u}{\partial x^2} + \dfrac{\partial^2 u}{\partial y^2}$ 
在一个内部网络点 $(i, j)$ (其中 $1\le i\le N_x - 2,\ 1\le j\le N_y-2$) 处，拉普拉斯算子 $\nabla^2u$ 使用二阶中心有限差分进行近似：
$$
\nabla^2u \left|_{(x_i, y_j)} \approx = \dfrac{u_{i-1,j} - 2u_{i,j} + u_{i+1,j}}{h_x^2} + \dfrac{u_{i,j-1} - 2u_{i,j} + u_{i,j+1}}{h_y^2} = -f_{i,j}\right.
$$
未知值为内部点上 $N_{int} = (N_x - 2)(N_y - 2)$ 个 $u_{i,j}$ 的值。通过将这些未知量排列成一个长度为 $N_{int}$ 的向量 $\boldsymbol u$，所有离散化方程构成要给稀疏线性系统 $A \boldsymbol u = \boldsymbol b$，其中矩阵 $A$ 表示离散化的负拉普拉斯算子 $\nabla^2$ 的矩阵表示，向量 $\boldsymbol b$ 表示离散化的源项 $-f$ 
问题规定源 $f$ 是一个总强度为 $S=1$ 的离散点源，其全部贡献都放在单个网络节点 $(I_c, J_c)$ 上，且 $I_c = \lfloor 0.5(N_x - 1) \rfloor$ 和 $J_c = \lfloor 0.5(N_y - 1) \rfloor$。问题又规定，右端向量 $\boldsymbol b$ 中的相应条目被设置为 $S$。这意味着 $\boldsymbol b$ 只有一个元素的值为 $S=1$，其余元素的值均为 $0$，该元素位于对应于网络节点 $(I_c, J_c)$ 的位置

**矩阵求解** 
矩阵 $A$ 是一个稀疏、对称、正定的矩阵，其结构是块三对角的
对于一个大小为 $(N_x - 2) \times (N_y - 2)$ 的内部网络，以及一个从 2D 索引 $(i', j')$ (其中 $i'\in \{0, \cdots, N_x-3\},\ j' \in \{ 0, \cdots, N_y-3 \}$) 到 1D 索引 $k=i'+j'(N_x-2)$ 的行主序映射，矩阵元素定义如下：
- 对角线元素：$A_{k,k} = -\dfrac{2}{h_x^2} - \dfrac{2}{h_y^2}$ 
- $x$ 方向邻居的非对角线元素：$A_{k, k\pm 1} = \dfrac 1{h_x^2}$ 
- $y$ 方向邻居的非对角线元素：$A_{k, k\pm(N_x-2)} = \dfrac 1{h_y^2}$ 

**算法流程** 
对于指定的三个测试案例中的每一个，执行以下算法过程：
1. 定义网格参数 $N_x$ 和 $N_y$，并计算 $h_x$ 和 $h_y$ 
2. 构建大小为 $N_{int} \times N_{int}$ 的稀疏矩阵 $A$，该矩阵表示有限差分算子
3. 构建大小为 $N_{int}$ 的右端项向量 $\boldsymbol b$。这包括找到源节点索引 $(I_c, J_c)$，将它们映射到 1D 内部索引 $k_c$，并设置 $\boldsymbol b_{k_c} = S=1$ 
4. 求解稀疏线性系统 $A\boldsymbol u = \boldsymbol b$ 以找到内部未知量向量 $\boldsymbol u$ 
5. 通过将内部解嵌入到一个零场中，重构大小为 $N_y \times N_x$ 的完整解网络 $u$ 
6. 计算两个量化度量：
	- 相对不对称性，$E_{\text{sym}} = \dfrac{\| u - M(u) \|_2}{\| u \|_2}$，其中 $M(u)$ 是绕中心反射的场：$M(u)_{i,j} = u_{N_x-1-i, N_y-1-j}$ 
	- 最大值与中心的偏移量，$d_\max = \sqrt{(i_\max h_x - 0.5)^2 + (j_\max h_y - 0.5)^2}$，其中 $(i_\max, j_\max)$ 是 $u$ 的最大值的索引

**案例分析** 
- **案例 1**：$N_x=80, N_y=80$，这里 $N_x-1=79$ 是奇数，所以物理中心 $x=0.5$ 落在两条网络线之间。向下取整规则将源放置在索引 $I_c = \lfloor 0.5 \times 79 \rfloor = 39$ 处，对应于 $x_{39} = 39 / 79 \approx 0.4937$。因此，离散源偏离了中心。这破坏了问题的反射对称性，我们预期会得到一个非零的不对称性度量，$E_{\text{sym}}>0$。解的最大值也将从中心移开，所以 $d_\max >0$ 
- **案例 2**：$N_x = 81, N_y = 81$，这里 $N_x-1=80$ 是偶数，源索引为 $I_c = \lfloor 0.5 \times 80 \rfloor = 40$。其物理位置是 $x_{40} = 40/80 = 0.5$。源被精确地放置在对称网格的中心。离散问题保留了连续模型的完全对称性，因此我们预期两个度量都为零 (或接近及其精度)，即 $E_{\text{sym}} \approx 0$ 和 $d_\max \approx 0$ 
- **案例 3**：$N_x=81, N_y=21$，该网格是各向异性的 $(h_x\not=h_y)$，但它关于中心线 $x=0.5$ 和 $y=0.5$ 是反射对称的。与案例 2 类似，源索引为 $I_c = 40$ 和 $J_c = 10$，将源放置在精确的中心 $(0.5, 0.5)$。尽管网格是各向异性的，且解的等值线呈椭圆形，但问题设置仍然是完全对称的。因此，我们再次预期 $E_{\text{sym}} \approx 0$ 和 $d_\max \approx 0$ 

**其他补充** 
通过 $\dfrac{u_{i-1,j} - 2u_{i,j} + u_{i+1,j}}{h_x^2} + \dfrac{u_{i,j-1} - 2u_{i,j} + u_{i,j+1}}{h_y^2}$ 来推导矩阵到底怎么放置
令 `Nix=Nx-2, Niy=Ny-2`，并令 `N_interior = Nix*Niy` 
首先强调我们求解的矩阵每一行都是 $u_{11}, \cdots u_{Nix, 1}, u_{12}, \cdots, u_{Nix,2}, \cdots, u_{1, Niy}, \cdots, u_{Nix, Niy}$ 前的系数
观察项数并分组：
- 中心项 $u_{i,j}$ 向量：前面系数为 $-\dfrac{2}{h_x^2} - \dfrac{2}{h_y^2}$，位置应放置在这个大矩阵的主对角线上
- 左右邻接点 $u_{i-1, j}, u_{i+1, j}$ 向量：前面系数均为 $\dfrac 1{h_x^2}$，向量位置应放置在这个大矩阵主对角线分别向上、下平移 1 个位置的斜线上，分别表示左邻接点和右邻接点。但注意到对于中心点 $u_{Nix, 1}, u_{Nix,2}, \cdots, u_{Nix, Niy}$，它们都没有右邻接点，由于向量从 $0$ 开始存储，所以从 $Nix-1$ 的位置开始每隔 $Nix$ 将对应的右邻接点的值置为 $0$；左邻接点同理。
- 上下邻接点 $u_{i, j-1}, u_{i, j+1}$ 向量：前面系数为 $\dfrac 1{h_y^2}$，向量位置应放置在这个大矩阵的主对角线分别向上、下平移 $Nix$ 个位置的斜线上。但注意到对于中心点 $u_{1,1}, u_{2, 1}, \cdots, u_{Nix, 1}$，它们都没有上邻接点，但由于这些点本身的上邻接点就不会出现在这个矩阵中，所以无需进行其他操作；下邻接点同理

#### 源代码
```python
import numpy as np
from scipy import sparse
from scipy.sparse.linalg import spsolve

def solve_poisson(Nx, Ny, S=1.0):
  '''
  求解单位正方形上带有离散点源的二维泊松方程。
  
  Args:
    Nx (int): x 方向的网格点数。
    Ny (int): y 方向的网格点数。
    S (float): 点源强度。
  
  Returns:
    tuple[float, float] : 包含不对称度量 (Esym) 和最大值偏移量 (dmax) 的元组。
  '''

  # 定义一些变量
  hx = 1.0 / (Nx - 1)
  hy = 1.0 / (Ny - 1)
  Nix = Nx - 2
  Niy = Ny - 2
  N_interior = Nix * Niy

  if N_interior <= 0:
    if Nx == 1 and Ny == 1:
      return 0.0, 0.5
    else:
      return 0.0, np.sqrt((0.5-0.5)**2 + (0.5-0.5)**2)
  
  # 构造稀疏矩阵 A
  # 该矩阵表示 5 点模板有限差分算子
  # 它通过其主对角线和副对角线构建而成
  main_diag = np.full(N_interior, -2.0/hx**2 - 2.0/hy**2)
  x_off_diag = np.full(N_interior-1, 1.0/hx**2)
  x_off_diag[Nix-1::Nix] = 0.0
  y_off_diag = np.full(N_interior - Nix, 1.0/hy**2)

  diagonals = [y_off_diag, x_off_diag, main_diag, x_off_diag, y_off_diag]
  offsets = [-Nix, -1, 0, 1, Nix]
  A = sparse.diags(diagonals, offsets, shape=(N_interior, N_interior), format='csr')

  # 构造右侧向量 b
  b = np.zeros(N_interior)
  Ic = int(np.floor(0.5*(Nx-1)))
  Jc = int(np.floor(0.5*(Ny-1)))
  ic_int = Ic - 1
  jc_int = Jc - 1

  # 检查源是不是在内部节点上
  if 0 <= ic_int < Nix and 0 <= jc_int < Niy:
    k_c = jc_int * Nix + ic_int # 映射为 1D 坐标
    b[k_c] = -S
  
  # 求解线性系统
  u_interior_flat = spsolve(A, b)

  # 重建完整的解网格
  u_full = np.zeros((Ny, Nx))
  u_interior = u_interior_flat.reshape((Niy, Nix))
  u_full[1:-1, 1:-1] = u_interior

  # 计算指标
  # Esym
  u_mirrored = np.flip(u_full)
  norm_u = np.linalg.norm(u_full)
  if norm_u == 0:
    Esym = 0.0
  else:
    norm_diff = np.linalg.norm(u_full - u_mirrored)
    Esym = norm_diff / norm_u
  
  # dmax
  j_max, i_max = np.unravel_index(np.argmax(u_full), u_full.shape)
  x_max = i_max * hx
  y_max = j_max * hy
  dmax = np.sqrt((x_max-0.5)**2 + (y_max-0.5)**2)
  
  return Esym, dmax

def solve():
  '''
  主函数，用于运行测试用例并打印结果
  '''
  # 根据问题陈述定义测试用例
  test_cases = [
    (80, 80),
    (81, 81),
    (81, 21)
  ]

  results = []
  source_strength = 1.0

  for case in test_cases:
    Nx, Ny = case
    Esym, dmax = solve_poisson(Nx, Ny, source_strength)
    results.append([Esym, dmax])
  
  cases_strs = [f"[{res[0]:.6f}, {res[1]:.6f}]" for res in results]
  print(f"[{','.join(cases_strs)}]")
  return

solve()
```

#### 问题描述
科学方法的最后一个支柱是可复现性。在计算科学中，由于编译器、硬件和库的差异，实现跨平台逐比特相同的结果往往是不可能的。本练习将引导您超越确定性的结果比较，建立一个更稳健的统计可复现性框架。您将使用假设检验来正式判断两组模拟结果的分布是否等价，从而将可复现性的概念从“完全相同”提升到“统计上无差异”。

**问题** 
要求您本着计算科学范式的精神，设计一个小型、独立的再现性案例研究。该研究将模拟在不同编译器和标志配置下运行相同的分子动力学模拟，并通过正式检验系综分布的相等性来判断结果是否可再现。
该模拟模型是一个使用速度 Verlet 更新方法积分的一维谐振子。在步长索引 $t$ 处的状态是位置 $x_t$ 和速度 $v_t$。物理参数是质量 $m$ 和刚度 $k$。模拟时间步长是 $\Delta t$。为了模拟编译器和标志的差异，每次更新时，中间算术运算都会四舍五入到指定的小数精度 $p$，并且可以在更新中应用一个微小的确定性偏差项 $b$ 来表示诸如融合乘加重排序等效应。所有量都是无量纲的；本问题不涉及物理单位。
从初始条件开始，您的程序必须为一组 $N$ 个独立的初始条件生成一个轨迹系综，然后形成一个最终能量的系综。状态 $(x, v)$ 的能量定义为 $E = \dfrac 12 mv^2 + \dfrac 12 kx^2$。您将为每个测试用例生成两个系综，代表两种编译器和标志配置 $A$ 和 $B$ 
您必须实现的单个时间步长的积分方案如下：
- 使用公式 $x_{t+\Delta t} = x_t + v_t \Delta t - \dfrac 12 \dfrac km x_t(\Delta t)^2 + bx_tv_t$ 计算下一个位置，然后将 $x_{t+\Delta t}$ 四舍五入到 $p$ 位小数
- 使用公式 $v_{t+\Delta t} = v_t - \dfrac 12 \dfrac km(x_t + x_{t+\Delta t})\Delta t + b x_{t+\Delta t} v_t$ 计算下一个速度，然后将 $v_{t+\Delta t}$ 四舍五入到 $p$ 位小数

必须通过在对称区间上均匀抽样 $N$ 个确定性初始位置 $x_0$ 来构建系综，并为所有系综成员设置 $v_0=0$。具体来说，使用在 $[-X, X]$ (其中 $X=0.5$) 上均匀分布的 $x_0$ 值。对于给定的配置 $(m,k,\Delta t, p, b)$ 和步数 $T$，您应该：
- 按所述初始化系综
- 使用上述更新将每个成员推进 $T$ 步
- 计算并收集每个成员的最终能量 $E$，形成一个能量系综

为了判定再现性，定义零假设 $H_0$ 为：来自配置 $A$ 和 $B$ 的两个能量系综是从相同的底层分布中抽取的样本：$H_0: F_A(E) = F_B(E)\ \text{for all}\ E$，其中 $F_A$ 和 $F_B$ 是累积分布函数。使用显著性水平为 $\alpha$ 的双样本 Kolmogorov-Smirnov (KS) 检验来接受或拒绝再现性。具体来说，计算两个能量样本的 KS $p$ 值；如果 $p$ 值大于或等于 $\alpha$，则宣布结果是可再现的，否则为不可再现
实现程序以运行以下测试套件，每个测试用例由配置 $A$ 和 $B$ 的参数元组以及 $\alpha$ 定义：
- 测试用例 1 (理想路径，相同配置)
	- 配置 $A$：$m=1.0,\ k=2.0,\ \Delta t = 0.005,\ p=12,\ b=0.0,\ T=100,\ N=1000$ 
	- 配置 $B$：$m=1.0,\ k=2.0,\ \Delta t = 0.005,\ p=12,\ b=0.0,\ T=100,\ N=1000$ 
	- $\alpha = 0.05$ 
- 测试用例 2 (边界条件，极小的系综规模)
	- 配置 $A$：$m=1.0,\ k=2.0,\ \Delta t = 0.005,\ p=12,\ b=0.0,\ T=50,\ N=8$ 
	- 配置 $B$：$m=1.0,\ k=2.0,\ \Delta t = 0.005,\ p=12,\ b=0.0,\ T=50,\ N=8$ 
	- $\alpha = 0.05$ 
- 测试用例 3 (质量参数有明显差异)
	- 配置 $A$：$m=1.0,\ k=2.0,\ \Delta t = 0.005,\ p=12,\ b=0.0,\ T=50,\ N=500$ 
	- 配置 $B$：$m=1.5,\ k=2.0,\ \Delta t = 0.005,\ p=12,\ b=0.0,\ T=50,\ N=500$ 
	- $\alpha = 0.05$ 
- 测试用例 4 (多重差异：步长、舍入精度和偏差)
	- 配置 $A$：$m=1.0,\ k=2.0,\ \Delta t = 0.005,\ p=12,\ b=0.0,\ T=50,\ N=500$ 
	- 配置 $B$：$m=2.0,\ k=2.0,\ \Delta t = 0.02,\ p=6,\ b=10^{-3},\ T=150,\ N=100$ 
	- $\alpha = 0.05$ 

您的程序必须：
- 实现所述的积分器和系综构建
- 对每个测试用例，为 $A$ 和 $B$ 生成能量系综
- 在指定的 $\alpha$ 水平上应用双样本 KS 检验
- 生成一行输出，其中包含一个用方括号括起来的、以逗号分隔的布尔值列表 (例如 `[True, False, True]`)，按测试用例 1 到 4 的顺序排列

所有计算都是无量纲的；不要包含或转换任何物理单位。本问题不使用角度。如果出现百分比，必须以小数形式表示；但是，本问题没有明确要求使用百分比。
#### 解答思路
该问题要求设计并实现一个计算实验来研究数值再现性。这通过在不同配置下模拟一维谐振子来完成，这些配置模拟了编译器或硬件的差异，然后使用统计检验来确定结果是否等效。该解决方案的核心涉及数值积分、系综生成和假设检验。

**建立模型的递推式** 
首先，我们定义物理模型及其数值积分。该系统是一个质量为 $m$、弹簧常数为 $k$ 的简谐振子。一个状态由其位置 $x$ 和速度 $v$ 定义。一个状态 $(x,v)$ 的总能量在理想物理系统中是一个守恒量，由表达式 $E = \dfrac 12mv^2 + \dfrac 12 kx^2$ 给出。
对于数值模拟，我们用步长 $\Delta t$ 将时间离散化。在时间不长索引 $t$ 处的状态 $(x_t, v_t)$ 使用指定的更新方案推进到下一个状态 $(x_{t+\Delta t}, v_{t+\Delta t})$。问题陈述提供了一个标准速度 Verlet 算法的变体：首先更新位置 $x_{t+\Delta t} = x_t + v_t \Delta t - \dfrac 12 \dfrac km x_t(\Delta t)^2 + bx_tv_t$，然后使用这个更新后的位置 $x_{t+\Delta t}$ 来计算新的速度：$v_{t+\Delta t} = v_t - \dfrac 12 \dfrac km(x_t + x_{t+\Delta t})\Delta t + b x_{t+\Delta t} v_t$ 
在这些方程中，与偏差参数 $b$ 成比例的项是一个微小的确定性扰动，旨在模拟计算环境之间的细微算术差异，例如由融合乘加指令重排序引起的差异。为了进一步模拟有限精度算术的影响，位置和速度更新的结果 $x_{t+\Delta t}$ 和 $v_{t+\Delta t}$ 都被四舍五入到指定的小数位数 $p$ 

**模型初始化** 
第二个原则是使用系综来捕捉系统演化的统计特性。单个轨迹对初始条件和扰动很敏感 (“蝴蝶效应”)。为了获得对动力学的稳健统计描述，我们模拟了一个由 $N$ 个独立系统组成的系综，每个系统都从略有不同的初始条件开始。
对于本问题，初始系综由 $N$ 个在区间 $[-0.5, 0.5]$ 上均匀分布的确定性起始位置 $x_0$ 构成。对于系综的所有成员，初始速度 $v_0$ 都设置为 $0$。然后，使用上述数值方案将这 $N$ 个系统中的每一个在时间上向前积分 $T$ 步。在模拟结束时，即时间 $T \Delta t$ 处，我们计算 $N$ 个成员中每一个的最终能量 $E$。这个过程产生两组最终能量，一组用于“参考”配置 $A$，另一组用于“测试”配置 $B$。

**检验再现性** 
最后一步是正式检验再现性。核心问题是，来自配置 $A$ 和 $B$ 的两个最终能量系综是否可能从相同的底层概率分布中抽取。我们将其形式化为一个零假设 $H_0$，即两种配置的能量累积分布函数 (CDF) 相同：$H_0: F_A(E)=F_B(E)$。
为了检验这个假设，我们采用双样本 Kolmogorov-Smirnov (KS) 检验。这是一种非参数检验，它量化了两个样本的经验累积分布函数之间的最大距离。KS 检验产生一个 $p$ 值，它表示在假设 $H_0$ 为真的情况下，观察到等于或大于测量值的差异的概率。一个小的 $р$ 值表明观察到的差异不太可能仅仅是由于随机机会造成的，从而导致我们拒绝 $H_0$。该问题基于显著性水平 $\alpha$ 定义再现性：如果计算出的 $p$ 值大于或等于 $\alpha$，我们就不拒绝零假设，并宣布结果是可再现的。如果 $p$ 值小于 $\alpha$，我们就拒绝 $H_0$，并宣布结果是不可再现的。

**算法流程** 
算法设计直接遵循上述步骤。
实现一个函数，用于对给定的参数集 $(m,k,\Delta t, p, b, T, N)$ 执行系综模拟。
该函数将 $N$ 个系综成员的位置和速度初始化为 `numpy` 数组，然后迭代 $T$ 个时间步长，为了计算效率，将矢量化的更新方程一次性应用于整个系综。积分之后，它计算并返回一个最终能量的数组。
程序的主体部分遍历指定的测试用例。对于每个用例，它调用配置 $A$ 和 $B$ 的模拟函数，获得两个能量系综，并将它们传递给 `scipy.stats.ks_2samp` 函数。将得到的 $p$ 值与给定的 $\alpha$ 进行比较，并存储一个布尔结果 (`True` 表示可再现，`False` 表示不可再现)。
最后，收集所有布尔结果并以指定格式打印。

**其他补充** 
- 这道题的核心目标是：让你通过编程实践，理解“科学可复现性”可以从“完全一致”放宽到“统计上无差异”
- 系统与系综的差异
	- **系统**：指一个具体的、单个的研究对象。
	- **系综**：指大量与所研究系统具有相同宏观条件（如相同的能量、体积、粒子数等）的、独立且完全相同的系统的集合。

```python
import numpy as np
from scipy import stats

def solve():
    """
    通过运行模拟来解决计算可重复性案例研究，
    并针对给定的测试用例并执行 Kolmogorov-Smirnov 检验。
    """

    def run_simulation(m: float, k: float, dt: float, p: int, b: float, T: int, N: int) -> np.ndarray:
        """
        针对给定的配置运行一次系综模拟。

        Args:
            m: 质量参数
            k: 刚度参数
            dt: 时间步长
            p: 四舍五入的小数位数
            b: 偏置项
            T: 时间步数
            N: 集合成员数

        Returns:
            每个系综成员的最终能量数组
        """
        # 初始化系综状态（位置 x，速度 v）
        # 当 N=1 时，linspace 会生成数组 ([0.])，即区间的中心，这是正确的。
        x = np.linspace(-0.5, 0.5, N)
        v = np.zeros(N)

        # 时间积分循环
        for _ in range(T):
            # 位置更新步骤
            x_new_unrounded = x + v * dt - 0.5 * (k / m) * x * (dt**2) + b * x * v
            x_new = np.round(x_new_unrounded, p)

            # 速度更新步骤，使用刚计算出的位置 x_new
            v_new_unrounded = v - 0.5 * (k / m) * (x + x_new) * dt + b * x_new * v
            v_new = np.round(v_new_unrounded, p)

            # 更新下一轮迭代的状态向量
            x, v = x_new, v_new

        # 计算每个集合成员的最终能量
        energy = 0.5 * m * v**2 + 0.5 * k * x**2
        return energy

    # 根据问题陈述定义测试用例
    test_cases = [
        # 测试用例 1（正常流程，配置相同）
        (
            {'m': 1.0, 'k': 2.0, 'dt': 0.005, 'p': 12, 'b': 0.0, 'T': 100, 'N': 1000}, # Config A
            {'m': 1.0, 'k': 2.0, 'dt': 0.005, 'p': 12, 'b': 0.0, 'T': 100, 'N': 1000}, # Config B
            0.05  # alpha
        ),
        # 测试用例 2（边界条件，集合规模极小）
        (
            {'m': 1.0, 'k': 2.0, 'dt': 0.005, 'p': 12, 'b': 0.0, 'T': 50, 'N': 8},
            {'m': 1.0, 'k': 2.0, 'dt': 0.005, 'p': 12, 'b': 0.0, 'T': 50, 'N': 8},
            0.05
        ),
        # 测试用例 3（质量参数存在明显差异）
        (
            {'m': 1.0, 'k': 2.0, 'dt': 0.005, 'p': 12, 'b': 0.0, 'T': 100, 'N': 500},
            {'m': 1.5, 'k': 2.0, 'dt': 0.005, 'p': 12, 'b': 0.0, 'T': 100, 'N': 500},
            0.05
        ),
        # 测试用例 4（多重差异：步长、舍入精度和偏差）
        (
            {'m': 1.0, 'k': 2.0, 'dt': 0.005, 'p': 12, 'b': 0.0, 'T': 150, 'N': 1000},
            {'m': 2.0, 'k': 2.0, 'dt': 0.02, 'p': 6, 'b': 1e-3, 'T': 150, 'N': 1000},
            0.05
        )
    ]

    results = []
    for config_A, config_B, alpha in test_cases:
        # 为这两种配置生成能量系综
        energy_A = run_simulation(**config_A)
        energy_B = run_simulation(**config_B)
        
        # 执行两样本 KS 检验
        ks_result = stats.ks_2samp(energy_A, energy_B)
        p_value = ks_result.pvalue
        
        # 根据 p 值和显著性水平 alpha 来判断结果的可重复性
        is_reproducible = p_value >= alpha
        results.append(is_reproducible)

    # 符合要求的最终打印格式。
    # Python 的 str(bool) 函数会根据需要返回 'True' 或 'False'
    print(f"[{','.join(map(str, results))}]")

solve()
```
