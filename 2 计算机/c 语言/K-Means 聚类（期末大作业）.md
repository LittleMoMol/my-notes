# 1 简介
将相近的样本归为同一个子集，使得相同子集中各元素间差异性最小，而不同子集间的元素差异性最大，这是聚类算法的本质。而 K-Means 正是这样一种算法的代表
# 2 基本步骤
具体步骤如下：
1. 从 $N$ 个样本数据中随机选取 $K$ 个对象，作为初始的聚类中心
2. 分别计算每个样本点到各个聚类中心的距离，并逐个分配到距离其最近的簇中
3. 所有对象分配完成后，更新 $K$ 个类中心位置，类中心的位置为：簇内所有对象在各个维度的均值（即质心）
4. 与前一次计算得到的 $K$ 个聚类中心比较，如果聚类中心改变，则跳转至步骤 2，否则跳转至步骤 5
5. 此时类中心不再发生变化，停止并输出聚类结果，结束算法

如此进行，满足“簇内差异小，簇间差异大”的聚类目标
# 3 优化分析
下面我们关注两个需要预设的参数，**聚类个数 $K$**、**初始聚类中心点**。
## 3.1 聚类个数 $K$ 
### 3.1.1 $SEE$ 表达式构建
$k$ 值的选定通常是难以估计的，很多时候，我们并不知道给定的数据集应该分成多少个类别才最合适，这也在一定程度上影响和限制了 K-Means 的应用合理性。
聚类的目标是使得**每个样本点到距离其最近的聚类中心的总误差平方和**尽可能小。为此，我们定义聚类的代价函数 $SSE$ 就表示每个样本点到距离其最近的聚类中心的总误差平方和。
我们先推导 $SSE$ 的表达式：
设 $x$ 为任意一个数据对象，$C_i$ 为第 $i$ 个聚类中心，$m$ 为数据对象的维度，$x_j, C_{ij}$ 为 $x$ 和 $C_i$ 的第 $j$ 个属性值，$K$ 为聚类的个数。
则空间中数据对象与聚类中心之间的欧式距离计算公式为：$\displaystyle d(x, C_i) = \sqrt{\sum_{j=1}^m (x_j - C_{ij})^2}$ 
那么整个数据集的误差平方和 $SSE$ 的计算公式为：$\displaystyle SSE = \sum_{i=1}^K \sum_{x\in C_i} |d(x, C_i)|^2$
其中，$SSE$ 的大小表示聚类结果的好坏。
### 3.1.2 分析 $K$ 值取法
理论上随着 $K$ 的增加，$SSE$ 会单调递减，这是因为类数的增加意味着总有一部分样本点会因为归属到新的类簇而节约下一段距离。直到 $K=N$ 时，情形变成了每个样本自成一类，此时 $SSE$ 就会变成 $0$，但这并不是我们希望的，这便陷入了“过拟合”。
根据长期实践经验，$K$ 值最大不应超过样本量的平方根，即：$K_\max \le \sqrt N$ 
确定了范围后，最优 $K$ 值又应该怎么判断？
### 3.1.3 手肘法
试图找到某一个值，要求当 $K$ 大于该值时，$SSE$ 的下降变化幅度明显变小。
换句话说，当 $K$ 超过某一个数后，每个类簇的聚合程度不再获得显著提升，此时我们就可以认为已找到最佳 $K$ 的取值。
**缺点**：若SSE的下降是均匀的，手肘法就失灵了。
对于最优 $K$ 值确定，仍未有最佳的方案
## 3.2 初始聚类中心点
### 3.2.1 初始聚类中心点的重要性
1. K-Means对初始聚类中心的位置十分敏感，每次迭代，初始点的不同往往会导致不同的聚类结果。
2. 过于临近的初始中心点，有时还会导致模型的收敛时间变长

尝试使用一些方法进行优化
### 3.2.2 最大距离法
1. 先选取数据集中距离最大的两个点作为初始聚类中心
2. 将剩余数据对象依据到聚类中心点距离的远近分配到相应的簇中，并更新聚类中心
3. 然后继续寻找与聚类中心距离最远的点作为下一个中心点
### 3.2.3 K-Means++
同样是基于最大距离，这里结合加权概率的思想优化了对 $K$ 个初始中心的选取，使得在选取第 $i+1\ (i+1\le K)$ 个聚类中心时，距离当前 $i$ 个聚类中心越远的点会有更高的概率被选为第 $i+1$ 个聚类中心

# 4 代码示例

本代码采用 C 语言实现，用的是最朴素的方法实现 K-Means，以一个具体的例子来展示：

```c
/*
此代码仅仅举了一个具体例子
样本总数：10
K 值：3
若需要更改，则只需在宏定义处和 mean 数组初始化处对应更改即可
*/
#include <stdio.h>
#include <string.h>
#include <math.h>

#define N 11
#define K 3

const int INF = 1e8;
const double eps = 1e-8;

typedef struct
{
	double x;
	double y;
} POI;

int center[N]; //数组含义：标号为 i 的点属于第 center[i] 个簇
int tot;
double E1, E2;

POI point[N] = {
    {2.0, 10.0},
    {2.0, 5.0},
    {8.0, 4.0},
    {5.0, 8.0},
    {7.0, 5.0},
    {6.0, 4.0},
    {1.0, 2.0},
    {4.0, 9.0},
    {7.0, 3.0},
    {1.0, 3.0},
    {3.0, 9.0}
};

POI mean[K]; //数组含义：标号为 i 的簇的中心点为 mean[i]

double get_dis(POI A, POI B)
{
	double x1 = A.x, x2 = B.x, y1 = A.y, y2 = B.y;
	double derx = x1 - x2;
	double dery = y1 - y2;
	double res = sqrt(derx * derx + dery * dery);
	return res;
}

// 计算每个簇的中心点
void GetMean()
{
	for (int i = 0; i < K; i ++ ) // 对于每个簇做这样的处理
	{
		int cnt = 0; //统计第 i 个簇所含样本点个数
		double x_sum = 0, y_sum = 0; //累加横坐标、纵坐标
		for (int j = 0; j < N; j ++ )
		{
			//如果第 j 个点的簇不是标号为 i 的簇的话，就跳过
			if (i != center[j]) continue;
			cnt ++ ;
			x_sum += point[j].x;
			y_sum += point[j].y;
		}
		double x_mean = x_sum / cnt;
		double y_mean = y_sum / cnt;
		mean[i].x = x_mean;
		mean[i].y = y_mean;
		printf("%.2lf, %.2lf\n", mean[i].x, mean[i].y);
	}
	for (int i = 0; i < K; i ++ )
		printf("第 %d 个簇的中心质点为：\t(%lf, %lf)\n", i + 1, mean[i].x, mean[i].y);
	return;
}

//计算平方误差
double getE()
{
	double res = 0;
	for (int i = 0; i < K; i ++ ) //簇下标 i
	{
		for (int j = 0; j < N; j ++ ) //样本点下标 j
		{
			if (i != center[j]) continue;
			double derx = point[j].x - mean[i].x;
			double dery = point[j].y - mean[i].y;
			res += derx * derx + dery * dery;
		}
	}
	return res;
}

//把所有样本点聚类
void cluster()
{
	double dist[N][K];
	memset(dist, 0, sizeof dist);
	for (int i = 0; i < N; i ++ ) //样本点下标 i，对每个样本点来看一看它属于哪个簇
	{
		for (int j = 0; j < K; j ++ )
			dist[i][j] = get_dis(point[i], mean[j]);
		double mn = INF;
		for (int j = 0; j < K; j ++ )
			if (dist[i][j] < mn)
			{
				mn = dist[i][j];
				center[i] = j;
			}
	}
}

int main()
{
	printf("所有样本点如下");
	for (int i = 0; i < N; i ++ )
		printf("\t( %.0f, %.0f )\n", point[i].x, point[i].y);
	
	//第一次行动得到一个平方误差
	mean[0].x = point[0].x; //Step 1：初始化每个簇的中心点
	mean[0].y = point[0].y;
    mean[1].x = point[1].x;
    mean[1].y = point[1].y;
    mean[2].x = point[2].x;
    mean[2].y = point[2].y;
	cluster(); 				//Step 2：根据最新的簇中心点，进行聚类
	E1 = getE(); 			//Step 3：根据聚类结果，计算第一次平方误差
	tot ++ ; 				//Step 4：迭代次数 +1
	printf("第 1 次平方误差为: %lf\n\n", E1);
	printf("---------------------------------------------------\n\n");
	
	//第二次行动得到第二个平方误差
	GetMean(); 		//Step 1：计算每个簇的新的中心点
	cluster(); 		//Step 2：根据最新的簇中心点，进行聚类
	E2 = getE(); 	//Step 3：根据聚类结果，计算第二次平方误差
	tot ++ ; 		//Step 4：迭代次数 +1
	printf("第 2 次平方误差为: %lf\n\n", E2);
	printf("---------------------------------------------------\n\n");
	
	//有了两次的平方误差之后，后续迭代过程就可以很容易地用循环表示了
    while(fabs(E2 -  E1) > eps) // 精度控制循环是否结束
    {
        E1 = E2;
        GetMean();
        cluster();
        E2 = getE();
        tot ++ ;
        printf("第 %d 次平方误差为: %lf\n\n", tot, E2);
        printf("---------------------------------------------------\n\n");
    }
	printf("总共的迭代次数为: %d\n\n", tot);  // 统计出迭代次数
	return 0;
}
```
