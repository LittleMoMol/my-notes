# 1 前置知识与简易介绍
## 1-1 面向对象编程的引入
- **面向对象编程**：即 Object Oriented Programming，简称 OOP，是以需要处理的对象为基础组织编程涉及的方法
- **类**、**数据成员**、**成员函数**：在 C++ 的**类**中可以包含两种成员，即数据和函数，分别称为**数据成员**和**成员函数** 
- **封装**、**类**（**class**）：在 C++ 中把一组数据和有权调用这些数据的函数**封装**在一起，组成一种称为**类**（**class**）的数据结构
	- 一个类是由一批数据以及对其操作的函数组成的
	- 类体现了数据的**封闭性**和**信息隐蔽** 
	- 类中数据分为两大类：**私有的**（**private**）和**公用的**（**public**）
	- 大多数情况下，都把所有数据指定为私有，以实现信息隐蔽
- **公用**特点：凡是被指定为**公用**的数据或函数，既可以被本类中的成员函数调用，也可以被类外的语句所调用
- **私有**特点：被指定为**私有**的函数或数据，只能被本类中的成员函数所调用，而不能被类以外调用（以后介绍的“友元类”成员以外）
	- 这样做的目的是对某些数据进行保护，只有被指定的本类中的成员函数才能调用它们，拒绝其他无关的部分调用它们，以防止误调用。这样才能真正实现封装的目的（把有关的数据与操作组成一个单位，与外界相对隔离）
	- 信息隐蔽是C++的一大特点
- **对象**（**object**）：具有“类”类型特征的变量称为“**对象**”（**object**）
## 1-2 `cin`、`cout`、变量定义
- **输出流对象**：`cout` 实际上是 C++ 系统定义的对象名，称为**输出流对象** 
- `setw`：如果要输出所占列数，可以用控制符 `setw` 进行设置。使用 `setw` 需引入 `iomanip` 或 `iomanip.h` 头文件
	- 例子：`cout << "pi=" << setw(5) << pi << endl;` 会输出 `pi= 3.14` 
- **插入**（**放到**）：在 C++ 中将数据送到输出流中称为“**插入**”（**inserting**）或“**放到**”（**putting**）
- **插入运算符**：`<<` 常称为**插入运算符** 
- **输入流**：从输入设备向内存流动的数据流称为**输入流** 
- **提取**（**得到**）：在 C++ 中，用 `>>` 运算符从输入设备键盘取得数据并送到输入流 `cin` 中。这种输入操作称为“**提取**”（**extracting**）或“**得到**”（**getting**）。
- **提取运算符**：`>>` 常称为**提取运算符** 
- C++为流输人输出提供了一些格式控制的功能，如：`dec`（指定数据用十进制形式），`hex`（指定数据用十六进制形式），`oct`（指定数据用八进制形式），还可以控制实数的输出精度等。后续会详细介绍
- 在 C 语言程序中要求声明部分必须在执行语句之前。而 C++ 允许对变量的声明放在程序的任何位置（但必须在使用该变量之前）
## 1-3 用 `const` 定义常量
- C++提供了用 `const` 定义常变量的方法，定义的变量具有变量的属性，有数据类型，占用存存储单元，有地址，可以用指针指向它，只是在程序运行期间变量的值是固定的，不能改变。
## 1-4 函数的声明、运算符与函数的重载
- **C 语言函数的声明**：在 C 语言程序中，如果函数调用的位置在函数定义之前，则应在函数调用之前对所调用的函数作声明，但如果所调用的函数是整型的，也可以不进行函数声明。函数声明的形式建议采用函数原型声明。
- **C++ 函数的声明**：在 C++ 中，如果函数调用的位置在函数定义之前，则要求在函数调用之前必须对所调用的函数作函数原型声明，这不是建议性的，而是强制性的。这样做的目的是使编译系统对函数调用的合法性进行严格的检查，尽量保证程序的正确性。
	- 函数声明的一般形式为 `函数类型 函数名(参数表)`。参数表中一般包括参数类型和参数名，也可以只包括参数类型而不包括参数名。在编译时只检查参数类型，而不检查参数名。故 `int max(int x, int y);` 与 `int max(int, int)` 等价。
- 运算符的**重载**（**overloading**）：允许一个运算符可以用于不同场合，不同的场合有不同的含义，这就叫运算符的“**重载**”（**overloading**），即重新赋予它新的含义。
	- 如插入运算符和提取运算符本来是 C 和 C++ 位运算中的左移运算符和右移运算符，现在 C++ 又把它作为输人输出运算符。
- 函数的**重载**（**overloading**）：C++ 允许在同一作用域中用同一函数名定义多个函数，这些函数的参数个数和参数类型不相同，这些同名的函数用来实现不同的功能，这就是函数的**重载**（**overloading**）
## 1-5 函数模板
- **函数模板**（**function template**）：C++ 提供了**函数模板**（**function template**）。所谓函数模板，实际上是建立一个通用函数，其函数类型和形参类型不具体指定，用一个虚拟的类型来代表，这个通用函数就称为函数模板。
	- **使用方法**：定义函数模板的一般形式为：`template <typename T>` 或 `template <class T>` 
	- **扩充**：类型参数可以不只一个，根据需要确定个数。如 `template <typename T1, typename T1>` 
	- **优点**：凡是函数体相同的函数都可以用这个模板来代替，不必定义多个函数，只须在模板中定义一次即可。在调用函数时系统会根据实参的类型来取代模板中的虚拟类型，从而实现了不同函数的功能。
	- **优点**：用函数模板比函数重载更方便，程序更简洁。
	- **注意**：函数模板只适用于函数的参数个数相同而类型不同，且函数体相同的情况。如果参数的个数不同，则不能用函数模板。
