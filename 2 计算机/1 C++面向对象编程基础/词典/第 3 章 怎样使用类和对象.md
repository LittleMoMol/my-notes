## 3-1 利用构造函数对类对象进行初始化
### 3-1-1 对象的初始化
- **注意**：不能在类声明中对数据成员进行初始化。因为类并不是一个实体，而是一种抽象类型，并不占存储空间，显然无处容纳数据。
- **方法**：如果一个类中所有的成员都是 `public` 的，则可以在定义对象时对数据成员进行初始化。
	- **注意**：如果数据成员是私有的，或者类中有` private` 或 `protected` 的数据成员，就不能用这种方法初始化
### 3-1-2 用构造函数实现数据成员的初始化
- **构造函数**（**constructor**）：C++ 提供了**构造函数**（**constructor**）来处理对象的初始化。构造函数是一种特殊的成员函数，与其他成员函数不同，不需要用户来调用它，而是在建立对象时自动执行。
	- 构造函数的是在对类进行声明的时候由类的设计者定义的，程序用户只须在定义对象的同时指定数据成员的初值即可。
	- 构造函数的名字必须与类名同名，而不能任意命名，以便编译系统能识别它，并把它作为构造函数处理。它不具有任何类型，不返回任何值。
	- 也可以只在类内对构造函数进行声明而在类外定义构造函数。
	- **注意**：构造函数不需用户调用，也不能被用户调用。
	- 构造函数是在定义对象时由系统自动执行的，而且只能执行一次。构造函数一般声明为 `public` 
	- 在构造函数的函数体中不仅可以对数据成员赋初值，而且可以包含其他语句。但是一般不提倡在构造函数中加人与初始化无关的内容，以保持程序的清晰。
	- 如果用户自己没有定义构造函数，则C++系统会自动生成一个构造函数，只是这个构造函数函数体是空的，也没有参数，不执行初始化操作。
- 可以用一个类对象初始化另一个类对象，如 `Time t2 = t1;` 
- **例子** 
	```cpp
	#include <iostream>
	using namespace std;
	class Time
	{
		public:
			Time();
		private:
			int h, m, s;
	};
	Time::Time() {h = m = s = 0;}
	int main()
	{
		Time t1; //建立对象 t1，同时自动调用构造函数 t1.Time()
	}
	```
### 3-1-3 带参数的构造函数
- **带参数的构造函数**：可以采用**带参数的构造函数**，在调用不同对象的构造函数时，从外面将不同的数据传递给构造函数，以实现不同的初始化。
	- 构造函数首部的一般格式为 `构造函数名 (类型 1 形参 1，类型 2 形参 2, ... )` 
	- 用户是不能调用构造函数的，因此无法采用常规的调用函数的方法给出实参。实参是在定义对象时给出的，定义对象的一般格式为 `类名 对象名 (实参 1, 实参 2, ...)` 
- **注意**：带参数的构造函数中的形参，其对应的实参是在建立对象时给定的。即在建立对象时同时指定数据成员的初值。
- **例子** 
	```cpp
	class Box
	{
		public:
			Box(int, int, int);
		private:
			int height, width, length;
	};
	Box::Box(int h, int w, int l)
	{height = h, width = w, length = l};
	int main()
	{
		Box box1(12, 25, 30);
	}
	```
### 3-1-4 用参数初始化表对数据成员初始化
- **参数初始化表**：C++ 还提供**参数初始化表**来实现对数据成员的初始化。这种方法不在函数体内对数据成员初始化，而是在函数首部实现
	- 带有参数初始化表的构造函数的一般形式为 `类名::构造函数名([参数表])[:成员初始化表] {[构造函数体]}`，其中方括号内为可选项，可有可无。
	- **例子**：`Box::Box(int h, int w, int l):height(h), width(w), length(l){}`，表示用形参 `h` 的值初始化数据成员 `height`，用形参 `w` 的值初始化数据成员 `width`，用形参 `len` 的值初始化数据成员 `length`。后面的花括号是空的，即函数体是空的，没有任何执行语句。
- **注意**：如果数据成员是数组，则应当在构造函数的函数体中用语句对其赋值，而不能在参数初始化表中对其初始化。
	- **例子** 
		```cpp
		class Student
		{
			public:
				Student(int n, char s, nam[]):num(n), sex(s)
				{strcpy(name, nam);}
			private:
				int num;
				char sex;
				char name[20];
		};
		int main()
		{
			Student stu1(10101, 'm', "zmh")
		}
		```
### 3-1-5 构造函数的重载
- **构造函数的重载**：在一个类中可以定义多个构造函数，以便为对象提供不同的初始化的方法，供用户选用。这些构造函数具有相同的名字，而参数的个数或参数的类型不相同，这称为**构造函数的重载** 
	- **例子**：可以在 `Box` 类的 `public` 里面声明一个无参的构造函数 `Box();` 和一个有参的构造函数 `Box(int h, int w, int l):height(h), width(w), length(l){}`，并在类外定义无参构造函数 `Box::Box(){height = 10, width = 10, length = 10;}`，就可以在主函数中指定对象 `Box box1;` 和 `Box box2(15, 30, 25);` 
- **默认构造参数**：建立对象时不必给出实参的构造函数，称为**默认构造函数**（**default constructor**）
	- 无参构造函数属于默认构造函数。
	- 一个类只能有一个默认构造函数。
	- 如果用户未定义构造函数，则系统会自动提供一个默认构造函数，但它的函数体是空的，不起初始化作用。如果用户希望在创建对象时就能使数据成员有初值，就必须自己定义构造函数。
- **注意**：如果在建立对象时选用的是无参构造函数，应注意正确书写定义对象的语句。如 `Box box1; //正确`，`Box box1(); //错误`，后者是声明一个普通函数 `box1`，此函数的返回值为 `Box` 类型。
- **注意**：在程序中不应出现调用无参构造函数，构造函数是不能被用户显式调用的。
### 3-1-6 使用默认参数的构造函数
- 构造函数中参数的值既可以通过实参传递，也可以指定为某些默认值，即如果用户不指定实参值，编译系统就使形参的值为默认值。
	- **例子**：可以在 `Box` 类的 `public` 里面声明一个指定默认参数的有参的构造函数 `Box(int h=10, int w=10, int l=10);`，并在类外定义有参构造函数 `Box::Box(int h, int w, int l){height = h, width = w, length = l;}`（定义时可以不指定默认参数）
- **优点**：即使在调用构造函数时没有提供实参值，不仅不会出错，而且还确保按照默认的参数值对对象进行初始化。
- **注意点** 
	- 在声明构造函数时指定默认值，而不能只在定义构造函数时指定默认值。因为类定义是放在头文件中的，它是类的对外接口，用户是可以看到的，而函数的定义是类的实现细节，用户往往是看不到的。在声明构造函数时指定默认参数值，使用户知道在建立对象时怎样使用默认参数。
	- 声明构造函数时，形参名可以省略，即写成 `Box(int=10, int=10, int=10);` 
	- 如果构造函数的全部参数都指定了默认值，则在定义对象时可以给一个或几个实参，也可以不给出实参。由于不需要实参也可以调用构造函数，因此全部参数都指定了默认值的构造函数也属于**默认构造函数** 
	- 一个类只能有一个默认构造函数，也就是说，一个类只能有一个可以不使用参数而调用的构造函数。如 `Box(); //声明一个无参的构造函数` 的同时 `Box(int=10, int=10, int=10); //声明一个全部参数都指定了默认值的构造函数` 是错误的。
	- 在一个类中定义了全部是默认参数的构造函数后，不能再定义重载构造函数。一般不应同时使用构造函数的重载和有默认参数的构造函数。
