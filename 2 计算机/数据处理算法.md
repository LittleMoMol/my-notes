# 线性回归 (Linear Regression)
假设目标变量 $y$ 和特征变量 $x$ 之间存在线性关系，试图找到一条最佳拟合直线来表述这种关系，即找到 $w$ 和 $b$ 使得 $y=wx+b$ 
其中：
- y 是预测值
- x 是特征变量
- w 是权重（斜率）
- b 是偏置（截距）
线性回归的目的是找到最佳的 w 和 b，使得预测值 y 与真实值之间的误差最小
## 最小二乘法
目标：最小化残差平方和（RSS），公式为：
$$
\mathrm{RSS} = \sum_{i=1}^n(y_i - \hat y_i)^2
$$
其中：
- $y_i$ 是实际值
- $\hat y_i$ 是预测值，由线性回归模型 $\hat y_i = wx_i + b$ 计算得到

通过最小化 RSS，可以得到以下正规方程：
$$

\begin{cases}
\displaystyle w\sum_{i=1}^n x_i^2 + b\sum_{i=1}^n x_i = \sum_{i=1}^n x_iy_i \\
\displaystyle w\sum_{i=1}^n x-i + bn = \sum_{i=1}^n y_i
\end{cases}
$$
将正规方程写成矩阵形式，即为：
$$
\begin{bmatrix}
\sum_{i=1}^n x_i^2 & \sum_{i=1}^n x_i \\
\sum_{i=1}^n x_i & n 
\end{bmatrix}
\begin{bmatrix}w \\ b\end{bmatrix}=
\begin{bmatrix}
\sum_{i=1}^n x_iy_i \\
\sum_{i=1}^n y_i
\end{bmatrix}
$$
求解上述矩阵方程得到最优的 $w$ 和 $b$ 
$$
\begin{bmatrix}w \\ b\end{bmatrix}=
\begin{bmatrix}
\sum_{i=1}^n x_i^2 & \sum_{i=1}^n x_i \\
\sum_{i=1}^n x_i & n 
\end{bmatrix}^{-1}
\begin{bmatrix}
\sum_{i=1}^n x_iy_i \\
\sum_{i=1}^n y_i
\end{bmatrix}
$$ 
code
```python
import numpy as np
import matplotlib.pyplot as plt
from sklearn.linear_model import LinearRegression

# 生成一些随机数据
np.random.seed(0) #设置随机种子，确保每次运行生成的随机数相同（可复现性）
x = 2 * np.random.rand(100, 1) # 生成100个介于[0, 2)的随机数作为特征（x）
y = 4 + 3 * x + np.random.randn(100, 1) # 生成标签（y），其真实关系为 y = 4 + 3x + 噪声

# 创建线性回归模型
model = LinearRegression()

# 拟合模型
model.fit(x, y) # 拟合模型，即通过最小二乘法求解最优参数

# 输出模型的参数
print(f"斜率 (w): {model.coef_[0][0]}") # 斜率（权重）的估计值，应为接近3的值（因真实斜率为3）
print(f"截距 (b): {model.intercept_[0]}") # 截距的估计值，应为接近4的值（因真实截距为4）

# 预测
# 用训练好的模型对输入 x 预测 y 值
y_pred = model.predict(x)

# 可视化拟合结果
plt.scatter(x, y) # 在二维坐标系中绘制散点图
plt.plot(x, y_pred, color='red')
plt.xlabel('x')
plt.ylabel('y')
plt.title('Linear Regression Fit')
plt.show()
```

## 寻找最优化划分
寻找最优划分属性是决策树过程中的重点，那么如何在众多的属性中选择最优的呢？
### 信息熵
熵是用来形容系统混乱程度的，系统越混乱，熵就越大。信息熵也具有同样的意义，它描述的是随机变量的不确定性
假设某随机变量的概率分布为 $P(X=x_i) = p_i\ (i=1,2,\cdots,n)$，则它的信息熵计算公式为：
$$
H(X) = -\sum_{i=1}^n p_i\log p_i
$$
令决策树样本集为 $D$，经过某一属性划分后，样本集被划分为 $v$ 个，分别为 $D_1, D_2, \cdots, D_v$ 
则对于总样本集：
划分前的信息熵为 $H(D) = -\sum\limits_{i=1}^n p_i\log p_i$ 
其中 $n$ 为样本集 $D$ 的样本数
令划分后的信息熵 $H(D^*) = \sum\limits_{i=1}^v \dfrac{|D_i|}{|D|} H(D_i)$ 
其中 $|U|$ 表示 $U$ 样本集的样本数，计算 $H(D_i)$ 的方式和计算 $H(D)$ 的方式一样
### 信息增益
信息增益就是划分前的信息熵减去划分后的信息熵，用 $D$ 表示总样本，用 $a$ 表示此次划分中所使用的属性，则信息增益可表示为 $Gain(D,a)=H(D)-H(D^*)$ 
ID3 算法
### 增益比
信息增益在理论上确实可以好到最有的划分属性，但由于信息增益比较偏好可取值较多的属性，导致信息增益大但没有什么使用价值的情形，因此引出增益比的思想
增益比就是为了矫正信息增益偏好的问题，使算法不偏向可取值较多的属性
令
$IV(a) = -\sum\limits_{i=1}^v \dfrac{|D_i|}{|D|} \log \dfrac{|D_i|}{|D|}$
可以看出 $IV(a)$ 是属性 $a$ 的固有属性，属性 $a$ 可取值增多时，$IV(a)$ 一般也增大。
则增益比 $Gain\_ratio(D,a)$ 可表示为：
$$
Gain\_ratio(D,a) = \dfrac{Gain(D,a)}{IV(a)}
$$
$IV(a)$ 的引入可以在一定程度上能抑制信息增益偏好取值多的属性的特点
算法 C4.5 是算法 ID3 的改进版，它使用了信息增益和增益比两种选择算法，步骤如下：
1. 选出信息增益高于平均水平的属性
2. 在这些属性中选择增益比最高的，作为最优化分属性
C4.5 算法综合了信息增益和增益比的优点，可以取得较好的结果
### 基尼指数
基尼指数也是一个寻找最优化分属性的准则，公式如下：
$$
Gini(D) = \sum_{k=1}^n \sum_{k'\not=k}p_kp_{k'} = 1 - \sum_{k=1}^n p_k^2
$$
可以理解为：基尼指数就是在样本集中随机抽出两个样本不同类别的概率。当样本集越不纯的时候，这个概率也就越大，即基尼指数也越大。
使用基尼指数来选择最优化分属性：对比不同属性划分后基尼指数的差值，选择使样本集基尼指数减小最多的属性
$$
Gain(D,a) = Gini(D) - \sum_{i=1}^v \dfrac{|D_i|}{|D|} Gini(D_i)
$$
和信息增益计算方式类似，使用划分前样本集 $D$ 和基尼指数减去划分后子样本集 $D_i$ 的基尼指数加权和
CART 决策树算法就是使用基尼指数来作为划分标准的，CART 决策树与 ID3 和 C4.5 的区别为：
1. 划分准则不同
2. ID3、C4.5 划分时，一个节点可以划分为多个子节点，子节点数量根据属性可取值的数量决定，而 CART 决策树是严格的二叉树结构，就是说 1 个节点最多划分为 2 个子节点
