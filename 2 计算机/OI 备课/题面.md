# A 百变小丸的精细打磨
## 题目描述
百变小丸喜欢细致严谨地思考问题，现在 ta 在考虑数字 $s$ 
现在 ta 面前有 $1$ 到 $n$ 共 $n$ 个正整数，由于 ta 很喜欢数字 $k$，于是 ta 要在这 $n$ 个数中选 $k$ 个，使选中的数之和为 $s$（每个数只能用 $1$ 次）
## 输入格式
一行 $3$ 个正整数 $n,k,s$。
## 输出格式
输出一行，一个字符串，`yes` 或 `N0`，表示是否可以恰好选择 $k$ 个数，使选中的数之和为 $s$。
## 样例 #1
### 样例输入 #1
```
5 2 5
```
### 样例输出 #1
```
yes
```
## 数据范围
对于 $100\%$ 的数据，$1\le k\le n\le10^9$，$1\le s\le10^{18}$。
# B 哆啦 A 默的超绝数感
## 题目描述
哆啦 A 默的数感及其强！ta 曾在一次超市购物中发现所有面包的价格都是 12.8 元每斤！
今天，哆啦 A 默分享了一道对他数感提升极大的题目：
给出正整数 $n$ 和 $k$，请计算
$$G(n, k) = \sum_{i = 1}^n k \bmod i$$
其中 $k\bmod i$ 表示 $k$ 除以 $i$ 的余数。
## 输入格式
输入只有一行两个整数，分别表示 $n$ 和 $k$。
## 输出格式
输出一行一个整数表示答案。
## 样例 #1
### 样例输入 #1
```
10 5
```
### 样例输出 #1
```
29
```
## 提示
#### 样例 1 解释
$G(10, 5)=0+1+2+1+0+5+5+5+5+5=29$。
#### 数据规模与约定
- 对于 $30\%$ 的数据，保证 $n , k \leq 10^3$。
- 对于 $60\%$ 的数据，保证 $n, k \leq 10^6$。
- 对于 $100\%$ 的数据，保证 $1 \leq n, k \leq 10^9$。
# C 百变小丸的魔法阵
## 题目描述
百变小丸想要看看哆啦 A 默究竟还有什么神奇之处，于是变出一个魔法阵。
这个魔法阵是一个 $n$ 行 $m$ 列的矩阵。而哆啦 A 默的神奇之处就暗藏其中。
具体地，这个魔法阵中**上下对称且左右对称的正方形子矩阵的个数**，便是哆啦 A 默的神奇点数。
百变小丸很想知道哆啦 A 默的神奇点数是多少，可是矩阵太大，且百变小丸行动力较低。只能请你编个程序来计算出哆啦 A 默的神奇点数。
## 输入格式
文件的第一行为两个整数 $n$ 和 $m$。接下来 $n$ 行每行包含 $m$ 个正整数，表示百变小丸变出的魔法阵。
## 输出格式
文件中仅包含一个整数 $ans$，表示矩阵中有 $ans$ 个上下左右对称的正方形子矩阵，也就是哆啦 A 默的神奇点数。
## 样例 #1
### 样例输入 #1
```
5 5
4 2 4 4 4 
3 1 4 4 3 
3 5 3 3 3 
3 1 5 3 3 
4 2 1 2 4
```
### 样例输出 #1
```
27
```
## 提示
- 对于 $30\%$ 的数据 $1\le n,m\le 100$；
- 对于 $100\%$ 的数据 $1\le n,m\le 1000$，矩阵中的数的大小不超过 $10^9$。
# D 哆啦 A 默的小心思
## 题目描述
刚刚学完数学分析和高等代数的百变小丸觉得自己很强，此时哆啦 A 默二话不说直接塞给 ta 一道新鲜的题目
已知多项式方程：
$$a_0+a_1x+a_2x^2+\cdots+a_nx^n=0$$ 
求这个方程在 $[1,m]$  内的整数解（$n$  和 $m$  均为正整数）。
当百变小丸看到数据范围的时候彻底懵了，于是把这道题甩给了你
## 输入格式
输入共 $n + 2$  行。  
第一行包含 $2$  个整数 $n, m$ ，每两个整数之间用一个空格隔开。  
接下来的 $n+1$  行每行包含一个整数，依次为 $a_0,a_1,a_2\ldots a_n$ 。
## 输出格式
第一行输出方程在 $[1,m]$  内的整数解的个数。  
接下来每行一个整数，按照从小到大的顺序依次输出方程在 $[1,m]$  内的一个整数解。
## 样例 #1
### 样例输入 #1
```
2 10 
1
-2
1
```
### 样例输出 #1
```
1
1
```
## 样例 #2
### 样例输入 #2
```
2 10
2
-3
1
```
### 样例输出 #2
```
2
1
2
```
## 样例 #3
### 样例输入 #3
```
2 10
1
3
2
```
### 样例输出 #3
```
0
```
## 数据范围
对于 $33\%$  的数据：$0<n\le 2,|a_i|\le 100,a_n≠0,m<100$ 。  
对于 $49\%$  的数据：$0<n\le 100,|a_i|\le 10^{100},a_n≠0,m<100$ 。  
对于 $66\%$  的数据：$0<n\le 100,|a_i|\le 10^{10000},a_n≠0,m<10^4$ 。  
对于 $100\%$  的数据：$0<n\le 100,|a_i|\le 10^{10000},a_n≠0,m<10^6$ 。
