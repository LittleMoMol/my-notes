# 1 基础知识
注意：该部分暑期已经讲过，课上只挑重点的提一下
- 组合计数的基础：加法原理、乘法原理
- 排列数 $A_n^m=\dfrac{n!}{(n-m)!}$；组合数 $C_n^m = \dfrac{n!}{m!(n-m)!}$ 
- $C_n^k = C_n^{n-k}$，这个直接套公式就能推出来。
- $1 \sim n$ 的全排列有 $A_n^n=n!$ 种（规定 $0!=1$）
- $A_n^m=C_n^mA_m^m$，即先选出来，再全排列。
- $C_n^m = C_{n-1}^m + C_{n-1}^{m-1}$，即讨论一下第 $n$ 个数选还是不选（dp 思想）
- $C_n^k = C_n^{k-1} \cdot \dfrac{n-k+1}{k}$，套公式即可。
- $\begin{cases} C_n^k > C_n^{k-1} & k < \dfrac{n+1}{2} \\ C_n^k < C_n^{k-1} &k>\dfrac{n+1}{2} \end{cases}$，直接能推出来。
- $C_p^i = \dfrac pi C_{p-1}^{i-1}$，套公式即可。
  $C_p^i = \dfrac{p!}{i!(p-i)!} = \dfrac pi \dfrac{(p-1)!}{(i-1)!(p-1-(i-1))!} = \dfrac pi C_{p-1}^{i-1}$ 
- $\sum\limits_{k=\max(1,n-N+M)}^{\min(n,M)} C_{M-1}^{k-1} C_{{N-M}}^{n-k} = C_{N-1}^{n-1}$，考虑左式和右式的意义即可。
- **二项式定理**：$(a+b)^n= C_n^0a^n+C_n^1a^{n-1}b^1+\dots+C_n^nb_n = \sum\limits_{k=0}^n C_n^k a^{n-k}b^k$ 
- $\sum\limits_{i=0}^n C_n^i = 2^n$，写出 $(1+x)^n$ 的二项式定理，然后令 $x=1$ 即可。
## 1-X 典例
### 1-X-1 环形染色问题
- **题目描述**：$n$ 个点的环，有 $m$ 种颜色，每个点必须染成一种颜色，相邻颜色不同，求方案数。
- **数据范围**：$3\le n,m \le 10^6$ 
- *思路* 
	为了方便，我们规定 $n$ 个点的编号为 $1,2,\dots,n$，且 $n$ 号点和 $1$ 号点是相邻的，每个点的颜色用 $a_i$ 表示。
	dp 思想，令 $f_i$ 表示考虑 $i$ 个点构成的环染成 $m$ 种颜色的方案数。
	转移有两种情况：$f_n = \begin{cases} (m-2) \cdot f_{n-1} & a_1 \not= a_{n-1} \\ (m-1) \cdot f_{n-2} &a_1=a_{n-1} \end{cases}$，上式好理解，下式难点在于求 $n$ 号点插入前的方案数，本身这个情况是不合法的，但把 $a_1$ 和 $a_{n-1}$ 合成一个点就合法了，且方案数等价，所以要乘 $f_{n-2}$。所以状态转移方程为 $f_n = (m-2)f_{n-1} + (m-1)f_{n-2}$ 
	$n \le 3$ 时手算，特别地，为什么 $n=3$ 时还要算，因为 $n=3$ 时 $a_1=a_{n-1}$ 这种情况合成一个点后依然不合法，不满足状态转移方程。
### 1-X-2 错排问题
洛谷P1595 信封问题
- **题目描述**：某人写了 $n$ 封信和 $n$ 个信封，如果所有的信都装错了信封。求所有信都装错信封共有多少种不同情况。
- **数据范围**：$n\le 20$（$n\le 20$ 是不为了让你写高精度，但其实该问题可以 $O(n)$ 解决）
- *思路* 
	令 $d[n]$ 表示 $n$ 封信错装的方案数，显然 $d[1]=0, d[2]=1$ 
	且有递推公式 $d[i] = (i - 1) * (d[i - 1] + d[i - 2])$ 
	最终答案为 $d[n]$ 
# 2 卢卡斯定理 / Lucas 定理
**定理**如下：
$$
\text {若 } p \text{ 为质数，则: }  C_a^b \equiv C_{\lfloor \frac ap \rfloor}^{\lfloor \frac bp \rfloor} \times C_{a\ \bmod\ p}^{b\ \bmod\ p} \pmod p
$$
**证明** 
- 由二项式定理可知：$(1+x)^p \equiv C_p^0 + C_p^1 x^1 + \dots + C_p^px^p \equiv C_p^0x^0 + C_p^px^p \equiv 1 + x^p \pmod p$ 
- 令 $a=k_1p+r_1,\ b=k_2p+r_2,\ (r_1<p,\ r_2<p)$，易知 $k_1 = \left\lfloor \dfrac ap \right\rfloor,\ k_2 = \left\lfloor \dfrac bp \right\rfloor$ 且 $r_1 = a \bmod p,\ r_2 = b \bmod p$ 
- 则有 $(1+x)^a = (1+x)^{k_1p+r_1} = (1+x)^{k_1p} \cdot (1+x)^{r_1}$ 和 $(1+x)^a \equiv ((1+x)^p)^{k_1} \cdot (1+x)^{r_1} \equiv (1+x^p)^{k_1}(1+x)^{r_1} \pmod p$ 
- 通过 $(1+x)^a \equiv (1+x^p)^{k_1}(1+x)^{r_1} \pmod p$，对比 $x^b$ 前系数有：$C_a^b x^b \equiv C_{k_1}^{k_2} x^{k_2p} \cdot C_{r_1}^{r_2} x^{r_2} \equiv C_{k_1}^{k_2} C_{r_1}^{r_2} x^{k_2p+r_2} \equiv C_{k_1}^{k_2} C_{r_1}^{r_2} x^{b} \pmod p$ 
- 又 $k_1 = \left\lfloor \dfrac ap \right\rfloor,\ k_2 = \left\lfloor \dfrac bp \right\rfloor$ 且 $r_1 = a \bmod p,\ r_2 = b \bmod p$ 
  故有 $C_a^b \equiv C_{\lfloor \frac ap \rfloor}^{\lfloor \frac bp \rfloor} \times C_{a\ \bmod\ p}^{b\ \bmod\ p} \pmod p$，证毕！
- 证明较难，可以先记住结论。

# 3 卡特兰数
- **定义**：写出 $n$ 个数字排成一排，每个数字是 0 或 1，要求：对于每一个位置，从开始到这个位置中 1 出现的次数小于等于 0 出现的次数，方案数即为卡特兰数的第 $n$ 项。
- **结论**：$Catalan_n = C_{2n}^n - C_{2n}^{n-1} = \dfrac{C_{2n}^n}{n + 1}$ 
- **证明** 
	转化问题
	![](https://cdn.luogu.com.cn/upload/image_hosting/wc29i7om.png)
	卡特兰数第 $n$ 项的值等于：从原点走到 $A(n,n)$，只能向右或向上走，不能**碰到**红线，可以碰到绿线，求方案数。
	这张图对应的方案数就是 $Catalan_5$ 的值。
	你会发现无论如何都要走 $2n$ 步，如果不考虑不能碰到红线，那么很简单，令 $A(n,n)$，那么答案为：$C_{2n}^n$ 
	考虑如何去掉不合法路线，你会发现任意一个碰到红线的路线，将路线与红线**第一次相交的点**之后的部分沿着**红线**进行轴对称，终点变为了 $A'(n-1,n)$，不合法路径即为 $C_{2n}^{n-1}$ 
	答案为 $C_{2n}^n - C_{2n}^{n-1}$ 
	为什么过红线才轴对称？注意这句话：**第一次相交的点**之后的部分。为什么强调这个？因为交点后面的翻转并不影响起点是原点，而如果不过红线就直接轴对称的话，起点就变成了 $(-1,1)$，这与原题要求不符。那么任何一个碰到红线的路线，经过轴对称后，会对应且**唯一对应**一条从原点到 $A'$ 的路线，并且这样的路线是**不重不漏**的。
	然后进行化简可以得到 $Catalan_n = C_{2n}^n - C_{2n}^{n-1} = \dfrac{C_{2n}^n}{n + 1}$，化简过程如下：$$
	C_{2n}^n - C_{2n}^{n-1} = \dfrac{(2n)!}{n!n!} - \dfrac{(2n)!}{(n-1)!(n+1)!} = \dfrac{(n+1)(2n)! - n(2n)!}{(n+1)!n!} = \dfrac {(2n)!}{(n+1)n!n!} = \dfrac{C_{2n}^n}{n+1}$$

# 4 容斥原理
- 对于 $n$ 个集合 $A_1,\dots,A_n$，并集与交集之间有如下关系：
$$
\left| \bigcup_{i=1}^n A_i \right| = \sum_{k=1}^n (-1)^{k-1} \sum_{1 \le i_1 <\dots<i_k \le n} |A_{i_1} \cap \dots \cap A_{i_k} |
$$
- 为什么容斥原理能够叫作原理？因为它可以像“加法原理”“乘法原理”一样解决很多问题
- 容斥原理的本质是：把集合并的问题转化为集合交的问题，而往往“交”可以保证集合的很多性质，从而使问题容易解决。

AcWing890. 能被整除的数
- **题目描述**：给定一个整数 $n$ 和 $m$ 个不同的质数 $p_1,p_2,\cdots,p_m$，请你求出 $1\sim n$ 中能被 $p_1,p_2,\cdots,p_m$ 中的至少一个数整除的整数有多少个。
- **数据范围**：$1\le m \le 16,\ 1\le n, p_i \le 10^9$ 
- *思路* 
	令集合 $S_{p_1} \cap S_{p_2} \cap \cdots \cap S_{p_k}$ 表示能够同时被 $p_1, p_2, \cdots, p_k$ 同时整除的数的个数，由于 $p_1, p_2, \cdots, p_k$ 都是素数，故 $|S_{p_1} \cap S_{p_2} \cap \cdots \cap S_{p_k}| = \left\lfloor \dfrac{n}{p_1p_2\cdots p_k} \right\rfloor$ 
	由容斥原理，最终解为：
	$\begin{aligned} &|S_{p_1} \cup S_{p_2} \cup \cdots \cup S_{p_m}| \\ =& |S_{p_1}| + |S_{p_2}| + |S_{p_3}| + \cdots \\ &- |S_{p_1} \cap S_{p_2}| - |S_{p_1} \cap S_{p_3}| - \cdots \\ &+ |S_{p_1} \cap S_{p_2} \cap S_{p_3}| + \cdots \\ &-\cdots \end{aligned}$ 
	用二进制枚举实现（和状态压缩 dp 很像）
- *代码* 
	```cpp
	#include <iostream>
	
	using namespace std;
	
	typedef long long LL;
	
	const int N = 20;
	
	int n, m, ans;
	int p[N];
	
	int main()
	{
	    cin >> n >> m;
	    for (int i = 0; i < m; i++)
	        cin >> p[i];
	    for (int S = 1; S < (1 << m); S++)
	    {
	        int t = 1, cnt = 0;
	        for (int j = 0; j < m; j++)
	        {
	            if ((S >> j) & 1)
	            {
	                cnt++;
	                if ((LL)t * p[j] > n)
	                {
	                    t = -1;
	                    break;
	                }
	                t *= p[j];
	            }
	        }
	        if (t != -1)
	        {
	            if (cnt % 2 == 1)
	                ans += n / t;
	            else
	                ans -= n / t;
	        }
	    }
	    cout << ans << endl;
	    return 0;
	}
	```
