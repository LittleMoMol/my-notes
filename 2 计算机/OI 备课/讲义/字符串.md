# 2 KMP
## 2-1 知识精讲
### 2-1-1 前置知识
- **KMP 在干什么**：KMP算法（Knuth-Morris-Pratt 算法）用于在**文本串中快速查找模式串**。
	- **举例**：如在文本串 $abcdefkababc$ 中查找模式串 $abc$ 出现的次数及具体位置。
- **核心思想**：通过预处理模式串，构建部分匹配表（next数组），避免在匹配失败时回溯文本串指针，从而提高效率。
- **难点**：next 数组的求法
- 一些**概念** 
	- **文本串**：待搜索的字符串
	- **模式串**：需要在文本串中查找的子串。
	- **公共前后缀（border）**：一个字符串 $s$ 的 **border** 为 $s$ 的一个非 $s$ 自身的子串 $t$，满足 $t$ 既是 $s$ 的前缀，又是 $s$ 的后缀
	- **最长公共前后缀**：最长的 border
	- **部分匹配表（next 数组）**：$\text{next}[i]$ 记录模式串前 $i$ 个字符的最长公共前后缀的长度，可用于匹配失败时跳过不必要的比较。
- 一些**例子** 
	- 模式串 $abcggabc$ 的 border 只有 $abc$，且最长 border 是 $abc$，next 数组为：$\begin{aligned} &abcggabc \\ \text{next}:&00000123 \end{aligned}$ 
	- 模式串 $aaaaa$ 的 border 有 $a,aa,aaa,aaaa$，且最长 border 是 $aaaa$，next 数组为：$\begin{aligned} &aaaaa \\ \text{next}:&01234 \end{aligned}$ 
	- 模式串 $abcba$ 的 border 只有 $a$，且最长 border 是 $a$，next 数组为：$\begin{aligned} &abcba \\ \text{next}:&00001 \end{aligned}$ 
	- 模式串 $abcabckkabcabc$ 的 border 有 $abc,abcabc$，且最长 border 是 $abcabc$，next 数组为：$\begin{aligned} &abcabcakabcabc \\ \text{next}:&00012310123456 \end{aligned}$ 
- 一些**结论**（很显然）
	- 最长 border 的长度与 next 数组最后一个数字相等
	- $\text{next}[i]$ 最多比 $\text{next}[i-1]$ 大 $1$ 
	- $\text{next}[i] \le i-1$ 
### 2-1-2 暴力解法
这个相信大家都会，时间复杂度 $O(nm)$（$n$ 为文本串长度，$m$ 为模式串长度）
```cpp
#include <iostream>
#include <string>

using namespace std;

const int N = 1e6 + 10;

string s1, s2;
int len1, len2;

int main()
{
    cin >> s1 >> s2; // s1 是文本串，s2 是模式串
    len1 = s1.size();
    len2 = s2.size();
    s1 = ' ' + s1;
    s2 = ' ' + s2;
    for (int i = 1; i + len2 <= len1; i++)
    {
        bool flag = true;
        for (int j = 1; j <= len2; j++)
            if (s1[i + j - 1] != s2[j])
            {
                flag = false;
                break;
            }
        if (flag)
        {
            // 此时匹配成功，具体执行后续操作即可
        }
    }
    return 0;
}
```
### 2-1-3 暴力解法中浪费的信息
我们一位一位地往后遍历字符串的时候，由于已经知道之前遍历的字符，故有很多字符是被我们重复多次扫描的，造成时间上的浪费。
我们举一个例子，文本串为 $aaaaaab$，模式串为 $aaab$ 时，暴力算法过程详细如下：
$$
\begin{matrix} 
\text{扫描次数:} & 1 & 2 & 3 & 4 & 3 & 2 & 1  \\
\text{文本串:} & a & a & a & a & a & a & b \\
\text{模式串:} & a & a & a & b \\
\text{模式串:} && a & a & a & b \\
\text{模式串:} &&& a & a & a & b \\
\text{模式串:} &&&& a & a & a & b \\
\end{matrix}
$$
所以文本串中很多字符被扫描了多次，而导致扫描次数不止一次的本质原因为：在模式串失配时，文本串的指针会退回到之前扫过的某个位置。如果我们能在保证正确性的前提下，确保文本串指针只会往前走（即失配时也不会回溯），那么时间复杂度便会大大降低。
### 2-1-4 考虑最大公共前后缀的作用
KMP 算法匹配失败的时候，回去看最后一个匹配的字符它所对应的 next 数值，若 next 值为 x，则直接跳过子串前 x 个字符，从子串第 x+1 个字符继续开始比对（我们先假设 next 数组已经求出来了）
![[Pasted image 20250205114102.png]]
你会发现，这种方法下，文本串的指针是不可能回溯的，这也就保证了时间复杂度为线性。
可以证明：这种方法不会错过文本串中任何一个可能匹配成功的子串，也能将时间复杂度优化到 $O(n)$ 
这部分代码如下：
```cpp
cin >> s1 >> s2;
len1 = s1.size();
len2 = s2.size();
s1 = ' ' + s1;
s2 = ' ' + s2;
GetNext();
j = 0;
for (int i = 1; i <= len1; i ++ )
{
	while (j && s1[i] != s2[j + 1]) j = nxt[j];
	if (s1[i] == s2[j + 1]) j ++ ;
	if (j == len2)
	{
		//此时匹配成功，执行需要的操作即可
	}
}
```
### 2-1-5 难点：求模式串的 next 数组
回顾一下 next 数组的含义：$\text{next}[i]$ 记录模式串前 $i$ 个字符的最长公共前后缀的长度。
再回顾一下 next 数组的两个性质：
1. $\text{next}[i]$ 最多比 $\text{next}[i-1]$ 大 $1$ 
2. $\text{next}[i] \le i-1$ 
根据递推求 next 数组
显然，$\text{next}[1]=0$ 
假设 $\text{next}[1],\text{next}[2],\cdots,\text{next}[i-1]$ 我们已经求出来了，现在求 $\text{next}[i]$，具体过程如下：
如果模式串的第 $i$ 位与第 $\text{next}[i-1]+1$ 位相同，则 $\text{next}[i] = \text{next}[i-1]+1$ 
否则，如果模式串的第 $i$ 位与第 $\text{next}[\text{next}[i-1]] + 1$ 位相同，则 $\text{next}[i] = \text{next}[\text{next}[i-1]] + 1$ 
否则，如果模式串的第 $i$ 位与第 $\text{next}[\text{next}[\text{next}[i-1]]] + 1$ 位相同，则 $\text{next}[i] = \text{next}[\text{next}[\text{next}[i-1]]] + 1$ 
……
如果模式串的第 $i$ 位与第 $1$ 位还是不同，那么 $\text{next}[i] = 0$ 
可以证明这种递推方式的正确性。
此部分代码如下：
```cpp
void GetNext()
{
	j = 0;
	for (int i = 2; i <= len2; i ++ )
	{
		while (j && s2[j + 1] != s2[i]) j = nxt[j];
		if (s2[j + 1] == s2[i]) j ++ ;
		nxt[i] = j;
	}
	return;
}
```

### 2-2-4 洛谷 P1470 最长前缀 Longest Prefix
- **题目描述**：如果一个集合 $P$ 中的元素可以串起来（元素可以重复使用）组成一个字符串 $s$ ，那么我们认为字符串 $s$ 可以分解为 $P$ 中的元素，元素不一定要全部出现。设计一个程序，输入一个元素集合以及一个大写字母构成的字符串，设 $s'$ 是序列 $s$ 的最长前缀，使其可以分解为给出的集合 $P$ 中的元素，求 $s'$ 的长度 $k$ 
- **数据范围**：$1\le \text{card}(P) \le 200$，$1\le |S| \le 2\times 10^5$，$P$ 中的元素长度均不超过 $10$ 
- *思路* 
	对每一个 $P$ 中元素进行一次 KMP，用二维数组标记每一个 $P$ 中元素在字符串 $s$ 中出现的所有位置。
	然后对 $s$ 进行 dp，令 $f[i]$ 表示前 $i$ 个字符是否可以分解为集合中的字符，$f[i]=true$ 表示可以，$f[i]=false$ 表示不可以。
	显然，$f[i]=true$ 的充要条件为存在一个比 $i$ 小的 $j$，满足 $f[j]=true$ 且从第 $j+1$ 到第 $i$ 个字符组成的字符串是 $P$ 中的一个元素。
	根据上面的充要条件和 KMP 之后得到的信息进行 dp 即可。
	最后一个为 $true$ 的 $f[i]$ 对应的 $i$ 即为答案。

# 3 哈希（hash）
## 3-1 知识精讲
- 当需要 $O(1)$ 来快速比对两个 $O(n)$ 的东西时，用哈希！
- **进制哈希**：对字符串单向加密的过程，把每一个字符串映射成大概率不同的数字（为了减小冲突的概率，你可以采取双哈希，但这里不作涉及）
- **区间哈希**：区间 $l\sim r$ 构成的子串对应的哈希值公式为 $h[r] - h[l-1] * p[r-l+1]$（其中 $p[i] = base^i$）
## 3-2 哈希（hash）习题
### 3-2-1 洛谷 P3370 【模板】字符串哈希
- **题目描述**：给 $n$ 个字符串，找出这 $n$ 个字符串中共有多少个不同的字符串
- **数据范围**：$n\le 10000$，所有字符串长度总和小于 $10^7$ 
- *思路* 
	选取进制与模数，把字符串映射成数字之后用 sort 排序，相邻相等的数字对应的字符串相同，此时很容易求出共有多少个不同的字符串
- *代码* 
	```cpp
	#include <iostream>
	#include <string>
	#include <algorithm>
	
	using namespace std;
	
	typedef unsigned long long ull;
	
	ull a[10010];
	ull base = 131;
	ull mod = 212370440130137957;
	int n, sum;
	string s;
	
	int ha(string s)
	{
	    ull res = 0;
	    int len = s.size();
	    for (int i = 0; i < len; i++)
	        res = (res * base + (ull)s[i]) % mod;
	    return res;
	}
	
	int main()
	{
	    cin >> n;
	    for (int i = 1; i <= n; i++)
	    {
	        cin >> s;
	        a[i] = ha(s);
	    }
	    sort(a + 1, a + 1 + n);
	    for (int i = 1; i < n; i++)
	        if (a[i] != a[i + 1])
	            sum++;
	    cout << ++sum << endl;
	    return 0;
	}
	```
