## P5436 【XR-2】缘分
**题意** 
$O(1)$ 求不超过 $n$ 的两个正整数的最小公倍数的最大值，$1\le n\le 10^9$ 
## P9825 \[ICPC 2020 Shanghai R\] Fibonacci
**题意** 
$f_n$ 是斐波那契数列，给定 $n$，计算 $\sum\limits_{i=1}^n \sum\limits_{j=i+1}^n g(f_i, f_j)$，其中当 $x\cdot y$ 为偶数时 $g(x,y)=1$，否则 $g(x,y)=0$，$1\le n\le 10^9$ 
**思路** 
斐波那契数列奇偶性规律：奇奇偶奇奇偶……
总共偶数个数为 $x= n / 3$ 
想要使乘积是偶数，只有两种可能：奇数乘偶数（贡献值 $x(n-x)$）、偶数乘偶数（贡献值 $\dfrac{x(x-1)}{2}$）
故答案为 $x(n-x) + \dfrac{x(x-1)}2$

## P1072 \[NOIP 2009 提高组\] Hankson 的趣味题
**题意** 
已知正整数 $a_0, a_1, b_0, b_1$，设某未知正整数 $x$ 满足：$x$ 和 $a_0$ 的最大公约数是 $a_1$，$x$ 和 $b_0$ 的最小公倍数是 $b_1$，求满足条件的 $x$ 的个数（数据保证：$a_1 \mid a_0,\ b_0 \mid b_1$ 以及 $n\le 2000$ 且 $1\le a_0, a_1, b_0, b_1 \le 2\times 10^9$）
**思路** 
由 $\gcd(x, a_0) = a_1$ 可知 $\gcd(x/a_1, a_0/a_1) = 1$ 
由 $\mathrm{lcm}(x,b_0)=b_1$ 可知 $\gcd(x,b_0) = xb_0 / b_1$，故 $\gcd(x/(xb_0/b_1), b_0/(xb_0/b_1)) = 1$，即 $\gcd(b_1/b_0, b_1/x)=1$ 
观察最终两个式子可知：$x$ 是 $a_1$ 的整数倍且是 $b_1$ 的因子
通过 $O(\sqrt{b_1})$ 枚举 $b_1$ 的因子，如果这个因子是 $a_1$ 的整数倍且满足上述两个式子，答案加一

## P2520 \[HAOI2011\] 向量
**题意** 
给你一对数 $(a,b)$，你可以任意使用 $(a,b), (a,-b), (-a,b), (-a,-b), (b,a), (b,-a), (-b,a), (-b,-a)$ 这些向量，问你能不能拼出另一个向量 $(x,y)$，共 $t$ 组询问
说明：这里的拼就是使得你选出的向量之和为 $(x,y)$ 
$t\leq50000,\ -2\times10^9\leq a,b,x,y\leq2\times10^9$ 
**思路** 
由对称性，实际只有四种操作 $(a,b), (a,-b), (b,a), (b,-a)$ 
故解方程组 $k(a,b) + w(a,-b) + q(b,a) + c(b,-a) = (x,y)$，即 $\begin{cases} (k+w)a + (q+c)b = x \\ (k-w)b + (q-c)a = y \end{cases}$ 
由裴蜀定理：$ax+by=c$ 有整数解 $x,y$ 的充要条件是 $\gcd(a,b)\mid c$ 
故使 $(k+w), (q+c), (k-w), (q-c)$ 都为整数的充要条件是 $\gcd(a,b) \mid x,\ \gcd(a,b) \mid y$ 
但 $k+w, k-w$ 都为整数是得不到 $k,w$ 都为整数的
令 $f=k+w, g=k-w$，则 $k=(f+g)/2,\ w=(f-g)/2$，故还需要 $f,g$ 同时为奇数或偶数，$q+c,q-c$ 同理
- 当 $k+w,k-w,q+c,q-c$ 同时为偶数时，将 $(k+w)a + (q+c)b=x$ 左式提出 $2$ 得到 $2\gcd(a,b)\mid x$，同理有 $2\gcd(a,b)\mid y$ 
- 当 $k+w,k-w,q+c,q-c$ 同时为奇数时，将 $(k+w)a + (q+c)b=x$ 左式先加 $a$ 再加 $b$ 再提出 $2$ 得到 $2\gcd(a,b)\mid (x+a+b)$，同理 $2\gcd(a,b)\mid (y+a+b)$ 
- 当 $k+w,k-w$ 奇且 $q+c,q-c$ 偶时，有 $2\gcd(a,b) \mid (x+a),\ 2\gcd(a,b) \mid (y+b)$ 
- 当 $k+w,k-w$ 偶且 $q+c,q-c$ 奇时，有 $2\gcd(a,b) \mid (x+b),\ 2\gcd(a,b) \mid (y+a)$ 

只要满足上述任意一种情况，就有解，否则无解
## P1890 gcd区间
**题意** 
给定 $n$ 个正整数 $a_1,a_2,\dots,a_n$。
$m$ 次询问，每次询问给定一个区间 $[l,r]$，输出 $a_l,a_{l+1},\dots,a_r$ 的最大公因数。
对于 $100\%$ 的数据，$1 \leq l \leq r \leq n \leq 1000$，$1\leq m \leq 10^6$，$1 \leq a_i \leq 10^9$ 
**思路** 
dp，$f[i][j]$ 表示区间 $[i,j]$ 中的 $\gcd$，则状态转移方程为 $f[i][j] = \gcd(f[i][i], f[i+1][j])$ 
边界 $f[i][i] = i$ 
也可以用线段树维护

## P1835 素数密度
**题意** 
给定 $L,R$，请计算区间 $[L,R]$ 中素数的个数
$1\le L \le R \le 2^{31},\ R-L\le 10^6$ 
**思路** 
1. 筛出 $1\sim50000$ 中的所有质数，并且对合数打上标记.
2. 在 $[L,R]$ 的范围呢用我们已求出的质数筛出其中的合数（设 $p$ 为质数,则$i*p$ 一定不为质数），并对其打上标记
3. 遍历 $[L,R]$，没有打标记的元素即为我们所求的素数
