# 1 数论基础知识
1. **整除**的定义：对于任意的整数 $a,b$，若存在整数 $c$ 使得 $b=ac$，则称：$a$ 整除 $b$，记为 $a \mid b$（换句话说，$\dfrac ba$ 是个整数，$b \ge a$）
	- 若 $a \mid b,\ a\mid c$，则 $a\mid (bx+cy)$，其中 $x,y$ 为任意整数
2. **质数、合数、约数** 
   - 若 $d \mid n$，则 $d$ 为 $n$ 的一个**约数**（在我们研究的数论问题中，约数也可以称为**因数**）
   - 在大于 1 的整数中，如果只包含 1 和这个数本身这两个约数，就被称为**质数**（也叫**素数**）
   - 在大于 1 的整数中，不是素数的数就是**合数** 
   - $0,1$ 既不是质数也不是合数；2 是最小的素数，也是唯一一个偶素数。
3. **算术基本定理**：任意正整数 $N>1$，都能被质数幂唯一分解。
4. **约数个数定理**：由算数基本定理我们令任意大于 1 的整数 $N=p_1^{\alpha_1}~p_2^{\alpha_2}\dots~ p_n^{\alpha_n}$，则 $N$ 的正因数个数 $d(N)$ 有 $(\alpha_1+1)~(\alpha_2+1)\cdots(\alpha_n+1)$ 个。
5. **约数和定理**：由算数基本定理我们令任意大于 1 的整数 $N=p_1^{\alpha_1}~p_2^{\alpha_2}\dots~ p_n^{\alpha_n}$，则 $N$ 的所有正因数和 $\sigma(N)$ 为 $(1+p_1+p_1^2+\dots+p_1^{\alpha_1})~(1+p_2+p_2^2+\dots+p_2^{\alpha_2})\dots(1+p_n+p_n^2+\dots+p_n^{\alpha_n})$ 
6. 对于一个整数 $N>1$，让它的所有正因数组成一个递增序列 $Q$，令该序列长度为 $len$，则 $Q_i Q_{len-i+1}=N$ 
7. 质数的判定——**试除法**：若 $d \mid n$，则必有 $\dfrac nd \mid n$，可知只用枚举到 $\sqrt n$，代码如下：
   ```cpp
   bool is_primer(int n)
   {
       if (n < 2) return false;
       for (int i = 2; i <= n / i; i ++ ) //判断条件不推荐 i*i<=n 和 i<=sqrt(n) 
           if (n % i == 0) return false;
       return true;
   }
   ```

8. 分解质因数——**试除法**：$n$ 最多有一个大于 $\sqrt n$ 的质因子，$1 \sim \sqrt n$ 枚举所有可能的因子，若 $i$ 不为质因子，由于 $1 \sim i-1$ 中的所有质因子已经处理完毕，故 $i$ 不可能对 $n$ 的分解有贡献。
   ```cpp
   void divide(int x)
   {
       for (int i = 2; i <= x / i; i ++ )
       {
           if (x % i == 0)
           {
               int s = 0;
               while (x % i == 0) x /= i, s ++ ;
               cout << i << ' ' << s << endl;
           }
       }
       if (x > 1) cout << x << ' ' << 1 << endl;
       cout << endl;
   }
   ```

9. **快速幂**：在 $O(\log k)$ 的时间复杂度之内求出 $a^k \bmod p$ 的结果。
   ```cpp
   //求 a^k%p, LL=long long
   int qmi(int a, int k, int p)
   {
       int res = 1;
       while (k)
       {
           if (k & 1) res = (LL)res * a % p;
           k >>= 1;
           a = (LL)a * a % p;
       }
       return res;
   }
   ```
10. **同余** 
	- 若 $a,b$ 除以 $m$ 所得的余数相同，则称 $a,b$ 关于模 $m$ 同余，记作 $a \equiv b \pmod m$ 
	- $a \equiv b \pmod m \Rightarrow m \mid (a-b)$ 
	- $a \equiv b \pmod m,\ c \equiv d \pmod m \Rightarrow a+c \equiv b+d \pmod m$ 
	- $a \equiv b \pmod m,\ c \equiv d \pmod m \Rightarrow ac \equiv bd \pmod m$ 
	- $a \bmod b = a- \left\lfloor\dfrac ab\right\rfloor \times b$ 
# 2 乘法逆元
## 2-1 乘法逆元的定义
- **为什么定义乘法逆元**？关于整数的运算已经有了加减乘，考虑到计算机除法为整除，故引入在模 p 意义下的乘法逆元来充当除法的效果。
- 若在 $\bmod p$ 意义下，对于一个整数 $a$，有 $ax \equiv 1 \pmod p$，那么这个整数 $x$ 即为 $a$ 的**乘法逆元**，同时 $a$ 也为 $x$ 的**乘法逆元**。$x$ 可以记为 $a^{-1}$，故有 $a \times a^{-1} \equiv 1 \pmod p$ 
- **性质 1**：$a$ 存在 $\bmod p$ 的乘法逆元的**充要条件**是 $\gcd(a,p)=1$，即 $a,\ p$ 互质。
- **性质 2**：若 $a^{-1}$ 是 $a$ 在模 $p$ 意义下的乘法逆元，则 $kp + a^{-1}$ 也是 $a$ 在模 $p$ 意义下的乘法逆元
	- **推论**：$a$ 在模 $p$ 意义下的乘法逆元，要么没有，要么有无穷个
## 2-2 求单个乘法逆元
- **问题**：给我们一个 $b$，我们要求得一个 $x$ 使得 $bx \equiv 1 \pmod p$（已知 $b,p$ 互质）
- **思路**：费马小定理 + 快速幂求逆元
  由于 $\gcd(b,p)=1$，由费马小定理可知：$b^{p-1} \equiv 1 \pmod p$，故 $b \times b^{p-2} \equiv 1 \pmod p$，所以 $b^{p-2}$ 必定是一个逆元。用快速幂求出即可。
## 2-3 线性求多个乘法逆元
- **问题**：请在 $O(n)$ 时间复杂度内求 $1 \sim n$ 在模 $p$ 意义下的乘法逆元（保证 $p$ 为素数）
- **解决方案**：***数学归纳法*** 
	- 首先有 $1^{-1} \equiv 1 \pmod p$ 
	- 假设我们已经求得了 $1 \sim i-1$ 的逆元
	- 若当前求 $i$ 在模 $p$ 意义下的乘法逆元，设 $p=ki+r,(1<r<i<p)$，即 $k$ 是 $\dfrac pi$ 的商，$r$ 是 $\dfrac pi$ 的余数，也即 $k = \left\lfloor \dfrac pi \right\rfloor,\ r=(p \bmod i)$ 
	- 由于 $p=ki+r$，故有 $ki+r \equiv 0 \pmod p$，左右乘上 $i^{-1}r^{-1}$ 可得：
		$$
		\begin{aligned}
		kr^{-1} + i^{-1} \equiv 0 \pmod p \\
		i^{-1} \equiv -kr^{-1} \pmod p \\
		i^{-1} \equiv -\left\lfloor \dfrac pi \right\rfloor \times (p \bmod i)^{-1} \pmod p \\
		i^{-1} \equiv p-\left\lfloor \dfrac pi \right\rfloor \times (p \bmod i)^{-1} \pmod p	
		\end{aligned}
		$$ 
	- 我们已经求得了 $1 \sim i-1$ 的逆元，而 $(p \bmod i) < i$，故 $(p\bmod i)^{-1}$ 已知，可以 $O(1)$ 直接算出 $i^{-1}$ 
- **代码** 
	```cpp
	inv[1] = 1;
	for (int i = 2; i < p; i ++ )
	    inv[i] = (p - p / i) * inv[p % i] % p;
	```
# 3 欧几里得算法（gcd）和扩展欧几里得算法（exgcd）
## 3-1 欧几里得算法（gcd）
- 欧几里得算法又称**辗转相除法**，是指用于计算两个正整数 $a,b$ 的最大公约数。
- 计算公式：$\gcd(a,b)=\gcd(b,a \bmod b)$，以除数和余数反复做除法运算，当余数为 0 时，取当前算式除数为最大公约数。
- 代码
  ```cpp
  int gcd(int a, int b)
  {
      if(!b) return a;
      return gcd(b, a % b);
  }
  ```
- 证明 $\gcd(a,b)=\gcd(b,a \bmod b)$ 
	$a \bmod b = a- \left\lfloor\dfrac ab\right\rfloor \times b = a-kb$ 
	只需证 $\gcd(a,b) = \gcd(b,a-kb) = d$ 
	若 $d \mid a,\ d \mid b$，则 $d \mid b,\ d \mid a-kb$；若 $d \mid b,\ d \mid a-kb$ 则 $d \mid a,\ d \mid b$ 
	故 $a,b$ 和 $b,\ a-kb$ 的公约数集合是相同的，所以最大公约数也相同，故 $\gcd(a,b) = \gcd(b,a-kb)$ 
## 3-2 裴蜀定理
- **裴蜀定理**：对于任意正整数 $a,b$，一定存在非零整数 $x,y$，使得 $ax+by=\gcd(a,b)$，可以证明 $\gcd(a,b)$ 是 $ax+by$ 能够凑出来的最小正整数。
- **性质**：令 $ax+by=d$，易知 $d$ 一定是 $\gcd(a,b)$ 的倍数（因为 $a$ 是 $\gcd(a,b)$ 的倍数，$b$ 是 $\gcd(a,b)$ 的倍数，$ax+by$ 也一定是 $\gcd(a,b)$ 的倍数）
## 3-3 扩展欧几里德算法（exgcd）
- 扩展欧几里德算法即为 $exgcd$ ，对于任意整数 $a,b$，常用于求 $ax + by = \gcd(a, b)$ 的一组可行解
- **求解过程** 
	设 $a x_1 + b y_1 = \gcd(a, b)$ 
	$bx_2 + (a \bmod b)y_2 = \gcd(b,\  a \bmod b)$ 
	由欧几里得定理( $gcd$ ) 可知， $\gcd(a, b) = \gcd(b,\  a  \bmod  b)$ 
	所以就有了 $ax_1 + by_1 = bx_2 + (a \bmod b)y_2$ 
	现在我们去掉模运算，因为 $a  \bmod b = a - \left( \left\lfloor \dfrac{a}{b}\right\rfloor \times b \right)$ 
	所以 $a x_1 + b y_1 = bx_2 + \left( a - \left( \left\lfloor \dfrac{a}{b}\right\rfloor \times b \right) \right) \times y_2$ 
	化简得到 $ax_1 + by_1 = ay_2 + b \left( x_2 - \left\lfloor \dfrac{a}{b} \right\rfloor y_2 \right)$ 
	由于 $a,b$ 是任意的，故想要上式恒成立必然有 $x_1=y_2,\ y_1= x_2 - \left\lfloor \dfrac{a}{b} \right\rfloor y_2$ 
	所以想要求解 $x_1,y_1$ 只需求解 $x_2,y_2$，将 $bx_2 + (a \bmod b)y_2 = \gcd(b,\  a \bmod b)$ 中的 $b,a\bmod b$ 看成下一轮递归的 $a,b$ 
	那么不断递归求解，当 $b=0$ 时， $\begin{cases} x=1 \\ y=0 \end{cases}$ 就是一组解，回溯即可
- **代码** 
  ```cpp
  int Exgcd(int a, int b, int &x, int &y) 
  {
    if (!b) 
    {
      x = 1;
      y = 0;
      return a;
    }
    int d = Exgcd(b, a % b, x, y);
    int t = x;
    x = y;
    y = t - (a / b) * y;
    return d;
  }
  ```

# 4 欧拉函数、欧拉定理、扩展欧拉定理
## 4-1 欧拉函数
### 4-1-1 基本概念、计算公式
- **定义**：欧拉函数 $\varphi(n)$ 表示 $1 \sim n$ 中和 $n$ 互质的数的个数，其中 $\varphi(1) = 1$ 
- **计算公式**：若 $N = p_1^{\alpha_1}p_2^{\alpha_2}\dots p_k^{\alpha_k}$，其中 $p_i$ 均为质数，则 $\varphi(N) = N \prod\limits_{i=1}^k \left( 1 - \dfrac 1{p_i} \right)$ 
	-  *证明过程* 
		用容斥原理
		$\varphi(N) = N - \dfrac N{p_1} - \dfrac N{p_2} \dots - \dfrac N{p_k} + \dfrac N{p_1p_2} + \dfrac N{p_1p_3} + \dots - \dfrac N{p_1p_2p_3} - \dfrac N{p_1p_2p_4} \dots = N \prod\limits_{i=1}^k \left( 1 - \dfrac 1{p_i} \right)$ 
- **代码**：直接求欧拉函数
  ```cpp
  int n;
  cin >> n;
  int res = n;
  for (int i = 2; i <= n / i; i ++ )
      if (n % i == 0)
      {
          res = res / i * (i - 1);
          while (n % i == 0) n /= i;
      }
  if (n > 1) res = res / n * (n - 1);
  cout << res << endl;
  ```
### *4-1-2 欧拉函数的性质*
- **性质 1**：$p$ 是素数等价于 $\varphi(p)=p-1$，证明显然。
- **性质 2**：如果 $p$ 是素数，$a$ 是一个正整数，那么 $\varphi(p^a) = p^a - p^{a-1} = p^{a-1}(p-1)$ 
	- *证明过程* 
		考虑不超过 $p^a$ 且和 $p$ 不互质的数的个数；也就是不超过 $p^a$ 且能够被 $p$ 整除的数的个数，即 $kp\ (1 \le k \le p^{a-1})$，所以这样的数有 $p^{a-1}$ 个，则有 $\varphi(p^a) = p^a - p^{a-1} = p^{a-1}(p-1)$ 
- **性质 3**：设 $m,n$ 是**互质**的正整数，那么 $\varphi(mn) = \varphi(m)\varphi(n)$ 
	- *证明过程* 
		若 $\gcd(n,m)=1$，则 $n,m$ 没有相同的质因子，设 $n$ 的质因子个数为 $cnt_n$，$m$ 的质因子个数为 $cnt_m$，$n$ 的质因子分别为 $p_i\ (1 \le i \le cnt_n)$，$m$ 的质因子分别为 $p'_i\ (1 \le i \le cnt_m)$，$nm$ 的质因子分别为 $p''_i\ (1 \le i \le cnt_n + cnt_m)$，则 $\varphi(n) \cdot \varphi(m) = n\prod\limits_{i=1}^{cnt_n}\left(1-\dfrac{1}{p_i}\right) \cdot m\prod\limits_{i=1}^{cnt_n}\left(1-\dfrac{1}{p'_i}\right) = nm\prod\limits_{i=1}^{cnt_n + cnt_m}\left(1-\dfrac{1}{p''_i}\right) = \varphi(nm)$ 
- **性质 4**：当 $n$ 是奇数时，$\varphi(2n) = \varphi(n)$ 
	- *证明过程* 
		当 $n$ 为奇数时，$\gcd(n,2)=1$，由欧拉函数是积性函数可知，$\varphi(2n) = \varphi(2)\varphi(n)$，由于 $\varphi(2)=1$，所以 $\varphi(2n) = \varphi(n)$ 
- **性质 5**：设 $n$ 为一个正整数，则 $\sum\limits_{d \mid n} \varphi(d) = n$ 
	- *证明过程* 
		我们将 $1\sim n$ 的整数构成的集合分类。一个整数 $m$ 属于 $C_d$ 类，当且仅当 $\gcd(m, n) = d$，即 $\gcd\left( \dfrac md, \dfrac nd \right) = 1$。这样可以将 $1 \sim n$ 的所有整数分成互不相交的类，且每个整数只属于其中一个类，那么有 $\sum\limits_{d\mid n} |C_d| = n$。又因为 $C_d$ 中的数满足小于 $\dfrac nd$ 且与 $\dfrac nd$ 互质，所以 $|C_d| = \varphi\left( \dfrac nd \right)$，所以 $\sum\limits_{d\mid n} \varphi\left(\dfrac nd \right) = n$，即 $\sum\limits_{d\mid n} \varphi(d) = n$ 
- **性质 6**：$1\sim n$ 中与 $n$ 互质的数的和为 $\dfrac{\varphi(n)}2 \cdot n\ (n > 1)$ 
	- *证明过程* 
		首先证明：若 $\gcd(n,i)=1$，则 $\gcd(n,n-i)=1$ 
		利用反证法，设存在 $\gcd(n,i)=1$ 使得 $\gcd(n,n-i)=k$，那么 $(n-i) \bmod k = 0,\ n \bmod k = 0$，所以 $i \bmod k = 0$，即 $\gcd(n,i)=k$，与假设矛盾，所以原命题成立。
		由 $\gcd(n,i) = \gcd(n,n-i)=1$ 可知与 $n$ 互质的数都是成对出现的（$i$ 和 $(n-i)$ 成对），每一对的和都为 $n$，即可证明原命题。
- **性质 7**：$\varphi(n)\ (n>2)$ 为偶数
	- *证明过程* 
		若 $\gcd(n,i)=1$，则 $\gcd(n,n-i)=1$，所以与 $n$ 互质的数都是成对出现的，结论显然成立。
- **性质 8**：若 $p \mid n$ 且 $p^2 \mid n$，则 $\varphi(n) = \varphi\left( \dfrac np \right) \cdot p$；若 $p\mid n$ 且 $p^2 \not\mid n$，则 $\varphi(n) = \varphi\left(\dfrac np\right) \cdot (p-1)$ 
	- *证明过程* 
		- 若 $p \mid n$ 且 $p^2 \mid n$，则 $n$ 和 $\dfrac np$ 有相同的质因子，只是 $p$ 这一项的指数不同，有 $\dfrac{\varphi(n)}{\varphi\left(\dfrac np\right)} = \dfrac{n\prod\limits_{i=1}^m \left( 1-\dfrac 1{p_i} \right)}{\dfrac np \prod\limits_{i=1}^m \left( 1-\dfrac 1{p_i} \right)} = p$，则有 $\varphi(n) = \varphi\left( \dfrac np \right) \cdot p$ 
		- 若 $p\mid n$ 且 $p^2 \not\mid n$，又因为 $p$ 为质数，所以 $\gcd\left( p, \dfrac np \right)=1$，又因为欧拉函数是积性函数，所以 $\varphi(n) = \varphi\left(\dfrac np \right)\varphi(p) = \varphi\left(\dfrac np \right) \cdot (p-1)$
		综上所述，结论得证。
- $\varphi(n) = \sum\limits_{d\mid n} \dfrac{\mu(d) \cdot n}{d}$ （九）
### *4-1-3 性质的应用*
- **$O\left( \dfrac{\sqrt n}{ \log n} \right)$ 计算欧拉函数**：分解质因数，由性质二可以顺便算出 $\varphi(p^k)$，因为 $\varphi$ 是积性函数，所以直接把每个值相乘即可得到该数的 $\varphi$。直接分解质因数是 $O(\sqrt n)$ 的，但是只要预处理出根号内的质数就可以 $O\left( \dfrac{\sqrt n}{ \log n} \right)$ 计算一个数的欧拉函数了。
## 4-2 欧拉定理及其推论、费马小定理
### 4-2-1 基本概念、定理证明
- **欧拉定理**：设 $m$ 是一个正整数，$a$ 是一个正整数且 $\gcd(a,m)=1$，那么 $a^{\varphi(m)} \equiv 1 \pmod m$ 
	- *证明过程* 
		设 $X_1, X_2, \dots, X_{\varphi(m)}$ 是 $1\sim m$ 里与 $m$ 互质的数，容易发现它们模 $m$ 的余数两两不同，且每个余数都与 $m$ 互质（毕竟模了之后还是原数）
		现在我们证明 $aX_1, aX_2, \dots, aX_{\varphi(m)}$ 也具有这两个性质。
		- **模 $m$ 的余数两两不同**：用反证法，假设存在 $i,j$ 满足 $aX_i \equiv aX_j \pmod m$，则 $a(X_i - X_j) \equiv 0 \pmod m$，即 $m\mid a(X_i-X_j)$，由于 $\gcd(a,m)=1$ 且 $X_i - X_j$ 不可能是 $m$ 的倍数，所以模 $m$ 一定不为 0，假设不成立，原命题成立。
		- **模 $m$ 的余数都与 $m$ 互质**：$\gcd(a,m)=1,\ \gcd(X_i, m) = 1$，所以 $\gcd(m, aX_i) = \gcd(aX_i \bmod m, m) = 1$ 
		
		所以 $X_1, X_2, \dots, X_{\varphi(m)}$ 的每个数一定与 $aX_1, aX_2, \dots, aX_{\varphi(m)}$ 中的一个数同余，且一一对应。
		那么 $a^{\varphi(m)} \prod\limits_{i=1}^{\varphi(m)} X_i \equiv \prod\limits_{i=1}^{\varphi(m)}aX_i \equiv \prod\limits_{i=1}^{\varphi(m)} X_i \pmod m$，所以 $m \mid (a^{\varphi(m)} - 1) \prod\limits_{i=1}^{\varphi(m)}X_i$ 
		又因为 $\gcd\left( m, \prod\limits_{i=1}^{\varphi(m)} X_i \right) = 1$，所以 $m \mid (a^{\varphi(m)}-1)$，所以 $a^{\varphi(m)} \equiv 1 \pmod m$，结论得证。
- **欧拉定理推论**：若正整数 $a,m$ 互质，则对于任意正整数 $b$，有 $a^b \equiv a^{b\ \bmod\ \varphi(m)} \pmod b$ 
	- *证明过程* 
		设 $b = q \times \varphi(m) + r$，其中 $0 \le r \le \varphi(m)$，即 $r\equiv b \pmod {\varphi(m)}$ 
		则 $a^b \equiv a^{q \times \varphi(m)+r} \equiv 1^q \times a^r \equiv a^r \equiv a^{b\ \bmod\ \varphi(m)} \pmod m$ 
- **费马小定理**：若 $p$ 为质数，则 $a^{p-1} \equiv 1 \pmod p$ 
	- *证明过程* 
		当 $p$ 为质数时，$\varphi(p) = p - 1$，由欧拉定理可知，$a^{p-1} \equiv 1 \pmod p$，即证。
### 4-2-2 应用
- **求逆元**：若 $\gcd(a,m)=1$，则有求 $a$ 模 $m$ 的逆的方法：$a^{\varphi(m)} \equiv 1 \pmod m$，所以 $a \cdot a^{\varphi(m)-1} \equiv 1 \pmod m$，$a^{\varphi(m)-1}$ 就是 $a$ 模 $m$ 的逆元。
- **求同余方程**：同余方程 $ax \equiv b \pmod m$，两边同乘 $a^{-1}$ 得到 $a^{\varphi(m)-1} ax \equiv a^{\varphi(m)-1}b \pmod m$，所以 $x \equiv a^{\varphi(m)-1}b \pmod m$ 
## *4-3 扩展欧拉定理*
注意：此部分为扩展内容，上课不会讲。
**定理**：$\large a^c \equiv \begin{cases} a^{c\ \bmod\ \varphi(m)} & \gcd(a,m)=1 \\ a^c & \gcd(a,m) \not=1,\ c < \varphi(m) \\ a^{(c\ \bmod\ \varphi(m)) + \varphi(m)} & \gcd(a,m) \not= 1,\ c \ge \varphi(m) \end{cases} \pmod m$ 
**证明** 
- $\mathcal{Case\ 1}$ 当 $\gcd(a,m)=1$ 时
	由欧拉定理可知 $a^{\varphi(m)} \equiv 1 \pmod m$ 
	我们可以把指数 $c$ 拆成 $k \times \varphi(m) + (c \bmod \varphi(m))$，那么 $a^c = (a^{\varphi(m)})^k \times a^{c\ \bmod\ \varphi(m)}$，再取模可以得到 $a^c \equiv a^{c\ \bmod \ \varphi(m)} \pmod m$ 
- $\mathcal{Case\ 2}$ 当 $\gcd(a,m) \not= 1$ 且 $c < \varphi(m)$ 时
	 $a^c \equiv a^c \pmod m$，这很显然。
-  $\mathcal{Case\ 3}$ 当 $\gcd(a,m) \not= 1,\ c \ge \varphi(m)$ 时
	 需要证明 $a^c \equiv  a^{(c\ \bmod\ \varphi(m)) + \varphi(m)}  \pmod m$ 
	 - **转化**：如果想证明上式，只需证明 $a$ 的任意一个质因子 $p_i$ 满足 $p_i^c \equiv p_i^{(c\ \bmod\ \varphi(m)) + \varphi(m)} \pmod m$
		**转化的正确性证明**：若上式成立，设 $a$ 的质因数分解结果为 $a=p_1^{r_1}p_2^{r_2}p_3^{r_3}\dots$，其中 $p_i$ 为质因数，$r_i$ 为其对应的指数。
		根据同余式可乘，可以推出 $(p_i^c)^{r_i} \equiv (p_i^{(c\ \bmod\ \varphi(m)) + \varphi(m)})^{r_i} \pmod m$ 
		进而推出 $(p_1^{r_1}p_2^{r_2}p_3^{r_3}\dots)^c \equiv (p_1^{r_1}p_2^{r_2}p_3^{r_3}\dots)^{(c\ \bmod\ \varphi(m)) + \varphi(m)} \pmod m$ 
		所以 $a^c \equiv a^{(c\ \bmod\ \varphi(m)) + \varphi(m)} \pmod m$，所以若转化的命题成立，则原命题成立。
	- **证明转化后的式子**：$a$ 的任意一个质因子 $p_i$ 满足 $p_i^c \equiv p_i^{(c\ \bmod\ \varphi(m)) + \varphi(m)} \pmod m$ 
		- 若 $m,p$ 互质
			则 $p^{\varphi(m)} \equiv 1 \pmod m$，可将指数 $c$ 拆成 $k \times \varphi(m) + (c \bmod \varphi(m))$，那么 $p^c = (p^{\varphi(m)})^k \times p^{c\ \bmod\ \varphi(m)}$，再对 $m$ 取模，得到 $p^c \equiv (p^{\varphi(m)})^k \times p^{c\ \bmod\ \varphi(m)} \equiv 1^k \times p^{c\ \bmod\ \varphi(m)} \equiv 1 \times p^{c\ \bmod\ \varphi(m)} \equiv p^{(c\ \bmod\ \varphi(m)) + \varphi(m)} \pmod m$ 
		- 若 $m,p$ 不互质
			由于 $p$ 为质数，所以 $m \ge 2p$。设 $m = s \times p^r$（看作 $m$ 质因数分解后含有 $p^r$，剩下的都在 $s$ 里面且 $s$ 中不含因数 $p$
			那么有 $\gcd(s,p^r) = \gcd(s,p)=1$，则有 $\varphi(m) = \varphi(s) \times \varphi(p^r)$（欧拉函数是积性函数），即 $\varphi(s) \mid \varphi(m)$ 
			由欧拉定理可知：$p^{\varphi(m)} = (p^{\varphi(s)})^{\varphi(p^r)} \equiv 1^{\varphi(p^r)} = 1 \pmod s$ 
			同时乘以 $p^r$ 得到 $p^{r + \varphi(m)} \equiv p^r \pmod {s \times p^r}$，即 ==$p^{r + \varphi(m)} \equiv p^r \pmod m$== ①
			接下来我们证明 ==$\varphi(m) \ge r$== ②
			$\varphi(m) = \varphi(s) \times \varphi(p^r) \ge \varphi(p^r)$（在 $s=1,2$ 处取等）
			$\varphi(p^r) = p^r - p^{r-1} = (p-1) \times p^{r-1} \ge p^{r-1}$（$p \ge 2$，在 $p=2$ 时取等）
			数学归纳法证明 $p^{r-1} \ge r$：$r=1$ 时显然成立，假设 $r=i$ 时 $p^{i-1} \ge i$ 成立，则 $p^i = p \times p^{i-1} \ge 2 \times p^{i-1} = p^{i-1} + p^{i-1} \ge p^{i-1} + 1 \ge i + 1$ 成立，因此 $p^{r-1} \ge r$ 对任意的 $p,r\in \mathbb{Z},\ p \ge 2,\ r\ge 1$ 成立
			那么就有 $\varphi(m) \ge \varphi(p^r) \ge p^{r-1} \ge r$，即证。
			由于题设条件 $c \ge \varphi(m)$，再根据 ② 得到 $c \ge r$，那么根据 ① 有 $p^c = p^{c-r} \times p^r \equiv p^{c-r} \times p^{r+\varphi(m)} = p^{\varphi(m) + c} \pmod m$ 
			由于题设条件 $c \ge \varphi(m)$，记 $f(x) = p^x \bmod \varphi(m)\ (x \ge \varphi(m))$，上式表明对于任意的正整数 $x$，有 $f(x + \varphi(m)) = f(x)$。那么当 $x -\varphi(m) \ge \varphi(m)$ 也就是 $x \ge 2\varphi(m)$ 时，有 $f(x) = f(x - \varphi(m))$ 
			如果要计算 $f(c)$，可以递推 $f(x) = f(x - \varphi(m))$，每次让 $c$ 减去 $x - \varphi(m)$，但只有 $c \ge 2\varphi(m)$ 时才成立。
			如果把递推条件改成 $c \ge \varphi(m)$，显然最后得到的值为 $c \bmod \varphi(m)$。但现在条件是 $c \ge 2\varphi(m)$，这比 $c \ge \varphi(m)$ 时少减了一次 $\varphi(m)$，所以加回来就好了，即 $f(c) = f((c \bmod \varphi(m)) + \varphi(m))$，也就是 $a^c \equiv a^{(c\ \bmod\ \varphi(m)) + \varphi(m)} \pmod m$，即证！
- 综上，扩展欧拉定理得证
# 5 筛法
## 5-1 朴素筛法
**实现**：将 i 从 2 到 n-1 枚举，删掉所有 i 的倍数。剩下的就是质数。
**时间复杂度**：$O(n\log n)$
**代码** 
```cpp
void get_primes(int n)
{
	for (int i = 2; i <= n; i ++ )
	{
		if (!st[i]) primes[cnt ++ ] = n;
		for (int j = i + i; j <= n; j += i) st[j] = true;
	}
}
```
## 5-2 埃氏筛法
**本质**：每一个合数其实都是被它的某些质因子筛掉了
**实现**：将 i 从 2 到 n-1 枚举，当 i 是合数时，跳过；当 i 是质数时，删掉所有 i 的倍数。剩下的就是质数。
**时间复杂度**：$O(n\log\log n)$ 
**代码** 
```cpp
void get_primes(int n)
{
	for (int i = 2; i <= n; i ++ )
	{
		if (!st[i])
		{
			primes[cnt ++ ] = n;
			for (int j = i + i; j <= n; j += i) st[j] = true;
		}
	}
}
```

## 5-3 线性筛
**本质**：每一个合数都只被它的最小质因子质因子筛掉，所以难点在于如何快速寻找每个合数的最小质因子
**实现**：将 $i$ 从 $2$ 到 $n-1$ 枚举，枚举到 $i$ 时，已经得到了 $2\sim i-1$ 之间的所有质数。对于每个 $i$，从小到大枚举 $i$ 之前的所有质数 $primes[j]$。如果 $i\bmod primes[j] == 0$，那么 $primes[j]$ 一定是 $i$ 的最小质因子，也一定是 $primes[j] \times i$ 的最小质因子；如果 $i\bmod primes[j] !=0$，那么 $primes[j]$ 一定小于 $i$ 的所有质因子，故 $primes[j]$ 也一定是 $primes[j] \times i$ 的最小质因子。
**时间复杂度**：$O(n)$ 
**代码** 
```cpp
void get_primes(int n)
{
	for (int i = 2; i <= n; i ++ )
	{
		if (!st[i]) primes[cnt ++ ] = n;
		for (int j = 0; primes[j] <= n / i; j ++ )
		{
			st[primes[j] * i] = true;
			if (i % primes[j] == 0) break;
		}
	}
}
```
