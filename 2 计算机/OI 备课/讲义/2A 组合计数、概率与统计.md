# 1 排列与组合
- **乘法原理**：如果某件事需经 $k$ 个步骤才能完成，做第一步有 $m_1$ 种方法，做第二步有 $m_2$ 种方法，……，做第 $k$ 步有 $m_k$ 种方法，那么完成这件事共有 $\prod\limits_{i=1}^k m_i$ 种方法
- **加法原理**：如果某件事可由 $k$ 类不同途径之一去完成，在第一类途径中有 $m_1$ 种完成方法，在第二类途径中有 $m_2$ 种完成方法，……，在第 $k$ 类途径中有 $m_k$ 种完成方法，那么完成这件事共有 $\sum\limits_{i=1}^k m_i$ 种方法
- **排列**：从 $n$ 个不同元素种任取 $r\ (r\le n)$ 个元素排成一列（考虑元素先后出现次序），称此为一个**排列**，此种排列的总数记为 $P_n^r$，按乘法原理此种组合的总数为 $P_n^r = \dfrac{n!}{(n-r)!}$ 
	- **全排列**：若 $r=n$，则称为**全排列**，记为 $P_n$。显然全排列 $P_n = n!$ 
- **重复排列**：从 $n$ 个不同元素中每次取出一个，放回后再取下一个，如此连续取 $r$ 次所得的排列称为**重复排列**，此种重复排列共有 $n^r$ 个（注意这里 $r$ 允许大于 $n$）
- **组合**：从 $n$ 个不同元素中任取 $r\ (r\le n)$ 个元素并成一组（不考虑元素间的先后次序），称此为一个**组合**，此种组合的总数记为 $\dbinom nr$ 或 $C_n^r$，按乘法原理此种组合的总数为 $\dbinom nr = \dfrac{n!}{r!(n-r)!}$ 
	- **规定**：$0!=1,\ \dbinom n0 = 1$ 
	- **性质**：$\dbinom nr = \dbinom n{n-r}$ 
- **重复组合**：从 $n$ 个不同元素中每次取出一个，放回后再取下一个，如此连续取 $r$ 次所得的组合称为**重复组合**，此种重复组合总数为 $\dbinom{n+r-1}r$（注意这里 $r$ 允许大于 $n$）
	- *证明过程* 
		将此 $n$ 个元素画成 $n$ 个盒子（用 $n+1$ 条竖线表示），如果第 $i$ 个元素取到过一次，则在此盒子中加一个圈
		如此，所有的 $r$ 个圈和 $n+1$ 条竖线种除了两端的那两个竖线不可以动外，共有 $n+r-1$ 个圈和竖线可随意摆放，不同摆放的方式表示不同的取法
		因此重复组合数就等于在此 $n+r-1$ 个位置上任选 $r$ 个放圈，或此 $n+r-1$ 个位置上任选 $n-1$ 个放竖线，故总数为 $\dbinom{n+r-1}r$ 
- $C_n^m = C_{n-1}^m + C_{n-1}^{m-1}$，即讨论一下第 $n$ 个数选还是不选（dp 思想）
- $C_n^k = C_n^{k-1} \cdot \dfrac{n-k+1}{k}$，套公式即可。
- $\begin{cases} C_n^k > C_n^{k-1} & k < \dfrac{n+1}{2} \\ C_n^k < C_n^{k-1} &k>\dfrac{n+1}{2} \end{cases}$，直接能推出来。
- $C_p^i = \dfrac pi C_{p-1}^{i-1}$，套公式即可。
  $C_p^i = \dfrac{p!}{i!(p-i)!} = \dfrac pi \dfrac{(p-1)!}{(i-1)!(p-1-(i-1))!} = \dfrac pi C_{p-1}^{i-1}$ 
- **二项式定理**：$(a+b)^n= C_n^0a^n+C_n^1a^{n-1}b^1+\dots+C_n^nb_n = \sum\limits_{k=0}^n C_n^k a^{n-k}b^k$ 
- $\sum\limits_{i=0}^n C_n^i = 2^n$，写出 $(1+x)^n$ 的二项式定理，然后令 $x=1$ 即可。
# 2 两个经典例子
## 2-1 环形染色问题
- **题目描述**：$n$ 个点的环，有 $m$ 种颜色，每个点必须染成一种颜色，相邻颜色不同，求方案数。
- **数据范围**：$3\le n,m \le 10^6$ 
- *思路* 
	为了方便，我们规定 $n$ 个点的编号为 $1,2,\dots,n$，且 $n$ 号点和 $1$ 号点是相邻的，每个点的颜色用 $a_i$ 表示。
	dp 思想，令 $f_i$ 表示考虑 $i$ 个点构成的环染成 $m$ 种颜色的方案数。
	转移有两种情况：$f_n = \begin{cases} (m-2) \cdot f_{n-1} & a_1 \not= a_{n-1} \\ (m-1) \cdot f_{n-2} &a_1=a_{n-1} \end{cases}$，上式好理解，下式难点在于求 $n$ 号点插入前的方案数，本身这个情况是不合法的，但把 $a_1$ 和 $a_{n-1}$ 合成一个点就合法了，且方案数等价，所以要乘 $f_{n-2}$。所以状态转移方程为 $f_n = (m-2)f_{n-1} + (m-1)f_{n-2}$ 
	$n \le 3$ 时手算，特别地，为什么 $n=3$ 时还要算，因为 $n=3$ 时 $a_1=a_{n-1}$ 这种情况合成一个点后依然不合法，不满足状态转移方程。

洛谷P1595 信封问题
- **题目描述**：某人写了 $n$ 封信和 $n$ 个信封，如果所有的信都装错了信封。求所有信都装错信封共有多少种不同情况。
- **数据范围**：$n\le 20$（$n\le 20$ 是不为了让你写高精度，但其实该问题可以 $O(n)$ 解决）
- *思路* 
	令 $d[n]$ 表示 $n$ 封信错装的方案数，显然 $d[1]=0, d[2]=1$ 
	且有递推公式 $d[i] = (i - 1) * (d[i - 1] + d[i - 2])$ 
	最终答案为 $d[n]$

适用于数据范围较小的情形
```cpp
LL C(LL a, LL b)
{
    if (a < b) return 0;
    LL res = 1;
    for (int i = a, j = 1; j <= b; i -- , j ++ )
        res = res * i % mod * qmi(j, mod - 2) % mod;
    return res;
}
```

## 3-4 卢卡斯定理 / Lucas 定理
$n$ 次询问 $C_a^b \bmod p$，其中 $p$ 是质数，$1\le n \le 20,\ 1\le b\le a \le 10^{18},\ 1\le p \le 10^5$ 
**定理**如下：
$$
\text {若 } p \text{ 为质数，则: }  C_a^b \equiv C_{\lfloor \frac ap \rfloor}^{\lfloor \frac bp \rfloor} \times C_{a\ \bmod\ p}^{b\ \bmod\ p} \pmod p
$$
**证明** 
- 由二项式定理可知：$(1+x)^p \equiv C_p^0 + C_p^1 x^1 + \dots + C_p^px^p \equiv C_p^0x^0 + C_p^px^p \equiv 1 + x^p \pmod p$ 
- 令 $a=k_1p+r_1,\ b=k_2p+r_2,\ (r_1<p,\ r_2<p)$，易知 $k_1 = \left\lfloor \dfrac ap \right\rfloor,\ k_2 = \left\lfloor \dfrac bp \right\rfloor$ 且 $r_1 = a \bmod p,\ r_2 = b \bmod p$ 
- 则有 $(1+x)^a = (1+x)^{k_1p+r_1} = (1+x)^{k_1p} \cdot (1+x)^{r_1}$ 和 $(1+x)^a \equiv ((1+x)^p)^{k_1} \cdot (1+x)^{r_1} \equiv (1+x^p)^{k_1}(1+x)^{r_1} \pmod p$ 
- 通过 $(1+x)^a \equiv (1+x^p)^{k_1}(1+x)^{r_1} \pmod p$，对比 $x^b$ 前系数有：$C_a^b x^b \equiv C_{k_1}^{k_2} x^{k_2p} \cdot C_{r_1}^{r_2} x^{r_2} \equiv C_{k_1}^{k_2} C_{r_1}^{r_2} x^{k_2p+r_2} \equiv C_{k_1}^{k_2} C_{r_1}^{r_2} x^{b} \pmod p$ 
- 又 $k_1 = \left\lfloor \dfrac ap \right\rfloor,\ k_2 = \left\lfloor \dfrac bp \right\rfloor$ 且 $r_1 = a \bmod p,\ r_2 = b \bmod p$ 
  故有 $C_a^b \equiv C_{\lfloor \frac ap \rfloor}^{\lfloor \frac bp \rfloor} \times C_{a\ \bmod\ p}^{b\ \bmod\ p} \pmod p$，证毕！
- 证明较难，可以先记住结论。
**代码** 
```cpp
LL C(LL a, LL b)
{
    if (a < b) return 0;
    LL res = 1;
    for (int i = a, j = 1; j <= b; i -- , j ++ )
        res = res * i % mod * qmi(j, mod - 2) % mod;
    return res;
}

LL Lucas(LL a, LL b)
{
    if (a < mod && b < mod) return C(a, b);
    return C(a % mod, b % mod) * Lucas(a / mod, b / mod) % mod;
}
```
# 4 卡特兰数
- **定义**：写出 $2n$ 个数字排成一排，每个数字是 0 或 1（$n$ 个 0 和 $n$ 个 1），要求：对于每一个位置，从开始到这个位置中 1 出现的次数小于等于 0 出现的次数，方案数即为卡特兰数的第 $n$ 项。
- **结论**：$Catalan_n = C_{2n}^n - C_{2n}^{n-1} = \dfrac{C_{2n}^n}{n + 1}$ 
- **证明** 
	转化问题
	![](https://cdn.luogu.com.cn/upload/image_hosting/wc29i7om.png)
	卡特兰数第 $n$ 项的值等于：从原点走到 $A(n,n)$，只能向右或向上走，不能**碰到**红线，可以碰到绿线，求方案数。
	这张图对应的方案数就是 $Catalan_5$ 的值。
	你会发现无论如何都要走 $2n$ 步，如果不考虑不能碰到红线，那么很简单，令 $A(n,n)$，那么答案为：$C_{2n}^n$ 
	考虑如何去掉不合法路线，你会发现任意一个碰到红线的路线，将路线与红线**第一次相交的点**之后的部分沿着**红线**进行轴对称，终点变为了 $A'(n-1,n)$，不合法路径即为 $C_{2n}^{n-1}$ 
	答案为 $C_{2n}^n - C_{2n}^{n-1}$ 
	为什么过红线才轴对称？注意这句话：**第一次相交的点**之后的部分。为什么强调这个？因为交点后面的翻转并不影响起点是原点，而如果不过红线就直接轴对称的话，起点就变成了 $(-1,1)$，这与原题要求不符。那么任何一个碰到红线的路线，经过轴对称后，会对应且**唯一对应**一条从原点到 $A'$ 的路线，并且这样的路线是**不重不漏**的。
	然后进行化简可以得到 $Catalan_n = C_{2n}^n - C_{2n}^{n-1} = \dfrac{C_{2n}^n}{n + 1}$，化简过程如下：$$
	C_{2n}^n - C_{2n}^{n-1} = \dfrac{(2n)!}{n!n!} - \dfrac{(2n)!}{(n-1)!(n+1)!} = \dfrac{(n+1)(2n)! - n(2n)!}{(n+1)!n!} = \dfrac {(2n)!}{(n+1)n!n!} = \dfrac{C_{2n}^n}{n+1}$$
# 5 容斥原理
- 对于 $n$ 个集合 $A_1,\dots,A_n$，并集与交集之间有如下关系：
$$
\left| \bigcup_{i=1}^n A_i \right| = \sum_{k=1}^n (-1)^{k-1} \sum_{1 \le i_1 <\dots<i_k \le n} |A_{i_1} \cap \dots \cap A_{i_k} |
$$
- 为什么容斥原理能够叫作原理？因为它可以像“加法原理”“乘法原理”一样解决很多问题
- 容斥原理的本质是：把集合并的问题转化为集合交的问题，而往往“交”可以保证集合的很多性质，从而使问题容易解决。

AcWing890. 能被整除的数
- **题目描述**：给定一个整数 $n$ 和 $m$ 个不同的质数 $p_1,p_2,\cdots,p_m$，请你求出 $1\sim n$ 中能被 $p_1,p_2,\cdots,p_m$ 中的至少一个数整除的整数有多少个。
- **数据范围**：$1\le m \le 16,\ 1\le n, p_i \le 10^9$ 
- *思路* 
	令集合 $S_{p_1} \cap S_{p_2} \cap \cdots \cap S_{p_k}$ 表示能够同时被 $p_1, p_2, \cdots, p_k$ 同时整除的数的个数，由于 $p_1, p_2, \cdots, p_k$ 都是素数，故 $|S_{p_1} \cap S_{p_2} \cap \cdots \cap S_{p_k}| = \left\lfloor \dfrac{n}{p_1p_2\cdots p_k} \right\rfloor$ 
	由容斥原理，最终解为：
	$\begin{aligned} &|S_{p_1} \cup S_{p_2} \cup \cdots \cup S_{p_m}| \\ =& |S_{p_1}| + |S_{p_2}| + |S_{p_3}| + \cdots \\ &- |S_{p_1} \cap S_{p_2}| - |S_{p_1} \cap S_{p_3}| - \cdots \\ &+ |S_{p_1} \cap S_{p_2} \cap S_{p_3}| + \cdots \\ &-\cdots \end{aligned}$ 
	用二进制枚举实现（和状态压缩 dp 很像）
- *代码* 
	```cpp
	#include <iostream>
	
	using namespace std;
	
	typedef long long LL;
	
	const int N = 20;
	
	int n, m, ans;
	int p[N];
	
	int main()
	{
	    cin >> n >> m;
	    for (int i = 0; i < m; i++)
	        cin >> p[i];
	    for (int S = 1; S < (1 << m); S++)
	    {
	        int t = 1, cnt = 0;
	        for (int j = 0; j < m; j++)
	        {
	            if ((S >> j) & 1)
	            {
	                cnt++;
	                if ((LL)t * p[j] > n)
	                {
	                    t = -1;
	                    break;
	                }
	                t *= p[j];
	            }
	        }
	        if (t != -1)
	        {
	            if (cnt % 2 == 1)
	                ans += n / t;
	            else
	                ans -= n / t;
	        }
	    }
	    cout << ans << endl;
	    return 0;
	}
	```
# 6 随机事件与概率
## 6-1 随机事件及其运算
### 6-1-1 随机现象、样本空间
- **随机现象**：在一定的条件下，并不总是出现相同结果的现象称为**随机现象** 
	- **随机现象的特点**：结果不止一个；哪一个结果出现，人们事先不知道
- **确定性现象**：只有一个结果的现象称为**确定性现象** 
- **随机试验**：对在相同条件下可以重复的随机现象的观察、记录、实验称为**随机试验** 
	- 也有很多随机现象是不能重复的
	- 概率论与数理统计主要研究能大量重复的随机现象，但也十分注意研究不能重复的随机现象
- **样本空间**、**样本点**：随机现象的一切可能基本结果组成的集合称为**样本空间**，记为 $\Omega = \{\omega\}$，其中 $\omega$ 表示基本结果，又称为**样本点** 
	- 样本点是今后抽样的最基本单元
	- 认识随机现象首先要列出它的样本空间
- **样本空间注意事项** 
	- 样本空间中的元素可以是数，也可以不是数
	- 随机现象的样本空间至少有两个样本点。如果将确定性现象放在一起考虑，则含有一个样本点的样本空间对应的为确定性现象
	- 从样本空间含样本点的个数来区分，样本空间可分为有限与无限两类
- **离散样本空间**、**连续样本空间**：我们将样本点的个数为有限个或可列的情况归为一类，称为**离散样本空间**；而将样本点的个数为不可列无限个的情况归为另一类，称为**连续样本空间** 
### 6-1-2 随机事件、随机变量
- **随机事件**（**事件**）：随机现象的某些样本点组成的集合称为**随机事件**，简称**事件**，常用大写字母 $A,B,C,\cdots$ 表示
	- 随机事件是样本空间中的子集
	- 事件可以用集合表示，也可以用明白无误的语言描述
- **维恩图**（**Venn 图**）：再概率论中常用一个长方形表示样本空间 $\Omega$，用其中一个圆或其他几何图形表示事件 $A,B,C,\cdots$，这类图形称为**维恩图**（**Venn 图**）
- **发生了**：当子集 $A$ 中某个样本点出现了，就说事件 $A$ **发生了**，或者说**事件 $A$ 发生当且仅当 $A$ 中某个样本点出现了** 
- **基本事件**、**必然事件**、**不可能事件**：由样本空间 $\Omega$ 中的单个元素组成的子集称为**基本事件**；而样本空间 $\Omega$ 的最大自己（即 $\Omega$ 本身）称为**必然事件**；样本空间 $\Omega$ 的最小子集（即空集 $\varnothing$）称为**不可能事件** 
- **随机变量**：用来表示随机现象结果的变量称为**随机变量**，常用大写字母 $X,Y,Z$ 表示
	- 很多事件都可以用随机变量表示，表示时应写明随机变量的含义，而随机变量的含义是人们按需要设置出来的。
### 6-1-3 事件间的关系
对于同一个样本空间 $\Omega$（即同一个随机现象）来讨论事件之间的关系
- **包含关系**：如果属于 $A$ 的样本点必属于 $B$，则称 **$A$ 被包含在 $B$ 中**，或称 **$B$ 包含 $A$**，记为 $A\subset B$ 或 $B\supset A$ 
	- **概率论的语言**：$B$ 包含 $A$ 就是说事件 $A$ 发生必然导致事件 $B$ 发生
	- **性质**：任一事件 $A$，必有 $\varnothing \subset A \subset \Omega$ 
- **相等关系**：如果事件 $A,B$ 满足属于 $A$ 的样本点必属于 $B$，且属于 $B$ 的样本点必属于 $A$（即 $A\subset B$ 且 $B\subset A$），则称事件 $A$ 与 $B$ 相等，记为 $A=B$ 
	- **集合论观点**：两个事件相等意味着这两事件是同一个集合
	- **注意**：有时不同语言描述的事件也可能是同一事件。如“最后摸出的几个球全是黑球”和“最后摸出的一个球是黑球”
- **互不相容**：如果 $A$ 与 $B$ 没有相同的样本点，就称 **$A$ 与 $B$ 互不相容** 
	- **概率论的语言**：$A$ 与 $B$ 互不相容就是事件 $A$ 与事件 $B$ 不可能同时发生
### 6-1-4 事件间的运算
- **事件 $A$ 与 $B$ 的并**：记为 $A\cup B$，其含义为“由事件 $A$ 与 $B$ 中所有的样本点（相同的只计入一次）组成的新事件”
	- **概率论语言**：$A\cup B$ 发生就是事件 $A$ 与 $B$ 中至少有一个发生
- **事件 $A$ 与 $B$ 的交**：记为 $A\cap B$，或简记为 $AB$，其含义为“由事件 $A$ 与 $B$ 中公共的样本点组成的新事件”
	- **概率论语言**：$A\cap B$ 发生就是事件 $A$ 与 $B$ 同时发生
	- **性质**：$AB=\varnothing$ $\iff$ $A,B$ 是互不相容事件
- **有限并**、**可列并**、**有限交**、**可列交**：事件的并与交运算可推广到有限个或可列个事件，比如有事件 $A_1, A_2, \cdots$，则 $\bigcup\limits_{i=1}^n A_i$ 称为**有限并**，$\bigcup\limits_{i=1}^\infty A_i$ 称为**可列并**，$\bigcap\limits_{i=1}^n A_i$ 称为**有限交**，$\bigcap\limits_{i=1}^\infty A_i$ 称为**可列交** 
- **事件 $A$ 对 $B$ 的差**：记为 $A-B$，其含义为“由在事件 $A$ 中而不在 $B$ 中的样本点组成的新事件”
	- **概率论语言**：$A-B$ 发生就是事件 $A$ 发生而 $B$ 不发生
- **对立事件**：事件 $A$ 的**对立事件**记为 $\overline A$，其含义为“由在 $\Omega$ 中而不在 $A$ 中的样本点组成的新事件”
	- **概率论语言**：$\overline A$ 发生就是 $A$ 不发生，即 $\overline A = \Omega - A$ 
	- **性质**：对立事件是相互的，即 $\overline{\overline A} = A$ 
	- **性质**：必然事件 $\Omega$ 与不可能事件 $\varnothing$ 互为对立事件，即 $\overline \Omega = \varnothing,\ \overline \varnothing = \Omega$ 
	- **性质**：$A-B = A\overline B$ 
	- **性质**：$A$ 与 $B$ 互为对立事件 $\iff$ $A\cap B = \varnothing$ 且 $A\cup B = \Omega$ 
	- **另一种定义**：如果事件 $A,B$ 满足 $A\cap B = \varnothing$ 且 $A\cup B = \Omega$，则称 $A$ 与 $B$ 互为**对立事件**，记为 $\overline A = B, \overline B = A$ 
- **注意点**：对立事件一定是互不相容的事件（即 $A\cap \overline A = \varnothing$）但互不相容的事件不一定是对立事件
- **例子**：设 $A,B,C$ 是某个随机现象的三个事件，则：
	- “$A,B$ 发生，$C$ 不发生”可表示为：$AB\overline C = AB-C$ 
	- “$A,B,C$ 至少有一个发生”可表示为：$A\cup B\cup C$ 
	- “$A,B,C$ 至少有两个发生”可表示为：$AB \cup AC \cup BC$ 
	- “$A,B,C$ 恰好有两个发生”可表示为：$AB\overline C \cup A\overline BC \cup \overline ABC$ 
	- “$A,B,C$ 同时发生”可表示为：$ABC$ 
	- “$A,B,C$ 都不发生”可表示为：$\overline A \overline B \overline C$ 
	- “$A,B,C$ 不全发生”可表示为：$\overline A \cup \overline B \cup \overline C$ 
- **事件的运算性质** 
	- **交换律**：$A\cup B = B\cup A,\ AB=BA$ 
	- **结合律**：$(A\cup B)\cup C = A \cup (B\cup C),\ (AB)C = A(BC)$ 
	- **分配律**：$(A\cup B)\cap C = AC \cup BC,\ (A\cap B)\cup C = (A\cup C) \cap (B\cup C)$ 
	- **对偶律**（**德摩根公式**）：$\overline{A\cup B} = \overline A \cap \overline B,\ \overline{A\cap B} = \overline A \cup \overline B$ 
		- **推广**：$\begin{aligned} \overline{\bigcup\limits_{i=1}^nA_i} = \bigcap\limits_{i=1}^n \overline A_i,\ \overline{\bigcup\limits_{i=1}^\infty A_i} = \bigcap\limits_{i=1}^\infty \overline A_i \\ \overline{\bigcap\limits_{i=1}^nA_i} = \bigcup\limits_{i=1}^n \overline A_i,\ \overline{\bigcap\limits_{i=1}^\infty A_i} = \bigcup\limits_{i=1}^\infty \overline A_i \end{aligned}$ 
- **并与对立是最基本的运算**：交的运算可以通过并与对立来实现（德摩根公式），差的运算可以通过对立与交来实现（$A-B=A\overline B$），故并与对立是最基本的运算
### 6-1-5 事件域
- **事件域**（**$\sigma$ 域**、**$\sigma$ 代数**）：设 $\Omega$ 为一样本空间，$\mathscr F$ 为 $\Omega$ 的某些子集所组合的集合类。如果 $\mathscr F$ 满足：
	(1) $\Omega \in \mathscr F$ 
	(2) 若 $A\in \mathscr F$，则对立事件 $\overline A \in \mathscr F$ 
	(3) 若 $A_n \in \mathscr F,\ (n=1,2,\cdots)$，则可列并 $\bigcup\limits_{n=1}^\infty A_n \in \mathscr F$ 
	则称 $\mathscr F$ 为一个**事件域**，又称为 **$\sigma$ 域**或 **$\sigma$ 代数**。在概率论中，又称 $(\Omega, \mathscr F)$ 为**可测空间**（在可测空间上才可定义概率，此时 $\mathscr F$ 中都是有概率可言的事件
- **常见的事件域** 
	- 若样本空间含有 $n$ 个样本点 $\Omega = \{ \omega_1, \omega_2, \cdots, \omega_n \}$，则其事件域 $\mathscr F$ 是由空集 $\varnothing$、$n$ 个单元素集、$\dbinom n2$ 个双元素集、$\dbinom n3$ 个三元素集……和 $\Omega$ 组成的集合类，此时 $\mathscr F$ 中共有 $2^n$ 个事件
	- 若样本空间含有可列个样本点 $\Omega = \{ \omega_1, \omega_2, \cdots, \omega_n, \cdots \}$，则其事件域 $\mathscr F$ 是由空集 $\varnothing$、可列个单元素集、可列个双元素集……可列个 $n$ 元素集……和 $\Omega$ 组成的集合类，此时 $\mathscr F$ 由可列个的可列个（仍为可列个）元素（事件）组成
## 6-2 概率的定义及其确定方法
### 6-2-1 概率的公理化定义
- **概率的公理化定义**、**概率空间**：设 $\Omega$ 为一个样本空间，$\mathscr F$ 为 $\Omega$ 的某些子集组成的一个事件域。如果对任一事件 $A \in \mathscr F$，定义在 $\mathscr F$ 上的一个实值函数 $P(A)$ 满足：
	(1) **非负性公理**：若 $A \in \mathscr F$，则 $P(A) \ge 0$ 
	(2) **正则性公理**：$P(\Omega) = 1$ 
	(3) **可列可加性公理**：若 $A_1, A_2, \cdots, A_n, \cdots$ 互不相容，则 $P\left( \bigcup\limits_{i=1}^\infty A_i \right) = \sum\limits_{i=1}^\infty P(A_i)$ 
	则称 $P(A)$ 为事件 $A$ 的**概率**，称三元素 $(\Omega, \mathscr F, P)$ 为**概率空间** 
- 概率的公理化定义刻画了**概率的本质**：概率是集合（事件）的函数
	- 若在事件域 $\mathscr F$ 上给出一个函数，当这个函数能满足上述三条公理，就被称为概率；当这个函数不能满足上述三条公理中任一条，就被认为不是概率。
### 6-2-2 确定概率的古典方法
- 古典方法的基本思想如下：
	(1) 所涉及的随机现象只有有限个样本点，譬如为 $n$ 个
	(2) 每个样本点发生的可能性相等（称为**等可能性**）
	(3) 若事件 $A$ 含有 $k$ 个样本点，则事件 $A$ 的概率为 $P(A) = \dfrac{\text{事件 A 所含样本点的个数}}{\Omega\text{ 中所有样本点的个数}} = \dfrac kn$（容易验证这个式子确定的概率满足公理化定义）
- 古典方法是概率论发展初期确定概率的常用方法，故所得的概率又称为**古典概率** 
- 在古典方法中，求事件 $A$ 的概率归结为计算 $A$ 中含有的样本点的个数和 $\Omega$ 中含有的样本点的总数
- **盒子模型**：设有 $n$ 个球，每个球都等可能地被放到 $N$ 个不同盒子中的任一个，每个盒子所放球数不限，则：
	(1) 指定的 $n(n\le N)$ 个盒子中各有一球的概率 $p_1 = \dfrac{n!}{N^n}$ 
	(2) 恰好有 $n(n\le N)$ 个盒子各有一球的概率 $p_2 = \dfrac{P_N^n}{N^n}$ 
- **生日问题**：$n$ 个人的生日全不相同的概率 $p_n = \dfrac{365!}{365^n(365-n)!} = \left( 1 - \dfrac{1}{365} \right) \left( 1 - \dfrac{2}{365} \right) \cdots \left( 1 - \dfrac{n-1}{365} \right)$ 
	- **注意**：当 $n$ 较小时，乘积 $\dfrac i{365} \times \dfrac j{365}$ 都可以忽略，于是有近似公式 $p_n \approx 1 - \dfrac{1+2+\cdots+(n-1)}{365} = 1 - \dfrac{n(n-1)}{730}$；当 $n$ 较大时，因为对较小的正数 $x$ 有 $\ln(1-x) = -x$，故 $\ln p_n \approx - \dfrac{1+2+\cdots+(n-1)}{365} = -\dfrac{n(n-1)}{730}$ 
	- **注意**：$n=30$ 时，$p_n \approx 0.3037$；$n=60$ 时，$p_n \approx 0.0078$。这是很让人吃惊的
### 6-2-3 确定概率的几何方法
- 确定概率的几何方法，基本思想如下：
	(1) 如果一个随机现象的样本空间 $\Omega$ 充满某个区域，其度量（长度、面积或体积等）大小可用 $S_\Omega$ 表示
	(2) 任意一点落在度量相同的子区域内（可能位置不同）是等可能的
	(3) 若事件 $A$ 为 $\Omega$ 中的某个子区域，且其度量大小可用 $S_A$ 表示，则事件 $A$ 的概率为 $P(A) = \dfrac{S_A}{S_\Omega}$，这个概率称为**几何概率**，它满足概率的公理化定义
- **会面问题**：甲乙两人约定在下午 6 时到 7 时之间在某处会面，并约定先到者应等候另一个人 20 分钟，过时即可离去，则两人能会面的概率为 $\dfrac 59$ 
- **问题**：在长度为 $a$ 的线段内任取两点将其分为三段，则它们可以构成一个三角形的概率为 $p = \dfrac 14$ 
- **贝特朗奇论**：在一圆内任取一条弦，问其长度超过该圆内接等边三角形的边长的概率是多少？
	- **解法一**：由对称性，可只考虑某指定方向的弦，此时的概率为 $\dfrac 12$ 
	- **解法二**：由对称性，可让弦的一端点固定，让另一端点在圆周上作随机移动，此时的概率为 $\dfrac 13$ 
	- **解法三**：圆内弦的位置被其中点唯一确定，在圆内作一同心圆，半径仅为大圆半径的一半，当且仅当中点落在小圆内满足题意，此时的概率为 $\dfrac 14$ 
	- **解释**：同一问题有三种不同答案，原因在于圆内“取弦”时规定尚不够具体，不同的“等可能性假设”导致了不同的样本空间
		(1) 解法一中假定弦的中点在直径上均匀分布，直径上的点组成样本空间 $\Omega_1$ 
		(2) 解法二中假定弦的另一活动端点在圆周上均匀分布，圆周上的点组成样本空间 $\Omega_2$ 
		(3) 解法三种假定弦的中点在大圆内均匀分布，大圆内的点组成样本空间 $\Omega_3$ 
	- **总结**：在定义概率时要事先明确指出样本空间是什么
## 6-3 概率的性质
### 6-3-1 概率的可加性
- **性质**：$P(\varnothing) = 0$ 
	- *证明过程* 
		由于任何事件与不可能事件之并仍是此事件本身，所以 $\Omega = \Omega \cup \varnothing \cup \varnothing \cup \cdots \cup \varnothing \cup \cdots$ 
		因为不可能事件与任何事件是互不相容的，故由可列可加性公理得 $P(\Omega) = P(\Omega) + P(\varnothing) + \cdots + P(\varnothing) + \cdots$ 
		从而由 $P(\Omega) = 1$ 得 $P(\Omega) + P(\Omega) + \cdots = 0$ 
		再由非负性公理，必有 $P(\varnothing) = 0$，证毕！
- **有限可加性**：若有限个事件 $A_1, A_2, \cdots, A_n$ 互不相容，则有 $P\left( \bigcup\limits_{i=1}^n A_i \right) = \sum\limits_{i=1}^n P(A_i)$ 
	- *证明过程* 
		对 $A_1, A_2, \cdots, A_n, \varnothing, \varnothing, \cdots$ 应用可列可加性，得
		$$
		\begin{aligned}
		& P(A_1 \cup A_2 \cup \cdots \cup A_n) \\
		=& P(A_1 \cup A_2 \cup \cdots \cup A_n \cup \varnothing \cup \varnothing \cup \cdots ) \\
		=& P(A_1) + P(A_2) + \cdots + P(A_n) + P(\varnothing) + P(\varnothing) + \cdots \\
		=& P(A_1) + P(A_2) + \cdots + P(A_n)
		\end{aligned}
		$$
		证毕！
- **性质**：对任一事件 $A$，有 $P(\overline A) = 1-P(A)$ 
	- *证明过程* 
		因为 $A$ 与 $\overline A$ 互不相容，且 $\Omega = A \cup \overline A$，所以由概率的正则性和有限可加性得 $1=P(A) + P(\overline A)$，由此得 $P(\overline A) = 1 - P(A)$ 
### 6-3-2 概率的单调性
- **性质**：若 $A\supset B$，则 $P(A-B) = P(A) - P(B)$ 
	- *证明过程* 
		因为 $A\supset B$，所以 $A = B\cup (A-B)$，$B$ 与 $A-B$ 互不相容，由有限可加性得 $P(A) = P(B) + P(A-B)$，证毕！
	- **推论**（**单调性**）：若 $A\supset B$，则 $P(A) \ge P(B)$ 
- **性质**：对任意两个事件 $A,B$，有 $P(A-B) = P(A) - P(AB)$ 
	- *证明过程* 
		因为 $A-B = A-AB$ 且 $AB \subset A$，所以 $P(A-B) = P(A-AB) = P(A) - P(AB)$ 
### 6-3-3 概率的加法公式
- **加法公式**：对任意两个事件 $A,B$，有 $P(A\cup B) = P(A) + P(B) - P(AB)$ 
	- *证明过程* 
		因为 $A\cup B = A \cup (B-AB)$ 且 $A$ 与 $B-AB$ 互不相容，所以 $P(A\cup B) = P(A) + P(B-AB) = P(A) + P(B) - P(AB)$ 
	- **推广**：对任意 $n$ 个事件 $A_1, A_2, \cdots, A_n$，有 $\displaystyle P\left( \bigcup_{i=1}^n A_i \right) = \sum_{k=1}^n (-1)^{k-1} \sum_{1 \le i_1 <\dots<i_k \le n} P(A_{i_1} \cap \dots \cap A_{i_k})$ 
- **推论**（**半可加性**）：对任意两个事件 $A,B$，有 $P(A\cup B) \le P(A) + P(B)$ 
	- **推广**：对任意 $n$ 个事件 $A_1, A_2, \cdots, A_n$，有 $\displaystyle P\left( \bigcup_{i=1}^n A_i \right) \le \sum_{i=1}^n P(A_i)$ 
- **配对问题**：在一个有 $n$ 个人参加的晚会上，每个人带了一件礼物，且假定各人带的礼物都不相同。晚会期间各人从放在一起的 $n$ 件礼物中随机抽取一件，问至少有一个人自己抽到自己礼物的概率是多少？
	- *答案*：$p = 1 - \dfrac 1{2!} + \dfrac 1{3!} - \dfrac 1{4!} + \cdots + (-1)^{n-1}\dfrac 1{n!}$ 
	- *证明过程* 
		以 $A_i\ (i=1,2,\cdots,n)$ 记事件“第 $i$ 个人自己抽到自己的礼物”。所求概率为 $P(A_1 \cup A_2 \cup \cdots \cup A_n)$，因为
		$$
		\begin{aligned}
		& P(A_1) = P(A_2) = \cdots = P(A_n) = \dfrac 1n \\
		& P(A_1A_2) = P(A_1A_3) = \cdots = P(A_{n-1}A_n) = \dfrac 1{n(n-1)} \\
		& P(A_1A_2A_3) = P(A_1A_2A_4) = \cdots = P(A_{n-2}A_{n-1}A_n) = \dfrac 1{n(n-1)(n-2)} \\
		& \cdots \\
		& P(A_1A_2\cdots A_n) = \dfrac 1{n!}
		\end{aligned}
		$$
		所以由概率的加法公式得 $P(A_1\cup A_2 \cup \cdots \cup A_n) = 1 - \dfrac 1{2!} + \dfrac 1{3!} - \dfrac 1{4!} + \cdots + (-1)^{n-1}\dfrac 1{n!}$ 
	- **注意**：当 $n\to\infty$ 时，此概率极限为 $1-\dfrac 1e = 0.6321$，这说明即使参加晚会的人很多，事件“至少有一个人自己抽到自己礼物”也不是必然事件
## 6-4 条件概率
### 6-4-1 条件概率的定义与性质
- **条件概率**：设 $A$ 与 $B$ 是样本空间 $\Omega$ 中的两事件，若 $P(B)>0$，则称 $P(A\mid B) = \dfrac{P(AB)}{P(B)}$ 为“**在 $B$ 发生下 $A$ 的条件概率**”，简称**条件概率** 
	- 计算条件概率 $P(A\mid B)$ 是在样本空间 $\Omega$ 缩小为 $\Omega_B = B$ 下进行的
- **性质**：条件概率是概率
	- *证明过程* 
		设 $P(B)>0$，只需证明三点：
		(1) $P(A\mid B) \ge 0,\ A\in\mathscr F$ 
		(2) $P(\Omega \mid B) = 1$ 
		(3) 若 $\mathscr F$ 中的 $A_1, A_2, \cdots, A_n, \cdots$ 互不相容，则 $P\left( \bigcup\limits_{n=1}^\infty A_n \mid B \right) = \sum\limits_{n=1}^\infty P(A_n \mid B)$ 
		根据条件概率的定义易证前两条，下证第三条
		因为 $A_1, A_2, \cdots, A_n, \cdots$ 互不相容，所以 $A_1B, A_2B, \cdots, A_nB, \cdots$ 也互不相容，故：
		$$
		\begin{aligned}
		P\left( \bigcup_{n=1}^\infty A_n \mid B \right) = & \dfrac{P\left( \left( \bigcup\limits_{n=1}^\infty A_n \right) B \right)}{P(B)} = \dfrac{P\left( \bigcup\limits_{n=1}^\infty (A_nB) \right)}{P(B)} \\
		=& \sum_{n=1}^\infty \dfrac{P(A_nB)}{P(B)} = \sum_{n=1}^\infty P(A_n \mid B)
		\end{aligned}
		$$
		证毕！
### 6-4-2 乘法公式
- **乘法公式**：若 $P(B)>0$，则 $P(AB) = P(B)P(A\mid B)$ 
- **乘法公式**：若 $P(A_1A_2\cdots A_{n-1})>0$，则 $P(A_1A_2\cdots A_n) = P(A_1) P(A_2 \mid A_1) P(A_3 \mid A_1A_2) \cdots P(A_n \mid A_1A_2\cdots A_{n-1})$ 
	- *证明过程* 
		因为 $P(A_1) \ge P(A_1A_2) \ge \cdots \ge P(A_1A_2\cdots A_{n-1})>0$ 
		所以公式中的所有条件概率均有意义，且由条件概率的定义可知
		乘法公式右边等于 $P(A_1) \cdot \dfrac{P(A_1A_2)}{P(A_1)} \cdot \dfrac{P(A_1A_2A_3)}{P(A_1A_2)} \cdot \cdots \cdot \dfrac{P(A_1A_2\cdots A_n)}{P(A_1A_2\cdots A_{n-1})} = P(A_1A_2\cdots A_n)$ 
		证毕！
- **罐子模型**（**波利亚(Polya)模型**）：设罐中有 $b$ 个黑球、$r$ 个红球，每次随机取出一个球，取出后将原球放回，还加进 $c$ 个同色球和 $d$ 个异色球。记 $B_i$ 为“第 $i$ 次取出的是黑球”，$R_j$ 为“第 $j$ 次取出的是红球”
	- **例子**：若连续从罐中取出三个球，其中有两个红球、一个黑球，则由乘法公式可知
		$$
		\begin{aligned}
		P(B_1R_2R_3) = & P(B_1) P(R_2 \mid B_1) P(R_3 \mid B_1R_2) \\
		=& \dfrac {b}{b+r} \cdot \dfrac{r+d}{b+r+c+d} \cdot \dfrac{r+d+c}{b+r+2c+2d} \\
		P(R_1B_2R_3) = & P(R_1) P(B_2 \mid R_1) P(R_3 \mid R_1B_2) \\
		=& \dfrac {r}{b+r} \cdot \dfrac{b+d}{b+r+c+d} \cdot \dfrac{r+d+c}{b+r+2c+2d} \\
		P(R_1R_2B_3) = & P(R_1) P(R_2 \mid R_1) P(B_3 \mid R_1R_2) \\
		=& \dfrac {r}{b+r} \cdot \dfrac{r+c}{b+r+c+d} \cdot \dfrac{b+2d}{b+r+2c+2d} \\
		\end{aligned}
		$$
		以上概率与黑球在第几次被抽出有关
	- **不返回抽样**：当 $c=-1,d=0$ 时，即为**不返回抽样**。前次抽取结果会影响后次抽取结果。但只要抽取的黑球和红球个数确定，则概率不依赖其抽出球的次序，都是一样的。此例有 $P(B_1R_2R_3) = P(R_1B_2R_3) = P(R_1R_2B_3) = \dfrac{br(r-1)}{(b+r)(b+r-1)(b+r-2)}$ 
	- **返回抽样**：当 $c=0,d=0$ 时，即为**返回抽样**。前次抽取结果不会影响后次抽取结果。故上述三个概率相等。此例有 $P(B_1R_2R_3) = P(R_1B_2R_3) = P(R_1R_2B_3) = \dfrac{br^2}{(b+r)^3}$ 
	- **传染病模型**：当 $c>0, d=0$ 时，即为**传染病模型**。此时每次取球后会增加下一次取到同色球的概率。此时上述三个相等。此例有 $P(B_1R_2R_3) = P(R_1B_2R_3) = P(R_1R_2B_3) = \dfrac{br(r+c)}{(b+r)(b+r+c)(b+r+2c)}$ 
	- **安全模型**：当 $c=0,d>0$ 时，即为**安全模型**。即每当事故发生了（红球被取出），安全工作就抓紧一下，下次再发生事故的概率就会减少；而当事故没有发生时（黑球被取出），安全工作就放松一些，下次再发生事故的概率就会增大。此例有：
		$$
		\begin{aligned}
		P(B_1R_2R_3) =& \dfrac {b}{b+r} \cdot \dfrac{r+d}{b+r+d} \cdot \dfrac{r+d}{b+r+2d} \\
		P(R_1B_2R_3) =& \dfrac {r}{b+r} \cdot \dfrac{b+d}{b+r+d} \cdot \dfrac{r+d}{b+r+2d} \\
		P(R_1R_2B_3) =& \dfrac {r}{b+r} \cdot \dfrac{r}{b+r+d} \cdot \dfrac{b+2d}{b+r+2d} \\
		\end{aligned}
		$$
### 6-4-3 全概率公式
- **全概率公式**：设 $B_1, B_2, \cdots, B_n$ 为样本空间 $\Omega$ 的一个分割，即 $B_1, B_2, \cdots, B_n$ 互不相容，且 $\bigcup\limits_{i=1}^n B_i = \Omega$，如果 $P(B_i)>0,\ (i=1,2,\cdots,n)$，则对任意事件 $A$ 有 $P(A) = \sum\limits_{i=1}^n P(B_i)P(A\mid B_i)$ 
	- *证明过程* 
		因为 $A=A\Omega = A\left(\bigcup\limits_{i=1}^n B_i \right) = \bigcup\limits_{i=1}^n (AB_i)$ 且 $AB_1, AB_2, \cdots, AB_n$ 互不相容，所以由可加性得 $P(A) = P\left( \bigcup\limits_{i=1}^n (AB_i) \right) = \sum\limits_{i=1}^n P(AB_i)$ 
		再将 $P(AB_i) = P(B_i)P(A\mid B_i),\ (i=1,2,\cdots,n)$ 代入上式，证毕！
	- **全概率公式的最简单形式**：假如 $0<P(B)<1$，则 $P(A) = P(B)P(A\mid B) + P(\overline B)P(A\mid \overline B)$ 
	- 条件“$B_1, B_2, \cdots, B_n$ 为样本空间的一个分割”可改成“$B_1, B_2, \cdots, B_n$ 互不相容且 $A\subset\bigcup\limits_{i=1}^n B_i$”，全概率公式仍然成立。
	- 对可列个事件 $B_1, B_2, \cdots, B_n, \cdots$ 互不相容且 $A\subset \bigcup\limits_{i=1}^\infty B_i$，则全概率公式 $P(A) = \sum\limits_{i=1}^\infty P(B_i)P(A\mid B_i)$ 仍然成立
- **摸彩模型**：设在 $n$ 张彩票中有 $k\ (k\le n)$ 张可中奖。设 $A_i$ 表示事件“第 $i\ (i=1,2,\cdots,n)$ 个人摸到中奖彩票”，则 $P(A_i) = \dfrac kn$ 
	- 这说明：摸到中奖彩票的机会与先后次序无关
- **应用**：通过全概率公式可以进行**敏感性问题调查** 
### 6-4-4 贝叶斯公式
- **贝叶斯公式**：设 $B_1, B_2, \cdots, B_n$ 是样本空间 $\Omega$ 的一个分割，即 $B_1, B_2, \cdots, B_n$ 互不相容且 $\bigcup\limits_{i=1}^n B_i = \Omega$，如果 $P(A)>0,\ P(B_i)>0,\ (i=1,2,\cdots,n)$，则 $P(B_i \mid A) = \dfrac{P(B_i)P(A\mid B_i)}{\sum\limits_{j=1}^n P(B_j)P(A \mid B_j)},\ (i=1,2,\cdots,n)$ 
	- *证明过程* 
		由条件概率的定义 $P(B_i \mid A) = \dfrac{P(AB_i)}{P(A)}$ 
		对上式的分子用乘法公式 $P(AB_i) = P(B_i)P(A\mid B_i)$，分母用全概率公式 $P(A) = \sum\limits_{j=1}^n P(B_j)P(A\mid B_j)$ 
		记得 $P(B_i \mid A) = \dfrac{P(B_i)P(A\mid B_i)}{\sum\limits_{j=1}^n P(B_j)P(A \mid B_j)},\ (i=1,2,\cdots,n)$，证毕！
	- **先验概率**、**后验概率**：在贝叶斯公式中，如果称 $P(B_i)$ 为 $B_i$ 的**先验概率**，称 $P(B_i \mid A)$ 为 $B_i$ 的**后验概率**，则贝叶斯公式是专门用于计算后验概率的。也就是通过 $A$ 的发生这个新信息，来对 $B_i$ 的概率作出的修正。
- **狼来了**：现在用贝叶斯公式分析寓言故事中村民对小孩的信任度是如何下降的
	记事件 $A$ 为“小孩说谎”，事件 $B$ 为“小孩可信”，不妨假设村民初始对这个小孩的印象为 $P(B) = 0.8, P(\overline B) = 0.2$ 
	进一步假设：可信的孩子说谎的可能性 $P(A \mid B) = 0.1$，不可信的孩子说谎的可能性 $P(A \mid \overline B) = 0.5$ 
	下面用贝叶斯公式求“小孩说了一次慌后，村民对他的信任度”，即概率 $P(B\mid A)$ 
	由贝叶斯公式，$P(B\mid A) = \dfrac{P(B)P(A\mid B)}{P(B)P(A\mid B) + P(\overline B)P(A\mid \overline B)} = \dfrac{0.8 \times 0.1}{0.8\times 0.1 + 0.2\times 0.5} = 0.444$ 
	这表明村民上了一次当后，对这个小孩的信任度由原来的 $0.8$ 调整为 $0.444$，即此时的 $P(B) = 0.444,\ P(\overline B) = 0.556$ 
	在此基础上，我们再一次用贝叶斯公式来计算 $P(B\mid A)$，得到 $P(B\mid A) = 0.138$ 
	这表明村民上了两次当后，对这个小孩的信任度由原来的 $0.8$ 下降到了 $0.138$，所以第三次便不再上山打狼
	启发：若某人向银行贷款，连续两次未还，银行便不会第三次贷款给你了。
## 6-5 独立性
### 6-5-1 两个事件的独立性
- **相互独立**（**独立**）、**不独立**（**相依**）：对于事件 $A,B$，如果 $P(AB) = P(A)P(B)$，则称事件 $A$ 与 $B$ **相互独立**，简称 $A$ 与 $B$ **独立**，否则称 $A$ 与 $B$ **不独立**或**相依** 
	- 独立就是指：一个事件的发生不影响另一个事件的发生
	- 从概率角度，独立就是指：$P(A\mid B) = P(A)$ 和 $P(B\mid A) = P(B)$ 
	- $P(A\mid B) = P(A) \iff P(AB)=P(A)P(B) \iff P(B\mid A) = P(B)$ 
- **性质**：若事件 $A$ 与 $B$ 独立，则 $A$ 与 $\overline B$ 独立，$\overline A$ 与 $B$ 独立，$\overline A$ 与 $\overline B$ 独立
	- *证明过程* 
		由概率的性质可知 $P(A\overline B) = P(A) - P(AB)$ 
		又由 $A$ 与 $B$ 的独立性知 $P(AB) = P(A)P(B)$ 
		所以 $P(A\overline B) = P(A) - P(A)P(B) = P(A)[1-P(B)] = P(A)P(\overline B)$，这表明 $A$ 与 $\overline B$ 独立
		同理可证 $\overline A$ 与 $B$ 独立，$\overline A$ 与 $\overline B$ 独立
### 6-5-2 多个事件的独立性
- **两两独立**、**相互独立**：设 $A,B,C$ 是三个事件，若有 $\begin{cases} P(AB) = P(A)P(B) \\ P(AC) = P(A)P(C) \\ P(BC) = P(B)P(C) \end{cases}$，则称 $A,B,C$ **两两独立**。若还有 $P(ABC) = P(A)P(B)P(C)$，则称 $A,B,C$ **相互独立**
	- **注意**：$\begin{cases} P(AB) = P(A)P(B) \\ P(AC) = P(A)P(C) \\ P(BC) = P(B)P(C) \end{cases}$ 与 $P(ABC) = P(A)P(B)P(C)$ 互相推不出
	- **性质**：若 $A,B,C$ 相互独立，则 $A\cup B$ 与 $C$ 相互独立，$AB$ 与 $C$ 相互独立，$A-B$ 与 $C$ 相互独立
		- **注意**：若 $A,B,C$ 仅仅是两两独立，上述三个结论都推不出
- **相互独立**：设有 $n$ 个事件 $A_1, A_2, \cdots, A_n$，对任意的 $1\le i < j < k < \cdots \le n$，如果有等式 $\begin{cases} P(A_iA_j) = P(A_i)P(A_j) \\ P(A_iA_jA_k) = P(A_i)P(A_j)P(A_k) \\ \cdots \\ P(A_1A_2\cdots A_n) = P(A_1)P(A_2)\cdots P(A_n) \end{cases}$ 均成立，则称此 $n$ 个事件 $A_1, A_2, \cdots, A_n$ **相互独立** 
	- **性质**：$n$ 个相互独立的事件中的任意一部分内仍是相互独立的；而且任意一部分与另一部分也是独立的
	- **性质**：将相互独立事件中的任一部分换为对立事件，所得的诸事件仍为相互独立的
### 6-5-3 试验的独立性
- **相互独立**：设有两个试验 $E_1$ 和 $E_2$，假如试验 $E_1$ 的任一结果（事件）与试验 $E_2$ 的任一结果（事件）都是相互独立的事件，则称**这两个试验相互独立** 
- **相互独立**：对于 $n$ 个试验 $E_1, E_2, \cdots, E_n$，如果 $E_1$ 的任一结果、$E_2$ 的任一结果、……、$E_n$ 的任一结果都是相互独立的事件，则称**试验 $E_1, E_2, \cdots, E_n$ 相互独立**。
- **$n$ 重独立重复试验**：称 $n$ 个相互独立的相同的试验为 **$n$ 重独立重复试验** 
- **$n$ 重伯努利(Bernoulli)试验**：如果在 $n$ 重独立重复试验中，每次试验的可能结果为两个 $A$ 或 $\overline A$，则称这种试验为 **$n$ 重伯努利(Bernoulli)试验** 
# 7 随机变量及其分布
## 7-1 随机变量及其分布
### 7-1-1 随机变量的概念
- **随机变量**：定义在样本空间 $\Omega$ 上的实值函数 $X=X(\omega)$ 称为**随机变量**，常用大写字母 $X,Y,Z$ 等表示随机变量，其取值用小写字母 $x,y,z$ 等表示
	- **随机变量是函数**：随机变量 $X$ 是样本点 $\omega$ 的一个函数，这个函数可以是不同样本点对应不同的实数，也允许多个样本点对应同一个实数
	- **注意**：这个函数的自变量（样本点）可以是数，也可以不是数，但因变量一定是实数
	- **区别**：与微积分中的变量不同，概率论中的随机变量是一种“随机取值的变量且伴随一个分布”
- **离散随机变量**：加入一个随机变量仅可能取有限个或可列个值，则称其为**离散随机变量** 
### 7-1-2 随机变量的分布函数
- **分布函数**、**服从**：设 $X$ 是一个随机变量，对任意实数 $x$，称 $F(x) = P(X\le x)$ 为随机变量 $X$ 的**分布函数**。且称 $X$ **服从** $F(x)$，记为 $X\sim F(x)$。有时也可用 $F_X(x)$ 以表明是 $X$ 的分布函数
	- 任一随机变量 $X$（离散的或连续的）都有一个分布函数
	- 有了分布函数，就可以据此算得与随机变量 $X$ 有关事件的概率
- 有关 $X$ 的各种事件的概率用分布函数表示，如对任意的实数 $a,b$，有：
	$$
	\begin{aligned}
	& P(a<X\le b) = F(b) - F(a) \\ 
	& P(X=a) = F(a) - F(a-0) \\ 
	& P(X\ge b) = 1 - F(b-0) \\ 
	& P(X>b) = 1 - F(b) \\ 
	& P(X<b) = F(b-0) \\ 
	& P(a<X<b) = F(b-0) - F(a) \\ 
	& P(a\le X\le b) = F(b) - F(a-0) \\ 
	& P(a\le X<b) = F(b-0) - F(a-0) \\ 
	\end{aligned}
	$$
	- **性质**：当 $F(x)$ 在 $a$ 与 $b$ 处连续时，有 $F(a-0)=F(a),\ F(b-0)=F(b)$ 
### 7-1-3 离散随机变量的概率分布列
- **概率分布列**（**分布列**）：设 $X$ 时一个离散随机变量，如果 $X$ 的所有可能取值是 $x_1, x_2, \cdots, x_n, \cdots$，则称 $X$ 取 $x_i$ 的概率 $p_i = p(x_i) = P(X=x_i),\ i=1,2,\cdots,n,\cdots$ 为 $X$ 的**概率分布列**，或简称为**分布列**，记为 $X\sim\{p_i\}$ 
	- 分布列可以用表格或 $\begin{pmatrix} x_1 & x_2 & \cdots & x_n & \cdots \\ p(x_1) & p(x_2) & \cdots & p(x_n) & \cdots \end{pmatrix}$ 表示
- **分布列的基本性质**：
	- **非负性**：$p(x_i)\ge 0,\ i=1,2,\cdots$ 
	- **正则性**：$\sum\limits_{i=1}^\infty p(x_i) = 1$ 
	- 以上两条基本性质是分布列必须具有的性质，也是判别某个数列是否能成为分布列的**充要条件** 
- **应用**：由离散随机变量 $X$ 的分布列很容易写出 $X$ 的分布函数 $F(x) = \sum\limits_{x_i\le x} p(x_i)$，它的图形是有限级（或可列无穷级）的阶梯函数
	- 在离散场合，常用来描述其分布的是分布列，很少用到分布函数
## 7-2 随机变量的数学期望
### 7-2-1 数学期望的定义
- **数学期望**（**期望**、**均值**）：设离散随机变量 $X$ 的分布列为 $p(x_i) = P(X=x_i),\ i=1,2,\cdots,n,\cdots$，如果 $\sum\limits_{i=1}^\infty |x_i|p(x_i) < \infty$，则称 $E(X) = \sum\limits_{i=1}^\infty x_ip(x_i)$ 为随机变量 $X$ 的**数学期望**，或称为该分布的数学期望，简称**期望**或**均值**。若级数 $\sum\limits_{i=1}^\infty |x_i| p(x_i)$ 不收敛，则称 $X$ 的数学期望不存在
	- 该定义中，要求级数绝对收敛的目的在于使数学期望唯一。这是因为随机变量的取值可正可负，取值次序可先可后，由无穷级数的理论知道，如果此无穷级数绝对收敛，则可保证其和不受次序变动的影响
	- 由于有限的和不受次序变动的影响，故取有限个可能值得随机变量得数学期望总是存在的
- **应用**：数学期望的理论意义是深刻的，它是消除随机性的主要手段
- 易知 $E(X)$ 由其分布唯一确定
### 7-2-2 数学期望的性质
- **定理**：若随机变量 $X$ 的分布用分布列 $p(x_i)$ 或用密度函数 $p(x)$ 表示，则 $X$ 的某一函数 $g(X)$ 的数学期望为 $E[g(X)] = \displaystyle \sum\limits_i g(x_i)p(x_i)$（这里所涉及的数学期望都假定存在）
- **性质 1**：若 $c$ 是常数，则 $E(c) = c$ 
	- *证明过程* 
		如果将常数 $c$ 看作仅取一个值得随机变量 $X$，则有 $P(X=c)=1$，从而其数学期望 $E(c)=E(X)=c\times 1=c$ 
- **性质 2**：对任意常数 $a$，有 $E(aX) = aE(X)$ 
	- *证明过程* 
		根据上述定理，令 $g(x)=ax$，然后把 $a$ 从求和号中提取出来即得
- **性质 3**：对任意得两个函数 $g_1(x)$ 和 $g_2(x)$，有 $E[g_1(X) \pm g_2(X)] = E[g_1(X)] \pm E[g_2(X)]$ 
	- *证明过程* 
		根据上述定理，令 $g(x) = g_1(x) \pm g_2(x)$，然后把和式分解成两个和式即可
## 7-3 随机变量的方差与标准差
### 7-3-1 方差与标准差的定义
- **方差**：若随机变量 $X^2$ 的数学期望 $E(X^2)$ 存在，则称偏差平方 $(X-E(X))^2$ 的数学期望 $E(X-E(X))^2$ 为随机变量 $X$（或相应分布）的**方差**，记为 $\mathrm{Var}(X) = E(X-E(X))^2 = \displaystyle \sum_i (x_i - E(X))^2 p(x_i)$ 
- **标准差**：称方差的正平方根 $\sqrt{\mathrm{Var}(X)}$ 为随机变量 $X$（或相应分布）的**标准差**，记为 $\sigma(X)$ 或 $\sigma_X$ 
- **应用**：方差与标准差的功能相似，都是用来描述随机变量取值的集中与分散程度（即散布大小）的两个特征数
	- 方差与标准差愈小，随机变量的取值愈集中
	- 方差与标准差愈大，随机变量的取值愈分散
- **差别**：方差与标准差之间的差别主要在量纲上。由于标准差所讨论的随机变量、数学期望有相同的量纲，其加减 $E(X)\pm k\sigma(X)$ 是有意义的（$k$ 为正实数），所以在实际中，人们比较乐意选用标准差，但标准差的计算必须通过方差才能算得
### 7-3-2 方差的性质
- **性质 1**：$\mathrm{Var}(X) = E(X^2) - [E(X)]^2$ 
	- *证明过程* 
		因为 $\mathrm{Var}(X) = E(X-E(X))^2 = E(X^2 - 2X\cdot E(X) + (E(X))^2)$，再由数学期望的性质可得 $\mathrm{Var} (x) = E(X^2) - 2E(Y)\cdot E(X) + (E(X))^2 = E(X^2) - (E(X))^2$ 
	- 在实际计算方差时，这个性质往往比定义 $\mathrm{Var}(X) = E(X-E(X))^2$ 更常用
- **性质 2**：常数的方差为 $0$，即 $\mathrm{Var}(c) = 0$，其中 $c$ 是常数
	- *证明过程* 
		若 $c$ 是常数，则 $\mathrm{Var}(c) = E(c-E(c))^2 = E(c-c)^2 = 0$ 
- **性质 3**：若 $a,b$ 是常数，则 $\mathrm{Var}(aX+b) = a^2\mathrm{Var}(X)$ 
	- *证明过程* 
		因 $a,b$ 是常数，则 $\mathrm{Var}(aX+b) = E(aX+b - E(aX+b))^2 = E(a(X-E(X)))^2 = a^2\mathrm{Var}(X)$ 
- **性质 4**：若 $E(X^2)=0$，则 $E(X) = 0$ 且 $\mathrm{Var}(X) = 0$ 
	- *证明过程* 
		这是从 $\mathrm{Var}(X) = E(X^2) - [E(X)]^2 \ge 0$ 看出的
## 7-4 常用离散分布
### 7-4-1 二项分布
- $X, A$：记 $X$ 为 $n$ 重伯努利试验中成功（记为事件 $A$）的次数，则 $X$ 的可能取值为 $1,\cdots,n$ 
- $p$：记 $p$ 为每次试验中 $A$ 发生的概率，即 $P(A)=p$，则 $P(\overline A) = 1-p$ 
- $\omega, \omega_i, \Omega$：将 $n$ 重伯努利试验的基本结果记作 $\omega = (\omega_1, \omega_2, \cdots, \omega_n)$，其中 $\omega_i$ 或者为 $A$，或者为 $\overline A$。这样的 $\omega$ 共有 $2^n$ 个，这 $2^n$ 个样本点 $\omega$ 组成了样本空间 $\Omega$ 
- **每个样本点的概率**：若某个样本点 $\omega = (\omega_1, \omega_2, \cdots, \omega_n) \in \{X=k\}$，由独立性可知 $P(\omega) = p^k(1-p)^{n-k}$ 
- **$X$ 的分布列**：由于事件 $\{X=k\}$ 中这样的 $\omega$ 共有 $\dbinom nk$ 个，故 $X$ 的分布列为 $P(X=k) = \dbinom nk p^k(1-p)^{n-k},\ (k=0,1,\cdots,n)$ 
- **二项分布**：上述分布称为**二项分布**，记为 $X\sim b(n,p)$ 
	- 由于 $\sum\limits_{k=0}^n \dbinom nk p^k(1-p)^{n-k} = [p+(1-p)]^n=1$，故其和恒为 $1$，并且可以知道，二项概率 $\dbinom nk p^k (1-p)^{n-k}$ 恰好是 $n$ 次二项式 $(p+(1-p))^n$ 的展开式中的第 $k+1$ 项，这便是其名称的由来
- **性质**：二项分布的数学期望为 $E(X) = np$，方差为 $\mathrm{Var}(X) = np(1-p)$ 
	- *证明过程* 
		对于数学期望，有如下推导：
		$$
		\begin{aligned}
		E(X) = & \sum_{k=0}^n k\binom nk p^k(1-p)^{n-k} = np\sum_{n=1}^n \binom{n-1}{k-1}p^{k-1}(1-p)^{(n-1)-(k-1)} \\
		=& np[p+(1-p)]^{n-1}=np
		\end{aligned}
		$$
		又因为：
		$$
		\begin{aligned}
		E(X^2) =& \sum_{k=0}^n k^2 \binom nk p^k(1-p)^{n-k} = \sum_{k=1}^n(k-1+1)k\binom nk p^k(1-p)^{n-k} \\
		=&\sum_{k=1}^n k(k-1) \binom nk p^k(1-p)^{n-k} + \sum_{k=1}^n k \binom nk p^k(1-p)^{n-k} \\
		=& \sum_{k=2}^n k(k-1) \binom nk p^k(1-p)^{n-k} + np \\
		=& n(n-1)p^2 \sum_{k=2}^n k^2 \binom {n-2}{k-2} p^{k-2}(1-p)^{(n-2)-(k-2)} + np \\
		=& n(n-1)p^2 + np
		\end{aligned}
		$$
		因此 $X$ 的方差为 $\mathrm{Var}(X) = E(X^2) - (E(X))^2 = np(1-p)$，证毕！
- **二项分布的概率图像**：位于均值 $np$ 附近概率较大，且随着 $p$ 的增加，分布的峰逐渐右移
### 7-4-2 二点分布
- **二点分布**（**0-1 分布**、**伯努利分布**）：$n=1$ 时的二项分布 $b(1,p)$ 称为**二点分布**，或称为 **0-1 分布**，或称为**伯努利分布** 
- **$X$ 的分布列**：$P(X=x) = p^x(1-p)^{1-x},\ (x=0,1)$，即 $P(X=0)=1-p,\ P(X=1)=p$ 
- **应用**：二点分布 $b(1,p)$ 主要用来描述一次伯努利试验中成功的次数（$0$ 或 $1$）
- **二项分布与二点分布的关系**：服从二项分布的随机变量 $X$ 总可以分解为 $n$ 个独立同为二点分布的随机变量 $X_i\ (i=1,2,\cdots,n)$ 之和，即 $X=X_1 + X_2, \cdots + X_n$ 
- **性质**：二点分布的数学期望 $E(X) = p$，方差为 $p(1-p)$ 
### 7-4-3 泊松分布
- **泊松分布的概率分布列**：$P(X=k) = \dfrac{\lambda^k}{k!} e^{-\lambda},\ (k=0,1,2,\cdots)$，其中参数 $\lambda>0$，记为 $X\sim P(\lambda)$ 
	- 验证泊松分布其和为 $1$：$\sum\limits_{k=0}^\infty \dfrac{\lambda^k}{k!} e^{-\lambda} = e^{-\lambda}\sum\limits_{k=0}^\infty \dfrac{\lambda^k}{k!} = e^{-\lambda}e^\lambda = 1$ 
- **应用**：泊松分布常与单位时间（或单位面积、单位产品等）上的计数过程相联系，譬如：
	- 在一天内，来到商场的顾客数服从泊松分布
	- $1$ 平方米内，玻璃上的气泡数服从泊松分布
- **性质**：泊松分布的数学期望 $E(X)=\lambda$，方差 $\mathrm{Var}(X)=\lambda$ 
	- *证明过程* 
		设随机变量 $X\sim P(\lambda)$，则 $E(X) = \sum\limits_{k=0}^\infty k \dfrac{\lambda^k}{k!} e^{-\lambda} = \lambda e^{-\lambda} \sum\limits_{k=1}^\infty \dfrac{\lambda^{k-1}}{(k-1)!} = \lambda e^{-\lambda} e^\lambda = \lambda$ 
		又因为：
		$$
		\begin{aligned}
		E(X^2) = & \sum_{k=0}^\infty k^2 \dfrac{\lambda^k}{k!}e^{-\lambda} = \sum_{k=1}^\infty k \dfrac{\lambda^k}{(k-1)!}e^{-\lambda} \\
		=& \sum_{k=1}^\infty [(k-1)+1] \dfrac{\lambda^k}{(k-1)!}e^{-\lambda} \\
		=& \lambda^2 e^{-\lambda} \sum_{k=2}^\infty \dfrac{\lambda^{k-2}}{(k-2)!} + \lambda e^{-\lambda} \sum_{k=1}^\infty \dfrac{\lambda^{k-1}}{(k-1)!} \\
		=& \lambda^2 + \lambda
		\end{aligned}
		$$
		故 $\mathrm{Var}(X) = E(X^2) - (E(X))^2 = \lambda$ 
- **泊松分布的概率图像**：位于均值 $\lambda$ 附近概率较大，且随着 $\lambda$ 的增加，分布逐渐趋于对称
- **泊松定理**（**二项分布的泊松近似**）：在 $n$ 重伯努利试验中，记事件 $A$ 在一次试验中发生的概率为 $p_n$（与试验次数 $n$ 有关），如果当 $n\to\infty$ 时，有 $np_n\to\lambda$，则 $\lim\limits_{n\to\infty} \dbinom nk p_n^k(1-p_n)^{n-k} = \dfrac{\lambda^k}{k!} e^{-\lambda}$ 
	- *证明过程* 
		记 $np_n = \lambda_n$，即 $p_n = \dfrac{\lambda_n}n$，我们可以得到：
		$$
		\begin{aligned}
		\binom nk p_n^k(1-p_n)^{n-k} =& \dfrac{n(n-1)\cdots(n-k+1)}{k!} \left( \dfrac{\lambda_n}n \right)^k \left( 1-\dfrac{\lambda_n}n \right)^{n-k} \\
		=& \dfrac{\lambda_n^k}{k!}\left( 1 - \dfrac 1n \right)\left( 1 - \dfrac 2n \right)\cdots \left( 1 - \dfrac {k-1}n \right)\left( 1 - \dfrac {\lambda_n}n \right)^{n-k}
		\end{aligned}
		$$
		对固定的 $k$ 有 $\lim\limits_{n\to\infty} \lambda_n = \lambda$ 和 $\lim\limits_{n\to\infty} \left(1 - \dfrac{\lambda_n}n\right)^{n-k} = e^{-\lambda}$ 和 $\lim\limits_{n\to\infty} \left( 1 - \dfrac 1n \right)\left( 1 - \dfrac 2n \right)\cdots \left( 1 - \dfrac {k-1}n \right) = 1$ 
		故 $\lim\limits_{n\to\infty}\dbinom nk p_n^k(1-p_n)^{n-k} = \dfrac{\lambda^k}{k!}e^{-\lambda}$ 对任意的 $k\ (k=0,1,2,\cdots)$ 成立，证毕！
	- 由于泊松定理是在 $np_n\to\lambda$ 条件下获得的，故在计算二项分布 $b(n,p)$ 时，当 $n$ 很大，$p$ 很小，而乘积 $\lambda=np$ 大小适中时，可以用泊松分布作近似，即 $\dbinom nk p^k(1-p)^{n-k} \approx \dfrac{(np)^k}{k!} e^{-np},\ (k=0,1,2,\cdots)$，这样可以减少二项分布中的计算量
### 7-4-4 超几何分布
- **超几何分布**：设有 $N$ 件产品，其中有 $M$ 件不合格品。若从中不放回地随机抽取 $n$ 件，则其中含有地不合格品地件数服从**超几何分布**，记为 $X\sim h(n,N,M)$，超几何分布的概率分布列为 $P(X=k) = \dfrac{\dbinom Mk \dbinom{N-M}{n-k}}{\dbinom Nn},\ (k=0,1,\cdots,r)$，其中 $r=\min\{M,n\}$ 且 $M\le N,\ n\le N$，$n,N,M$ 均为正整数
	- **验证其为一个概率分布列**：通过组合等式 $\sum\limits_{k=0}^r \dbinom Mk \dbinom{N-M}{n-k} = \dbinom Nn$ 即可验证
- **性质**：超几何分布 $X\sim h(n,N,M)$ 的数学期望 $E(X) = n\dfrac MN$，方差 $\mathrm{Var}(X) = \dfrac{nM(N-M)(N-n)}{N^2(N-1)}$ 
	- *证明过程* 
		数学期望：$E(X) = \sum\limits_{k=0}^r k\dfrac{\dbinom {M}{k} \dbinom{N-M}{n-k}}{\dbinom {N}{n}} = n\dfrac MN \sum\limits_{k=1}^r \dfrac{\dbinom {M-1}{k-1} \dbinom{N-M}{n-k}}{\dbinom {N-1}{n-1}} = n\dfrac MN$ 
		又因为：
		$$
		\begin{aligned}
		E(X^2) =& \sum_{k=1}^r k^2 \dfrac{\dbinom {M}{k} \dbinom{N-M}{n-k}}{\dbinom {N}{n}} = \sum_{k=2}^r k(k-1) \dfrac{\dbinom {M}{k} \dbinom{N-M}{n-k}}{\dbinom {N}{n}} + n\dfrac MN \\
		=& \dfrac{M(M-1)}{\dbinom Nn} \sum_{k=2}^r \dbinom{M-2}{k-2}\dbinom{N-M}{n-k} + n\dfrac MN \\
		=& \dfrac{M(M-1)}{\dbinom Nn}\dbinom{N-2}{n-2} + n\dfrac MN = \dfrac{M(M-1)n(n-1)}{N(N-1)} + n\dfrac MN
		\end{aligned}
		$$
		因此 $X$ 的方差 $\mathrm{Var}(X) = E(X^2) - (E(X))^2 = \dfrac{nM(N-M)(N-n)}{N^2(N-1)}$，证毕！
- **超几何分布的二项近似**：当 $n \ll N$ 时，即抽取个数 $n$ 远小于产品总数 $N$ 时，每次抽取后，总体中的不合格品率 $p=\dfrac MN$ 改变甚微，所以不放回抽样可近似地看成放回抽样，此时超几何分布可用二项分布近似：$\dfrac{\dbinom {M}{k} \dbinom{N-M}{n-k}}{\dbinom {N}{n}} \approx \dbinom nk p^k (1-p)^{n-k}$，其中 $p=\dfrac MN$ 
### 7-4-5 几何分布
- **几何分布**：在伯努利试验序列中，记每次试验中事件 $A$ 发生的概率为 $p$，如果 $X$ 为事件 $A$ 首次出现时的试验次数，则 $X$ 的可能取值为 $1,2,\cdots$，称 $X$ 服从**几何分布**，记为 $X\sim Ge(p)$，其分布列为 $P(X=k) = (1-p)^{k-1}p,\ (k=1,2,\cdots)$ 
	- **例子**：掷一颗骰子，首次出现 $6$ 点的投掷次数 $Z\sim Ge(1/6)$ 
- **性质**：几何分布 $X\sim Ge(p)$ 的数学期望 $E(X) = \dfrac 1p$，方差 $\mathrm{Var}(X) = \dfrac{1-p}{p^2}$ 
	- *证明过程* 
		令 $q=1-p$，则对于数学期望有如下推导：
		$$
		\begin{aligned}
		E(X) = & \sum_{k=1}^\infty kpq^{k-1} = p\sum_{k=1}^\infty kq^{k-1} = p\sum_{k=1}^\infty \dfrac{\mathrm dq^k}{\mathrm dq} \\
		=& p \dfrac{\mathrm d}{\mathrm dq} \left( \sum_{k=0}^\infty q^k \right) = p\dfrac{\mathrm d}{\mathrm dq} \left( \dfrac 1{1-q} \right) = \dfrac{p}{(1-q)^2} = \dfrac 1p
		\end{aligned}
		$$
		又因为：
		$$
		\begin{aligned}
		E(X^2) = & \sum_{k=1}^\infty k^2pq^{k-1} = p\left[ \sum_{k=1}^\infty k(k-1)q^{k-1} + \sum_{k=1}^\infty kq^{k-1} \right] \\
		=& pq\sum_{k=1}^\infty k(k-1)q^{k-2} + \dfrac 1p = pq\sum_{k=1}^\infty \dfrac{\mathrm d^2}{\mathrm dq^2} q^k + \dfrac 1p \\
		=& pq\dfrac{\mathrm d^2}{\mathrm dq^2} \left( \sum_{k=0}^\infty q^k \right) + \dfrac 1p = pq \dfrac{\mathrm d^2}{\mathrm dq^2} \left( \dfrac 1{1-q} \right) + \dfrac 1p \\
		=& pq\dfrac{2}{(1-q)^3} + \dfrac 1p = \dfrac{2q}{p^2} + \dfrac 1p
		\end{aligned}
		$$
		因此 $X$ 的方差 $\mathrm{Var}(X) = E(X^2) - (E(X))^2 = \dfrac{1-p}{p^2}$ 
- **几何分布的无记忆性**：设 $X\sim Ge(p)$，则对任意正整数 $m$ 与 $n$ 有 $P(X>m+n \mid X>m) = P(X>n)$ 
	- *证明过程* 
		因为 $P(X>n) = \sum\limits_{k=n+1}^\infty (1-p)^{k-1}p = \dfrac{p(1-p)^n}{1-(1-p)} = (1-p)^n$ 
		所以对任意的正整数 $m$ 与 $n$，条件概率 $P(X>m+n\mid X>m) = \dfrac{P(X>m+n)}{P(X>m)} = \dfrac{(1-p)^{m+n}}{(1-p)^m} = (1-p)^n = P(X>n)$，证毕！
	- **含义**：在前面 $m$ 次试验中 $A$ 没有出现的条件下，在接下去的 $n$ 次试验中 $A$ 仍未出现的概率只与 $n$ 有关，而与以前的 $m$ 次试验无关，似乎忘记了前 $m$ 次试验结果，这就是无记忆性
### 7-4-6 负二项分布
- **负二项分布**（**帕斯卡分布**）：在伯努利试验序列中，记每次试验中事件 $A$ 发生的概率为 $p$，如果 $X$ 为事件 $A$ 第 $r$ 次出现时的试验次数，则 $X$ 的可能取值为 $r, r+1, \cdots, r+m, \cdots$，称 $X$ 服从**负二项分布**或**帕斯卡分布**，其分布列为 $P(X=k) = \dbinom{k-1}{r-1}p^r(1-p)^{k-r},\ (k=r, r+1, \cdots)$，记为 $X\sim Nb(r,p)$ 
	- **解释**：这是因为在 $k$ 次伯努利试验中，最后一次一定是 $A$，而前 $k-1$ 次中 $A$ 应出现 $r-1$ 次，由二项分布知其概率为 $\dbinom{k-1}{r-1} p^{r-1}(1-p)^{k-r}$，再乘以最后一次出现 $A$ 的概率 $p$，即得其分布列
	- **特例**：当 $r=1$ 时，负二项分布即为几何分布
- **性质**：负二项分布 $X\sim Nb(r,p)$ 的数学期望 $E(X) = \dfrac rp$，方差 $\mathrm{Var}(X) = \dfrac{r(1-p)}{p^2}$ 
- **性质**：负二项分布 $X\sim Nb(r,p)$ 可分解成 $r$ 个独立同分布的几何分布随机变量 $X_i \sim Ge(p)\ (i=1,2,\cdots,r)$ 之和
