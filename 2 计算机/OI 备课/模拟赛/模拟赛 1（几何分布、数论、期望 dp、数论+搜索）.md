# A 猫爪拍拍拍（cat）
### 题目描述
家里有一只辣么可爱的猫猫可太太太幸福了~
但是趁主人不在家的时候，那只调皮的猫猫竟然偷偷玩起了遥控器！！
猫猫说：“主人家里有 $n$ 盏灯和 $1$ 个遥控器喵，我可以用这一个遥控器来控制任意一盏灯喵，但令本猫气恼的是，遥控器竟然有一定概率失灵！！”
猫猫接着骄傲地说道：“但天下没有什么可以难得倒本猫，我每次可以指定任意一盏灯，然后按动遥控器，可以将指定的灯打开喵，但是有 $\dfrac 1p$ 的概率会失灵（就是没法打开）”
初始，所有灯都是关的，猫猫想用她粉粉嫩嫩的爪子把 $n$ 盏灯都打开，猫猫想知道按动遥控器次数的期望。
### 输入格式
从文件 $cat.in$ 中读入数据
共 $T+1$ 行
第一行一个正整数 $T(1\le T\le 100)$，代表测试用例的数量。
之后 $T$ 行，每行两个正整数 $n,p(2\le n, p\le 100)$，分别代表灯的数量和每次按动遥控器失灵的概率 $\dfrac 1p$ 
### 输出格式
输出到文件 $cat.out$ 中
依次输出每个样例的结果，每个样例输出一行。
如果答案为整数，直接输出这个整数，否则输出 $x/y$ 的形式，要求 $x$ 与 $y$ 互质。
### 样例 1 输入
```bash
3
2 2
2 9
4 5
```
### 样例 1 输出
```bash
4
9/4
5
```
### 样例 1 解释
第一组数据中：按 $2$ 次成功的概率为 $\dfrac 14$，按 $3$ 次成功的概率为 $\dfrac 28$，按 $4$ 次成功的概率为 $\dfrac{3}{16}$，按 $5$ 次成功的概率为 $\dfrac{4}{32}$，以此类推，期望为 $\sum\limits_{i=2}^\infty \dfrac{(i-1)i}{2^i} = 4$

# B 狗爪算算算（dog）
### 题目描述
猫猫拍她的遥控器去了，留下狗狗一人算数学题，惨惨的狗。
猫猫给了狗狗两个正整数 $x_0, y_0$，命令狗狗要在 $1$ 秒内求出满足下列条件的 $P, Q$ 的个数：
1. $P,Q$ 是正整数。
2. 要求 $P, Q$ 以 $x_0$ 为最大公约数，以 $y_0$ 为最小公倍数。
### 输入格式
从文件 $dog.in$ 中读入数据
一行两个正整数 $x_0, y_0$ 
### 输出格式
输出到文件 $dog.out$ 中
一行一个数，表示求出满足条件的 $P, Q$ 的个数。
### 样例 1 输入
```
3 60
```
### 样例 1 输出
```
4
```
### 样例 1 解释
$P,Q$ 有 $4$ 种：
1. $3, 60$。
2. $15, 12$。
3. $12, 15$。
4. $60, 3$。
### 样例 2
见选手目录下的 $dog2.in$ 与 $dog2.ans$ 
### 数据规模与约定
对于 $5\%$ 的数据满足 $x_0=y_0$ 
另有 $5\%$ 的数据满足 $x_0>y_0$ 
另有 $40\%$ 的数据满足 $2\le x_0 < y_0 \le 10^3$ 
对于 $100\%$ 的数据，$2 \le x_0, y_0 \le {10}^6$ 
# C 收集癖的赌神（gambler）
### 题目描述
有 $n$ 种不同的卡片，赌神想收集所有种类的卡片。唯一的收集方法是到猫猫和狗狗开的摊子那里购买，每次只能买一张，并且买到的卡片究竟是 $n$ 种卡片中的哪一种是等概率的，概率均为 $1/n$。但是由于猫猫狗狗也很喜欢卡片，所以赌神购买第 $k$ 次卡片需要支付 $k$ 元钱。
现在赌神手中没有卡片，赌神想知道自己得到所有种类的卡片需要花费的钱数目的期望。

一行，一个数字 $N$（$N \le 10000$）
### 输出格式
输出到文件 $gambler.out$ 中
输出要付出多少钱，保留二位小数。
### 样例 1 输入
```
3
```
### 样例 1 输出
```
21.25
```

# D 你是我的另一半（couple）
### 题目描述
人与人之间，数字相连。
ta 总是拿着号码牌，想要找到自己的另一半。
ta 知道：假设自己的号码牌上写着数字 $S$，那么自己可能的另一半的号码牌数字的所有正约数之和必定等于 $S$ 
ta 想通过这个性质找到自己所有的可能的另一半。
由于 ta 没有学过编程，想拜托你写一个程序能够快速地找到所有自己等的人。
### 输入格式
从文件 $couple.in$ 中读入数据
输入包含 $k$ 组数据。
对于每组数据，输入包含一个号码牌 $S$。
### 输出格式
输出到文件 $couple.out$ 中
对于每组数据，输出有两行，第一行包含一个整数 $m$，表示有 $m$ 个等的人。
第二行包含相应的 $m$ 个数，表示所有等的人的号码牌。
特别地，当某组数据出现 $m=0$，即不存在满足题意的号码牌时，该组数据不应输出第二行（只应输出第一行的 $0$）。
注意：你输出的号码牌必须按照升序排列。
### 样例 1 输入
```
42
```
### 样例 1 输出
```
3
20 26 41
```

### 样例 3
见选手目录下的 $couple3.in$ 与 $couple3.ans$ 
### 数据规模与约定
对于 $30\%$ 的数据，$k\le 100,\ S \le 2\times 10^3$ 
对于 $60\%$ 的数据，$k\le 100,\ S\le 2\times 10^6$ 
对于 $100\%$ 的数据，$k\le 100,\ S\le 2\times10^9$
