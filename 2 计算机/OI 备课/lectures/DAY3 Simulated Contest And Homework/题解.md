$n$ 个灯彼此独立，只需考虑 $1$ 个灯的答案，最后乘 $n$ 即可

对于 $1$ 个灯，每一次能够打开的概率为 $1-\dfrac 1p$，由于其服从几何分布，故期望为 $\dfrac{1}{1-\dfrac 1p}$，即为 $\dfrac p{1-p}$ 

所以答案就是 $\dfrac{np}{1-p}$，化简使用 gcd 即可

由于 $gcd(P,Q)=x_0,\ lcm(P,Q)=y_0$，故 $P\times Q = x_0y_0$ 

对于符合条件的不同的 $P,Q$，交换它们的次序可以得到与之对应的另一组解

从 $1$ 到 $\sqrt{x_0y_0}$ 枚举 $P$，判断是否有 $P\mid x_0y_0$，若有，令 $Q = x_0y_0 / P$，再判断 $gcd(P,Q)=x_0, lcm(P,Q)=y_0$ 是否成立，若成立，则答案 +2

若符合条件的 $P,Q$ 相同，则交换它们的次序的解是不变的，而 $P=Q$ 时必然有 $gcd(P,Q)=lcm(P,Q)$，故当 $x_0=y_0$ 时答案 -1

用 $f[i]$ 表示：现在取到 $i$ 张卡片，要取完剩下卡片的期望次数。显然 $f[n]=0$ 

有递推公式 $f[i] = \dfrac in (f[i]+1) + \dfrac{n-i}n (f[i+1]+1)$，即 $f[i] = f[i+1] + \dfrac{n}{n-i}$ 

令 $g[i]$ 表示：现在取到 $i$ 张卡片，要取完剩下卡片的期望价格。显然 $g[n]=0$ 

有递推公式 $g[i] = \dfrac in(g[i]+f[i]+1) + \dfrac{n-i}n(g[i+1]+f[i+1]+1)$ 

化简可得 $g[i] = \dfrac{i}{n-i}f[i] + g[i+1]+f[i+1] + \dfrac n{n-i}$ 

答案为 $g[0]$

约数和的公式 $S = (1+p_1+p_1^2+\cdots+p_1^{a_1})(1+p_2+p_2^2+…+p_2^{a_2})\cdots(1+p_n+p_n^2+\cdots+p_n^{a_n})$ 

由该公式可见符合条件的项不会很多

那么这个时候我们就可以用 dfs 进行搜索，看我们能不能得到符合条件的 $(1+p_k+p_k^2+\cdots+p_k^{a_k})$ 使得 $S$ 能够整除，即 $S \% (1+p_k+p_k^2+\cdots+p_k^{a_k}) == 0$，然后 $S /= (1+p_k+p_k^2+\cdots+p_k^{a_k})$，再 dfs 到下一层

当 $S=(1+P_i)$ 时，因为 $P_i$ 为质数，那么 $S-1$ 也一定为质数，那么这个时候只需要判断 $S-1$ 是否为质数即可，在此特殊情况之外，$S$ 只会有两种情况：一种情况包括一个因子里面有 $(1+P_i)$，另一种情况不包括 $(1+P_i)$ 
即 $S = (1+P_i)(1+P_j+P_j^2+\cdots)\cdots$ 或$S = (1+Pi+Pi^2)(1+\cdots)\cdots$ 

从这两种情况都可以看出来 $P_i ^2 \le S$，故 dfs 枚举 $P_i$ 的上限就是 $\sqrt S$ 

详细 dfs 代码如下，自己看一看如何实现的，细节蛮多，代码难度较大

```cpp
void dfs(LL pos, LL rst, LL num) //第 pos 个素数，还有 rst 可以分解，现在的数字为 num
{
	if (rst == 1)
	{
		ans[ ++ m] = num;
		return;
	}
	if (rst > primes[pos] && is_prime(rst - 1)) ans[ ++ m] = num * (rst - 1);
	
	for (LL i = pos; primes[i] * primes[i] <= rst; i ++ )
	{
		LL sum = primes[i] + 1, tmp = primes[i];
		for (; sum <= rst; tmp *= primes[i], sum += tmp)
			if (rst % sum == 0) dfs(i + 1, rst / sum, num * tmp);
	}
	
	return;
}
```
