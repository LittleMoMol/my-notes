# 1 集合
## 1-1 集合的表示
- **集合**、**元素**：在一定范围内的个体事物的全体，当将它们看作一个整体时，我们把这个整体称为一个**集合**，其中每个个体事物叫做该集合的**元素** 
	- 一个集合的各个元素必须是彼此互异的
	- 哪些事物是给定集合的元素必须是明确的
- **集合的表示**：一个具体集合 $A$ 可以通过列举其元素 $a,b,c,\cdots$ 来定义，可记为 $A = \{a,b,c,\cdots\}$，也可以通过该集合中的各元素必须且只需满足的条件 $p$ 来定义，并记为 $A = \{x:x\text{ 满足条件 } p\}$ 
- **属于**、**不属于**：设 $A$ 是一个集合，$x$ 是 $A$ 的元素，我们称 $x$ **属于** $A$，记为 $x\in A$。若 $x$ 不是 $A$ 的元素，称 $x$ **不属于** $A$，记为 $x\not\in A$ 或 $x\overline \in A$ 
	- $\varnothing$ 表示不含任何元素的空集
	- 习惯上，$\mathbb N$ 表示自然数集，$\mathbb Z$ 表示整数集，$\mathbb Q$ 表示有理数集，$\mathbb R$ 表示实数集
- **值域**、**原像**：设 $f(x)$ 是定义在 $E$ 上的函数，记 $f(E) = \{ f(x): x\in E \}$，称之为 $f$ 的**值域**。若 $D$ 是 $\mathbb R$ 中的集合，则 $f^{-1}(D) = \{ x:x\in E, f(x)\in D \}$ 称之为 $D$ 的原像
	- 在不致混淆时，$\{x:x\in E,\ f(x)\text{ 满足条件 } p\}$ 可简写为 $\{x:f(x)\text{ 满足条件 }p\}$ 
- **子集**、**真子集**：若集合 $A$ 和 $B$ 满足对任意 $x\in A$ 可得到 $x\in B$，则称 $A$ 是 $B$ 的**子集**，记为 $A\subset B$ 或 $B\supset A$。若 $A\subset B$ 但 $A$ 并不与 $B$ 相同，则称 $A$ 是 $B$ 的**真子集** 
- **相等**：若集合 $A$ 和 $B$ 满足 $A\subset B$ 且 $B\subset A$，则称 $A$ 和 $B$ **相等**，记为 $A=B$ 
## 1-2 集合的运算
### 1-2-1 并交差补
- **并集**（**和集**、**并**、**和**）：设 $A,B$ 是任意两个集合，设 $C$ 由一切或属于 $A$ 或属于 $B$ 的元素所组成，则我们称 $C$ 为 $A$ 与 $B$ 的**并集**或**和集**，简称为**并**或**和**，记为 $C=A\cup B$，它可表示为 $A\cup B = \{ x:x\in A\text{ 或 }x\in B \}$ 
	- **推广**：设有一族集合 $\{ A_\alpha:\alpha\in\Lambda \}$，其中 $\alpha$ 是在固定指标集 $\Lambda$ 中变化的指标，则由一切 $A_\alpha\ (\alpha\in\Lambda)$ 的所有元素组成的集合称为这族集合的并集或和集，记为 $\bigcup\limits_{\alpha\in\Lambda} A_\alpha$，它可表示为 $\bigcup\limits_{\alpha\in\Lambda} A_\alpha = \{ x:\text{存在某个 }\alpha\in\Lambda,\text{ 使 } x\in A_\alpha \}$ 
	- 习惯上，当 $\Lambda = \{1,2,\cdots,k\}$ 为有限集时，$A = \bigcup\limits_{\alpha\in\Lambda} A_\alpha$ 写成 $A = \bigcup\limits_{n=1}^k a_n$，而 $A = \bigcup\limits_{n\in\mathbb N}A_n$ 写成 $A = \bigcup\limits_{n=1}^\infty A_n$ 
- **交集**（**积集**、**交**、**积**）：设 $A,B$ 是任意两个集合，由一切既属于 $A$ 又属于 $B$ 的元素组成的集合 $C$，称为 $A$ 和 $B$ 的**交集**或**积集**，简称为**交**或**积**，记为 $C=A\cap B$，它可表示为 $A\cap B = \{ x:x\in A\text{ 且 }x\in B \}$ 
	- **推广**：设 $\{ A_\alpha:\alpha\in\Lambda \}$ 是任意集族，其中 $\alpha$ 是指标，$\Lambda$ 是指标集。则由一切同时属于每个 $A_\alpha\ (\alpha\in\Lambda)$ 的元素所组成的集合，称为该集族的交集或积集，记为 $\bigcap\limits_{\alpha\in\Lambda} A_\alpha$，它可表示为 $\bigcap\limits_{\alpha\in\Lambda} A_\alpha = \{ x:\text{对任意 }\alpha\in\Lambda \text{ 有 } x\in A_\alpha \}$ 
	- 习惯上，当 $\Lambda = \{1,2,\cdots,k\}$ 为有限集时，$A = \bigcap\limits_{\alpha\in\Lambda} A_\alpha$ 写成 $A = \bigcap\limits_{n=1}^k a_n$，而 $A = \bigcap\limits_{n\in\mathbb N}A_n$ 写成 $A = \bigcap\limits_{n=1}^\infty A_n$ 
- **并和交的四个性质** 
	- **交换律**：$A\cup B = B\cup A$，$A\cap B = B\cap A$ 
	- **结合律**：$A\cup(B\cup C) = (A\cup B)\cup C$，$A\cap(B\cap C) = (A\cap B)\cap C$ 
	- **分配律**：$A\cap(B\cup C) = (A\cap B)\cup(A\cap C)$，$A\cap\left( \bigcup\limits_{\alpha\in\Lambda} B_\alpha \right) = \bigcup\limits_{\alpha\in\Lambda}(A\cap B_\alpha)$ 
	- $A\cup A = A$，$A\cap A = A$ 
- **差集**、**补集**：若 $A$ 和 $B$ 是集合，称 $A\backslash B = \{ x: x\in A\text{ 且 } x\not\in B \}$ 为 $A$ 和 $B$ 的**差集**。当我们讨论的集合都是某一个大集合 $S$（称为**全集**）的子集时，我们称 $S\backslash A$ 为 $A$ 的**补集**，并记 $S\backslash A = A^c$ 
	- 在欧氏空间 $\mathbb R^n$ 中，$\mathbb R^n \backslash A$ 写成 $A^c$ 
	- 当全集确定时，$A\backslash B = A\cap B^c$ 
- **德摩根(De Morgan)公式**：若 $\{A_\alpha:\alpha\in\Lambda\}$ 是一族集合，则 $\left( \bigcup\limits_{\alpha\in\Lambda} A_\alpha \right)^c = \bigcap\limits_{\alpha\in\Lambda} A_\alpha^c$，$\left( \bigcup\limits_{\alpha\in\Lambda} A_\alpha \right)^c = \bigcup\limits_{\alpha\in\Lambda} A_\alpha^c$ 
	- *证明过程* 
		设 $x\in \left( \bigcup\limits_{\alpha\in\Lambda} A_\alpha \right)^c$，则 $x\not\in \bigcup\limits_{\alpha\in\Lambda} A_\alpha$，因此对任意 $\alpha\in\Lambda$，$x\not\in A_\alpha$，即对任意 $\alpha\in\Lambda$，$x\in A_\alpha^c$，从而 $x\in\bigcap\limits_{\alpha\in\Lambda}A_\alpha^c$ 
		反之，设 $x\in \bigcap\limits_{\alpha\in\Lambda} A_\alpha^c$，则对任意 $\alpha\in\Lambda$，$x\in A_\alpha^c$，即对任意 $\alpha\in\Lambda$，$x\not\in A_\alpha$，则 $x\not\in \bigcup\limits_{\alpha\in\Lambda} A_\alpha$，从而 $x\in \left( \bigcup\limits_{\alpha\in\Lambda} A_\alpha \right)^c$ 
		综合可得 $\left( \bigcup\limits_{\alpha\in\Lambda} A_\alpha \right)^c = \bigcap\limits_{\alpha\in\Lambda} A_\alpha^c$，第二个式子同理可证
- **注意**：与“存在”相对应的是并集运算，与“任意”相对应的是交集运算
- **例子**：设 $\{f_n(x)\}$ 是定义在 $E$ 上的函数列，若 $x\in E$，则 $\{f_n(x)\}$ 有界 $\iff$ 存在 $M>0$，使得对任意 $n$，$|f_n(x)|\le M$ 
	- 上面例子可以翻译为：$\{x:\{f_n(x)\} \text{ 有界}\} = \bigcup\limits_{M\in\mathbb R^+} \bigcap\limits_{n=1}^\infty \{ |f_n(x)|\le M \}$
	- 若用德摩根公式则有：$\{x:\{f_n(x)\} \text{ 无界}\} = \left(\bigcup\limits_{M\in\mathbb R^+} \bigcap\limits_{n=1}^\infty \{ |f_n(x)|\le M \}\right)^c = \bigcap\limits_{M\in\mathbb R^+} \bigcup\limits_{n=1}^\infty \{ |f_n(x)|> M \}$ 
- **例子**：设 $\{f_n(x)\}$ 是定义在 $E$ 上的函数列，若 $x$ 是使 $|f_n(x)|$ 收敛于 $0$ 的点，则对任意 $\varepsilon>0$，存在 $N\in\mathbb N$，使得对任意 $n\ge N$，$|f_n(x)|<\varepsilon$。用集合语言描述为 $x\in \{x: \lim\limits_{n\to\infty} f_n(x)=0\} \iff x\in \bigcap\limits_{\varepsilon\in\mathbb R^+} \bigcup\limits_{N=1}^\infty \bigcap\limits_{n=N}^\infty \{ x:|f_n(x)|<\varepsilon \}$ 
	- *翻译过程* 
		$x\in \{x: \lim\limits_{n\to\infty} f_n(x)=0\}$，即为：对任意 $\varepsilon>0$，存在 $N$，对任意 $n\ge N$，$|f_n(x)|<\varepsilon$ 
		即为：对任意 $\varepsilon>0$，存在 $N$，对任意 $n\ge N$，$|f_n(x)|<\varepsilon$ 
		即为：对任意 $\varepsilon>0$，存在 $N$，$x\in \bigcap\limits_{n=N}^\infty \{ x:|f_n(x)|<\varepsilon \}$ 
		即为：对任意 $\varepsilon>0$，$x\in \bigcup\limits_{N=1}^\infty \bigcap\limits_{n=N}^\infty \{ x:|f_n(x)|<\varepsilon \}$ 
		即为，$x\in \bigcap\limits_{\varepsilon\in\mathbb R^+} \bigcup\limits_{N=1}^\infty \bigcap\limits_{n=N}^\infty \{ x:|f_n(x)|<\varepsilon \}$ 
	- 用德摩根公式得到：$x\in \{x: \lim\limits_{n\to\infty} f_n(x)\not=0\text{ 或不存在}\} \iff x\in \bigcup\limits_{\varepsilon\in\mathbb R^+} \bigcap\limits_{N=1}^\infty \bigcup\limits_{n=N}^\infty \{ x:|f_n(x)|\ge\varepsilon \}$ 
### 1-2-2 上极限、下极限
- **上极限**：设 $A_1, A_2, \cdots, A_n, \cdots$ 是任意一列集，由属于上述集列中无限多个集合的那种元素的全体所组成的集合称为这一集列的**上极限**，记为 $\overline\lim\limits_{n\to\infty} A_n$ 或 $\lim\limits_{n\to\infty} \sup A_n$ 
	- $\overline\lim\limits_{n\to\infty} A_n = \{x:\text{存在无穷多个 } A_n, \text{ 使 } x\in A_n\}$ 
	- $\overline\lim\limits_{n\to\infty} A_n = \{x:\text{对任意 } N>0, \text{ 存在 } n>N, \text{ 使 } x\in A_n\}$ 
- **下极限**：设 $A_1, A_2, \cdots, A_n, \cdots$ 是任意一列集，那种除有限个下标外，属于集列中每个集合的元素全体所组成的集合称为这一集列的**下极限**，记为 $\underline\lim\limits_{n\to\infty} A_n$ 或 $\lim\limits_{n\to\infty} \inf A_n$ 
	- $\underline\lim\limits_{n\to\infty} A_n = \{x:\text{当 } n \text{ 充分大以后都有 } x\in A_n\}$ 
	- $\underline\lim\limits_{n\to\infty} A_n \subset \overline\lim\limits_{n\to\infty} A_n$ 
- **定理**：上下极限可以用交集与并集来表示：$\overline\lim\limits_{n\to\infty} A_n = \bigcap\limits_{n=1}^\infty \bigcup\limits_{m=n}^\infty A_m$，$\underline\lim\limits_{n\to\infty} A_n = \bigcup\limits_{n=1}^\infty \bigcap\limits_{m=n}^\infty A_m$ 
	- *证明过程* 
		记 $A = \overline\lim\limits_{n\to\infty} A_n,\ B = \bigcap\limits_{n=1}^\infty \bigcup\limits_{m=n}^\infty A_m$ 
		设 $x\in A$，则对任意取定的 $n$，存在 $m>n$，使 $x\in A_m$，即对任何 $n$ 总有 $x\in \bigcup\limits_{m=n}^\infty A_m$，故 $x\in B$ 
		设 $x\in B$，则对任意的 $N>0$，总有 $x\in\bigcup\limits_{m=N+1}^\infty A_m$，即总存在 $m>N$，有 $x\in A_m$，所以 $x\in A$ 
		因此 $A=B$，即 $\overline\lim\limits_{n\to\infty} A_n = \bigcap\limits_{n=1}^\infty \bigcup\limits_{m=n}^\infty A_m$ 
		另一个公式可同理证明
- **例子**：设 $\{f_n(x)\}$ 是定义在 $E$ 上的函数列，若 $x$ 是使 $|f_n(x)|$ 收敛于 $0$ 的点，则对任意 $\varepsilon>0$，存在 $N\in\mathbb N$，使得对任意 $n\ge N$，$|f_n(x)|<\varepsilon$。用集合语言描述为
	- $\{x: \lim\limits_{n\to\infty} f_n(x)=0\} \iff \bigcap\limits_{\varepsilon\in\mathbb R^+} \bigcup\limits_{N=1}^\infty \bigcap\limits_{n=N}^\infty \{ x:|f_n(x)|<\varepsilon \} \iff \bigcap\limits_{\varepsilon\in\mathbb R^+} \underline\lim\limits_{n\to\infty} \{ x: |f_n(x)| <\varepsilon \}$ 
	- $\{x: \lim\limits_{n\to\infty} f_n(x)\not=0\text{ 或不存在}\} \iff \bigcup\limits_{\varepsilon\in\mathbb R^+} \bigcap\limits_{N=1}^\infty \bigcup\limits_{n=N}^\infty \{ x:|f_n(x)|\ge\varepsilon \} \iff \bigcup\limits_{\varepsilon\in\mathbb R^+} \overline\lim\limits_{n\to\infty} \{ x: |f_n(x)| \ge \varepsilon \}$ 
- **收敛**：如果 $\overline\lim\limits_{n\to\infty} A_n = \underline\lim\limits_{n\to\infty} A_n$，则称 $\{A_n\}$ **收敛**，记为 $\lim\limits_{n\to\infty} A_n$ 
	- 若极限允许取 $\pm \infty$，则单调数列总有极限
### 1-2-3 单调集列
- **增加集列**：如果集列 $\{A_n\}$ 满足 $A_n\subset A_{n+1},\ n=1,2,\cdots$，则称 $\{A_n\}$ 为**增加集列** 
- **减少集列**：如果集列 $\{A_n\}$ 满足 $A_n\supset A_{n+1},\ n=1,2,\cdots$，则称 $\{A_n\}$ 为**减少集列** 
- **单调集列**：增加集列和减少集列统称为**单调集列** 
- **性质**：单调集列是收敛的
	- 如果 $\{A_n\}$ 增加，则 $\lim\limits_{n\to\infty} A_n = \bigcup\limits_{n=1}^\infty A_n$ 
	- 如果 $\{A_n\}$ 减少，则 $\lim\limits_{n\to\infty} A_n = \bigcap\limits_{n=1}^\infty A_n$ 
### 1-2-4 集合的直积
- **直积**：若 $A_i\ (i=1,2,\cdots,n)$ 是集合，则 $A = \{(x_1,x_2,\cdots, x_n): x_i\in A_i,\ i=1,2,\cdots,n \}$ 称为 $A_i\ (i=1,2,\cdots,n)$ 的**直积**，记为 $\prod\limits_{i=1}^n A_i$ 或 $A_1 \times A_2 \times \cdots \times A_n$ 
	- **推广**：类似地，$\prod\limits_{i=1}^\infty A_i = A_1 \times A_2 \times \cdots = \{ (x_1,x_2,\cdots): x_i\in A_i,\ i=1,2,\cdots \}$ 
	- 若 $A_i = A\ (i=1,2,\cdots)$，则 $\prod\limits_{i=1}^n A_i = A^n,\ \prod\limits_{i=1}^\infty A_i = A^\infty$ 
## 1-3 对等与基数
### 1-3-1 对等
- **有限集**、**无限集**：空集与只含有有限多个元素的集合称为**有限集**，其余的称为**无限集** 
	- 两个非空有限集合元素个数相同 $\iff$ 它们能够和正整数列的同一截段一一对应 $\iff$ 这两个集合彼此一一对应
- **映射**、**像**：设 $A,B$ 为两个非空集合，如果有某一法则 $\varphi$，使每个 $x\in A$ 有唯一确定的 $y\in B$ 和它对应，则称 $\varphi$ 为 **$A$ 到 $B$ 内的映射**，记为 $\varphi:A\rightarrow B$。当映射 $\varphi$ 使 $y$ 和 $x$ 对应时，$y$ 称为 $x$ 在映射 $\varphi$ 下的**像**，记作 $y=\varphi(x)$ 
- **像集**、**原像**：对任意 $E\subset A$，称 $\varphi(E) = \{ y:y=f(x),\ x\in E \}$ 为 $A$ 在 $\varphi$ 下的**像集**。若 $F\subset B$，称 $\varphi^{-1}(F) = \{ x: \varphi(x)\in F \}$ 为 $F$ 关于 $\varphi$ 的**原像** 
- **单射**、**满射**、**双射**：设 $\varphi:A\to B$，称 $\varphi$ 为
	- **单射**：若由任意 $x,y\in A$，$\varphi(x) = \varphi(y)$，可推得 $x=y$ 
	- **满射**：若对任意 $y\in B$，存在 $x\in A$，使得 $\varphi(x) = y$ 
	- **双射**：若 $\varphi$ 既是单射又是满射
- **逆映射**：设 $\varphi$ 是从 $A$ 到 $B$ 上的一个双射，则对任意 $y\in B$，存在唯一 $x\in A$，使 $y=\varphi(x)$，称 $\sigma(y) = x$ 所定义的映射 $\sigma: B\to A$ 为 $\varphi$ 的**逆映射**，记为 $\sigma = \varphi^{-1}:B\to A$ 
- **复合映射**：设 $\varphi:A\to B$，$\psi:B\to C$，则称 $\rho(x) = \psi(\varphi(x))$ 所定义的映射 $\rho: A\to C$ 是 $\varphi$ 和 $\psi$ 的**复合映射**，记为 $\rho = \psi \circ \varphi:A\to C$ 
- **对等**：若 $A,B$ 是非空集合，且存在双射 $\varphi:A\to B$，则称 $A$ 与 $B$ **对等**，记为 $A\sim B$，规定 $\varnothing \sim \varnothing$ 
	- **性质**：一个无限集可以和它的一个真子集对等
- **对等的性质**：对任何集合 $A,B,C$ 均有
	- **自反性**：$A\sim A$ 
	- **对称性**：$A\sim B \Rightarrow B\sim A$ 
	- **传递性**：$A\sim B, B\sim C \Rightarrow A\sim C$ 
### 1-3-2 基数
- **相等的基数**：若 $A$ 和 $B$ 对等，则称它们有**相同的基数**，记为 $\overline {\overline A} = \overline{\overline B}$ 
- **较小的基数**、**较大的基数**：设 $A,B$ 是两个集合，如果 $A$ 不与 $B$ 对等，但存在 $B$ 的真子集 $B^*$，有 $A\sim B^*$，则称 $A$ 比 $B$ 有**较小的基数**（或 $B$ 比 $A$ 有**较大的基数**），并记为 $\overline{\overline A} < \overline{\overline B}$ 或 $\overline{\overline B} > \overline{\overline A}$ 
- **定理**：任给两个集合 $A,B$，在 $\overline {\overline A} < \overline{\overline B},\ \overline {\overline A} = \overline{\overline B},\ \overline {\overline A} > \overline{\overline B}$ 中必有一个成立且只有一个成立
- **伯恩斯坦(Bernstein)定理**：设 $A,B$ 是两个非空集合，如果 $A$ 对等于 $B$ 的一个子集，$B$ 又对等于 $A$ 的一个子集，那么 $A$ 对等于 $B$ 
	- **利用基数的描述**：设 $\overline {\overline A} \le \overline{\overline B},\ \overline {\overline B} \le \overline{\overline A}$，则 $\overline {\overline A} = \overline{\overline B}$ 
	- *证明过程* 
		由假设，存在 $A$ 到 $B$ 的子集 $B_1$ 上的一一映射 $\varphi_1$ 及 $B$ 到 $A$ 的子集 $A_1$ 上的一一映射 $\varphi_2$，因为 $B_1\subset B$，记 $A_2 = \varphi_2(B_1)$ 
		显然 $\varphi_2$ 是 $B_1$ 到 $A_2$ 上的一一映射，即 $A \overset{\varphi_1} \sim B_1 \overset{\varphi_2}\sim A_2$，并且 $A_2\subset A_1$ 
		作映射 $\varphi_1$ 和 $\varphi_2$ 的复合映射 $\varphi$ 如下：当 $x\in A$ 时，$\varphi(x) = \varphi_2(\varphi_1(x))$，那么 $\varphi$ 实现了 $A$ 到 $A_2$ 上的一一对应
		因为 $A_1$ 是 $A$ 的子集，$A_3=\varphi(A_1)$ 是 $A_2$ 的子集，所以 $A_1\overset\varphi\sim A_3$，并且 $A_3\subset A_2$ 
		照这样进行下去，我们得到一列子集 $A_1\supset A_2 \supset A_3 \supset \cdots \supset A_n \supset \cdots$ 
		于是在同一个映射 $\varphi$ 之下，有 $A\sim A_2\sim A_4\sim \cdots$，$A_1\sim A_3\sim A_5\sim \cdots$ 
		这样我们可以把 $A$ 分解为一系列互不相交的子集的并，即：
		$$
		\begin{aligned}
		A = & (A\backslash A_1)\cup A_1 = (A\backslash A_1)\cup (A_1\backslash A_2)\cup A_2 \\
		= & (A\backslash A_1)\cup (A_1\backslash A_2)\cup (A_2\backslash A_3) \cup \cdots \cup D
		\end{aligned}
		$$
		其中 $D = A\cap A_1 \cap A_2 \cap A_3 \cap \cdots$ 
		类似地，$A_1 = (A_1\backslash A_2) \cup (A_2\backslash A_3) \cup (A_4\backslash A_4) \cup \cdots \cup D_1$，其中 $D_1 = A_1\cap A_2 \cap A_3 \cap \cdots$ 
		易知，$D=D_1$，所以 $D\sim D_1$，又因为映射 $\varphi$ 是一一映射，容易看出
		$$
		\begin{matrix}
		A \backslash A_1 \sim A_2 \backslash A_3 \\
		A_1 \backslash A_2 \sim A_3 \backslash A_4 \\
		\cdots \\
		A_n \backslash A_{n+1} \sim A_{n+2} \backslash A_{n+3} \\
		\cdots 
		\end{matrix}
		$$
		显然，我们可以把 $A$ 及 $A_1$ 的上述分解写成
		$$
		\begin{matrix}
		A = D \cup (A\backslash A_1)\cup (A_1\backslash A_2)\cup (A_2\backslash A_3) \cup (A_3 \backslash A_4) \cup \cdots \\
		A_1 = D \cup (A_2\backslash A_3)\cup (A_1\backslash A_2)\cup (A_4\backslash A_5) \cup (A_3 \backslash A_4) \cup \cdots \\
		\end{matrix}
		$$
		它们的对应项在映射 $\varphi$ 之下是对等的，从而有 $A\sim A_1$，而 $A_1\sim B$，所以 $A\sim B$，证毕！

	- 该定理给我们提供了一个判定两个集合对等的有力工具
	- **推论**：设 $A\supset B\supset C$ 且 $A\sim C$，则 $A\sim B\sim C$ 
		- *证明过程* 
			由假设知 $B\sim C^* \subset C$ 及 $C\sim B^* \supset B$，再由伯恩斯坦定理可知 $B\sim C$，从而 $A\sim B$，故 $A\sim B\sim C$ 
## 1-4 可数集合
- **可数集合**（**可列集合**）：凡和全体正整数所成的集合 $\mathbb Z^+$ 对等的集合都称为**可数集合**或**可列集合** 
	- 可数集合是无限集合
	- 一个集合 $A$ 是可数集合 $\iff$ $A$ 可以排成一个无穷序列 $a_1,a_2,a_3,\cdots,a_n,\cdots$ 
- **定理 1**：任何无限集合都至少包含一个可数子集
	- *证明过程* 
		设 $M$ 是一个无限集，因 $M\not=\varnothing$，总可以从 $M$ 中取一元素记为 $e_1$ 
		由于 $M$ 是无限集，故 $M\backslash \{e_1\}\not=\varnothing$，于是又可以从 $M\backslash\{e_1\}$ 中取一元素，记为 $e_2$，显然 $e_2\in M$ 且 $e_1\not=e_2$ 
		设已从 $M$ 中取出 $n$ 个这样的互异元素 $e_1,e_2,\cdots,e_n$ 
		由于 $M$ 是无限集，故 $M\backslash\{e_1,e_2,\cdots,e_n\}\not=\varnothing$，于是又可以从 $M\backslash\{e_1,e_2,\cdots,e_n\}$ 中取一元素，记为 $e_{n+1}$，显然 $e_{n+1}\in M$ 且和 $e_1,e_2,\cdots,e_n$ 都不相同
		由归纳法，我们就找到 $M$ 的一个无限子集 $\{e_1,e_2,e_3,\cdots,e_n,\cdots\}$，它显然是一个可数集
	- **可数集的特征**：它在所有无限集中有最小的基数
- **定理 2**：可数集合的任何子集或者是有限集或者是可数集
	- *证明过程* 
		只需证：可数集合的任何无限子集必为可数集合
		设 $A$ 为可数集而 $A^*$ 是 $A$ 的一个无限子集，则由于 $A^*$ 是 $A$ 的子集，有 $\overline{\overline{A^*}} \le \overline{\overline A}$；又由于 $A^*$ 是无限集合，而 $A$ 是可数集，依**定理 1** 有$\overline{\overline{A^*}} \ge \overline{\overline A}$ 
		因此，按伯恩斯坦定理就有 $\overline{\overline {A^*}} = \overline{\overline A}$，即 $A^*$ 也是可数集
- **定理 3**：设 $A$ 为可数集，$B$ 为有限或可数集，则 $A\cup B$ 为可数集
	- *证明过程* 
		**第一种情况**：$A\cap B  = \varnothing$ 
		由于可数集总可排列成无穷序列，不妨设 $A = \{a_1,a_2,\cdots\},\ B = \{b_1,b_2,\cdots,b_n\}$（当 $B$ 有限时）或 $B = \{ b_1,b_2,\cdots, b_n, \cdots \}$（当 $B$ 可数时）
		由于当 $B$ 有限时（$B$ 排在前，$A$ 排在后），$A\cup B = \{b_1,b_2,\cdots, b_n, a_1,a_2,\cdots\}$ 
		又当 $B$ 可数时（交错排列），$A\cup B = \{a_1,b_1,a_2,b_2,\cdots,a_n,b_n,\cdots\}$ 
		可见 $A\cup B$ 总可以排成无穷序列，从而是可数集
		**第二种情况**：一般情形下（$A\cap B \not=\varnothing$）
		此时，令 $B^* = B\backslash A$，则 $A\cap B^* = \varnothing,\ A\cup B = A\cup B^*$，但 $B^*$ 作为 $B$ 的子集仍为有限或可数集（定理 2），这样就归结到第一种情况了
		综上证毕！
	- **推论**：设 $A_i\ (i=1,2,\cdots,n)$ 是有限集或可数集，则 $\bigcup\limits_{i=1}^n A_i$ 也是有限集或可数集，但如果至少有一个 $A_i$ 是可数集，则 $\bigcup\limits_{i=1}^n A_i$ 必为可数集
- **定理 4**：设 $A_i\ (i=1,2,3,\cdots)$ 都是可数集，则 $\bigcup\limits_{i=1}^\infty A_i$ 也是可数集
	- *证明过程* 
		**情况 1**：若 $A_i\cap A_j = \varnothing\ (i\not=j)$ 
		因 $A_i$ 都是可数集，故可令
		![[Pasted image 20251126191842.png|180]]
		按照箭头顺序可将 $\bigcup\limits_{i=1}^\infty A_i$ 排成 $\bigcup\limits_{i=1}^\infty A_i = \{ a_{11}, a_{12}, a_{21}, a_{31}, a_{22}, a_{13}, a_{14}, \cdots \}$，因此 $\bigcup\limits_{i=1}^\infty A_i$ 是可数集
		注意，上面的证明当部分（不是全部）$A_i$ 是有限集时仍可适用
		**情况 2**：一般情形下
		令 $A_1^* = A_1,\ A_i^* = A_i - \bigcup\limits_{j=1}^{i-1}A_j\ (i\ge 2)$，则 $A_i^* \cap A_j^* = \varnothing\ (i\not=j)$，且 $\bigcup\limits_{i=1}^\infty A_i = \bigcup\limits_{i=1}^\infty A_i^*$ 
		易知 $A_i^*$ 都是有限集或可数集（定理 2），如果只有有限个 $A_i^*$ 不为空集，则由定理 3 的推论，$\bigcup\limits_{i=1}^\infty A_i^*$ 为可数集（因为至少 $A_1^* = A_1$ 为可数集）

		故在任何情形下，$\bigcup\limits_{i=1}^\infty A_i$ 都是可数集，证毕！
- $a,\ \aleph_0$：今后用 $a$ 或 $\aleph_0$ 表示可数集的基数
	- 则当 A_i$ 均为可数集合时，定理 3 推论可简记为 $n\cdot a = \underbrace{a+a+\cdots+a}_{n\text{ 个}} = a$，定理 4 可简记为 $a\cdot a = \underbrace{a+a+\cdots +a + \cdots}_{\text{可数个}} = a$ 
- **定理 5**：有理数全体成一可数集合
	- *证明过程* 
		设 $A_i = \left\{ \dfrac 1i, \dfrac 2i, \dfrac 3i, \cdots \right\}\ (i=1,2,3,\cdots)$，则 $A_i$ 是可数集，由定理 4 可知全体正有理数成一可数集 $\mathbb Q^+ = \bigcup\limits_{i=1}^\infty A_i$ 
		因正负有理数通过 $\varphi(r) = -r$ 成为一一对应，故全体负有理数成一可数集 $\mathbb Q^-$ 
		有理数全体所成之集合 $\mathbb Q = \mathbb Q^+ \cup \mathbb Q^- \cup \{0\}$，故由定理 3 推论可知 $\mathbb Q$ 为可数集，证毕！
	- 注意：有理数在实数中是处处稠密的，即在数轴上任何小区间中都有有理数存在（并且有无穷多个）。尽管如此，全体有理数还只不过是一个和稀疏分布着的正整数全体成为一一对应的可数集。

- **定理 6**：设 $A_i\ (i=1,2,\cdots,n)$ 是可数集，则 $A = A_1\times A_2\times \cdots \times A_n$ 是可数集
	- *证明过程* 
		用归纳法，显然 $i=1$ 时，结论成立
		假设已知：若 $A_i\ (i=1,2,\cdots,n-1)$ 是可数集，则 $A = A_1\times A_2\times \cdots \times A_{n-1}$ 是可数集
		因已知 $A_n$ 可数，故可设 $A_n = \{ x_1,x_2,\cdots,x_k,\cdots \}$ 
		记 $\hat A_k = A_1\times A_2\times \cdots \times A_{n-1}\times \{x_k\}$，则 $\hat A_k \sim A_1\times A_2\times \cdots \times A_{n-1}\ (k=1,2,\cdots)$，因此 $\hat A_k$ 是可数集
		又 $A_1\times A_2\times \cdots \times A_n = \bigcup\limits_{k=1}^\infty \hat A_k$，由定理 4，$A = A_1\times A_2\times \cdots \times A_n$ 是可数集，证毕！
- **定理 7**：代数数的全体成一可数集（所谓代数数，乃是整系数多项式的根）
	- *证明过程* 
		**第一步**：证明整系数多项式 $a_0x^n + a_1x^{n-1} + \cdots + a_{n-1}x + a_n$ 的全体是一可数集
		对任意 $n$，设 $A_n$ 是 $n$ 次整系数多项式的全体组成的集合，则 $A_n = \{a_0x^n + a_1x^{n-1} + \cdots + a_n\}\sim \mathbb Z_0 \times \underbrace{\mathbb Z\times \cdots \times \mathbb Z}_{n\text{ 个}}$，其中 $\mathbb Z_0 = \mathbb Z \backslash \{0\}$ 和 $\mathbb Z$ 都是可数集
		因此由定理 6，$A_n$ 是可数集，从而整系数多项式的全体组成的集合 $A = \bigcup\limits_{n=0}^\infty A_n$ 也是可数集
		**第二步**：证明原定理
		由于每个多项式只有有限个根，故原定理成立
## 1-5 不可数集合
- **不可数集合**：不是可数集合的无限集合称为**不可数集合** 
- **十进位无穷小数**：可定义**十进位无穷小数** $a = 0.a_1a_2a_3\cdots = \sum\limits_{n=1}^\infty \dfrac{a_n}{10^n}$ 
- **十进位正规表示**：十进位无穷小数的**正规表示**为 $a = 0.a_1a_2a_3\cdots = \sum\limits_{n=1}^\infty \dfrac{a_n}{10^n}$，其中各 $a_n$ 是 $0,1,\cdots,9$ 中的一个数字，不全为 $9$，且不以 $0$ 为循环节
- **$p$ 进位无穷小数**：可定义 **$p$ 进位无穷小数** $a = 0.a_1a_2a_3\cdots = \sum\limits_{n=1}^\infty \dfrac{a_n}{p^n}$，其中 $p\ (\ge 2)$ 为正整数，$a_n$ 取 $0,1,2,\cdots,p-1$ 
- **$p$ 进位正规表示**：$p$ 进位无穷小数的**正规表示**为 $a = 0.a_1a_2a_3\cdots = \sum\limits_{n=1}^\infty \dfrac{a_n}{p^n}$，其中各 $a_n$ 是 $0,1,\cdots,p-1$ 中的一个数字，不全为 $p-1$，且不以 $0$ 为循环节
- **定理 1**：全体实数所成集合 $\mathbb R$ 是一个不可数集合
	- *证明过程* 
		对每个 $x\in (0,1)$，令 $\varphi(x) = \tan\left( \pi x - \dfrac \pi 2 \right)$，则区间 $(0,1)$ 和全体实数 $\mathbb R$ 对等，故只需证明 $(0,1)$ 不是可数集
		首先 $(0,1)$ 中每一个实数 $a$ 都可以唯一地表示为十进位无穷小数 $a = 0.a_1a_2a_3\cdots = \sum\limits_{n=1}^\infty \dfrac{a_n}{10^n}$ 的形式，其中各 $a_n$ 是 $0,1,\cdots,9$ 中的一个数字，不全为 $9$，且不以 $0$ 为循环节，实数的这种表示为一个**正规表示** 
		反之，每一个上述形式的无穷小数都是 $(0,1)$ 中某一实数的正规表示
		现用反证法，假设 $(0,1)$ 中的全体实数可排列成一个序列 $(0,1) = \{a^{(1)}, a^{(2)}, a^{(3)}, \cdots \}$，将每个 $a^{(n)}$ 表示成正规的无穷小数：
		$$
		\begin{matrix}
		a^{(1)} = 0.a_1^{(1)}a_2^{(1)}a_3^{(1)}\cdots,\\
		a^{(2)} = 0.a_1^{(2)}a_2^{(2)}a_3^{(2)}\cdots,\\
		a^{(3)} = 0.a_1^{(3)}a_2^{(3)}a_3^{(3)}\cdots,\\
		\cdots
		\end{matrix}
		$$
		现设法在 $(0,1)$ 中找一个与所有这些实数都不同的实数，为此利用对角线上的数字 $a_n^{(n)}\ (n=1,2,\cdots)$ 
		作一个无穷小数如下：$0.a_1a_2a_3\cdots,\ \text{其中 }a_n = \begin{cases} 1 & a_n^{(n)}\not=1 \\ 2 & a_n^{(n)}=1 \end{cases}$ 
		则此无穷小数的各位数字既不全是 $9$，也不以 $0$ 为循环节，因此必是 $(0,1)$ 中某一实数 $a$ 的正规表示
		但从这个无穷小数的作法可知，它与每一个 $a^{(n)}$ 的正规表示都不同（因为至少第 $n$ 为小数不同）
		因此 $a\not=a^{(n)}\ (n=1,2,3,\cdots)$，从而 $(0,1)\not=\{ a^{(1)}, a^{(2)}, a^{(3)}, \cdots \}$，与假设矛盾，因此 $(0,1)$ 是不可数集合
	- **推论**：若用 $c$ 表示全体实数所成集合 $\mathbb R$ 的基数，用 $a$ 表示全体正整数所成集合 $\mathbb Z^+$ 的基数，则 $c>a$ 
	- **连续基数**：以后称 $c$ 为连续基数（$c$ 有时记为 $\aleph$）
- **定理 2**：设 $a<b$，则任意区间 $(a,b), [a,b), (a,b], (0,\infty),[0,\infty)$ 均具有连续基数 $c$ 
- **定理 3**：设 $A_1,A_2,\cdots,A_n.\cdots$ 是一列互不相交的集合，它们的基数都是 $c$，则 $\bigcup\limits_{n=1}^\infty A_n$ 的基数也是 $c$ 
	- *证明过程* 
		设 $I_n = [n-1,n)$，则 $I_n\cap I_m = \varnothing\ (m\not=n)$，但 $\overline{\overline {I_n}} = c\ (n=1,2,\cdots)$，故 $I_n\sim A_n\ (n=1,2,\cdots)$，从而 $\bigcup\limits_{n=1}^\infty A_n \sim \bigcup\limits_{n=1}^\infty I_n = [0,\infty)$ 
		再由定理 2 即证
- **定理 4**：设若有一列集合 $\{A_n: n\in\mathbb Z^+\},\ \overline{\overline{A_n}} = c\ (n=1,2,\cdots)$，而 $A = \prod\limits_{n=1}^\infty A_n$，则 $\overline{\overline A} = c$ 
	- *证明过程* 
		由于 $\overline{\overline{A_n}} = \overline{\overline{(0,1)}}=c$，不妨设 $A_n = (0,1),\ n=1,2,\cdots$ 
		首先把 $(0,1)$ 中任何 $x$ 与 $A$ 中点 $\overline x = \{x,x,x,\cdots\}$ 对应，就知道 $(0,1)$ 对等于 $A$ 的一个子集
		反之，对 $A$ 中的任何 $x = \{x_1,x_2,\cdots,x_n,\cdots\}$ 按正规十进位无限小数表示 $x_n$ 有：
		$$
		\begin{matrix}
		x_1 = 0.x_{11}x_{12}\cdots x_{1n}\cdots \\
		x_2 = 0.x_{21}x_{22}\cdots x_{2n}\cdots \\
		\cdots \\
		x_n = 0.x_{n1}x_{n2}\cdots x_{nn}\cdots \\
		\cdots
		\end{matrix}
		$$
		由上述一列数 $x = \{x_n\}\in B$，作一小数 $\psi(x) = 0.x_{11}x_{12}x_{21}x_{31}x_{22}x_{13}x_{14}x_{23}\cdots$ 
		显然 $\psi(x)\in (0,1)$，而且当 $x\not=y$ 时，$\psi(x)\not=\psi(y)$ 
		由映射 $\psi$，$A$ 也对等于 $(0,1)$ 的一个子集，所以由伯恩斯坦定理得 $A\sim(0,1)$，定理得证！
	- 该定理可简写为 $c^a = c$ 
- **$n$ 维欧几里得空间**（**欧氏空间**）、**点**、**坐标**：设 $n$ 为一个正整数，将由 $n$ 个实数 $x_1,x_2,\cdots,x_n$，按确定的次序排成的数组 $(x_1,x_2,\cdots,x_n)$ 全体称为 **$n$ 维欧几里得空间**（简称**欧氏空间**），记为 $\mathbb R^n$，每个组 $(x_1,x_2,\cdots,x_n)$ 称为**欧几里得空间的点**。又称 $x_i$ 为点 $(x_1,x_2,\cdots,x_n)$ 的第 $i$ 个坐标
	- 记 $\mathbb R^\infty = \{ (x_1,x_2,\cdots): x_i\in\mathbb R,\ i=1,2,\cdots \}$ 
- **定理 5**：$n$ 维欧几里得空间 $\mathbb R^n$ 的基数为 $c$ 
	- *证明过程* 
		若将 $\mathbb R^n$ 中点 $(x_1,x_2,\cdots,x_n)$ 对应于 $\mathbb R^\infty$ 中点 $(x_1,x_2,\cdots,x_n,0,\cdots,0,\cdots)$ 时，就知道 $\mathbb R^n$ 对等于 $\mathbb R^\infty$ 的子集
		如果再将 $\mathbb R$ 中点 $x$ 对应于 $\mathbb R^n$ 中点 $(x,0,\cdots,0)$ 时，又知道 $\mathbb R$ 对应于 $\mathbb R^n$ 的一个子集
		则有 $c=\overline{\overline{\mathbb R}} \le \overline{\overline{\mathbb R^n}} \le \overline{\overline{\mathbb R^\infty}} =c$，因此 $\overline{\overline{\mathbb R^n}} = c$，证毕！
	- 该定理可简写为 $c^n = c$ 
- **推论**：设若有一列集合 $\{B_n: n\in\mathbb Z^+ \},\ B_n = \{0,1\}\ (n=1,2,\cdots)$，而 $B = \prod\limits_{n=1}^\infty B_n$，则 $\overline{\overline B} = c$ 
	- *证明过程* 
		由于 $\overline{\overline{B_n}}\le c$，因此 $\overline{\overline B} = \overline{\overline{\prod\limits_{n=1}^\infty B_n}} \le \overline{\overline{\prod\limits_{n=1}^\infty A_n}} \le = c$，其中 $A_n = (0,1),\ n=1,2,\cdots$ 
		任取 $x\in(0,1)$，用正规的二进制小数表示 $x$，即 $x=0.a_1a_2\cdots a_n\cdots$，其中 $a_n = 0,1;\ n=1,2,\cdots$ 
		定义 $\varphi:(0,1)\to B,\ \varphi(x) = (a_1,a_2,\cdots,a_n,\cdots)$，显然 $\varphi$ 是单射，于是 $\overline{\overline B}\ge \overline{\overline{\varphi((0,1))}} = \overline{\overline{(0,1)}} = c$，由伯恩斯坦定理，$\overline{\overline B} = c$ 
	- 该定理可简写为 $2^a = c$ 
- **定理 6**：设 $M$ 是任意的一个集合，它的所有子集作成新的集合 $\mu$，则 $\overline{\overline \mu} > \overline{\overline M}$ 
	- *证明过程* 
		**第一步**：先证明 $\mu$ 不能与 $M$ 对等
		假设 $\mu\sim M$，则对应于每个 $\alpha\in M$，都应有 $M$ 的一个子集 $M_\alpha$ 与之对应
		现在我们将 $M$ 中所有那样的 $\alpha$，满足 $\alpha\not\in M_\alpha$，作成一集合 $M^1$，则 $M^1\subset M$，所以 $M^1\in \mu$，从而应有 $M$ 中元素 $\alpha^1$ 与之对应
		若 $\alpha^1\in M^1$，则与 $M^1$ 的定义矛盾。这是因为 $M^1$ 是由那些 $\alpha\not\in M_\alpha$ 的 $\alpha$ 作成的，可见 $\alpha^1\not\in M^1$ 
		若 $\alpha^1\not\in M^1$，那么由 $M^1$ 的定义，$\alpha^1$ 又应该属于 $M^1$，因为 $M^1$ 包括了所有 $\alpha\in M_\alpha$ 的 $\alpha$ 
		这就产生了矛盾，因而 $M$ 不对等于 $\mu$ 
		**第二步**：证明原命题
		因为那些只含一个元素的子集自然是作成一个对等于 $M$ 的 $\mu$ 的子集，故 $M$ 对等于 $\mu$ 的一个子集
		综上，$\overline{\overline \mu} > \overline{\overline M}$ 
	- 一般，集合 $M$ 的所有子集组成的集合记为 $2^M$ 
	- 该定理证明了：对任意集合 $M$，$\overline{\overline M}< \overline{\overline{2^M}}$，从而没有最大的基数
- **说明**：由于可数集中元素比连续基数集中元素少得多，我们通常尽可能地用可数集合交、并运算代替不可数集合的交、并运算
- **例子**：设 $f(x)$ 是定义在点集 $E$ 上的函数，则 $\{ x:|f(x)|=0 \} = \bigcap\limits_{\varepsilon\in\mathbb R^+} \{ x:|f(x)|<\varepsilon \} = \bigcap\limits_{n=1}^\infty \left\{ x:|f(x)| < \dfrac 1n \right\}$ 
- **例子**：设 $\{f_n(x)\}$ 是定义在点集 $E$ 上的函数列，则
	- $\{x: \lim\limits_{n\to\infty} f_n(x)=0\} = \bigcap\limits_{\varepsilon\in\mathbb R^+} \bigcup\limits_{N=1}^\infty \bigcap\limits_{n=N}^\infty \{ x:|f_n(x)|<\varepsilon \} = \bigcap\limits_{k=1}^\infty \bigcup\limits_{N=1}^\infty \bigcap\limits_{n=N}^\infty \left\{ x:|f_n(x)|<\dfrac 1k \right\}$ 
	- $\{x: \lim\limits_{n\to\infty} f_n(x)\not=0\text{ 或不存在}\} =  \bigcup\limits_{\varepsilon\in\mathbb R^+} \bigcap\limits_{N=1}^\infty \bigcup\limits_{n=N}^\infty \{ x:|f_n(x)|\ge\varepsilon \} = \bigcup\limits_{k=1}^\infty \bigcap\limits_{N=1}^\infty \bigcup\limits_{n=N}^\infty \left\{ x:|f_n(x)|\ge\dfrac 1k \right\}$
