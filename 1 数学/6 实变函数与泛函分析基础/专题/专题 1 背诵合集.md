# 1 集合
## 1-1 集合的表示与运算
- **值域**、**原像**：设 $f(x)$ 是定义在 $E$ 上的函数，记 $f(E) = \{ f(x): x\in E \}$，称之为 $f$ 的**值域**。若 $D$ 是 $\mathbb R$ 中的集合，则 $f^{-1}(D) = \{ x:x\in E, f(x)\in D \}$ 称之为 $D$ 的原像
	- 在不致混淆时，$\{x:x\in E,\ f(x)\text{ 满足条件 } p\}$ 可简写为 $\{x:f(x)\text{ 满足条件 }p\}$ 
- **子集**、**真子集**：若集合 $A$ 和 $B$ 满足对任意 $x\in A$ 可得到 $x\in B$，则称 $A$ 是 $B$ 的**子集**，记为 $A\subset B$ 或 $B\supset A$。若 $A\subset B$ 但 $A$ 并不与 $B$ 相同，则称 $A$ 是 $B$ 的**真子集** 
- **相等**：若集合 $A$ 和 $B$ 满足 $A\subset B$ 且 $B\subset A$，则称 $A$ 和 $B$ **相等**，记为 $A=B$ 
- **并集**（**和集**、**并**、**和**）：设 $A,B$ 是任意两个集合，设 $C$ 由一切或属于 $A$ 或属于 $B$ 的元素所组成，则我们称 $C$ 为 $A$ 与 $B$ 的**并集**或**和集**，简称为**并**或**和**，记为 $C=A\cup B$，它可表示为 $A\cup B = \{ x:x\in A\text{ 或 }x\in B \}$ 
	- **推广**：设有一族集合 $\{ A_\alpha:\alpha\in\Lambda \}$，其中 $\alpha$ 是在固定指标集 $\Lambda$ 中变化的指标，则由一切 $A_\alpha\ (\alpha\in\Lambda)$ 的所有元素组成的集合称为这族集合的并集或和集，记为 $\bigcup\limits_{\alpha\in\Lambda} A_\alpha$，它可表示为 $\bigcup\limits_{\alpha\in\Lambda} A_\alpha = \{ x:\text{存在某个 }\alpha\in\Lambda,\text{ 使 } x\in A_\alpha \}$ 
	- 习惯上，当 $\Lambda = \{1,2,\cdots,k\}$ 为有限集时，$A = \bigcup\limits_{\alpha\in\Lambda} A_\alpha$ 写成 $A = \bigcup\limits_{n=1}^k a_n$，而 $A = \bigcup\limits_{n\in\mathbb N}A_n$ 写成 $A = \bigcup\limits_{n=1}^\infty A_n$ 
- **交集**（**积集**、**交**、**积**）：设 $A,B$ 是任意两个集合，由一切既属于 $A$ 又属于 $B$ 的元素组成的集合 $C$，称为 $A$ 和 $B$ 的**交集**或**积集**，简称为**交**或**积**，记为 $C=A\cap B$，它可表示为 $A\cap B = \{ x:x\in A\text{ 且 }x\in B \}$ 
	- **推广**：设 $\{ A_\alpha:\alpha\in\Lambda \}$ 是任意集族，其中 $\alpha$ 是指标，$\Lambda$ 是指标集。则由一切同时属于每个 $A_\alpha\ (\alpha\in\Lambda)$ 的元素所组成的集合，称为该集族的交集或积集，记为 $\bigcap\limits_{\alpha\in\Lambda} A_\alpha$，它可表示为 $\bigcap\limits_{\alpha\in\Lambda} A_\alpha = \{ x:\text{对任意 }\alpha\in\Lambda \text{ 有 } x\in A_\alpha \}$ 
	- 习惯上，当 $\Lambda = \{1,2,\cdots,k\}$ 为有限集时，$A = \bigcap\limits_{\alpha\in\Lambda} A_\alpha$ 写成 $A = \bigcap\limits_{n=1}^k a_n$，而 $A = \bigcap\limits_{n\in\mathbb N}A_n$ 写成 $A = \bigcap\limits_{n=1}^\infty A_n$ 
- **并和交的四个性质** 
	- **交换律**：$A\cup B = B\cup A$，$A\cap B = B\cap A$ 
	- **结合律**：$A\cup(B\cup C) = (A\cup B)\cup C$，$A\cap(B\cap C) = (A\cap B)\cap C$ 
	- **分配律**：$A\cap(B\cup C) = (A\cap B)\cup(A\cap C)$，$A\cap\left( \bigcup\limits_{\alpha\in\Lambda} B_\alpha \right) = \bigcup\limits_{\alpha\in\Lambda}(A\cap B_\alpha)$ 
	- $A\cup A = A$，$A\cap A = A$ 
- **差集**、**补集**：若 $A$ 和 $B$ 是集合，称 $A\backslash B = \{ x: x\in A\text{ 且 } x\not\in B \}$ 为 $A$ 和 $B$ 的**差集**。当我们讨论的集合都是某一个大集合 $S$（称为**全集**）的子集时，我们称 $S\backslash A$ 为 $A$ 的**补集**，并记 $S\backslash A = A^c$ 
	- 当全集确定时，$A\backslash B = A\cap B^c$ 
- **德摩根(De Morgan)公式**：若 $\{A_\alpha:\alpha\in\Lambda\}$ 是一族集合，则 $\left( \bigcup\limits_{\alpha\in\Lambda} A_\alpha \right)^c = \bigcap\limits_{\alpha\in\Lambda} A_\alpha^c$，$\left( \bigcap\limits_{\alpha\in\Lambda} A_\alpha \right)^c = \bigcup\limits_{\alpha\in\Lambda} A_\alpha^c$ 
- **注意**：与“存在”相对应的是并集运算，与“任意”相对应的是交集运算
## 1-2 上极限、下极限、单调集列、直积
- **上极限**：设 $A_1, A_2, \cdots, A_n, \cdots$ 是任意一列集，由属于上述集列中无限多个集合的那种元素的全体所组成的集合称为这一集列的**上极限**，记为 $\overline\lim\limits_{n\to\infty} A_n$ 或 $\lim\limits_{n\to\infty} \sup A_n$ 
	- $\overline\lim\limits_{n\to\infty} A_n = \{x:\text{存在无穷多个 } A_n, \text{ 使 } x\in A_n\}$ 
	- $\overline\lim\limits_{n\to\infty} A_n = \{x:\text{对任意 } N>0, \text{ 存在 } n>N, \text{ 使 } x\in A_n\}$ 
- **下极限**：设 $A_1, A_2, \cdots, A_n, \cdots$ 是任意一列集，那种除有限个下标外，属于集列中每个集合的元素全体所组成的集合称为这一集列的**下极限**，记为 $\underline\lim\limits_{n\to\infty} A_n$ 或 $\lim\limits_{n\to\infty} \inf A_n$ 
	- $\underline\lim\limits_{n\to\infty} A_n = \{x:\text{当 } n \text{ 充分大以后都有 } x\in A_n\}$ 
	- $\underline\lim\limits_{n\to\infty} A_n \subset \overline\lim\limits_{n\to\infty} A_n$ 
- **定理**：上下极限可以用交集与并集来表示：$\overline\lim\limits_{n\to\infty} A_n = \bigcap\limits_{n=1}^\infty \bigcup\limits_{m=n}^\infty A_m$，$\underline\lim\limits_{n\to\infty} A_n = \bigcup\limits_{n=1}^\infty \bigcap\limits_{m=n}^\infty A_m$ 
- **增加集列**：如果集列 $\{A_n\}$ 满足 $A_n\subset A_{n+1},\ n=1,2,\cdots$，则称 $\{A_n\}$ 为**增加集列** 
- **减少集列**：如果集列 $\{A_n\}$ 满足 $A_n\supset A_{n+1},\ n=1,2,\cdots$，则称 $\{A_n\}$ 为**减少集列** 
- **单调集列**：增加集列和减少集列统称为**单调集列** 
- **性质**：单调集列是收敛的
	- 如果 $\{A_n\}$ 增加，则 $\lim\limits_{n\to\infty} A_n = \bigcup\limits_{n=1}^\infty A_n$ 
	- 如果 $\{A_n\}$ 减少，则 $\lim\limits_{n\to\infty} A_n = \bigcap\limits_{n=1}^\infty A_n$ 
- **直积**：若 $A_i\ (i=1,2,\cdots,n)$ 是集合，则 $A = \{(x_1,x_2,\cdots, x_n): x_i\in A_i,\ i=1,2,\cdots,n \}$ 称为 $A_i\ (i=1,2,\cdots,n)$ 的**直积**，记为 $\prod\limits_{i=1}^n A_i$ 或 $A_1 \times A_2 \times \cdots \times A_n$ 
	- **推广**：类似地，$\prod\limits_{i=1}^\infty A_i = A_1 \times A_2 \times \cdots = \{ (x_1,x_2,\cdots): x_i\in A_i,\ i=1,2,\cdots \}$ 
	- 若 $A_i = A\ (i=1,2,\cdots)$，则 $\prod\limits_{i=1}^n A_i = A^n,\ \prod\limits_{i=1}^\infty A_i = A^\infty$ 
## 1-3 对等与基数
- **有限集**、**无限集**：空集与只含有有限多个元素的集合称为**有限集**，其余的称为**无限集** 
	- 两个非空有限集合元素个数相同 $\iff$ 它们能够和正整数列的同一截段一一对应 $\iff$ 这两个集合彼此一一对应
- **映射**、**像**：设 $A,B$ 为两个非空集合，如果有某一法则 $\varphi$，使每个 $x\in A$ 有唯一确定的 $y\in B$ 和它对应，则称 $\varphi$ 为 **$A$ 到 $B$ 内的映射**，记为 $\varphi:A\rightarrow B$。当映射 $\varphi$ 使 $y$ 和 $x$ 对应时，$y$ 称为 $x$ 在映射 $\varphi$ 下的**像**，记作 $y=\varphi(x)$ 
- **像集**、**原像**：对任意 $E\subset A$，称 $\varphi(E) = \{ y:y=f(x),\ x\in E \}$ 为 $A$ 在 $\varphi$ 下的**像集**。若 $F\subset B$，称 $\varphi^{-1}(F) = \{ x: \varphi(x)\in F \}$ 为 $F$ 关于 $\varphi$ 的**原像** 
- **单射**、**满射**、**双射**：设 $\varphi:A\to B$，称 $\varphi$ 为
	- **单射**：若由任意 $x,y\in A$，$\varphi(x) = \varphi(y)$，可推得 $x=y$ 
	- **满射**：若对任意 $y\in B$，存在 $x\in A$，使得 $\varphi(x) = y$ 
	- **双射**：若 $\varphi$ 既是单射又是满射
- **逆映射**：设 $\varphi$ 是从 $A$ 到 $B$ 上的一个双射，则对任意 $y\in B$，存在唯一 $x\in A$，使 $y=\varphi(x)$，称 $\sigma(y) = x$ 所定义的映射 $\sigma: B\to A$ 为 $\varphi$ 的**逆映射**，记为 $\sigma = \varphi^{-1}:B\to A$ 
- **复合映射**：设 $\varphi:A\to B$，$\psi:B\to C$，则称 $\rho(x) = \psi(\varphi(x))$ 所定义的映射 $\rho: A\to C$ 是 $\varphi$ 和 $\psi$ 的**复合映射**，记为 $\rho = \psi \circ \varphi:A\to C$ 
- **对等**：若 $A,B$ 是非空集合，且存在双射 $\varphi:A\to B$，则称 $A$ 与 $B$ **对等**，记为 $A\sim B$，规定 $\varnothing \sim \varnothing$ 
	- **性质**：一个无限集可以和它的一个真子集对等
- **对等的性质**：对任何集合 $A,B,C$ 均有
	- **自反性**：$A\sim A$ 
	- **对称性**：$A\sim B \Rightarrow B\sim A$ 
	- **传递性**：$A\sim B, B\sim C \Rightarrow A\sim C$ 
- **相等的基数**：若 $A$ 和 $B$ 对等，则称它们有**相同的基数**，记为 $\overline {\overline A} = \overline{\overline B}$ 
- **较小的基数**、**较大的基数**：设 $A,B$ 是两个集合，如果 $A$ 不与 $B$ 对等，但存在 $B$ 的真子集 $B^*$，有 $A\sim B^*$，则称 $A$ 比 $B$ 有**较小的基数**（或 $B$ 比 $A$ 有**较大的基数**），并记为 $\overline{\overline A} < \overline{\overline B}$ 或 $\overline{\overline B} > \overline{\overline A}$ 
- **定理**：任给两个集合 $A,B$，在 $\overline {\overline A} < \overline{\overline B},\ \overline {\overline A} = \overline{\overline B},\ \overline {\overline A} > \overline{\overline B}$ 中必有一个成立且只有一个成立
- **伯恩斯坦(Bernstein)定理**：设 $A,B$ 是两个非空集合，如果 $A$ 对等于 $B$ 的一个子集，$B$ 又对等于 $A$ 的一个子集，那么 $A$ 对等于 $B$ 
	- **利用基数的描述**：设 $\overline {\overline A} \le \overline{\overline B},\ \overline {\overline B} \le \overline{\overline A}$，则 $\overline {\overline A} = \overline{\overline B}$ 
	- **推论**：设 $A\supset B\supset C$ 且 $A\sim C$，则 $A\sim B\sim C$ 
## 1-4 可数集合、不可数集合
- **$n$ 维欧几里得空间**（**欧氏空间**）、**点**、**坐标**：设 $n$ 为一个正整数，将由 $n$ 个实数 $x_1,x_2,\cdots,x_n$，按确定的次序排成的数组 $(x_1,x_2,\cdots,x_n)$ 全体称为 **$n$ 维欧几里得空间**（简称**欧氏空间**），记为 $\mathbb R^n$，每个组 $(x_1,x_2,\cdots,x_n)$ 称为**欧几里得空间的点**。又称 $x_i$ 为点 $(x_1,x_2,\cdots,x_n)$ 的第 $i$ 个坐标
	- 记 $\mathbb R^\infty = \{ (x_1,x_2,\cdots): x_i\in\mathbb R,\ i=1,2,\cdots \}$ 
- **可数集合** (**可列集合**)：凡和全体正整数所成的集合 $\mathbb Z^+$ 对等的集合都称为**可数集合**或**可列集合** 
	- 可数集合是无限集合
	- 一个集合 $A$ 是可数集合 $\iff$ $A$ 可以排成一个无穷序列 $a_1,a_2,a_3,\cdots,a_n,\cdots$ 
- $a,\ \aleph_0$：今后用 $a$ 或 $\aleph_0$ 表示可数集的基数
- **定理**：全体实数所成集合 $\mathbb R$ 是一个不可数集合
- $c, \aleph$：若用 $c$ 表示全体实数所成集合 $\mathbb R$ 的基数，用 $a$ 表示全体正整数所成集合 $\mathbb Z^+$ 的基数，则 $c>a$。称 $c$ 为连续基数（$c$ 有时记为 $\aleph$）
- **定理**：任何无限集合都至少包含一个可数子集
	- **可数集的特征**：它在所有无限集中有最小的基数
- **定理**：可数集合的任何子集或者是有限集或者是可数集
- **定理**：$n\cdot a  = a$ 
- **定理**：$a\cdot a = a$ 
- **定理**：有理数全体成一可数集合
- **定理**：$a^n=a$ 
- **定理**：代数数的全体成一可数集（所谓代数数，乃是整系数多项式的根）
- **定理**：设 $a<b$，则任意区间 $(a,b), [a,b), (a,b], (0,\infty),[0,\infty)$ 均具有连续基数 $c$ 
- **定理**：$a\cdot c = c$ 
- **定理**：$c^a = c$ 
- **定理**：$c^n = c$ 
- **推论**：$2^a = c$ 
- **定理**：设 $M$ 是任意的一个集合，它的所有子集作成新的集合 $\mu$，则 $\overline{\overline \mu} > \overline{\overline M}$ 
	- 一般，集合 $M$ 的所有子集组成的集合记为 $2^M$ 
	- 该定理证明了：对任意集合 $M$，$\overline{\overline M}< \overline{\overline{2^M}}$，从而没有最大的基数
# 2 点集
## 2-1 度量空间、$n$ 维欧氏空间
- **距离**、**度量空间**（**距离空间**）、**点**
	设 $X$ 是一个集合，若对于 $X$ 中任意两个元素 $x,y$，都有唯一确定的实数 $d(x,y)$ 与之对应，而且这一对应关系满足下列条件：
	(1) $d(x,y)\ge 0$ 且 $d(x,y)=0$ 的充要条件为 $x=y$ 
	(2) **三点不等式**：$d(x,y) \le d(x,z)+d(y,z)$，对任意 $z$ 都成立
	则称 $d(x,y)$ 是 $x,y$ 之间的**距离**，称 $(X,d)$ 为**度量空间**或**距离空间**。$X$ 中的元素称为**点** 
- $d(x,y)=d(y,x)$ 
- **子空间**：如果 $(X,d)$ 是度量空间，$Y$ 是 $X$ 的一个非空子集，则 $(Y,d)$ 也是一个度量空间，称为 $(X,d)$ 的**子空间** 
- **$n$ 维欧氏空间**、**欧几里得距离**：对 $\mathbb R^n$ 中任意两点 $x=(\xi_1,\xi_2,\cdots,\xi_n),\ y=(\eta_1,\eta_2,\cdots,\eta_n)$，则可以定义距离 $d(x,y) = \left( \sum\limits_{i=1}^n (\xi_i-\eta_i)^2 \right)^{\frac 12}$，$(\mathbb R^n, d)$ 称为 **$n$ 维欧氏空间**，$d$ 称为**欧几里得距离** 
	- **注意**：在一个集合中引入距离的方法可以不限于一种，该情形下还可定义距离 $\rho'(x,y) = \max\limits_i|\xi_i-\eta_i|$ 或 $\rho''(x,y) = \sum\limits_{i=1}^n |\xi_i-\eta_i|$ 
- **邻域**、**邻域的中心**、**邻域的半径**：$\mathbb R^n$ 中所有和定点 $P_0$ 的距离小于定数 $\delta>0$ 的点的全体，即集合 $\{P:d(P,P_0)<\delta\}$ 称为点 $P_0$ 的 $\delta$ **邻域**，并记为 $U(P_0,\delta)$。$P_0$ 称为**邻域的中心**，$\delta$ 称为**邻域的半径** 
	- 在不需要特别指出是怎样的一个半径时，可直接说是 $P_0$ 的一个邻域，记作 $U(P_0)$ 
- **邻域的基本性质** 
	- $P\in U(P)$ 
	- 对于 $U_1(P)$ 和 $U_2(P)$，存在 $U_3(P) \subset U_1(P)\cap U_2(P)$ 
	- 对于 $Q\in U(P)$，存在 $U(Q)\subset U(P)$ 
	- 对于 $P\not=Q$，存在 $U(P)$ 和 $U(Q)$，使 $U(P)\cap U(Q)=\varnothing$ 
- **收敛于**：设 $\{P_n\}$ 为 $\mathbb R^m$ 中一点列，$P_0\in\mathbb R^m$，如果当 $n\to\infty$ 时有 $d(P_n,P_0)\to 0$，则称点列 $\{P_n\}$ **收敛于** $P_0$，记为 $\lim\limits_{n\to\infty} P_n = P_0$ 或 $P_n\to P_0\ (n\to\infty)$ 
	- 用**邻域**的术语来描述：对于 $P_0$ 的任意邻域 $U(P_0)$，存在某个自然数 $N$，使当 $n>N$ 时，$P_n\in U(P_0)$ 
- **距离**：两个非空的点集 $A,B$ 的**距离**定义为 $d(A,B) = \inf\{ d(x,y): x\in A, y\in B \}$ 
	- 当 $A = \{x\}$ 是单点集时，$d(x,B) = d(\{x, B\}) = \inf\{ d(x,y):y\in B \}$ 
- **直径**：一个非空点集 $E$ 的直径定义为 $\delta(E) = \sup\limits_{\substack{P\in E \\ Q\in E}} d(P,Q)$ 
- **有界点集**：设 $E$ 为 $\mathbb R^n$ 中一点集，如果 $\delta(E)<\infty$，则称 $E$ 为**有界点集**（空集也作为有界点集）
	- **性质**：$E$ 为有界点集 $\iff$ 存在常数 $K>0$，使对于所有的 $x=(x_1,x_2,\cdots,x_n)\in E$ 都有 $|x_i|\le K\ (i=1,2,\cdots,n)$ $\iff$ 存在 $K>0$，对所有 $x\in E$ 有 $d(x,0)\le K$，这里 $0=(0,0,\cdots,0)$，称为 $n$ 维实空间的**原点** 
- **开区间**、**闭区间**、**区间**、**边长**、**体积** 
	- **开区间**：点集 $\{ (x_1,x_2,\cdots,x_n): a_i<x_i<b_i,\ i=1,2,\cdots,n \}$ 称为一个**开区间**($n$ 维)
	- **闭区间**：如果其中不等式一律换成 $a_i\le x_i\le b,\ i=1,2,\cdots, n$ (或 $a_i<x_i\le b_i,\ i=1,2,\cdots,n$)，则称之为一个**闭区间**(或**左开右闭区间**)
	- **区间**：当上述各种区间无区别的必要时，统称为**区间**，记作 $I$ 
	- **边长**：$b_i-a_i\ (i=1,2,\cdots,n)$ 称为 $I$ 的第 $i$ 个**边长** 
	- **体积**：$\prod\limits_{i=1}^n(b_i-a_i)$ 称为 $I$ 的**体积**，记为 $|I|$ 
## 2-2 聚点、内点、界点
- **内点**：如果存在 $P_0$ 的某一邻域 $U(P_0)$ 使 $U(P_0)\subset E$，则称 $P_0$ 为 $E$ 的**内点** 
- **外点**：如果 $P_0$ 是 $E^c$ 的内点（这里余集是对全空间 $\mathbb R^n$ 来作的，即 $E^c = \mathbb R^n \backslash E$，以后仿此），则称 $P_0$ 为 $E$ 的**外点** 
- **界点**（**边界点**）：如果 $P_0$ 既非 $E$ 的内点又非 $E$ 的外点，也就是 $P_0$ 的任一邻域内既有属于 $E$ 的点，也有不属于 $E$ 的点，则称 $P_0$ 为 $E$ 的**界点**或**边界点** 
- **聚点**：设 $E$ 是 $\mathbb R^n$ 中一点集，$P_0$ 为 $\mathbb R^n$ 中一定点，如果 $P_0$ 的任一邻域内都含有无穷多个属于 $E$ 的点，则称 $P_0$ 为 $E$ 的一个**聚点** 
	- 有限集没有聚点
	- $E$ 的内点必为 $E$ 的聚点；$E$ 的聚点不一定是 $E$ 的内点，还可能是 $E$ 的界点
	- $E$ 的内点一定属于 $E$，$E$ 的聚点可以属于 $E$ 也可以不属于 $E$ 
- **聚点的等价描述**：下面三个陈述是等价的
	(1) $P_0$ 是 $E$ 的聚点
	(2) 在 $P_0$ 的任一邻域内，至少含有一个属于 $E$ 而异于 $P_0$ 的点
	(3) 存在 $E$ 中互异的点所成点列 $\{P_n\}$ 使 $P_n\to P_0\ (n\to\infty)$ 
- **孤立点**：设 $E$ 是 $\mathbb R^n$ 中一点集，$P_0$ 为 $\mathbb R^n$ 中一定点，如果 $P_0$ 属于 $E$ 但不是 $E$ 的聚点，则 $P_0$ 称为 $E$ 的**孤立点** 
	- **性质**：$P_0$ 是 $E$ 的孤立点 $\iff$ 存在 $P_0$ 的某邻域 $U(P_0)$ 使 $E\cap U(P_0) = \{ P_0 \}$ 
	- **性质**：$E$ 的界点不是聚点便是孤立点
- **总结**：$\mathbb R^n$ 中的点（对 $E$ 来说）可分为内点、界点、外点；亦可分为聚点、孤立点、外点
	- **注意**：对于一个具体的点集 $E$ 来说，上述任何分两类中的三种点不一定都出现
	- **注意**：界点或聚点可以属于 $E$，也可以不属于 $E$；孤立点、内点必属于 $E$；外点必不属于 $E$ 
- **开核**、**导集**、**边界**、$\{ E\text{ 的孤立点} \}$、**闭包** ：设 $E$ 是 $\mathbb R^n$ 中一个点集，有
	1. **开核**：$E$ 的全体内点组成的集合，称为 $E$ 的**开核**，记为 $\overset\circ E$，即 $\overset\circ E = \{ x: \text{存在 }U(x)\subset E \}$ 
	2. **导集**：$E$ 的全体聚点所成的集合，称为 $E$ 的**导集**，记为 $E'$，即 $E' = \{x: \text{对任意 } U(x),\ U(x)\cap E\backslash\{x\} \not=\varnothing \}$ 
	3. **边界**：$E$ 的全体界点所成的集合，称为 $E$ 的边界，记为 $\partial E$，即 $\partial E = \{ x:\text{对任意 } U(x),\ U(x)\cap E \not=\varnothing,\ U(x)\cap E^c \not=\varnothing \}$ 
	4. $\{ E\text{ 的孤立点} \} = \{ x:\text{ 存在 } U(x),\ U(x)\cap E = \{x\} \}$ 
	5. **闭包**：$E\cup E'$ 称为 $E$ 的闭包，记为 $\overline E$，即 $\overline E = \{ x:\text{对任意 }U(x),\ U(x)\cap E\not=\varnothing \}$ 
	- **性质**：$\overline E = E \cup\partial E = \overset\circ E \cup \partial E = E' \cup \{ E\text{ 的孤立点} \}$ 
	- **闭包与开核的对偶关系**：$(\overset\circ E)^c = \overline{E^c}$，$(\overline E)^c = \overset\circ{E^c}$ 
- **性质**：设 $A\subset B$，则 $A'\subset B',\ \overset\circ A \subset \overset\circ B,\ \overline A\subset \overline B$ 
- **性质**：$(A\cup B)' = A'\cup B'$ 
- **Bolzano-Weierstrass 定理**：设 $E$ 是一个有界的无限集合，则 $E$ 至少有一个聚点
	- 该定理告诉我们什么时候 $E'\not=\varnothing$ 
- **性质**：设 $E\not=\varnothing,\ E\not=\mathbb R^n$，则 $E$ 至少有一界点，即 $\partial E\not=\varnothing$ 
## 2-3 开集、闭集、完备集
- **开集**：设 $E\subset \mathbb R^n$，如果 $E$ 的每一点都是 $E$ 的内点，则称 $E$ 为**开集** 
	- $E$ 为开集 $\iff$ $E\subset \overset\circ E$ $\iff$ $E=\overset\circ E$ 
	- 开集常用字母 $G$ 表示
- **闭集**：设 $E\subset \mathbb R^n$，如果 $E$ 的每一聚点都属于 $E$，则称 $E$ 为闭集
	- $E$ 为闭集 $\iff$ $E'\subset E$ $\iff$ $\partial E\subset E$ 
	- 闭集常用字母 $F$ 表示
- **性质**：对任何 $E\subset \mathbb R^n$，$\overset \circ E$ 是开集，$E'$ 和 $\overline E$ 都是闭集
- **开集与闭集的对偶性**：设 $E$ 是开集，则 $E^c$ 是闭集；设 $E$ 是闭集，则 $E^c$ 是开集
- **性质**：任意多个开集之并仍是开集，有限多个开集之交仍是开集
	- **注意**：任意多个开集的交不一定是开集
- **性质**：任意多个闭集之交仍为闭集，有限多个闭集之并仍为闭集
	- **注意**：任意多个闭集的和不一定是闭集
- **定理**：设 $F_1,F_2$ 是 $\mathbb R$ 中两个互不相交的闭集，则存在两个互不相交的开集 $G_1,G_2$，使 $G_1\supset F_1, G_2\supset F_2$ 
	- **注意**：两个闭集 $F_1,F_2$ 不相交不能推出它们之间的距离 $d(F_1,F_2) = \inf\limits_{\substack{P\in F_1 \\ Q\in F_2}} d(P,Q)>0$ 
- **海涅-博雷尔(Heine-Borel)有限覆盖定理**：设 $F$ 是一个有界闭集，$\mathscr M$ 是一族开集 $\{U_i\}_{i\in\Lambda}$，它覆盖了 $F$（即 $F\subset \bigcup\limits_{i\in\Lambda} U_i$），则 $\mathscr M$ 中一定存在有限多个开集 $U_1,U_2,\cdots,U_m$，它们同样覆盖了 $F$（即 $F\subset \bigcup\limits_{i=1}^m U_i$）
- **紧集**：设 $M$ 是度量空间 $X$ 中一集合，$\mathscr M$ 是 $X$ 中任一族覆盖了 $M$ 的开集，如果必可从 $\mathscr M$ 中选出有限个开集仍然覆盖 $M$，则称 $M$ 为 $X$ 中的**紧集** 
- **定理**：设 $M$ 是 $\mathbb R^n$ 中的紧集，则 $M$ 是 $\mathbb R^n$ 中的有界闭集
	- 在 $\mathbb R^n$ 中紧集与有界闭集是一致的
	- 在一般度量空间中，紧集一定是有界闭集，但反之不然
- **自密集**：设 $E\subset \mathbb R^n$，如果 $E\subset E'$，就称 $E$ 是**自密集** 
	- 当集合中每点都是这个集的聚点时，这个集是自密集
	- 没有孤立点的集就是自密集
- **完备集**（**完全集**）：设 $E\subset \mathbb R^n$，如果 $E=E'$，则称 $E$ 为**完备集**或**完全集** 
	- 完备集就是自密闭集，也就是没有孤立点的闭集
## 2-4 直线上的开集、闭集、完备集的构造
- **构成区间**：设 $G$ 是直线上的开集，如果开区间 $(\alpha, \beta)\subset G$，而且端点 $\alpha,\beta$ 不属于 $G$，那么称 $(\alpha,\beta)$ 为 $G$ 的**构成区间** 
	- **例子**：开集 $(0,1)\cup (2,3)$ 的构成区间是 $(0,1)$ 以及 $(2,3)$ 
- **开集构造定理**：直线上任一个非空开集可以表示成有限个或可数个互不相交的构成区间的和集
- **余区间**（**邻接区间**）：设 $A$ 是直线上的闭集，称 $A$ 的余集 $A^c$ 的构成区间为 $A$ 的**余区间**或**邻接区间** 
- **闭集构造定理**：直线上的闭集 $F$ 或者是全直线，或者是从直线上挖掉有限个或可数个互不相交的开区间（即 $F$ 的余区间）所得到的集
	- 闭集的孤立点一定是它的两个余区间的公共端点
- **完备集的构造**：完备集是没有孤立点的闭集，所以，完备集就是没有相邻接的余区间的闭集。
- *补充*：当 $n>1$ 时，$\mathbb R^n$ 中的开集一般不能表示成至多可数个互不相交的开区间（$n$ 维）的和，但总可表示成可数个互不相交的半开半闭区间的和，不过这种表示方法没有唯一性（在 $\mathbb R$ 中一个开集只能用一种方式表示成构成区间之和）
## 2-5 康托尔三分集
- **稠密**：设 $E\subset \mathbb R^n$，$F\subset \mathbb R^n$，若对任意 $x\in F$ 和任意邻域 $U(x)$，$U(x)\cap E\not=\varnothing$，则称 $E$ 在 $F$ 中**稠密** 
- **疏朗集***（**无处稠密集**）：设 $E\subset\mathbb R^n$，若对任意 $x\in \mathbb R^n$ 和任意邻域 $U(x)$，存在 $U(y)\subset U(x)\cap E^c$，则称 $E$ 是**疏朗集**或**无处稠密集** 
- **康托三分集**的*构造过程* 
	将 $[0,1]$ 三等分，去掉中间的开区间 $\left( \dfrac 13, \dfrac 23 \right)$，剩下两个闭区间 $\left[ 0, \dfrac 13 \right],\ \left[ \dfrac 23, 1 \right]$，记这两个闭区间之并为 $E_1$ 
	又把这两个闭区间各三等分，去掉中间的两个开区间，即 $\left( \dfrac 19, \dfrac 29 \right),\ \left( \dfrac 79, \dfrac 89 \right)$，剩下 $2^2$ 个闭区间，记这些闭区间之并为 $E_2$ 
	一般地，当进行到第 $n$ 次时，一共去掉 $2^{n-1}$ 个开区间，剩下 $2^n$ 个长度为 $3^{-n}$ 的互相隔离的闭区间，记这些闭区间之并为 $E_n$ 
	而在第 $n+1$ 次时，再将这 $2^n$ 个闭区间各三等分，并去掉中间的开区间
	如此继续下去，就从 $[0,1]$ 去掉了可数多个互不相交且没有公共端点的开区间，剩下的必是一个闭集（它至少包含各邻接区间的端点及其聚点），称它为康托尔三分集，记为 $P$ 
- **康托三分集 $P$ 的性质** 
	- $P$ 是完备集
	- $P$ 没有内点
	- $P$ 是疏朗集	
	- $[0,1]\backslash P$ 是可数个互不相交的开区间，其长度之和为 $1$ 
	- $P$ 的基数为 $c$ 
- **一句话描述康托尔三分集**：它是一个测度为零且基数为 $c$ 的疏朗完备集
# 3 测度论
## 3-1 外侧度
- **勒贝格外侧度**（**$L$ 外侧度**、**外侧度**）：设 $E$ 为 $\mathbb R^n$ 中任一点集，对于每一列覆盖 $E$ 的开区间 $\bigcup\limits_{i=1}^\infty I_i \subset E$，作出它的体积总和 $\mu = \sum\limits_{i=1}^\infty |I_i|$（$\mu$ 可以等于 $\infty$，不同的区间列一般有不同的 $\mu$），所有这一切的 $\mu$ 组成一个下方有界的数集，它的下确界（完全由 $E$ 确定）称为 $E$ 的**勒贝格外侧度**，简称 **$L$ 外侧度**或**外侧度**，记为 $m^*E$ 
	- **符号表示**：$m^* E = \inf\limits_{E\subset \bigcup\limits_{i=1}^\infty I_i} \sum\limits_{i=1}^\infty |I_i|$ 
	- **补充**：$\bigcup\limits_{i=1}^\infty I_i$ 也可以是有限序列，因为某些 $I_i$ 也可以是空集
	- **补充**：“一切的 $\mu$ 组成一个下方有界的数集”中的数可以是 $+\infty$，今后我们把 $+\infty$ 和 $-\infty$ 看作广义实数，$+\infty$ 比任何有限实数都大，$-\infty$ 比任何有限实数都小
- **外侧度的三条基本性质** 
	- $m^* E \ge 0$，当 $E$ 为空集时，$m^*E=0$ 
	- **单调性**：设 $A\subset B$，则 $m^* A \le m^* B$ 
	- **次可数可加性**：$m^*\left( \bigcup\limits_{i=1}^\infty A_i \right) \le \sum\limits_{i=1}^\infty m^* A_i$ 
- **性质**：设 $E$ 为 $[0,1]$ 中的全体有理数，则 $m^* E = 0$ 
- **性质**：对于区间 $I$，有 $m^* I = |I|$ 
- **注意**：任何集合都有外测度，但外侧度只具有次可数可加性，不具有可数可加性
## 3-2 可测集
- **引理**：设 $E\subset \mathbb R^n$，则 $m^* I = m^*(I\cap E) + m^*(I\cap E^c)$ 对 $\mathbb R^n$ 中任何开区间 $I$ 都成立 $\iff$ 对 $\mathbb R^n$ 中的任何点集 $T$ 都有 $m^* T = m^* (T\cap E) + m^* (T\cap E^c)$ 
- **$L$ 可测的**、**$L$ 测度**：设 $E$ 为 $\mathbb R^n$ 中的点集，如果对任一点集 $T$ 都有 $m^*T = m^*(T\cap E) + m^*(T\cap E^c)$，则称 $E$ 是 **$L$ 可测的**，这时 $E$ 的 $L$ 外侧度 $m^*E$ 即称为 $E$ 的 **$L$ 测度**，记为 $mE$ 
	- $L$ 可测集全体记为 $\mathscr M$ 
- **可测的等价定义**：集合 $E$ 可测 $\iff$ 对于任意 $A\subset E,\ B\subset E^c$，总有 $m^*(A\cup B) = m^* A + m^* B$ 
- **可测的对偶性**：$S$ 可测 $\iff$ $S^c$ 可测
- **可测集的有限并可测**：设 $S_i\ (i=1,2,\cdots,n)$ 都可测，则 $\bigcup\limits_{i=1}^n S_i$ 也可测，并且当 $S_i \cap S_j = \varnothing\ (i\not=j)$ 时，对于任意集合 $T$ 总有 $m^* \left( T\cap \left( \bigcup\limits_{i=1}^n S_i \right) \right) = \sum\limits_{i=1}^n m^* (T\cap S_i)$ 
- **可测集的有限交可测**：设 $S_i\ (i=1,2,\cdots,n)$ 都可测，则 $\bigcap\limits_{i=1}^n S_i$ 也可测
- **可测集的差可测**：设 $S_1, S_2$ 都可测，则 $S_1 \backslash S_2$ 也可测
- **可测集的可数可加性**：设 $\{S_i\}$ 是一列互不相交的可测集，则 $\bigcup\limits_{i=1}^\infty S_i$ 也是可测集，且 $m\left( \bigcup\limits_{i=1}^\infty S_i \right) = \sum\limits_{i=1}^\infty mS_i$ 
- **可测集的可列并可测**：设 $\{S_i\}$ 是一列可测集合，则 $\bigcup\limits_{i=1}^\infty S_i$ 也是可测集合
- **可测集的可列交可测**：设 $\{S_i\}$ 是一列可测集合，则 $\bigcap\limits_{i=1}^\infty S_i$ 也是可测集合
- **定理**：设 $\{S_i\}$ 是一列递增的可测集合 $S_1 \subset S_2 \subset \cdots \subset S_n \subset \cdots$，令 $S = \bigcup\limits_{i=1}^\infty S_i = \lim\limits_{n\to\infty} S_n$，则 $mS = \lim\limits_{n\to\infty} mS_n$ 
- **定理**：设 $\{S_i\}$ 是一列递降的可测集合 $S_1 \supset S_2 \supset \cdots \supset S_n \supset \cdots$，令 $S = \bigcap\limits_{i=1}^\infty S_i = \lim\limits_{n\to\infty} S_n$，则当 $mS_1 < \infty$ 时，$mS = \lim\limits_{n\to\infty} mS_n$ 
	- **注意**：$mS_1<\infty$ 的条件是很重要的，若无此条件可举出反例
## 3-3 可测集类
- **零测度集的定义与性质** 
	1. 凡外侧度为零之集皆可测，称为**零测度集** 
	2. 零测度集之任何子集仍为零测度集
	3. 有限个或可数个零测度集之和仍为零测度集
- **定理**：区间 $I$（不论开、闭或半开半闭区间）都是可测集合，且 $mI = |I|$ 
- **定理**：凡开集、闭集皆可测
- **$\sigma$ 代数** 
	设 $\Omega$ 是由 $\mathbb R^n$ 的一些子集类组成的集合类，如果 $\Omega$ 满足条件：
	(1) $\varnothing \in \Omega$ 
	(2) 若 $E\in \Omega$，则 $E^c \in \Omega$ 
	(3) 若 $E_n \in \Omega,\ n=1,2,\cdots$，则 $\bigcup\limits_{n=1}^\infty E_n \in \Omega$ 
	则称 $\Omega$ 是 $\mathbb R^n$ 的一个 **$\sigma$ 代数** 
- $L_n$、**性质**：$\mathbb R^n$ 中可测集全体所成的集合类 $L_n$ 是一 $\sigma$ 代数
	- 为方便起见，当不至于混淆时，我们用 $L$ 代替 $L_n$ 
- **性质**：如果 $\{\Omega_\alpha\}$ 是 $\mathbb R^n$ 上的一族 $\sigma$ 代数，则它们的交集 $\bigcap\limits_\alpha \Omega_\alpha$ 也是 $\sigma$ 代数
- **正测度**（**测度**） 
	设 $\Omega$ 是 $\mathbb R^n$ 上的一个 $\sigma$ 代数，如果定义在 $\Omega$ 上的非负值集合函数 $\mu$ 满足条件：
	(1) $\mu(\varnothing) = 0$ 
	(2) 若 $E_n\in \Omega,\ (n=1,2,\cdots)$，且满足对任意 $n\not= m$ 有 $E_n\cap E_m = \varnothing$，则 $\mu(\bigcup\limits_{n=1}^\infty E_n) = \sum\limits_{n=1}^\infty \mu(E_n)$ 
	则称 $\mu$ 是 $\Omega$ 上的**正测度**，或简称**测度** 
- *回顾*：勒贝格测度 $m$ 是定义在 $\sigma$ 代数 $L$ 上的测度
- $\Sigma$ 产生的 **$\sigma$ 代数**：设 $\Sigma$ 是 $\mathbb R^n$ 的一个子集族，则称所有包含 $\Sigma$ 的 $\sigma$ 代数的交集为 $\Sigma$ 产生的 **$\sigma$ 代数** 
	- 由于 $\mathbb R^n$ 全体子集组成的子集类是包含 $\Sigma$ 的 $\sigma$ 代数，因此包含 $\Sigma$ 的 $\sigma$ 代数不是空集，并且是包含 $\Sigma$ 的最小的 $\sigma$ 代数
- **博雷尔代数**：由 $\mathbb R^n$ 中全体开集组成的子集类生成的 $\sigma$ 代数，记为 $\mathscr B_n$，称为**博雷尔代数** 
	- 为方便起见，当不至于混淆时，我们用 $\mathscr B$ 代替 $\mathscr B_n$ 
- **博雷尔集**：博雷尔代数中的集合称为**博雷尔集** 
	- 博雷尔集全体已构成一个 $\sigma$ 代数，但并非每个 $L$ 可测集都是博雷尔集
- **定理**：凡博雷尔集都是勒贝格可测集
- **测度空间**：若 $\Omega$ 是 $\mathbb R^n$ 上的一个 $\sigma$ 代数，$\mu$ 是 $\Omega$ 上的测度，则称 $(\mathbb R^n, \Omega, \mu)$ 为**测度空间** 
	- $(\mathbb R^n, L, m)$ 和 $(\mathbb R^n, \mathscr B, m)$ 都是测度空间
- **$G_\delta$ 型集**：设集合 $G$ 可表示为一列开集 $\{G_i\}$ 之交集 $G=\bigcap\limits_{i=1}^\infty G_i$，则称 $G$ 为 **$G_\delta$ 型集** 
- **$F_\sigma$ 型集**：设集合 $F$ 可表示为一列闭集 $\{F_i\}$ 之交集 $F=\bigcup\limits_{i=1}^\infty F_i$，则称 $F$ 为 **$F_\sigma$ 型集** 
	- $G_\delta$ 型集、$F_\sigma$ 型集都是博雷尔集
- **定理**：设 $E$ 是任一可测集，则一定存在 $G_\delta$ 型集 $G$，使 $G\supset E$ 且 $m(G\backslash E) = 0$ 
- **定理**：设 $E$ 是任一可测集，则一定存在 $F_\sigma$ 型集 $F$，使 $F\subset E$ 且 $m(E\backslash F) = 0$ 
	- 只要有了全部 $G_\delta$ 型集（或 $F_\sigma$ 型集）（它们只是博雷尔集合的一部分）和全部 $L$ 零测度集，那么一切 $L$ 可测集都可以获得。它们一律可以表示为 $E = G\backslash M$ 或 $E = F\cup M$ 的形式，其中 $G$ 是 $G_\delta$ 型集，$F$ 是 $F_\sigma$ 型集，而 $M$ 是零测度集
- **勒贝格测度的正规性**：
	若 $E$ 是一可测集，则
	(1) **外正规性**：$mE = \inf \{ mG: G\text{ 是开集},\ E\subset G \}$ 
	(2) **内正规性**：$mE = \sup\{ mK: K\text{ 是紧集},\ K\subset E \}$ 
- **性质**：若 $E$ 是有界可测集，则 $\inf\{ mG:G\text{ 是开集},\ E\subset G \} = \sup\{ mK: K\text{ 是紧集},\ K\subset E \}$；反之，若有界集 $E$ 满足 $\inf\{ mG:G\text{ 是开集},\ E\subset G \} = \sup\{ mK: K\text{ 是紧集},\ K\subset E \}$，则 $E$ 是可测集
# 4 可测函数
## 4-1 可测函数及其性质
- $E[f>a]$：一个定义在 $E\subset\mathbb R^n$ 上的实函数 $f(x)$ 确定了 $E$ 的一组子集 $\{x:x\in E, f(x)>a\}$（简记作 $E[f>a]$），这里 $a$ 取遍一切有限实数；反之，易知 $f(x)$ 本身也由 $E$ 的这组子集完全确定，因此从这组子集的性质可以反映出 $f(x)$ 的性质
- **可测函数**：设 $f(x)$ 是定义在可测集 $E\subset \mathbb R^n$ 的实函数，如果对于任何有限实数 $a$，$E[f>a]$ 都是可测集，则称 $f(x)$ 为定义在 $E$ 上的**可测函数** 
- **定理 1**：设 $f(x)$ 是定义在可测集 $E$ 上的实函数，下列任一条件都是 $f(x)$ 在 $E$ 上可测的充要条件：
	(1) 对任何有限实数 $a$，$E[f\ge a]$ 都可测
	(2) 对任何有限实数 $a$，$E[f< a]$ 都可测
	(3) 对任何有限实数 $a$，$E[f\le a]$ 都可测
	(4) 对任何有限实数 $a$，$b(a<b),\ E[a\le f<b]$ 都可测（但充分性要假定 $f(x)$ 是有限函数）
- **推论**：设 $f(x)$ 在 $E$ 上可测，则 $E[f=a]$ 总可测，不论 $a$ 是有限实数或 $\pm\infty$ 
- **连续**：定义在 $E\subset \mathbb R^n$ 上的实函数 $f(x)$ 称为在 $x_0\in E$ **连续**，如果 $y_0=f(x_0)$ 有限，而且对于 $y_0$ 的任一邻域 $V$，存在 $x_0$ 的某邻域 $U$，使得 $f(U\cap E) \subset V$，即只要 $x\in E$ 且 $x\in U$ 时，便有 $f(x)\in V$。如果 $f(x)$ 在 $E$ 中每一点都连续，则称 **$f(x)$ 在 $E$ 上连续** 
	- 一个函数在其定义域中的每一个孤立点都是连续的
- **定理 2**：可测集 $E\subset\mathbb R^n$ 上的连续函数是可测函数
- **定理 3.1**：设 $f(x)$ 是可测集 $E$ 上的可测函数，而 $E_1\subset E$ 为 $E$ 的可测子集，则 $f(x)$ 看作定义在 $E_1$ 上的函数时，它是 $E_1$ 上的可测函数
- **定理 3.2**：设 $f(x)$ 定义在有限个可测集 $E_i\ (i=1,2,\cdots,s)$ 的并集 $E=\bigcup\limits_{i=1}^s E_i$ 上，且 $f(x)$ 在每个 $E_i$ 上都可测，则 $f(x)$ 在 $E$ 上也可测
- **简单函数**：设 $f(x)$ 的定义域 $E$ 可分为有限个互不相交的可测集 $E_1, E_2, \cdots, E_s$，$E = \bigcup\limits_{i=1}^s E_i$，使 $f(x)$ 在每个 $E_i$ 上都等于某常数 $c_i$，则称 $f(x)$ 为**简单函数** 
	- 在区间 $[0,1]$ 上的狄利克雷函数便是简单函数
	- 定义在可测集上的常值函数是可测的
	- 任何简单函数都是可测的
- **引理**：设 $f(x)$ 与 $g(x)$ 为 $E$ 上的可测函数，则 $E[f>g]$ 与 $E[f\ge g]$ 都是可测集
- **定理 4**：设 $f(x), g(x)$ 在 $E$ 上可测，则函数 $f(x)+g(x),\ |f(x)|,\ \dfrac 1{f(x)},\ f(x)\cdot g(x)$（假定它们在 $E$ 上有意义）皆在 $E$ 上可测
- **定理 5**：设 $\{ f_n(x) \}$ 是 $E$ 上一列（或有限个）可测函数，则 $\mu(x) = \inf\limits_n f_n(x)$ 与 $\lambda(x) = \sup\limits_n f_n(x)$ 都在 $E$ 上可测
- **定理 6**：设 $\{ f_n(x) \}$ 是 $E$ 上一列可测函数，则 $F(x) = \underline\lim\limits_{n\to\infty} f_n(x),\ G(x) = \overline\lim\limits_{n\to\infty} f_n(x)$ 也在 $E$ 上可测，特别当 $F(x) = \lim\limits_n f_n(x)$ 存在时，它也在 $E$ 上可测
	- 一列简单函数 $\varphi_n(x)$ 的极限函数 $f(x) = \lim\limits_{n\to\infty} \varphi_n(x)$ 是 $E$ 上的可测函数
- **正部**、**负部**：设 $f(x)$ 是定义在 $E$ 上的实函数，令 $f^+(x) = \max\{ f(x), 0 \} = \begin{cases} f(x) & f(x)\ge 0 \\ 0 & f(x)<0 \end{cases}$，$f^-(x) = -\min\{ f(x), 0 \} = \begin{cases} -f(x) & f(x)\le 0 \\ 0 & f(x)>0 \end{cases}$，则 $f^+(x)$ 和 $f^-(x)$ 都是 $E$ 上非负函数，分别称为 $f(x)$ 的**正部**和**负部** 
	- $f(x) = f^+(x) - f^-(x)$，$|f(x)| = f^+(x) + f^-(x)$ 
	- 若 $g(x), h(x)$ 是 $E$ 上两个非负实函数，则它们分别是某个实函数的正部及负部 $\iff$ $E[g>0] \cap E[h>0] = \varnothing$ 
	- 若 $f(x)$ 是 $E$ 上可测函数，则 $f^+(x), f^-(x)$ 也是 $E$ 上的可测函数
- **定理 7**（**可测函数与简单函数的关系**）
	(1) 若 $f(x)$ 在 $E$ 上非负可测，则存在可测简单函数列 $\{ \varphi_k(x) \}$，使得对任意 $x\in E$，$\varphi_k(x)\le \varphi_{k+1}(x)\ (k=1,2,\cdots)$ 且 $\lim\limits_{k\to\infty} \varphi_k(x) = f(x)$ 
	(2) 若 $f(x)$ 在 $E$ 上可测，则存在可测简单函数列 $\{ \varphi_k(x) \}$，使得对任意 $x\in E$，$\lim\limits_{k\to\infty} \varphi_k(x) = f(x)$。若 $f(x)$ 还在 $E$ 上有界，则上述收敛可以是一致的
- **几乎处处成立** (**$\text{a.e.}$ 于 $E$**)：设 $\pi$ 是一个与集合 $E$ 的点 $x$ 有关的命题，如果存在 $E$ 的子集 $M$，满足 $mM=0$，使得 $\pi$ 在 $E\backslash M$ 上恒成立，即 $E\backslash E[\pi \text{ 成立}]$ 是零测度集，则我们称 $\pi$ 在 $E$ 上**几乎处处成立**，或者说 $\pi\ \text{a.e.}$ 于 $E$ 
	- **性质**：根据零测度性质可知，$\pi_1\ \text{a.e.}$ 于 $E$ 且 $\pi_2\ \text{a.e.}$ 于 $E$ $\Rightarrow$ $\pi_1\text{ 且 }\pi_2\ \text{a.e.}$ 于 $E$ 
	- **例子**：$|\tan x|<\infty\ \text{a.e. 于 } \mathbb R$，$[0,1] \text{ 上的狄利克雷函数 } D(x)=0\text{ a.e. 于 } [0,1]$ 
	- **例子**：$f(x)=g(x)\text{ a.e. 于 } E$ 且 $g(x)=h(x)\text{ a.e. 于 } E$ $\Rightarrow$ $f(x)=h(x)\text{ a.e. 于 } E$ 
- **基本上成立**：设 $\pi$ 是一个与集合 $E$ 的点 $x$ 有关的命题，如果对任意 $\delta>0$，存在可测子集 $E_\delta \subset E$，使得 $\pi$ 在 $E_\delta$ 上恒成立，且 $m(E\backslash E_\delta) < \delta$，则我们称 $\pi$ 在 $E$ 上**基本上成立** 
- **叶戈罗夫定理**：设 $mE<\infty$，$\{ f_n \}$ 是 $E$ 上一列 $\text{a.e.}$ 收敛于一个 $\text{a.e.}$ 有限的函数 $f$ 的可测函数，则对任意 $\delta>0$，存在子集 $E_\delta \subset E$，使 $\{ f_n \}$ 在 $E_\delta$ 上一致收敛，且 $m(E\backslash E_\delta)<\delta$ 
	- **该定理说明**：凡是满足定理假设的 $\text{a.e.}$ 收敛的可测函数列，即使不一致收敛，也是“基本上”（指去掉一个测度可任意小的某点集外）一致收敛的。因此在许多场合它提供了处理极限交换问题的有力工具。
	- **注意**：当 $mE=\infty$ 时，定理不成立。而逆定理当 $mE<\infty$ 和 $mE=\infty$ 时都成立
- **卢津定理**：设 $f(x)$ 是 $E$ 上 $\text{a.e.}$ 有限的可测函数，则对任意 $\delta>0$，存在闭子集 $F_\delta \subset E$，使 $f(x)$ 在 $F_\delta$ 上是连续函数，且 $m(E\backslash F_\delta)<\delta$ 
	- 该定理表明：在 $E$ 上 $\text{a.e.}$ 有限的可测函数是“基本上连续”的函数
	- **卢津定理的意义**：使我们对可测函数的结构有了进一步的了解，它揭示了可测函数与连续函数的关系
	- **应用**：通过它常常可以把有关的可测函数问题归结为连续函数的问题，从而得以简化
- 另一个形式的**卢津定理**：设 $f(x)$ 是 $E\subset \mathbb R$ 上 $\text{a.e.}$ 有限的可测函数，则对任意 $\delta>0$，存在闭集 $F\subset E$ 及整个 $\mathbb R$ 上的连续函数 $g(x)$（$F$ 及 $g(x)$ 依赖于 $\delta$），使得在 $F$ 上 $g(x)=f(x)$ 且 $m(E\backslash F) < \delta$，此外还可要求 $\sup\limits_{\mathbb R} g(x) = \sup\limits_F f(x)$ 及 $\inf\limits_{\mathbb R} g(x) = \inf\limits_F f(x)$ 
	- 注意：这个定理也可推广到 $n$ 维空间
## 4-2 依测度收敛
- **依测度收敛** (**度量收敛**)：设 $\{f_n\}$ 是 $E \subset \mathbb{R}^q$ 上的一列 $\text{a.e.}$ 有限的可测函数，若有 $E$ 上 $\text{a.e.}$ 有限的可测函数 $f(x)$ 满足对任意 $\sigma > 0$，有 $\lim\limits_{n \to \infty} m\left[ E\left[ |f_n - f| \geqslant \sigma \right] \right] = 0$，则称函数列 $\{f_n\}$ **依测度收敛**于 $f$，或**度量收敛**于 $f$，记为 $f_n(x) \Rightarrow f(x)$。  
	- 改用 $\varepsilon-N$ 说法：对任意 $\varepsilon > 0$ 及 $\sigma > 0$，存在正数 $N(\varepsilon, \sigma)$，使当 $n \geqslant N(\varepsilon, \sigma)$ 时，$m\left[ E\left[ |f_n - f| \geqslant \sigma \right] \right] < \varepsilon$ 
	- 依测度收敛用文字叙述：如果事先给定一个 (误差) $\sigma > 0$，不论这个 $\sigma$ 有多么小，使得 $|f_n(x) - f(x)|$ 大于 $\sigma$ 的点 $x$ 虽然可能很多，但这些点所成之集合的测度随着 $n$ 无限增大而趋于零。  
	- 依测度收敛和我们熟知的处处收敛或几乎处处收敛的概念是有很大区别的
- **定理 1** (**里斯 (Riesz) 定理**)：设在 $E$ 上 $\{f_n\}$ 依测度收敛于 $f$，则存在子列 $\{f_{n_i}\}$ 在 $E$ 上 $\text{a.e.}$ 收敛于 $f$ 
- **定理 2** (**勒贝格**)：设  
	(1) $mE < \infty$ 
	(2) $\{f_n\}$ 是 $E$ 上 $\text{a.e.}$ 有限的可测函数列 
	(3) $\{f_n\}$ 在 $E$ 上 $\text{a.e.}$ 收敛于 $\text{a.e.}$ 有限的函数 $f$，
	则 $f_n(x) \Rightarrow f(x)$ 
	- 上面定理说明 $\text{a.e.}$ 收敛的函数列是在何时成为依测度收敛的
	- *注意*：$mE < \infty$ 这个条件是不能去掉的。在 $mE < \infty$ 条件下，依测度收敛弱于 $\text{a.e.}$ 收敛
- **定理 3**：设 $f_n(x) \Rightarrow f(x)$，$f_n(x) \Rightarrow g(x)$，则 $f(x) = g(x)$ 在 $E$ 上几乎处处成立
# 5 积分论
## 5-1 非负简单函数的勒贝格积分
- **黎曼积分** (**$R$ 积分**)：黎曼将柯西只对连续函数定义的积分概念扩张成现在我们所知的**黎曼积分** (即 $R$ 积分)，从而扩大了积分的应用范围。
- **勒贝格积分** (**$L$ 积分**、**积分**)：设 $E \subset \mathbb{R}^n$ 为可测集，$\varphi(x)$ 为 $E$ 上的一个非负简单函数，即 $E$ 表示为有限个互不相交的可测集 $E_1, E_2, \cdots, E_k$ 之并，而在每个 $E_i$ 上 $\varphi(x)$ 取非负常数值 $c_i$，也就是说 $\varphi(x) = \sum\limits_{i=1}^{k} c_i \chi_{E_i}(x)$，这里 $\chi_{E_i}(x)$ 是 $E_i$ 的特征函数 $\chi_{E_i}(x) = \begin{cases} 1 & x\in E_i \\ 0 & x\not\in E_i \end{cases}$。则 $\varphi(x)$ 在 $E$ 上的**勒贝格积分** (简称 **$L$ 积分**，不产生误解时就称为**积分**) 定义为 $\displaystyle \int_E \varphi(x) \, dx = \sum_{i=1}^{k} c_i m E_i$ 
- **勒贝格积分**：设 $A \subset E$ 为可测子集，$\varphi(x)$ 在 $A$ 上的勒贝格积分定义为 $\varphi$ 在 $A$ 上的限制 $\varphi|_A$ 在 $A$ 上的**勒贝格积分**，于是 $\displaystyle \int_A \varphi(x) \, dx = \sum_{i=1}^{k} c_i m(A \cap E_i)$
- **定理 1** 
	设 $E \subset \mathbf{R}^n$ 为可测集，$\varphi(x)$ 为 $E$ 上的一个非负简单函数。我们有：
	(1) 对于任意的非负实数 $c$，$\displaystyle \int_E c\varphi(x) \, \mathrm dx = c \int_E \varphi(x) \, \mathrm dx$ 
	(2) 设 $A$ 和 $B$ 是 $E$ 的两个不相交的可测子集，则 $\displaystyle \int_{A \cup B} \varphi(x) \mathrm dx = \int_A \varphi(x) \mathrm dx + \int_B \varphi(x) \mathrm dx$ 
	(3) 设 $\{A_n\}_{n=1}^{\infty}$ 是 $E$ 的一列可测子集，满足 $A_1 \subset A_2 \subset \cdots \subset A_n \subset A_{n+1} \subset \cdots$ 和 $\bigcup\limits_{n=1}^{\infty} A_n = E$，则 $\displaystyle \lim_{n \to \infty} \int_{A_n} \varphi(x) \mathrm dx = \int_E \varphi(x) \mathrm dx$ 
- **定理 2** 
	设 $E \subset \mathbf{R}^n$ 为可测集，$\varphi(x)$ 和 $\psi(x)$ 都是 $E$ 上的非负简单函数，则  
	(1) $\displaystyle \int_E \varphi(x) \, \mathrm{d}x + \int_E \psi(x) \, \mathrm{d}x = \int_E (\varphi(x) + \psi(x)) \, \mathrm{d}x$ 
	(2) 对于任意的非负实数 $\alpha$ 和 $\beta$，有 $\displaystyle \alpha \int_E \varphi(x) \, \mathrm{d}x + \beta \int_E \psi(x) \, \mathrm{d}x = \int_E (\alpha \varphi(x) + \beta \psi(x)) \, \mathrm{d}x$ 
## 5-2 非负可测函数的勒贝格积分
- **勒贝格积分**：设 $E \subset \mathbf{R}^n$ 为可测集，$f(x)$ 是 $E$ 上的一个非负可测函数，$f(x)$ 在 $E$ 上的**勒贝格积分**定义为 $\displaystyle \int_E f(x) \, \mathrm{d}x = \sup \left\{ \int_E \varphi(x) \, \mathrm{d}x: \varphi(x) \text{ 是 } E \text{ 上的简单函数，且 } x \in E \text{ 时，} 0 \leqslant \varphi(x) \leqslant f(x) \right\}$ 
	- **勒贝格可积**：显然 $\displaystyle 0 \leqslant \int_E f(x) \, \mathrm{d}x \leqslant \infty$，若 $\displaystyle \int_E f(x) \, \mathrm{d}x < \infty$，则称 $f(x)$ 在 $E$ 上**勒贝格可积** 
- **勒贝格积分**：设 $A\subset E$ 为可测集，则 $f(x)$ 在 $A$ 上的**勒贝格积分**定义为 $f$ 在 $A$ 上的限制 $f\mid_A$ 在 $A$ 上的勒贝格积分。我们有 $\displaystyle \int_A f(x)\mathrm dx = \int_E f(x) \chi_A(x)\mathrm dx$，$\chi_{A}(x) = \begin{cases} 1 & x\in A \\ 0 & x\not\in A \end{cases}$ 
- **定理 1**：
	设 $E \subset \mathbf{R}^n$ 为可测集，$f(x)$ 为 $E$ 上的一个非负可测函数，我们有  
	(1) 若 $mE = 0$，则 $\displaystyle \int_E f(x) \, \mathrm{d}x = 0$ 
	(2) 若 $\displaystyle \int_E f(x) \, \mathrm{d}x = 0$，则 $f(x) = 0$ $\text{a.e.}$ 于 $E$ 
	(3) 若 $\displaystyle \int_E f(x) \, \mathrm{d}x < \infty$，则 $0 \leqslant f(x) < \infty$ $\text{a.e.}$ 于 $E$ 
	(4) 设 $A$ 和 $B$ 为 $E$ 的两个互不相交的可测子集，则 $\displaystyle \int_{A \cup B} f(x) \, \mathrm{d}x = \int_A f(x) \, \mathrm{d}x + \int_B f(x) \, \mathrm{d}x$ 
- **定理 2**：
	设 $E \subset \mathbf{R}^n$ 为可测集，$f(x)$ 和 $g(x)$ 都是 $E$ 上的非负可测函数。我们有  
	(1) 若 $f(x) \leqslant g(x)$ a.e. 于 $E$，则 $\displaystyle \int_E f(x) \, \mathrm{d}x \leqslant \int_E g(x) \, \mathrm{d}x$；这时，若 $g(x)$ 在 $E$ 上 $L$ 可积，则 $f(x)$ 也在 $E$ 上 $L$ 可积
	(2) 若 $f(x) = g(x)$ a.e. 于 $E$，则 $\displaystyle \int_E f(x) \, \mathrm{d}x = \int_E g(x) \, \mathrm{d}x$ 
- **定理 3** (**莱维 (Levi) 定理**)：设 $E \subset \mathbf{R}^n$ 为可测集，$\{f_n\}_{n=1}^\infty$ 为 $E$ 上的一列非负可测函数，当 $x \in E$ 时对于任一正整数 $n$，有 $f_n(x) \leqslant f_{n+1}(x)$。令 $f(x) = \lim\limits_{n \to \infty} f_n(x), x \in E$，则 $\displaystyle \lim\limits_{n \to \infty} \int_E f_n(x) \mathrm dx = \int_E f(x) \mathrm dx$ 
- **定理 4**：设 $E \subset \mathbf{R}^n$ 为可测集，$f(x)$ 和 $g(x)$ 都是 $E$ 上的非负可测函数，$\alpha$ 和 $\beta$ 都是非负实数，则 $\displaystyle \int_E (\alpha f(x) + \beta g(x)) \, \mathrm{d}x = \alpha \int_E f(x) \, \mathrm{d}x + \beta \int_E g(x) \, \mathrm{d}x$，特别地 $\displaystyle \int_E \alpha f(x) \, \mathrm{d}x = \alpha \int_E f(x) \, \mathrm{d}x$，$\displaystyle \int_E (f(x) + g(x)) \, \mathrm{d}x = \int_E f(x) \, \mathrm{d}x + \int_E g(x) \, \mathrm{d}x$ 
	- **推论**：设 $E \subset \mathbf{R}^n$ 为可测集，$f$ 和 $g$ 都是 $E$ 上的非负 $L$ 可积函数，$\alpha$ 和 $\beta$ 是非负实数，则 $\alpha f + \beta g$ 也在 $E$ 上非负 $L$ 可积
- **定理 5** (**逐项积分定理**)：设 $E \subset \mathbf{R}^n$ 为可测集，$\{f_n\}_{n=1}^\infty$ 为 $E$ 上的一列非负可测函数，则 $\displaystyle \int_E \left( \sum_{n=1}^\infty f_n(x) \right) \mathrm{d}x = \sum_{n=1}^\infty \int_E f_n(x) \mathrm{d}x$ 
- **定理 6** (**法图 (Fatou) 引理**)：设 $E \subset \mathbf{R}^n$ 为可测集，$\{f_n\}_{n=1}^\infty$ 为 $E$ 上的一列非负可测函数，则 $\displaystyle \int_E \lim_{n \to \infty} f_n(x) \mathrm{d}x \leqslant \lim_{n \to \infty} \int_E f_n(x) \mathrm{d}x$ 
	- *注意*：不能把法图引理中的 $\le$ 改成 $=$ 
## 5-3 一般可测函数的勒贝格积分
- **在 $E$ 上积分确定**、**在 $E$ 上的勒贝格积分**：设 $E \subset \mathbf{R}^n$ 为可测集，$f(x)$ 为 $E$ 上的可测函数。令 $f^+(x) = \max\{f(x), 0\}, \ f^-(x) = \max\{-f(x), 0\}$，则 $f^+$ 和 $f^-$ 都是 $E$ 上的非负可测函数，当 $x \in E$ 时，$f^+(x) - f^-(x) = f(x),\ f^+(x) + f^-(x) = |f(x)|$。若 $\displaystyle \int_E f^+(x) \mathrm{d}x$ 和 $\displaystyle \int_E f^-(x) \mathrm{d}x$ 中至少一个有限，则称 $f$ **在 $E$ 上积分确定**，称 $\displaystyle \int_E f^+(x) \mathrm{d}x - \int_E f^-(x) \mathrm{d}x$ 为 $f$ **在 $E$ 上的勒贝格积分**，记作 $\displaystyle \int_E f(x) \mathrm{d}x$ 
	- **在 $E$ 上勒贝格可积** (**$L$ 可积**)：若 $\displaystyle \int_E f^+(x) \mathrm{d}x$ 和 $\displaystyle \int_E f^-(x) \mathrm{d}x$ 都有限，则称 $f$ **在 $E$ 上勒贝格可积**，简称 **$L$ 可积** 
	- $L(E)$：可测集 $E$ 上 $L$ 可积函数的全体所成之集记作 $L(E)$ 
- **定理 1** 
	设 $E \subset \mathbf{R}^n$ 为可测集，我们有
	(1) 若 $E \neq \varnothing$ 但 $mE = 0$，则 $E$ 上的任何实函数 $f$ 都在 $E$ 上 $L$ 可积且 $\displaystyle \int_E f(x) \mathrm{d}x = 0$ 
	(2) 若 $f \in L(E)$，则 $mE[|f| = \infty] = 0$，即 $|f(x)| < \infty$ a.e. 于 $E$ 
	(3) 设 $f$ 在 $E$ 上积分确定，则 $f$ 在 $E$ 的任一可测子集 $A$ 上也积分确定，又若 $E = A \cup B$，这里 $A$ 和 $B$ 都是 $E$ 的可测子集且 $A \cap B = \varnothing$，则 $\displaystyle \int_E f(x) \mathrm{d}x = \int_A f(x) \mathrm{d}x + \int_B f(x) \mathrm{d}x$ 
	(4) 设 $f$ 在 $E$ 上积分确定且 $f(x) = g(x)$ a.e. 于 $E$，则 $g$ 也在 $E$ 上积分确定且 $\displaystyle \int_E f(x) \mathrm{d}x = \int_E g(x) \mathrm{d}x$ 
	(5) 设 $f$ 和 $g$ 都在 $E$ 上积分确定且 $f(x) \leqslant g(x)$ a.e. 于 $E$，则 $\displaystyle \int_E f(x) \mathrm{d}x \leqslant \int_E g(x) \mathrm{d}x$。特别地，若 $mE < \infty$ 且 $b \leqslant f(x) \leqslant B$ a.e. 于 $E$，则 $\displaystyle bmE \leqslant \int_E f(x) \mathrm{d}x \leqslant BmE$ 
	(6) 设 $f$ 在 $E$ 上 $L$ 可积，则 $|f|$ 也在 $E$ 上 $L$ 可积，且 $\displaystyle \left| \int_E f(x) \mathrm{d}x \right| \leqslant \int_E |f(x)| \mathrm{d}x$ 
	(7) 设 $f$ 是 $E$ 上的可测函数，$g$ 是 $E$ 上的非负 $L$ 可积函数且 $|f(x)| \leqslant g(x)$ a.e. 于 $E$，则 $f$ 也在 $E$ 上 $L$ 可积且 $\displaystyle \left| \int_E f(x) \mathrm{d}x \right| \leqslant \int_E |f(x)| \mathrm{d}x \leqslant \int_E g(x) \mathrm{d}x$ 
- **定理 2**：设 $E\subset \mathbf{R}^{n}$ 为可测集，$f$ 和 $g$ 都是 $E$ 上的 $L$ 可积函数，则
	(1) 对于任意的 $\lambda\in \mathbf{R}$，$\lambda f$ 在 $E$ 上 $L$ 可积且 $\displaystyle\int_{E}\lambda f(x)\,\mathrm{d}x = \lambda\int_{E}f(x)\,\mathrm{d}x$ 
	(2) $f+g$ 在 $E$ 上 $L$ 可积且 $\displaystyle \int_{E}(f(x)+g(x))\,\mathrm{d}x = \int_{E}f(x)\,\mathrm{d}x + \int_{E}g(x)\,\mathrm{d}x$ 
	(3) 对于任意的 $\alpha,\beta\in \mathbf{R}$，$\alpha f+\beta g$ 在 $E$ 上 $L$ 可积，且 $\displaystyle \int_{E}(\alpha f(x)+\beta g(x))\,\mathrm{d}x = \alpha\int_{E}f(x)\,\mathrm{d}x + \beta\int_{E}g(x)\,\mathrm{d}x$ 
- **定理 3** (**积分的绝对连续性**)：设 $E\subset\mathbf{R}^{n}$ 为可测集，$f\in L(E)$，则对于任意的 $\varepsilon>0$，存在 $\delta>0$，使得对于任意的可测集 $A\subset E$，只要 $mA<\delta$，就有 $\displaystyle \left| \int_{A}f(x) \mathrm{d}x \right| \leqslant \int_{A}|f(x)| \mathrm{d}x < \varepsilon$ 
- **定理 4** (**积分的可数可加性**)：设 $E \subset \mathbf{R}^{n}$ 为可测集，$E = \bigcup\limits_{n=1}^{\infty} E_{n}$，这里每个 $E_{n}$ 都是可测集且 $i \neq j$ 时 $E_{i} \cap E_{j} = \varnothing$，设 $f$ 在 $E$ 上积分确定，则 $\displaystyle \int_{E}f(x)\mathrm{d}x = \sum_{n=1}^{\infty} \int_{E_{n}} f(x) \mathrm{d}x$
- **定理 5** (**勒贝格控制收敛定理**)：设 $E\subset\mathbf{R}^{n}$ 为可测集，$\{f_{n}\}_{n=1}^{\infty}$ 为 $E$ 上的一列可测函数。$F$ 是 $E$ 上的非负 $L$ 可积函数，如果对于任意的正整数 $n$，$|f_{n}(x)|\leqslant F(x)$ a.e. 于 $E$ 且 $\lim\limits_{n\to\infty}f_{n}(x) = f(x)$ a.e. 于 $E$，则
	(1) $\displaystyle \lim_{n \to \infty} \int_E |f_n(x) - f(x)| \mathrm{d}x = 0$ 
	(2) $\displaystyle \lim_{n \to \infty} \int_E f_n(x) \mathrm{d}x = \int_E f(x) \mathrm{d}x$ 
- **定理 6**：设 $E \subset \mathbf{R}^{n}$ 为可测集，$f$ 和 $f_{n} (n = 1, 2, 3, \cdots)$ 都是 $E$ 上的可测函数，$F$ 是 $E$ 上的非负 $L$ 可积函数，如果 $|f_{n}(x)| \leqslant F(x)$ a.e. 于 $E$ 且 $n \to \infty$ 时 $f_{n} \Rightarrow f$，则
	(1) $\displaystyle \lim\limits_{n \to \infty} \int_{E} |f_{n}(x) - f(x)| \mathrm{d}x = 0$ 
	(2) $\displaystyle \lim\limits_{n \to \infty} \int_{E} f_{n}(x) \mathrm{d}x = \int_{E} f(x) \mathrm{d}x$ 
- **推论** 
	设 $E \subset \mathbf{R}^{n}$ 为可测集，$mE < \infty$，$f$ 和 $f_{n} (n = 1, 2, 3, \cdots)$ 都是 $E$ 上的可测函数。如果存在 $M > 0$ 使得对于任意的正整数 $n$，$|f_{n}(x)| \leqslant M$ a.e. 于 $E$，且 $n \to \infty$ 时 $f_{n}(x) \to f(x)$ a.e. 于 $E$ 或 $f_{n} \Rightarrow f$，则：
	(1) $\displaystyle \lim\limits_{n \to \infty} \int_{E} |f_{n}(x) - f(x)| \mathrm{d}x = 0$ 
	(2) $\displaystyle \lim\limits_{n \to \infty} \int_{E} f_{n}(x) \mathrm{d}x = \int_{E} f(x) \mathrm{d}x$ 
- **定理 7**：设 $E \subset \mathbf{R}^{n}$ 为可测集，$\{f_{n}\}_{n=1}^{\infty}$ 为 $E$ 上的一列 $L$ 可积函数。如果正项级数 $\displaystyle \sum_{n=1}^{\infty} \int_{E} |f_{n}(x)| \mathrm{d}x$ 收敛，则函数项级数 $\sum\limits_{n=1}^{\infty} f_{n}(x)$ 在 $E$ 上 a.e. 收敛，其和函数在 $E$ 上 $L$ 可积，且 $\displaystyle \int_{E} \left( \sum_{n=1}^{\infty} f_{n}(x) \right) \mathrm{d}x = \sum_{n=1}^{\infty} \int_{E} f_{n}(x) \mathrm{d}x$ 
- **定理 8**：设 $E \subset \mathbf{R}^{n}$ 为可测集，$f(x,t)$ 是 $E \times (a,b)$ 上的实函数。如果对于任意的 $t \in (a,b)$，$f(x,t)$ 作为 $x$ 的函数在 $E$ 上 $L$ 可积，对于 a.e. 的 $x \in E$，$f(x,t)$ 作为 $t$ 的函数在 $(a,b)$ 上可导且 $\left| \dfrac{\partial}{\partial t} f(x,t) \right| \leqslant F(x)$，这里 $F$ 是 $E$ 上某个非负 $L$ 可积函数，则 $\displaystyle \int_{E} f(x,t) \mathrm{d}x$ 作为 $t$ 的函数在 $(a,b)$ 上可导，且 $\displaystyle \dfrac{\mathrm{d}}{\mathrm{d}t} \int_{E} f(x,t) \mathrm{d}x = \int_{E} \frac{\partial}{\partial t} f(x,t) \mathrm{d}x$ 
## 5-4 黎曼积分和勒贝格积分
- 本节就一元函数的情形讨论黎曼积分和勒贝格积分的关系。
- **黎曼积分**、**勒贝格积分**：我们把一元函数 $f(x)$ 在 $[a,b]$ 上的**黎曼积分**和**勒贝格积分**分别记为 $\displaystyle (R)\int_{[a,b]} f(x) \mathrm{d}x$ 和 $\displaystyle (L)\int_{[a,b]} f(x) \mathrm{d}x$ 
- 勒贝格积分是黎曼积分的推广但不是黎曼反常积分的推广
- **定理 1**：设 $f(x)$ 是 $[a,b]$ 上有界函数，则 $f(x)$ 在 $[a,b]$ 上 $R$ 可积的充要条件为 $f(x)$ 在 $[a,b]$ 上 a.e. 连续，即 $f(x)$ 的不连续点全体成一零测度集。
- **定理 2**：设 $f(x)$ 是 $[a,b]$ 上的一个有界函数，若 $f(x)$ 在 $[a,b]$ 上 $R$ 可积，则 $f(x)$ 在 $[a,b]$ 上 $L$ 可积，且 $\displaystyle (L) \int_{[a,b]} f(x) \mathrm{d}x = (R) \int_{[a,b]} f(x) \mathrm{d}x$ 
- **定理 3**：设 $f(x)$ 是 $[a, \infty)$ 上的一个非负实函数，若对于任意的 $A > a$，$f(x)$ 在 $[a, A]$ 上 $R$ 可积且 $R$ 反常积分 $\displaystyle (R) \int_{a}^{\infty} f(x) \mathrm{d}x$ 收敛，则 $f(x)$ 在 $[a, \infty)$ 上 $L$ 可积且 $\displaystyle (L) \int_{[a, \infty)} f(x) \mathrm{d}x = (R) \int_{a}^{\infty} f(x) \mathrm{d}x$ 
	- 关于非负无界函数的 $R$ 反常积分与 $L$ 积分的关系，也有类似的结果，这里就不一一叙述了。
- *总结*：**定理 2** 说明 $L$ 积分是 $R$ 积分的推广，**定理 3** 说明对于非负函数而言 $L$ 积分也是 $R$ 反常积分的推广，但注意在一般情况下 $L$ 积分并不是 $R$ 反常积分的推广，这主要因为 $L$ 积分是绝对收敛的积分而收敛的 $R$ 反常积分并不一定绝对收敛。
## 5-5 勒贝格积分的几何意义、富比尼定理
- *前言*：到目前为止，我们讲测度也好，积分也好，都是就同一个 $n$ 维空间来考虑的。现在我们将考虑不同维空间的可测集及测度，并研究其间的关系。这样不仅可以得到 $L$ 积分的几何解释，而且还可以导出重积分化累次积分的重要公式
- **直积**：设 $A \subset \mathbf{R}^p$, $B \subset \mathbf{R}^q$ 为两个非空点集，则 $\mathbf{R}^{p+q}$ 中的点集 $\{(x,y): x \in A, y \in B\}$ 称为 $A$ 与 $B$ 的**直积**，记作 $A \times B$ 
	- *注意*：一般地，$A \times B \neq B \times A$ 
- **截面**：设 $E$ 是 $\mathbf{R}^{p+q}$ 中一点集，$x_0$ 是 $\mathbf{R}^p$ 中一固定点，则 $\mathbf{R}^q$ 中的点集 $\{y \in \mathbf{R}^q: (x_0, y) \in E\}$ 称为 $E$ 关于 $x_0$ 的**截面** (如下图)，记为 $E_{x_0}$ (当然也可以定义 $E$ 关于 $y_0\in \mathbb R^q$ 的截面 $\{ x\in \mathbb R^p: (x, y_0)\in E \} = E_{y_0}$)
	![[Pasted image 20260424171733.png|200]]
- *直积与截面的简单性质*：
	1. 如果 $A_1 \subset A_2$，则 $A_1 \times B \subset A_2 \times B$ 
	2. 如果 $A_1 \cap A_2 = \varnothing$，则 $(A_1 \times B) \cap (A_2 \times B) = \varnothing$ 
	3. $\left( \bigcup\limits_i A_i \right) \times B = \bigcup\limits_i (A_i \times B)$，$\left( \bigcap\limits_i A_i \right) \times B = \bigcap\limits_i (A_i \times B)$ 
	4. $(A_1 \setminus A_2) \times B = (A_1 \times B) \setminus (A_2 \times B)$ 
	5. 如果 $A_1 \subset A_2$，则 $(A_1)_x \subset (A_2)_x$ 
	6. 如果 $A_1 \cap A_2 = \varnothing$，则 $(A_1)_x \cap (A_2)_x = \varnothing$ 
	7. $\left( \bigcup\limits_i A_i \right)_x = \bigcup\limits_i (A_i)_x$，$\left( \bigcap\limits_i A_i \right)_x = \bigcap\limits_i (A_i)_x$ 
	8. $(A_1 \setminus A_2)_x = (A_1)_x \setminus (A_2)_x$ 
- **定理 1** (**截面定理**)
	设 $E \subset \mathbf{R}^{p+q}$ 是可测集，则
	(1) 对于 $\mathbf{R}^p$ 中几乎所有的点 $x$，$E_x$ 是 $\mathbf{R}^q$ 中可测集
	(2) $mE_x$ 作为 $x$ 的函数，它是 $\mathbf{R}^p$ 上 a.e. 有定义的可测函数
	(3) $\displaystyle mE = \int_{\mathbf{R}^p} mE_x \, \mathrm{d}x$ 
	- 该重要定理给我们提供了一个由低维测度求高维测度的工具
- **定理 2**：设 $A, B$ 分别是 $\mathbf{R}^p, \mathbf{R}^q$ 中的可测集，则 $A \times B$ 是 $\mathbf{R}^{p+q}$ 中的可测集且 $m(A \times B)$ $= mA \cdot mB$ 
- **下方图形**：设 $f(x)$ 是 $E \subset \mathbf{R}^n$ 上的非负函数，则 $\mathbf{R}^{n+1}$ 中的点集 $\{(x,z): x \in E,\ 0 \leqslant z < f(x)\}$ 称为 $f(x)$ 在 $E$ 上的**下方图形**，记为 $G(E, f)$ 
- **定理 3** (**非负可测函数积分的几何意义**)
	设 $f(x)$ 为可测集 $E \subset \mathbf{R}^n$ 上的非负函数，则：
	(1) $f(x)$ 是 $E$ 上的可测函数的充要条件是 $G(E,f)$ 是 $\mathbf{R}^{n+1}$ 中的可测集
	(2) 当 $f(x)$ 在 $E$ 上可测时，$\displaystyle \int_E f(x) \mathrm{d}x = mG(E,f)$ 
	- **推论 1**：设 $f(x)$ 为 $E \subset \mathbf{R}^n$ 上的可积函数，则 $\displaystyle \int_E f(x) \, \mathrm{d}x = mG(E,f^+) - mG(E,f^-)$ 
	- **推论 2**：可测函数 $f(x)$ 在 $E \subset \mathbf{R}^n$ 上可积分的充要条件是 $mG(E,f^+)$ 与 $mG(E,f^-)$ 都是有限的
- **定理 4** (**富比尼定理**)
	(1) 设 $f(P) = f(x,y)$ 在 $A \times B \subset \mathbf{R}^{p+q}$ ($A, B$ 分别为 $\mathbf{R}^p$ 与 $\mathbf{R}^q$ 中之可测集) 上非负可测，则对 a.e. 的 $x \in A$，$f(x,y)$ 作为 $y$ 的函数在 $B$ 上可测，且 $\displaystyle \int_{A \times B} f(P) \, \mathrm{d}P = \int_A \mathrm{d}x \int_B f(x,y) \, \mathrm{d}y$ 
	(2) 设 $f(P) = f(x,y)$ 在 $A \times B \subset \mathbf{R}^{p+q}$ 上可积，则对 a.e. 的 $x \in A$，$f(x,y)$ 作为 $y$ 的函数在 $B$ 上可积，又 $\displaystyle \int_B f(x,y) \, dy$ 作为 $x$ 的函数在 $A$ 上可积且 $\displaystyle \int_{A \times B} f(P) \, \mathrm{d}P = \int_A \mathrm{d}x \int_B f(x,y) \, \mathrm{d}y$ 式成立.
	- 由**定理 2**、**定理 3** 立即可以导出富比尼定理，它说明了高维积分与低维积分之间的联系，也就是数学分析中重积分化累次积分的推广
	- *注意*：公式 $\displaystyle \int_{A \times B} f(P) \, \mathrm{d}P = \int_A \mathrm{d}x \int_B f(x,y) \, \mathrm{d}y$ 换成 $\displaystyle \int_{A \times B} f(P) \mathrm dP = \int_B \mathrm dy \int_A f(x,y) \mathrm dx$ 照样成立，当然定理中某些字母都要作相应的对调。
- 读者可以回忆一下，在 $R$ 积分理论中重积分化成累次积分所要求的条件比 $L$ 积分理论中要多，这是 $L$ 积分的另一个成功之处。
- 从富比尼定理，我们看到，只要重积分有限，它就和两个累次积分相等。
# 6 微分与不定积分
## 6-1 维塔利定理
- **$V$—覆盖**：设 $E \subset \boldsymbol{R}$，$\mathscr{V} = \{ I \}$ 是长度为正的区间族，如果对于任意 $x \in E$ 及任意 $\varepsilon > 0$，存在区间 $I_x \in \mathscr{V}$，使 $x \in I_x$，且 $mI_x < \varepsilon$，则称 $\mathscr{V}$ 依维塔利意义覆盖 $E$，简称 $E$ 的 **$V$—覆盖** 
	- 易证其定义的等价形式为：对于任意 $x \in E$，存在一列区间 $\{ I_n \} \subset \mathscr{V}$，使 $x \in I_n,\ n = 1, 2, \cdots$ 且 $mI_n \to 0\ (n \to \infty)$ 
- **定理** (**维塔利覆盖定理**)：设 $E \subset \boldsymbol{R}$ 且 $m^* E < \infty$，$\mathscr{V}$ 是 $E$ 的 $V$—覆盖，则可选出区间列 $\{ I_n \} \subset \mathscr{V}$，使各 $I_n$ 互不相交且 $m\left( E \setminus \bigcup\limits_{k} I_k \right) = 0$ 
- **推论**：设 $E \subset \mathbf{R}$ 且 $m^* E < \infty$，$\mathscr{V}$ 是 $E$ 的 $V$—覆盖，则对任何 $\varepsilon > 0$，可从 $\mathscr{V}$ 中选出互不相交的有限个区间 $I_1, I_2, \cdots, I_n$，使 $m^* \left( E \setminus \bigcup\limits_{i=1}^{n} I_i \right) < \varepsilon$ 
	- 维塔利覆盖定理也可表示成另一种形式
## 6-2 单调函数的可微性
- **列导数**：设 $f(x)$ 为 $[a, b]$ 上的有限函数，$x_0 \in [a, b]$，如果存在数列 $h_n \to 0\ (h_n \not=0)$ 使极限 $\lim\limits_{n} \dfrac{f(x_{0}+h_{n})-f(x_{0})}{h_{n}} = \lambda$ 存在 ($\lambda$ 可为 $\pm\infty$)，则称 $\lambda$ 为 $f(x)$ 在点 $x_{0}$ 处的一个**列导数**，记为 $Df(x_{0})=\lambda$ 
	- *注意*：列导数 $Df(x_{0})$ 与数列 $\{h_{n}\}$ 的取法有关。例如 $f(x)$ 取作狄利克雷函数，设 $x_{0}$ 为有理数，则 $\dfrac{f(x_{0}+h_{n})-f(x_{0})}{h_{n}} = \begin{cases}0,&h_{n}\text{为有理数} \\ - \dfrac{1}{h_{n}}, & h_{n}\text{为无理数} \end{cases}$，故得 $Df(x_{0}) = \begin{cases}0, & h_{n}\text{为有理数} \\ \infty & h_{n}\text{为无理数且当 } n \text{ 充分大时} , h_{n}<0\\ -\infty, & h_{n} \text{为无理数且当 } n \text{ 充分大时}, h_{n}>0 \end{cases}$ 
- *结论*：$f(x)$ 在点 $x_{0}$ 存在导数 $f^{\prime}(x_{0})$ 的充要条件是 $f(x)$ 在点 $x_{0}$ 处的一切列导数都相等
- **引理** 
	设 $f(x)$ 为 $[a,b]$ 上的严格增函数
	(1) 如果对于 $E\subset[a,b]$ 中每一点 $x$，至少有一个列导数 $Df(x)\leqslant p\,(p\geqslant 0)$，则 $m^{*}f(E)\leqslant p\,m^{*}E$ 
	(2) 如果对于 $E\subset[a,b]$ 中每一点 $x$，至少有一个列导数 $Df(x)\geqslant q\,(q\geqslant 0)$，则 $m^{*}f(E)\geqslant q\,m^{*}E$ 
	- 魏尔斯特拉斯曾经给出过处处连续而无处可导的函数的例子，但是单调函数却有下面十分深刻的性质。
- **定理** (**勒贝格**)
	设 $f(x)$ 为 $[a,b]$ 上的单调函数，则
	(1) $f(x)$ 在 $[a,b]$ 上几乎处处存在导数 $f'(x)$ 
	(2) $f'(x)$ 在 $[a,b]$ 上可积
	(3) 如果 $f(x)$ 为增函数，有 $\displaystyle \int_{a}^{b}f'(x)dx \leqslant f(b)-f(a)$ 
	- *注意*：对某些函数，不等式确实严格成立。
	- 下节我们还要建立等号成立的条件
## 6-3 有界变差函数
- **可求长的**、**长**：设 $C$ 是平面上一条连续弧，$x=\varphi(t), y=\psi(t),\ \alpha \leqslant t \leqslant \beta$ 是它的参数表示，这里 $\varphi(t), \psi(t)$ 为 $[\alpha, \beta]$ 上的连续函数，相应于区间 $[\alpha, \beta]$ 的任一分划 $T: \alpha=t_0 < t_1 < \cdots < t_n=\beta$，得到 $C$ 上一组分点 $P_i=(\varphi(t_i), \psi(t_i)), i=0, 1, 2, \cdots, n$，设依次联结各分点 $P_i$ 所得内接折线的长为 $|L(T)|$，如果对于 $[\alpha, \beta]$ 的一切分划 $T$，$|L(T)|$ 成一有界数集，则称 $C$ 为**可求长的**，并称其上确界 $L=\sup_T L(T)$，为 $C$ 之**长** 
- *连续弧可求长的充要条件*：连续弧可求长 $\iff$ $[\alpha, \beta]$ 的一切分划 $T$ 都使 $\left\{ \sum\limits_{i=1}^n |\varphi(t_i)-\varphi(t_{i-1})| \right\}$ 及 $\left\{ \sum\limits_{i=1}^n |\psi(t_i)-\psi(t_{i-1})| \right\}$ 成为有界数集
- **有界变差函数** (**囿变函数**)、**变差**：设 $f(x)$ 为 $[a,b]$ 上的有限函数，如果对于 $[a,b]$ 的一切分划 $T$，使 $\left\{ \sum\limits_{i=1}^{n} |f(x_i)-f(x_{i-1})| \right\}$ 成一有界数集，则称 $f(x)$ 为 $[a,b]$ 上的**有界变差函数**（或**囿变函数**），并称该有界数集的上确界为 $f(x)$ 在 $[a,b]$ 上的**全变差**，记为 $\mathrm V_a^b \left( f \right)$。用一个分划作成的和数 $V = \sum\limits_{i=1}^{n} |f(x_i)-f(x_{i-1})|$，称为 $f(x)$ 在此分划下对应的**变差** 
- **定理 1**：连续弧 $x=\varphi(t),\ y=\psi(t),\ \alpha \leqslant t \leqslant \beta$ 可求长的充要条件是 $\varphi(t)$ 与 $\psi(t)$ 都是 $[\alpha,\beta]$ 上的有界变差函数。
- 现在我们集中研究有界变差函数。
	- 在有限闭区间上满足利普希茨 (Lipschitz) 条件的函数是有界变差函数
	- 在有限闭区间上的单调有限函数也是有界变差函数
	- 有界变差函数不一定是连续函数
	- 连续函数也不一定是有界变差函数。例如 $f(x)=\begin{cases} x \cos \dfrac{\pi}{2x} & 0 < x\leqslant 1 \\ 0 &x=0 \end{cases}$，显然它在 $[0,1]$ 上是连续函数。如果对 $[0,1]$ 取分划 $T:0 < \dfrac{1}{2n} < \dfrac{1}{2n-1} < \cdots < \dfrac{1}{3} < \dfrac{1}{2}<1$，则容易证明 $\sum\limits_{i=1}^{2n} \left|f(x_i)-f(x_{i-1}) \right| = \sum\limits_{i=1}^{n} \dfrac{1}{i}$，从而得到 $\mathrm V_0^1 (f) = \infty$ 
- **定理 2** 
	(1) **可加性**：设 $f(x)$ 在 $[a,b]$ 上有界变差，则也在其任一子区间 $[a_1,b_1]$ 上有界变差。又如 $a<c<b$，$f(x)$ 分别在 $[a,c]$ 及 $[c,b]$ 上有界变差，则 $f(x)$ 在 $[a,b]$ 上也有界变差且 $\mathrm{V}_a^b(f) = \mathrm{V}_a^c (f) + \mathrm{V}_c^b(f)$ 
	(2) 设 $f(x)$ 在 $[a,b]$ 上有界变差，则 $f(x)$ 在 $[a,b]$ 上有界
	(3) 设 $f(x),g(x)$ 在 $[a,b]$ 上都有界变差，则 $f(x)\pm g(x),f(x)g(x)$ 在 $[a,b]$ 上有界变差
	- 前面提到 $[a,b]$ 上的有限增函数是有界变差函数，由该定理知，两个有限增函数的差还是有界变差函数。反之，我们有下面重要结论。
- **定理 3** (**若尔当 (Jordan) 分解**)：在 $[a,b]$ 上的任一有界变差函数 $f(x)$ 都可表示为两个增函数之差。
	- 因为单调函数至多有可数个不连续点，由**定理 3** 便知有界变差函数至多有可数个不连续点。
- **推论** 
	设 $f(x)$ 为 $[a, b]$ 上的有界变差函数，则
	(1) $f(x)$ 在 $[a, b]$ 上几乎处处存在导数 $f'(x)$ 
	(2) $f'(x)$ 在 $[a, b]$ 上可积
## 6-4 不定积分
- **不定积分**：设 $f(x)$ 在 $[a,b]$ 上 $L$ 可积，则 $[a,b]$ 上的函数 $\displaystyle F(x) = \int_a^x f(t)\mathrm{d}t + C$ ($C$ 为任一常数) 称为 $f(x)$ 的一个**不定积分** 
- **绝对连续函数**：设 $F(x)$ 为 $[a, b]$ 上的有限函数，如果对任意 $\varepsilon>0$，存在 $\delta>0$，使对 $[a, b]$ 中互不相交的任意有限个开区间 $\left(a_{i}, b_{i}\right),\ i=1,2, \cdots, n$，只要 $\sum\limits_{i=1}^{n}\left(b_{i}-a_{i}\right)<\delta$，就有 $\sum\limits_{i=1}^{n} \left|F\left(b_{i}\right)-F\left(a_{i}\right)\right|<\varepsilon$，则称 $F(x)$ 为 $[a, b]$ 上的**绝对连续函数** 
- **定理 1** 设 $f(x)$ 在 $[a, b]$ 上可积，则其不定积分为绝对连续函数。
- *结论*：不难证明绝对连续函数是一致连续函数，并且也是有界变差函数。满足利普希茨条件的函数是绝对连续函数。
- **定理 2** 设 $F(x)$ 为 $[a, b]$ 上的绝对连续函数，且 $F'(x)=0$ a.e. 于 $[a, b]$，则 $F(x)= \text{常数}$ 
- **定理 3**：设 $f(x)$ 在 $[a, b]$ 上可积，则存在绝对连续函数 $F(x)$ 使 $F'(x) = f(x)$ a.e. 于 $[a, b]$ (只需取 $\displaystyle F(x) = \int_a^x f(t) \mathrm{d}t$)
	- 该定理说明一重要事实，即在 $L$ 积分范围内积分再微分则还原。
- **定理 4**：设 $F(x)$ 是 $[a, b]$ 上的绝对连续函数，则 a.e. 有定义的 $F'(x)$ 在 $[a, b]$ 上可积且 $\displaystyle F(x) = F(a) + \int_a^x F'(t) \mathrm{d}t, \quad (t5)$，即 $F(x)$ 总是 $[a, b]$ 上可积函数的不定积分
	- 由此我们得到：$F(x)$ 是 $[a, b]$ 上的绝对连续函数的充要条件，它是一个可积函数的不定积分。
	- **定理 1** 和**定理 4** 说明：绝对连续函数之所以重要在于它完全可以标志不定积分
	- **定理 4** 是 $R$ 积分理论中牛顿—莱布尼茨公式的推广，对绝对连续函数而言，微分再积分也还原 (至多差一常数)。但是如前节末所看到的那样，对有界变差函数一般却不能保证**定理 4** 成立。因此，$L$ 积分在积分与微分的关系问题上虽比 $R$ 积分优越得多，但还不够理想。至于进一步的扩充需要引进当**茹瓦 (Denjoy) 积分**，这已超出了本书的范围
## 6-5 斯蒂尔切斯积分
- *前言*：现在我们着手推广 $L$ 积分，得到所谓**勒贝格—斯蒂尔切斯 ($L$-$S$) 积分**，并为此在本节先介绍一下作为 $L$-$S$ 积分前身的**黎曼—斯蒂尔切斯积分** (简称 **$R$-$S$ 积分**或 **$S$ 积分**)，当然 $R$-$S$ 积分是 $R$ 积分的另一种推广。
- **斯蒂尔切斯和数** (**$S$ 和数**)、**$S$ 可积的**、**$S$ 积分**：设 $f(x)$, $\alpha(x)$ 为 $[a, b]$ 上的有限函数，对 $[a, b]$ 作一分划 $T: a = x_0 < x_1 < \cdots < x_n = b$ 及属于此分划的任一组“介点”$x_{i-1} \leqslant \xi_i \leqslant x_i (i = 1, 2, \cdots, n)$ 作和数 (叫做**斯蒂尔切斯和数**，简称 **$S$ 和数**) $\sum\limits_{i=1}^{n} f(\xi_i) [\alpha(x_i) - \alpha(x_{i-1})]$。如果当 $\delta(T) \to 0$ 时，此和数总趋于一确定的有限极限 (不论 $T$ 分法如何，也不论介点取法如何)，则称 $f(x)$ 在 $[a, b]$ 上关于 $\alpha(x)$ 为 **$S$ 可积的**，此极限叫做 $f(x)$ 在 $[a, b]$ 上关于 $\alpha(x)$ 的 **$S$ 积分**，记为 $\displaystyle \int_a^b f(x) \mathrm{d}\alpha(x)$ 
	- 易知当 $\alpha(x) = x$ 时，$S$ 积分便成为 $R$ 积分，可见 $S$ 积分是 $R$ 积分的一种推广。
	- 又如当我们考虑曲线积分 $\displaystyle \int_C f(x,y) \mathrm{d}x$，$C: x=\varphi(t),\ y=\psi(t)\ (\alpha \leqslant t \leqslant \beta)$，则 $\displaystyle \int_C f(x,y) \mathrm{d}x = \int_\alpha^\beta f(\varphi(t), \psi(t)) \mathrm{d}\varphi(t)$ 就是一种特殊的 $S$ 积分
- **定理 1** 
	(1) $\displaystyle \int_a^b [f_1(x) + f_2(x)] \mathrm{d}\alpha(x) = \int_a^b f_1(x) \mathrm{d}\alpha(x) + \int_a^b f_2(x) \mathrm{d}\alpha(x)$ 
	(2) $\displaystyle \int_a^b f(x) \mathrm{d}(\alpha_1(x) + \alpha_2(x)) = \int_a^b f(x) \mathrm{d}\alpha_1(x) + \int_a^b f(x) \mathrm{d}\alpha_2(x)$ 
	(3) 设 $k, l$ 为常数，则 $\displaystyle \int_a^b k f(x) \mathrm{d}(l \alpha(x)) = k \cdot l \int_a^b f(x) \mathrm{d}\alpha(x)$ 
	以上三式之意义，是当右边积分有意义时左边积分也有意义，而且等式成立。
	(4) 设 $a < c < b$，则 $\displaystyle \int_a^b f(x) \mathrm{d}\alpha(x) = \int_a^c f(x) \mathrm{d}\alpha(x) + \int_c^b f(x) \mathrm{d}\alpha(x)$，设左、右边各积分都存在
- **定理 2**：设 $f(x)$ 在 $[a, b]$ 上连续，$\alpha(x)$ 在 $[a, b]$ 上是有界变差的，则 $\displaystyle \int_a^b f(x) \mathrm{d}\alpha(x)$ 存在。
	- 该定理是一个在应用上重要的 $S$ 积分存在的充分条件。
- **定理 3**：设 $f(x)$ 在 $[a, b]$ 上连续，$\alpha(x)$ 处处可导且 $\alpha'(x)$ 又 $R$ 可积，则 $\displaystyle (S) \int_{a}^{b} f(x) \mathrm{d}\alpha(x) = (R) \int_{a}^{b} f(x) \alpha'(x) \mathrm{d}x \quad (*)$ 
- **定理 4**：设 $f(x)$ 在 $[a, b]$ 上连续，$g(x)$ 为绝对连续，则 $\displaystyle (S) \int_{a}^{b} f(x) \mathrm{d}g(x) = (L) \int_{a}^{b} f(x) g'(x) \mathrm{d}x$ 
- **定理 5** 设 $\displaystyle \int_{a}^{b} f(x) \mathrm{d}\alpha(x)$ 与 $\displaystyle \int_{a}^{b} \alpha(x) \mathrm{d}f(x)$ 中有一个存在，则另一个也存在，且 $\displaystyle \int_{a}^{b} f(x) \mathrm{d}\alpha(x) + \int_{a}^{b} \alpha(x) \mathrm{d}f(x) = f(x)\alpha(x) \bigg|_{a}^{b}$ 
- **推论**：设 $f(x)$ 在 $[a, b]$ 上是有界变差函数，$\alpha(x)$ 连续，则积分 $\int_{a}^{b} f(x) \mathrm{d}\alpha(x)$ 存在。
- *注意*：上面介绍的 $S$ 积分是只就 $\mathbb{R}$ 讲的，但在 $\mathbb{R}^n(n>1)$ 中也可定义 $S$ 积分，此处不再叙述了
## 6-6 $L$-$S$ 测度与积分
- *前言*：本节主要介绍 $L$ 测度、$L$ 积分的推广，所谓 $L-S$ 测度，以及建立在它上面的 $L-S$ 积分。这部分只作简单介绍不加详细论述。
- **权**：设 $\alpha(x)$ 为定义在 $\mathbb{R}$ 上的有限增函数，对任意开区间 $I=(x, x')$，称 $\alpha(x') - \alpha(x)$ 为区间 $I$ 的**权**，记为 $|I| = \alpha(x') - \alpha(x)$ 
- **$L$-$S$ 外测度**：对任一点集 $E \subset \mathbb{R}$，非负实数 $\inf \sum\limits_{i=1}^{\infty} |I_i|$ 称为 $E$ 关于分布函数 $\alpha(x)$ 的 **$L-S$ 外测度**，记为 $m_\alpha^* E$ 
	- 显然，当 $\alpha(x) = x$ 时，$L-S$ 外测度便成为 $L$ 外测度。
- **性质**：$L$-$S$ 外测度与 $L$ 外测度有同样的基本性质：
	1. $m_\alpha^* E \geqslant 0$，且 $m_\alpha^* \varnothing = 0$ 
	2. **单调性**：设 $A \subset B$，则 $m_\alpha^* A \leqslant m_\alpha^* B$ 
	3. **次可数可加性**：$m_\alpha^* \left( \bigcup\limits_{i=1}^{\infty} E_i \right) \leqslant \sum\limits_{i=1}^{\infty} m_\alpha^* E_i$ 
- *注意*：但在 $L$ 测度中，区间 $\langle a, b \rangle$ 不论开、闭或半开半闭都是 $m_\alpha^*\langle a, b \rangle = b-a$，而在一般 $L-S$ 外测度中则不然。
- **定理** 
	(1) $m_\alpha^*(a, b) = \alpha(b-0) - \alpha(a+0)$ 
	(2) $m_\alpha^*(a, b] = \alpha(b+0) - \alpha(a+0)$ 
	(3) $m_\alpha^*[a, b] = \alpha(b+0) - \alpha(a-0)$ 
	(4) $m_\alpha^*[a, b) = \alpha(b-0) - \alpha(a-0)$ 
	- 由定理看出，对 $\alpha(x)$ 取常值的任一开区间 $I$ 总有 $m_\alpha^* I = 0$，而对于 $\alpha(x)$ 的任一不连续点 $x_0$，则有 $m_\alpha^*|\{x_0\}| = \alpha(x_0 + 0) - \alpha(x_0 - 0) > 0$。这恰好与 $L$ 外测度情形相反。
