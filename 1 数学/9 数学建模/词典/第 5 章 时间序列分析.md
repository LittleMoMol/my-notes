# 5 时间序列分析
## 5-0 简要介绍
- **时间序列**：**时间序列**是按时间顺序排列的、随时间变化且相互关联的数据序列
- **时间序列分析**：分析时间序列的方法构成数据分析的一个重要领域，即**时间序列分析** 
- **趋势项部分**、**周期项部分**、**随机噪声部分**：任何时间序列经过合理的函数变换后都可以被认为是由三个部分叠加而成，分别是**趋势项部分**、**周期项部分**、**随机噪声项部分** 
	- 从时间序列中把这三个部分分解出来是时间序列分析的首要任务。
- *分类*：时间序列根据所研究的依据不同，可有不同的分类。
	- 根据*所研究的对象的数量*可分为：一元时间序列、多元时间序列
	- 根据*时间的连续性*可分为：离散时间序列、连续时间序列
	- 根据*序列的统计特性*可分为：平稳时间序列、非平稳时间序列
## 5-1 平稳时间序列
### 5-1-1 平稳时间序列定义
1. **随机过程的均值函数**的定义：对于随机过程 $\{X_{t}, t \in T\}$，$t$ 固定时，$X_{t}$ 是一个随机变量，设其均值为 $\mu_{t}$，当 $t$ 变动时，$\mu_{t}$ 是 $t$ 的函数，即**随机过程的均值函数**，记为 $\mu_{t} = E(X_{t})$ 
2. **随机过程的方差函数**的定义：对于随机过程 $\{X_{t}, t \in T\}$，$t$ 固定时，$X_{t}$ 的方差为 $\sigma_{t}^{2}$，当 $t$ 变动时，$\sigma_{t}^{2}$ 称为**随机过程的方差函数**，记为 $\sigma_{t}^{2} = \operatorname{Var}(X_{t}) = E\left[ (X_{t} - \mu_{t})^{2} \right]$ 
	- **随机过程的标准差函数**：方差函数的平方根 $\sigma_{t}$ 称为**随机过程的标准差函数**，它表示随机过程 $X_{t}$ 对于均值函数 $\mu_{t}$ 的偏离程度
3. **自协方差函数**的定义：对随机过程 $\{X_{t}, t \in T\}$ 取定 $t, s \in T$，定义其**自协方差函数**为 $\gamma_{t,s} = \operatorname{Cov}(X_{t}, X_{s}) = E\left[ (X_{t} - \mu_{t})(X_{s} - \mu_{s}) \right]$ 
4. **自相关函数**的定义：为刻画 $\{X_{t}, t \in T\}$ 在时刻 $t$ 与 $s$ 之间的相关性，将 $\gamma_{t,s}$ 标准化后定义**自相关函数**为 $\rho_{t,s} = \dfrac{\gamma_{t,s}}{\sqrt{\gamma_{t,t}} \sqrt{\gamma_{s,s}}} = \dfrac{\gamma_{t,s}}{\sigma_{t} \sigma_{s}}$ 
5. **平稳时间序列** (**平稳序列**) 的定义：若随机序列 $\{X_{t},t=0,\pm1,\pm2,\cdots\}$ 满足条件：$E(X_{t})=\mu$ 为常数，$\gamma_{t+k,t}=\gamma_{k}\ (k=0,\pm1,\pm2,\cdots)$ 与 $t$ 无关，则称 $X_{t}$ 为**平稳时间序列**，简称**平稳序列** 
6. **平稳白噪声序列**的定义：若随机序列 $\{X_{t},t=0,\pm1,\pm2,\cdots\}$ 是由一个不相关的随机变量序列构成的，且其期望和方差都是常数，即 $E(X_{t})=\mu$，$\gamma_{t,s}=\left\{\begin{array}{ll}0, &t\neq s,\\\sigma^{2},&t=s,\end{array}\right.$，则称该序列为**平稳白噪声序列** 
	- 平稳白噪声序列是一种最基本的平稳序列。
### 5-1-2 ARMA 模型的基本形式
- **ARMA 模型**主要包括三种基本模型：**AR 模型** (**Auto Regression Model**)、**MA 模型** (**Moving Average Model**)、**ARMA 模型** (**Auto Regression Moving Average Model**)
#### 5-1-2-1 AR 模型
- **$p$ 阶自回归模型** $AR(p)$、**$p$ 阶自回归序列**、**自回归参数向量**、**回归系数**：具有如下结构的模型称为 **$p$ 阶自回归模型**（简记为 $AR(p)$）：$X_{t}=\varphi_{0}+\varphi_{1}X_{t-1}+\varphi_{2}X_{t-2}+\cdots+\varphi_{p}X_{t-p}+\varepsilon_{t}$，满足条件 $\left\{ \begin{array}{l} \varphi_{p} \neq 0, \\ E\left( \varepsilon_{t} \right) = 0, \ \operatorname{Var}\left( \varepsilon_{t} \right) = \sigma_{\varepsilon}^{2}, \ E\left( \varepsilon_{t} \varepsilon_{s} \right) = 0,\ s \neq t \\ E\left( X_{s} \varepsilon_{t} \right) = 0, \ \forall s < t \end{array} \right.$，其中 $\varepsilon_{t}$ 是零均值、方差是 $\sigma_{\varepsilon}^{2}$ 的平稳白噪声。则称 $X_{t}$ 是**阶数为 $p$ 的自回归序列**，而 $\varphi = \left( \varphi_{0}, \varphi_{1}, \cdots, \varphi_{p} \right)^{\mathrm{T}}$ 称为**自回归参数向量**，其分量 $\varphi_{j}\ (j=0,1,\cdots,p)$ 称为**回归系数** 
	- 其中，条件一保证模型的阶是 $p$；条件二和三说明当期的随机干扰与过去的序列值无关
	- 当 $\varphi_{0}=0$ 时，称为**中心化 $AR(p)$ 模型**  
	- 当 $\varphi_{0} \neq 0$ 时，可通过平移变为**中心化序列**，平移变换如下 $\begin{aligned} \mu &= \dfrac{\varphi_{0}}{1 - \varphi_{1} - \cdots - \varphi_{p}} \\ Y_{t} &= X_{t} - \mu \end{aligned}$，则原序列即化为中心化序列 $\boxed{Y_{t} = \varphi_{1} Y_{t-1} + \varphi_{2} Y_{t-2} + \cdots + \varphi_{p} Y_{t-p} + \varepsilon_{t}\quad (*)}$ 
	- 所以，以后我们重点讨论中心化时间序列。
- **线性后移算子** $B$、**算子多项式** $\varphi(B)$：**线性后移算子** $B$ 定义为 $BX_{t} = X_{t-1},\ B^{k} X_{t} = X_{t-k}$，记**算子多项式** $\varphi(B) = 1 - \varphi_{1}B - \varphi_{2}B^{2} - \cdots - \varphi_{p}B^{p}$ 
	- 引进后移算子对描述方程 $(*)$ 比较方便。
	- 方程 $(*)$ 可变为 $\varphi(B) Y_{t} = \varepsilon_{t}$ 
#### 5-1-2-2 MA 模型
- **$q$ 阶滑动平均序列** $MA(q)$、**$q$ 阶滑动平均序列**、**滑动平均参数向量**、**滑动平均系数**：设零均值平稳序列 $\{X_{t}, t = 0, \pm 1, \pm 2, \cdots\}$，具有如下结构的模型称为 **$q$ 阶滑动平均模型**（简记为 $MA(q)$）：$X_{t} = \mu + \varepsilon_{t} - \theta_{1} \varepsilon_{t-1} - \theta_{2} \varepsilon_{t-2} - \cdots - \theta_{q} \varepsilon_{t-q}$，满足条件 $\left\{ \begin{array}{l} \theta_{q} \neq 0 \\ E\left( \varepsilon_{t} \right) = 0, \ \operatorname{Var}\left( \varepsilon_{t} \right) = \sigma_{\varepsilon}^{2},\ E\left( \varepsilon_{t} \varepsilon_{s} \right) = 0, \ s \neq t \end{array} \right.$，其中 $\varepsilon_{t}$ 是均值为 $0$、方差为 $\sigma_{\varepsilon}^{2}$ 的平稳白噪声。则称 $X_{t}$ 是**阶数为 $q$ 的滑动平均序列**，而 $\theta=\left(\theta_{1}, \theta_{2}, \cdots, \theta_{q}\right)^{\mathrm{T}}$ 称为**滑动平均参数向量**，其分量 $\theta_{j}\ (j=1,2, \cdots, q)$ 称为**滑动平均系数** 
	- 当 $\mu=0$ 时，称为**中心化 $MA(q)$ 模型** 
	- 当 $\mu\not=0$ 时，可以通过平移变为**中心化序列**，平移变换如下 $Y_t = X_t - \mu$，则将原序列化为中心化序列 $\boxed{Y_t =  \varepsilon_{t} - \theta_{1} \varepsilon_{t-1} - \theta_{2} \varepsilon_{t-2} - \cdots - \theta_{q} \varepsilon_{t-q}\quad (*)}$ 
- **线性后移算子** $B$、**算子多项式**：定义**线性后移算子** $B$ 为 $B\varepsilon_{t}=\varepsilon_{t-1},\ B^{k}\varepsilon_{t}=\varepsilon_{t-k}$，**算子多项式**为 $\theta(B)=1-\theta_{1} B-\theta_{2} B^{2}-\cdots-\theta_{q} B^{q}$ 
	- 则方程 $(*)$ 可变为 $Y_{t}=\theta(B) \varepsilon_{t}$ 
#### 5-1-2-3 ARMA 模型
- **$p,q$ 阶自回归滑动平均模型**、**$p,q$ 阶自回归滑动平均序列**：设平稳序列 $\left\{X_{t}, t=0, \pm 1, \pm 2, \cdots\right\}$，具有如下结构的模型称为 **$p,q$ 阶自回归滑动平均模型**（简记为 $ARMA(p,q)$）：$X_{t} = \varphi_0 + \varphi_{1} X_{t-1} + \cdots + \varphi_{p} X_{t-p} + \varepsilon_{t}-\theta_{1} \varepsilon_{t-1}-\theta_{2} \varepsilon_{t-2}-\cdots-\theta_{q} \varepsilon_{t-q}$，满足条件 $\begin{cases} \theta_{q} \neq 0,\ \varphi_{p} \neq 0 \\ E\left( \varepsilon_{t} \right) = 0, \quad \operatorname{Var}\left( \varepsilon_{t} \right) = \sigma_{\varepsilon}^{2}, \quad E\left( \varepsilon_{t} \varepsilon_{s} \right) = 0, \quad s \neq t \\ E\left( \varepsilon_{t} X_{s} \right) = 0,\ \forall\ s < t \end{cases}$，其中 $\varepsilon_{t}$ 是均值为 0、方差为 $\sigma_{\varepsilon}^{2}$ 的平稳白噪声。则称 $X_{t}$ 是**阶数为 $p,q$ 的自回归滑动平均序列** 
	- 当 $\varphi_{0}=0$ 时，称为**中心化 $\operatorname{ARMA}(p,q)$ 模型**（若原序列为零均值平稳序列，则 $\varphi_0 = 0$ 自动满足），模型变为 $\boxed{X_{t} = \varphi_{1} X_{t-1} + \cdots + \varphi_{p} X_{t-p} + \varepsilon_{t}-\theta_{1} \varepsilon_{t-1}-\theta_{2} \varepsilon_{t-2}-\cdots-\theta_{q} \varepsilon_{t-q} \quad (*)}$ 
	- 当 $q=0$ 时，它是 $\operatorname{AR}(p)$ 序列
	- 当 $p=0$ 时，它为 $\operatorname{MA}(q)$ 序列
- **算子多项式**：引进**算子多项式** $\varphi(B) = 1 - \varphi_{1}B - \varphi_{2}B^{2} - \cdots - \varphi_{p}B^{p}$，$\theta(B)=1-\theta_{1} B-\theta_{2} B^{2}-\cdots-\theta_{q} B^{q}$，则方程 $(*)$ 可变为 $\varphi(B) X_{t} = \theta(B) \varepsilon_{t}$ 
### 5-1-3 ARMA 模型的平稳性与可逆性
- *结论*：对于一般的平稳序列 $\{X_{t}, t=0,\pm1,\pm2,\cdots\}$，设均值 $E(X_{t})=\mu$，则满足模型 $\boxed{(X_{t} - \mu) - \varphi_{1}(X_{t-1} - \mu) - \cdots - \varphi_{p}(X_{t-p} - \mu) = \varepsilon_{t} - \theta_{1}\varepsilon_{t-1} - \cdots - \theta_{q}\varepsilon_{t-q}\quad (*)}$，其中 $\varepsilon_{t}$ 是均值为 $0$、方差为 $\sigma_{\varepsilon}^{2}$ 的平稳白噪声。
	- 利用后移算子 $\varphi(B), \theta(B)$，$(*)$ 可变为 $\varphi(B) (X_{t} - \mu) = \theta(B) \varepsilon_{t}$ 
- *符号假设*：对于算子多项式 $\varphi(B), \theta(B)$，假定 $\varphi(B)$ 和 $\theta(B)$ 无公共因子，且 $\varphi(B) \neq 0, \theta(B) \neq 0$ 
- **平稳性条件**：利用线性差分方程的稳定性理论可知，$ARMA(p,q)$ 过程的平稳性完全取决于回归参数，而与移动平均参数无关，即对应的 AR$(p)$ 的特征方程 $\lambda^{p} - \varphi_{1} \lambda^{p-1} - \cdots - \varphi_{p} = 0$ 的根在单位圆内。该条件称为模型的**平稳性条件** 
	- 该条件等价于系数方程 $\varphi(B)=0$ 的根全在单位圆外
- **可逆性条件**：$\theta(B)=0$ 的根全在单位圆外，该条件称为模型的可逆性条件。
### 5-1-4 ARMA 模型识别与定阶方法
#### 5-1-4-1 自相关系数、偏自相关系数
- **自相关**、**自相关系数** (**ACF**) $\rho_k$：构成时间序列的每个序列值之间的简单相关关系称为**自相关**，具体的计算公式为 $\rho_{k} = \dfrac{\gamma_{k}}{\gamma_{0}}$。自相关程度是由**自相关系数**来度量的，表示时间序列中间隔 $k$ 的观测值之间的相关程度。
- **偏自相关系数** (**PACF**) $\varphi_{kk}$：所谓**滞后 $k$ 偏自相关系数**就是指在给定中间 $k-1$ 个随机变量 $X_{t-1},X_{t-2},\cdots,X_{t-k+1}$ 的条件下，或者说，在剔除了中间 $k-1$ 个随机变量的干扰之后，$X_{t-k}$ 对 $X_{t}$ 影响的相关度量。即 $\varphi_{kk}=\dfrac{E\left[ \left( X_{t} - \hat{E}X_{t} \right) \left( X_{t-k} - \hat{E}X_{t-k} \right) \right]}{E\left[ \left( X_{t} - \hat{E}X_{t} \right)^{2} \right]}=\dfrac{D_{k}}{D}$，式中 $\hat{E}X_{t}=E\left[ X_{t} \mid X_{t-1}, \cdots, X_{t-k+1} \right],\ \hat{E}X_{t-k}=E\left[ X_{t-k} \mid X_{t-1}, \cdots, X_{t-k+1} \right]$，$D=\left|\begin{array}{cccc} 1 & \rho_{1} & \cdots & \rho_{k-1} \\ \rho_{1} & 1 & \cdots & \rho_{k-2} \\ \vdots & \vdots &  & \vdots \\ \rho_{k-1} & \rho_{k-2} & \cdots & 1 \end{array}\right|,\quad D_{k}=\left|\begin{array}{cccc} 1 & \rho_{1} & \cdots & \rho_{1} \\ \rho_{1} & 1 & \cdots & \rho_{2} \\ \vdots & \vdots &  & \vdots \\ \rho_{k-1} & \rho_{k-2} & \cdots & \rho_{k} \end{array}\right|$ 
	- 自相关系数与偏自相关系数反映 $\operatorname{AR}(p)$，$\operatorname{MA}(q)$ 和 $\operatorname{ARMA}(p,q)$ 模型的固有特征。
	- *结论*：对应于零均值序列 $\{X_{t},t=0,\pm1,\pm2,\cdots\}$，若其为 $\operatorname{AR}(p)$ 序列，则有自相关系数拖尾，偏自相关系数 $p$ 步截尾；若其为 $\operatorname{MA}(q)$ 序列，则有自相关系数 $q$ 步截尾，偏自相关系数拖尾；若其为 $\operatorname{ARMA}(p,q)$ 序列，则有自相关系数拖尾，偏自相关系数也拖尾。
#### 5-1-4-2 ACF、PACF 的计算方法与模型拟合
- 相应观察值序列的样本自相关系数 $\hat{\rho}_{k}$ 的计算公式：$\hat{\rho}_{k} = \dfrac{\sum\limits_{t=1}^{n-k} \left( X_{t} - \bar{X} \right) \left( X_{t+k} - \bar{X} \right)}{\sum\limits_{t=1}^{n} \left( X_{t} - \bar{X} \right)^{2}}$，其中 $\bar{X} = \dfrac{1}{n}\sum\limits_{t=1}^{n} X_{t}$ 
- 相应观察值序列的样本偏自相关系数 $\hat{\varphi}_{kk}$ 的计算公式：$\hat{\varphi}_{kk} = \dfrac{\hat{D}_{k}}{\hat{D}}$，其中 $\hat{D} = \left| \begin{array}{cccc} 1 & \hat{\rho}_{1} & \cdots & \hat{\rho}_{k-1} \\ \hat{\rho}_{1} & 1 & \cdots & \hat{\rho}_{k-2} \\ \vdots & \vdots & \ddots & \vdots \\ \hat{\rho}_{k-1} & \hat{\rho}_{k-2} & \cdots & 1 \end{array} \right|, \quad \hat{D}_{k} = \left| \begin{array}{cccc} 1 & \hat{\rho}_{1} & \cdots & \hat{\rho}_{1} \\ \hat{\rho}_{1} & 1 & \cdots & \hat{\rho}_{2} \\ \vdots & \vdots & \ddots & \vdots \\ \hat{\rho}_{k-1} & \hat{\rho}_{k-2} & \cdots & \hat{\rho}_{k} \end{array} \right|$ 
- 根据样本自相关系数和偏自相关系数的性质，选择适当的 $\operatorname{ARMA}(p,q)$ 模型进行拟合。具体*判断标准*为：
	1. 若 $\hat{\rho}_{k}$ 为 $q$ 阶截尾，则判断 $X_{t}$ 是 $\operatorname{MA}(q)$ 序列
	2. 若 $\hat{\varphi}_{kk}$ 为 $p$ 阶截尾，则判断 $X_{t}$ 是 $\operatorname{AR}(p)$ 序列
	3. 若 $\hat{\rho}_{k}$，$\hat{\varphi}_{kk}$ 都不截尾，而仅仅是以负指数衰减，则可初步认为 $X_{t}$ 是 $\operatorname{ARMA}$ 序列。它的阶数要求由从低阶到高阶逐步增加，再通过检验来确定。
- 在实际数据处理中，要使 $\hat{\rho}_{k}$，$\hat{\varphi}_{kk}$ 在某一步之后全部为 $0$ 几乎是不可能的，而只能是在某一步之后围绕零值上下波动，对于 $\hat{\rho}_{k}$，$\hat{\varphi}_{kk}$ 的截尾性判断借助于统计手段

#### 5-1-4-3 AIC 定阶准则
- 不同判断准则下，初选模型可能有多个，因此一般才能用由低阶向高阶依次探索的方法来识别模型类型及阶数
- 在确定参数估计后，通过检验判断哪个模型适合预测
- **最小信息准则**：便于为模型寻求开始的各个阶数，在模式识别时，为简化定价的过程，常采用**最小信息准则** 
	- 目前较为常用的最小信息准则是：赤池提出的 **AIC 准则**、**SC 准则**、**HQ 准则** 
- **AIC 准则**：$ARMA(p,q)$ 序列的 AIC 定阶准则为：选取 $p,q$ 使得 $\min \ \mathrm{AIC} = n \ln \hat{\sigma}_{\varepsilon}^{2} + 2(p + q + 1)$，其中 $n$ 为样本数目，$\hat{\sigma}_{\varepsilon}^{2}$ 为 $\sigma_{\varepsilon}^{2}$ 的估计，$\ln \hat{\sigma}_{\varepsilon}^{2}$ 为对数似然函数，使函数达到最小的 $p,q$ 即为模型的阶
### 5-1-5 模型的参数确定
- $ARMA(p,q)$ 模型的参数估计有**矩估计**、**最大似然估计**、**最小二乘估计**等
- **最小二乘估计** 
	在 $ARMA(p,q)$ 模型场中，记 $\tilde{\beta} = (\varphi_{1}, \cdots, \varphi_{p}, \theta_{1}, \cdots, \theta_{q})^{T}$，$F_{t}(\tilde{\beta}) = \varphi_{1}X_{t-1} + \cdots + \varphi_{p}X_{t-p} - \theta_{1}\varepsilon_{t-1} - \cdots - \theta_{q}\varepsilon_{t-q}$，残差项为 $\varepsilon_{t}=X_{t}-F_{t}\left( \tilde{\beta} \right)$，残差平方和为 $Q\left( \tilde{\beta} \right) = \sum\limits_{i=1}^{n} \varepsilon_{t}$ 
	最常用的方法是条件最小二乘估计方法，假定过去未观测到的序列值等于零，即 $X_{t}=0$, $t \leqslant 0$ 
	根据这个假定可得残差序列的有限表达式 $\varepsilon_{t}=\dfrac{\Phi(B)}{\theta(B)} X_{t} = X_{t} - \sum\limits_{i=1}^{t} \pi_{i} X_{t-i}$ 
	于是残差平方和为 $Q\left( \widetilde{\beta} \right) = \sum\limits_{i=1}^{n} \left( \dfrac{\Phi(B)}{\theta(B)} X_{t} \right)^{2}$ 
	通过运用迭代法，使 $Q\left( \tilde{\beta} \right)$ 达到最小值的估计值，即为参数 $\beta$ 的条件最小二乘估计。
### 5-1-6 模型的检验及优化
- 在定阶与参数估计后，需对建立的模型进行检验。其基本的做法是检验模型误差 $\varepsilon_{t}$ 是否为白噪声。
	- 若检验认为 $\varepsilon_{t}$ 是白噪声，则建模获得通过，否则拟合模型通过不过检验，此时需转向 5-14，重新进行定阶，再进行参数估计，更新选择模型拟合。
	- 在 Eviews 软件中，利用统计量 $p$ 来检验模型的有效性，当 $p < \alpha$ 时，残差序列不为白噪声序列，反之则为白噪声序列。
- **$\chi^{2}$ 检验** 
	若拟合模型的残差记为 $\hat{\varepsilon}_{t}$，它是 $\varepsilon_{t}$ 的估计。以 $\mathrm{AR}(p)$ 序列为例进行说明。
	设未知参数的估计是 $\hat{\varphi}_{1}, \hat{\varphi}_{2}, \cdots, \hat{\varphi}_{p}$，则残差 $\hat{\varepsilon}_{t} = X_{t} - \hat{\varphi}_{1} X_{t-1} - \cdots - \hat{\varphi}_{p} X_{t-p},\ t = 1, 2, \cdots, p$ 
	设 $X_{0} = X_{-1} = \cdots = X_{1-p} = 0$，记 $\eta_{k} = \dfrac{ \sum\limits_{t=1}^{n-k} \hat{\varepsilon}_{t} \hat{\varepsilon}_{t+k}}{\sum\limits_{t=1}^{n} \hat{\varepsilon}_{t}^{2}},\ k = 1, 2, \cdots, m$ 
	Ljung-Box 的 $\chi^{2}$ 检验统计量是 $n(n+2) \sum\limits_{k=1}^{m} \dfrac{\eta_{k}^{2}}{n-k} \sim \chi^{2}(m-p)$ 
	检验的假设是：$H_{0}: \rho_{k} = 0$，当 $k \leqslant m$；$H_{1}$：对某些 $k \leqslant m$，$\rho_{k} \neq 0$ 
	在 $H_{0}$ 成立时，若 $n$ 充分大，则 $\chi^{2}$ 近似于 $\chi^{2}(m - r)$ 分布，其中 $r$ 是估计的模型参数个数。
	$\chi^{2}$ 检验法：给定显著性水平 $\alpha$，查表得 $\alpha$ 分位数 $\chi^{2}_{\alpha}(m - r)$，则当 $\chi^{2} > \chi^{2}_{\alpha}(m - r)$ 时拒绝 $H_{0}$，即认为 $\varepsilon_{t}$ 是非白噪声，模型检验未通过；而当 $\chi^{2} \leqslant \chi^{2}_{\alpha}(m - r)$ 时，接受 $H_{0}$，认为 $\varepsilon_{t}$ 是白噪声，模型检验通过。
	若实际序列是 $\operatorname{ARMA}(p,q)$ 序列，应对各种可能的 $p,q$ 值计算其 $\mathrm{AIC}$。选取 $\mathrm{AIC}$ 达到的最小值，才能求得较优的阶 $p$ 和 $q$。
## 5-2 非平稳序列建模
### 5-2-1 ARIMA 模型的结构
#### 5-2-1-1 $d$ 阶差分的表示
- $d$ 阶差分后序列可以表示为 $\nabla^{d} X_{t} = \sum\limits_{i=1}^{d} (-1)^{i} C_{d}^{i} X_{t-i}$，式中 $C_{d}^{i} = \dfrac{d!}{i!(d-i)!}$，即差分后序列等于原序列的若干序列值的加权和，而对它又可以拟合自动回归移动平均 (ARMA) 模型
#### 5-2-1-2 $\operatorname{ARIMA}(p,d,q)$ 模型
- **求和自回归移动平均模型** (**Autoregressive Integrated Moving Average**, $\operatorname{ARIMA}(p,d,q)$ 模型)、**自回归系数多项式**、**移动平滑系数多项式**：具有如下结构的模型称为**求和自回归移动平均模型** (**Autoregressive Integrated Moving Average**, $\operatorname{ARIMA}(p,d,q)$ 模型)：$\left\{ \begin{array}{l} \Phi(B) \nabla^{d} X_{t} = \Theta(B) \varepsilon_{t} \\ E\left( \varepsilon_{t} \right) = 0,\ \operatorname{Var}\left( \varepsilon_{t} \right) = \sigma^{2},\ E\left( \varepsilon_{t} \varepsilon_{s} \right) = 0, \ s \neq t \\ E\left( X_{s} \varepsilon_{t} \right) = 0,\ \forall\ s < t \end{array} \right.$。式中 $\nabla^{d} = (1 - B)^{d}$，称 $\Phi(B) = 1 - \phi_{1}B - \cdots - \phi_{p}B^{p}$ 为平稳可逆 $\operatorname{ARMA}(p,q)$ 模型的**自回归系数多项式**，称 $\Theta(B) = 1 - \theta_{1}B - \cdots - \theta_{q}B^{q}$ 为平稳可逆 $\operatorname{ARMA}(p,q)$ 模型的**移动平滑系数多项式**。
	- $ARIMA(p,d,q)$ 模型可以简记为 $\nabla^{d} X_{t} = \dfrac{\Theta(B)}{\Phi(B)} \varepsilon_{t}$，式中 $\{\varepsilon_{t}\}$ 为零均值白噪声序列。
	- 由 $\nabla^{d} X_{t} = \dfrac{\Theta(B)}{\Phi(B)} \varepsilon_{t}$ 易见，$\operatorname{ARIMA}$ 模型的实质就是差分运算与 $\operatorname{ARMA}$ 模型的组合。这一关系意义重大，这说明非平稳序列只要通过适当阶数的差分运算实现差分后平稳，就可以对差分后序列进行 $\operatorname{ARMA}$ 模型拟合了。而 $\operatorname{ARMA}$ 模型的分析方法非常成熟，这意味着对差分平稳序列的分析非常简单可靠。
- 对于模型中的 $p,d,q$，特别地：
	- 当 $d = 0$ 时，$\operatorname{ARIMA}(p,d,q)$ 模型实际上就是 $\operatorname{ARMA}(p,q)$ 模型；
	- 当 $p = 0$ 时，$\operatorname{ARIMA}(0,d,q)$ 模型可以简记为 $\operatorname{IMA}(d,q)$ 
	- 当 $q = 0$ 时，$\operatorname{ARIMA}(p,d,0)$ 模型可以简记为 $\operatorname{ARI}(p,d)$ 
- **随机游走 (Random Walk) 模型**：特别地，当 $d=1$，$p=q=0$ 时，$\operatorname{ARIMA}(0,1,0)$ 模型为 $\left\{\begin{array}{l} X_{t}=X_{t-1}+\varepsilon_{t} \\ E\left( \varepsilon_{t} \right)=0,\ \operatorname{Var}\left( \varepsilon_{t} \right)=\sigma^{2}, \ E\left( \varepsilon_{t} \varepsilon_{s} \right)=0, \ s \neq t \\ E\left( X_{s} \varepsilon_{t} \right)=0\ \forall\ s<t \end{array}\right.$，该模型被称为**随机游走 (Random Walk) 模型** 

### 5-2-2 ARIMA 建模
#### 5-2-2-1 ARIMA 模型预测
- $\operatorname{ARIMA}(p,d,q)$ 模型的一般表示方法为 $\varPhi(B)(1-B)^{d} X_{t} = \Theta(B) \varepsilon_{t}$ 
- *问题*：在时间点 $t$ 已知 $\{X_t, X_{t-1}, \cdots\}$ 和对应的 $\{ \varepsilon_t, \varepsilon_{t-1}, \cdots \}$，如何预测未来值 $X_{t+l}$？
	和 $\operatorname{ARMA}$ 模型一样，也可以用历史观测值的线性函数表示，记 $X_{t} = \varepsilon_{t} + \varPsi_{1} \varepsilon_{t-1} + \varPsi_{2} \varepsilon_{t-2} + \cdots = \varPsi(B) \varepsilon_{t}$，式中，$\varPsi_{1}, \varPsi_{2}, \cdots$ 的值由如下等式 $\varPhi(B)(1-B)^{d} \varPsi(B) = \Theta(B)$ 确定
	记 $\Phi^{*}(B)=\Phi(B)(1-B)^{d}=1-\phi_{1}B-\phi_{2}B^{2}+\cdots$ 
	容易验证 $\varPsi_{1}, \varPsi_{2}, \cdots$ 的值满足如下递推公式
	$$
	\left\{\begin{array}{l}
	\varPsi_{1}=\phi_{1}-\theta_{1}, \\
	\varPsi_{2}=\phi_{1} \varPsi_{1}+\phi_{2}-\theta_{2}, \\
	\cdots\cdots \\
	\varPsi_{j}=\phi_{1} \varPsi_{j-1}+\cdots+\phi_{p+q} \varPsi_{j-p-d}-\theta_{j},
	\end{array}\right.
	$$
	式中 $\theta_{j}=0, \ j>q; \ \varPsi_{j}=\left\{\begin{array}{ll} 0, & j<1 \\ 1, & j=0 \end{array}\right.$ 
	那么，$X_{t+l}$ 的真实值为 $X_{t+l}=(\varepsilon_{t+l}+\varPsi_{1}\varepsilon_{t+l-1}+\cdots+\varPsi_{l-1}\varepsilon_{t+1})+(\varPsi_{l}\varepsilon_{t}+\varPsi_{l+1}\varepsilon_{t-1}+\cdots)$ 
	由于 $\varepsilon_{t+l}, \varepsilon_{t+l-1}, \cdots, \varepsilon_{t+1}$ 的不可获得性，因此 $X_{t+l}$ 的估计值只能为 $\hat{x}(l)=\varPsi_{0}^{*}\varepsilon_{t}+\varPsi_{1}^{*}\varepsilon_{t-1}+\varPsi_{2}^{*}\varepsilon_{t-2}+\cdots$ 
	真实值和预报值之间的均方误差为 $E\left[ x_{t+l} - \hat{x}_{t}(l) \right]^{2} = \left( 1 + \varPsi_{1}^{2} + \cdots + \varPsi_{t-1}^{2} \right) \sigma^{2} + \sum\limits_{j=0}^{\infty} \left( \varPsi_{l+j} - \varPsi_{j}^{*} \right)^{2} \sigma^{2}$ 
	要使均方误差最小，当且仅当 $\varPsi_{j}^{*} = \varPsi_{l+j}$ 
	所以，在均方误差最小的原则下，$l$ 期的预报值为 $\hat{x}_{t}(l) = \varPsi_{l} \varepsilon_{t} + \varPsi_{l+1} \varepsilon_{t-1} + \varPsi_{l+2} \varepsilon_{t-2} + \cdots$ 
	$l$ 期的预报误差为 $e_{t}(l) = \varepsilon_{t+l} + \varPsi_{1} \varepsilon_{t+l-1} + \cdots + \varPsi_{l-1} \varepsilon_{t+1}$ 
	真实值等于预报值加上预报误差
	$$
	\begin{aligned}
	X_{t+l} &= \left( \varPsi_{l} \varepsilon_{t} + \varPsi_{l+1} \varepsilon_{t-1} + \varPsi_{l+2} \varepsilon_{t-2} + \cdots \right) + \left( \varepsilon_{t+1} + \varPsi_{1} \varepsilon_{t+l-1} + \cdots + \varPsi_{l-1} \varepsilon_{t+1} \right) \\
	&= \hat{x}_{t}(l) + e_{t}(l)
	\end{aligned}
	$$
	$l$ 期预报的方差为 $\operatorname{Var}[e_t(l)] = (1 + \varPsi_1^2 + \cdots + \varPsi_{t-1}^2)\sigma^2$
