# 4 随机性模型
## 4-1 马氏链模型
### 4-1-0 前言
- **无后效性**、**马尔可夫 (Markov) 性**、**马氏性**：在考虑一个做随机运动的动态系统时，经常会遇到这样的情况：系统在每个时刻所处的状态是随机的，从这个时刻到下个时刻的状态按照一定的概率进行转移，并且在下个时刻，系统处于哪个状态，只取决于这个时刻的状态和转移概率，与该时刻以前系统所处的状态无关。这种性质称为**无后效性**，或**马尔可夫 (Markov) 性**，简称**马氏性** 
	- 通俗地讲，就是在已知“现在”的条件下，“将来”与“过去”无关。
- **马氏过程**：一般我们把具有马尔可夫性的随机过程称为**马氏过程** 
	- 马氏过程是一类广泛适用于各种领域的重要的随机过程
- **马尔科夫链** (**Markov Chain**, **马氏链**)：具有离散时间，状态为有限或可数的马尔可夫过程，称为离散参数**马尔可夫链** (**Markov Chain**)，简称**马氏链** 
### 4-1-1 马氏链的基本概念
- **马氏链**：一随机过程 $\{X_{n}, n \geqslant 0\}$ 称为一个**马氏链**，如果 $X_{n} \in S\ (n = 0, 1, 2, \cdots)$，其中 $S$ 为一个有限或可数集合（称为马**氏链的状态空间**），并且对任意的 $i, j, i_{0}, i_{1}, \cdots, i_{n-1} \in S$ 都有 $P(X_{n+1} = j \mid X_{0} = i_{0}, X_{1} = i_{1}, \cdots, X_{n-1} = i_{n-1}, X_{n} = i) = P(X_{n+1} = j \mid X_{n} = i)$ 
	- 马氏链表明：如果过程在时刻 $n$ 处于状态 $i$，则不管它以前处于什么状态，过程下一时刻处于状态 $j$ 的概率都是 $p_{ij}(n)$，即在已知“现在”的条件下，“将来”与“过去”无关。
- **一步转移概率**（**转移概率**）：称 $P(X_{n+1} = j \mid X_{n} = i)$ 为马氏链的**一步转移概率**（简称**转移概率**），记为 $p_{ij}(n)$ 
- **齐次**：若 $p_{ij}(n)$ 与 $n$ 无关，则称此马氏链为**齐次**的。
	- 在这一节，我们只讨论齐次马氏链。
- **转移概率矩阵**：对齐次马氏链 $\{X_{n}, n \geqslant 0\}$，描述它的变化进程的最重要的量就是它的转移概率 $\{p_{ij}, i, j \in S\}$，通常我们把它们写成矩阵的形式，记为 $P = (p_{ij})$，称 $P$ 为马氏链的**转移概率矩阵** 
- *例 1*（**无限制随机游动**）：考虑在直线上做随机游动的质点，如果某个时刻质点位于 $i$，则在下一步质点以概率 $p$ 向右移动一格到 $i+1$，而以概率 $q=1-p$ 向左移动一格到 $i-1$。若以 $X(n)$ 表示时刻 $n$ 质点的位置，那么 $\{X(n),n=0,1,\cdots\}$ 是一个随机过程，而且当 $X(n)=i$ 时，$X(n+1),X(n+2),\cdots,X(n+k)$ 等以后的行为只与 $X(n)=i$ 有关，而与质点在 $n$ 以前是如何到达 $i$ 是完全无关的，所以它是一个马氏链，而且还是齐次的，其状态空间 $S=\{\cdots,-2,-1,0,1,2,\cdots\}$，一步转移概率为 $p_{i,i+1}=p,\ p_{i,i-1}=q=1-p,\ i\in S$，其中 $0 \leqslant p \leqslant 1$，其他的 $p_{ij}$ 都等于 0 
- *例 2*（**带有一个吸收壁的随机游动**）：考虑随机游动，其状态空间 $S=\{0,1,\cdots\}$，而且一旦 $X(n)=0$ 以后，$X(n+1)$ 也就停留在 0 这个状态上，这样的状态称为吸收状态，仿照例1可证明：$\{X(n),n\geqslant 0\}$ 也是一个齐次马氏链，它的一步转移概率为 $p_{i,i+1}=p,\ p_{i,i-1}=q=1-p,\ i\geqslant 1,\ p_{00}=1$ 
	- 在本例中，$0$ 正好又是状态空间的端点（壁），所以称这一随机游动为**带有一个吸收壁的随机游动** 
- *例 3*（**离散分支过程**）：考虑某一群体，用 $X(n)$ 表示第 $n$ 代中个体的数目，假定某一代的每一个个体可产生 $Y$ 个下一代个体，其中 $Y$ 是一个取非负整数值的离散型随机变量 $P\{Y = k\} = p_{k}, \ k = 0, 1, \cdots$，并设某一代中各个个体产生下一代的个数相互独立，则有 $X(n+1) = Y_{1} + Y_{2} + \cdots + Y_{X(n)}$，其中 $\{Y_{i}\}$ 是相互独立且与 $Y$ 同分布的随机变量。由此可见，只要知道了 $X(n)$，那么 $X(n+1)$ 的分布就完全决定了，而与以前的代的个数 $X(n-1)$，$X(n-2)$，$\cdots$ 无关，从而是一个马氏链。称该马氏链为**离散的分支过程**。
### 4-1-2 马氏链的基本性质
- **$k$ 步转移概率**：令 $p_{ij}^{(k)}(m) = P\{X(m+k) = j \mid X(m) = i\}, \ i, j \in S, k \geqslant 1$，我们称 $p_{ij}^{(k)}(m)$ 为时刻 $m$ 的 **$k$ 步转移概率**。
- **定理 1**（**Chapman-Kolmogrov 方程**）：设 $\{X(n), n \geqslant 0\}$ 为马氏链，其状态空间为 $S$，则对于任意 $i, j \in S$，有 $p_{ij}^{(k+l)}(m) = \sum\limits_{r \in S} p_{ir}^{(k)}(m) p_{rj}^{(l)}(m+k)$ 
	- *证明过程* 
		$$
		\begin{aligned}
		p_{ij}^{(k+l)}(m) &= P\{X(m + k + l) = j \mid X(m) = i\} \\
		&= P\left\{X(m + k + l) = j, \bigcup\limits_{r \in S} \{X(m + k) = r\} \mid X(m) = i\right\} \\
		&= \sum\limits_{r \in S} P\{X(m + k + l) = j, X(m + k) = r \mid X(m) = i\} \\
		&= \sum\limits_{r \in S} P\{X(m + k) = r \mid X(m) = i\} \cdot P\{X(m + k + l) = j \mid X(m + k) = r, X(m) = i\} \\
		&= \sum\limits_{r \in S} P\{X(m + k) = r \mid X(m) = i\} \cdot P\{X(m + k + l) = j \mid X(m + k) = r\} \\
		&= \sum\limits_{r \in S} p_{ir}^{(k)}(m) p_{rj}^{(l)}(m + k).
		\end{aligned}
		$$
		证毕！
- **推论**：若 $\{X(n), n \geqslant 0\}$ 为齐次马氏链，$P = (p_{ij})$ 为一步转移概率矩阵，则 $p_{ij}^{(k+l)} = \sum\limits_{r \in S} p_{ir}^{(k)} p_{rj}^{(l)}$，其中 $S$ 为马氏链 $\{X(n), n \geqslant 0\}$ 的状态空间。
	- **性质**：由一步转移概率矩阵，可以决定两步转移概率矩阵，反复应用上述作法，得到：由一步转移概率，可以决定所有的高阶转移概率。
- **定理**：若马氏链 $\{X_{n}, n \geqslant 0\}$ 的初始分布为 $P\{X_{0} = i\} = p_{i}$，其转移率矩阵为 $P = (p_{ij})$，则 $\{X_{n}, n \geqslant 0\}$ 的有限维分布为 $P\{X_{0} = i_{0}, X_{1} = i_{1}, \cdots, X_{n} = i_{n}\} = p_{i_{0}} \cdot p_{i_{0}i_{1}} \cdot p_{i_{1}i_{2}} \cdots p_{i_{n-1}i_{n}},\ \forall\ i_{0}, i_{1}, \cdots, i_{n} \in S$
	- *证明过程* 
		由乘法公式与马氏性可知：
		$$
		\begin{aligned}
		& P\{X_{0} = i_{0}, X_{1} = i_{1}, X_{2} = i_{2}, \cdots, X_{n} = i_{n}\} \\
		&= P\{X_{0} = i_{0}\} P\{X_{1} = i_{1} \mid X_{0} = i_{0}\} P\{X_{2} = i_{2} \mid X_{1} = i_{1}, X_{0} = i_{0}\} \cdots \\
		&\quad \cdot P\{X_{n} = i_{n} \mid X_{n-1} = i_{n-1}, \cdots, X_{0} = i_{0}\} \\
		&= p_{i_{0}} p_{i_{0}i_{1}} p_{i_{1}i_{2}} \cdots p_{i_{n-1}i_{n}}
		\end{aligned}
		$$
		证毕！
	- 该定理说明：一个马氏链可由其初始状态 $X_{0}$（或其初始分布 $P\{X_{0} = i\} = p_{i}$）以及其转移概率矩阵 $P$ 所完全确定。
	- *注意*：一般来说，从 $P=(p_{ij})$ 出发，要求出 $P^n$ 的明显表达式，可能十分困难
### 4-1-3 马氏链的状态分类
- *前言*：在马氏链的研究中，虽然我们经常无法求出 $P^n$ 的表达式，但是我们仍然可以研究，当步数 $n\to\infty$ 时，马氏链到达各状态的统计规律，即 $P^n$ 的极限
- **可达**（$i\to j$）、**互通**（$i \leftrightarrow j$）：设 $i, j$ 为马氏链 $\{X_{n}, n \geqslant 0\}$ 的两个状态，若存在 $n \geqslant 1$，使 $p_{ij}^{(n)} > 0$，则称自**状态 $i$ 可达状态 $j$**，记为 $i \to j$。若 $i \to j, j \to i$ 则称**状态 $i$ 和 $j$ 是互通的**，记为 $i \leftrightarrow j$ 
- **定理 3**：若 $i \to k, k \to j$，则 $i \to j$ 
	- *证明过程* 
		若 $i \to k, k \to j$，则存在 $l \geqslant 1, r \geqslant 1$ 使得 $p_{ik}^{(l)} > 0, p_{kj}^{(r)} > 0$ 
		而 $p_{ij}^{(l+r)} = \sum\limits_{m \in S} p_{im}^{(l)} p_{mj}^{(r)} \geqslant p_{ik}^{(l)} \cdot p_{kj}^{(r)} > 0$，故 $i \to j$ 
	- **推论**：若 $i \to k_{1}, k_{1} \to k_{2}, \cdots, k_{n} \to j$，则 $i \to j$ 
	- **推论**：若 $i \to k_{1}, k_{1} \leftrightarrow k_{2}, \cdots, k_{n} \leftrightarrow j$，则 $i \to j$ 
- $T_{ij}$：对于任意两个状态 $i$ 和 $j$，在事件 $\{X_{0}=i\}$ 上引入随机变量 $T_{ij} \triangleq \min \{n: X_{0}=i, X_{n}=j, n \geqslant 1\}$ 
	- *定义理解*：$T_{ij}$ 表示从状态 $i$ 出发，首次进入状态 $j$ 的时刻
	- 对 $\omega \in \{X_{0} \neq i\}$ 或 $\omega \in \{X_{0}=i, X_{n} \neq j, n \geqslant 1\}$，我们定义 $T_{ij}(\omega) = +\infty$ 
- $f_{ij}^{(n)}$：令 $f_{ij}^{(n)} \triangleq P\left\{ T_{ij} = n \mid X_{0} = i \right\}$，$f_{ij}^{(n)}$ 表示系统自状态 $i$ 出发，经 $n$ 步首次到达状态 $j$ 的概率
	- *定义理解*：$f_{ij}^{(n)} = P\left\{ X_{n} = j; X_{m} \neq j, m = 1, 2, \cdots, n-1 \mid X_{0} = i \right\}$
- $f_{ij}$：令 $f_{ij} = \sum\limits_{n=1}^{\infty} f_{ij}^{(n)} = \sum\limits_{n=1}^{\infty} P\left\{ T_{ij} = n \right\} = P\left\{ T_{ij} < \infty \right\}$ 
	- *定义理解*：则 $f_{ij}$ 表示系统自状态 $i$ 出发，迟早要到达状态 $j$ 的概率
	- **性质**：$0 \leqslant f_{ij}^{(n)} \leqslant f_{ij} \leqslant 1$ 
- **定理 4**：$p_{ij}^{(n)}=\sum\limits_{l=1}^{n}f_{ij}^{(l)}p_{jj}^{(n-l)}$  
	- *证明过程*
		$$
		\begin{aligned}
		p_{ij}^{(n)}&=P\{X_{n}=j\mid X_{0}=i\}\\
		&=P\{T_{ij}\leqslant n,X_{n}=j\mid X_{0}=i\}\\
		&=\sum\limits_{l=1}^{n}P\{T_{ij}=l,X_{n}=j\mid X_{0}=i\}\\
		&=\sum\limits_{l=1}^{n}P\{T_{ij}=l\mid X_{0}=i\}P\{X_{n}=j\mid X_{0}=i,T_{ij}=l\}\\
		&=\sum\limits_{l=1}^{n}P\{T_{ij}=l\mid X_{0}=i\}P\{X_{n}=j\mid X_{l}=j\}\\
		&=\sum\limits_{l=1}^{n}f_{ij}^{(l)}p_{jj}^{(n-l)}
		\end{aligned}
		$$
		证毕！
- **定理 5**：$f_{ij}>0$ $\iff$ $i \to j$ 
	- *证明过程* 
		**充分性** 
		若 $i \rightarrow j$，则存在 $n \geqslant 1$ 使 $p_{ij}^{(n)}>0$ 
		又因为 $p_{ij}^{(n)} = \sum\limits_{l=1}^{n} f_{ij}^{(l)} p_{jj}^{(n-l)} > 0$，所以 $f_{ij}^{(1)}, f_{ij}^{(2)}, \cdots, f_{ij}^{(n)}$ 中至少有一个大于零。
		而 $f_{ij} = \sum\limits_{l=1}^{\infty} f_{ij}^{(l)}$，故 $f_{ij}>0$ 
		充分性证毕！
		**必要性** 
		若 $f_{ij}>0$，则由于 $f_{ij} = \sum\limits_{n=1}^{\infty} f_{ij}^{(n)}$，所以存在 $n \geqslant 1$ 使 $f_{ij}^{(n)}>0$ 
		又因为 $p_{ij}^{(n)} \geqslant f_{ij}^{(n)}>0$，所以 $i \rightarrow j$ 
		必要性证毕！
	- **推论**：$f_{ij}>0, f_{ji}>0$ $\iff$ $i\leftrightarrow j$ 
	- 当 $i=j$ 时，$T_{ii}$ 便是从状态 $i$ 出发，首次返回到状态 $i$ 的时刻，$f_{ii}$ 是从状态 $i$ 出发，在有限步内迟早要返回状态 $i$ 的概率。
- **常返**、**非常返**：若 $f_{ii}=1$，则称状态 $i$ 是**常返**的；若 $f_{ii}<1$，则称状态 $i$ 是**非常返**的。
	- **性质**：若状态 $i$ 是常返的，则以概率 $1$，系统将无穷次返回状态 $i$；若 $i$ 为非常返状态，则系统将以概率 $1$，有限次返回状态 $i$ 
- **平均返回时间**：对于常返状态 $i$，我们引入平均返回时间 $\mu_{i} = \sum\limits_{n=1}^{\infty} n \cdot f_{ii}^{(n)}$ 
- **正常返**、**零常返**：设 $i$ 为马氏链 $\{X_{n}: n \ge 0\}$ 的常返状态，若 $\mu_{i}<\infty$，则称状态 $i$ 为**正常返**的；若 $\mu_{i}=\infty$，则称状态 $i$ 为**零常返**的。
- **定理 6**：状态 $i$ 为常返的 $\iff$ $\sum\limits_{n=1}^{\infty} p_{ii}^{(n)}=\infty$ 
	- 该定理为状态 $i$ 为常返的判别准则
- **周期的**、**非周期的**：称状态 $i$ 是**周期**为 $t\ (t>1)$ 的，若 $p_{ii}^{(n)}$ 除 $n= t,2t,3t,\cdots$ 外均为零，但没有比 $t$ 更大的 $t'$ 使 $p_{ii}^{(n)}$ 除 $n= t',2t',3t',\cdots$ 外均为零；当满足上述条件的 $t$ 不存在时，称状态 $i$ 为**非周期**的。
- **遍历状态**：非周期的正常返状态，称为**遍历状态** 
- **定理 7**：若状态 $i$ 是遍历状态，则 $\lim\limits_{n \rightarrow \infty} p_{ii}^{(n)} = \dfrac{1}{\mu_{i}}$；若 $i$ 是周期为 $t$ 的正常返状态，则 $\lim\limits_{n \rightarrow \infty} p_{ii}^{(nt)} = \dfrac{t}{\mu_{i}}$，其中 $\mu_i$ 为状态 $i$ 的平均返回时间
- **定理 8**：若 $i \leftrightarrow j$，则
	(i) 状态 $i$ 和 $j$ 或同为非常返，或同为常返；在后一情形，或同时为零常返或同为正常返；
	(ii) 状态 $i$ 和 $j$ 或同为非周期的，或同为周期的；在后一情形，它们有相同的周期。
### 4-1-4 马氏链的转移概率的极限性质——极限概率分布
- **不可约的**：若马氏链 $\{X_{n}, n \ge 0\}$ 的所有状态两两互通，则称此链是**不可约的** 
- **定理 9**：设马氏链 $\{X_{n}, n \ge 0\}$ 的状态空间 $S = \{1, 2, \cdots, m\}$ 为一个有限集，转移概率矩阵 $P = (p_{ij})_{m \times m}$，若该马氏链是非周期、不可约的，则 $\lim\limits_{n \to \infty} p_{ij}^{(n)} = p_{j}$，$p_{j}$ 与 $i$ 无关，并且 $p_{1}, p_{2}, \cdots, p_{m}$ 是方程组 $\left( \pi_{1}, \pi_{2}, \cdots, \pi_{m} \right) = \left( \pi_{1}, \pi_{2}, \cdots, \pi_{m} \right) P$ 在 $\pi_{j} > 0$ 及 $\sum\limits_{j=1}^{m} \pi_{j} = 1$ 条件下的唯一解。
## 4-2 排队论模型
### 4-2-1 排队模型的组成和特征
- **顾客**、**服务员**：在描述各种排队问题时，排队论把所有要求服务的对象均称为**顾客**；顾客要求使用某类设备或取得某种服务，所涉及的每件设备或每个提供服务者，不论是人还是物，都称为**服务员** 
- *一个排队系统通常的工作方式*：当一个顾客到来时，若服务员是空闲的，则服务员立即为顾客服务，当服务完成以后，服务员或者休息等待新顾客的到来，或者为正在排队等待的顾客服务；当一个来到的顾客发现没有空闲服务员时，该顾客必须马上作出决定，例如加入等待的队列，或者立即离开。
- *一般的排队系统由三个基本部分组成*：**输入过程**、**排队规则**、**服务机制** 
- **输入过程**（**顾客到达过程**）：输入过程也称**顾客到达过程**，输入过程是用来描述顾客到达的规律。
	- 顾客源可以是有限的，也可以是无限的
	- 顾客的到来方式可以是一个一个的，也可能是成批的
	- 顾客的到达是相互独立的
	- 顾客相继到达的时间间隔可以是确定型的，也可以是随机的
	- 顾客相继到达的时间间隔分布，与时间无关
- **排队规则**：排队规则一般有**等待制**和**即时制**两种 
	- **等待制**：当所有服务员都不空闲时，顾客便排队等待服务。
		- 等待制的服务规则有先到先服务、后到先服务、随机服务、有优先权的服务等。
		- 排队可以是有形的，也可以是无形的
		- 排队容量可以是有限的，也可以是无限的
		- 排队数目可以是单列，也可以是多列，有的可以是相互转移，有的不可相互转移
	- **即时制**：一旦所有服务员忙碌，顾客便随即离去
- **服务机制**：指服务员的数目、服务时间和服务方式。
	- 服务员的数目可以是一个，也可以是多个
	- 一个服务系统对顾客可以逐个服务，也可成批服务
	- 服务员为每一个顾客服务的时间可以是确定的，也可以是随机的，对于随机型的，一般假定每个顾客所需的服务时间是独立同分布的随机变量
	- 服务时间的分布对时间是平稳的，即分布均值、方差等参数都与时间无关，都不受时间的影响。
- *注意*：对于一个实际问题建立排队论模型，首先要明确给定以上三方面内容，在此基础上，或者可以对模型进行理论分析（例如，研究队列长度、顾客等待时间、服务员工作强度等），或者可以对排队系统进行模拟
- *排队论的主要任务*：建立数学模型来描述排队系统的概率规律性，研究排队顾客的平均数、顾客平均的等待时间、服务员平均接待的顾客等数量规律，为系统的最优设计与最优控制提供决策依据
### 4-2-2 排队模型的标准形式
- **排队模型的标准形式**：$X/Y/Z/A/B/C$，其中 $X$ 表示相继到达间隔时间的分布，$Y$ 表示服务时间的分布，$Z$ 表示并列的服务台的个数，$A$ 表示系统的容量限制，$B$ 表示顾客源数目，$C$ 表示服务规则
- $X$ 和 $Y$ 通常有以下*几种情形*：
	- $M$ (**Markov**)：指数分布（指数分布具有无记忆性，即 **Markov** 性）
	- $D$ (**Deterministic**)：确定型分布
	- $E_k$ (**Erlang**)：$k$ 阶埃尔朗分布
	- $GI$ (**General Independent**)：一般相互独立的时间间隔分布
	- $G$ (**General**)：一般服务时间的分布
- *例子*：$M/M/1$ 表示相继到达间隔时间为指数分布、服务时间为指数分布、单服务台的模型
- $C$ 通常有以下*几种情形*：**先到先服务** (**FCFS**)、**后到先服务** (**LCFS**)、**随机服务**等。
	- *注*：在本章中，我们只考虑先到先服务 (FCFS)
### 4-2-3 排队系统运行的数量指标
-  研究排队问题的*目的*：主要是研究其运行的效率，估计服务质量，确定系统参数的最优值，以确定系统结构是否合理、研究设计改进措施等
- 研究排队问题的*方法*：研究排队问题，首先要确定用以判断系统运行优劣的基本数量指标，然后求出这些指标的概率分布和数字特征。
- *排队系统的主要数量指标*：
	1. **队长**：系统中的顾客数，其期望值记作 $L_s$ 
	2. **排队长**：系统中排队等待服务的顾客数，其期望值记作 $L_q$ 
		- *注*：$L_s$ 或 $L_q$ 越大，说明服务效率越低
	3. **逗留时间**：一个顾客在系统中的停留时间，其期望值记作 $W_s$ 
	4. **等待时间**：一个顾客在系统中排队等待的时间，其期望值记作 $W_q$ 
		- *注*：逗留时间 = 等待时间 + 服务时间
	5. **忙期**：服务机构连续工作的时间长度；
		- 该指标关系到服务员的工作强度
		- 忙期和一个忙期平均完成服务的顾客数，是衡量服务机构效率的重要指标
	6. **损失率**：由于即时制或排队系统条件的限制，使顾客被拒绝服务而使服务机构受到损失的概率
### 4-2-4 系统的状态
- **系统的状态**：指系统中顾客的数量。若系统中有 $n$ 个顾客，则称系统的状态为 $n$ 
	- 当队长无限制时，则 $n = 0, 1, \cdots$ 
	- 当队长有限制，且最大值为 $N$ 时，则 $n=0,1,\cdots,N$ 
	- 当服务台个数为 $c$，且服务为即时制时，则 $n=0,1,\cdots, c$ 
- $p_n(t)$：一般说来，状态的取值与时间 $t$ 有关，因此在时刻 $t$ 状态取值 $n$ 的概率记为 $p_n(t)$ 
- **稳态解**（**统计平衡状态解**）：若 $\lim\limits_{t\to\infty} p_n(t) = p_n$，则称为**稳态解**（或**统计平衡状态解**）
	- 稳态的含义是，当系统运行了无限长的时间后，初始 $(t=0)$ 出发状态的概率分布 $(p_n(0),\ n≥0)$ 的影响将消失，而且系统的状态概率分布不再随时间变化
	- 在实际应用中大多数问题，系统会很快趋于稳态，而无须真正等到 $t\to\infty$，即过一段时间以后，就有 $p_n(t) \to p_n$ 
### 4-2-5 应用：电话总机的设置
#### 4-2-5-0 模型介绍
- *问题提出*：考虑一部电话总机，它的功能是当有用户呼叫时，提供一条线路供用户通话。若为每一用户准备一条专线，则费用很高；当线路较少而需要服务的用户很多时，就会导致有呼叫而没有闲置线路的可能，于是，要求通话的用户必须等待，由此问题产生了：应当有多少条线路，才能使被延误的通话数量低于某一指标
- *问题特点*：呼叫发生的时刻，每次通话延续的时间，一段时间内要求提供的线路数量，以及被延误的通话数都具有随机性
- *问题具体化*：为讨论方便，只需考虑两个城市，二者之间共有 $s$ 条线路，当线路全部被占用时，再来的呼叫不能立即通话，我们分别讨论这样的呼叫排队等待及随即离去两种情形，要求对不能立即通话的呼叫比例加以估计，并由此说明应如何合理选择的值。
- *问题前提*：按照给定排队论问题的一般原则，首先应给出系统的输入过程，即通话呼叫发生的方式及强度；还应规定服务机制，即每次通话延续时间所服从的概率分布，然后才能根据不同情况，对系统进行分析。
#### 4-2-5-1 呼叫发生与通话时间的概率描述
- *基本假设* 
	1. 设电话用户在 $(t, t+\Delta t)$ 在这段时间内对电话站呼叫一次的概率等于 $\lambda \Delta t + o(\Delta t)$ 
	2. 在互不重叠的时间间隔内，总机收到的呼叫次数是相互独立的随机变量
	3. 在 $(t, t + \Delta t)$ 这段时间内，呼叫两次或两次以上的概率等于 $o(\Delta t)$ 
- *符号规定 1* 
	- $P_{k}(t)$ 表示长度为 $t$ 的时间间隔内有 $k$ 次呼叫的概率
	- $N(t)$ 表示长度为 $t$ 的时间间隔内，电话用户对总机的呼叫次数。
- *结论 1*（*输入过程*）：$P_k(t) = e^{-\lambda t} \cdot \dfrac{(\lambda t)^k}{k!},\ k=1,2,\cdots$ 
	- *推导过程* 
		*第 1 步*：求 $P_0(t)$ 
		根据上述假设，我们有 $P_{1}(\Delta t) = \lambda \Delta t + o(\Delta t)$ 和 $\sum\limits_{k=2}^{\infty} P_{k}(\Delta t) = o(\Delta t)$ 
		因此 $P_{0}(\Delta t) = 1 - \lambda \Delta t + o(\Delta t)$，显然 $P_{0}(0) = 1,\ P_{k}(0) = 0,\ k = 1, 2, \cdots$ 
		故 $P_{0}(t + \Delta t) = P_{0}(t) \cdot P_{0}(\Delta t) = P_{0}(t)(1 - \lambda \Delta t + o(\Delta t))$ 
		故  $\dfrac{P_{0}(t + \Delta t) - P_{0}(t)}{\Delta t} = -\lambda P_{0}(t) + P_{0}(t) \cdot \dfrac{o(\Delta t)}{\Delta t}$ 
		于是 $\left\{ \begin{array}{l} \dfrac{\mathrm{d} P_{0}(t)}{\mathrm{d} t} = -\lambda P_{0}(t) \\ P_{0}(0) = 1 \end{array} \right.$，解微分方程得到 $P_{0}(t) = e^{-\lambda t}$ 
		*第 2 步*：求 $P_k(t)$ 
		对 $k \geqslant 1$，我们有：
		$$
		\begin{aligned}
		P_{k}(t + \Delta t) &= P_{k}(t) P_{0}(\Delta t) + P_{k-1}(t) P_{1}(\Delta t) + \sum\limits_{i=2}^{k} P_{k-i}(t) P_{i}(\Delta t) \\
		&= P_{k}(t)(1 - \lambda \Delta t + o(\Delta t)) + P_{k-1}(t)(\lambda \Delta t + o(\Delta t)) + o(\Delta t)
		\end{aligned}
		$$
		化简为 $\dfrac{P_{k}(t + \Delta t) - P_{k}(t)}{\Delta t} = -\lambda P_{k}(t) + \lambda P_{k-1}(t) + \dfrac{o(\Delta t)}{\Delta t}$ 
		令 $\Delta t \to 0$，$\dfrac{\mathrm{d} P_{k}(t)}{\mathrm{d} t} = -\lambda P_{k}(t) + \lambda P_{k-1}(t)$ 
		又因为 $P_{k}(0) = 0, k = 1, 2, \cdots$，且 $P_{0}(t) = e^{-\lambda t}$，我们得到以下微分方程组
		$$
		\left\{\begin{array}{l}
		\dfrac{\mathrm{d} P_{k}(t)}{\mathrm{d} t} = -\lambda P_{k}(t) + \lambda P_{k-1}(t) \\
		P_{k}(0) = 0, \quad k = 1, 2, \cdots, P_{0}(t) = e^{-\lambda t}
		\end{array}\right.
		$$
		求解得 $P_k(t) = e^{-\lambda t} \cdot \dfrac{(\lambda t)^k}{k!},\ k=1,2,\cdots$ 
		推导完毕！
	- 按照这一规律发生的电话呼叫次数 $\{ N(t),\ t\ge 0 \}$，构成了一随机过程，称为**泊松 (Poisson) 过程** 
	- 由于 $N(t)$ 服从参数为 $\lambda t$ 的泊松分布，所以 $N(t)$ 的数学期望 $E(N(t)) = \lambda t$，$N(t)$ 的方差 $D(N(t)) = \lambda t$，其中 $\lambda$ 表示单位时间内的平均呼叫次数
	- 至此，我们从三条基本假设出发，推导出了输入过程
- *符号规定 2* 
	- $T$ 表示任何连续两次呼叫的时间间隔，易知 $T$ 是独立同分布的连续型随机变量
	- $t_k$ 表示第 $k$ 次呼叫发生的时刻，特殊地，$t_0 = 0$ 
- *结论 2*（*连续两次呼叫时间间隔的分布*）：随机变量 $T$ 服从参数为 $\lambda$ 的指数分布
	- *推导过程* 
		设 $T_1$ 表示第一次呼叫发生的时刻，可知 $T_1 = t_1 - t_0$ 
		易知 $T_1$ 的分布就是任意连续两次呼叫间隔 $T$ 的分布
		由前面的结论，我们有 $P\left\{T_{1}>t\right\}=P\left\{\text{在}(0, t)\text{内呼叫次数为零}\right\}=P_{0}(t)=e^{-\lambda t}$ 
		用 $F(t)$ 表示随机变量 $T_{1}$，即 $T$ 的分布函数，则有 $F(t)=P(T\leqslant t)=\left\{\begin{array}{ll} 1-e^{-\lambda t},&t\geqslant 0 \\ 0, &t<0 \end{array}\right.$ 
		随机变量 $T$ 的概率分布密度 $\varphi(t)=\left\{\begin{array}{ll} \lambda e^{-\lambda t},&t>0 \\ 0, &t\leqslant 0 \end{array}\right.$ 
		于是随机变量 $T$ 服从参数为 $\lambda$ 的指数分布。
		推导完毕！
	- $T$ 的数学期望 $E(T)=\dfrac{1}{\lambda}$，方差 $D(T)=\dfrac{1}{\lambda^{2}}$，这说明两次呼叫的间隔时间的平均值为 $\dfrac{1}{\lambda}$ 
	- 上面的讨论实际上也说明了泊松过程与指数分布之间的关系。
- *符号规定 3* 
	- $T$ 表示任何一次通话的延续时间，则 $T$ 是一个随机变量，且可以假设 $T$ 服从参数为 $\mu$ 的指数分布，即 $T$ 的概率密度函数为 $\varphi_{1}(t)=\left\{\begin{array}{ll} \mu \mathrm{e}^{-\mu t}, & t>0,\\ 0, & t \leqslant 0, \end{array}\right.$（这是因为：指数分布可以用来描述连续两次呼叫时间间隔的分布，而一次通话的延续时间也是一个时间间隔，因此，指数分布也可用来刻画通话时间的概率规律）
- *结论 3*：在任何时间间隔 $[t, t+\Delta t)$ 内，一次通话结束的概率为 $\mu \Delta t + o(\Delta t)$ 
	- *推导过程* 
		可知
		$$
		\begin{aligned}
		\lim\limits_{\Delta t \rightarrow 0} \frac{P(T \leqslant t+\Delta t \mid T>t)}{\Delta t} =& \lim\limits_{\Delta t \rightarrow 0} \frac{P(t<T \leqslant t+\Delta t)}{\Delta t \cdot P(T>t)} \\
		=& \lim_{\Delta t\to 0} \dfrac{(1-e^{-\mu(t+\Delta t)}) - (1-e^{-\mu t})}{\Delta t \cdot e^{-\mu t}} \\
		=& \lim_{\Delta t\to 0} \dfrac{1-e^{-\mu\Delta t}}{\Delta t} = \mu
		\end{aligned}
		$$
		故在任何时间间隔 $[t, t+\Delta t)$ 内，一次通话结束的概率为 $\mu \Delta t + o(\Delta t)$，推导完毕！
	- 这一概率与 $t$（通话已经持续的时间）无关。
	- *推论*：由于每次通话延续的时间相互独立，且与当时多少条线路被占用无关，因此，如果在时刻 $t$ 恰有 $k$ 条线路在通话，则“在 $(t, t+\Delta t)$ 内恰有一次通话结束”的概率为 $\mu k \Delta t + o(\Delta t)$，“在这段时间内至少结束二次通话”的概率则为 $o(\Delta t)$ 
	- *推论*：由于呼叫的发生也服从指数分布，因此“在这段时间内发生一次呼叫且结束一次通话”的概率也是 $o(\Delta t)$ 
	- *补充*：参数 $\mu$ 表示一条线路单位时间内结束的通话数的平均值。
- *评价*：对任何一次通话时间作指数分布的假设不仅符合实际，而且指数分布具有一个很好的性质：**无记忆性**，即 $P(T \geqslant s + t \mid T \geqslant t) = P(T \geqslant s)$ 
#### 4-2-5-2 Erlang 等待制系统
- *符号规定* 
	- **Erlang 等待制系统**：在下面，我们假设 $s$ 条线路均被占用时，再发生的呼叫依次排队，等待服务，队列长度没有限制，其他假设不变，这种系统叫做 **Erlang 等待制系统**。
	- 以后 $E_{j}$ 表示系统中有 $j$ 个顾客时的状态，此时 $0 \leqslant j < \infty$ 
		- 当 $j \leqslant s$ 时，所有顾客各自占用一条线路进行通话
		- 当 $j > s$ 时，则有 $j - s$ 个顾客在队列中等待
	- 仍以 $P_{j}(t)$ 表示 $t$ 时刻系统处于状态 $E_{j}$ 的概率。
	- 令 $P_j = \lim\limits_{t\to\infty} P_j(t)$（该极限的存在性可以由马氏链的理论加以说明）
	- 将系统在时间间隔 $(t, t + h)$ 内由状态 $E_{j}$ 变成状态 $E_{j+1}$ 及 $E_{j-1}$ 的概率依次记为 $\lambda_{j}h + o(h)$ 与 $\mu_{j}h + o(h)$ 
	- 系统的输入过程由参数为 $\lambda$ 的泊松过程描述，不受系统状态影响，因此 $\lambda_{j} = \lambda \ (j = 0, 1, \cdots)$，然而 $\mu_{j} = \left\{ \begin{array}{ll} j \mu, & j \leqslant s \\ s \mu, & j > s \end{array} \right.$ 
- *结论 1*：$P_{j}(t) \ (j = 0, 1, \cdots)$ 满足微分方程组 $\begin{aligned} \dfrac{d P_{j}(t)}{dt} &= \lambda P_{j-1}(t) - (\lambda + \mu_{j}) P_{j}(t) + \mu_{j+1} P_{j+1}(t),\ j = 1, 2, \cdots \\ \dfrac{d P_{0}(t)}{dt} &= \mu P_{1}(t) - \lambda P_{0}(t) \end{aligned}$ 
- *结论 2*：极限概率分布 $P_{j} = \dfrac{a^{j}}{j!} P_{0},\ j = 1, 2, \cdots, s-1$，$P_{j} = \dfrac{a^{j}}{s! s^{j-s}} P_{0}\ j = s, s+1, s+2, \cdots$，$P_{0} = \left( \sum\limits_{k=0}^{s-1} \dfrac{a^{k}}{k!} + \sum\limits_{k=s}^{\infty} \dfrac{a^{k}}{s! s^{k-s}} \right)^{-1}$，式中 $a = \dfrac{\lambda}{\mu}$ 
	- *注意*：$P_{0}$ 的值由一个无穷级数所表示。当 $a < s$ 时，该级数收敛，有 $P_{0} = \left( \sum\limits_{k=0}^{s-1} \dfrac{a^{k}}{k!} + \dfrac{a^{s}}{s! (1 - a/s)} \right)^{-1}$；当 $a \geqslant s$ 时，级数发散，$P_{0} = 0$ 
	- *推论*：对于任何一个有限指标 $j$，$P_{j} = 0$。也就是说，不存在平稳分布，等待服务的队列持续不断地加长，队列趋于无穷长的概率为 $1$ 
- **等待制下的 Erlang 公式**：令 $C(s, a) = \sum\limits_{j=s}^{\infty} P_{j} = \dfrac{a^{s}}{s! (1 - a/s)} P_{0} = \dfrac{a^{s}}{s! (1 - a/s)} \bigg/ \left( \sum\limits_{k=0}^{s-1} \dfrac{a^{k}}{k!} + \dfrac{a^{s}}{s! (1 - a/s)} \right)\ (0 \leqslant a < s)$，上式称为**等待制下的 Erlang 公式** 
	- 对所考虑的模型，它表示所有线路被占用，因而一个新到来的呼叫不能被立即服务的概率
- *结论 3*：以 $\overline{a}$ 表示电话系统平衡时平均占用的线路数，直接计算可得 $\overline{a} = \sum\limits_{j=1}^{s-1} j P_{j} + s \sum\limits_{j=s}^{\infty} P_{j} = a$ 
	- *直观意义*：在 Erlang 等待制系统中，每个来到的顾客最终均被服务，因而系统平衡时必有顾客要求的服务强度等于实际提供的服务强度。
	- 此式也对平衡条件 $a < s$ 提供了解释：当 $a < s$ 时，若能达到平衡，应有 $\overline{a} = a$，这意味着要求提供的线路数超过实际可能的线路数，这当然是做不到的；当 $a = s$ 时是临界情况，只有线路毫不间断地充分利用，才可能平衡，但顾客来到是随机的，必然有线路闲置的时刻，这些“浪费”的时间不断累积，因而达不到平衡。
- 上述模型，排队论中以标准形式：$M/M/s/\infty$ 表示，第一个 $M$ 表示到达规律服从泊松分布，第二个 $M$ 表示服务时间为指数分布，第三个 $s$ 表示系统中有 $s$ 个服务员，第四个 $\infty$ 表示队列长度无限。
#### 4-2-5-3 Erlang 消失制系统
- *符号规定* 
	- **Erlang 消失制系统**：当全部线路均已占用，再来的通话要求自动放弃的情况，这种规则称为消失制。采用这一规则的系统称为 **Erlang 消失制系统** 
	- 假设系统只有 $s$ 条线路；当有 $j$ 条被占用时，系统处于状态 $E_{j}\ (j=0,1,\cdots, s)$ 
	- 以 $P_{j}(t)$ 表示时刻 $t$ 时系统处于状态 $E_{j}$ 的概率
	- 记 $t$ 时刻被占用的线路数为 $N(t)$ 
- *结论 1*：$P_{j}(t)$ 满足微分方程组 $\begin{aligned} &\dfrac{\mathrm{d} P_{j}(t)}{\mathrm{d} t} = \lambda P_{j-1}(t) - (\lambda + j\mu) P_{j}(t) + (j+1)\mu P_{j+1}(t),\ j=1,2,\cdots,s-1 \\ &\dfrac{\mathrm{d} P_{0}(t)}{\mathrm{d} t} = \mu P_{1}(t) - \lambda P_{0}(t),\ \dfrac{\mathrm{d} P_{s}(t)}{\mathrm{d} t} = \lambda P_{s-1}(t) - s\mu P_{s}(t) \end{aligned}$ 
	- *推导过程* 
		先假设 $0 < j < s$，则 $P_{j}(t)=P(N(t)=j)$ 
		由全概率公式有 $P(N(t+h)=j)=\sum\limits_{i=0}^{s} P(N(t)=i) P(N(t+h)=j \mid N(t)=i)$ 
		由前面的假设可知 $P(N(t+h)=j \mid N(t)=i)=\left\{\begin{array}{ll} \lambda h+o(h), & i=j-1 \\ (j+1) \mu \cdot h+o(h), & i=j+1 \\ o(h), & |i-j| \geqslant 2 \end{array}\right.$
		又由 $\sum\limits_{k} P(N(t+h)=k \mid N(t)=j)=1$，所以
		$$ 
		\begin{aligned}
		&P(N(t+h)=j \mid N(t)=j)=1-\lambda h-j\mu h+o(h) \\
		&P_{j}(t+h)=\lambda hP_{j-1}(t)+(1-\lambda h-j\mu h)P_{j}(t)+(j+1)\mu hP_{j+1}(t)+o(h) \\
		&\frac{P_{j}(t+h)-P_{j}(t)}{h}=\lambda P_{j-1}(t)-(\lambda+j\mu) P_{j}(t)+(j+1)\mu P_{j+1}(t)+\frac{o(h)}{h}
		\end{aligned}
		$$
		令 $h \to 0$ 有 $\dfrac{\mathrm{d} P_{j}(t)}{\mathrm{d} t} = \lambda P_{j-1}(t) - (\lambda + j\mu) P_{j}(t) + (j+1)\mu P_{j+1}(t),\ j=1,2,\cdots,s-1$ 
		类似地可以证 $\dfrac{\mathrm{d} P_{0}(t)}{\mathrm{d} t} = \mu P_{1}(t) - \lambda P_{0}(t),\ \dfrac{\mathrm{d} P_{s}(t)}{\mathrm{d} t} = \lambda P_{s-1}(t) - s\mu P_{s}(t)$ 
	- 若 $t=0$ 时，系统处于状态 $E_{i}$，则上述微分方程组的初始条件为 $P_{j}(0)=\left\{\begin{array}{ll}1, &j=i \\ 0, &j\neq i \end{array}\right.$ 
	- 利用如上的微分方程组与相应初值，可以得到任何时刻系统处于任何状态的概率。
- 但我们在实际中，更感兴趣的问题是：
- *结论 2*、**细致平衡**、**截断的泊松分布**：此处所讨论问题的平衡分布是存在并且唯一的，且为 $\begin{aligned} &P_{j} = \dfrac{(\lambda/\mu)^{j}}{j!} P_{0},\ j = 1, 2, \cdots, s \\ &P_{0} = \left( \sum\limits_{j=0}^{s} \dfrac{(\lambda/\mu)^{j}}{j!} \right)^{-1} \end{aligned}$ 
	- *推导过程*
		由马氏链理论可以证明：此处所讨论问题的平衡分布是存在并且唯一的，下面我们直接求出平衡分布，从而说明了平衡分布的存在性。唯一性可利用线性代数方程组解的唯一性理论加以说明。
		令 $P_j$ 表示平衡分布达到时系统处于状态 $E_j$ 概率，显然 $P_j$ 与 $t$ 无关
		***在 (2) 与 (3) 中***（狗屎教材指代不明）令 $t \to \infty$，我们得到平衡概率分布满足方程组
		$$
		\begin{aligned}
		&\lambda P_{j-1} - (\lambda + j\mu) P_j + (j+1)\mu P_{j+1} = 0, \quad j = 1,2,\cdots,s-1 \\
		&\mu P_1 - \lambda P_0 = 0, \quad \lambda P_{s-1} - s\mu P_s = 0
		\end{aligned}
		$$
		此外，显然有 $\sum\limits_{j} P_j = 1$ 
		化简上面方程，可知它的解满足关系：$j\mu P_j - \lambda P_{j-1} = 0,\ j = 1,2,\cdots,s$ 
		上式表明：当系统处于平衡时，在任意一段时间中，从任何一状态转化为另一状态的概率，与同一时间内反向变化的概率相等；故而这种平衡又称作**细致平衡**。
		由 $\sum\limits_{j} P_j = 1$，不难得出平衡概率分布为
		$$
		\begin{aligned}
		&P_{j} = \dfrac{(\lambda/\mu)^{j}}{j!} P_{0},\ j = 1, 2, \cdots, s \\
		&P_{0} = \left( \sum\limits_{j=0}^{s} \dfrac{(\lambda/\mu)^{j}}{j!} \right)^{-1}
		\end{aligned}
		$$
		这一分布称为**截断的泊松分布** 
	- *该结论说明*：当运行时刻足够长时，系统的分布会稳定下来，趋于一个平衡分布，且给出了平衡分布形式
	- *注意*：该平衡分布只依赖于 $\lambda / \mu$ 
	- *符号含义*：$\lambda$ 表示单位时间内发生的呼叫次数，$\mu^{-1}$ 表示一次通话的平均时间，$a = \lambda / \mu$ 表示顾客所要求的电话总机服务强度
	- *符号含义*：令 $\breve{a} = \sum\limits_{j=1}^{s} j P_{j}$，当系统平衡时，它表示实际提供服务的平均线路数，另一方面，它也是被占用线路数的时间平均值
	- *符号含义*：再令 $\rho = \breve{a} / s$，这个数表示了每条线路的实际平均负载，或者说系统的效率，显然有 $\rho \leqslant 1$ 
- **Erlang 消失公式**：当系统平衡时处于状态 $E_{s}$ 的概率是 $P(s, a) = \dfrac{a^{s}}{s!} \bigg/ \sum\limits_{k=0}^{s} \dfrac{a^{k}}{k!}$，该公式称为**Erlang 消失公式** 
	- *符号含义*：当系统处于状态 $E_s$ 时，所有的线路被占用，再来的呼叫不能被服务，因此 $P(s,a)$ 也表示不能立即接通的通话要求所占的比例
	- *该公式告诉我们*：当 $a$ 给定（即顾客的服务强度已知）时，$s$ 应如何选择，即设置多少条线路，才能保证一定的通话率。这一公式也可回答相反的问题，即当 $s$ 一定时，为保证一定的通话率，$a$ 应限定在什么范围。
- *结论  3*：消失制系统种有 $\breve{a} = a\left[1 - P(s, a)\right] = \lambda\left[1 - P(s, a)\right]\mu^{-1}$ 
	- *该公式表示*：实际的服务强度是顾客要求服务强度的未消失部分。
	- *符号含义*：$\breve{a}$ 也可被解释为任何时刻被服务顾客的平均数，它等于实际进入系统的顾客平均到来速率 $\lambda\left[1 - P(s, a)\right]$ 乘以每个顾客在系统内的平均停留时间 $\mu^{-1}$。这一关系是有一般意义的，它实际上是排队论中著名的 **Little 定理**的特殊情况。
- *结论 4*：对不同的参数值，数值计算 $P(s,a)$ 及 $\breve{a}$ 的值，绘制成图表。从这些图表的分析可得以下结论
	1. 若使 $s, a$ 均增加，但 $P(s,a)$ 保持不变，则 $\rho = \dfrac{\breve{a}}{s}$ 增加，即当通话率保持不变时，可供使用的线路越多越有效
	2. 当 $s$ 固定，随着 $a$ 增加 $\rho$ 也增多，即效率提高，但此时 $P(s,a)$ 也随之增加，因此一味增加效率是不可取的。
- *注*：以上排队模型，排队论中用标准形式 $M/M/s$ 表示。
## 4-3 随机性存贮策略
### 4-3-0 随机性存储模型的重要特点
- 是需求为随机的，其概率分布为已知。
- 存储策略的优劣，通常以赢利的期望值的大小作为衡量的标准。
### 4-3-1 需求是离散型随机变量（以**报童问题**为例）
- *问题背景*：报童每天清晨从报社购进报纸零售，晚上将没有卖掉的报纸退回给报社，报童每天售报的数量是一个随机变量，报童每售出一份报纸赚 $a$ 元，如报纸未能售出，每份赔 $b$ 元，每天报童售出报纸份数 $r$ 的概率 $p(r)$ 根据以往的经验是已知的，问报童每天最好购进多少份报纸，才能使获取的收入最大？
- *问题重述*：该问题是报童每天报纸的订货量 $Q$ 为何值时，收入的期望值达到最大？换句话说，如何适当地选择 $Q$ 值，使因不能售出报纸的损失及因缺货失去销售机会的损失，两者期望值之和最小。
- *符号假设*：假设售出报纸数量为 $r$，其概率 $P(r)$ 已知，设报童订购报纸数量为 $Q$ 
- *结论*：最佳订报份数 $Q$ 应满足下面不等式 $\sum\limits_{r=0}^{Q-1} P(r) < \dfrac{a}{a+b} \leqslant \sum\limits_{r=0}^{Q} P(r)$  
	- *推导过程* 
		*第 1.1 步*：从损失最小角度出发，建立损失期望值表达式，并列出条件
		设报童订报数量为 $Q$，损失期望值为 $C(Q)$ 
		当 $r \leq Q$ 时，此时因报纸不能售出而承担损失，其期望值为 $\sum\limits_{r=0}^{Q} b (Q - r) P(r)$ 
		当 $r > Q$ 时，此时因缺货而少赚钱，损失的期望值为 $\sum\limits_{r=Q+1}^{\infty} a (r - Q) P(r)$ 
		综合上述两种情形，当订报数量为 $Q$ 时，损失的期望值为 $C(Q) = b \sum\limits_{r=0}^{Q} (Q - r) P(r) + a \sum\limits_{r=Q+1}^{\infty} (r - Q) P(r)$ 
		由此可见，报童的最佳订报数量 $Q$，应使 $C(Q)$ 达到最小。
		由于报童订购报纸的份数只能取整数，$r$ 是离散型变量，所以不能用求导方法来求极值，若设报童每日订购报纸份数的最佳值为 $Q$，则应有下面两个条件同时成立：
		(1) $C(Q) \leq C(Q+1)$ 
		(2) $C(Q) \leq C(Q-1)$ 
		*第 1.2 步*：分析条件 (1)
		由 (1) 有
		$$
		\begin{aligned}
		& b \sum\limits_{r=0}^{Q} (Q-r) P(r) + a \sum\limits_{r=Q+1}^{\infty} (r-Q) P(r) \\
		& \leqslant b \sum\limits_{r=0}^{Q+1} (Q+1-r) P(r) + a \sum\limits_{r=Q+2}^{\infty} (r-Q-1) P(r)
		\end{aligned}
		$$
		化简得 $b \sum\limits_{r=0}^{Q} P(r) - a \sum\limits_{r=Q+1}^{\infty} P(r) \geqslant 0$ 
		又因 $\sum\limits_{r=0}^{\infty} P(r) = 1$，故 $(a+b) \sum\limits_{r=0}^{Q} P(r) - a \geqslant 0$，即 $\sum\limits_{r=0}^{Q} P(r) \geqslant \dfrac{a}{a+b}$ 
		*第 1.3 步*：分析条件 (2)
		由 (2) 有
		$$
		\begin{aligned}
		& b \sum_{r=0}^{Q} (Q-r) P(r) + a \sum_{r=Q+1}^{\infty} (r-Q) P(r) \\
		& \leqslant b \sum_{r=0}^{Q-1} (Q-1-r) P(r) + a \sum_{r=Q}^{\infty} (r-Q+1) P(r)
		\end{aligned}
		$$
		化简得 $b \sum\limits_{r=0}^{Q-1} P(r) - a \sum\limits_{r=Q}^{\infty} P(r) \leqslant 0$，即 $(a+b) \sum\limits_{r=0}^{Q-1} P(r) - a \leqslant 0$，从而 $\sum\limits_{r=0}^{Q-1} P(r) \leqslant \dfrac{a}{a+b}$ 
		*第 1.4 步*：得出亏损最小角度下的结论
		综合 (1), (2)，得到报童最佳订报数量 $Q$ 应通过不等式 $\sum\limits_{r=0}^{Q-1} P(r) < \dfrac{a}{a+b} \leqslant \sum\limits_{r=0}^{Q} P(r)$ 确定。
		*第 2.1 步*：从赢利最大的角度出发，建立盈利期望值表达式，并列出条件
		接下来，我们从赢利最大的角度出发，来确定报童的最佳订报数量。
		设报童订报数量为 $Q$，获利期望值为 $C(Q)$ 
		当需求 $r \leqslant Q$ 时，报童只售出了 $r$ 份报纸，共赚 $a \cdot r$ 元，未售出的报纸，退还给报社，每份赔 $b$ 元，共赔 $b(Q-r)$ 元。此时赢利的期望值为 $\sum\limits_{r=0}^{Q} [a r - b(Q-r)] P(r)$ 
		当需求 $r > Q$ 时，赢利的期望值为 $\sum\limits_{r=Q+1}^{\infty} a \cdot Q P(r)$ 
		故 $C(Q) = \sum\limits_{r=0}^{Q} [a r - b(Q-r)] P(r) + \sum\limits_{r=Q+1}^{\infty} a \cdot Q P(r)$ 
		为使订购 $Q$ 份报的赢利达到最大，则应有
		(3) $C(Q+1) \leqslant C(Q)$ 
		(4) $C(Q-1) \leqslant C(Q)$ 
		*第 2.2 步*：分析条件 (3)
		由 (3) 有
		$$
		\begin{aligned}
		&\sum_{r=0}^{Q+1}[a r-b(Q+1-r)]P(r)+\sum_{r=Q+2}^{\infty} a\cdot(Q+1) P(r) \\ 
		&\leqslant \sum_{r=0}^{Q}[a r-b(Q-r)] P(r)+\sum_{r=Q+1}^{\infty} a \cdot Q \cdot P(r)
		\end{aligned}
		$$
		经整理得到 $a\sum\limits_{r=Q+1}^{\infty} P(r)-b\sum\limits_{r=0}^{Q} P(r) \leqslant 0$，即 $a-(a+b)\sum\limits_{r=0}^{Q} P(r) \leqslant 0$ 	
		即 $\sum\limits_{r=0}^{Q} P(r) \geqslant \dfrac{a}{a+b}$ 
		*第 2.3 步*：分析条件 (4)
		由 (4) 有
		$$
		\begin{aligned}
		&\sum_{r=0}^{Q-1}[a r-b(Q-1-r)]P(r)+\sum_{r=Q}^{\infty} a\cdot(Q-1)P(r) \\ 
		&\leqslant\sum_{r=0}^{Q}[a r-b(Q-r)]P(r)+\sum_{r=Q+1}^{\infty} a\cdot QP(r)
		\end{aligned}
		$$
		化简后得到 $\sum\limits_{r=0}^{Q-1} P(r) \leqslant \dfrac{a}{a+b}$
		*第 2.4 步*：得出盈利最大角度下的结论
		综上讨论，得到最佳订报份数 $Q$ 应满足下面不等式 $\sum\limits_{r=0}^{Q-1} P(r) < \dfrac{a}{a+b} \leqslant \sum\limits_{r=0}^{Q} P(r)$ 
		*第 3 步*：得出最终结论
		由于两个角度下 $Q$ 应满足的不等式均为 $\displaystyle \boxed{\sum\limits_{r=0}^{Q-1} P(r) < \dfrac{a}{a+b} \leqslant \sum\limits_{r=0}^{Q} P(r)}$，故得出结论
### 4-3-2 需求是连续性随机变量（通过例子表述）
- *问题*：设货物单位成本为 $K$，货物单位售价为 $P$，单位存贮费用为 $C_1$，需求量 $r$ 是连续型随机变量，概率密度函数为 $f(r)$，其分布函数 $\displaystyle F(a) = \int_0^a f(r)\mathrm dr,\ a>0$，生产或订购的数量为 $Q$，问如何确定 $Q$ 的值，使赢利的期望值最大？
- *结论*：通过 $F(Q) = \dfrac{P-K}{C_{1}+P}$ 解出 $Q$ 即为所求
	- *推导过程* 
		*第 1 步*：初步分析
		当订购数量为 $Q$ 时，实际销售量为 $\min\{r,Q\}$，需支付的存贮费用 $C_{2}(Q)=\left\{\begin{array}{ll} C_{1}(Q-r), & r \leqslant Q \\ 0, & r>Q \end{array}\right.$ 
		货物的总成本为 $KQ$ 
		本阶段订购量为 $Q$ 时，赢利为 $W(Q)$，赢利的期望值记为 $E[W(Q)]$，则 
		$$
		\begin{aligned}
		&W(Q)=P \cdot \min\{r, Q\}-KQ-C_{2}(Q) \\
		&E[W(Q)]=\displaystyle\int_{0}^{Q} P r f(r) \mathrm dr + \displaystyle\int_{Q}^{\infty} P Q f(r) \mathrm dr - KQ - \displaystyle\int_{0}^{Q} C_{1}(Q-r) f(r) \mathrm dr \\
		&E[W(Q)]=P \displaystyle\int_{0}^{+\infty} r f(r) \mathrm dr - \left\{ \displaystyle\int_{Q}^{\infty} (r-Q) f(r) \mathrm dr + \displaystyle\int_{0}^{Q} C_{1}(Q-r) f(r) \mathrm dr + KQ \right\}
		\end{aligned}$$
		在上式中 $P \displaystyle\int_{0}^{+\infty} r f(r) \mathrm dr$ 表示“平均盈利”，$P \displaystyle\int_{Q}^{+\infty} (r-Q) f(r) \mathrm dr$ 表示“因缺货失去销售机会损失的期望值”，$\displaystyle \int_0^Q C_1(Q-r) f(r)\mathrm dr$ 表示“只考虑存贮费的条件下，因滞销受到损失的期望值”
		记 $E[C(Q)]=P\displaystyle\int_{Q}^{\infty}(r-Q) f(r) \ \mathrm{d}r+C_{1} \displaystyle\int_{0}^{Q}(Q-r) f(r) \ \mathrm{d}r+K Q$ 
		显然 $\max E[W(Q)]=P \displaystyle\int_{0}^{\infty} r f(r) \ \mathrm{d}r-\min E[C(Q)]$ 
		上式表明：赢利最大与损失最小所得出的 $Q$ 值相同，从而求赢利最大可以转化为求 $E[C(Q)]$ 极小
		*第 2 步*：求解问题
		当 $Q$ 可以连续取值时，$E[C(Q)]$ 是 $Q$ 的连续函数，且有 $\displaystyle \dfrac{\mathrm{d}E[C(Q)]}{\mathrm{d}Q} = C_{1} \int_{0}^{Q} f(r)\ \mathrm{d} r - P \int_{Q}^{\infty} f(r)\ \mathrm{d}r + K$ 
		令 $\dfrac{\mathrm{d}E[C(Q)]}{\mathrm{d}Q}=0$，记 $F(Q)=\displaystyle\int_{0}^{Q} f(r) \mathrm{d}r$ 
		则 $C_{1} F(Q)-P[1-F(Q)]+K=0$，即 $F(Q) = \dfrac{P-K}{C_{1}+P}$ 
		从 $F(Q) = \dfrac{P-K}{C_{1}+P}$ 中解出 $Q$，记为 $Q^{*}$，$Q^{*}$ 为 $E[C(Q)]$ 的驻点。
		又因 $\dfrac{\mathrm{d}^{2} E[C(Q)]}{\mathrm{d}Q^{2}}=C_{1} f(Q)+P f(Q)>0$，所以 $Q^{*}$ 为 $E[C(Q)]$ 的极小值点，同时也是最小值点。
		特别地，若 $P - K \leqslant 0$，显然由于 $F(Q) \geqslant 0$，等式不成立，此时 $Q^{*}$ 取零值，即售价低于进价时，不需要订货。
		*第 3 步*：拓展：缺货时要付出费用的情形
		前面只考虑了失去销售机会的损失，若缺货时要付出的费用 $C_{2} > P$ 时，应有 $E[C(Q)] = C_{2} \displaystyle\int_{Q}^{\infty} (r - Q) f(r) \ \mathrm{d}r + C_{1} \displaystyle\int_{0}^{Q} (Q - r) f(r) \ \mathrm{d}r + KQ$ 
		仿照前面的办法，可得 $F(Q) = \displaystyle\int_{0}^{Q} f(r) \ \mathrm{d}r = \dfrac{C_{2} - K}{C_{1} + C_{2}}$，用该式求出 $Q$ 即可
		*第 4 步*：拓展：多阶段情形
		在前面的讨论中，模型只解决一个阶段的问题，但在许多实际问题中，上一个阶段未售出的货物，可以在第二阶段继续出售，这时应如何制订存贮策略呢？
		假设上一阶段未能售出的货物数量为 $I$，作为本阶段初的存贮，有 $\min E[C(Q)] = K(Q - I) + C_{2} \displaystyle\int_{Q}^{\infty} (r - Q) f(r) \ \mathrm{d}r + C_{1} \displaystyle\int_{0}^{Q} (Q - r) f(r) \ \mathrm{d}r$ 
		利用 $\displaystyle F(Q) = \int_0^Q f(r)\mathrm dr = \dfrac{C_2 - K}{C_1 + C_2}$ 求出 $Q^*$ 值即可
		相应的存贮策略为：当 $I\ge Q^*$ 时，本阶段不订货；当 $I<Q^*$ 时，本阶段的订货量 $Q = Q^* - I$，，使本阶段的存贮达到 $Q^*$ 这时赢利期望最大
		这种策略叫做**定期订货、订货量不定**的存贮策略
### 4-3-3 $(s,S)$ 型随机存贮策略
#### 4-3-3-0 问题引入
- *问题*：商店在一个月中的销售量是随机的，每到月底，商店的经理要根据仓库存货的多少来决定是否订购货物，以供下个月的销售。经理采用的一种简单的策略是：制订一个下界 $s$ 和一个上界 $S$，当月底存货不少于 $s$ 时就不订货，当存货少于 $s$ 时则订货，且订货的数量使得下月初的存货量达到 $S$，这种策略称为 **$(s, S)$ 型随机存贮策略**。在考虑 $(s,S)$ 型随机存贮策略时，我们只考虑订购货物费、存贮费、缺货损失费及货物的进价，存贮策略的优劣以平均意义下的总费用为标准，根据需求是连续的还是离散的
- 下面我们分两种情形来讨论 $(s, S)$ 型随机存贮策略
#### 4-3-3-1 需求为连续型随机变量
- *模型假设* 
	- 为叙述方便，时间以月为单位，商品数量以件为单位
	- 商品在一月中的销售量 $r$ 是连续型随机变量，其概率密度函数为 $f(r)$ 
	- 每件商品的进价为 $K$，每件商品一月的存贮费为 $C_1$，每件商品的缺货损失费为 $C_2$，每次订购货物的费用为 $C_3$（与订货数量无关）
	- 记月底的存货量为 $I$，订货量为 $Q$，并且订货以后，立即到货，于是下月初货物存贮达到 $S=I+Q$ 
- *结论*：存储策略为：每个月底检查库存，若库存 $I < s$ 时，需订货，订货的数量为 $Q = S - I$，当库存 $I \ge s$ 时，本月不订货（$s, S$ 如何确定详见过程）
	- *推导过程* 
		*第 1 步*：初步分析
		按照制订 $(s, S)$ 型策略的要求，当月底存货量 $I \geqslant s$ 时，订货量 $Q = 0$，当月底存货量 $I < s$ 时，订货量 $Q = S - I$ 
		确定 $s,S$ 应该根据总费用最小的原则，又因为销售量是随机的，存贮量和缺货量也是随机的，从而一月的存贮费和缺货费也是随机的，因此目标函数应该取一个月总费用的期望值。
		由模型假设条件知：
		本月所需订货费为 $C_{3} + KQ$ 
		需支付的存贮费用的期望值为 $\displaystyle\int_{0}^{I+Q=S} C_{1}(S - r) f(r) \ \mathrm{d}r$ 
		需付缺货损失费用的期望值为 $\displaystyle\int_{I+Q=S}^{\infty} C_{2}(r - S) f(r) \ \mathrm{d}r$ 
		故本月所需订货费、存贮费及缺货费期望值之和为
		$$
		\begin{aligned}
		C(S) =& C_{3} + KQ + \int_{0}^{S} C_{1}(S - r) f(r) \ \mathrm{d}r + \int_{S}^{\infty} C_{2}(r - S) f(r) \ \mathrm{d}r \\
		=& C_{3} + K(S - I) + \int_{0}^{S} (S - r) f(r) \ \mathrm{d}r + \int_{S}^{\infty} C_{2}(r - S) f(r) \ \mathrm{d}r
		\end{aligned}
		$$
		因为 $Q$ 可以连续取值，所以 $C(S)$ 是 $S$ 的连续函数。
		计算可得 $\displaystyle C^{\prime}(S) = K + C_{1} \int_{0}^{S} f(r) \mathrm{d}r - C_{2} \int_{S}^{\infty} f(r) \mathrm{d}r$ 
		*第 2 步*：确定 $S$ 和 $Q$ 
		令 $C^{\prime}(S) = 0$ 有 $\displaystyle K + C_{1} \int_{0}^{S} f(r) \ \mathrm{d}r - C_{2} \int_{S}^{\infty} f(r) \ \mathrm{d}r = 0$，又因为 $\displaystyle\int_{0}^{\infty} f(r) \ \mathrm{d}r = 1$ 
		所以 $\displaystyle K + C_{1} \int_{0}^{S} f(r) \ \mathrm{d}r - C_{2} \left( 1 - \int_{0}^{S} f(r) \ \mathrm{d}r \right) = 0$，即 $\displaystyle\int_{0}^{S} f(r) \ \mathrm{d}r = \dfrac{C_{2} - K}{C_{1} + C_{2}}$ 
		于是，我们得出本月的存贮策略，通过 $\displaystyle\int_{0}^{S} f(r) \ \mathrm{d}r = \dfrac{C_{2} - K}{C_{1} + C_{2}}$ 确定 $S$ 的值，订货量 $Q = S - I$ 
		*第 3 步*：确定 $s$ 
		若本月不订货，则可以节约订购费 $C_{3}$ 
		因此我们设想是否存在一个数值 $s(s \leqslant S)$，使不等式
		$$
		\begin{aligned}
		&K s + C_{1} \int_{0}^{s} (s - r) f(r) \ \mathrm{d}r + C_{2} \int_{s}^{\infty} (r - s) f(r) \ \mathrm{d}r \\ 
		&\leqslant C_{3} + K S + C_{1} \int_{0}^{S} (S - r) f(r) \ \mathrm{d}r + C_{2} \int_{S}^{\infty} (r - S) f(r) \ \mathrm{d}r
		\end{aligned}
		$$
		成立。
		当 $s = S$ 时，不等式显然成立
		当 $s < S$ 时，上面不等式右端存贮费用期望值大于左端存储费用期望值，右端缺货费用期望值小于左端缺货费用期望值，一减一增后，使不等式成立的可能性是存在的，若满足上述不等式的 $s$ 不止一个，则选取其中最小的作为 $(s, S)$ 型存贮策略的 $s$ 
		*第 4 步*：最终结论
		综上所述，我们得到的存贮策略是：每个月底检查库存，若库存 $I < s$ 时，需订货，订货的数量为 $Q = S - I$，当库存 $I \ge s$ 时，本月不订货
- **二堆方法**：定期订货但订货数量不确定，订货数量的多少，取决于库存 $I$。对于不易清点数量的存贮，人们常把存贮分两堆存放，一堆的数量为 $s$，其余的放另一堆，平常从另放的一堆中取用。当动用了数量为 $s$ 的一堆时，月底即订货，若没有动用数量为 $s$ 的一堆时，月底可以不订货，因此这种方法，俗称**二堆方法**。
#### 4-3-3-2 需求为离散型随机变量
- *模型假设* 
	- 商品在一个月中需求取值为 $r_{0}, r_{1}, \cdots, r_{m}$ 其中 $r_{i} < r_{i+1}$，对应的概率为 $p_{0}, p_{1}, \cdots, p_{m}$，满足 $\sum\limits_{i=0}^{m} p_{i} = 1$ 
	- 每件商品的进价为 $K$，每件商品一个月的存贮费为 $C_{1}$，每件商品的缺货损失费为 $C_{2}$，每次订购费用为 $C_{3}$（与订购数量无关）
	- 记月底的存货量为 $I$，订货量为 $Q$（每月最多订一次货），并且订货以后，立即到货，于是下个月初货物存贮达到 $I + Q$ 
- *结论*：存储策略为：每个月底检查库存，若库存 $I < s$ 时，需订货，订货的数量为 $Q = S - I$，当库存 $I \ge s$ 时，本月不订货（$s, S$ 如何确定详见过程）
	*第 1 步*：初步分析
	根据上述假设，本月所需的各种费用如下：
	订货费：$C_{3} + KQ$ 
	存贮费：当需求 $r < I + Q$ 时，没有售出的货物需支付存贮费，所需存贮费的期望值为 $\sum\limits_{r \leqslant I+Q} C_{1} (I + Q - r) p_{r}$ 
	缺货损失费：当需求量 $r > I + Q$ 时，$(r - I - Q)$ 件货物需付缺货费，缺货损失费用的期望值 $\sum\limits_{r > I + Q} C_{2}(r - I - Q) p_{r}$ 
	本月总费用的期望值为 $C(I + Q) = C_{3} + KQ + \sum\limits_{r \leqslant Q + I} C_{1}(I + Q - r) p_{r} + \sum\limits_{r > I + Q} C_{2}(r - I - Q) p_{r}$ 
	记 $S = I + Q$，则有 $C(S) = C_{3} + KQ + \sum\limits_{r \leqslant S} C_{1}(S - r) p_{r} + \sum\limits_{r > S} C_{2}(r - S) p_{r}$ 
	求出 $S$ 值，使 $C(S)$ 最小。
	*第 2 步*：求 $S$ 值
	第一步，将需求量 $r$ 的取值按大小顺序排列为 $r_{0}$, $r_{1}$, …, $r_{m}$，其中 $r_{i} < r_{i+1}$，记 $\Delta r_{i} = r_{i+1} - r_{i}$。
	第二步，$S$ 只从 $r_{0}, r_{1}, \cdots, r_{m}$ 中取值，当 $S$ 取值 $r_{i}$ 时，记为 $S_{i}$，记 $\Delta S_{i}=S_{i+1}-S_{i}=r_{i+1}-r_{i}=\Delta r_{i} \neq 0$ 
	第三步，求 $S$ 的值，使 $C(S)$ 最小。
	因
	$$
	\begin{aligned}
	&C\left(S_{i+1}\right)=C_{3}+K\left(S_{i+1}-I\right)+\sum\limits_{r \leqslant S_{i+1}} C_{1}\left(S_{i+1}-r\right) p_{r}+\sum\limits_{r>S_{i+1}} C_{2}\left(r-S_{i+1}\right) p_{r} \\ 
	&C\left(S_{i}\right)=C_{3}+K\left(S_{i}-I\right)+\sum\limits_{r \leqslant S_{i}} C_{1}\left(S_{i}-r\right) p_{r}+\sum\limits_{r>S_{i}} C_{2}\left(r-S_{i}\right) p_{r} \\
	&C\left(S_{i-1}\right) = C_{3}+K\left(S_{i-1}-I\right)+\sum\limits_{r \leqslant S_{i-1}} C_{1}\left(S_{i-1}-r\right) p_{r}+\sum\limits_{r>S_{i-1}} C_{2}\left(r-S_{i-1}\right) p_{r}
	\end{aligned}
	$$
	若 $C\left(S_{i}\right)=\min\limits_{0 \leqslant j \leqslant m} C\left(S_{j}\right)$，则 $\left\{ \begin{array}{l} C\left(S_{i+1}\right)-C\left(S_{i}\right) \geqslant 0 \\ C\left(S_{i}\right)-C\left(S_{i-1}\right) \leqslant 0 \end{array} \right.$ 
	令 $\Delta C\left(S_{i}\right)=C\left(S_{i+1}\right)-C\left(S_{i}\right)$，则通过化简 $\Delta C\left(S_{i}\right)=K \Delta S_{i}+\left(C_{1}+C_{2}\right) \Delta S_{i} \sum\limits_{r \leqslant S_{i}} p_{r}-C_{2} \Delta S_{i} \geqslant 0$ 
	固定 $\Delta S_i > 0$，所以 $\sum\limits_{r \leqslant S_i} p_r \geqslant \dfrac{C_2 - K}{C_1 + C_2}$ 
	仿照上面的做法，我们可得类似的不等式 $\sum\limits_{r \leqslant S_{i-1}} p_r \geqslant \dfrac{C_2 - K}{C_1 + C_2}$ 
	记 $N = \dfrac{C_2 - K}{C_1 + C_2}$，我们得到确定 $S_i$ 的不等式 $\boxed{\sum\limits_{r \leqslant S_{i-1}} p_r < \dfrac{C_2 - K}{C_1 + C_2} = N = \sum\limits_{r \leqslant S_i} p_r\quad (*)}$ 
	取满足 $(*)$ 的 $S_i$ 为 $S$，本月的订货量 $Q = S - I$ 
	*第 3 步*：求 $s$ 值
	考察不等式
	$$
	\begin{aligned}
	&K s + \sum\limits_{r \leqslant s} C_1 (s - r) p_r + \sum\limits_{r > s} C_2 (r - s) p_r \\ 
	&\leqslant C_{3}+K S+\sum\limits_{r \leqslant S} C_{1}(S-r) p_{r}+\sum\limits_{r>S} C_{2}(r-S) p_{r}
	\end{aligned}
	$$
	因 $s$ 只从 $r_{0},r_{1},\cdots ,r_{m}$ 中取值，使不等式成立的 $r_{i}(r_{i} \leqslant S)$ 的值中最小者定为 $s$ 
	事实上，满足上述不等式的 $s$ 一定存在，因为当 $s<S$ 时，不等式左端缺货费用的期望值虽然会增加，但订货费及存贮费用期望值都减少，一增一减使不等式可能成立，在最坏的情形下 $s=S$ 时不等式是成立的
	一般说来，计算 $s$ 比计算 $S$ 要复杂一些。
