# 1 基础概念
- **代数方程**：如果函数未知，但知道变量与函数的代数关系式，便组成**代数方程**，通过求解代数方程解出未知函数。
- **微分方程**：如果函数未知，但知道自变量、未知函数及函数的导数（或微分）组成的关系式，得到的便是**微分方程**，通过求解微分方程求出未知数
- **常微分方程**：自变量只有一个的微分方程称为**常微分方程** 
- **实值微分方程**：自变量、未知函数均为实值的微分方程称为**实值微分方程** 
- **复值微分方程**：未知函数取复值，或自变量及未知函数均取复值时称为**复值微分方程** 
	- 本书只讨论实值微分方程，若无特殊声明，均值实变量的实值微分方程
- **常微分方程**：如果在微分方程中，自变量的个数只有一个，我们称这种微分方程为**常微分方程**，在本文中经常简称为**微分方程**或**方程** 
- **偏微分方程**：如果在微分方程中，自变量的个数为两个或两个以上，我们称这种微分方程为**偏微分方程** 
- **阶数**：微分方程中出现的未知函数最高阶导数的阶数称为微分方程的**阶数** 
- **$n$ 阶线性微分方程**：若方程 $F\left( x, y, \dfrac{\mathrm dy}{\mathrm dx}, \cdots, \dfrac{\mathrm d^n y}{\mathrm dx^n} \right) = 0$ 的左端为 $y, \dfrac{\mathrm dy}{\mathrm dx}, \cdots, \dfrac{\mathrm d^ny}{\mathrm dx^n}$ 的一次有理整式，则称其为 **$n$ 阶线性微分方程** 
	- $n$ 阶线性微分方程的一般形式为 $\dfrac{\mathrm d^n y}{\mathrm dx^n} + a_1(x)\dfrac{\mathrm d^{n-1}y}{\mathrm dx^{n-1}} + \cdots + a_{n-1}(x) \dfrac{\mathrm dy}{\mathrm dx} + a_n(x)y = f(x)$，其中 $a_1(x), \cdots, a_n(x), f(x)$ 为 $x$ 的已知函数
- **非线性微分方程**：不是线性微分方程的微分方程称为**非线性微分方程** 
- **显式解**（**解**）：使微分方程 $F\left( x, y, \dfrac{\mathrm dy}{\mathrm dx}, \cdots, \dfrac{\mathrm d^n y}{\mathrm dx^n} \right) = 0$ 变为恒等式的函数 $y=\varphi(x)$ 称为方程的**显式解**，或称为**解** 
- **隐式解**（**积分**）：如果微分方程 $F\left( x, y, \dfrac{\mathrm dy}{\mathrm dx}, \cdots, \dfrac{\mathrm d^n y}{\mathrm dx^n} \right) = 0$ 的解 $y=\varphi(x)$ 由关系式 $\Phi(x,y)=0$ 决定，则称 $\Phi(x,y)=0$ 为微分方程 $F\left( x, y, \dfrac{\mathrm dy}{\mathrm dx}, \cdots, \dfrac{\mathrm d^n y}{\mathrm dx^n} \right) = 0$ 的**隐式解**，隐式解也成为“**积分**”
- **通解**：$n$ 阶微分方程 $F\left( x, y, \dfrac{\mathrm dy}{\mathrm dx}, \cdots, \dfrac{\mathrm d^n y}{\mathrm dx^n} \right) = 0$ 的含有 $n$ 个独立的任意常数 $c_1, c_2, \cdots, c_n$ 的解 $y=\varphi(x, c_1, c_2, \cdots, c_n)$ 称为 $n$ 阶方程 $F\left( x, y, \dfrac{\mathrm dy}{\mathrm dx}, \cdots, \dfrac{\mathrm d^n y}{\mathrm dx^n} \right) = 0$ 的**通解** 
	- **注释**：对 $\varphi$ 及其 $n-1$ 阶偏导数关于 $n$ 个常数 $c_1, c_2, \cdots, c_n$ 的雅可比（Jacobi）行列式不为 $0$ 
- **定解条件**：为了确定微分方程一个特定的解，我们通常给出这个解所必需的条件，这就是所谓的**定解条件** 
	- 常见的定解条件是初值条件和边值条件
- **初值条件**：所谓 $n$ 阶微分方程 $F\left( x, y, \dfrac{\mathrm dy}{\mathrm dx}, \cdots, \dfrac{\mathrm d^n y}{\mathrm dx^n} \right) = 0$ 的初值条件指 $n$ 个条件：当 $x=x_0$ 时，$y=y_0,\ \dfrac{\mathrm dy}{\mathrm dx} = y_0^{(1)}, \cdots, \dfrac{\mathrm d^{n-1}y}{\mathrm dx^{n-1}} = y_0^{(n-1)}$，这里 $x_0,y_0,y_0^{(1)}, \cdots, y_0^{(n-1)}$ 是给定的 $n-1$ 个常数
	- 该初值条件有时写为 $y(x_0)=y_0,\ \dfrac{\mathrm dy(x_0)}{\mathrm dx} = y_0^{(1)}, \cdots, \dfrac{\mathrm d^{n-1}y(x_0)}{\mathrm dx^{n-1}} = y_0^{(n-1)}$ 
- **定解问题**：求微分方程满足定解条件的解，就是所谓的**定解问题** 
- **初值问题**：当定解条件为初值条件时，相应的定解问题就称为**初值问题** 
- **特解**：满足初值条件的解称为微分方程的**特解** 
- **微分方程组**：用两个以上的关系式表示的微分方程称为**微分方程组** 
# 2 一阶微分方程的初等解法
- 一阶微分方程的一般形式为：$\dfrac{\mathrm dy}{\mathrm dx} = f(x,y)$ 或 $M(x,y)\mathrm dx + N(x,y)\mathrm dy = 0$
## 法 1——用变量变换解决可化为变量分离方程的方程
- **变量分离方程**：形如 $\dfrac{\mathrm dy}{\mathrm dx} = f(x)\varphi(y)$ 的方程，称为**变量分离方程**，这里 $f(x), \varphi(y)$ 分别是 $x,y$ 的连续函数
- 情形 1（**齐次微分方程**）：形如 $\dfrac{\mathrm dy}{\mathrm dx} = g\left( \dfrac yx \right)$ 的方程称为**齐次微分方程**，这里 $g(u)$ 是 $u$ 的连续函数
	- **解法**：令 $u=\dfrac yx$，两边再对 $x$ 求导
- 情形 2：形如 $\dfrac{\mathrm dy}{\mathrm dx} = f(ax+by+c),\ (a\not=0, b\not=0)$，这里 $f(u)$ 是 $u$ 的连续函数
	- **解法**：令 $u=ax+by+c$，两边再对 $x$ 求导
- 情形 3（一般情形）：形如 $\dfrac{\mathrm dy}{\mathrm dx} = f\left( \dfrac{a_1x+b_1y+c_1}{a_2x+b_2y+c_2} \right)$，这里 $a_1,a_2,b_1,b_2,c_1,c_2$ 均为常数
	- 当 $c_1=c_2=0$ 时，$\dfrac{\mathrm dy}{\mathrm dx} = f\left( \dfrac{a_1 + b_1\dfrac yx}{a_2 + b_2\dfrac yx} \right) = g\left( \dfrac yx \right)$ 为齐次微分方程，化为情形 1
	- 当 $c_1, c_2$ 不全为零时
		1. $\begin{vmatrix} a_1 & b_1 \\ a_2 & b_2 \end{vmatrix} \not= 0$ 时，方程组 $\begin{cases} a_1x+b_1y+c_1=0 \\ a_2x+b_2y+c_2=0 \end{cases}$ 有唯一解 $\begin{cases} x = \alpha \\ y=\beta \end{cases}$ 
			令 $\begin{cases} X = x-\alpha \\ Y = y-\beta \end{cases}$，则 $\dfrac{\mathrm dy}{\mathrm dx} = f\left( \dfrac{a_1x+b_1y+c_1}{a_2x+b_2y+c_2} \right)$ 化为 $\dfrac{\mathrm dY}{\mathrm dX} = f\left( \dfrac{a_1 + b_1\dfrac YX}{a_2 + b_2 \dfrac YX} \right) = g\left( \dfrac YX \right)$ 
			化为齐次微分方程的情形
		2. $\begin{vmatrix} a_1 & b_1 \\ a_2 & b_2 \end{vmatrix} = 0$ 时
			(1) $a_1=b_1=0$ 时，$\dfrac{\mathrm dy}{\mathrm dx} = f\left( \dfrac{a_1x+b_1y+c_1}{a_2x+b_2y+c_2} \right)$ 变为 $\dfrac{\mathrm dy}{\mathrm dx} = f\left( \dfrac{c_1}{a_2x+b_2y+c_2} \right)$；$a_2=b_2=0$ 时，$\dfrac{\mathrm dy}{\mathrm dx} = f\left( \dfrac{a_1x+b_1y+c_1}{a_2x+b_2y+c_2} \right)$ 便为 $\dfrac{\mathrm dy}{\mathrm dx} = f\left( \dfrac{a_1x+b_1y+c_1}{c_2} \right)$，化为情形 2
			(2) $b_1=b_2=0$ 时，$\dfrac{\mathrm dy}{\mathrm dx} = f\left( \dfrac{a_1x+b_1y+c_1}{a_2x+b_2y+c_2} \right)$ 变为 $\dfrac{\mathrm dy}{\mathrm dx} = f\left( \dfrac{a_1x+c_1}{a_2x+c_2} \right)$；$a_1=a_2=0$ 时，$\dfrac{\mathrm dy}{\mathrm dx} = f\left( \dfrac{a_1x+b_1y+c_1}{a_2x+b_2y+c_2} \right)$ 变为 $\dfrac{\mathrm dy}{\mathrm dx} = f\left( \dfrac{b_1y+c_1}{b_2y+c_2} \right)$，化为**变量分离方程** 
			(3) $\dfrac{a_1}{a_2} = \dfrac{b_1}{b_2}=k$ 时，令 $u=a_2x+b_2y$，此时 $\dfrac{\mathrm du}{\mathrm dx} = a_2 + b_2 \dfrac{\mathrm dy}{\mathrm dx}$，$f\left( \dfrac{a_1x+b_1y+c_1}{a_2x+b_2y+c_2} \right) = f\left( \dfrac{k(a_2x+b_2y)+c_1}{(a_2x+b_2y)+c_2} \right) = f\left( \dfrac{ku+c_1}{u+c_2} \right) = g(u)$，故 $\dfrac{\mathrm dy}{\mathrm dx} = f\left( \dfrac{a_1x+b_1y+c_1}{a_2x+b_2y+c_2} \right)$ 化为 $\dfrac{\mathrm du}{\mathrm dx} = a_2+b_2g(u)$，化为**变量分离方程** 
## 法 2——用常数变易法解决一阶线性微分方程
- **一阶线性微分方程**：$\dfrac{\mathrm dy}{\mathrm dx} = P(x)y + Q(x)$，其中 $P(x), Q(x)$ 在考虑的区间上是 $x$ 的连续函数。
- **一阶齐次线性微分方程**：$\dfrac{\mathrm dy}{\mathrm dx} = P(x)y$ 
- **一阶非齐次线性微分方程**：$\dfrac{\mathrm dy}{\mathrm dx} = P(x)y + Q(x)$，其中 $Q(x)\not=0$ 
- **一阶齐次线性微分方程 $\dfrac{\mathrm dy}{\mathrm dx} = P(x)y$ 的解法** 
	由于 $\dfrac{\mathrm dy}{\mathrm dx} = P(x)y$ 是变量分离方程，可解得其通解为 $y=ce^{\int P(x)\mathrm dx}$，其中 $c$ 为任意常数
- **一阶非齐次线性微分方程 $\dfrac{\mathrm dy}{\mathrm dx} = P(x)y + Q(x)$ 的解法** 
		令 $\dfrac{\mathrm dy}{\mathrm dx} = P(x)y + Q(x)$ 通解为 $y=c(x) e^{\int P(x)\mathrm dx}$ 的形式，其中 $c(x)$ 为待定函数
		**确定 $c(x)$** 
		对该式求导得到 $\dfrac{\mathrm dy}{\mathrm dx} = \dfrac{\mathrm dc(x)}{\mathrm dx} e^{\int P(x)\mathrm dx} + c(x) P(x) e^{\int P(x)\mathrm dx}$ 
		将 $y=c(x) e^{\int P(x)\mathrm dx}$ 代入 $\dfrac{\mathrm dy}{\mathrm dx} = P(x)y + Q(x)$ 得到 $\dfrac{\mathrm dy}{\mathrm dx} = c(x) P(x) e^{\int P(x)\mathrm dx} + Q(x)$ 
		故 $\dfrac{\mathrm dc(x)}{\mathrm dx} = Q(x)e^{-\int P(x)\mathrm dx}$，积分得到 $\displaystyle c(x) = \int Q(x) e^{-\int P(x)\mathrm dx} \mathrm dx + \overline c$，这里 $\overline c$ 是任意常数
		**代入原式** 
		将该式代入 $y=c(x) e^{\int P(x)\mathrm dx}$，得到 $\dfrac{\mathrm dy}{\mathrm dx} = P(x)y + Q(x)$ 的通解为 $\displaystyle y= e^{\int P(x)\mathrm dx} \left( \int Q(x) e^{-\int P(x)\mathrm dx} \mathrm dx + \overline c \right)$ 
- **伯努利（Bernoulli）微分方程**：$\dfrac{\mathrm dy}{\mathrm dx} = P(x)y + Q(x)y^n,\ (n\not=0, 1,\ n\in \mathbb R)$，其中 $P(x), Q(x)$ 在考虑的区间上是 $x$ 的连续函数
## 法3——验证并求解恰当微分方程
- **恰当微分方程**：若存在某个二元函数 $u(x,y)$，使得 $M(x,y)\mathrm dx + N(x,y)\mathrm dy = \mathrm du(x,y) = \dfrac{\partial u}{\partial x}\mathrm dx + \dfrac{\partial u}{\partial y}\mathrm dy$，则称 $M(x,y)\mathrm dx + N(x,y)\mathrm dy = 0$ 为**恰当微分方程** 
- **方法 1**：利用恰当微分方程的判定求解
	- **验证条件**：先验证 $\dfrac{\partial M}{\partial y} = \dfrac{\partial N}{\partial x}$，若成立，则为恰当微分方程
	- **设出所求**：设所求的 $u(x,y)$ 同时满足条件 $M(x,y) = \dfrac{\partial u}{\partial x}$ 和 $N(x,y) = \dfrac{\partial u}{\partial y}$ 
	- **对 $x$ 积分**：将 $M(x,y) = \dfrac{\partial u}{\partial x}$ 两边关于 $x$ 积分，得到 $\displaystyle \int M(x,y)\mathrm dx + \varphi(y) = u(x,y)$，这里 $\varphi(y)$ 是关于 $y$ 的任何可导函数
	- **对 $y$ 求导**：在 $\displaystyle \int M(x,y)\mathrm dx + \varphi(y) = u(x,y)$ 两边对 $y$ 求导数，得 $\displaystyle \dfrac{\partial u}{\partial y} = \dfrac{\partial}{\partial y}\int M(x,y)\mathrm dx + \dfrac{\mathrm d\varphi(y)}{\mathrm dy} = N(x,y)$，因此 $\displaystyle \dfrac{\mathrm d\varphi(y)}{\mathrm dy} = N(x,y) - \dfrac{\partial}{\partial y} \int M(x,y)\mathrm dx$ 
	- **对 $y$ 积分**：则 $\displaystyle \dfrac{\mathrm d\varphi(y)}{\mathrm dy} = N(x,y) - \dfrac{\partial}{\partial y} \int M(x,y)\mathrm dx$ 的右端是 $y$ 的一元函数，两边积分可得 $\displaystyle \varphi(y) = \int \left[ N(x,y) - \dfrac{\partial}{\partial y}\int M(x,y)\mathrm dx \right]\mathrm dy$ 
	- **代入原式**：将该式代入 $\displaystyle \int M(x,y)\mathrm dx + \varphi(y) = u(x,y)$ 可得 $\displaystyle u(x,y) = \int M(x,y)\mathrm dx + \int \left[ N(x,y) - \dfrac{\partial}{\partial y}\int M(x,y)\mathrm dx \right]\mathrm dy$ 
- **方法 2**：利用曲线积分求 $u(x,y)$ 
	- 验证 $\dfrac{\partial M}{\partial y} = \dfrac{\partial N}{\partial x}$，若成立，则为恰当微分方程
	- $u(x,y)$ 可以利用从定点 $A(x_0,y_0)$ 到动点 $B(x,y)$ 的曲线积分来求，即 $\displaystyle u(x,y) = \int_A^B M(x,y)\mathrm dx + N(x,y)\mathrm dy$ 
	- 可以利用积分与路径的无关性，选择简单的路径进行积分，如 $\displaystyle u(x,y) = \int_{x_0}^x M(x,y_0)\mathrm dx + \int_{y_0}^y N(x,y)\mathrm dy$ 和 $\displaystyle u(x,y) = \int_{y_0}^y M(x_0,y)\mathrm dy + \int_{x_0}^x N(x,y)\mathrm dx$ 
- **方法 3**：分项组合法
	- 利用二元函数微分的特点，将恰当微分方程的各项“分项组合”凑成全微分形式
	- **一些简单二元函数的全微分** 
		- $y\mathrm dx + x\mathrm dy = \mathrm d(xy)$ 
		- $\dfrac{y\mathrm dx-x\mathrm dy}{y^2} = \mathrm d\left( \dfrac xy \right)$ 
		- $\dfrac{-y\mathrm dx + x\mathrm dy}{x^2} = \mathrm d\left( \dfrac yx \right)$ 
		- $\dfrac{y\mathrm dx - x\mathrm dy}{xy} = \mathrm d\left( \ln \left| \dfrac xy \right| \right)$ 
		- $\dfrac{y\mathrm dx - x\mathrm dy}{x^2+y^2} = \mathrm d\left( \mathrm{arccot} \dfrac yx \right)$ 
		- $\dfrac{y\mathrm dx - x\mathrm dy}{x^2-y^2} = \dfrac 12 \mathrm d \left( \ln \left| \dfrac{x-y}{x+y} \right| \right)$ 
## 法 4——用积分因子解决可化为恰当微分方程的方程
- **积分因子**：如果存在连续可微函数 $\mu(x,y)\not=0$，使得 $\mu(x,y)M(x,y)\mathrm dx + \mu(x,y)N(x,y)\mathrm dy = 0$ 为一恰当微分方程，则称 $\mu(x,y)$ 为方程 $M(x,y)\mathrm dx + N(x,y)\mathrm dy = 0$ 的**积分因子** 
- **如何求解积分因子** 
	由于函数 $\mu(x,y)\not=0$ 为方程 $M(x,y)\mathrm dx + N(x,y)\mathrm dy = 0$ 的积分因子 $\iff$ $\dfrac{\partial(\mu M)}{\partial y} = \dfrac{\partial(\mu N)}{\partial x}$ $\iff$ $N\dfrac{\partial \mu}{\partial x} - M \dfrac{\partial \mu}{\partial y} = \left( \dfrac{\partial M}{\partial y} - \dfrac{\partial N}{\partial x} \right)\mu$ 
	若 $M(x,y)\mathrm dx + N(x,y)\mathrm dy = 0$ 存在只与 $x$ 有关的积分因子 $\mu=\mu(x)$ 
	则其充要条件为 $\dfrac{\dfrac{\partial M}{\partial y} - \dfrac{\partial N}{\partial x}}{N} = \psi(x)$，解得 $\mu(x) = e^{\int \psi(x)\mathrm dx}$ 
	若 $M(x,y)\mathrm dx + N(x,y)\mathrm dy = 0$ 存在只与 $y$ 有关的积分因子 $\mu=\mu(y)$ 
	则其充要条件为 $\dfrac{\dfrac{\partial M}{\partial y} - \dfrac{\partial N}{\partial x}}{-M} = \varphi(y)$，解得 $\mu(y) = e^{\int \varphi(y)\mathrm dy}$ 
## 法 5——解一些特殊形式的一阶隐式微分方程
- **一阶隐式微分方程**形式为 $F(x,y,y')=0$ 
	- 若能通过一阶隐式微分方程解出 $y' = f(x,y)$，则再根据之前的方法进行求解 $y'=f(x,y)$ 即可
	- 若不能解出 $y'$ 或 $y' = f(x,y)$ 的形式很复杂，则可通过引进参数使方程变为导数容易解出的方程类型
- 本节主要讨论 $y=f(x,y'),\ x=f(y,y'),\ F(x,y')=0,\ F(y,y')=0$ 四种类型
- 形如 $y=f(x,y')$ 的方程（这里假设函数 $f(x,y')$ 有连续的偏导数）
	令 $y'=p$，两边对 $x$ 求导数，并将 $y'=p$ 代入，得 $p = \dfrac{\partial f}{\partial x} + \dfrac{\partial f}{\partial p} \dfrac{\mathrm dp}{\mathrm dx}$，这是关于 $x,p$ 的一阶微分方程，可用已知方法求解
	若 $p = \dfrac{\partial f}{\partial x} + \dfrac{\partial f}{\partial p} \dfrac{\mathrm dp}{\mathrm dx}$ 的通解为 $\Phi(x,p,c)=0$，则方程 $y=f(x,y')$ 的通解为参数方程形式 $\begin{cases} \Phi(x,p,c)=0 \\ y=f(x,p) \end{cases}$，其中 $p$ 为参数，$c$ 是任意常数
- 形如 $x=f(y,y')$ 的方程（这里假设函数 $f(y,y')$ 有连续的偏导数）
	令 $y'=p$，两边对 $y$ 求导数，并将 $y'=p$ 代入，得 $\dfrac 1p = \dfrac{\partial f}{\partial y} + \dfrac{\partial f}{\partial p} \dfrac{\mathrm dp}{\mathrm dy}$，这是关于 $y,p$ 的一阶微分方程，可按已知方法求解
	若 $\dfrac 1p = \dfrac{\partial f}{\partial y} + \dfrac{\partial f}{\partial p} \dfrac{\mathrm dp}{\mathrm dy}$ 的通解为 $\Phi(y,p,c)=0$，则 $x=f(y,y')$ 的通解为参数方程形式 $\begin{cases} x=f(y,p) \\ \Phi(y,p,c)=0 \end{cases}$，其中 $p$ 为参数，$c$ 是任意常数
- 形如 $F(x,y')=0$ 的方程
	令 $y'=p$，方程化为 $F(x,p)=0$，代表 $Oxp$ 平面上的一条曲线
	如果把曲线表示成参数方程形式 $\begin{cases} x=\varphi(t) \\ p=\psi(t) \end{cases}$，$t$ 为参数，代入 $\mathrm dy = p\mathrm dx$ 得 $\mathrm dy = \psi(t)\varphi'(t)\mathrm dt$ 
	积分得原方程的通解为 $\begin{cases} x=\varphi(t) \\ \displaystyle y=\int \psi(t)\varphi'(t)\mathrm dt + c \end{cases}$，其中 $c$ 为任意常数
- 形如 $F(y,y')=0$ 的方程
	令 $y'=p$，方程化为 $F(y,p)=0$，代表 $Oyp$ 平面上的一条曲线
	如果把曲线表示成参数方程形式 $\begin{cases} y=\varphi(t) \\ p = \psi(t) \end{cases}$，$t$ 为参数，代入 $\mathrm dy = p\mathrm dx$ 得 $\mathrm dx = \dfrac{\varphi'(t)}{\psi(t)} \mathrm dt$ 
	积分得原方程的通解为 $\begin{cases} \displaystyle x = \int \dfrac{\varphi'(t)}{\psi(t)} \mathrm dt + c \\ y = \varphi(t) \end{cases}$，其中 $c$ 为任意常数
	当 $y'=p=0$ 时，$F(y,0)$ 有实根 $y=k$，故 $y=k$ 也是方程的解
# 3 一阶微分方程的一般解法
## 3-1 逐步逼近法解一阶微分方程 $\dfrac{\mathrm dy}{\mathrm dx} = f(x,y)$ 
- **利普希茨（Lipschitz）条件**、**利普希茨常数**：考虑导数已解出的一阶微分方程 $\dfrac{\mathrm dy}{\mathrm dx} = f(x,y)$，这里 $f(x,y)$ 是在矩形域 $R: |x-x_0| \le a,\ |y-y_0| \le b$ 上的连续函数。函数 $f(x,y)$ 称为在 $R$ 上关于 $y$ 满足**利普希茨（Lipschitz）条件**，如果存在常数 $L>0$，使得不等式 $|f(x,y_1) - f(x,y_2)| \le L |y_1-y_2|$ 对于所有 $(x,y_1), (x,y_2) \in R$ 都成立，$L$ 称为**利普希茨常数** 
- **解的存在唯一性定理**：如果 $f(x,y)$ 在矩形域 $R$ 上连续且关于 $y$ 满足利普希茨条件，则方程 $\dfrac{\mathrm dy}{\mathrm dx} = f(x,y)$ 存在唯一的解 $y=\varphi(x)$，定义于 $|x-x_0|\le h$ 上，连续且满足初值条件 $\varphi(x_0) = y_0$，这里 $h = \min \left( a, \dfrac bM \right),\ M = \max\limits_{(x,y)\in R} |f(x,y)|$ 
- 如何解 $\dfrac{\mathrm dy}{\mathrm dx} = f(x,y)$？
	1. 任取一个连续函数 $\varphi_0(x)$ 满足初值条件
	2. 计算**第一次近似解** $\displaystyle \varphi_1(x) = y_0 + \int_{x_0}^x f(x,\varphi_0(x))\mathrm dx$，如果 $\varphi_1(x) = \varphi_0(x)$，那么 $\varphi_0(x)$ 就是积分方程的解，亦是原方程的解
	3. 否则，计算**第二次近似解** $\displaystyle \varphi_2(x) = y_0 + \int_{x_0}^x f(x,\varphi_1(x))\mathrm dx$，如果 $\varphi_2(x) = \varphi_1(x)$，那么 $\varphi_1(x)$ 就是积分方程的解，亦是原方程的解。否则我们继续这个步骤
	4. 可知 $\lim\limits_{n\to\infty} \varphi_n(x) = \varphi(x)$，且 $\varphi(x)$ 一定是积分方程的解，亦是原方程的解
	- 第 $n$ 次近似解 $\varphi_n(x)$ 和真正解 $\varphi(x)$ 在 $|x-x_0|\le h$ 内的误差估计式 $|\varphi_n(x) - \varphi(x)| \le \dfrac{ML^n}{(n+1)!}h^{n+1}$ 
## 3-2 解对初值的连续性与可微性
- **解对初值的连续性定理**：若函数 $f(x,y)$ 在区域 $G$ 内连续，且关于 $y$ 满足局部利普希茨条件，则方程 $\dfrac{\mathrm dy}{\mathrm dx} = f(x,y)$ 的解 $y=\varphi(x,x_0,y_0)$ 作为 $x,x_0,y_0$ 的函数在它的存在范围内是连续的
- **解对初值的可微性定理**：若函数 $f(x,y)$ 以及 $\dfrac{\partial f}{\partial y}$ 都在区域 $G$ 内连续，则方程 $\dfrac{\mathrm dy}{\mathrm dx} = f(x,y)$ 的解 $y=\varphi(x,x_0,y_0)$ 作为 $x,x_0,y_0$ 的函数在它的存在范围内是连续可微的，其解对初值 $x_0,y_0$ 的微分公式为 $\displaystyle \dfrac{\partial \varphi}{\partial x_0} = -f(x_0,y_0) \exp\left( \int_{x_0}^x \dfrac{\partial f(x,\varphi)}{\partial y} \mathrm dx \right)$ 和 $\displaystyle \dfrac{\partial \varphi}{\partial y_0} = \exp\left( \int_{x_0}^x \dfrac{\partial f(x,\varphi)}{\partial y} \mathrm dx \right)$ 
## 3-3 奇解、包络
- 包络等价于奇解：对同一个满足某条件的方程，几何上称其为包络，微分方程中称其为奇解
- **包络**：设给定单参数曲线族 $\Phi(x,y,c)=0$，其中 $c$ 是参数，$\Phi(x,y,c)$ 是 $x,y,c$ 的连续可微函数。曲线族 $\Phi(x,y,c)$ 的**包络**是指这样的曲线，它本身并不包含在曲线族 $\Phi(x,y,c)=0$ 中，但过此曲线的每一点，有曲线族 $\Phi(x,y,c)=0$ 中的一条曲线和它在这点相切
- **奇解**：微分方程的某一个解称为奇解，如果在这个解的每一点上至少还有方程的另外一个解存在
- **求包络的方法** 
	- 设已知曲线族 $\Phi(x,y,c)=0$ 
	- 求出 $\Phi_c'(x,y,c)=0$ 
	- 联立 $\begin{cases} \Phi(x,y,c)=0 \\ \Phi_c'(x,y,c)=0 \end{cases}$ 消去 $c$ 得到一个或一些新的曲线，称为 $\Phi(x,y,c)=0$ 的 **$c-$判别曲线** 
	- 根据 $c-$判别曲线的几何画图直观或验证以下三点来判断是否为包络：
		- **不在曲线族本身**：$c-$判别曲线不是曲线族 $\varPhi(x,y,c)=0$ 的任一特定曲线
		- **与曲线族相切**：取 $c-$判别曲线中任意一点 $P_0(x_0,y_0)$ 代入曲线族 $\varPhi(x_0,y_0,c)=0$ 求出参数 $c=c_0$；计算 $P_0$ 点处 $c-$判别曲线的斜率 $k_L$ 和特定曲线 $\varPhi(x,y,c_0)=0$ 的斜率 $k_\varPhi$，满足 $k_L=k_\varPhi$ 
		- **与曲线族只相切于一点**：即验证 $c_0$ 是唯一的
- **求奇解的方法** 
	- 设已知方程为 $F\left( x,y,\dfrac{\mathrm dy}{\mathrm dx} \right) = 0$，令 $p=\dfrac{\mathrm dy}{\mathrm dx}$，则方程为 $F(x,y,p)=0$ 
	- 求出 $F_p'(x,y,p)=0$ 
	- 联立 $\begin{cases} F(x,y,p)=0 \\ F_p'(x,y,p)=0 \end{cases}$ 消去 $p$ 而得到一个或一些新的曲线，称为 $F(x,y,p)$ 的 **$p-$判别曲线** 
	- 根据 $p-$判别曲线的几何画图直观或验证以下三点来判断是否为奇解：
		- **是解**：$p-$判别曲线是微分方程 $F\left( x,y,\dfrac{\mathrm dy}{\mathrm dx} \right) = 0$ 的解
		- **不是通解中的特解**：$p-$判别曲线不是微分方程 $F\left( x,y,\dfrac{\mathrm dy}{\mathrm dx} \right) = 0$ 的通解的任一特解
		- **是通解曲线族的包络**：取 $p-$判别曲线中任意一点 $P_0(x_0,y_0)$ 代入通解表达式 $\varPhi(x_0,y_0,c)=0$ 求出参数 $c=c_0$；计算 $P_0$ 点处 $p-$判别曲线的斜率 $k_L$ 和积分曲线 $\varPhi(x,y,c_0)=0$ 的斜率 $k_\varPhi$，满足 $k_L=k_\varPhi$ 
- **克莱罗（Clairaut）微分方程**：形如 $y=xp+f(p)$ 的方程，称为**克莱罗（Clairaut）微分方程**，这里 $p=\dfrac{\mathrm dy}{\mathrm dx}$，$f(p)$ 是 $p$ 的连续可微函数
	- **克莱罗微分方程的通解**：$y=cx+f(c)$，$c$ 为任意常数
	- **克莱罗微分方程的奇解**：只需验证其通解构成的曲线族的 $c-$判别曲线在曲线族中即可
# 4 高阶微分方程
## 4-1 解 $n$ 阶非齐次线性微分方程
- 解 $n$ 阶非齐次线性微分方程 $\dfrac{\mathrm d^n x}{\mathrm dt^n} + a_1(t) \dfrac{\mathrm d^{n-1} x}{\mathrm dt^{n-1}} + \cdots + a_{n-1}(t) \dfrac{\mathrm dx}{\mathrm dt} + a_n(t)x = f(t)$ 的通用方法
	1. 假设已经求出对应的齐次线性微分方程 $\dfrac{\mathrm d^n x}{\mathrm dt^n} + a_1(t) \dfrac{\mathrm d^{n-1} x}{\mathrm dt^{n-1}} + \cdots + a_{n-1}(t) \dfrac{\mathrm dx}{\mathrm dt} + a_n(t)x = 0$ 的基本解组 $x_1(t), x_2(t), \cdots, x_n(t)$ 
	2. 用常数变易法，令原方程的通解为 $c_1(t)x_1(t) + c_2(t)x_2(t) + \cdots + c_n(t)x_n(t)$，其中 $c_1(t), c_2(t), \cdots, c_n(t)$ 为待定函数
	3. 解方程 $\begin{cases} c_1'(t)x_1(t) + c_2'(t)x_2(t) + \cdots + c_n'(t)x_n(t) = 0 \\ c_1'(t)x_1'(t) + c_2'(t)x_2'(t) + \cdots + c_n'(t)x_n'(t)=0 \\ \cdots \\ x_1^{(n-2)}(t)c_1'(t) + x_2^{(n-2)}(t)c_2'(t) + \cdots + x_n^{(n-2)}(t)c_n'(t) = 0 \\ x_1^{(n-1)}(t)c_1'(t) + x_2^{(n-1)}(t)c_2'(t) + \cdots + x_n^{(n-1)}(t)c_n'(t) = f(t) \end{cases}$ 得到 $c_1'(t), c_2'(t), \cdots, c_n'(t)$ 
	4. 求积分得 $c_1(t), c_2(t), \cdots, c_n(t)$ 
	5. 代入原方程得通解 $c_1(t)x_1(t) + c_2(t)x_2(t) + \cdots + c_n(t)x_n(t)$ 
## 4-2 解 $n$ 阶常系数线性微分方程
- 解 $n$ 阶常系数线性微分方程 $\dfrac{\mathrm d^nx}{\mathrm dt^n} + a_1 \dfrac{\mathrm d^{n-1}x}{\mathrm dt^{n-1}} + \cdots + a_{n-1} \dfrac{\mathrm dx}{\mathrm dt} + a_nx = f(t)$ 的通用方法
	1. 写出特征方程 $F(\lambda) \equiv \lambda^n + a_1\lambda^{n-1} + \cdots + a_{n-1}\lambda + a_n$ 
	2. 解 $F(\lambda)=0$ 得到 $n$ 个特征值：$k_1$ 重根 $\lambda_1$，$k_2$ 重根 $\lambda_2$，……，$k_m$ 重根 $\lambda_m$ 
	3. 则对应的常系数齐次线性微分方程的基本解组为 $\begin{cases} e^{\lambda_1 t}, te^{\lambda_1 t}, t^2e^{\lambda_1 t}, \cdots, t^{k_1-1}e^{\lambda_1t} \\ e^{\lambda_2 t}, te^{\lambda_2 t}, t^2e^{\lambda_2 t}, \cdots, t^{k_2-1}e^{\lambda_2t} \\ \cdots \\ e^{\lambda_m t}, te^{\lambda_m t}, t^2e^{\lambda_m t}, \cdots, t^{k_m-1}e^{\lambda_mt}  \end{cases}$，注：若 $\lambda = \alpha + i\beta$ 是 $k$ 重特征值，则 $\overline \lambda = \alpha - i\beta$ 也是 $k$ 重特征值可得到常系数齐次线性微分方程的 $2k$ 个实值解：$\begin{cases} e^{\alpha t}\cos \beta t,\ te^{\alpha t}\cos \beta t,\ t^2e^{\alpha t}\cos \beta t,\ t^{k-1}e^{\alpha t}\cos \beta t \\ e^{\alpha t}\sin \beta t,\ te^{\alpha t}\sin \beta t,\ t^2e^{\alpha t}\sin \beta t,\ t^{k-1}e^{\alpha t}\sin \beta t \end{cases}$ 
	4. 再用常数变易法求解即可
- 解 $n$ 阶常系数线性微分方程 $\dfrac{\mathrm d^nx}{\mathrm dt^n} + a_1 \dfrac{\mathrm d^{n-1}x}{\mathrm dt^{n-1}} + \cdots + a_{n-1} \dfrac{\mathrm dx}{\mathrm dt} + a_nx = f(t)$ 的特殊方法
	- **类型一**：设 $f(t) = (b_0t^m + b_1t^{m-1} + \cdots + b_{m-1}t + b_m)e^{\lambda_0 t}$，其中 $\lambda_0$ 及 $b_i\ (i=0,1,2,\cdots,m)$ 为实常数
		则原方程有形如 $\widetilde x = t^{k_0}(B_0t^m + B_1t^{m-1} + \cdots + B_{m-1}t + B_m)e^{\lambda_0 t}$ 的特解，其中 $k_0$ 为特征方程 $F(\lambda) = 0$ 的根 $\lambda$ 的重数（单根相当于 $k=1$，当 $\lambda_0$ 不是特征值时，取 $k=0$），而 $B_0,B_1,\cdots,B_m$ 是待定常数，将特解代入微分方程并比较 $t$ 的同次幂系数的方法确定
	- **类型二**：设 $f(t) = [A(t)\cos\beta t + B(t)\sin\beta t]e^{\alpha t}$，其中 $\alpha,\beta$ 为常数，而 $A(t), B(t)$ 是带实系数的 $t$ 的多项式，其中一个的次数为 $m$，而另一个的次数不超过 $m$ 
		那么方程 $L[x] \equiv \dfrac{\mathrm d^nx}{\mathrm dt^n} + a_1 \dfrac{\mathrm d^{n-1}x}{\mathrm dt^{n-1}} + \cdots + a_{n-1} \dfrac{\mathrm dx}{\mathrm dt} + a_nx = f(t)$ 有形如 $\widetilde x = t^{k_0} [P(t)\cos\beta t + Q(t)\sin\beta t]e^{\alpha t}$ 的特解，这里 $k_0$ 为特征方程 $F(\lambda)=0$ 的根 $\alpha + i\beta$ 的重数，而 $P(t),Q(t)$ 均为待定的带实系数的次数不高于 $m$ 的 $t$ 的多项式，可以通过比较系数的方法来确定
## 4-3 高阶微分方程的降阶
- **第一类**：方程不显含未知函数 $x$，或更一般地，设方程不含 $x,x',\cdots,x^{(k-1)}$，即方程形如 $F(t,x^{(k)}, x^{(k+1)}, \cdots, x^{(n)}) = 0\ (1\le k\le n)$ 
	- 做变换 $x^{(k)}(t)=y(t)$，等价于求解方程 $F(t,y,y', \cdots, y^{(n-k)})=0$，即可降 $k$ 阶
- **第二类**：不显含自变量 $t$ 的方程 $F(x, x', \cdots, x^{(n)})=0$ 
	- 做变换 $x'(t)=y(t)$ 
	- $x^{(k)}$ 可用 $y,\dfrac{\mathrm dy}{\mathrm dx}, \cdots, \dfrac{\mathrm d^{k-1}y}{\mathrm dx^{k-1}}$ 表示 $(k\le n)$ 
	- 等将于求解方程 $G\left( x,y,\dfrac{\mathrm dy}{\mathrm dx}, \cdots, \dfrac{\mathrm d^{n-1}y}{\mathrm dx^{n-1}} \right) = 0$，$x$ 为自变量，$y$ 为函数，即可降 $1$ 阶
- **第三类**：齐次线性微分方程 $\dfrac{\mathrm d^nx}{\mathrm dt^n} + a_1(t) \dfrac{\mathrm d^{n-1}x}{\mathrm dt^{n-1}} + \cdots + a_{n-1}(t) \dfrac{\mathrm dx}{\mathrm dt} + a_n(t)x = 0$，且已知 $k$ 个线性无关解 $x_1,x_2,\cdots,x_k$ 
	- 做变换 $z_i(t) = \left( \dfrac{x_i(t)}{x_k(t)} \right)'\ (i=1,2,\cdots,k-1)$，原方程可化为 $z^{(n-1)} + b_1(t)z^{(n-2)} + \cdots + b_{n-1}(t)z=0$ 
	- 按照上述过程仍可降阶，总共可降 $k$ 阶
## 4-4 二阶线性微分方程的幂级数解法
- **定理**：若方程 $\dfrac{\mathrm d^2y}{\mathrm dx^2} + p(x)\dfrac{\mathrm dy}{\mathrm dx} + q(x)y = 0$ 中系数 $p(x)$ 和 $q(x)$ 都能展开成 $x$ 的幂级数，且收敛区间为 $|x|<R$，则方程 $\dfrac{\mathrm d^2y}{\mathrm dx^2} + p(x)\dfrac{\mathrm dy}{\mathrm dx} + q(x)y = 0$ 有形如 $y=\sum\limits_{n=0}^\infty a_nx^n$ 的特解，也以 $|x|<R$ 为级数的收敛区间
- **定理**：若方程 $\dfrac{\mathrm d^2y}{\mathrm dx^2} + p(x)\dfrac{\mathrm dy}{\mathrm dx} + q(x)y = 0$ 中系数 $p(x)$ 和 $q(x)$ 具有这样的性质，即 $xp(x)$ 和 $x^2q(x)$ 均能展开成 $x$ 的幂级数，且收敛区间为 $|x|<R$，若 $a_0\not=0$，则方程 $\dfrac{\mathrm d^2y}{\mathrm dx^2} + p(x)\dfrac{\mathrm dy}{\mathrm dx} + q(x)y = 0$ 有形如 $y=x^\alpha \sum\limits_{n=0}^\infty a_nx^n$，即 $y=\sum\limits_{n=0}^\infty a_n x^{\alpha + n}$ 的特解，$\alpha$ 是一个待定的常数，级数 $y=\sum\limits_{n=0}^\infty a_n x^{\alpha + n}$ 也以 $|x|<R$ 为收敛区间
# 5 线性微分方程组
## 5-0 $n$ 阶方程与 $1$ 阶方程组之间的联系
第 4 章和第 5 章的**联系**：$\begin{cases} x^{(n)} + a_1(t)x^{(n-1)} + \cdots + a_{n-1}(t)x' + a_n(t)x = f(t) \\ x(t_0) = \eta_1,\ x'(t_0) = \eta_2, \cdots, x^{(n-1)}(t_0) = \eta_n \end{cases}$ $\iff$ $\begin{cases} \boldsymbol x' = \begin{bmatrix} 0 & 1 & 0 & \cdots & 0 \\ 0 & 0 & 1 & \cdots & 0 \\ \vdots & \vdots & \vdots & & \vdots \\ 0 & 0 & 0 & \cdots & 1 \\ -a_n(t) & -a_{n-1}(t) & -a_{n-2}(t) & \cdots & -a_1(t) \end{bmatrix}\boldsymbol x + \begin{bmatrix} 0 \\ 0 \\ \vdots \\ 0 \\ f(t) \end{bmatrix} \\ \boldsymbol x(t_0) = \boldsymbol\eta \end{cases}$ 
## 5-1 解齐次线性微分方程组
- **解矩阵**、**基解矩阵**、**标准基解矩阵**：如果 一个 $n\times n$ 矩阵的每一列都是 $\boldsymbol x' = \boldsymbol A(t)\boldsymbol x$ 的解，我们称这个矩阵维 $\boldsymbol x' = \boldsymbol A(t)\boldsymbol x$ 的**解矩阵**。它的列再 $a\le t\le b$ 上是线性无关的解矩阵，称为在 $a\le t\le b$ 上 $\boldsymbol x' = \boldsymbol A(t)\boldsymbol x$ 的**基解矩阵**，我们用 $\boldsymbol \Phi(t)$ 表示由 $\boldsymbol x' = \boldsymbol A(t)\boldsymbol x$ 的 $n$ 个线性无关的解 $\boldsymbol \varphi_1(t), \boldsymbol\varphi_2(t), \cdots, \boldsymbol\varphi_n(t)$ 作为列构成的基解矩阵。当 $\boldsymbol\varPhi(t_0) = \boldsymbol E$（$\boldsymbol E$ 维单位矩阵）时称其为**标准基解矩阵** 
	- **基解矩阵必定存在**：$\boldsymbol x' = \boldsymbol A(t)\boldsymbol x$ 一定存在一个基解矩阵 $\boldsymbol \Phi(t)$ 
	- **基解矩阵线性组合可表示任一解**：
	- **基解矩阵的判定方法**：$\boldsymbol x' = \boldsymbol A(t)\boldsymbol x$ 的一个解矩阵 $\boldsymbol\varPhi(t)$ 是基解矩阵 $\iff$ $\det \boldsymbol\varPhi(t)\not=0\ (a\le t\le b)$，而且，如果对某一个 $t_0\in [a,b]$，$\det \boldsymbol\varPhi(t_0)\not=0$，则 $\det \boldsymbol\varPhi(t)\not=0\ (a\le t\le b)$ 
	- **基解矩阵之间的关系**：如果 $\boldsymbol\varPhi(t), \boldsymbol\psi(t)$ 在 $a\le t\le b$ 上是 $\boldsymbol x' = \boldsymbol A(t)\boldsymbol x$ 的两个基解矩阵，那么存在一个非奇异 $n\times n$ 常数矩阵 $\boldsymbol C$，使得在 $a\le t\le b$ 上 $\boldsymbol\psi(t) = \boldsymbol\varPhi(t)\boldsymbol C$ 
- 求 $\boldsymbol x' = \boldsymbol A(t) \boldsymbol x$ 的通解 $\boldsymbol\psi(t)$：
	- 解出一个基解矩阵 $\boldsymbol \varPhi(t)$ 
	- 则 $\boldsymbol\psi(t) = \boldsymbol\varPhi(t)\boldsymbol c$ 为原方程组通解，这里 $\boldsymbol c$ 是确定的 $n$ 维常数列向量
- 求 $\boldsymbol x' = \boldsymbol A(t) \boldsymbol x$ 的满足初值条件 $\boldsymbol\varphi_h(t_0) = \boldsymbol\eta$ 的解
	- 解出一个基解矩阵 $\boldsymbol \varPhi(t)$ 
	- $\displaystyle \boldsymbol\varphi_h(t) = \boldsymbol\varPhi(t)\boldsymbol\varPhi^{-1}(t_0)\boldsymbol\eta$ 是 $\boldsymbol x' = \boldsymbol A(t)\boldsymbol x$ 的满足初值条件 $\boldsymbol\varphi_h(t_0) = \boldsymbol\eta$ 的解
## 5-2 解非齐次线性微分方程组
- 求 $\boldsymbol x' = \boldsymbol A(t) \boldsymbol x + \boldsymbol f(t)$ 的满足初值条件 $\boldsymbol\varphi(t_0) = \boldsymbol\eta$ 的解 $\boldsymbol\varphi(t)$：
	- 解出 $\boldsymbol x' = \boldsymbol A(t)\boldsymbol x$ 的一个基解矩阵 $\boldsymbol\varPhi(t)$ 
	- 通过**常数变易公式** $\displaystyle \boldsymbol\varphi(t) = \boldsymbol\varPhi(t)\boldsymbol\varPhi^{-1}(t_0)\boldsymbol\eta + \boldsymbol\varPhi(t)\int_{t_0}^t \boldsymbol\varPhi^{-1}(s)\boldsymbol f(s)\mathrm ds$ 即为所求（这里 $\displaystyle \boldsymbol\varphi_h(t) = \boldsymbol\varPhi(t)\boldsymbol\varPhi^{-1}(t_0)\boldsymbol\eta$ 是 $\boldsymbol x' = \boldsymbol A(t)\boldsymbol x$ 的满足初值条件 $\boldsymbol\varphi_h(t_0) = \boldsymbol\eta$ 的解）
- 求 $\boldsymbol x' = \boldsymbol A(t)\boldsymbol x + \boldsymbol f(t)$ 的通解 $\boldsymbol\psi(t)$：
	- 解出 $\boldsymbol x' = \boldsymbol A(t)\boldsymbol x$ 的一个基解矩阵 $\boldsymbol\varPhi(t)$ 
	- 自己任给一个初值条件（如 $\boldsymbol\varphi(0) = \boldsymbol 0$），求出原方程一个特解 $\displaystyle \boldsymbol\varphi(t) = \boldsymbol\varPhi(t)\boldsymbol\varPhi^{-1}(t_0)\boldsymbol\eta + \boldsymbol\varPhi(t)\int_{t_0}^t \boldsymbol\varPhi^{-1}(s)\boldsymbol f(s)\mathrm ds$ 
	- 则 $\boldsymbol\psi(t) = \boldsymbol\varPhi(t)\boldsymbol c + \boldsymbol\varphi(t)$ 即为原方程的通解
## 5-3 用常数变易公式解 $n$ 阶非齐次线性微分方程组
- **$n$ 阶非齐次线性微分方程的常数变易公式**：如果 $a_1(t), a_2(t), \cdots, a_n(t), f(t)$ 是 $a\le t\le b$ 上的连续函数，$x_1(t), x_2(t), \cdots, x_n(t)$ 是 $a\le t\le b$ 上齐次线性微分方程 $x^{(n)} + a_1(t)x^{(n-1)} + \cdots + a_n(t)x = 0$ 的基本解组，那么非齐次线性微分方程 $x^{(n)} + a_1(t)x^{(n-1)} + \cdots + a_n(t)x = f(t)$ 的满足初值条件 $\varphi(t_0) = 0,\ \varphi'(t_0) = 0, \cdots, \varphi^{(n-1)}(t_0) = 0,\ t_0\in [a,b]$ 的解由**常数变易公式** $\displaystyle \varphi(t) = \sum_{k=1}^n x_k(t) \int_{t_0}^t \dfrac{W_k[x_1(s), x_2(s), \cdots, x_n(s)]}{W[x_1(s), x_2(s), \cdots, x_n(s)]} f(s)\mathrm ds$ 给出，这里 $W[x_1(s), x_2(s), \cdots, x_n(s)]$ 是 $x_1(s), x_2(s), \cdots, x_n(s)$ 的朗斯基行列式，$W_k[x_1(s), x_2(s), \cdots, x_n(s)]$ 是在 $W[x_1(s), x_2(s), \cdots, x_n(s)]$ 中的第 $k$ 列代以 $(0,0,\cdots,0,1)^T$ 后得到的行列式，而且 $x^{(n)} + a_1(t)x^{(n-1)} + \cdots + a_n(t)x = f(t)$ 的任一解 $u(t)$ 都具有形式 $u(t) = c_1x_1(t) + c_2x_2(t) + \cdots + c_nx_n(t) + \varphi(t)$，这里 $c_1,c_2,\cdots,c_n$ 是适当选取的常数
## 5-4 求常系数齐次线性微分方程组的基解矩阵
- **一些概念与性质** 
	- **定理**：矩阵 $\boldsymbol\varPhi(t) = \exp \boldsymbol At$ 是 $\boldsymbol x' = \boldsymbol A\boldsymbol x$ 的基解矩阵，且 $\boldsymbol\varPhi(0) = \boldsymbol E$ 
	- 如果 $\boldsymbol A$ 是实矩阵，那么 $\exp \boldsymbol At$ 也是实矩阵 
	- **特征值**、**对应于特征值的特征向量**：假设 $\boldsymbol A$ 是一个 $n\times n$ 常数矩阵，使得关于 $\boldsymbol u$ 的线性代数方程组 $(\lambda \boldsymbol E - \boldsymbol A)\boldsymbol u = \boldsymbol 0$ 具有非零解的常数 $\lambda$ 称为 $\boldsymbol A$ 的一个**特征值**。$(\lambda\boldsymbol E - \boldsymbol A)\boldsymbol u = \boldsymbol 0$ 的对应于任一特征值 $\lambda$ 的非零解 $\boldsymbol u$ 称为 **$\boldsymbol A$ 的对应于特征值 $\lambda$ 的特征向量** 
- 若 $\boldsymbol x' = \boldsymbol A\boldsymbol x$ 的矩阵 $\boldsymbol A$ 具有 $n$ 个线性无关的特征向量 $\boldsymbol v_1, \boldsymbol v_2, \cdots, \boldsymbol v_n$：
	- 通过 $\det(\lambda\boldsymbol E - \boldsymbol A) = 0$ 求解对应的特征值分别为 $\lambda_1, \lambda_2, \cdots, \lambda_n$（不必各不相同）
	- 通过 $(\lambda_i\boldsymbol E - \boldsymbol A)\boldsymbol\mu = \boldsymbol0$ 求解特征向量 $\boldsymbol v_1, \boldsymbol v_2, \cdots, \boldsymbol v_n$，保证它们总共有 $n$ 个，且彼此线性无关
	- 那么矩阵 $\boldsymbol\varPhi(t) = [e^{\lambda_1 t}\boldsymbol v_1, e^{\lambda_2 t}\boldsymbol v_2, \cdots, e^{\lambda_n t}\boldsymbol v_n],\ (-\infty < t < +\infty)$ 是常系数线性微分方程组 $\boldsymbol x' = \boldsymbol A\boldsymbol x$ 的一个基解矩阵
	- 基解矩阵 $\boldsymbol \varPhi(t)$ 可能有复数。由于 $\boldsymbol A$ 是实矩阵，通过 $\exp \boldsymbol At = \boldsymbol\varPhi(t)\boldsymbol\varPhi^{-1}(0)$ 可得到实的基解矩阵
- 若 $\boldsymbol x' = \boldsymbol A\boldsymbol x$ 的矩阵 $\boldsymbol A$ 只有一个特征值 $\lambda$ 时（其重数显然为 $n$）:
	- $\exp\boldsymbol At = e^{\lambda t}\exp(\boldsymbol A - \lambda\boldsymbol E)t = e^{\lambda t}\sum\limits_{i=0}^{n-1} \dfrac{t^i}{i!}(\boldsymbol A - \lambda \boldsymbol E)^i$ 
- 若 $\boldsymbol x' = \boldsymbol A\boldsymbol x$ 的矩阵 $\boldsymbol A$ 为一般矩阵：
	- 求出矩阵 $\boldsymbol A$ 的特征值。假设 $\lambda_1, \lambda_2, \cdots, \lambda_k$ 分别是 $n_1,n_2,\cdots,n_k$ 重不同特征值
	- 考虑任一满足初值条件 $\boldsymbol\varphi(0) = \boldsymbol\eta$ 的解 $\boldsymbol\varphi(t)$ 
	- 由方程组 $(\boldsymbol A - \lambda_j \boldsymbol E)^{n_j}\boldsymbol u = \boldsymbol 0$ 的解产生子空间 $U_j\ (j=1,2,\cdots,k)$，可证明 $\boldsymbol\eta$ 可唯一分解为 $\boldsymbol\eta = \boldsymbol v_1 + \cdots + \boldsymbol v_k$，其中 $\boldsymbol v_j \in U_j$，设法求出 $\boldsymbol v_1, \cdots, \boldsymbol v_k$ 
	- 根据 $\boxed{\boldsymbol\varphi(t) = \sum\limits_{j=1}^k e^{\lambda_jt} \left[ \sum\limits_{i=0}^{n_j-1} \dfrac{t^i}{i!}(\boldsymbol A - \lambda_j\boldsymbol E)^i \right]\boldsymbol v_j}$ 求出满足初值条件 $\boldsymbol\varphi(0) = \boldsymbol\eta$ 的解 $\boldsymbol\varphi(t)$ 
	- 令 $\boldsymbol e_1 = \begin{bmatrix} 1 \\ 0 \\ \vdots \\ 0 \\ 0 \end{bmatrix},\ \boldsymbol e_2 = \begin{bmatrix} 0 \\ 1 \\ 0 \\ \vdots \\ 0 \end{bmatrix}, \cdots, \boldsymbol e_n = \begin{bmatrix} 0 \\ 0 \\ \vdots \\ 0 \\ 1 \end{bmatrix}$，分别取 $\boldsymbol\eta = \boldsymbol e_1, \boldsymbol e_2, \cdots, \boldsymbol e_n$，求出对应的 $\boldsymbol\varphi(t)$ 
	- 将上面求出的 $n$ 个 $\boldsymbol\varphi(t)$ 按列排列成矩阵即为所求的基解矩阵 $\exp \boldsymbol At$

## 5-5 解常系数非齐次线性微分方程组
- 求常系数微分方程 $\boldsymbol x' = \boldsymbol A \boldsymbol x + \boldsymbol f(t)$ 的满足初值条件 $\boldsymbol\varphi(t_0) = \boldsymbol\eta$ 的解 $\boldsymbol\varphi(t)$：

	- 通过**常数变易公式** $\displaystyle \boldsymbol\varphi(t) = \exp[(t-t_0)\boldsymbol A]\boldsymbol\eta + \int_{t_0}^t \exp[(t-s)\boldsymbol A]\boldsymbol f(s)\mathrm ds$ 即为所求
## 5-6 拉普拉斯变换
- **拉普拉斯变换**、**原函数**、**像函数**：由积分 $\displaystyle F(s) = \int_0^{+\infty} e^{-st}f(t)\mathrm dt$ 所定义的确定于复平面 $(\Re s>\sigma)$ 上的复变数 $s$ 的函数 $F(s)$，称为函数 $f(t)$ 的拉普拉斯变换，其中 $f(t)$ 于 $t\ge 0$ 有定义，且满足不等式 $|f(t)| < Me^{\sigma t}$（对于复值的 $f(t)$，$|f(t)|$ 表示其模），这里 $M,\sigma$ 为某两个正常数，我们称 $f(t)$ 为**原函数**，而称 $F(s)$ 为**像函数** 
- 给定微分方程 $\dfrac{\mathrm d^n x}{\mathrm dt^n} + a_1\dfrac{\mathrm d^{n-1}x}{\mathrm dt^{n-1}} + \cdots + a_nx = f(t)$ 及初值条件 $x(0) = x_0,\ x'(0) = x_0', \cdots, x^{(n-1)}(0) = x_0^{(n-1)}$，其中 $a_1,a_2,\cdots,a_n$ 是常数，而 $f(t)$ 连续且满足原函数的条件，下面是用拉普拉斯变换求解过程
	- 假设 $x(t)$ 是方程 $\dfrac{\mathrm d^n x}{\mathrm dt^n} + a_1\dfrac{\mathrm d^{n-1}x}{\mathrm dt^{n-1}} + \cdots + a_nx = f(t)$ 的任意解，记 $\begin{matrix} \displaystyle F(s) = \mathscr L[f(t)] \equiv \int_0^{+\infty} e^{-st}f(t)\mathrm dt \\ \displaystyle X(s) = \mathscr L[x(t)] \equiv \int_0^{+\infty} e^{-st}x(t)\mathrm dt \end{matrix}$ 
	- 计算 $\begin{matrix} \mathscr L[x'(t)] = sX(s) - x_0 \\ \vdots \\ \mathscr L[x^{(n)}(t)] = s^nX(s) - s^{n-1}x_0 - s^{n-2}x_0' - \cdots - x_0^{(n-1)} \end{matrix}$ 
	- 对方程 $\dfrac{\mathrm d^n x}{\mathrm dt^n} + a_1\dfrac{\mathrm d^{n-1}x}{\mathrm dt^{n-1}} + \cdots + a_nx = f(t)$ 两端施行拉普拉斯变换，得到 $A(s)X(s) = F(s) + B(s)$，其中 $A(s), B(s), F(s)$ 都是已知多项式，计算 $X(s) = \dfrac{F(s) + B(s)}{A(s)}$ 
	- 查表得到 $x(t)$
