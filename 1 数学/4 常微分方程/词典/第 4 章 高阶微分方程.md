# 4 高阶微分方程
## 4-1 线性微分方程的一般理论
### 4-1-1 存在唯一性定理
- **$n$ 阶齐次线性微分方程**（**齐次线性微分方程**）、**$n$ 阶非齐次线性微分方程**（**非齐次线性微分方程**）、**对应于非齐次线性微分方程的齐次线性微分方程**：我们讨论 $n$ 阶线性微分方程 $\dfrac{\mathrm d^n x}{\mathrm dt^n} + a_1(t) \dfrac{\mathrm d^{n-1} x}{\mathrm dt^{n-1}} + \cdots + a_{n-1}(t) \dfrac{\mathrm dx}{\mathrm dt} + a_n(t)x = f(t)$，其中 $a_i(t)\ (i=1,2,\cdots,n)$ 及 $f(t)$ 都是 $a\le t\le b$ 上的连续函数 
	- 如果 $f(t)\equiv 0$，则原方程变为 $\dfrac{\mathrm d^n x}{\mathrm dt^n} + a_1(t) \dfrac{\mathrm d^{n-1} x}{\mathrm dt^{n-1}} + \cdots + a_{n-1}(t) \dfrac{\mathrm dx}{\mathrm dt} + a_n(t)x = 0$,我们称它为 **$n$ 阶齐次线性微分方程**，简称**齐次线性微分方程** 
	- 而把一般的方程 $\dfrac{\mathrm d^n x}{\mathrm dt^n} + a_1(t) \dfrac{\mathrm d^{n-1} x}{\mathrm dt^{n-1}} + \cdots + a_{n-1}(t) \dfrac{\mathrm dx}{\mathrm dt} + a_n(t)x = f(t)$ 称为 **$n$ 阶非齐次线性微分方程**，简称**非齐次线性微分方程** 
	- 并且通常把 $\dfrac{\mathrm d^n x}{\mathrm dt^n} + a_1(t) \dfrac{\mathrm d^{n-1} x}{\mathrm dt^{n-1}} + \cdots + a_{n-1}(t) \dfrac{\mathrm dx}{\mathrm dt} + a_n(t)x = 0$ 称为**对应于 $\dfrac{\mathrm d^n x}{\mathrm dt^n} + a_1(t) \dfrac{\mathrm d^{n-1} x}{\mathrm dt^{n-1}} + \cdots + a_{n-1}(t) \dfrac{\mathrm dx}{\mathrm dt} + a_n(t)x = f(t)$ 的齐次线性微分方程** 
- **存在唯一性定理**：如果 $a_i(t)\ (i=1,2,\cdots,n)$ 及 $f(t)$ 都是 $a\le t\le b$ 上的连续函数，则对于任一 $t_0 \in [a,b]$ 及任意的 $x_0, x_0^{(1)}, \cdots, x_0^{(n-1)}$，方程 $\dfrac{\mathrm d^n x}{\mathrm dt^n} + a_1(t) \dfrac{\mathrm d^{n-1} x}{\mathrm dt^{n-1}} + \cdots + a_{n-1}(t) \dfrac{\mathrm dx}{\mathrm dt} + a_n(t)x = f(t)$ 存在唯一解 $x=\varphi(t)$ 定义于 $a\le t\le b$ 上，且满足初值条件 $\varphi(t_0) = x_0,\ \dfrac{\mathrm d\varphi(t_0)}{\mathrm dt} = x_0^{(1)}, \cdots, \dfrac{\mathrm d^{n-1}\varphi(t_0)}{\mathrm dt^{n-1}} = x_0^{(n-1)}$ 
### 4-1-2 齐次线性微分方程的解的性质与结构
- **定理 1**（**叠加原理**）：如果 $x_1(t), x_2(t), \cdots, x_k(t)$ 是方程 $\dfrac{\mathrm d^n x}{\mathrm dt^n} + a_1(t) \dfrac{\mathrm d^{n-1} x}{\mathrm dt^{n-1}} + \cdots + a_{n-1}(t) \dfrac{\mathrm dx}{\mathrm dt} + a_n(t)x = 0$ 的 $k$ 个解，那么它们的线性组合 $c_1x_1(t) + c_2x_2(t) + \cdots + c_kx_k(t)$ 也是 $\dfrac{\mathrm d^n x}{\mathrm dt^n} + a_1(t) \dfrac{\mathrm d^{n-1} x}{\mathrm dt^{n-1}} + \cdots + a_{n-1}(t) \dfrac{\mathrm dx}{\mathrm dt} + a_n(t)x = 0$ 的解，这里 $c_1, c_2, \cdots, c_k$ 是任意常数
	- 特别地，$k=n$ 时，方程 $\dfrac{\mathrm d^n x}{\mathrm dt^n} + a_1(t) \dfrac{\mathrm d^{n-1} x}{\mathrm dt^{n-1}} + \cdots + a_{n-1}(t) \dfrac{\mathrm dx}{\mathrm dt} + a_n(t)x = 0$ 有解 $x=c_1x_1(t) + c_2x_2(t) + \cdots + c_nx_n(t)$，它含有 $n$ 个任意常数。
	- 下面解决问题：$x=c_1x_1(t) + c_2x_2(t) + \cdots + c_nx_n(t)$ 在什么条件下能够称为 $n$ 阶齐次线性微分方程 $\dfrac{\mathrm d^n x}{\mathrm dt^n} + a_1(t) \dfrac{\mathrm d^{n-1} x}{\mathrm dt^{n-1}} + \cdots + a_{n-1}(t) \dfrac{\mathrm dx}{\mathrm dt} + a_n(t)x = 0$ 的通解？它将具有什么性质？
- **线性相关**、**线性无关**：考虑定义在 $a\le t\le b$ 上的函数 $x_1(t), x_2(t), \cdots, x_k(t)$，若存在不全为零的常数 $c_1, c_2, \cdots, c_k$ 使得恒等式 $c_1x_1(t) + c_2x_2(t) + \cdots + c_kx_k(t) \equiv 0$ 对于所有 $t\in[a,b]$ 都成立，则称这些函数是**线性相关**的，否则就称这些函数再所给区间上是**线性无关**的 
	- **例子**：函数 $\cos t$ 和 $\sin t$ 在任何区间上都是线性无关的，但函数 $\cos^2t$ 和 $\sin^2t-1$ 在任何区间上都是线性相关的
	- **例子**：函数 $1,t,t^2,\cdots, t^n$ 在任何区间上都是线性无关的
- **朗斯基行列式**：由定义在 $a\le t\le b$ 上的 $k$ 个可微 $k-1$ 次函数 $x_1(t), x_2(t), \cdots, x_k(t)$ 所作成的行列式 $W[x_1(t), x_2(t), \cdots, x_k(t)] \equiv W(t)\equiv \begin{vmatrix} x_1(t) & x_2(t) & \cdots & x_k(t) \\ x_1'(t) & x_2'(t) & \cdots & x_k'(t) \\ \vdots & \vdots & & \vdots \\ x_1^{(k-1)}(t) & x_2^{(k-1)}(t) & \cdots & x_k^{(k-1)}(t) \end{vmatrix}$ 称为这些函数的朗斯基行列式
- **定理 2**：若函数 $x_1(t), x_2(t), \cdots, x_n(t)$ 在 $a\le t\le b$ 上线性相关，则在 $[a,b]$ 上它们的朗斯基行列式 $W(t)\equiv 0$ 
	- *证明过程* 
		由假设可知，存在一组不全为零的常数 $c_1, c_2, \cdots, c_n$ 使得 $c_1x_1(t) + c_2x_2(t) + \cdots + c_nx_n(t) \equiv 0,\ (a\le t\le b)$ 
		将此恒等式依次对 $t$ 求导数，得到 $\begin{cases} c_1x_1'(t) + c_2x_2'(t) + \cdots + c_nx_n'(t) = 0 \\ c_1x_1''(t) + c_2x_2''(t) + \cdots + c_nx_n''(t) = 0 \\ \cdots \\ c_1x_1^{(n-1)}(t) + c_2x_2^{(n-1)}(t) + \cdots + c_nx_n^{(n-1)}(t) = 0 \end{cases}$ 
		将 $c_1x_1(t) + c_2x_2(t) + \cdots + c_nx_n(t) = 0$ 和 $\begin{cases} c_1x_1'(t) + c_2x_2'(t) + \cdots + c_nx_n'(t) = 0 \\ c_1x_1''(t) + c_2x_2''(t) + \cdots + c_nx_n''(t) = 0 \\ \cdots \\ c_1x_1^{(n-1)}(t) + c_2x_2^{(n-1)}(t) + \cdots + c_nx_n^{(n-1)}(t) = 0 \end{cases}$ 看成关于 $c_1, c_2, \cdots, c_n$ 的齐次线性代数方程组，它的系数行列式就是 $W[x_1(t), x_2(t), \cdots, x_n(t)]$ 
		于是由线性代数理论知道，要此方程组存在非零解，则它的系数行列式必须为零，即 $W(t)\equiv 0\ (a\le t\le b)$，定理证毕！
	- **注意**：此定理的逆定理不成立，存在这样的函数组，由其构成的朗斯基行列式恒为零，但它们确实线性无关的，如函数 $x_1(t) = \begin{cases} t^2 & -1\le t\le 0 \\ 0 & 0\le t\le 1 \end{cases}$ 和 $x_2(t) = \begin{cases} 0 & -1\le t\le 0 \\ t^2 & 0\le t\le 1 \end{cases}$ 
- **定理 3**：若方程 $\dfrac{\mathrm d^n x}{\mathrm dt^n} + a_1(t) \dfrac{\mathrm d^{n-1} x}{\mathrm dt^{n-1}} + \cdots + a_{n-1}(t) \dfrac{\mathrm dx}{\mathrm dt} + a_n(t)x = 0$ 的解 $x_1(t), \cdots, x_2(t), \cdots, x_n(t)$ 在 $a\le t\le b$ 上线性无关，则 $W[x_1(t), x_2(t), \cdots, x_n(t)]$ 在这个区间的任何点上都不等于零，即 $W(t)\not=0\ (a\le t\le b)$ 
	- *证明过程* 
		反证法，设有某个 $t_0\ (a\le t_0\le b)$ 使得 $W(t_0)=0$ 
		考虑关于 $c_1,c_2,\cdots,c_n$ 的齐次线性代数方程组 $\begin{cases} c_1x_1'(t_0) + c_2x_2'(t_0) + \cdots + c_nx_n'(t_0) = 0 \\ c_1x_1''(t_0) + c_2x_2''(t_0) + \cdots + c_nx_n''(t_0) = 0 \\ \cdots \\ c_1x_1^{(n-1)}(t_0) + c_2x_2^{(n-1)}(t_0) + \cdots + c_nx_n^{(n-1)}(t_0) = 0 \end{cases}$ 
		其系数行列式 $W(t_0)=0$，故该方程组有非零解 $c_1, c_2, \cdots, c_n$ 
		现在以这组常数构造函数 $x(t)\equiv c_1x_1(t) + c_2x_2(t) + \cdots + c_nx_n(t),\ (a\le t\le b)$ 
		根据叠加原理 $x(t)$ 是 $\dfrac{\mathrm d^n x}{\mathrm dt^n} + a_1(t) \dfrac{\mathrm d^{n-1} x}{\mathrm dt^{n-1}} + \cdots + a_{n-1}(t) \dfrac{\mathrm dx}{\mathrm dt} + a_n(t)x = 0$ 的解
		再根据齐次线性代数方程组，可知这个解 $x(t)$ 要满足初值条件 $x(t_0) = x'(t_0) = \cdots = x^{(n-1)}(t_0)=0$ 
		但 $x=0$ 显然也是方程 $\dfrac{\mathrm d^n x}{\mathrm dt^n} + a_1(t) \dfrac{\mathrm d^{n-1} x}{\mathrm dt^{n-1}} + \cdots + a_{n-1}(t) \dfrac{\mathrm dx}{\mathrm dt} + a_n(t)x = 0$ 的满足初值条件 $x(t_0) = x'(t_0) = \cdots = x^{(n-1)}(t_0)=0$ 的解
		由解的唯一性，可知 $x(t)\equiv 0\ (a\le t\le b)$，即 $c_1x_1(t) + c_2x_2(t) + \cdots + c_nx_n(t)\equiv 0,\ (a\le t\le b)$ 
		但因为 $c_1, c_2, \cdots, c_n$ 不全为零，这就与 $x_1(t), x_2(t), \cdots, x_n(t)$ 线性无关的假设矛盾，证毕！
- **定理 4**：$n$ 阶齐次线性微分方程 $\dfrac{\mathrm d^n x}{\mathrm dt^n} + a_1(t) \dfrac{\mathrm d^{n-1} x}{\mathrm dt^{n-1}} + \cdots + a_{n-1}(t) \dfrac{\mathrm dx}{\mathrm dt} + a_n(t)x = 0$ 一定存在 $n$ 个线性无关的解
	- *证明过程* 
		由定理 2 和定理 3 可知，由 $n$ 阶齐次线性微分方程 $\dfrac{\mathrm d^n x}{\mathrm dt^n} + a_1(t) \dfrac{\mathrm d^{n-1} x}{\mathrm dt^{n-1}} + \cdots + a_{n-1}(t) \dfrac{\mathrm dx}{\mathrm dt} + a_n(t)x = 0$ 的 $n$ 个解构成的朗斯基行列式或者恒等于零，或者在方程的系数为连续区间内处处不等于零
		根据存在唯一性定理，方程 $\dfrac{\mathrm d^n x}{\mathrm dt^n} + a_1(t) \dfrac{\mathrm d^{n-1} x}{\mathrm dt^{n-1}} + \cdots + a_{n-1}(t) \dfrac{\mathrm dx}{\mathrm dt} + a_n(t)x = 0$ 满足初值条件 $\begin{cases} x_1(t_0) = 1,\ x_1'(t_0)=0,\cdots,\ x_1^{(n-1)}=0 \\ x_2(t_0) = 1,\ x_2'(t_0)=0,\cdots,\ x_2^{(n-1)}=0 \\ \cdots \\ x_n(t_0) = 1,\ x_n'(t_0)=0,\cdots,\ x_n^{(n-1)}=0 \\  \end{cases}$ 的解 $x_1(t), x_2(t), \cdots, x_n(t)$ 一定存在
		又因为 $W[x_1(t_0), x_2(t_0), \cdots, x_n(t_0)]\not= 0$，故根据定理 2，这 $n$ 个解一定是线性无关的
- **定理 5**（**通解结构**）：如果 $x_1(t), x_2(t), \cdots, x_n(t)$ 是方程 $\dfrac{\mathrm d^n x}{\mathrm dt^n} + a_1(t) \dfrac{\mathrm d^{n-1} x}{\mathrm dt^{n-1}} + \cdots + a_{n-1}(t) \dfrac{\mathrm dx}{\mathrm dt} + a_n(t)x = 0$ 的 $n$ 个线性无关的解，那么方程 $\dfrac{\mathrm d^n x}{\mathrm dt^n} + a_1(t) \dfrac{\mathrm d^{n-1} x}{\mathrm dt^{n-1}} + \cdots + a_{n-1}(t) \dfrac{\mathrm dx}{\mathrm dt} + a_n(t)x = 0$ 的通解可以表示为 $x=c_1x_1(t) + c_2x_2(t) + \cdots + c_nx_n(t)$，其中 $c_1,c_2,\cdots, c_n$ 是任意常数，且通解 $x=c_1x_1(t) + c_2x_2(t) + \cdots + c_nx_n(t)$ 中包含了方程 $\dfrac{\mathrm d^n x}{\mathrm dt^n} + a_1(t) \dfrac{\mathrm d^{n-1} x}{\mathrm dt^{n-1}} + \cdots + a_{n-1}(t) \dfrac{\mathrm dx}{\mathrm dt} + a_n(t)x = 0$ 的所有解
	- *证明过程* 
		首先，由叠加原理知道 $x=c_1x_1(t) + c_2x_2(t) + \cdots + c_nx_n(t)$ 是 $\dfrac{\mathrm d^n x}{\mathrm dt^n} + a_1(t) \dfrac{\mathrm d^{n-1} x}{\mathrm dt^{n-1}} + \cdots + a_{n-1}(t) \dfrac{\mathrm dx}{\mathrm dt} + a_n(t)x = 0$ 的解，它包含有 $n$ 个任意常数，我们指出这些常数是彼此独立的。事实上 $\begin{vmatrix} \dfrac{\partial x}{\partial c_1} & \dfrac{\partial x}{\partial c_2} & \cdots &\dfrac{\partial x}{\partial c_n} \\ \dfrac{\partial x'}{\partial c_1} & \dfrac{\partial x'}{\partial c_2} & \cdots &\dfrac{\partial x'}{\partial c_n} \\ \vdots & \vdots & & \vdots \\ \dfrac{\partial x^{(n-1)}}{\partial c_1} & \dfrac{\partial x^{(n-1)}}{\partial c_2} & \cdots &\dfrac{\partial x^{(n-1)}}{\partial c_n} \end{vmatrix} = W[x_1(t), x_2(t), \cdots, x_n(t)] \not= 0\ (a\le t\le b)$ 
		因而 $x=c_1x_1(t) + c_2x_2(t) + \cdots + c_nx_n(t)$ 为方程 $\dfrac{\mathrm d^n x}{\mathrm dt^n} + a_1(t) \dfrac{\mathrm d^{n-1} x}{\mathrm dt^{n-1}} + \cdots + a_{n-1}(t) \dfrac{\mathrm dx}{\mathrm dt} + a_n(t)x = 0$ 的通解
		现在我们证明了它包括了方程的所有解。由于方程的解唯一地决定于初值条件，所以只需证明：任给一初值条件 $x(t_0) = x_0,\ x'(t_0) = x_0', \cdots, x^{(n-1)}(t_0) = x_0^{(n-1)}$，能够确定 $x=c_1x_1(t) + c_2x_2(t) + \cdots + c_nx_n(t)$ 中的常数 $c_1, c_2, \cdots, c_n$ 的值，使 $x=c_1x_1(t) + c_2x_2(t) + \cdots + c_nx_n(t)$ 满足 $x(t_0) = x_0,\ x'(t_0) = x_0', \cdots, x^{(n-1)}(t_0) = x_0^{(n-1)}$ 
		现在令 $x=c_1x_1(t) + c_2x_2(t) + \cdots + c_nx_n(t)$ 满足条件 $x(t_0) = x_0,\ x'(t_0) = x_0', \cdots, x^{(n-1)}(t_0) = x_0^{(n-1)}$，我们得到关于 $c_1,c_2,\cdots, c_n$ 的线性代数方程组 $\begin{cases} c_1x_1(t_0) + c_2x_2(t_0) + \cdots + c_nx_n(t_0) = x_0 \\ c_1x_1'(t_0) + c_2x_2'(t_0) + \cdots + c_nx_n'(t_0) = x_0' \\ \cdots \\ c_1x_1^{(n-1)}(t_0) + c_2x_2^{(n-1)}(t_0) + \cdots + c_nx_n^{(n-1)}(t_0) = x_0^{(n-1)} \end{cases}$，它的系数行列式就是 $W(t_0)$ 
		由定理 3 可知 $W(t_0)\not-0$，根据线性代数方程组的理论，该方程组有唯一解 $\widetilde c_1, \widetilde c_2, \cdots, \widetilde c_n$ 
		因此，只要表达式 $x=c_1x_1(t) + c_2x_2(t) + \cdots + c_nx_n(t)$ 中常数取为 $\widetilde c_1, \widetilde c_2, \cdots, \widetilde c_n$，则它就满足条件 $x(t_0) = x_0,\ x'(t_0) = x_0', \cdots, x^{(n-1)}(t_0) = x_0^{(n-1)}$ 
		定理证毕！
	- **推论**：方程 $\dfrac{\mathrm d^n x}{\mathrm dt^n} + a_1(t) \dfrac{\mathrm d^{n-1} x}{\mathrm dt^{n-1}} + \cdots + a_{n-1}(t) \dfrac{\mathrm dx}{\mathrm dt} + a_n(t)x = 0$ 的线性无关解的最多个数等于 $n$，即 $n$ 阶齐次线性微分方程的所有解构成一个 $n$ 维线性空间
- **基本解组**、**标准基本解组**：方程 $\dfrac{\mathrm d^n x}{\mathrm dt^n} + a_1(t) \dfrac{\mathrm d^{n-1} x}{\mathrm dt^{n-1}} + \cdots + a_{n-1}(t) \dfrac{\mathrm dx}{\mathrm dt} + a_n(t)x = 0$ 的一组 $n$ 个线性无关解称为方程的一个**基本解组**，基本解组不是唯一的。特别地，当 $W(t_0)=1$ 时称其为**标准基本解组** 
### 4-1-3 非齐次线性微分方程与常数变易法
- **性质**：如果 $\overline x(t)$ 是方程 $\dfrac{\mathrm d^n x}{\mathrm dt^n} + a_1(t) \dfrac{\mathrm d^{n-1} x}{\mathrm dt^{n-1}} + \cdots + a_{n-1}(t) \dfrac{\mathrm dx}{\mathrm dt} + a_n(t)x = f(t)$ 的解，而 $x(t)$ 是方程 $\dfrac{\mathrm d^n x}{\mathrm dt^n} + a_1(t) \dfrac{\mathrm d^{n-1} x}{\mathrm dt^{n-1}} + \cdots + a_{n-1}(t) \dfrac{\mathrm dx}{\mathrm dt} + a_n(t)x = 0$ 的解，那么 $\overline x(t) + x(t)$ 也是方程 $\dfrac{\mathrm d^n x}{\mathrm dt^n} + a_1(t) \dfrac{\mathrm d^{n-1} x}{\mathrm dt^{n-1}} + \cdots + a_{n-1}(t) \dfrac{\mathrm dx}{\mathrm dt} + a_n(t)x = f(t)$ 的解
- **性质**：方程 $\dfrac{\mathrm d^n x}{\mathrm dt^n} + a_1(t) \dfrac{\mathrm d^{n-1} x}{\mathrm dt^{n-1}} + \cdots + a_{n-1}(t) \dfrac{\mathrm dx}{\mathrm dt} + a_n(t)x = f(t)$ 的任意两解之差必为方程 $\dfrac{\mathrm d^n x}{\mathrm dt^n} + a_1(t) \dfrac{\mathrm d^{n-1} x}{\mathrm dt^{n-1}} + \cdots + a_{n-1}(t) \dfrac{\mathrm dx}{\mathrm dt} + a_n(t)x = 0$ 的解
- **定理**：设 $x_1(t), x_2(t), \cdots, x_n(t)$ 为方程 $\dfrac{\mathrm d^n x}{\mathrm dt^n} + a_1(t) \dfrac{\mathrm d^{n-1} x}{\mathrm dt^{n-1}} + \cdots + a_{n-1}(t) \dfrac{\mathrm dx}{\mathrm dt} + a_n(t)x = 0$ 的基本解组，而 $\overline x(t)$ 是方程 $\dfrac{\mathrm d^n x}{\mathrm dt^n} + a_1(t) \dfrac{\mathrm d^{n-1} x}{\mathrm dt^{n-1}} + \cdots + a_{n-1}(t) \dfrac{\mathrm dx}{\mathrm dt} + a_n(t)x = f(t)$ 的某一解，则方程 $\dfrac{\mathrm d^n x}{\mathrm dt^n} + a_1(t) \dfrac{\mathrm d^{n-1} x}{\mathrm dt^{n-1}} + \cdots + a_{n-1}(t) \dfrac{\mathrm dx}{\mathrm dt} + a_n(t)x = f(t)$ 的通解可以表示为 $x=c_1x_1(t) + c_2x_2(t) + \cdots + c_nx_n(t) + \overline x(t)$，其中 $c_1, c_2, \cdots, c_n$ 为任意常数，而且这个通解 $x=c_1x_1(t) + c_2x_2(t) + \cdots + c_nx_n(t) + \overline x(t)$ 包括了方程 $\dfrac{\mathrm d^n x}{\mathrm dt^n} + a_1(t) \dfrac{\mathrm d^{n-1} x}{\mathrm dt^{n-1}} + \cdots + a_{n-1}(t) \dfrac{\mathrm dx}{\mathrm dt} + a_n(t)x = f(t)$ 的所有解
	- *证明过程* 
		根据前面的性质可知，$x=c_1x_1(t) + c_2x_2(t) + \cdots + c_nx_n(t) + \overline x(t)$ 是方程 $\dfrac{\mathrm d^n x}{\mathrm dt^n} + a_1(t) \dfrac{\mathrm d^{n-1} x}{\mathrm dt^{n-1}} + \cdots + a_{n-1}(t) \dfrac{\mathrm dx}{\mathrm dt} + a_n(t)x = f(t)$ 的解，它包含了 $n$ 个任意常数，可以证明这些常数是彼此独立的，因此它是方程 $\dfrac{\mathrm d^n x}{\mathrm dt^n} + a_1(t) \dfrac{\mathrm d^{n-1} x}{\mathrm dt^{n-1}} + \cdots + a_{n-1}(t) \dfrac{\mathrm dx}{\mathrm dt} + a_n(t)x = f(t)$ 的通解
		现设 $\tilde x(t)$ 是方程 $\dfrac{\mathrm d^n x}{\mathrm dt^n} + a_1(t) \dfrac{\mathrm d^{n-1} x}{\mathrm dt^{n-1}} + \cdots + a_{n-1}(t) \dfrac{\mathrm dx}{\mathrm dt} + a_n(t)x = f(t)$ 的任一解，则由上面性质可知，$\tilde x(t) - \overline x(t)$ 是方程 $\dfrac{\mathrm d^n x}{\mathrm dt^n} + a_1(t) \dfrac{\mathrm d^{n-1} x}{\mathrm dt^{n-1}} + \cdots + a_{n-1}(t) \dfrac{\mathrm dx}{\mathrm dt} + a_n(t)x = 0$ 的解，则必有一组确定的常数 $\tilde c_1, \tilde c_2, \cdots, \tilde c_n$ 使得 $\tilde x(t) - \overline x(t) = \tilde c_1x_1(t) + \tilde c_2x_2(t) + \cdots + \tilde c_nx_n(t)$，即 $\tilde x(t) = \tilde c_1x_1(t) + \tilde c_2x_2(t) + \cdots + \tilde c_nx_n(t) + \overline x(t)$ 
		这就是说，方程 $\dfrac{\mathrm d^n x}{\mathrm dt^n} + a_1(t) \dfrac{\mathrm d^{n-1} x}{\mathrm dt^{n-1}} + \cdots + a_{n-1}(t) \dfrac{\mathrm dx}{\mathrm dt} + a_n(t)x = f(t)$ 的任一解 $\overline x(t)$ 可以由 $x=c_1x_1(t) + c_2x_2(t) + \cdots + c_nx_n(t) + \overline x(t)$ 表出，其中 $c_1, c_2, \cdots, c_n$ 为相应的确定常数
		由于 $\tilde x(t)$ 的任意性，这就证明了通解表达式 $x=c_1x_1(t) + c_2x_2(t) + \cdots + c_nx_n(t) + \overline x(t)$ 包括方程 $\dfrac{\mathrm d^n x}{\mathrm dt^n} + a_1(t) \dfrac{\mathrm d^{n-1} x}{\mathrm dt^{n-1}} + \cdots + a_{n-1}(t) \dfrac{\mathrm dx}{\mathrm dt} + a_n(t)x = f(t)$ 的所有解，证毕！
	- 该定理说明：妖界非齐次线性微分方程，只需知道它的一个解和对应的齐次线性微分方程的基本解组
- **进一步指出**：只要知道对应的齐次线性微分方程的基本解组，就可以利用常数变易法求得非齐次线性微分方程的解
	- *证明过程* 
		设 $x_1(t), x_2(t), \cdots x_n(t)$ 是方程 $\dfrac{\mathrm d^n x}{\mathrm dt^n} + a_1(t) \dfrac{\mathrm d^{n-1} x}{\mathrm dt^{n-1}} + \cdots + a_{n-1}(t) \dfrac{\mathrm dx}{\mathrm dt} + a_n(t)x = 0$ 的基本解组，因而 $x=c_1x_1(t) + c_2x_2(t) + \cdots + c_nx_n(t)$ 为 $\dfrac{\mathrm d^n x}{\mathrm dt^n} + a_1(t) \dfrac{\mathrm d^{n-1} x}{\mathrm dt^{n-1}} + \cdots + a_{n-1}(t) \dfrac{\mathrm dx}{\mathrm dt} + a_n(t)x = f(t)$ 的通解
		把其中的任意常数 $c_i$ 看作 $t$ 的待定函数 $c_i(t)\ (i=1,2,\cdots,n)$，这时 $x=c_1x_1(t) + c_2x_2(t) + \cdots + c_nx_n(t)$ 变为 $x=c_1(t)x_1(t) + c_2(t)x_2(t) + \cdots + c_n(t)x_n(t)$ 
		把它代入方程 $\dfrac{\mathrm d^n x}{\mathrm dt^n} + a_1(t) \dfrac{\mathrm d^{n-1} x}{\mathrm dt^{n-1}} + \cdots + a_{n-1}(t) \dfrac{\mathrm dx}{\mathrm dt} + a_n(t)x = f(t)$，就得到 $c_1(t), c_2(t), \cdots, c_n(t)$ 必须满足的一个方程
		但待定函数有 $n$ 个，即 $c_1(t), c_2(t), \cdots, c_n(t)$，为了确定它们，必须再找出 $n-1$ 个限制条件，在理论上，这些另外加的条件可以任意给出，其法无穷，当然以运算上简便为宜，为此我们将按下面的方法来给出这 $n-1$ 个条件：
		**第 1 条** 
		将 $x=c_1(t)x_1(t) + c_2(t)x_2(t) + \cdots + c_n(t)x_n(t)$ 对 $t$ 求导得到 $x'=c_1(t)x_1'(t) + c_2(t)x_2'(t) + \cdots + c_n(t)x_n'(t) + c_1'(t)x_1(t) + c_2'(t)x_2(t) + \cdots + c_n'(t)x_n(t)$ 
		令 $\boxed{c_1'(t)x_1(t) + c_2'(t)x_2(t) + \cdots + c_n'(t)x_n(t) = 0}$ 得到 $x'=c_1(t)x_1'(t) + c_2(t)x_2'(t) + \cdots + c_n(t)x_n'(t)$ 
		**第 2 条** 
		将 $x'=c_1(t)x_1'(t) + c_2(t)x_2'(t) + \cdots + c_n(t)x_n'(t)$ 对 $t$ 求导数，向上面方法一样，含有函数 $c_i'(x)$ 的部分等于零，则我们又得到一个条件 $\boxed{c_1'(t)x_1'(t) + c_2'(t)x_2'(t) + \cdots + c_n'(t)x_n'(t)=0}$ 和表达式 $x''=c_1(t)x_1''(t) + c_2(t)x_2''(t) + \cdots + c_n(t)x_n''(t)$ 
		**第 $n-1$ 条** 
		继续上面的做法，在最后一次我们得到第 $n-1$ 个条件 $\boxed{x_1^{(n-2)}(t)c_1'(t) + x_2^{(n-2)}(t)c_2'(t) + \cdots + x_n^{(n-2)}(t)c_n'(t) = 0}$ 和表达式 $x^{(n-1)} = c_1(t)x_1^{(n-1)}(t) + c_2(t)x_2^{(n-1)}(t) + \cdots + c_n(t)x_n^{(n-1)}(t)$ 
		**第 $n$ 条** 
		最后将该式对 $t$ 求导数，得到 $x^{(n)} = c_1(t)x_1^{(n)}(t) + c_2(t)x_2^{(n)}(t) + \cdots + c_n(t)x_n^{(n)}(t) + c_1'(t)x_1^{(n-1)}(t) + c_2'(t)x_2^{(n-1)}(t) + \cdots + c_n'(t)x_n^{(n-1)}(t)$ 
		现在将 $\begin{cases}  x=c_1(t)x_1(t) + c_2(t)x_2(t) + \cdots + c_n(t)x_n(t) \\ x'=c_1(t)x_1'(t) + c_2(t)x_2'(t) + \cdots + c_n(t)x_n'(t) \\ x''=c_1(t)x_1''(t) + c_2(t)x_2''(t) + \cdots + c_n(t)x_n''(t) \\ \cdots \\ x^{(n)} = c_1(t)x_1^{(n)}(t) + c_2(t)x_2^{(n)}(t) + \cdots + c_n(t)x_n^{(n)}(t) + c_1'(t)x_1^{(n-1)}(t) + c_2'(t)x_2^{(n-1)}(t) + \cdots + c_n'(t)x_n^{(n-1)}(t) \end{cases}$ 代入 $\dfrac{\mathrm d^n x}{\mathrm dt^n} + a_1(t) \dfrac{\mathrm d^{n-1} x}{\mathrm dt^{n-1}} + \cdots + a_{n-1}(t) \dfrac{\mathrm dx}{\mathrm dt} + a_n(t)x = f(t)$，并注意到 $x_1(t), x_2(t), \cdots, x_n(t)$ 是 $\dfrac{\mathrm d^n x}{\mathrm dt^n} + a_1(t) \dfrac{\mathrm d^{n-1} x}{\mathrm dt^{n-1}} + \cdots + a_{n-1}(t) \dfrac{\mathrm dx}{\mathrm dt} + a_n(t)x = 0$ 的解，得到 $\boxed{x_1^{(n-1)}(t)c_1'(t) + x_2^{(n-1)}(t)c_2'(t) + \cdots + x_n^{(n-1)}(t)c_n'(t) = 0}$ 
		这样我们得到了含 $n$ 个未知函数 $c_i'(t)\ (i=1,2,\cdots, n)$ 的 $n$ 个方程 $\begin{cases} c_1'(t)x_1(t) + c_2'(t)x_2(t) + \cdots + c_n'(t)x_n(t) = 0 \\ c_1'(t)x_1'(t) + c_2'(t)x_2'(t) + \cdots + c_n'(t)x_n'(t)=0 \\ \cdots \\ x_1^{(n-2)}(t)c_1'(t) + x_2^{(n-2)}(t)c_2'(t) + \cdots + x_n^{(n-2)}(t)c_n'(t) = 0 \\ x_1^{(n-1)}(t)c_1'(t) + x_2^{(n-1)}(t)c_2'(t) + \cdots + x_n^{(n-1)}(t)c_n'(t) = 0 \end{cases}$ 
		它们组成一个线性代数方程组，其系数行列式就是 $W[x_1(t), x_2(t), \cdots, x_n(t)]$，它不等于零，因而方程组的解可唯一确定
		设求得 $c_i'(t) = \varphi_i(t),\ (i=1,2,\cdots,n)$，积分得 $\displaystyle c_i(t) = \int\varphi_i(t)\mathrm dt + \gamma_i,\ (i=1,2,\cdots,n)$，这里 $\gamma_i$ 是任意常数
		将所得 $c_i(t)\ (i=1,2,\cdots,n)$ 的表达式代入 $x=c_1(t)x_1(t) + c_2(t)x_2(t) + \cdots + c_n(t)x_n(t)$，即得方程 $\dfrac{\mathrm d^n x}{\mathrm dt^n} + a_1(t) \dfrac{\mathrm d^{n-1} x}{\mathrm dt^{n-1}} + \cdots + a_{n-1}(t) \dfrac{\mathrm dx}{\mathrm dt} + a_n(t)x = f(t)$ 的解 $\displaystyle x = \sum_{i=1}^n \gamma_ix_i(t) + \sum_{i=1}^n x_i(t)\int \varphi_i(t)\mathrm dt$ 
		显然，它也是方程 $\dfrac{\mathrm d^n x}{\mathrm dt^n} + a_1(t) \dfrac{\mathrm d^{n-1} x}{\mathrm dt^{n-1}} + \cdots + a_{n-1}(t) \dfrac{\mathrm dx}{\mathrm dt} + a_n(t)x = 0$ 的通解
		为了得到方程的一个解，只需给常数 $\gamma_i\ (i=1,2,\cdots,n)$ 以确定的值
		例如，当 $\gamma_i=0\ (i=1,2,\cdots,n)$ 时，即得解 $\displaystyle x = \sum_{i=1}^n x_i(t) \int\varphi_i(t)\mathrm dt$ 
	- 可以看到，如果已知对应的齐次线性微分方程的基本解组，那么非齐次线性微分方程的任一解可由求积得到。因此对于线性微分方程来说，关键是求出齐次线性微分方程的基本解组
