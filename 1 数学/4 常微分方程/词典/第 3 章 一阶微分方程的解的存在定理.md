# 3 一阶微分方程的解的存在定理
## 3-1 解的存在唯一性定理与逐步逼近法
### 3-1-1 存在唯一性定理
- **利普希茨（Lipschitz）条件**、**利普希茨常数**：考虑导数已解出的一阶微分方程 $\dfrac{\mathrm dy}{\mathrm dx} = f(x,y)$，这里 $f(x,y)$ 是在矩形域 $R: |x-x_0| \le a,\ |y-y_0| \le b$ 上的连续函数。函数 $f(x,y)$ 称为在 $R$ 上关于 $y$ 满足**利普希茨（Lipschitz）条件**，如果存在常数 $L>0$，使得不等式 $|f(x,y_1) - f(x,y_2)| \le L |y_1-y_2|$ 对于所有 $(x,y_1), (x,y_2) \in R$ 都成立，$L$ 称为**利普希茨常数** 
	- 可以证明：$f(x,y)$ 在 $R$ 上有对 $y$ 得连续偏导数，可以推出其满足利普希茨条件。但反过来不成立
	- 由于利普希茨条件比较难检验，常用 $f(x,y)$ 在 $R$ 上有对 $y$ 得连续偏导数来代替
- **解的存在唯一性定理**：如果 $f(x,y)$ 在矩形域 $R$ 上连续且关于 $y$ 满足利普希茨条件，则方程 $\dfrac{\mathrm dy}{\mathrm dx} = f(x,y)$ 存在唯一的解 $y=\varphi(x)$，定义于 $|x-x_0|\le h$ 上，连续且满足初值条件 $\varphi(x_0) = y_0$，这里 $h = \min \left( a, \dfrac bM \right),\ M = \max\limits_{(x,y)\in R} |f(x,y)|$ 
	- *证明思想*、**逐步逼近法**、**第 $n$ 次近似解**  
		采用皮卡（Picard）的**逐步逼近法**来证明这个定理，只对 $x_0 \le x \le x_0 + h$ 进行讨论，对 $x-h\le x\le x_0$ 的讨论完全一样
		逐步逼近法证明定理的主要思想：首先证明求微分方程初值问题的解等价于求积分方程 $\displaystyle y=y_0 + \int_{x_0}^x f(x,y)\mathrm dx$ 的连续解，再证明积分方程的解的唯一性
		任取一个连续函数 $\varphi_0(x)$ 代入上面积分方程右端的 $y$，得到函数 $\displaystyle \varphi_1(x) = y_0 + \int_{x_0}^x f(x,\varphi_0(x))\mathrm dx$，显然 $\varphi_1(x)$ 也是连续函数
		如果 $\varphi_1(x) = \varphi_0(x)$，那么 $\varphi_0(x)$ 就是积分方程的解
		否则，我们又把 $\varphi_1(x)$ 代入积分方程的右端的 $y$，得到 $\displaystyle \varphi_2(x) = y_0 + \int_{x_0}^x f(x,\varphi_1(x))\mathrm dx$ 
		如果 $\varphi_2(x) = \varphi_1(x)$，那么 $\varphi_1(x)$ 就是积分方程的解，否则我们继续这个步骤
		一般地，作函数 $\displaystyle \varphi_n(x) = y_0 + \int_{x_0}^x f(x,\varphi_{n-1}(x))\mathrm dx$，这样就得到连续函数序列 $\varphi_0(x), \varphi_1(x), \cdots, \varphi_n(x), \cdots$ 
		其中 $\varphi_n(x)$ 称为**第 $n$ 次近似解** 
		如果 $\varphi_{n+1}(x) = \varphi_n(x)$，那么 $\varphi_n(x)$ 就是积分方程的解
		如果始终不发生这种情况，我们可以证明上面的函数序列有一个极限函数，即 $\lim\limits_{n\to\infty} \varphi_n(x) = \varphi(x)$ 存在，因而对 $\displaystyle \varphi_n(x) = y_0 + \int_{x_0}^x f(x,\varphi_{n-1}(x))\mathrm dx$ 取极限时，得到：
		$$
		\begin{aligned}
		\lim_{n\to\infty} \varphi_n(x) = & y_0 + \int_{x_0}^x f(x,\varphi_{n-1}(x))\mathrm dx \\
		=& y_0 + \int_{x_0}^x \lim_{n\to\infty} f(x, \varphi_{n-1}(x))\mathrm dx \\ 
		=& y_0 + \int_{x_0}^x f(x, \varphi(x))\mathrm dx
		\end{aligned}
		$$
		即 $\displaystyle \varphi(x) = y_0 + \int_{x_0}^x f(x, \varphi(x))\mathrm dx$，这就是说 $\varphi(x)$ 是积分方程的解
		**逐步逼近法**：向上面一步一步地求出方程的解的方法就称为**逐步逼近法** 
	- 考虑 $h$ 的几何意义，详见教材 58 页
	- 下面通过五个命题，分部证明该结论
- **命题 1**：设 $y=\varphi(x)$ 是方程 $\dfrac{\mathrm dy}{\mathrm dx} = f(x,y)$ 的定义于 $x_0\le x\le x_0+h$ 上，满足初值条件 $\varphi(x_0)=y_0$ 的解 $\iff$ $y=\varphi(x)$ 是积分方程 $\displaystyle y = y_0 + \int_{x_0}^x f(x,y)\mathrm dx,\ (x_0\le x\le x_0+h)$ 的定义于 $x_0\le x\le x_0+h$ 上的连续解
	- *证明过程* 
		因为 $y=\varphi(x)$ 是方程 $\dfrac{\mathrm dy}{\mathrm dx} = f(x,y)$ 的解，故有 $\dfrac{\mathrm d\varphi(x)}{\mathrm dx} = f(x,\varphi(x))$ 
		两边从 $x_0$ 到 $x$ 取定积分，得到 $\displaystyle \varphi(x) - \varphi(x_0) \int_{x_0}^x f(x,\varphi(x))\mathrm dx,\ (x_0\le x\le x_0+h)$ 
		把 $\varphi(x_0)=y_0$ 代入上式，即有 $\displaystyle \varphi(x) = y_0 + \int_{x_0}^x f(x,\varphi(x)) \mathrm dx,\ (x_0\le x\le x_0+h)$ 
		因此，$y=\varphi(x)$ 是 $\displaystyle y = y_0 + \int_{x_0}^x f(x,y)\mathrm dx,\ (x_0\le x\le x_0+h)$ 的定义于 $x_0\le x\le x_0+h$ 上的连续解
		反之，如果 $y=\varphi(x)$ 是 $\displaystyle y = y_0 + \int_{x_0}^x f(x,y)\mathrm dx,\ (x_0\le x\le x_0+h)$ 的连续解，则有 $\displaystyle \varphi(x) = y_0 + \int_{x_0}^x f(x,\varphi(x)) \mathrm dx,\ (x_0\le x\le x_0+h)$ 
		对 $x$ 求导数，得到 $\dfrac{\mathrm d\varphi(x)}{\mathrm dx} = f(x,\varphi(x))$ 
		又把 $x=x_0$ 代入 $\displaystyle y = y_0 + \int_{x_0}^x f(x,y)\mathrm dx,\ (x_0\le x\le x_0+h)$ 得到 $\varphi(x_0)=y_0$ 
		因此 $y=\varphi(x)$ 是方程 $\dfrac{\mathrm dy}{\mathrm dx} = f(x,y)$ 的定义于 $x_0\le x\le x_0+h$ 上，且满足初值条件 $\varphi(x_0) = y_0$ 的解
		综上证毕！
- 现取 $\varphi_0(x) = y_0$，构造皮卡逐步逼近函数序列 $\begin{cases} \varphi_0(x) = y_0 \\ \displaystyle \varphi_n(x) = y_0 + \int_{x_0}^x f(\xi, \varphi_{n-1}(\xi))\mathrm d\xi,\ x_0\le x\le x_0+h\ (n=1,2,\cdots) \end{cases}$ 
- **命题 2**：对于所有的 $n$，$\begin{cases} \varphi_0(x) = y_0 \\ \displaystyle \varphi_n(x) = y_0 + \int_{x_0}^x f(\xi, \varphi_{n-1}(\xi))\mathrm d\xi,\ x_0\le x\le x_0+h\ (n=1,2,\cdots) \end{cases}$ 中函数 $\varphi_n(x)$ 在 $x_0\le x\le x_0+h$ 上有定义、连续且满足不等式 $|\varphi_n(x) - y_0|\le b$ 
	- *证明过程* 
		当 $n=1$ 时，$\displaystyle \varphi_1(x) = y_0 + \int_{x_0}^x f(\xi, y_0)\mathrm d\xi$，显然 $\varphi_1(x)$ 在 $x_0\le x \le x_0 + h$ 上有定义、连续且有
		$$
		\begin{aligned}
		|\varphi_1(x) - y_0| =& \left| \int_{x_0}^x f(\xi, y_0)\mathrm d\xi \right| \le \int_{x_0}^x |f(\xi, y_0)|\mathrm d\xi \\
		\le & M(x-x_0)\le Mh\le b
		\end{aligned}
		$$
		故该命题在 $n=1$ 时成立，现采用数学归纳法证明对于任何正整数 $n$，该命题都成立
		设该命题在 $n=k$ 时成立，即 $\varphi_k(x)$ 在 $x_0\le x \le x_0+h$ 上有定义、连续且满足不等式 $|\varphi_k(x) - y_0| \le b$ 
		此时 $\displaystyle \varphi_{k+1}(x) = y_0 + \int_{x_0}^x f(\xi, \varphi_k(\xi))\mathrm d\xi$ 
		再由假设可知，$\varphi_{k+1}(x)$ 在 $x_0\le x\le x_0+h$ 上有定义、连续且有 $\displaystyle |\varphi_{k+1}(x)-y_0| \le \int_{x_0}^x |f(\xi, \varphi_k(\xi))|\mathrm d\xi \le M(x-x_0) \le Mh\le b$ 
		故该命题在 $n=k+1$ 时也成立，由数学归纳法可知该命题对所有 $n$ 均成立，证毕！
- **命题 3**：函数序列 $\{\varphi_n(x)\}$ 在 $x_0\le x \le x_0 + h$ 上是一致收敛的
	- *证明过程* 
		考虑级数 $\varphi_0(x) + \sum\limits_{k=1}^\infty [\varphi_k(x) - \varphi_{k-1}(x)],\ (x_0\le x\le x_0+h)$，它的部分和为 $\varphi_0(x) + \sum\limits_{k=1}^n[\varphi_k(x) - \varphi_{k-1}(x)] = \varphi_n(x)$ 
		因此，要证明函数序列 $\{\varphi_n(x)\}$ 在 $x_0\le x\le x_0+h$ 上一致收敛，只需证明级数 $\varphi_0(x) + \sum\limits_{k=1}^\infty [\varphi_k(x) - \varphi_{k-1}(x)],\ (x_0\le x\le x_0+h)$ 在 $x_0\le x \le x_0+h$ 上一致收敛，为此我们进行如下估计
		由 $\begin{cases} \varphi_0(x) = y_0 \\ \displaystyle \varphi_n(x) = y_0 + \int_{x_0}^x f(\xi, \varphi_{n-1}(\xi))\mathrm d\xi,\ x_0\le x\le x_0+h\ (n=1,2,\cdots) \end{cases}$ 可知 $\displaystyle |\varphi_1(x) - \varphi_0(x)| \le \int_{x_0}^x |f(\xi, \varphi_0(\xi))| \mathrm d\xi \le M(x-x_0)$ 及 $\displaystyle |\varphi_2(x) - \varphi_1(x)| \le \int_{x_0}^x |f(\xi, \varphi_1(\xi)) - f(\xi, \varphi_0(\xi))| \mathrm d\xi$ 
		利用利普希茨条件及 $\displaystyle |\varphi_1(x) - \varphi_0(x)| \le \int_{x_0}^x |f(\xi, \varphi_0(\xi))| \mathrm d\xi \le M(x-x_0)$ 得到 $\displaystyle |\varphi_2(x) - \varphi_1(x)| \le L \int_{x_0}^x |\varphi_1(\xi) - \varphi_0(\xi)|\mathrm d\xi \le L \int_{x_0}^x M(\xi - x_0)\mathrm d\xi = \dfrac{ML}{2!}(x-x_0)^2$ 
		对于正整数 $n$，不等式 $|\varphi_n(x) - \varphi_{n-1}(x)| \le \dfrac{ML^{n-1}}{n!}(x-x_0)^n$ 成立，则由利普希茨条件，当 $x_0\le x\le x_0+h$ 时有：
		$$
		\begin{aligned}
		|\varphi_{n+1}(x) - \varphi_n(x)| \le & \int_{x_0}^x |f(\xi,\varphi_n(\xi)) - f(\xi,\varphi_{n-1}(\xi))|\mathrm d\xi \\
		\le & L \int_{x_0}^x |\varphi_n(x) - \varphi_{n-1}(\xi)|\mathrm d\xi \\
		\le & \dfrac{ML^n}{n!} \int_{x_0}^x (\xi-x_0)^n \mathrm d\xi \\
		=& \dfrac{ML^n}{(n+1)!} (x-x_0)^{n+1}
		\end{aligned}
		$$
		于是，由数学归纳法可知，对于所有的正整数 $k$，有估计 $|\varphi_k(x) - \varphi_{k-1}(x)| \le \dfrac{ML^{k-1}}{k!}(x-x_0)^k,\ (x_0\le x\le x_0+h)$ 
		从而可知，当 $x_0\le x\le x_0+h$ 时，$|\varphi_k(x) - \varphi_{k-1}(x)| \le \dfrac{ML^{k-1}}{k!}h^k$ 
		而该式右端是正项收敛级数 $\sum\limits_{k=1}^\infty ML^{k-1}\dfrac{h^k}{k!}$ 的一般项，由 Weierstrass 判别法可知，级数 $\varphi_0(x) + \sum\limits_{k=1}^\infty [\varphi_k(x) - \varphi_{k-1}(x)],\ (x_0\le x\le x_0+h)$ 在 $x_0\le x\le x_0+h$ 上一致连续，因而序列 $\{\varphi_n(x)\}$ 也在 $x_0\le x\le x_0+h$ 上一致收敛，证毕！
- 现设 $\lim\limits_{n\to\infty} \varphi_n(x) = \varphi(x)$，则 $\varphi(x)$ 也在 $x_0\le x\le x_0+h$ 上连续，且由 $|\varphi_n(x) - y_0|\le b$ 可知 $|\varphi(x) - y_0|\le b$ 
- **命题 4**：$\varphi(x)$ 是积分方程 $\displaystyle y = y_0 + \int_{x_0}^x f(x,y)\mathrm dx,\ (x_0\le x\le x_0+h)$ 的定义于 $x_0\le x\le x_0+h$ 上的连续解
	- *证明过程* 
		由利普希茨条件 $|f(x, \varphi_n(x)) - f(x,\varphi(x))| \le L|\varphi_n(x) - \varphi(x)|$ 以及 $\{\varphi_n(x)\}$ 在 $x_0\le x\le x_0+h$ 上一致收敛于 $\varphi_n(x)$，即知序列 $\{f(x, \varphi_n(x))\}$ 在 $x_0\le x\le x_0+h$ 上一致收敛于 $f(x,\varphi(x))$ 
		因此，对 $\begin{cases} \varphi_0(x) = y_0 \\ \displaystyle \varphi_n(x) = y_0 + \int_{x_0}^x f(\xi, \varphi_{n-1}(\xi))\mathrm d\xi,\ x_0\le x\le x_0+h\ (n=1,2,\cdots) \end{cases}$ 两边取极限得到 $\displaystyle \lim_{n\to\infty} \varphi_n(x) = y_0 + \lim_{n\to\infty}\int_{x_0}^x f(\xi, \varphi_{n-1}(\xi))\mathrm d\xi = y_0 + \int_{x_0}^x\lim_{n\to\infty} f(\xi, \varphi_{n-1}(\xi))\mathrm d\xi$，即 $\displaystyle \varphi(x) = y_0 + \int_{x_0}^x f(\xi, \varphi(\xi))\mathrm d\xi$ 
		这就是说，$\varphi(x)$ 是积分方程 $\displaystyle y = y_0 + \int_{x_0}^x f(x,y)\mathrm dx,\ (x_0\le x\le x_0+h)$ 的定义于 $x_0\le x\le x_0+h$ 上的连续解，证毕！
- **命题 5**：设 $\psi(x)$ 是积分方程 $\displaystyle y = y_0 + \int_{x_0}^x f(x,y)\mathrm dx,\ (x_0\le x\le x_0+h)$ 定义于 $x_0\le x\le x_0+h$ 上的另一个连续解，则 $\varphi(x) = \psi(x)\ (x_0\le x\le x_0+h)$ 
	- *证明过程* 
		我们证明 $\psi(x)$ 也是序列 $\{\varphi_n(x)\}$ 的一致收敛极限函数。为此，从 $\varphi_0(x)=y_0$、$\displaystyle \varphi_n(x) = y_0 + \int_{x_0}^x f(\xi, \varphi_{n-1}(\varphi))\mathrm d\varphi\ (n\ge 1)$、$\displaystyle \psi(x) = y_0 + \int_{x_0}^x f(\xi, \psi(\xi))\mathrm d\xi$ 可以进行如下估计：
		$$
		\begin{aligned}
		|\varphi_0(x) - \psi(x)| \le & \int_{x_0}^x |f(\xi,\psi(\xi))|\mathrm d\xi \le M(x-x_0) \\ 
		|\varphi_1(x) - \psi(x)| \le & \int_{x_0}^x | f(\xi, \varphi_0(\xi)) - f(\xi, \psi(\xi)) |\mathrm d\xi \\
		\le & L\int_{x_0}^x |\varphi_0(\xi) - \psi(\xi)| \mathrm d\xi \\
		\le & ML \int_{x_0}^x (\xi - x_0)\mathrm d\xi = \dfrac{ML}{2!} (x-x_0)^2 
		\end{aligned}
		$$
		现设 $|\varphi_{n-1}(x) - \psi(x)| \le \dfrac{ML^{n-1}}{n!} (x-x_0)^n$，则有：
		$$
		\begin{aligned}
		|\varphi_n(x) - \psi(x)| \le & \int_{x_0}^x |f(\xi, \varphi_{n-1}(\xi)) - f(\xi, \psi(\xi))|\mathrm d\xi \\
		\le & L \int_{x_0}^x |\varphi_{n-1}(\xi) - \psi(\xi)| \mathrm d\xi \\
		\le & \dfrac{ML^n}{n!}\int_{x_0}^x (\xi-x_0)^n\mathrm d\xi = \dfrac{ML^n}{(n+1)!}(x-x_0)^{n+1}
		\end{aligned}
		$$
		故由数学归纳法知，对于所有的正整数 $n$，有估计式 $|\varphi_n(x) - \psi(x)| \le \dfrac{ML^n}{(n+1)!}(x-x_0)^{n+1}$ 
		因此，在 $x_0\le x\le x_0+h$ 上有 $|\varphi_n(x) - \psi(x)| \le \dfrac{ML^n}{(n+1)!}h^{n+1}$ 
		$\dfrac{ML^n}{(n+1)!}h^{n+1}$ 是收敛级数的一般项，故当 $n\to\infty$ 时，$\dfrac{ML^n}{(n+1)!}h^{n+1}\to 0$，因而 $\{\varphi_n(x)\}$ 在 $x_0\le x\le x_0+h$ 上一致收敛于 $\psi(x)$ 
		根据极限的唯一性，即得 $\varphi(x) = \psi(x),\ x_0\le x\le x_0+h$，证毕！
- **特例**：若方程 $\dfrac{\mathrm dy}{\mathrm dx} = f(x,y)$ 是线性的，即方程为 $\dfrac{\mathrm dy}{\mathrm dx} = P(x)y + Q(x)$，那么当 $P(x), Q(x)$ 在区间 $[\alpha, \beta]$ 上连续时，解的存在唯一性定理就能满足，且由任一初值 $(x_0,y_0),\ x_0\in [\alpha, \beta]$ 所确定的解在整个区间 $[\alpha, \beta]$ 上都有定义
- **注意**：对于一般方程 $\dfrac{\mathrm dy}{\mathrm dx} = f(x,y)$，由初值所确定的解只能定义在 $|x-x_0|\le h$ 上。这是因为在构造逐步逼近函数序列 $\{\varphi_n(x)\}$ 时，要求它不越出原来的矩形域 $R$。而现在，右端函数对 $y$ 没有任何限制。为了证明我们的结论，譬如取 $M = \max\limits_{x\in[\alpha,\beta]} |P(x)y_0+Q(x)|$，而逐字重复定理的证明过程，即可证由 $\begin{cases} \varphi_0(x) = y_0 \\ \displaystyle \varphi_n(x) = y_0 + \int_{x_0}^x f(\xi, \varphi_{n-1}(\xi))\mathrm d\xi,\ x_0\le x\le x_0+h\ (n=1,2,\cdots) \end{cases}$ 所作出的函数序列 $\{\varphi_n(x)\}$ 在整个区间 $[\alpha, \beta]$ 上都有定义和一致收敛
- **定理**：对于一阶隐式方程 $F(x,y,y')=0$，如果在点 $(x_0,y_0,y_0')$ 的某一邻域中，满足 $F(x,y,y')$ 对所有变元 $(x,y,y')$ 连续，且存在连续偏导数；且 $F(x_0,y_0,y_0')=0$；且 $\dfrac{\partial F(x_0,y_0, y_0')}{\partial y'}\not= 0$，则方程 $F(x,y,y')=0$ 存在唯一解 $y=y(x),\ |x-x_0|\le h\ (h\text{ 为足够小的正数})$ 满足初值条件 $y(x_0)=y_0, y'(x_0)=y_0'$ 
	- *证明过程* 
		由隐函数存在定理，若于 $(x_0,y_0,y_0')$ 的某一邻域内 $F$ 连续且 $F(x_0,y_0,y_0')=0$，而 $\dfrac{\partial F}{\partial y'}\not=0$，则必可把 $y'$ 唯一地表示为 $x,y$ 地函数 $y'=f(x,y)$，并且 $f(x,y)$ 于 $(x_0,y_0)$ 的某一邻域内连续，且满足 $y_0' = f(x_0,y_0)$ 
		又由于 $F$ 关于所有变元存在连续偏导数，故 $f(x,y)$ 对 $x,y$ 也存在连续偏导数，且 $\dfrac{\partial f}{\partial y} = -\dfrac{\partial F / \partial y}{\partial F / \partial y}$，显然它是有界的
		再由解的存在唯一性定理，方程 $y'=f(x,y)$ 满足初值条件 $y(x_0)=y_0$ 的解存在且唯一，即方程 $F(x,y,y')=0$ 的过点 $(x_0,y_0)$ 且切线斜率为 $y_0'$ 的积分曲线存在且唯一（即对任意给定的一组值 $(x_0,y_0,y_0')$，$F(x_0,y_0,y_0')=0$，方程 $F(x,y,y')=0$ 的沿已给方向 $y_0'$ 通过点 $(x_0,y_0)$ 的积分曲线有且仅有一条），证毕！
### 3-1-2 近似计算和误差估计
在证明存在唯一性定理中采用的逐步逼近法在实用上也是求方程近似解的一种方法
在估计式 $|\varphi_n(x) - \psi(x)| \le \dfrac{ML^n}{(n+1)!}h^{n+1}$ 中令 $\psi(x) = \varphi(x)$，我们就得到第 $n$ 次近似解 $\varphi_n(x)$ 和真正解 $\varphi(x)$ 在 $|x-x_0|\le h$ 内的误差估计式 $|\varphi_n(x) - \varphi(x)| \le \dfrac{ML^n}{(n+1)!}h^{n+1}$ 
这样，我们在进行近似计算时，可以根据误差的要求，选取适当的逐步逼近函数 $\varphi_n(x)$
