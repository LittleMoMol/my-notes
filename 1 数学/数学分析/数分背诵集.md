# 1 三角函数、反三角函数、双曲函数
## 1-1 三角函数
在 $\triangle ABC$ 中，边和角 $a,A;\ b,B;\ c,C$ 一一对应，则 6 种**三角函数**具体见下表：

| 函数名称 | 英文        | 缩写       | 表达式              | 语言描述                        |
| ---- | --------- | -------- | ---------------- | --------------------------- |
| 正弦函数 | sine      | $$\sin$$ | $$\dfrac{a}{c}$$ | $$\angle A$$ 的**对**边比**斜**边 |
| 余弦函数 | cosine    | $$\cos$$ | $$\dfrac{b}{c}$$ | $$\angle A$$ 的**邻**边比**斜**边 |
| 正切函数 | tangent   | $$\tan$$ | $$\dfrac{a}{b}$$ | $$\angle A$$ 的**对**边比**邻**边 |
| 余切函数 | cotangent | $$\cot$$ | $$\dfrac{b}{a}$$ | $$\angle A$$ 的**邻**边比**对**边 |
| 正割函数 | secant    | $$\sec$$ | $$\dfrac{c}{b}$$ | $$\angle A$$ 的**斜**边比**邻**边 |
| 余割函数 | cosecant  | $$\csc$$ | $$\dfrac{c}{a}$$ | $$\angle A$$ 的**斜**边比**对**边 |
可知：$\begin{cases} \cot x = \dfrac 1 {\tan x} \\ \sec x = \dfrac 1 {\cos x} \\ \csc x = \dfrac 1 {\sin x} \end{cases}$ 

## 1-2 反三角函数
**反三角函数**的定义域与对应的值域：
- $y=\arcsin x,\quad x\in[-1,1],\quad y\in\left[-\dfrac \pi 2, \dfrac \pi 2\right]$ 
- $y=\arccos x,\quad x\in[-1,1],\quad y\in[0, \pi]$ 
- $y=\arctan x,\quad x\in(-\infty,+\infty),\quad y\in\left(-\dfrac \pi 2, \dfrac \pi 2\right)$ 
- $y=\text{arccot } x,\quad x\in(-\infty,+\infty),\quad y\in(0,\pi)$ 
## 1-3 双曲函数
**双曲函数列举** 

| 名称   | 公式                                                                        |
| ---- | ------------------------------------------------------------------------- |
| 双曲正弦 | $$\sinh x = \dfrac{e^x-e^{-x}}{2}$$                                       |
| 双曲余弦 | $$\cosh x = \dfrac{e^x+e^{-x}}{2}$$                                       |
| 双曲正切 | $$\tanh x = \dfrac{\sinh x}{\cosh x} = \dfrac{e^x-e^{-x}}{e^x + e^{-x}}$$ |
| 双曲余切 | $$\coth x = \dfrac{1}{\tanh x} = \dfrac{e^x+e^{-x}}{e^x-e^{-x}}$$         |
| 双曲正割 | $$\mathrm{sech}\ x = \dfrac{1}{\cosh x} = \dfrac{2}{e^x + e^{-x}}$$       |
| 双曲余割 | $$\mathrm{csch}\ x = \dfrac{1}{\sinh x} = \dfrac{2}{e^x - e^{-x}}$$       |

2. $\begin{cases} -|a+b| \le |a| - |b| \le |a+b| \\ -|a-b| \le |a|-|b| \le |a-b| \end{cases}$ 
3. $||a|-|b|| \le |a\pm b| \le |a| + |b|$ 
4. $|\sqrt a - \sqrt b| \le \sqrt{|a-b|}$ 
5. $\dfrac{|a+b|}{1+|a+b|} \le \dfrac{|a|}{1+|a|} + \dfrac{|b|}{1+|b|}$ 
	- *证明过程* 
		设 $f(x)=\dfrac x{1+x}$，易知其单调增加，所以有：
		$\dfrac{|a+b|}{1+|a+b|} \le \dfrac{|a|+|b|}{1+|a|+|b|} = \dfrac{|a|}{1+|a|+|b|} + \dfrac{|b|}{1+|a|+|b|} \le \dfrac{|a|}{1+|a|} + \dfrac{|b|}{1+|b|}$，证毕！
## 2-2 三角函数相关
1. $|\sin x| \le |x|,\ |\cos x|\le 1$ 
2. $|\sin x - \sin y| \le |x-y|$ 
3. $|\cos x - \cos y| \le |x-y|$ 
4. $|\arctan a - \arctan b| \le |a-b|$ 
	- *证明过程* 
		显然 $f(x)=\arctan x$ 在任意区间 $[a,b]$ 上满足 Lagrange 中值条件
		所以存在 $\xi\in(a,b)$ 满足 $|\arctan a - \arctan b| =|f'(\xi)| \cdot |a-b| = \left| \dfrac {1}{1+\xi^2} \right| \cdot |a-b|$ 
		所以 $|\arctan a - \arctan b| \le |a-b|$

## 2-4 对数相关
1. $a\ln a + b\ln b \ge (a+b)[\ln(a+b) - \ln 2]\ (a,b>0)$ 
	- *证明过程* 
		令 $f(x)=x\ln x$，则 $f''(x)=\dfrac 1x>0\ (x>0)$，故 $f(x)$ 在 $(0,+\infty)$ 上是严格下凸的
		因此，对任意 $a,b>0$ 都成立 $\dfrac{f(a)+f(b)}{2} \ge f\left(\dfrac{a+b}{2}\right)$（在 $a=b$ 时取等）
		即 $\dfrac{a\ln a + b\ln b}{2} \ge \dfrac{a+b}{2}\ln \dfrac{a+b}{2}$，即 $a\ln a + b\ln b \ge (a+b)[\ln(a+b) - \ln 2]\ (a,b>0)$ 
	- **推论**：$\sum\limits_{i=1}^n x_i\ln x_i \ge \left(\sum\limits_{i=1}^n x_i \right) \left[ \ln \left(\sum\limits_{i=1}^n x_i\right) - \ln n \right]$ 
2. $\dfrac 1n\sum\limits_{i=1}^n \ln x_i \le \ln\left( \dfrac 1n\sum\limits_{i=1}^n x_i \right)$ 
	- *证明过程* 
		根据 $f(x)=\ln x$ 的严格上凸性和 Jensen 不等式即证！
## 2-5 其他
1. 设 $a,b\ge 0$，$p,q$ 为满足 $\dfrac 1p + \dfrac 1q = 1$ 的正数，则：$ab \le  \dfrac 1p a^p + \dfrac 1q b^q$ 
	- *证明过程* 
		当 $a,b$ 其中之一为 $0$ 时，上式显然成立
		现证 $a,b>0$ 情形，考虑函数 $f(x)=\ln x\ (x>0)$，由于在 $(0,+\infty)$ 上 $f''(x)=-\dfrac 1{x^2} < 0$，所以 $f(x)$ 在 $(0,+\infty)$ 上是严格上凸函数。
		于是由定义可知：$\dfrac 1pf(a^p) + \dfrac 1qf(b^q) \le f\left( \dfrac 1pa^p + \dfrac 1qb^q \right)$（$a=b$ 时取等），所以 $\ln ab \le \ln\left( \dfrac 1pa^p + \dfrac 1qb^q \right)$ 
		利用 $f(x)=\ln x$ 在 $(0,+\infty)$ 上的单调增加性即得 $ab \le \dfrac 1pa^p + \dfrac 1qb^q\ (a,b>0)$ 
2. $ny^{n-1}(x-y) < x^n-y^n < nx^{n-1}(x-y)\ (n>1, x>y>0)$ 
	- *证明过程* 
		令 $f(x)=x^n$，则 $f'(x)=nx^{n-1}$ 
		由 Lagrange 中值定理可知存在 $\xi$ 使得 $f'(\xi) = \dfrac{f(x)-f(y)}{x-y}\ (0 < y < \xi < x)$，即 $x^n-y^n = n\xi^{n-1}(x-y)$ 
		由 $x^{n-1}>\xi^{n-1}>y^{n-1}>0$ 得到 $ny^{n-1}(x-y) < x^n-y^n < nx^{n-1}(x-y)\ (n>1, x>y>0)$ 
3. $\dfrac{x^n+y^n}{2} \ge \left(\dfrac{x+y}{2}\right)^n,\ x,y>0,\ n>1$ 
	- *证明过程* 
		设 $f(x)=x^n$，则 $f''(x)=n(n-1)x^{n-2}>0,\ \forall\ x>0$，故 $f(x)$ 在 $(0,+\infty)$ 上严格下凸，故有 $\dfrac{x^n+y^n}{2} \ge \left(\dfrac{x+y}{2}\right)^n,\ x,y>0,\ n>1$ 
4. $\dfrac{e^x+e^y}{2}>e^{\frac{x+y}{2}},\ x\not=y$ 
	- *证明过程* 
		设 $f(x)=e^x$，则 $f''(x)=e^x>0,\ x\in(-\infty,+\infty)$，所以 $f(x)$ 在 $(-\infty,+\infty)$ 上严格下凸，因而 $\dfrac{e^x+e^y}{2}>e^{\frac{x+y}{2}},\ x\not=y$

		记 $x_n = \left( 1 + \dfrac 1n \right)^n,\ y_n = \left( 1 + \dfrac 1n \right)^{n+1}$，利用平均值不等式 $\prod\limits_{i=1}^n a_i \le \left(\dfrac 1n \sum\limits_{i=1}^n a_i\right)^n\ (a_k>0,\ k=1,2,\cdots, n)$ 得到：
		$\begin{cases}x_n = \left(1+\dfrac 1n\right)^n \cdot 1 < \left[ \dfrac{n\left(1+\dfrac{1}{n}\right)+1}{n+1}\right]^{n+1} = \left(1 +\dfrac 1{n+1}\right)^{n+1} = x_{n+1}  \\ \dfrac 1{y_n} = \left(\dfrac{n}{n+1}\right)^{n+1} \cdot 1 < \left[\dfrac{(n+1)\dfrac{n}{n+1}+1}{n+2}\right]^{n+2} = \left(\dfrac{n+1}{n+2}\right)^{n+2} = \dfrac 1{y_{n+1}}   \end{cases}$（思考为什么是严格小于）
		因此，$\{x_n\}$ 严格单调增加，$\{y_n\}$ 严格单调减少

			数学归纳法，显然 $k=0,1$ 时成立，现在假设 $\lim\limits_{n\rightarrow\infty} \left(1+\dfrac kn \right)^n = e^k$，只需证 $\lim\limits_{n\rightarrow\infty} \left(1+\dfrac {k+1}n \right)^n = e^{k+1}$

## 3-2 函数极限
- $\lim\limits_{x\rightarrow \infty} \left( 1+\dfrac 1x \right)^x = \lim\limits_{x\rightarrow 0} \left( 1+x \right)^{\frac 1x} = e,\ \lim\limits_{x\rightarrow\infty} \left(1-\dfrac 1x\right)^x  = \dfrac 1e$ 
	- *证明过程* 
		- 先证 $\lim\limits_{x\rightarrow+\infty} \left( 1+\dfrac 1x \right)^x = e$ 
			对于任意 $x\ge 1$，有 $[x] \le x\le [x]+1$，且等号不可能同时取得，故有：$\left(1+\dfrac{1}{[x]+1}\right)^{[x]} < \left(1+\dfrac 1x\right)^x < \left(1+\dfrac {1}{[x]}\right)^{[x]+1}$ 
			当 $x\rightarrow+\infty$ 时，不等式的左右两侧表现为两个数列极限 $\lim\limits_{n\rightarrow\infty}\left(1+\dfrac 1{n+1}\right)^n = e$ 与$\lim\limits_{n\rightarrow\infty}\left(1+\dfrac 1n\right)^{n+1}=e$ 
			利用函数极限的夹逼性，得 $\lim\limits_{x\rightarrow+\infty} \left( 1+\dfrac 1x \right)^x = e$ 
		- 再证 $\lim\limits_{x\rightarrow-\infty} \left( 1+\dfrac 1x \right)^x = e$ 
			令 $y=-x$，于是当 $x\rightarrow -\infty$ 时，$y\rightarrow+\infty$，从而有：
			$\lim\limits_{x\rightarrow-\infty} \left( 1+\dfrac 1x \right)^x = \lim\limits_{y\rightarrow+\infty} \left( 1-\dfrac 1y \right)^{-y} = \lim\limits_{y\rightarrow+\infty}\left(\dfrac{y}{y-1}\right)^y = \lim\limits_{y\rightarrow+\infty}\left[ \left(\dfrac{y}{y-1}\right)^{y-1} \cdot \dfrac{y}{y-1} \right] = \lim\limits_{y\rightarrow+\infty}\left[ \left(1+\dfrac 1{y-1}\right)^{y-1} \cdot \left( 1 + \dfrac 1{y-1} \right) \right] = e$ 
		- 综上两条，有 $\lim\limits_{x\rightarrow\infty} \left( 1+\dfrac 1x \right)^x = e$，故有 $\lim\limits_{x\rightarrow 0} \left( 1+x \right)^{\frac 1x} = e$ 
		- 最后证明 $\lim\limits_{x\rightarrow\infty} \left(1-\dfrac 1x\right)^x  = \dfrac 1e$

# 4 常用的等价无穷小
- 一阶：$\begin{cases} x \sim \sin x \sim \tan x \sim \arcsin x \sim \arctan x \sim \ln(1+x)\sim e^x-1 \\ a^x-1 \sim x\ln a \\ (1+x)^{\alpha} \sim \alpha x + 1 \end{cases} (x\rightarrow 0)$ 
- 二阶：$\begin{cases} 1-\cos x \sim \dfrac 12 x^2 \\ \ln(1+x) \sim x-\dfrac 12 x^2 \end{cases} (x\rightarrow 0)$ 
- 三阶：$\begin{cases} \sin x \sim x- \dfrac 16 x^3 \\ \arcsin x \sim x + \dfrac 16 x^3 \\ \tan x \sim x + \dfrac 13 x^3 \\ \arctan x \sim x - \dfrac 13 x^3 \end{cases} (x\rightarrow 0)$ 
- 当 $x\rightarrow +\infty$ 时，从低阶无穷大量到高阶无穷大量的排列为：$\ln^k x(k>0),\ x^\alpha(\alpha>0),\ a^x(a>1),\ [x]!,\ x^x$ 
- 当 $x\rightarrow 0+$ 时，从低阶无穷小量到高阶无穷小量的的排列为：$\ln^{-k}\left(\dfrac 1x\right)(k>0),\ x^\alpha(\alpha>0),\ a^{-\frac 1x}(a>1),\ \dfrac{1}{\left[\dfrac 1x\right]!},\ \left(\dfrac 1x\right)^{-\frac 1x}$

# 6 泰勒公式
## 6-1 常见的 Maclaurin 公式
下面列出几个常见函数在 $x_0=0$ 处的带拉格朗日余项的泰勒公式：
- $e^x = 1 + x + \dfrac{x^2}{2!} + \cdots + \dfrac{x^n}{n!} + \dfrac{e^{\theta x}x^{n+1}}{(n+1)!}$

- $\cos x = 1 - \dfrac{x^2}{2!} + \cdots + \dfrac{(-1)^{n}}{(2n)!}x^{2n} + \dfrac{\cos\left(\theta x + \dfrac{2n+2}{2}\pi \right)}{(2n+2)!} x^{2n+2}$
