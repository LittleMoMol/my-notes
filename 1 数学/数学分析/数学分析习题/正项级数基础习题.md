# 普通题
1. 求解 $\sum\limits_{n=1}^\infty \dfrac{4^{n+1} - 3 \cdot 2^n}{5^n}$
	- 答案：$14$ 
2. 求解 $\sum\limits_{n=1}^\infty \dfrac{2n-1}{2^n}$ 
	- 答案：$3$ 
3. 求 $\sum\limits_{n=1}^\infty \dfrac{n+3}{2n^3-n}$ 的敛散性
	- 答案：由比较判别法（极限形式）可知收敛
4. 判断正项级数 $\sum\limits_{n=1}^\infty \dfrac{n^3 [\sqrt 2 + (-1)^n]^n}{3^n}$ 的敛散性
	- 答案：通过 Cauchy 判别法可知 $\overline\lim\limits_{n\to\infty} \sqrt[n]{x_n} = \dfrac{\sqrt 2 + 1}{3} < 1$，故原级数收敛
5. 判断正项级数 $\sum\limits_{n=1}^\infty \dfrac{n^n}{3^n \cdot n!}$ 的敛散性
	- 答案：通过 d'Alembert 判别法可知 $\overline\lim\limits_{n\to+\infty} \dfrac{x_{n+1}}{x_n} = \dfrac e3 < 1$，故原级数收敛
6. 判断级数 $1+\sum\limits_{n=1}^\infty \dfrac{(2n-1)!!}{(2n)!!} \cdot \dfrac 1{2n+1}$ 的敛散性
	- 答案：经验证发现 d'Alembert 与 Cauchy 判别法均失效，使用 Rabbe 判别法 $\lim\limits_{n\to\infty} n\left( \dfrac{a_n}{a_{n+1}} - 1 \right) = \dfrac{3}{2} > 1$，故原级数收敛。或用 $n\to+\infty$ 时的 $\begin{cases} \dfrac{(2n-1)!!}{(2n)!!} \sim \dfrac 1{n\pi} \\ n! \sim \sqrt{2\pi n}\cdot \left( \dfrac ne \right)^n \end{cases}$，再用比较判别法或 d'Alembert 判别法也能出来
7. 判断级数 $\sum\limits_{n=1}^\infty \dfrac{4n}{n^4+1}$ 的敛散性
	- 答案：由比较判别法（极限形式）可知原级数收敛
8. 判断 $\sum\limits_{n=1}^\infty \dfrac{n^2}{2^n}$ 的敛散性
	- 答案：由 d'Alembert 判别法可知 $\overline\lim\limits_{n\to\infty} \dfrac{x_{n+1}}{x_n} = \dfrac 12 < 1$，故级数收敛
9. 判断 $\sum\limits_{n=1}^\infty n^2e^{-n}$ 的敛散性
	- 答案：由 d'Alembert 判别法可知 $\overline\lim\limits_{n\to\infty} \dfrac{x_{n+1}}{x_n} = \dfrac 1e<1$，故级数收敛
10. 判断 $\sum\limits_{n=1}^\infty \dfrac{a^n}{(1+a)(1+a^2)\cdots(1+a^n)}$ 的敛散性
	- 答案：由 d'Alembert 判别法可知 $\overline\lim\limits_{n\to\infty} = \dfrac{a}{1+a^{n+1}}$。$a<1$ 时上极限为 $a$，级数收敛。$a=1$ 时，上极限为 $\dfrac 12$，级数收敛。$a>1$ 时，上极限为 $0$，级数收敛。综上，级数收敛
11. 证明 $\lim\limits_{n\to\infty} \dfrac{n^n}{(n!)^2}=0$ 
	- 答案：只需证 $\sum\limits_{n=1}^\infty \dfrac{n^n}{(n!)^2}$ 收敛，通过 d'Alembert 判别法可知 $\overline\lim\limits_{n\to\infty} \dfrac{x_{n+1}}{x_n} = 0 < 1$ 证毕！
12. 证明 $\lim\limits_{n\to\infty} \dfrac{(2n)!}{2^{n(n+1)}}=0$ 
	- 答案：只需证 $\sum\limits_{n=1}^\infty \dfrac{(2n)!}{2^{n(n+1)}}$ 收敛，通过 d'Alembert 判别法可知 $\overline\lim\limits_{n\to\infty} \dfrac{x_{n+1}}{x_n} = 0<1$ 证毕！
13. 判断 $\sum\limits_{n=1}^\infty \dfrac{n!}{(a+1)(a+2)\cdots(a+n)}$ 的敛散性（$a>0$）
	- 答案：可验证 d'Alembert 判别法失效，由 Rabee 判别法可知 $\lim\limits_{n\to\infty}n\left(\dfrac{a_n}{a_{n+1}} - 1\right) = a$。对 $a$ 分类讨论可得：$a>1$ 时收敛，$0<a\le1$ 时发散
14. 判断 $\sum\limits_{n=1}^\infty \dfrac{1}{3^{\ln n}}$ 的敛散性
	- 答案：可验证 d'Alembert 判别法失效，由 Rabee 判别法可知 $\lim\limits_{n\to\infty} n\left(\dfrac{a_n}{a_{n+1}} - 1\right) = \ln 3 > 1$，故原级数收敛
15. 判断 $\sum\limits_{n=1}^\infty \left( \dfrac 12 \right)^{1+\frac 12 + \cdots + \frac 1n}$ 的敛散性
	- 答案：可验证 d'Alembert 判别法失效，由 Rabee 判别法可知 $\lim\limits_{n\to\infty} n\left( \dfrac{a_n}{a_{n+1}} - 1 \right) = \ln 2 < 1$，故原级数发散
16. 判断 $\displaystyle\sum\limits_{n=1}^\infty \int_0^{\frac 1n} \ln(1+x)\mathrm dx$ 的敛散性
	- 答案：由于 $\displaystyle \int_0^{\frac 1n} \ln(1+x)\mathrm dx \le \int_0^{\frac 1n} x\mathrm dx = \dfrac 1{2n^2}$，由比较判别法可知原级数收敛
17. 设正项级数 $\sum\limits_{n=1}^\infty x_n$ 收敛
	1. 证明：当 $p> \dfrac 12$ 时，级数 $\sum\limits_{n=1}^\infty \dfrac{\sqrt{x_n}}{n^p}$ 收敛
	2. 当 $0<p\le \dfrac 12$ 时，结论是否仍然成立？
	- 答案
		**第一问** 
		由施瓦兹不等式 $\left(\sum\limits_{n=1}^\infty a_n^2\right)\left(\sum\limits_{n=1}^\infty b_n^2\right) \ge \left(\sum\limits_{n=1}^\infty a_nb_n\right)^2$ 可知 $\left( \sum\limits_{n=1}^\infty \dfrac{\sqrt{x_n}}{n^p} \right)^2 \le \left( \sum\limits_{n=1}^\infty x_n \right) \left( \sum\limits_{n=1}^\infty \dfrac{1}{n^{2p}} \right)$ 
		由 $\sum\limits_{n=1}^\infty x_n$ 与 $\sum\limits_{n=1}^\infty \dfrac 1{n^{2p}}$ 都收敛以及比较判别法可知 $\left( \sum\limits_{n=1}^\infty \dfrac{\sqrt x_n}{n^p} \right)^2$ 收敛，故原级数收敛
		**第二问** 
		反例：令 $x_n = \dfrac 1{n(\ln n)^2}$ 就是符合条件的反例
18. 设 $\displaystyle a_n =  \int_0^{\frac \pi 4} \tan^n x \mathrm dx\ (n=1,2,\cdots)$，求级数 $\sum\limits_{n=1}^\infty \dfrac{a_n + a_{n+2}}{n}$ 的和
	- 答案：$\displaystyle a_n + a_{n+2} = \int_0^{\frac \pi 4} \tan^n x(1 + \tan^2x)\mathrm dx = \int_0^{\frac \pi 4} \tan^nx \mathrm d\tan x = \dfrac 1{n+1}$，故 $S_N = \sum\limits_{n=1}^N \dfrac{a_n + a_{n+2}}n = \sum\limits_{n=1}^N \dfrac 1{n(n+1)} = \sum\limits_{n=1}^N \left( \dfrac 1n - \dfrac 1{n+1} \right) = 1-\dfrac 1{N+1}$，故 $\lim\limits_{n\to\infty} S_N = 1$，故级数的和为 $1$ 
# 标星题
1. 上极限、下极限的定义
2. 判断正项级数 $\sum\limits_{n=1}^\infty \sin \dfrac{\pi}{n}$ 的敛散性
	- 答案：由放缩和比较判别法可知发散
3. 判断正项级数 $\sum\limits_{n=1}^\infty \left( e^{\frac{1}{n^2}} -\cos \dfrac{\pi}{n} \right)$ 敛散性
	- 答案：泰勒展开 $\begin{cases} e^{\frac{1}{n^2}} = 1 + \dfrac 1{n^2} + o\left( \dfrac 1{n^2} \right) \\ \cos\dfrac \pi n = 1 - \dfrac 12 \cdot \dfrac{\pi^2}{n^2} + o\left( \dfrac 1{n^2} \right) \end{cases}$，故 $e^{\frac{1}{n^2}} - \cos\dfrac \pi n = \dfrac{1}{n^2}\left(1+\dfrac{\pi^2}{2}\right) + o\left( \dfrac 1{n^2} \right)$，由比较判别法的极限形式可知原级数收敛
4. 判断 $\sum\limits_{n=2}^\infty \dfrac{1}{\ln^2n}$ 的敛散性
	- 答案：使用积分判别法。考虑函数 $f(x) = \dfrac 1{\ln^2x}$。$x\ge 2$ 时 $f(x)>0$ 且单调递减。则 $\displaystyle\int_2^\infty \dfrac{1}{\ln^2x}\mathrm dx = \int_{\ln 2}^\infty \dfrac{e^u}{u^2}\mathrm du\ (u=\ln x) = -\int_{\ln2}^\infty e^u \mathrm d\dfrac 1u = -\left.\left[e^u \dfrac 1u \right]\right|_{\ln2}^\infty + \int_{\ln2}^\infty \dfrac{e^u}{u}\mathrm du$。由于 $\dfrac{e^u}u\to+\infty\ (u\to+\infty)$，故 $\displaystyle\int_2^\infty \dfrac 1{\ln^2x}\mathrm dx$ 发散，由积分判别法可知 $\sum\limits_{n=2}^\infty \dfrac 1{\ln^2n}$ 发散
5. 判断 $\sum\limits_{n=1}^\infty \dfrac{\ln n}{n^2}$ 的敛散性
	- 答案：由于 $\dfrac{\ln n}{n^2} < \dfrac{n^{\frac 12}}{n^2} = \dfrac 1{n^{\frac 32}}$，由比较判别法可知 $\sum\limits_{n=1}^\infty \dfrac{\ln n}{n^2}$ 收敛
6. 判断 $\sum\limits_{n=1}^\infty \dfrac{1}{\sqrt[n]{n}}$ 的敛散性
	- 答案：由于 $\lim\limits_{n\to\infty} \dfrac 1{\sqrt[n]n} = 1\not=0$，故级数发散
7. 判断 $\sum\limits_{n=1}^\infty (\sqrt{n^2+1} - \sqrt{n^2-1})$ 的敛散性
	- 答案：$a_n = \sqrt{n^2+1} - \sqrt{n^2-1} = \dfrac{2}{\sqrt{n^2+1} + \sqrt{n^2-1}}$，通过比较判别法得到所求级数与 $\sum\limits_{n=1}^\infty \dfrac 1n$ 敛散性相同，故原级数发散
8. 判断 $\sum\limits_{n=2}^\infty \ln \dfrac{n^2+1}{n^2-1}$ 的敛散性
	- 答案：$\ln\dfrac{n^2+1}{n^2-1} = \ln\left( 1 + \dfrac{2}{n^2-1} \right) \le \dfrac{2}{n^2-1}$，由比较判别法可知原级数收敛
9. 讨论 $\displaystyle\sum\limits_{n=1}^\infty \int_{0}^{\frac 1n} \sqrt{\dfrac{x}{1-x}}\mathrm dx$ 的敛散性
	- 答案：$n\ge 2$ 时有 $\displaystyle \int_0^{\frac 1n} \sqrt{\dfrac{x}{1-x}}\mathrm dx \le \int_0^{\frac 1n} \sqrt {2x} \mathrm dx = \dfrac {2\sqrt 2}3 \cdot \dfrac 1{n^{\frac 32}}$，由比较判别法可知原级数收敛
10. 讨论 $\displaystyle \sum\limits_{n=1}^\infty \int_{n\pi}^{2n\pi} \dfrac{\sin^2x}{x^2}\mathrm dx$ 的敛散性
	- 答案：$\displaystyle\int_{n\pi}^{2n\pi} \dfrac{\sin^2x}{x^2}\mathrm dx > \dfrac {1}{4n^2\pi^2} \int_{n\pi}^{2n\pi} \sin^2x \mathrm dx = \dfrac 1{8n\pi}$，由比较判别法可知原级数发散
11. 设 $f(x)$ 在 $[1,+\infty)$ 上单调增加，且 $\lim\limits_{x\to +\infty} f(x) = A$ 
	1. 证明级数 $\sum\limits_{n=1}^\infty [f(n+1) - f(n)]$ 收敛，并求其和
	2. 进一步设 $f(x)$ 在 $[1,+\infty)$ 上二阶可导，且 $f''(x) < 0$，证明 $\sum\limits_{n=1}^\infty f'(n)$ 收敛
	- 答案
		**第一问** 
		$S_N = \sum\limits_{k=1}^N [f(k+1) - f(k)] = f(N+1) - f(1)$，故 $\lim\limits_{N\to\infty} S_N = A - f(1)$，故级数收敛，其和为 $A-f(1)$ 
		**第二问** 
		由 $f''(x) < 0$ 可知 $f'(x)$ 单调递减，
		由于 $f(x)$ 在 $[1,+\infty)$ 上单调递增，故 $f'(x)>0$ 
		由拉格朗日中值定理可知：$\exists\ \xi>0,\ \xi \in [n,n+1]$ 使得 $\dfrac{f(n+1) - f(n)}{n+1-n} = f'(\xi) = f(n+1)-f(n)$ 
		再由 $f'(n+1) \le f'(\xi) \le f'(n)$ 可知 $f'(n+1) \le f(n+1) - f(n) \le f'(n)$ 
		故 $\sum\limits_{n=1}^\infty f'(n+1) \le A - f(1)$，故 $\sum\limits_{n=1}^\infty f'(n)$ 收敛
12. 设正项级数 $\sum\limits_{n=1}^\infty x_n$ 发散，$S_n = \sum\limits_{k=1}^n x_k$，证明级数 $\sum\limits_{n=1}^\infty \dfrac{x_n}{S_n^2}$ 收敛
	- 答案
		由 $x_n = S_n - S_{n-1}$ 可知 $\dfrac{x_n}{S_n^2} \le \dfrac{S_n - S_{n-1}}{S_nS_{n-1}} = \dfrac 1{S_{n-1}} - \dfrac 1{S_n}$ 
		故 $\sum\limits_{n=1}^\infty \dfrac{x_n}{S_n^2} \le \dfrac 2{x_1} - \dfrac 1{S_n}$，由 $\lim\limits_{n\to\infty} S_n = +\infty$ 得到 $\sum\limits_{n=1}^\infty \dfrac{x_n}{S_n^2} \le \dfrac 2{x_1}$，故收敛
