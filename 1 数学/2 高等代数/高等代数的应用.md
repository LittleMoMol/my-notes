# 1 线性空间的应用

## 1-1 斐波那契数列通项公式

**斐波那契数列**：若实数序列 $$(h_n) = (h_0, h_1, h_2, \cdots)$$ 满足 $$h_0 = h_1 = 1$$ 且 $$h_n = h_{n-2} + h_{n-1},\ n\ge 2$$，则这个序列称为**斐波那契数列**

- 下面我们用线性空间和基为工具来找出**一个统一的表达式来计算所有的** $$h_n$$
    
      我们将所有满足递推关系 $$h_n = h_{n-2} + h_{n-1},\ n\ge 2$$ 的序列的集合记做 $$V(\mathbb R)$$
    
- **接下来我们在** $$V(\mathbb R)$$ **中定义加法和数量乘法**：两个序列 $$(h_n),\ (h_n') \in V(\mathbb R),\ k\in \mathbb R$$，令 $$l_n = h_n + h_n',\ k_n = kh_n\ (n=0,1,2,\cdots)$$，则 $$(l_n),\ (k_n)$$ 仍然满足关系 $$h_n = h_{n-2} + h_{n-1},\ n\ge 2$$，故 $$(l_n),\ (k_n) \in V(\mathbb R)$$，记 $$(l_n) = (h_n) + (h_n')$$ 为 $$(h_n),\ (h_n')$$ 的和，记 $$(k_n) = k(h_n)$$ 为 $$(h_n)$$ 的 $$k$$ 倍，这样就在 $$V(\mathbb R)$$ 中定义了加法和数量乘法。可以验证，和有限维向量空间 $$P^n$$ 一样，$$V(\mathbb R)$$ 构成实数域 $$\mathbb R$$ 上线性空间。
    
- **接下来我们证明** $$V(\mathbb R)$$ **是** $$\mathbb R$$ **上的二维空间**
    
      在 $$\mathbb R^2$$ 中入选任一基 $$(k_0, k_1)$$ 及 $$(k_0', k_1')$$，它们通过递推公式 $$h_n = h_{n-2} + h_{n-1},\ n\ge 2$$ 决定了两个序列 $$(k_n),\ (k_n')$$，而 $$(k_0, k_1)$$ 与 $$(k_0', k_1')$$ 无关，故 $$(k_n), (k_n')$$ 也无关
    
      对于任一 $$(h_n) \in V(\mathbb R)$$，因为 $$(k_0, k_1)$$ 及 $$(k_0', k_1')$$ 是 $$\mathbb R^2$$ 的基，故必有 $$\lambda, \mu$$ 使得 $$(h_0, h_1) = \lambda (k_0, k_1) + \mu (k_0', k_1')$$
    
      而 $$\lambda (k_n) + \mu (k_n') \in V(\mathbb R)$$ 且 $$\lambda (k_n) + \mu (k_n')$$ 的前两个元素正是 $$h_0,h_1$$，故 $$(h_n) \in V(\mathbb R)$$，而 $$(h_n)$$ 和 $$\lambda (k_n) + \mu (k_n')$$ 的最前两个元素相等，故 $$(h_n) = \lambda (k_n) + \mu (k_n')$$，故 $$(k_n), (k_n')$$ 是 $$V(\mathbb R)$$ 的基，故 $$V(\mathbb R)$$ 是二维空间
    
    其实在这里我们就知道了：如果 $$(k_0, k_1)$$ 及 $$(k_0', k_1')$$ 是 $$\mathbb R^2$$ 上的一组基，那么它们通过递推公式决定的两个序列 $$(k_n), (k_n')$$ 是 $$V(\mathbb R)$$ 的一组基
    
- **下面我们设法找出** $$V(\mathbb R)$$ **的一组具体的基**
    
      我们试着从等比数列中来寻找，令 $$h_n = q^n$$ 使得 $$h_n = h_{n-1} + h_{n-1},\ n \ge 2$$，即 $$q^2-q-1=0$$，得 $$q_1 = \dfrac{1+\sqrt 5}2,\ q_2 = \dfrac{1-\sqrt 5}2$$，由于 $$(q_1^0, q_1^1) = \left(1, \dfrac{1+\sqrt 5}2 \right),\ (q_2^0, q_2^1) = \left(1, \dfrac{1-\sqrt 5}2 \right)$$ 是 $$\mathbb R^2$$ 的基，故通过递推公式，$$(q_1^n),\ (q_2^n)$$ 是 $$V(\mathbb R)$$ 的基
    
- **最终求解**
    
      $$(q_1^n),\ (q_2^n)$$ 是 $$V(\mathbb R)$$ 的基，故存在 $$a_1, a_2$$ 使得 $$(h_n) = a_1(q_1^n) + a_2(q_2^n)$$，可根据前两项 $$\begin{cases} 1 = h_0 = a_1 \cdot 1 + a_2 \cdot 1 \\ 1 = h_1 = a_1 \cdot \dfrac{1+\sqrt 5}2 + a_2 \cdot \dfrac{1-\sqrt 5}2 \end{cases}$$ 解得 $$a_1 = \dfrac{1+\sqrt 5}{2\sqrt 5},\ a_2 = \dfrac{-1+\sqrt 5}{2\sqrt 5}$$
    
      于是 $$h_n = a_1q_a^n + a_2q_2^n$$，即 $$h_n = \dfrac{1+\sqrt 5}{2\sqrt 5} \left( \dfrac{1+\sqrt 5}2 \right)^n + \dfrac{-1+\sqrt 5}{2\sqrt 5} \left( \dfrac{1-\sqrt 5}2 \right)^n = \dfrac 1{\sqrt 5} \left[ \left( \dfrac{1+\sqrt 5}2 \right)^{n+1} - \left( \dfrac{1-\sqrt 5}2 \right)^{n+1} \right]$$
