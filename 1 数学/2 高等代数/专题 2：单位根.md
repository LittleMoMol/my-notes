# 1 单位根的定义

我们称 $$x^n = 1$$ 在复数域上的解为 $$n$$ **次单位根**，我们用 $$\omega_n^i$$ 表示**第** $$i$$ **个** $$n$$ **次单位根**

令 $$z=a+bi$$ 表示 $$n$$ 次单位根其中之一，则 $$|z| = \sqrt{a^2+b^2}$$，$$|z^n| = (\sqrt{a^2+b^2})^n = 1$$，解得 $$|z| = 1$$，故**单位根一定在以原点为圆心，半径为 1 的圆上**！而形如 $$z = \cos\theta + i\sin\theta $$ 的复数也在以原点为圆心，半径为 1 的圆上。

因此我们设 $$\omega_n^k = \cos\theta + i\sin\theta$$，则 $$(\omega_n^k)^n = (\cos\theta + i\sin\theta)^n = \cos (n\theta) + i\sin(n\theta)$$

而由定义有 $$(\omega_n^k)^n = 1$$，故 $$\cos(n\theta) + i\sin(n\theta) = 1$$，则 $$n\theta = 2k\pi$$

故：$$\boxed{ \omega_n^k = \cos\left(\dfrac{2k\pi}{n}\right) + i\sin\left(\dfrac{2k\pi}{n}\right)\ (0 \le k \le n-1) }$$

# 2 单位根的性质

- $$\forall\ i \not= j,\ \omega_n^i \not= \omega_n^j$$
    
- $$\omega_n^0 = 1$$
    
- $$\omega_n^k = (\omega_n^1)^k$$
    
- $$\omega_{dn}^{dk} = \omega_n^k$$
    
- $$\omega_n^{k+\frac{n}{2}} = -\omega_n^k $$（$$n$$ 为偶数）
    
- $$\omega_n^i \omega_n^j = \omega_n^{i+j} $$
    
- $$\sum_{k=0}^{n-1} \omega_n^k=0$$
    
- $$1 + (\omega_n^1)^a + (\omega_n^2)^a + \cdots (\omega_n^{n-1})^a = \begin{cases} n & \gcd(a,n) = 1 \\ 0 & \gcd(a,n) \not= 1 \end{cases}$$
