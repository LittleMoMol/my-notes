# 6 不定积分
## 6-1 定义
- **原函数**：若在某个区间上，函数 $F(x)$ 和 $f(x)$ 成立关系 $F'(x) = f(x)$（也就是 $\mathrm d(F(x)) = f(x) \mathrm dx$），则称 $F(x)$ 是 $f(x)$ 在这个区间上的一个**原函数**。
	- 之所以要称“一个”原函数，是由于一个函数若存在原函数，那么它的原函数必定不是唯一的。
	- $f(x)$ 的所有原函数都具有 $F(x)+C$（$C$ 为常数）的形式（由拉格朗日中值定理的推论 1 可以证明），所以只要求出了 $f(x)$ 的任意一个原函数 $F(x)$，就可以用 $F(x)+C$ 来代表 $f(x)$ 的全部原函数了。
- **不定积分**：一个函数 $f(x)$ 的与原函数的全体称为这个函数的**不定积分**，记作 $\displaystyle\int f(x) \mathrm dx$  
	- **积分号**、**被积函数**、**积分变量**：“$\displaystyle\int$”称为**积分符号**，$f(x)$ 称为**被积函数**，$x$ 称为**积分变量**。
	- 积分变量采用的字母是无关紧要的，即 $\displaystyle\int f(x)\mathrm dx = F(x)+C,\ \int f(u)\mathrm du = F(u)+C,\ \int f(t)\mathrm dt = F(t)+C$ 等形式本质是一样的。
	- 求不定积分 $\displaystyle\int f(x)\mathrm dx$ 就是由一个函数的微分 $f(x)\mathrm dx$ 求它的原函数，因此微分运算“$\mathrm d$”与不定积分运算“$\displaystyle\int$”构成一对逆运算：$\begin{aligned} F(x)\xrightarrow{\mathrm d} f(x)\mathrm dx \\ F(x)+C \xleftarrow[\int]{} f(x)\mathrm dx  \end{aligned}$，具体可以写成 $\displaystyle\mathrm d\left(\int f(x)\mathrm dx \right) = f(x)\mathrm dx \left(\text{即}\dfrac{\mathrm d}{\mathrm dx}\left( \int f(x)\mathrm dx \right) = f(x)\right)$ 与 $\displaystyle\int \mathrm dF(x) = F(x) + C$ 
	- 可以认为微分号 $\mathrm d$ 与积分号 $\displaystyle\int$ 在一起时可以相互抵消（注意：先做微分运算后做不定积分运算时要相差一个常数）
	- 注：尽管在观念上，应当从微分的概念出发去讨论不定积分，再理论推导时也确实大多是这样做的。但实际求不定积分时，一般总是直接从导数出发考虑的，这样更方便一些。                 
- **有理函数**：形如 $\dfrac{p_m(x)}{q_n(x)}$ 的函数称为**有理函数**，这里 $p_m(x)$ 和 $q_n(x)$ 分别是 $m$ 次和 $n$ 次多项式。
## 6-2 性质与技巧
### 6-2-1 不定积分的线性性质
- **线性性**：若函数 $f(x)$ 和 $g(x)$ 的原函数都存在，则对任意常数 $k_1$ 和 $k_2$，函数 $k_1f(x) + k_2g(x)$ 的原函数也存在，且有 $\displaystyle\int[k_1f(x) + k_2g(x)]\mathrm dx = k_1\int f(x)\mathrm dx + k_2\int g(x)\mathrm dx$ 
	- 此式应理解为等式两端所表示的函数族相同。另外，当 $k_1 = k_2 = 0$ 时，等式右端应理解为常数 $C$ 
	- *证明过程* 
		设 $F(x)$ 和 $G(x)$ 分别为 $f(x)$ 和 $g(x)$ 的一个原函数，那么对于任意常数 $k_1$ 和 $k_2$，$k_1F(x) + k_2G(x)$ 是 $k_1f(x) + k_2g(x)$ 的一个原函数，因此有 $\displaystyle\int[k_1f(x) + k_2g(x)]\mathrm dx = k_1F(x) + k_2G(x) + C$ 
		而 $\displaystyle\begin{aligned} k_1\int f(x)\mathrm dx + k_2\int g(x) \mathrm dx &= k_1(F(x)+C_1) + k_2(G(x)+C_2) \\ &= k_1F(x) + k_2G(x) + (k_1C_1 + k_2C_2) \end{aligned}$ 
		由于上面两式中的 $C, C_1, C_2$ 都代表任意常数，所以上面两等式的右端所表示的函数族相同，于是有 $\displaystyle\int[k_1f(x) + k_2g(x)]\mathrm dx = k_1\int f(x)\mathrm dx + k_2\int g(x)\mathrm dx$，证毕！
### 6-2-2 换元积分法（***存疑***）
前言：由于求不定积分是微分运算 $\mathrm d(F(x)) = f(x)\mathrm dx$ 的逆运算，所以在用换元法求不定积分的过程中，前几章得到的微分运算的所有法则都可以用。
- **第一类换元积分法** 
	- **理论**：在不定积分 $\displaystyle\int f(x)\mathrm dx$ 中，若可以找到函数 $\widetilde f(x), g(x)$ 使得 $f(x)\equiv \widetilde f(g(x))g'(x)$ 且 $\tilde f(u)$ 的原函数 $\widetilde F(u)$ 是容易的。 由 $[\widetilde F(g(x))]' = \widetilde F'(g(x))g'(x) = \widetilde f(g(x))g'(x) = f(x)$ 可知 $\displaystyle\int f(x)\mathrm dx = \int [\widetilde F(g(x))]' \mathrm dx = \int \dfrac{\mathrm d\widetilde F(g(x))}{\mathrm dx} \mathrm dx = \widetilde F(g(x)) + C$ 
	- 在**运算**中，可采用下述步骤：用 $u=g(x)$ 对原式作变量代换，这时相应地有 $\mathrm du = g'(x) \mathrm dx$，于是：
		$\begin{aligned} \displaystyle\int f(x)\mathrm dx &= \int \widetilde f(g(x))g'(x) \mathrm dx = \int \widetilde f(g(x)) \mathrm dg(x) \\ &= \int \widetilde f(u) \mathrm du = \widetilde F(u) + C = \widetilde F(g(x)) + C \end{aligned}$ 
	- 这个方法称为**第一类换元积分法**（由于在将 $f(x)\mathrm dx$ 化成 $\widetilde f(g(x)) g'(x) \mathrm dx = \widetilde f(g(x))\mathrm dg(x)$ 地过程中往往要采取适当地“凑”的办法，它也被俗称为“**凑积分法**”）
- **第二类换元积分法** 
	- **理论**：若不定积分 $\displaystyle\int f(x)\mathrm dx$ 不能直接求出，但能够找到一个适当的变量代替 $x=\varphi(t)$（要求 $x=\varphi(t)$ 的反函数 $t=\varphi^{-1}(x)$ 存在），将原式化为 $\displaystyle\int f(x)\mathrm dx = \int f(\varphi(t))\mathrm d\varphi(t) = \int f(\varphi(t))\varphi'(t)\mathrm dt$，而 $f(\varphi(t))\varphi'(t)$ 的原函数 $\widetilde F(t)$ 是容易求的。那么有 $\widetilde F'(t) = f(\varphi(t))\varphi'(t)$，便有 $\begin{aligned} &\dfrac{\mathrm d}{\mathrm dx}\widetilde F(\varphi^{-1}(x)) = \dfrac{\mathrm d}{\mathrm dx}\widetilde F(t)) = \widetilde F'(t) \dfrac{\mathrm dt}{\mathrm dx} = f(\varphi(t))\varphi'(t) \dfrac{\mathrm dt}{\mathrm dx} \\ =& f(\varphi(t))\varphi'(t) \dfrac{1}{\dfrac{\mathrm d(\varphi(t))}{\mathrm dt}} f(\varphi(t))\varphi'(t)\dfrac{1}{\varphi'(t)} = f(\varphi(t)) = f(x) \end{aligned}$，便有 $\displaystyle\int f(x) \mathrm dx = \widetilde F(\varphi^{-1}(x)) + C$ 
	- 在**运算**中，可以采取下述与第一类换元积分法方向相反的步骤：
		$\displaystyle\int f(x) \mathrm dx = \int f(\varphi(t))\mathrm d\varphi(t) = \int f(\varphi(t))\varphi'(t)\mathrm dt = \widetilde F(t) + C = \widetilde F(\varphi^{-1}(x)) + C$ 
	- 这个方法称为**第二类换元积分法** 
	- **经验**：若被积函数中含有诸如 $\sqrt{a^2-x^2}, \sqrt{x^2 - a^2}, \sqrt{x^2 + a^2}$ 这样形式的根式，可以分别考虑将变换取为 $x=a\sin t,\ x=a\sec t,\ x=a\tan t$ 以化去根号
### 6-2-3 分部积分法
- **理论基础**：函数乘积的微分公式
- **分部积分公式**：$\displaystyle\int u(x)\mathrm d[v(x)] = u(x)v(x) - \int v(x)\mathrm d[u(x)]$ 或 $\displaystyle\int u(x)v'(x)\mathrm dx = u(x)v(x) - \int v(x)u'(x)\mathrm dx$ 
	- *推导过程* 
		对于任意两个可微的函数 $u(x), v(x)$ 成立关系式 $\mathrm d[u(x)v(x)] = v(x)\mathrm d[u(x)] + u(x)\mathrm d[v(x)]$ 
		两边同时求不定积分并移项，就有 $\displaystyle\int u(x)\mathrm d[v(x)] = u(x)v(x) - \displaystyle\int v(x)\mathrm d[u(x)]$ 
		也即 $\displaystyle\int u(x)v'(x)\mathrm dx = u(x)v(x) - \displaystyle\int v(x)u'(x)\mathrm dx$ 
- **适用场景**：直接求 $\displaystyle\int u(x)v'(x) \mathrm dx$ 与求 $\displaystyle\int v(x)u'(x)\mathrm dx$ 的难度相差很大时，那么通过分部积分公式转换，便迎刃而解了。
- 分部积分公式的**正确使用**大致有下述几种模式
	- 通过对 $u(x)$ 求导降低它的复杂程度，而 $v'(x)$ 与 $v(x)$ 的类型相似或复杂程度相当。
		记 $p_n(x)$ 为 $n$ 次多项式，则对于形如 $\displaystyle\int p_n(x)\sin\alpha x \mathrm dx,\ \int p_n(x) \cos\beta x \mathrm dx,\ \int p_n(x) e^{\lambda x} \mathrm dx$ 之类的不定积分，总是取 $p_n(x)$ 为 $u(x)$，而将另一个函数看成 $v'(x)$，这时 $v(x)$ 是很容易求的。通过分部积分，$p_n(x)$ 的次数随着求导而逐次降低，直到最后成为常数。
	- 通过对 $u(x)$ 求导使得它的类型与 $v(x)$ 的类型相同或相近，然后将它们作为一个统一的形式来处理。
		例如，对于形如 $\displaystyle\int p_n(x)\arcsin x\mathrm dx,\ \int p_n(x)\arctan x\mathrm dx,\ \int p_n(x) \ln x \mathrm dx$ 之类的不定积分，总是取 $p_n(x)$ 为 $v'(x)$，而将另一个函数看成 $u(x)$，这时关于 $u'(x)v(x)$ 的不定积分就比较容易求出（因为 $u(x)=\arcsin x,\ \arctan x,\ \ln x$ 等时，$u'(x)$ 的长相很像多项式，即与 $v'(x) = p_n(x)$ 的类型相同或相近）
	- 利用有些函数经数次求导后形式会复原的性质，通过若干次分部积分，使等式右边也产生 $\displaystyle\int u(x)v'(x)\mathrm dx$ 的项，只要它的系数不为 $1$，就可以用解方程的办法求得 $\displaystyle\int u(x)v'(x)\mathrm dx$ 
		如对于形如 $\displaystyle\int e^{\lambda x}\sin\alpha x\mathrm dx$ 或 $\displaystyle\int e^{\lambda x}\cos\beta x\mathrm dx$ 之类的不定积分，可以取 $e^{\lambda x}$ 与 $\sin \alpha x$（或 $\cos\beta x$）中任一个为 $u(x)$，而另一个为 $v'(x)$；对于 $\displaystyle\int\sqrt{x^2+a^2} \mathrm dx$ 之类的不定积分，则可将 $u(x)$ 取作 $\sqrt{x^2+a^2}$，而将 $v'(x)$ 视为 $1$ 
	- 对某些形如 $\displaystyle\int f^n(x)\mathrm dx$ 的不定积分，利用分部积分法降低幂指数，导出递推公式。
## 6-3 有理函数的不定积分及其应用
- **前言**：初等函数的不定积分并非都是初等函数，如 $\displaystyle\int \dfrac{\sin x}{x}\mathrm dx,\ \int e^{\pm x^2} \mathrm dx,\ \int\dfrac {1}{\ln x}\mathrm dx$ 和 $\displaystyle\int\sqrt{1-k^2\sin^2x}\mathrm dx\ (0<k^2<1)$ 等，就无法用基本初等函数的有限次四则运算和复合来表达，俗称“**积不出**”（这并不意味着这些被积函数没有原函数。事实上，任何一个连续函数必存在原函数，只是上述不定积分不能用初等函数表示出来）
- **定理 1**：设有理函数 $\dfrac{p(x)}{q(x)}$ 是真分式，多项式 $q(x)$ 有 $k$ 重实根 $\alpha$，即 $q(x)=(x-\alpha)^kq_1(x),\ q_1(\alpha)\not= 0$。则存在实数 $\lambda$ 与多项式 $p_1(x)$，$p_1(x)$ 的次数低于 $(x-\alpha)^{k-1}q_1(x)$ 的次数，成立 $\dfrac{p(x)}{q(x)} = \dfrac{\lambda}{(x-\alpha)^k} + \dfrac{p_1(x)}{(x-\alpha)^{k-1}q_1(x)}$ 
	- *证明过程* 
		令 $\dfrac{p(\alpha)}{q_1(\alpha)} = \lambda$，则 $x=\alpha$ 是多项式 $p(x) - \lambda q_1(x)$ 的根
		设 $p_1(x) = \dfrac{p(x)-\lambda q_1(x)}{(x-\alpha)}$ 
		根据已知条件则有 $\begin{cases} q(x) = (x-\alpha)^kq_1(x),\ q_1(\alpha)\not= 0 \\ p(x) = p_1(x)(x-\alpha) + \lambda q_1(x) \end{cases}$ 
		那么 $\dfrac{p(x)}{q(x)} = \dfrac{p_1(x)(x-\alpha)+\lambda q_1(x)}{(x-\alpha)^kq_1(x)} = \dfrac{\lambda}{(x-\alpha)^k} + \dfrac{p_1(x)}{(x-\alpha)^{k-1}q_1(x)}$ ，证毕！
- **定理 2**：设有理函数 $\dfrac{p(x)}{q(x)}$ 是真分式，多项式 $q(x)$ 有 $l$ 重共轭复根 $\beta \pm i\gamma$，即 $q(x) = (x^2 + 2\xi x + \eta^2)^l q^*(x),\ q^*(\beta \pm i\gamma)\not= 0$，其中 $\xi = -\beta,\ \eta^2 = \beta^2 + \gamma^2\ (\xi^2 < \eta^2)$。则存在 $\mu, \nu$ 和多项式 $p^*(x)$，$p^*(x)$ 的次数低于 $(x^2+2\xi x + \eta^2)^{l-1}q^*(x)$ 的次数，成立 $\dfrac{p(x)}{q(x)} = \dfrac{\mu x + \nu}{(x^2+2\xi x + \eta^2)^l} + \dfrac{p^*(x)}{(x^2 + 2\xi x + \eta^2)^{l-1} q^*(x)}$ 
	- *证明过程* 
		令 $\dfrac{p(\beta + i\gamma)}{q^*(\beta + i\gamma)} = \mu(\beta + i\gamma) + \nu$，其中 $\mu, \nu$ 为实数，则 $\dfrac{p(\beta - i\gamma)}{q^*(\beta - i\gamma)} = \mu(\beta - i\gamma) + \nu$，于是 $x=\beta \pm i\gamma$ 是多项式 $p(x) - (\mu x + \nu)q^*(x)$ 的根
		设 $p^*(x)$ 满足 $p(x) - (\mu x + \nu)q^*(x) = (x^2 + 2\xi x + \eta^2) p^*(x)$ 
		根据已知条件则有 $\begin{cases} q(x) = (x^2 + 2\xi x + \eta^2)^l q^*(x),\ q^*(\beta \pm i\gamma)\not= 0 \\ p(x) = (\mu x + \nu)q^*(x) + (x^2 + 2\xi x + \eta^2) p^*(x) \end{cases}$ 
		那么 $\dfrac{p(x)}{q(x)} = \dfrac{(\mu x + \nu)q^*(x) + (x^2 + 2\xi x + \eta^2) p^*(x)}{(x^2 + 2\xi x + \eta^2)^l q^*(x)} = \dfrac{\mu x + \nu}{(x^2+2\xi x + \eta^2)^l} + \dfrac{p^*(x)}{(x^2 + 2\xi x + \eta^2)^{l-1} q^*(x)}$，证毕！
- 现在考虑有理函数的不定积分 $\displaystyle\int \dfrac{p_m(x)}{q_n(x)} \mathrm dx$ 
	- 我们总假定 $\dfrac{p_m(x)}{q_n(x)}$ 是真分式，即成立 $m<n$，因为不然的话，可以通过多项式的带余除法，使得 $\dfrac{p_m(x)}{q_n(x)} = p_{m-n}(x) + \dfrac{r(x)}{q_n(x)}$，其中 $p_{m-n}(x)$ 是 $m-n$ 次多项式，而 $r(x)$ 是次数不超过 $n-1$ 的多项式，这样就得到 $\displaystyle\int\dfrac{p_m(x)}{q_n(x)}\mathrm dx = \int P_{m-n}(x) \mathrm dx + \int \dfrac{r(x)}{q_n(x)}\mathrm dx$，由于求 $\displaystyle\int P_{m-n}(x)\mathrm dx$ 非常容易，原问题就变为求一个真分式类型的有理函数的不定积分了。另外，为了讨论的方便，我们假定 $q_n(x)$ 的最高此项系数为 $1$ 
	- 由代数基本定理，坟墓多项式 $q_n(x)$ 在复数域上恰有 $n$ 个根。由于 $q_n(x)$ 是实多项式，因此它的根要么是实根，要么是成对出现的共轭复根。设它的全部实根为 $\alpha_1, \alpha_2, \cdots, \alpha_i$，其重数分别为 $m_1, m_2, \cdots, m_i$；全部复根为 $\beta_1 \pm i\gamma_1, \beta_2 \pm i\gamma_2, \cdots, \beta_j \pm i\gamma_j$，其重数分别为 $n_1, n_2, \cdots, n_j$，易知满足 $\sum\limits_{k=1}^i m_k + 2\sum\limits_{k=1}^j n_k = n$。记 $\xi_k = -\beta_k,\ \eta_k^2 = \beta_k^2 + \gamma_k^2\ (\xi_k^2 < \eta_k^2)$，则在实数域上可将 $q_n(x)$ 因式分解为 $q_n(x) = \prod\limits_{k=1}^i (x-\alpha_k)^{m_k} \cdot \prod\limits_{k=1}^j(x^2 + 2\xi_k x + \eta_k^2)^{n_k}$ 
	- 求有理函数的不定积分 $\displaystyle\int \dfrac{p_m(x)}{q_n(x)} \mathrm dx$ 的关键，是将有理函数 $\dfrac{p_m(x)}{q_n(x)}$ 分解成简单分式之和，再分别求简单分式的不定积分
	- 重复利用定理 1 和定理 2，可将有理函数 $\dfrac{p_m(x)}{q_n(x)} = \dfrac{p_m(x)}{\prod\limits_{k=1}^i(x-\alpha_k)^{m_k} \cdot \prod\limits_{k=1}^j(x^2+2\xi_kx+\eta_k^2)^{n_k}}$ 分解成简单分式之和，分解规律是：若 $q_n(x)$ 含有因子 $(x-\alpha_k)^{m_k}$，则在和式中就有项 $\dfrac{\lambda_{k1}}{x-\alpha_k},\ \dfrac{\lambda_{k2}}{(x-\alpha_k)^2},\cdots,\dfrac{\lambda_{km_k}}{(x-\alpha_k)^{m_k}}$；若 $q_n(x)$ 含有因子 $(x^2+2\xi_kx+\eta_k^2)^{n_k}$，则在和式中就有项 $\dfrac{\mu_{k1}x + \nu_{k1}}{x^2+2\xi_kx+\eta_k^2},\ \dfrac{\mu_{k2}x + \nu_{k2}}{(x^2+2\xi_kx+\eta_k^2)^2},\cdots,\dfrac{\mu_{kn_k}x + \nu_{kn_k}}{(x^2+2\xi_kx+\eta_k^2)^{n_k}}$。所以就有：$\dfrac{p_m(x)}{q_n(x)} = \sum\limits_{k=1}^i \sum\limits_{r=1}^{m_k} \dfrac{\lambda_{kr}}{(x-\alpha_k)^r} + \sum\limits_{k=1}^j \sum\limits_{r=1}^{n_k} \dfrac{\mu_{kr} + \nu_{kr}}{(x^2+2\xi_kx+\eta_k^2)^r}$，其中 $\lambda_{kr},\ \mu_{kr},\ \nu_{kr}$ 可以用待定系数法具体算出来
	- 根据不定积分的线性性质，即知 $\displaystyle\int\dfrac{p_m(x)}{q_n(x)} = \sum\limits_{k=1}^i \sum\limits_{r=1}^{m_k} \lambda_{kr} \int \dfrac{\mathrm dx}{(x-\alpha_k)^r} + \sum\limits_{k=1}^j \sum\limits_{r=1}^{n_k} \int \dfrac{\mu_{kr} + \nu_{kr}}{(x^2+2\xi_kx+\eta_k^2)^r} \mathrm dx$，它所涉及的不定积分只有两种类型：
		- $\displaystyle\int \dfrac{\mathrm dx}{(x-\alpha)^n}\ (n\ge 1)$ 
			根据第一类换元积分法可以求得 $\displaystyle\int\dfrac{\mathrm dx}{(x-\alpha)^n} = \begin{cases} \ln|x-\alpha| + C & n=1 \\ -\dfrac{1}{n-1} \cdot \dfrac{1}{(x-\alpha)^{n-1}} + C & n \ge 2 \end{cases}$ 
		- $\displaystyle\int\dfrac{\mu x + \nu}{(x^2+2\xi x + \eta^2)^n}\mathrm dx\ (n\ge 1,\ \xi^2 < \eta^2)$ 
			首先将原式化成 $\displaystyle\int \dfrac{\mu x + \nu}{(x^2+2\xi x + \eta^2)^n}\mathrm dx = \dfrac \mu 2 \int\dfrac{2x + 2\xi}{(x^2+2\xi x + \eta^2)^n}\mathrm dx + (\nu - \mu\xi)\int\dfrac{\mathrm dx}{(x^2 + 2\xi x + \eta^2)^n}$ 
			等号右端第一项中的积分可以利用第一类换元积分法，$\displaystyle\int\dfrac{2x+2\xi}{(x^2+2\xi x + \eta^2)^n}\mathrm dx = \int\dfrac{\mathrm d(x^2+2\xi x + \eta^2)}{(x^2+2\xi x + \eta^2)^n} = \begin{cases} \ln|x^2+2\xi x + \eta^2| + C & n=1 \\ = - \dfrac {1}{n-1} \cdot \dfrac{1}{(x^2+2\xi x + \eta^2)^{n-1}} + C & n \ge 2 \end{cases}$ 
			等号有段第二项中的积分可配成 $\displaystyle\int\dfrac{\mathrm dx}{(x^2+2\xi x + \eta^2)^n} = \int\dfrac{\mathrm d(x+\xi)}{[(x+\xi)^2 + (\eta^2 - \xi^2)]^n}$，再利用分部积分法降低幂指数，导出递推公式，得到 $I_n = \displaystyle\int\dfrac{\mathrm dx}{(x^2+2\xi x + \eta^2)^n}$ 的递推表达式为 $I_n = \begin{cases} \dfrac{1}{2(\eta^2-\xi^2)(n-1)} \left[(2n-3)I_{n-1} + \dfrac{x+\xi}{(x^2+2\xi x + \eta^2)^{n-1}} \right] & n\ge 2 \\ \dfrac{1}{\sqrt{\eta^2 - \xi^2}}\arctan\dfrac{x+\xi}{\sqrt{\eta^2-\xi^2}} + C \end{cases}$。特别地，$I_2 = \dfrac{1}{2(\sqrt{\eta^2 - \xi^2})^3} \arctan\dfrac{x+\xi}{\sqrt{\eta^2-\xi^2}} + \dfrac{1}{2(\eta^2-\xi^2)} \cdot \dfrac{x+\xi}{x^2 + 2\xi x + \eta^2}$ 
	- 至此在理论上，求有理函数的不定积分问题已经圆满地得到了解决，并且上面的结果也告诉我们，有理函数的原函数一定是初等函数。
- 现在分析可化成有理函数不定积分的情况
	- $R\left(x,\ \sqrt[n]{\dfrac{\xi x + \eta}{\mu x + \nu}}\right)$ 类的不定积分。这里 $R(u,v)$ 表示两个变量 $u,v$ 的有理函数（即分子和分母都是关于 $u,v$ 的二元多项式）
		对 $R\left(x,\ \sqrt[n]{\dfrac{\xi x + \eta}{\mu x + \nu}}\right)$ 作变量替换 $\sqrt[n]{\dfrac{\xi x + \eta}{\mu x + \nu}} = t$，则 $x=\varphi(t) = \dfrac{-\nu t^n + \eta}{\mu t^n - \xi}$ 
			由于有理函数与有理函数的复合仍为有理函数，有理函数的导数也是有理函数，因此 $\displaystyle\int R\left(x,\ \sqrt[n]{\dfrac{\xi x + \eta}{\mu x + \nu}}\right) \mathrm dx = \int R\left( \dfrac{-\nu t^n + \eta}{\mu t^n - \xi}, t\right)\varphi'(t)\mathrm dx$ 
			上式右端的被积函数是一个关于变量 $t$ 的有理函数用前面讲过的方法就可以将它求出来。
			$R\left(x,\ \sqrt[n]{\dfrac{\xi x + \eta}{\mu x + \nu}}\right)$ 类型不定积分的最常见的简单情况是 $\mu = 0$，这时被积函数变成了 $R(x, \sqrt[n]{\xi x + \eta})$ 
		对于 $\sqrt[n]{(\xi x + \eta)^i (\mu x + \nu)^j}\ (i+j=kn)$ 类型的函数，可以先化成 $\sqrt[n]{(\xi x + \eta)^i(\mu x + \nu)^j} = (\xi x + \nu)^k \cdot \sqrt[n]{\dfrac{(\mu x + \nu)^j}{(\xi x + \eta)^j}}$，再作代换 $\sqrt[n]{\dfrac{\mu x + \nu}{\xi x + \eta}} = t$，然后套用上面的步骤来做
	- $R(\sin x, \cos x)$ 类的不定积分。这里 $R(u,v)$ 表示两个变量 $u,v$ 的有理函数（即分子和分母都是关于 $u,v$ 的二元多项式）
		由于 $\tan x,\cot x,\sec x,\csc x$ 都是 $\sin x$ 和 $\cos x$ 的有理函数，所以凡是三角函数的有理函数都可以化成 $\sin x$ 和 $\cos x$ 的有有理函数，因此我们只要研究如何去求形如 $\displaystyle\int R(\sin x, \cos x)\mathrm dx$ 的不定积分就可以了。
		用三角函数的万能公式 $\tan \dfrac x2 = t$ 作代换，则 $\sin x = 2\sin\dfrac x2 \cos \dfrac x2 = \dfrac{2t}{1+t^2}$，$\cos = \cos^2\dfrac x2 - \sin^2\dfrac x2 = \dfrac{1-t^2}{1+t^2}$，$\mathrm dx = \mathrm d(2\arctan t) = \dfrac{2\mathrm dt}{1+t^2}$ 
		于是原式化成了求有理函数 $\displaystyle \int R(\sin x, \cos x)\mathrm dx = \int R\left( \dfrac{2t}{1+t^2}, \dfrac{1-t^2}{1+t^2} \right)\dfrac{2}{1+t^2}\mathrm dt$ 的不定积分，同样可以用前面讲过的方法将它求出来
		**注意**：尽管用万能公式可以确保求出所有的 $R(\sin x, \cos x)$ 类函数的不定积分，但也不能一见到三角函数的有理函数，就不管具体情况地将万能公式用上去，事实上，利用三角函数的性质或其他方法在很多时候会更方便。
## 6-4 最基本的不定积分公式
根据微分与不定积分的关系以及基本初等函数的微分公式，可以得到一些最基本的不定积分公式
$$
\begin{aligned}
&\mathrm d(e^x) = e^x \mathrm dx & \quad & \displaystyle\int e^x \mathrm dx = e^x + C\\
&\mathrm d(\ln x) = \dfrac{\mathrm dx}x & \quad & \displaystyle\int \dfrac{\mathrm dx}{x} = \ln|x|+C \\
&\mathrm d(x^\alpha) = \alpha x^{\alpha-1}\mathrm dx & \quad & \displaystyle\int x^\alpha \mathrm dx = \dfrac{1}{\alpha+1} x^{\alpha + 1} + C\ (\alpha\not= -1)\\
&\mathrm d(\sin x) = \cos x \mathrm dx & \quad & \displaystyle\int \cos x \mathrm dx = \sin x + C\\
&\mathrm d(\cos x) = -\sin x \mathrm dx & \quad & \displaystyle\int \sin x \mathrm dx = -\cos x + C\\
&\mathrm d(\tan x) = \sec^2 x \mathrm dx & \quad & \displaystyle\int \sec^2 x \mathrm dx = \tan x + C\\
&\mathrm d(\cot x) = -\csc^2 x \mathrm dx & \quad & \displaystyle\int \csc^2 x \mathrm dx = -\cot x + C\\
&\mathrm d(\sec x) = \tan x \sec x \mathrm dx & \quad & \displaystyle\int \tan x \sec x \mathrm dx = \sec x + C\\
&\mathrm d(\csc x) = -\cot x \csc x \mathrm dx & \quad & \displaystyle\int \cot x \csc x \mathrm dx = -\csc x + C\\
&\mathrm d(\arcsin x) = \dfrac{\mathrm dx}{\sqrt{1-x^2}} & \quad & \displaystyle\int \dfrac{\mathrm dx}{\sqrt{1-x^2}} = \arcsin x + C\\
&\mathrm d(\arctan x) = \dfrac{\mathrm dx}{1+x^2} & \quad & \displaystyle\int \dfrac{\mathrm dx}{1+x^2} = \arctan x + C 
\end{aligned}
$$
## 6-5 基本积分表
- $\displaystyle\int x^\alpha \mathrm dx = \begin{cases} \dfrac{1}{\alpha + 1} x^{\alpha + 1} + C & \alpha \not= -1 \\ \ln |x| + C & \alpha = -1 \end{cases}$ 
- $\displaystyle\int\ln x \mathrm dx = x(\ln x - 1) + C$ 
- $\displaystyle\int a^x \mathrm dx = \dfrac{a^x}{\ln a} + C$，特别地 $\displaystyle\int e^x \mathrm dx = e^x + C$ 
- $\displaystyle\int \sin x \mathrm x = -\cos x + C$  
- $\displaystyle\int \cos x \mathrm dx = \sin x + C$ 
- $\displaystyle\int \tan x \mathrm dx = -\ln |\cos x| + C$ 
- $\displaystyle\int \cot x \mathrm dx = \ln |\sin x| + C$ 
- $\displaystyle\int \sec x \mathrm dx = \ln|\sec x + \tan x| + C$ 
- $\displaystyle\int\csc x \mathrm dx = \ln |\csc x - \cot x| + C$ 
- $\displaystyle\int \text{sh } x \mathrm dx = \text{ch } x + C$ 
- $\displaystyle\int \text{ch }x\mathrm dx = \text{sh }x + C$ 
- $\displaystyle\int \dfrac{\mathrm dx}{\sqrt{a^2-x^2}} = \arcsin \dfrac xa + C$ 
- $\displaystyle\int \dfrac{\mathrm dx}{\sqrt{x^2 \pm a^2}} = \ln |x + \sqrt{x^2 \pm a^2}| + C$ 
- $\displaystyle\int \dfrac{\mathrm dx}{x^2-a^2} = \dfrac {1}{2a}\ln \left| \dfrac{x-a}{x+a} \right| + C$ 
- $\displaystyle\int\dfrac{\mathrm dx}{x^2+a^2} = \dfrac 1a\arctan\dfrac xa + C$ 
- $\displaystyle\int\sqrt{a^2-x^2}\mathrm dx = \dfrac 12x\sqrt{a^2-x^2} + \dfrac{a^2}2\arcsin\dfrac xa + C$ 
- $\displaystyle\int\sqrt{x^2\pm a^2} \mathrm dx = \dfrac 12(x\sqrt{x^2 \pm a^2} \pm a^2 \ln |x+\sqrt{x^2 \pm a^2}|) + C$ 
- 由于任一个二次多项式 $ax^2 + bx + c$ 必能通过配方化成 $a[(x-p)^2 \pm q^2]$ 的形式，因此最后的六个（实际上是八个）公式对于求某些 $f(ax^2 + bx + c)$ 型的不定积分是很有用的。
