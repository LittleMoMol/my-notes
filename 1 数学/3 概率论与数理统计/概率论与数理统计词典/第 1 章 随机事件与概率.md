# 1 随机事件与概率
## 1-1 随机事件及其运算
### 1-1-1 随机现象、样本空间
- **随机现象**：在一定的条件下，并不总是出现相同结果的现象称为**随机现象** 
	- **随机现象的特点**：结果不止一个；哪一个结果出现，人们事先不知道
- **确定性现象**：只有一个结果的现象称为**确定性现象** 
- **随机试验**：对再相同条件下可以重复的随机现象的观察、记录、实验称为**随机试验** 
	- 也有很多随机现象是不能重复的
	- 概率论与数理统计主要研究能大量重复的随机现象，但也十分注意研究不能重复的随机现象
- **样本空间**、**样本点**：随机现象的一切可能基本结果组成的结合称为**样本空间**，记为 $\Omega = \{\omega\}$，其中 $\omega$ 表示基本结果，又称为**样本点** 
	- 样本点是今后抽样的最基本单元
	- 认识随机现象首先要列出它的样本空间
- **样本空间注意事项** 
	- 样本空间中的元素可以是数，也可以不是数
	- 随机现象的样本空间至少有两个样本点。如果将确定性现象放在一起考虑，则含有一个样本点的样本空间对应的为确定性现象
	- 从样本空间含样本点的个数来区分，样本空间可分为有限与无限两类
- **离散样本空间**、**连续样本空间**：我们将样本点的个数为有限个或可列的情况归为一类，称为**离散样本空间**；而将样本点的个数为不可列无限个的情况归为另一类，称为**连续样本空间** 
### 1-1-2 随机事件、随机变量
- **随机事件**（**事件**）：随机现象的某些样本点组成的集合称为**随机事件**，简称**事件**，常用大写字母 $A,B,C,\cdots$ 表示
	- 随机事件是样本空间中的子集
	- 事件可以用集合表示，也可以用明白无误的语言描述
- **维恩图**（**Venn 图**）：再概率论中常用一个长方形表示样本空间 $\Omega$，用其中一个圆或其他几何图形表示事件 $A,B,C,\cdots$，这类图形称为**维恩图**（**Venn 图**）
- **发生了**：当子集 $A$ 中某个样本点出现了，就说事件 $A$ **发生了**，或者说**事件 $A$ 发生当且仅当 $A$ 中某个样本点出现了** 
- **基本事件**、**必然事件**、**不可能事件**：由样本空间 $\Omega$ 中的单个元素组成的子集称为**基本事件**；而样本空间 $\Omega$ 的最大自己（即 $\Omega$ 本身）称为**必然事件**；样本空间 $\Omega$ 的最小子集（即空集 $\varnothing$）称为**不可能事件** 
- **随机变量**：用来表示随机现象结果的变量称为**随机变量**，常用大写字母 $X,Y,Z$ 表示
	- 很多事件都可以用随机变量表示，表示时应写明随机变量的含义，而随机变量的含义是人们按需要设置出来的。
### 1-1-3 事件间的关系
对于同一个样本空间 $\Omega$（即同一个随机现象）来讨论事件之间的关系
- **包含关系**：如果属于 $A$ 的样本点必属于 $B$，则称 **$A$ 被包含在 $B$ 中**，或称 **$B$ 包含 $A$**，记为 $A\subset B$ 或 $B\supset A$ 
	- **概率论的语言**：$B$ 包含 $A$ 就是说事件 $A$ 发生必然导致事件 $B$ 发生
	- **性质**：任一事件 $A$，必有 $\varnothing \subset A \subset \Omega$ 
- **相等关系**：如果事件 $A,B$ 满足属于 $A$ 的样本点必属于 $B$，且属于 $B$ 的样本点必属于 $A$（即 $A\subset B$ 且 $B\subset A$），则称事件 $A$ 与 $B$ 相等，记为 $A=B$ 
	- **集合论观点**：两个事件相等意味着这两事件是同一个集合
	- **注意**：有时不同语言描述的事件也可能是同一事件。如“最后摸出的几个球全是黑球”和“最后摸出的一个球是黑球”
- **互不相容**：如果 $A$ 与 $B$ 没有相同的样本点，就称 **$A$ 与 $B$ 互不相容** 
	- **概率论的语言**：$A$ 与 $B$ 互不相容就是事件 $A$ 与事件 $B$ 不可能同时发生
### 1-1-4 事件间的运算
- **事件 $A$ 与 $B$ 的并**：记为 $A\cup B$，其含义为“由事件 $A$ 与 $B$ 中所有的样本点（相同的只计入一次）组成的新事件”
	- **概率论语言**：$A\cup B$ 发生就是事件 $A$ 与 $B$ 中至少有一个发生
- **事件 $A$ 与 $B$ 的交**：记为 $A\cap B$，或简记为 $AB$，其含义为“由事件 $A$ 与 $B$ 中公共的样本点组成的新事件”
	- **概率论语言**：$A\cap B$ 发生就是事件 $A$ 与 $B$ 同时发生
	- **性质**：$AB=\varnothing$ $\iff$ $A,B$ 是互不相容事件
- **有限并**、**可列并**、**有限交**、**可列交**：事件的并与交运算可推广到有限个或可列个事件，比如有事件 $A_1, A_2, \cdots$，则 $\bigcup\limits_{i=1}^n A_i$ 称为**有限并**，$\bigcup\limits_{i=1}^\infty A_i$ 称为**可列并**，$\bigcap\limits_{i=1}^n A_i$ 称为**有限交**，$\bigcap\limits_{i=1}^\infty A_i$ 称为**可列交** 
- **事件 $A$ 对 $B$ 的差**：记为 $A-B$，其含义为“由在事件 $A$ 中而不在 $B$ 中的样本点组成的新事件”
	- **概率论语言**：$A-B$ 发生就是事件 $A$ 发生而 $B$ 不发生
- **对立事件**：事件 $A$ 的**对立事件**记为 $\overline A$，其含义为“由在 $\Omega$ 中而不在 $A$ 中的样本点组成的新事件”
	- **概率论语言**：$\overline A$ 发生就是 $A$ 不发生，即 $\overline A = \Omega - A$ 
	- **性质**：对立事件是相互的，即 $\overline{\overline A} = A$ 
	- **性质**：必然事件 $\Omega$ 与不可能事件 $\varnothing$ 互为对立事件，即 $\overline \Omega = \varnothing,\ \overline \varnothing = \Omega$ 
	- **性质**：$A-B = A\overline B$ 
	- **性质**：$A$ 与 $B$ 互为对立事件 $\iff$ $A\cap B = \varnothing$ 且 $A\cup B = \Omega$ 
	- **另一种定义**：如果事件 $A,B$ 满足 $A\cap B = \varnothing$ 且 $A\cup B = \Omega$，则称 $A$ 与 $B$ 互为**对立事件**，记为 $\overline A = B, \overline B = A$ 
- **注意点**：对立事件一定是互不相容的事件（即 $A\cap \overline A = \varnothing$）但互不相容的事件不一定是对立事件
- **例子**：设 $A,B,C$ 是某个随机现象的三个事件，则：
	- “$A,B$ 发生，$C$ 不发生”可表示为：$AB\overline C = AB-C$ 
	- “$A,B,C$ 至少有一个发生”可表示为：$A\cup B\cup C$ 
	- “$A,B,C$ 至少有两个发生”可表示为：$AB \cup AC \cup BC$ 
	- “$A,B,C$ 恰好有两个发生”可表示为：$AB\overline C \cup A\overline BC \cup \overline ABC$ 
	- “$A,B,C$ 同时发生”可表示为：$ABC$ 
	- “$A,B,C$ 都不发生”可表示为：$\overline A \overline B \overline C$ 
	- “$A,B,C$ 不全发生”可表示为：$\overline A \cup \overline B \cup \overline C$ 
- **事件的运算性质** 
	- **交换律**：$A\cup B = B\cup A,\ AB=BA$ 
	- **结合律**：$(A\cup B)\cup C = A \cup (B\cup C),\ (AB)C = A(BC)$ 
	- **分配律**：$(A\cup B)\cap C = AC \cup BC,\ (A\cap B)\cup C = (A\cup C) \cap (B\cup C)$ 
	- **对偶律**（**德摩根公式**）：$\overline{A\cup B} = \overline A \cap \overline B,\ \overline{A\cap B} = \overline A \cup \overline B$ 
		- **推广**：$\begin{aligned} \overline{\bigcup\limits_{i=1}^nA_i} = \bigcap\limits_{i=1}^n \overline A_i,\ \overline{\bigcup\limits_{i=1}^\infty A_i} = \bigcap\limits_{i=1}^\infty \overline A_i \\ \overline{\bigcap\limits_{i=1}^nA_i} = \bigcup\limits_{i=1}^n \overline A_i,\ \overline{\bigcap\limits_{i=1}^\infty A_i} = \bigcup\limits_{i=1}^\infty \overline A_i \end{aligned}$ 
- **并与对立是最基本的运算**：交的运算可以通过并与对立来实现（德摩根公式），差的运算可以通过对立与交来实现（$A-B=A\overline B$），故并与对立是最基本的运算
### 1-1-5 事件域
- **事件域**（**$\sigma$ 域**、**$\sigma$ 代数**）：设 $\Omega$ 为一样本空间，$\mathscr F$ 为 $\Omega$ 的某些子集所组合的集合类。如果 $\mathscr F$ 满足：
	(1) $\Omega \in \mathscr F$ 
	(2) 若 $A\in \mathscr F$，则对立事件 $\overline A \in \mathscr F$ 
	(3) 若 $A_n \in \mathscr F,\ (n=1,2,\cdots)$，则可列并 $\bigcup\limits_{n=1}^\infty A_n \in \mathscr F$ 
	则称 $\mathscr F$ 为一个**事件域**，又称为 **$\sigma$ 域**或 **$\sigma$ 代数**。在概率论中，又称 $(\Omega, \mathscr F)$ 为**可测空间**（在可测空间上才可定义概率，此时 $\mathscr F$ 中都是有概率可言的事件
- **常见的事件域** 
	- 若样本空间含有 $n$ 个样本点 $\Omega = \{ \omega_1, \omega_2, \cdots, \omega_n \}$，则其事件域 $\mathscr F$ 是由空集 $\varnothing$、$n$ 个单元素集、$\dbinom n2$ 个双元素集、$\dbinom n3$ 个三元素集……和 $\Omega$ 组成的集合类，此时 $\mathscr F$ 中共有 $2^n$ 个事件
	- 若样本空间含有可列个样本点 $\Omega = \{ \omega_1, \omega_2, \cdots, \omega_n, \cdots \}$，则其事件域 $\mathscr F$ 是由空集 $\varnothing$、可列个单元素集、可列个双元素集……可列个 $n$ 元素集……和 $\Omega$ 组成的集合类，此时 $\mathscr F$ 由可列个的可列个（仍为可列个）元素（事件）组成
- **博雷尔(Borel)事件域**：若样本空间中含有全体实数 $\Omega = (-\infty, +\infty) = \mathbb R$，此时事件域 $\mathscr F$ 中的元素无法一一列出，而是由一个基本集合类逐步扩展形成，具体操作如下：
	(1) 取基本集合类 $\mathscr P$ 为“全体半直线组成的类”，即 $\mathscr P = \{ (-\infty, x) \mid -\infty < x < \infty \}$ 
	(2) 利用事件域的要求，首先把有限的左闭右开区间扩展进来：$[a,b) = (-\infty, b) - (-\infty, a)$，其中 $a,b$ 为任意实数
	(3) 再把闭区间、单点集、左开右闭区间、开区间扩展进来：$\begin{matrix} [a,b] = \bigcap\limits_{n=1}^\infty \left[ a, b + \dfrac 1n \right) \\ \{b\} = [a,b] - [a,b) \\ (a,b] = [a,b] - \{a\} \\ (a,b) = [a,b) - \{a\} \end{matrix}$ 
	(4) 最后用（有限个或可列个）并运算和交运算把实数集中一切有限集、可列集、开集、闭集都扩展进来
	经过上述几步扩展所得之集的全体满足事件域的定义，这样的事件域 $\mathscr F$ 又称为**博雷尔(Borel)事件域**，域中每个元素（集合）又称为**博雷尔集**，或称为**可测集**，这种可测集都是有概率可言的事件
- **样本空间的分割**：对样本空间 $\Omega$，如果有 $n$ 个事件 $D_1,D_2,\cdots,D_n$ 满足诸 $D_i$ 互不相容且 $\bigcup\limits_{i=1}^n D_i = \Omega$，则称 $D_1,D_2,\cdots,D_n$ 为样本空间 $\Omega$ 的一组**分割**，记为 $\mathscr D = \{D_1, D_2, \cdots, D_n\}$ 
	- 也可以是可列个互不相容的事件 $D_1, D_2, \cdots,D_n,\cdots$ 组成 $\Omega$ 的一个分割
- **由分割 $\mathscr D$ 产生的事件域 $\sigma(\mathscr D)$**：对样本空间做一个分割 $\mathscr D = \{D_1, D_2, \cdots\}$，这时人们的研究只要限制在由分割 $\mathscr D = \{D_1, D_2, \cdots\}$ 中一切可能的并及空集 $\varnothing$ 组成的事件域上，因此该事件域称为由**分割 $\mathscr D$ 产生的事件域**，记为 $\sigma(\mathscr D)$ 
	- 一般场合，若分割 $\mathscr D = \{D_1, D_2, \cdots, D_n\}$ 由 $n$ 个事件组成，则其产生的事件域 $\sigma(\mathscr D)$ 共含有 $2^n$ 个不同的事件

## 1-2 概率的定义及其确定方法
### 1-2-1 概率的公理化定义
- **概率的公理化定义**、**概率空间**：设 $\Omega$ 为一个样本空间，$\mathscr F$ 为 $\Omega$ 的某些子集组成的一个事件域。如果对任一事件 $A \in \mathscr F$，定义在 $\mathscr F$ 上的一个实值函数 $P(A)$ 满足：
	(1) **非负性公理**：若 $A \in \mathscr F$，则 $P(A) \ge 0$ 
	(2) **正则性公理**：$P(\Omega) = 1$ 
	(3) **可列可加性公理**：若 $A_1, A_2, \cdots, A_n, \cdots$ 互不相容，则 $P\left( \bigcup\limits_{i=1}^\infty A_i \right) = \sum\limits_{i=1}^\infty P(A_i)$ 
	则称 $P(A)$ 为事件 $A$ 的**概率**，称三元素 $(\Omega, \mathscr F, P)$ 为**概率空间** 
- 概率的公理化定义刻画了**概率的本质**：概率是集合（事件）的函数
	- 若在事件域 $\mathscr F$ 上给出一个函数，当这个函数能满足上述三条公理，就被称为概率；当这个函数不能满足上述三条公理中任一条，就被认为不是概率。
### 1-2-2 排列与组合公式
- **乘法原理**：如果某件事需经 $k$ 个步骤才能完成，做第一步有 $m_1$ 种方法，做第二步有 $m_2$ 种方法，……，做第 $k$ 步有 $m_k$ 种方法，那么完成这件事共有 $\prod\limits_{i=1}^k m_i$ 种方法
- **加法原理**：如果某件事可由 $k$ 类不同途径之一去完成，在第一类途径中有 $m_1$ 种完成方法，在第二类途径中有 $m_2$ 种完成方法，……，在第 $k$ 类途径中有 $m_k$ 种完成方法，那么完成这件事共有 $\sum\limits_{i=1}^k m_i$ 种方法
- **排列**：从 $n$ 个不同元素种任取 $r\ (r\le n)$ 个元素排成一列（考虑元素先后出现次序），称此为一个**排列**，此种排列的总数记为 $P_n^r$，按乘法原理此种组合的总数为 $P_n^r = \dfrac{n!}{(n-r)!}$ 
	- **全排列**：若 $r=n$，则称为**全排列**，记为 $P_n$。显然全排列 $P_n = n!$ 
- **重复排列**：从 $n$ 个不同元素中每次取出一个，放回后再取下一个，如此连续取 $r$ 次所得的排列称为**重复排列**，此种重复排列共有 $n^r$ 个（注意这里 $r$ 允许大于 $n$）
- **组合**：从 $n$ 个不同元素中任取 $r\ (r\le n)$ 个元素并成一组（不考虑元素间的先后次序），称此为一个**组合**，此种组合的总数记为 $\dbinom nr$ 或 $C_n^r$，按乘法原理此种组合的总数为 $\dbinom nr = \dfrac{n!}{r!(n-r)!}$ 
	- **规定**：$0!=1,\ \dbinom n0 = 1$ 
	- **性质**：$\dbinom nr = \dbinom n{n-r}$ 
- **重复组合**：从 $n$ 个不同元素中每次取出一个，放回后再取下一个，如此连续取 $r$ 次所得的组合称为**重复组合**，此种重复组合总数为 $\dbinom{n+r-1}r$（注意这里 $r$ 允许大于 $n$）
	- *证明过程* 
		将此 $n$ 个元素画成 $n$ 个盒子（用 $n+1$ 条竖线表示），如果第 $i$ 个元素取到过一次，则在此盒子中加一个圈
		如此，所有的 $r$ 个圈和 $n+1$ 条竖线种除了两端的那两个竖线不可以动外，共有 $n+r-1$ 个圈和竖线可随意摆放，不同摆放的方式表示不同的取法
		因此重复组合数就等于在此 $n+r-1$ 个位置上任选 $r$ 个放圈，或此 $n+r-1$ 个位置上任选 $n-1$ 个放竖线，故总数为 $\dbinom{n+r-1}r$ 
### 1-2-3 确定概率的频率方法
- **频数**、**频率**：在 $n$ 次重复试验中，记 $n(A)$ 为事件 $A$ 出现的次数，又称 $n(A)$ 为事件 $A$ 的**频数**，称 $f_n(A)= \dfrac{n(A)}{n}$ 为事件 $A$ 出现的**频率** 
- **频率的稳定值**：人们的长期实践表明随着试验重复次数 $n$ 的增加，频率 $f_n(A)$ 会稳定在某常数 $a$ 附近，我们称这个常数为**频率的稳定值** 
- 容易验证，频率满足非负性、正则性、可加性，故可以用频率的稳定值去近似获得概率
### 1-2-4 确定概率的古典方法
- 古典方法的基本思想如下：
	(1) 所涉及的随机现象只有有限个样本点，譬如为 $n$ 个
	(2) 每个样本点发生的可能性相等（称为**等可能性**）
	(3) 若事件 $A$ 含有 $k$ 个样本点，则事件 $A$ 的概率为 $P(A) = \dfrac{\text{事件 A 所含样本点的个数}}{\Omega\text{ 中所有样本点的个数}} = \dfrac kn$（容易验证这个式子确定的概率满足公理化定义）
- 古典方法是概率论发展初期确定概率的常用方法，故所得的概率又称为**古典概率** 
- 在古典方法中，求事件 $A$ 的概率归结为计算 $A$ 中含有的样本点的个数和 $\Omega$ 中含有的样本点的总数
- **概率分布**：用随机变量或文字表述分成多种情况，若每个情况的概率之和为 $1$，则称其为一个**概率分布**。若是由随笔变量 $X$ 分类的，则此分布为 $X$ 的分布。
	- 概率分布是全面地（一个不漏）、动态地描述随机变量取值的概率规律，从中可提取更多信息，研究随机现象更深层次的问题
- **抽样模型**：一批产品共有 $N$ 件，其中 $M$ 件是不合格品，$N-M$ 件是合格品。从中无放回地随机取出 $n$ 件 $(n\le N)$，试求事件 $A_m=\text{取出的 n 件产品中有 m 件不合格品}$ 的概率 $(m\le M, n-m\le N-M)$ 
	- *答案*：$P(A_m) = \dfrac{\dbinom Mm \dbinom{N-M}{n-m}}{\dbinom Nn},\ m=0,1,2,\cdots,r,\ r=\min\{n,M\}$ 
	- *证明过程* 
		先计算样本空间 $\Omega$ 中样本点的总数：从 $N$ 件产品中任取 $n$ 件，因为不讲次序，所以样本点的总数为 $\dbinom Nn$，又因为是随机抽取的，所以这 $\dbinom Nn$ 个样本点是等可能的
		根据乘法原理，易知 $A_m$ 中含有 $\dbinom Mm \dbinom {N-M}{n-m}$ 个样本点，因此 $A_m$ 的概率为：$P(A_m) = \dfrac{\dbinom Mm \dbinom{N-M}{n-m}}{\dbinom Nn},\ m=0,1,2,\cdots,r,\ r=\min\{n,M\}$ 
- **放回抽样**：一批产品共有 $N$ 件，其中 $M$ 件是不合格品，$N-M$ 件是合格品。从中有放回地随机取出 $n$ 件 $(n\le N)$，试求事件 $B_m=\text{取出的 n 件产品中有 m 件不合格品}$ 的概率 $(m\le M, n-m\le N-M)$ 
	- *答案*：$P(B_m) = \dbinom nm \left( \dfrac MN \right)^m \left( 1 - \dfrac MN \right)^{n-m},\ (m=0,1,2,\cdots,n)$ 
- **盒子模型**：设有 $n$ 个球，每个球都等可能地被放到 $N$ 个不同盒子中的任一个，每个盒子所放球数不限，则：
	(1) 指定的 $n(n\le N)$ 个盒子中各有一球的概率 $p_1 = \dfrac{n!}{N^n}$ 
	(2) 恰好有 $n(n\le N)$ 个盒子各有一球的概率 $p_2 = \dfrac{P_N^n}{N^n}$ 
- **生日问题**：$n$ 个人的生日全不相同的概率 $p_n = \dfrac{365!}{365^n(365-n)!} = \left( 1 - \dfrac{1}{365} \right) \left( 1 - \dfrac{2}{365} \right) \cdots \left( 1 - \dfrac{n-1}{365} \right)$ 
	- **注意**：当 $n$ 较小时，乘积 $\dfrac i{365} \times \dfrac j{365}$ 都可以忽略，于是有近似公式 $p_n \approx 1 - \dfrac{1+2+\cdots+(n-1)}{365} = 1 - \dfrac{n(n-1)}{730}$；当 $n$ 较大时，因为对较小的正数 $x$ 有 $\ln(1-x) = -x$，故 $\ln p_n \approx - \dfrac{1+2+\cdots+(n-1)}{365} = -\dfrac{n(n-1)}{730}$ 
	- **注意**：$n=30$ 时，$p_n \approx 0.3037$；$n=60$ 时，$p_n \approx 0.0078$。这是很让人吃惊的
### 1-2-5 确定概率的几何方法
- 确定概率的几何方法，基本思想如下：
	(1) 如果一个随机现象的样本空间 $\Omega$ 充满某个区域，其度量（长度、面积或体积等）大小可用 $S_\Omega$ 表示
	(2) 任意一点落在度量相同的子区域内（可能位置不同）是等可能的
	(3) 若事件 $A$ 为 $\Omega$ 中的某个子区域，且其度量大小可用 $S_A$ 表示，则事件 $A$ 的概率为 $P(A) = \dfrac{S_A}{S_\Omega}$，这个概率称为**几何概率**，它满足概率的公理化定义
- **会面问题**：甲乙两人约定在下午 6 时到 7 时之间在某处会面，并约定先到者应等候另一个人 20 分钟，过时即可离去，则两人能会面的概率为 $\dfrac 59$ 
- **问题**：在长度为 $a$ 的线段内任取两点将其分为三段，则它们可以构成一个三角形的概率为 $p = \dfrac 14$ 
- **比丰投针问题**：平面上画有间隔为 $d(d>0)$ 的等距平行线，向平面任意投掷一枚长为 $l(l<d)$ 的针，则针与任一平行线相交的概率 $p = \dfrac{2l}{d\pi}$ 
	- 这是一种计算圆周率 $\pi$ 的方法
- **随机模拟法**（**蒙特卡罗(Monte Carlo)法**）：设计一个随机试验，使一个事件的概率与某个未知数有关，然后通过重复试验，以频率估计概率，即可求得未知数的近似解。这种方法称为**随机模拟法**，也称为**蒙特卡罗(Monte Carlo)法** 
- **贝特朗奇论**：在一圆内任取一条弦，问其长度超过该圆内接等边三角形的边长的概率是多少？
	- **解法一**：由对称性，可只考虑某指定方向的弦，此时的概率为 $\dfrac 12$ 
	- **解法二**：由对称性，可让弦的一端点固定，让另一端点在圆周上作随机移动，此时的概率为 $\dfrac 13$ 
	- **解法三**：圆内弦的位置被其中点唯一确定，在圆内作一同心圆，半径仅为大圆半径的一半，当且仅当中点落在小圆内满足题意，此时的概率为 $\dfrac 14$ 
	- **解释**：同一问题有三种不同答案，原因在于圆内“取弦”时规定尚不够具体，不同的“等可能性假设”导致了不同的样本空间
		(1) 解法一中假定弦的中点在直径上均匀分布，直径上的点组成样本空间 $\Omega_1$ 
		(2) 解法二中假定弦的另一活动端点在圆周上均匀分布，圆周上的点组成样本空间 $\Omega_2$ 
		(3) 解法三种假定弦的中点在大圆内均匀分布，大圆内的点组成样本空间 $\Omega_3$ 
	- **总结**：在定义概率时要事先明确指出样本空间是什么
### 1-2-6 确定概率的主观方法
- **主观概率**：一个事件的概率是人们根据经验对事件发生的可能性所给出的个人信念，这样给出的概率称为**主观概率** 
	- 主观给定的概率要符合公理化的定义
## 1-3 概率的性质
### 1-3-1 概率的可加性
- **性质**：$P(\varnothing) = 0$ 
	- *证明过程* 
		由于任何事件与不可能事件之并仍是此事件本身，所以 $\Omega = \Omega \cup \varnothing \cup \varnothing \cup \cdots \cup \varnothing \cup \cdots$ 
		因为不可能事件与任何事件是互不相容的，故由可列可加性公理得 $P(\Omega) = P(\Omega) + P(\varnothing) + \cdots + P(\varnothing) + \cdots$ 
		从而由 $P(\Omega) = 1$ 得 $P(\Omega) + P(\Omega) + \cdots = 0$ 
		再由非负性公理，必有 $P(\varnothing) = 0$，证毕！
- **有限可加性**：若有限个事件 $A_1, A_2, \cdots, A_n$ 互不相容，则有 $P\left( \bigcup\limits_{i=1}^n A_i \right) = \sum\limits_{i=1}^n P(A_i)$ 
	- *证明过程* 
		对 $A_1, A_2, \cdots, A_n, \varnothing, \varnothing, \cdots$ 应用可列可加性，得
		$$
		\begin{aligned}
		& P(A_1 \cup A_2 \cup \cdots \cup A_n) \\
		=& P(A_1 \cup A_2 \cup \cdots \cup A_n \cup \varnothing \cup \varnothing \cup \cdots ) \\
		=& P(A_1) + P(A_2) + \cdots + P(A_n) + P(\varnothing) + P(\varnothing) + \cdots \\
		=& P(A_1) + P(A_2) + \cdots + P(A_n)
		\end{aligned}
		$$
		证毕！
- **性质**：对任一事件 $A$，有 $P(\overline A) = 1-P(A)$ 
	- *证明过程* 
		因为 $A$ 与 $\overline A$ 互不相容，且 $\Omega = A \cup \overline A$，所以由概率的正则性和有限可加性得 $1=P(A) + P(\overline A)$，由此得 $P(\overline A) = 1 - P(A)$ 
### 1-3-2 概率的单调性
- **性质**：若 $A\supset B$，则 $P(A-B) = P(A) - P(B)$ 
	- *证明过程* 
		因为 $A\supset B$，所以 $A = B\cup (A-B)$，$B$ 与 $A-B$ 互不相容，由有限可加性得 $P(A) = P(B) + P(A-B)$，证毕！
	- **推论**（**单调性**）：若 $A\supset B$，则 $P(A) \ge P(B)$ 
- **性质**：对任意两个事件 $A,B$，有 $P(A-B) = P(A) - P(AB)$ 
	- *证明过程* 
		因为 $A-B = A-AB$ 且 $AB \subset A$，所以 $P(A-B) = P(A-AB) = P(A) - P(AB)$ 
### 1-3-3 概率的加法公式
- **加法公式**：对任意两个事件 $A,B$，有 $P(A\cup B) = P(A) + P(B) - P(AB)$ 
	- *证明过程* 
		因为 $A\cup B = A \cup (B-AB)$ 且 $A$ 与 $B-AB$ 互不相容，所以 $P(A\cup B) = P(A) + P(B-AB) = P(A) + P(B) - P(AB)$ 
	- **推广**：对任意 $n$ 个事件 $A_1, A_2, \cdots, A_n$，有 $\displaystyle P\left( \bigcup_{i=1}^n A_i \right) = \sum_{k=1}^n (-1)^{k-1} \sum_{1 \le i_1 <\dots<i_k \le n} P(A_{i_1} \cap \dots \cap A_{i_k})$ 
- **推论**（**半可加性**）：对任意两个事件 $A,B$，有 $P(A\cup B) \le P(A) + P(B)$ 
	- **推广**：对任意 $n$ 个事件 $A_1, A_2, \cdots, A_n$，有 $\displaystyle P\left( \bigcup_{i=1}^n A_i \right) \le \sum_{i=1}^n P(A_i)$ 
- **配对问题**：在一个有 $n$ 个人参加的晚会上，每个人带了一件礼物，且假定各人带的礼物都不相同。晚会期间各人从放在一起的 $n$ 件礼物中随机抽取一件，问至少有一个人自己抽到自己礼物的概率是多少？
	- *答案*：$p = 1 - \dfrac 1{2!} + \dfrac 1{3!} - \dfrac 1{4!} + \cdots + (-1)^{n-1}\dfrac 1{n!}$ 
	- *证明过程* 
		以 $A_i\ (i=1,2,\cdots,n)$ 记事件“第 $i$ 个人自己抽到自己的礼物”。所求概率为 $P(A_1 \cup A_2 \cup \cdots \cup A_n)$，因为
		$$
		\begin{aligned}
		& P(A_1) = P(A_2) = \cdots = P(A_n) = \dfrac 1n \\
		& P(A_1A_2) = P(A_1A_3) = \cdots = P(A_{n-1}A_n) = \dfrac 1{n(n-1)} \\
		& P(A_1A_2A_3) = P(A_1A_2A_4) = \cdots = P(A_{n-2}A_{n-1}A_n) = \dfrac 1{n(n-1)(n-2)} \\
		& \cdots \\
		& P(A_1A_2\cdots A_n) = \dfrac 1{n!}
		\end{aligned}
		$$
		所以由概率的加法公式得 $P(A_1\cup A_2 \cup \cdots \cup A_n) = 1 - \dfrac 1{2!} + \dfrac 1{3!} - \dfrac 1{4!} + \cdots + (-1)^{n-1}\dfrac 1{n!}$ 
	- **注意**：当 $n\to\infty$ 时，此概率极限为 $1-\dfrac 1e = 0.6321$，这说明即使参加晚会的人很多，事件“至少有一个人自己抽到自己礼物”也不是必然事件
### 1-3-4 概率的连续性
- 单调不减的**极限事件**：对 $\mathscr F$ 中任一单调不减的事件序列 $F_1 \subset F_2 \subset \cdots \subset F_n \subset \cdots$，称可列并 $\bigcup\limits_{n=1}^\infty F_n$ 为 $\{F_n\}$ 的**极限事件**，记为 $\lim\limits_{n\to\infty} F_n = \bigcup\limits_{n=1}^\infty F_n$ 
- 单调不增的**极限事件**：对 $\mathscr F$ 中任一单调不增的事件序列 $E_1 \supset E_2 \supset \cdots \supset E_n \supset \cdots$，称可列交 $\bigcap\limits_{n=1}^\infty E_n$ 为 $\{E_n\}$ 的**极限事件**，记为 $\lim\limits_{n\to\infty} = \bigcap\limits_{n=1}^\infty E_n$ 
- **下连续**：对 $\mathscr F$ 上的一个概率 $P$，若它对 $\mathscr F$ 中任一单调不减的事件序列 $\{F_n\}$ 均成立 $\lim\limits_{n\to\infty} P(F_n) = P(\lim\limits_{n\to\infty} F_n)$，则称概率 $P$ 是**下连续**的
- **上连续**：对 $\mathscr F$ 上的一个概率 $P$，若它对 $\mathscr F$ 中任一单调不增的事件序列 $\{E_n\}$ 均成立 $\lim\limits_{n\to\infty} P(E_n) = P(\lim\limits_{n\to\infty} E_n)$，则称概率 $P$ 是**上连续**的
- **概率的连续性**：若 $P$ 为事件域 $\mathscr F$ 上的概率，则 $P$ 既是下连续的，又是上连续的。
	- *证明过程* 
		**先证 $P$ 的下连续性** 
		设 $\{F_n\}$ 是 $\mathscr F$ 中一个单调不减的事件序列，即 $\bigcup\limits_{i=1}^\infty F_i = \lim\limits_{n\to\infty} F_n$ 
		若定义 $F_0 = \varnothing$，则 $\bigcup\limits_{i=1}^\infty F_i = \bigcup\limits_{i=1}^\infty (F_i - F_{i-1})$ 
		由于 $F_{i-1}\subset F_i$，显然诸 $(F_i - F_{i-1})$ 两两不相容，再由可列可加性可知 $P\left( \bigcup\limits_{i=1}^\infty F_i \right) = \sum\limits_{i=1}^\infty P(F_i - F_{i-1}) = \lim\limits_{n\to\infty} \sum\limits_{i=1}^n P(F_i - F_{i-1})$ 
		又由有限可加性可知 $\sum\limits_{i=1}^n P(F_i - F_{i-1}) = P\left( \bigcup\limits_{i=1}^n (F_i - F_{i-1}) \right) = P(F_n)$ 
		所以 $P(\lim\limits_{n\to\infty} F_n) = \lim\limits_{n\to\infty} P(F_n)$，这就得到了 $P$ 的下连续性
		**再证 $P$ 的上连续性** 
		设 $\{E_n\}$ 是单调不增的事件序列，则 $\{\overline E_n\}$ 为单调不减的事件序列，由概率的下连续性、德摩根公式可知：
		$$
		\begin{aligned}
		1 - \lim_{n\to\infty} P(E_n) = & \lim_{n\to\infty}[1-P(E_n)] = \lim_{n\to\infty} P (\overline E_n) \\
		=& P\left( \bigcup_{n=1}^\infty \overline E_n \right) = P\left( \overline{\bigcap_{n=1}^\infty E_n} \right) \\
		=& 1 - P\left( \bigcap_{n=1}^\infty E_n \right)
		\end{aligned}
		$$
		故 $\lim\limits_{n\to\infty} P(E_n) = P\left( \bigcap\limits_{n=1}^\infty E_n \right)$，这就得到了 $P$ 的上连续性
- **性质**：若 $P$ 是 $\mathscr F$ 上满足 $P(\Omega) = 1$ 的非负集合函数，则它具有可列可加性 $\iff$ 它是有限可加的且它是下连续的
	- *证明过程* 
		必要性可通过前面的性质直接得到，下证充分性
		设 $A_i \in \mathscr F,\ (i=1,2,\cdots)$ 是两两不相容的事件序列，由有限可加性可知：对任意有限的 $n$ 都有 $P\left( \bigcup\limits_{i=1}^n A_i \right) = \sum\limits_{i=1}^n P(A_i)$ 
		这个等式的左边不超过 $1$，因此正项级数 $\sum\limits_{i=1}^\infty P(A_i)$ 收敛，即 $\lim\limits_{n\to\infty} P\left( \bigcup\limits_{i=1}^n A_i \right) = \lim\limits_{n\to\infty} \sum\limits_{i=1}^n P(A_i) = \sum\limits_{i=1}^\infty P(A_i)$ 
		记 $F_n = \bigcup\limits_{i=1}^n A_i$，则 $\{F_n\}$ 为单调不减的事件序列，所以由下连续性得 $\lim\limits_{n\to\infty} P\left( \bigcup\limits_{i=1}^n A_i \right) = \lim\limits_{n\to\infty} P(F_n) = P\left( \bigcup\limits_{n=1}^\infty F_n \right) = P\left( \bigcup\limits_{n=1}^\infty A_n \right)$，再结合 $\lim\limits_{n\to\infty} P\left( \bigcup\limits_{i=1}^n A_i \right) = \lim\limits_{n\to\infty} \sum\limits_{i=1}^n P(A_i) = \sum\limits_{i=1}^\infty P(A_i)$ 可得可列可加性
	- **推论**：在概率的公理化定义中，可以将可列可加性换成有限可加性和下连续性
