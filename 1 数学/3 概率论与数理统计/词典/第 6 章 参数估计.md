## 6-0 绪论
- 这里的参数是指下面三类未知参数
	1. 分布中所含的未知参数 $\theta$。如二点分布 $b(1,p)$ 中的概率 $p$，正态分布 $N(\mu,\sigma^2)$ 中的 $\mu$ 和 $\sigma^2$ 
	2. 分布中所含的未知参数 $\theta$ 的函数。如服从正态分布 $N(\mu,\sigma^2)$ 的变量 $X$ 不超过某给定值 $a$ 的概率 $P(X\le a) = \varPhi\left( \dfrac{a-\mu}{\sigma} \right)$ 是未知参数 $\mu,\sigma$ 的函数
	3. 分布中的各种特征数也都是未知参数。如 $E(X),\ \mathrm{Var}(X)$ 等
- **参数空间**：参数 $\theta$ 所有可能取值组成的集合称为**参数空间**，常用 $\Theta$ 表示
- 参数估计问题就是根据样本构造适当的统计量对上述各种未知参数作出估计
	- 参数估计的形式有两种：**点估计**与**区间估计** 
## 6-1 点估计的概念与无偏性
### 6-1-1 点估计及无偏性
- **点估计**（**估计**）：设 $x_1,x_2,\cdots,x_n$ 是来自总体的一个样本，用于估计未知参数 $\theta$ 的统计量 $\hat\theta = \hat\theta(x_1,x_2,\cdots,x_n)$ 称为 $\theta$ 的**估计量**，或称为 $\theta$ 的**点估计**，简称**估计** 
	- 这里如何构造统计量 $\hat\theta$ 并没有明确的规定，只要它满足一定的合理性即可
	- 最常见的合理性要求就是无偏性
- **无偏估计**、**有偏估计**：设 $\hat\theta = \hat\theta(x_1,x_2,\cdots,x_n)$ 是 $\theta$ 的一个估计，$\theta$ 的参数空间为 $\Theta$，若对任意的 $\theta\in\Theta$，有 $E_\theta(\hat\theta) = \theta$，则称 $\hat\theta$ 是 $\theta$ 的**无偏估计**，否则称为**有偏估计** 
	- 无偏性要求可以改写为 $E_\theta(\hat\theta-\theta) = 0$，这表示无偏估计没有系统偏差
	- **解释**：当我们使用 $\hat\theta$ 估计 $\theta$ 时，由于样本的随机性，$\hat\theta$ 与 $\theta$ 总是有偏差的，这种偏差时而正，时而负，时而大，时而小。无偏性表示，把这些偏差平均起来其值会为 $0$。而若估计不具有无偏性，则无论使用多少次，其平均也会与参数真值有一定的距离，这个距离就是**系统误差** 
- **渐近无偏估计**：当样本量趋于无穷时，有 $E(\hat\theta)\to\theta$，我们称 $\hat\theta$ 为 $\theta$ 的**渐近无偏估计** 
- **举例** 
	- 对任一总体，样本均值是总体均值的无偏估计
	- 当总体 $k$ 阶矩存在时，样本 $k$ 阶原点矩 $a_k$ 时总体 $k$ 阶原点矩 $\mu_k$ 的无偏估计
	- 但对 $k$ 阶中心矩不一样，如样本方差 $s_n^2$ 就不是总体方差 $\sigma^2$ 的无偏估计，而满足 $E(s_n^2) = \dfrac{n-1}n \sigma^2$ 
		- $s_n^2$ 为 $\sigma^2$ 的**渐近无偏估计**，这表明当样本量较大时，$s_n^2$ 可以近似看作 $\sigma^2$ 的无偏估计
		- 若对 $s_n^2$ 作修正 $s^2 = \dfrac{ns_n^2}{n-1} = \dfrac 1{n-1}\sum\limits_{i=1}^n(x_i-\overline x)^2$，则 $s^2$ 是总体方差的无偏估计。
		- 这种简单修正方法在一些场合被采用，$s^2$ 也称为样本方差，它比 $s_n^2$ 更常用。这是因为在 $n\ge 2$ 时 $s_n^2 < s^2$，因此用 $s_n^2$ 估计 $\sigma^2$ 有偏小的倾向，特别在小样本场合要使用 $s^2$ 估计 $\sigma^2$ 
- **无偏性不具有不变性**：即若 $\hat\theta$ 是 $\theta$ 的无偏估计，一般而言，其函数 $g(\hat\theta)$ 不是 $g(\theta)$ 的无偏估计，除非 $g(\theta)$ 是 $\theta$ 的线性函数
	- **例子**：$s^2$ 是 $\sigma^2$ 的无偏估计，但 $s$ 不是 $\sigma$ 的无偏估计
- 大偏差通常被视为估计的一种不足，有人提出了多种缩小偏差的方法
- **刀切法**（**jackknife**）
	- **概念定义** 
		设 $T(\boldsymbol x)$ 是基于样本 $\boldsymbol x = (x_1,x_2,\cdots,x_n)$ 的关于参数 $g(\theta)$ 的估计量，且满足 $E_\theta(T(\boldsymbol x)) = g(\theta) + O\left( \dfrac 1n \right)$ 
		如以 $\boldsymbol x_{(-i)}$ 表示从样本中删去 $x_i$ 后的向量，则 $T(\boldsymbol x)$ 的**刀切统计量**定义为 $T_J(\boldsymbol x) = nT(\boldsymbol x) - \dfrac{n-1}n \sum\limits_{i=1}^n T(\boldsymbol  x_{(-i)})$ 
		刀切统计量有性质 $E_\theta(T_J(\boldsymbol x)) = g(\theta) + O\left( \dfrac 1{n^2} \right)$，并且其方差不会增大
	- **例子** 
		设总体为 $b(1,\theta)$，$x_1,x_2,\cdots,x_n$ 是其样本，又设 $g(\theta) = \theta^2$，则 $T(\boldsymbol x) = \overline x^2$ 是 $g(\theta)$ 的一个估计，且 $E(T(\boldsymbol x)) = \theta^2 + \dfrac{\theta(1-\theta)}n = g(\theta) + O\left( \dfrac 1n \right)$ 
		下面应用刀切法，注意到 $T(\boldsymbol x_{(-i)}) = \left( \dfrac{\sum\limits_{j=1}^n x_j - x_i}{n-1} \right)^2 = \dfrac{n^2\overline x^2 + x_i^2 - 2nx_i\overline x}{(n-1)^2}$ 
		于是 $T_J(\boldsymbol x) = n\overline x^2 - \dfrac{n-1}n\sum\limits_{i=1}^n \dfrac{n^2\overline x^2 + x_i^2 - 2nx_i\overline x}{(n-1)^2} = \dfrac{n\overline x}{n-1} - \dfrac{\sum\limits_{i=1}^n x_i^2}{n(n-1)}$ 
		可以验证 $ET_J(\boldsymbol x) = g(\theta)$ 
- **可估的**、**不可估的**：并不是所有的参数都存在无偏估计，当参数存在无偏估计时，我们称该参数是**可估的**，否则称它是**不可估的** 
	- **例子**：设总体为二点分布 $b(1,p),\ 0<p<1$，$x_1,x_2,\cdots,x_n$ 是样本，则参数 $\theta = \dfrac 1p$ 是不可估的
### 6-1-2 有效性
- **有效**：设 $\hat\theta_1, \hat\theta_2$ 是 $\theta$ 的两个无偏估计，如果对任意的 $\theta\in \Theta$ 有 $\mathrm{Var}(\hat\theta_1) \le \mathrm{Var}(\hat\theta_2)$，且至少有一个 $\theta\in\Theta$ 是的上述不等号严格成立，则称 **$\hat\theta_1$ 比 $\hat\theta_2$ 有效** 
## 6-2 矩估计及相合性
### 6-2-1 替换原理和矩法估计
- **替换原理**（**矩法**）：1900 年 K.皮尔逊提出了一个**替换原理**，后来人们称此方法为**矩法** 
- **替换原理**常指如下两句话：
	- 用样本矩去替换总体矩，这里的矩可以是原点矩也可以是中心矩
	- 用样本矩的函数去替换相应的总体矩的函数，
- 根据这个替换原理，在总体分布形式未知场合也可对各种参数作出估计，譬如：
	- 用样本均值估计总体均值 $E(X)$ 
	- 用样本方差 $s^2$ 估计总体方差 $\mathrm{Var}(X)$ 
	- 用事件 $A$ 出现的频率估计事件 $A$ 发生的概率
	- 用样本的 $p$ 分位数估计总体的 $p$ 分位数，特别，用样本中位数估计总体中位数
- 矩法估计的统计思想（替换原理）十分简单明确，众人都能接受，使用场合甚广
- **替换原理的实质**：用经验分布函数去替换总体分布，其理论基础是格利文科定理，
### 6-2-2 概率函数已知时未知参数的矩估计
- 设总体具有已知的概率函数 $p(x;\theta_1,\theta_2,\cdots,\theta_k),\ (\theta_1,\theta_2,\cdots,\theta_k)\in\Theta$ 是未知参数或参数向量，$x_1,x_2,\cdots,x_n$ 是样本，假定总体的 $k$ 阶原点矩 $\mu_k$ 存在，则对所有的 $j\ (0<j<k)$，$\mu_j$ 都存在，若假设 $\theta_1,\theta_2,\cdots,\theta_k$ 能够表示成 $\mu_1,\mu_2,\cdots,\mu_k$ 的函数 $\theta_j = \theta_j(\mu_1,\mu_2,\cdots,\mu_k$)，则可给出诸 $\theta_j$ 的矩估计 $\hat\theta_j = \theta_j(a_1,a_2,\cdots,a_k),\ j=1,2,\cdots,k$，其中 $a_1,a_2,\cdots,a_k$ 是前 $k$ 阶样本原点矩 $a_j = \dfrac 1n \sum\limits_{i=1}^n x_i^j$ 
- 进一步，如果我们要估计 $\theta_1,\theta_2,\cdots,\theta_k$ 的函数 $\eta = g(\theta_1,\theta_2,\cdots,\theta_k)$，则可直接得到 $\eta$ 的矩估计 $\hat\eta = g(\hat\theta_1,\hat\theta_2,\cdots,\hat\theta_k)$ 
- 当 $k=1$ 时，我们通常可以由样本均值出发对未知参数进行估计
- 当 $k=2$ 时，我们可以由一阶、二阶原点矩（或二阶中心矩）出发估计未知参数
### 6-2-3 相合性
- **相合估计**：设 $\theta\in\Theta$ 为未知参数，$\hat\theta_n = \hat\theta_n(x_1,x_2,\cdots,x_n)$ 是 $\theta$ 的一个估计量，$n$ 是样本容量，若对任何一个 $\varepsilon>0$，都有 $\lim\limits_{n\to\infty} P(|\hat\theta_n - \theta|\ge \varepsilon)=0$，则称 $\hat\theta_n$ 为参数 $\theta$ 的**相合估计** 
	- **相合性被认为是对估计的一个最基本要求**，如果一个估计量在样本量不断增大时，它都不能把估参数估计到任意指定的精度，那么这个估计是很值得怀疑的
	- 通常，不满足相合性要求的估计不予考虑
	- 若把依赖于样本量 $n$ 的估计量 $\hat\theta_n$ 看作一个随机变量序列，相合性就是 $\hat\theta_n$ 依概率收敛于 $\theta$，所以证明估计的相合性可应用依概率收敛的性质及各种大数定律
	- 参数的相合估计不止一个
- **例子**：设 $x_1,x_2,\cdots$ 是来自正态总体 $N(\mu,\sigma^2)$ 的样本序列，则 $\overline x$ 是 $\mu$ 的相合估计，$s_n^2, s^2$ 是 $\sigma^2$ 的相合估计
- **定理**：设 $\hat\theta_n = \hat\theta_n(x_1,x_2,\cdots,x_n)$ 是 $\theta$ 的一个估计量，若 $\lim\limits_{n\to\infty} E(\hat\theta_n) = \theta,\ \lim\limits_{n\to\infty}\mathrm{Var}(\hat\theta_n) = 0$，则 $\hat\theta_n$ 是 $\theta$ 的相合估计
	- *证明过程* 
		对任意的 $\varepsilon>0$，由切比雪夫不等式有 $P\left( |\hat\theta_n - E(\hat\theta_n)| \ge \dfrac \varepsilon 2 \right) \le \dfrac 4{\varepsilon^2}\mathrm{Var}(\hat\theta_n)$ 
		另一方面，由 $\lim\limits_{n\to\infty} E(\hat\theta_n) = \theta$ 可知，当 $n$ 充分大时有 $|E(\hat\theta_n) - \theta| < \dfrac\varepsilon 2$ 
		注意到此时如果 $|\hat\theta_n-E(\hat\theta_n)| < \dfrac \varepsilon2$，就有 $|\hat\theta_n - \theta| \le |\hat\theta_n - E(\hat\theta_n)| + |E(\hat\theta_n) - \theta| < \varepsilon$ 
		故 $\left\{ |\hat\theta_n - E(\hat\theta_n)| < \dfrac \varepsilon 2 \right\} \subset \{ |\hat\theta_n - \theta|<\varepsilon \}$，等价地，$\left\{ |\hat\theta_n - E(\hat\theta_n)| \ge \dfrac \varepsilon 2 \right\} \supset \{ |\hat\theta_n - \theta|\ge \varepsilon \}$ 
		由此即有 $P(|\hat\theta_n - \theta|\ge \varepsilon)\le P\left( |\hat\theta_n - E(\hat\theta_n)|\ge \dfrac \varepsilon 2 \right) \le \dfrac 4{\varepsilon^2}\mathrm{Var}(\hat\theta_n)\to 0\ (n\to\infty)$ 
		证毕！
- **定理**：若 $\hat\theta_{n1}, \hat\theta_{n2}, \cdots, \hat\theta_{nk}$ 分别是 $\theta_1,\theta_2,\cdots,\theta_k$ 的相合分布，$\eta = g(\theta_1,\theta_2,\cdots,\theta_k)$ 是 $\theta_1,\theta_2,\cdots,\theta_k$ 的连续函数，则 $\hat\eta_n = g(\hat\theta_{n1}, \hat\theta_{n2}, \cdots, \hat\theta_{nk})$ 是 $\eta$ 的相合分布
	- *证明过程* 
		由函数 $g$ 的连续性，对任意给定的 $\varepsilon>0$，存在一个 $\delta>0$，当 $|\theta_{nj} - \theta_j| < \delta,\ j=1,2,\cdots,k$ 时，有 $|g(\hat\theta_{n1}, \hat\theta_{n2}, \cdots, \hat\theta_{nk}) - g(\theta_1,\theta_2,\cdots,\theta_k)|<\varepsilon$ 
		又由 $\hat\theta_{n1}, \hat\theta_{n2}, \cdots, \hat\theta_{nk}$ 的相合性，对给定的 $\delta>0$，对任意给定的 $v>0$，存在正整数 $N$，使得 $n\ge N$ 时，$P(|\hat\theta_{nj} - \theta_j|\ge \delta) < \dfrac vk,\ j=1,2,\cdots,k$，从而有
		$$
		\begin{aligned}
		P\left( \bigcap\limits_{j=1}^k \{ |\hat\theta_{nj} - \theta_j| < \delta \} \right) = & 1 - P \left( \bigcup\limits_{j=1}^k \{ | \hat\theta_{nj} - \theta_j | \ge \delta \} \right) \\
		\ge & 1 - \sum_{j=1}^k P(|\hat\theta_{nj} - \theta_j|\ge \delta) \\
		> & 1 - k\cdot \dfrac vk = 1 - v
		\end{aligned}
		$$
		根据 $|g(\hat\theta_{n1}, \hat\theta_{n2}, \cdots, \hat\theta_{nk}) - g(\theta_1,\theta_2,\cdots,\theta_k)|<\varepsilon$，$\bigcap\limits_{j=1}^k \{ |\hat\theta_{nj} - \theta_j| < \delta \} \subset \{ | \hat\eta_n - \eta | < \varepsilon \}$，故有 $P(|\hat\eta_n - \eta|<\varepsilon)>1-v$ 
		由 $v$ 的任意性，定理得证
- 矩估计一般都具有相合性
	- 样本均值是总体均值的相合估计
	- 样本标准差是总体标准差的相合估计
	- 样本变异系数 $\dfrac s{\overline x}$ 是总体变异系数的相合估计
## 6-3 最大似然估计（MLE）与 EM 算法
### 6-3-1 最大似然估计
- **似然函数**、**最大似然估计**（**MLE**）：设总体的概率函数为 $p(x;\theta),\ \theta\in\Theta$，其中 $\theta$ 是一个未知函数或几个未知参数组成的参数向量，$\Theta$ 是参数空间，$x_1,x_2,\cdots,x_n$ 是来自该总体的样本，将样本的联合概率函数看成 $\theta$ 的函数，用 $L(\theta;x_1,x_2,\cdots,x_n)$ 表示，简记为 $L(\theta)$，$L(\theta) = L(\theta;x_1,x_2,\cdots,x_n) = p(x_1;\theta)p(x_2;\theta)\cdots p(x_n;\theta)$，$L(\theta)$ 称为样本的**似然函数**。如果某统计量 $\hat\theta = \hat\theta(x_1,x_2,\cdots,x_n)$ 满足 $L(\hat\theta) = \max\limits_{\theta\in\Theta} L(\theta)$，则称 $\hat\theta$ 是 $\theta$ 的**最大似然估计**，简记为 **MLE**（**maximum likelihood estimate**）
	- 由于 $\ln x$ 是 $x$ 的单调增函数，因此，使对数似然函数 $\ln L(\theta)$ 达到最大与使 $L(\theta)$ 达到最大是等价的
	- 人们通常更习惯于由 $\ln L(\theta)$ 出发寻找 $\theta$ 的最大似然估计
	- 当 $L(\theta)$ 是可微函数时，求导是求最大似然估计最常用的方法，此时对对数似然函数求导更加简单些
	- **注意**：若 $L(\theta)$ 与联合概率函数相差一个与 $\theta$ 无关的比例因子，不会影响最大似然估计。因此，可以在 $L(\theta)$ 中剔去与 $\theta$ 无关的因子
- **最大似然估计的不变性**：如果 $\hat\theta$ 是 $\theta$ 的最大似然估计，则对任一函数 $g(\theta)$，$g(\hat\theta)$ 是其最大似然估计
### 6-3-2 EM 算法
- MLE 是一种非常有效的参数估计方法，但当分布中有多余参数或数据为截尾或缺失时，其 MLE 的求取是比较困难的
- Dempster 等人于1977年提出了 EM 算法，其出发点是把求 MLE 的过程分两步走，第一步求期望，以便把多余的部分去掉，第二步求极大值
- EM 算法中的 E 步和 M 步可以表述如下
	- **E 步**：在已有观测数据 $x_1,x_2,\cdots,x_n$ 及第 $t$ 步估计值 $\theta = \theta^{(t)}$ 的条件下，求基于完全数据的对数似然函数的期望（即把其中与隐变量有关的部分积分掉）：$Q(\theta \mid x_1,\cdots,x_n, \theta^{(t)}) = E_Z[\ln L(\theta; x_1,\cdots,x_n, Z)]$，其中 $Z$ 表示隐变量，$\ln L(\theta; x_1,\cdots,x_n, Z)$ 是基于完全数据的对数似然函数。
	- **M 步**：求 $Q(\theta \mid x_1,\cdots,x_n, \theta^{(t)})$ 关于 $\theta$ 的最大值 $\theta^{(t+1)}$，即找 $\theta^{(t+1)}$ 使得 $Q(\theta^{(t+1)} \mid x_1,\cdots,x_n, \theta^{(t)}) = \max\limits_{\theta \in \Theta} Q(\theta \mid x_1,\cdots,x_n, \theta^{(t)})$ 
- 在很一般的条件下，EM 算法是收敛的
### 6-3-3 渐近正态性
- **渐近正态分布**、**渐近方差**：参数 $\theta$ 的相合估计 $\hat\theta_n$ 称为渐近正态的，若存在趋于 $0$ 的非负常数序列 $\sigma_n(\theta)$ 使得 $\dfrac{\hat\theta_n - \theta}{\sigma_n(\theta)}$ 依分布收敛于标准正态分布。这时也称 $\hat\theta_n$ 服从**渐近正态分布** $N(\theta,\sigma_n^2(\theta))$，记为 $\hat\theta_n\sim AN(\theta, \sigma_n^2(\theta))$。$\sigma_n^2(\theta)$ 称为 $\hat\theta_n$ 的**渐近方差** 
	- 最大似然估计通常具有渐近正态性
	- $\sigma_n(\theta)$ 表示着估计量 $\hat\theta_n$ 以概率收敛于 $\theta$ 的速度。因为只有当“$\sigma_n(\theta)$ 趋于 $0$ 的速度”与“$\hat\theta_n$ 依概率收敛于 $\theta$ 的速度”相当（即同阶），其比值 $\dfrac{\hat\theta_n - \theta}{\sigma_n(\theta)}$ 的分布才可能稳定地收敛于标准正态分布 $N(0,1)$ 
	- 大多数渐近正态估计都是以 $\dfrac 1{\sqrt n}$ 的速度依概率收敛于被估参数
- **定理**：设总体 $X$ 有密度函数 $p(x;\theta),\ \theta\in\Theta$，$\Theta$ 为非退化区间，假定
	(1) 对任意的 $x$，偏导数 $\dfrac{\partial\ln p}{\partial\theta},\ \dfrac{\partial^2\ln p}{\partial\theta^2},\ \dfrac{\partial^3\ln p}{\partial\theta^3}$ 对所有 $\theta\in\Theta$ 都存在
	(2) $\forall\ \theta\in\Theta$，有 $\left| \dfrac{\partial p}{\partial\theta} \right| < F_1(x),\ \left| \dfrac{\partial^2p}{\partial\theta^2} \right| < F_2(x),\ \left| \dfrac{\partial^3\ln p}{\partial\theta^3} < F_3(x) \right|$，其中函数 $F_1(x), F_2(x), F_3(x)$ 满足 $\displaystyle \int_{-\infty}^\infty F_1(x)\mathrm dx < \infty$，$\displaystyle\int_{-\infty}^\infty F_2(x)\mathrm dx < \infty$，$\displaystyle\sup_{\theta\in\Theta}\int_{-\infty}^\infty F_3(x)p(x;\theta)\mathrm dx<\infty$ 
	(3) $\forall\ \theta\in\Theta$，有 $\displaystyle 0<I(\theta)\equiv \int_{-\infty}^\infty \left( \dfrac{\partial\ln p}{\partial\theta} \right)^2 p(x;\theta)\mathrm dx < \infty$ 
	若 $x_1,x_2,\cdots,x_n$ 是来自该总体的样本则存在未知参数 $\theta$ 的最大似然估计 $\hat\theta_n = \hat\theta_n(x_1,x_2,\cdots,x_n)$，且 $\hat\theta_n$ 具有相合性和渐近正态性，$\hat\theta_n \sim AN\left(\theta, \dfrac 1{nI(\theta)} \right)$ 
	- 该定理表明：最大似然估计通常是渐近正态的，且其渐近方差 $\sigma_n^2(\theta) = (nI(\theta))^{-1}$ 有一个统一的形式，其中 $I(\theta)$ 称为**费希尔信息量** 
- 在有多个相合估计时，常用其渐近正态分布的方差比较好坏
## 6-4 最小方差无偏估计
### 6-4-1 均方误差
- **大样本场合下评价估计好坏的重要标准**：相合性、渐近正态性
- **小样本场合下评价估计好坏的重要标准**：对无偏估计常使用方差，对有偏估计常使用均方误差
- **均方误差**：一般而言，在样本量一定时，评价一个点估计的好坏使用的度量指标总是点估计值 $\hat\theta$ 与参数真值 $\theta$ 的距离的函数，最常用的函数是距离的平方。由于 $\hat\theta$ 具有随机性，可以对该函数求期望，故定义**均方误差**为 $\mathrm{MSE}(\hat\theta) = E(\hat\theta - \theta)^2$ 
	- 均方误差是评价点估计的最一般的标准
	- 我们希望估计的均方误差越小越好
- **性质**：$\mathrm{MSE}(\hat\theta) = \mathrm{Var}(\hat\theta) + (E(\hat\theta) - \theta)^2$ 
	- *证明过程* 
		$$
		\begin{aligned}
		\mathrm{MSE}(\hat\theta) &= E[(\hat\theta - E(\hat\theta)) + (E(\hat\theta) - \theta)]^2 \\ 
		&= E(\hat\theta - E(\hat\theta))^2 + (E(\hat\theta) - \theta)^2 + 2E[(\hat\theta - E(\hat\theta))(E(\hat\theta) - \theta)] \\
		&= \mathrm{Var}(\hat\theta) + (E(\hat\theta) - \theta)^2
		\end{aligned}
		$$
	- 均方误差由点估计的方差与偏差 $|E(\hat\theta) - \theta|$ 的平方两部分组成
	- 如果 $\hat\theta$ 是 $\theta$ 的无偏估计，则 $\mathrm{MSE}(\hat\theta) = \mathrm{Var}(\hat\theta)$，此时用均方误差评价点估计与用方差是完全一样的
	- 如果 $\hat\theta$ 不是 $\theta$ 的无偏估计，就要看其均值误差 $\mathrm{MSE}(\hat\theta)$，即不仅要看其方差大小，还要看其偏差大小
	- 在均方误差的含义下，有些有偏估计优于无偏估计
- **一致最小均方误差估计**：设有样本 $x_1,x_2,\cdots,x_n$，对待估参数 $\theta$，设有一个估计类，称 $\hat\theta(x_1,x_2,\cdots,x_n)$ 是该估计类中 $\theta$ 的**一致最小均方误差估计**，如果对该估计类中另外任意一个 $\theta$ 的估计 $\tilde\theta$，在参数空间 $\Theta$ 上都有 $\mathrm{MSE}_\theta(\hat\theta) \le \mathrm{MSE}_\theta(\tilde\theta)$ 
	- 一致最小均方误差估计通常是在一个确定的估计类中进行的
	- 若 $\hat\theta$ 是 $\theta$ 的所有估计中的一致最小均方误差估计，取定任一个 $\theta_0\in\Theta$，令 $\tilde\theta \equiv \theta_0$，它是 $\theta$ 的一个有特别倾向的估计，且 $\mathrm{MSE}_{\theta_0}(\tilde\theta) = 0$，于是要求一致最小均方误差估计 $\hat\theta$ 在 $\theta_0$ 处也有 $\mathrm{MSE}_{\theta_0}(\hat\theta) = 0$，由 $\theta_0$ 的任意性，这意味着 $\mathrm{MSE}_\theta(\hat\theta)$ 处处为 $0$，这显然是做不到的
- 既然一致最小均方误差估计一般都不存在，则需对估计提一些合理性要求，如无偏性等
### 6-4-2 一致最小方差无偏估计
- **一致最小方差无偏估计**：对参数估计问题，设 $\hat\theta$ 是 $\theta$ 的一个无偏估计，如果对另外任意一个 $\theta$ 无偏估计 $\tilde\theta$，在参数空间 $\Theta$ 上都有 $\mathrm{Var}_\theta(\hat\theta) \le \mathrm{Var}_\theta(\tilde\theta)$，则称 $\hat\theta$ 是 $\theta$ 的**一致最小方差无偏估计**，简记为 $\mathrm{UMVUE}$ 
- **定理**：设 $\boldsymbol X = (x_1,x_2,\cdots,x_n)$ 是来自某总体的一个样本，$\hat\theta = \hat\theta(\boldsymbol X)$ 是 $\theta$ 的一个无偏估计，$\mathrm{Var}(\hat\theta) < \infty$，则 $\hat\theta$ 是 $\theta$ 的 $\mathrm{UMVUE}$ $\iff$ 对任意一个满足 $E(\varphi(\boldsymbol X)) = 0$ 和 $\mathrm{Var}(\varphi(\boldsymbol X)) < \infty$ 的 $\varphi(\boldsymbol X)$，都有 $\mathrm{Cov}_\theta(\hat\theta,\varphi) = 0,\ \forall\ \theta\in\Theta$ 
	- *证明过程* 
		**充分性** 
		对 $\theta$ 的任意一个无偏估计 $\tilde\theta$，令 $\varphi = \tilde\theta - \hat\theta$，则 $E(\varphi) = E(\tilde\theta) - E(\hat\theta) = 0$ 
		于是 $\mathrm{Var}(\tilde\theta) = E(\tilde\theta - \theta)^2 = E[(\tilde\theta - \hat\theta) + (\hat\theta - \theta)]^2 = E(\varphi^2) + \mathrm{Var}(\hat\theta) + 2\mathrm{Cov}(\varphi,\hat\theta)\ge \mathrm{Var}(\hat\theta)$ 
		这表明 $\hat\theta$ 在 $\theta$ 的无偏估计类中方差一致最小
		**必要性**，用反证法
		设 $\hat\theta$ 是 $\theta$ 的 $\mathrm{UMVUE}$，$\varphi(\boldsymbol X)$ 满足 $E_\theta(\varphi(\boldsymbol X)) = 0$，$\mathrm{Var}_\theta(\varphi(\boldsymbol X)) < \infty$，倘若在参数空间 $\Theta$ 中有一个 $\theta_0$ 使得 $\mathrm{Cov}_{\theta_0}(\hat\theta, \varphi(\boldsymbol X)) \xlongequal{\Delta} a \not=0$，取 $b = -\dfrac{a}{\mathrm{Var}_{\theta_0}(\varphi(\boldsymbol X))} \not=0$ 
		则 $b^2\mathrm{Var}_{\theta_0}(\varphi(\boldsymbol X)) + 2ab = b(-a+2a) = -\dfrac{a^2}{\mathrm{Var}_{\theta_0}(\varphi(\boldsymbol X))} < 0$ 
		令 $\tilde\theta = \hat\theta + b\varphi(\boldsymbol X)$，则 $E_\theta(\tilde\theta) = E_\theta(\hat\theta) + bE_\theta(\varphi(\boldsymbol X)) = \theta$，这说明 $\tilde\theta$ 也是 $\theta$ 的无偏估计，但其方差
		$$
		\begin{aligned}
		\mathrm{Var}_{\theta_0}(\tilde\theta) =& E_{\theta_0}(\hat\theta + b\varphi(\boldsymbol X) - \theta)^2 = E_{\theta_0}(\hat\theta - \theta)^2 + b^2E_{\theta_0}(\varphi(\boldsymbol X)^2) + 2bE_{\theta_0}((\hat\theta - \theta)\varphi(\boldsymbol X)) \\
		=& \mathrm{Var}_{\theta_0}(\hat\theta) + b^2\mathrm{Var}_{\theta_0}(\varphi(\boldsymbol X)) + 2ab < \mathrm{var}_{\theta_0}(\hat\theta)
		\end{aligned}
		$$
		这与 $\hat\theta$ 是 $\theta$ 的 $\mathrm{UMVUE}$ 矛盾，这就证明了对参数空间 $\Theta$ 中任意的 $\theta$ 都有 $\mathrm{Cov}_\theta(\hat\theta, \varphi(\boldsymbol X)) = 0$，证毕！
	- $\mathrm{UMVUE}$ 的重要特征：$\theta$ 的 $\mathrm{UMVUE}$ 必与任一零的无偏估计不相关，反之亦然
### 6-4-3 充分性原则
- **定理**：设总体概率函数是 $p(x;\theta), x_1,x_2,\cdots,x_n$ 是其样本，$T = T(x_1,x_2,\cdots,x_n)$ 是 $\theta$ 的充分统计量，则对 $\theta$ 的任一无偏估计 $\hat\theta = \hat\theta(x_1,x_2,\cdots,x_n)$，令 $\tilde\theta = E(\hat\theta \mid T)$，则 $\tilde\theta$ 也是 $\theta$ 的无偏估计，且 $\mathrm{Var}(\tilde\theta) \le \mathrm{Var}(\hat\theta)$ 
	- *证明过程* 
		由于 $T = T(x_1,x_2,\cdots,x_n)$ 是充分统计量，故而 $\tilde\theta = E(\hat\theta\mid T)$ 与 $\theta$ 无关，因此它也是 $\theta$ 的一个估计（统计量），根据重期望公式，有 $E(\tilde\theta) = E(E(\hat\theta\mid T)) = E(\hat\theta) = \theta$，故 $\tilde\theta$ 是 $\theta$ 的无偏估计
		再考察其方差 $\mathrm{Var}(\hat\theta) = E[(\hat\theta - \tilde\theta) + (\tilde\theta - \theta)]^2 = E(\hat\theta - \tilde\theta)^2 + E(\tilde\theta - \theta)^2 + 2E[(\hat\theta - \tilde\theta)(\tilde\theta - \theta)]$ 
		由于 $E[(\hat\theta - \tilde\theta)(\tilde\theta - \theta)] = E\{ E[ (\hat\theta-\tilde\theta)(\tilde\theta-\theta) \mid T ] \} = E \{ (\tilde\theta - \theta) E[(\hat\theta-\tilde\theta) \mid T] \} = 0$ 
		由此即有 $\mathrm{Var}(\hat\theta) = E(\hat\theta - \tilde\theta)^2 + \mathrm{Var}(\tilde\theta)$ 
		由于上式右端第一项非负，故 $\mathrm{Var}(\tilde\theta) \le \mathrm{Var}(\hat\theta)$，证毕！
	- 如果无偏估计不是充分统计量的函数，则将之对充分统计量求条件期望可以得到一个新的无偏估计，该估计的方差比原来的估计的方差要小，从而降低了无偏估计的方差
- **充分性原则**：考虑 $\theta$ 的估计问题只需要在基于充分统计量的函数中进行即可，该说法对所有的统计推断问题都是成立的，这便是所谓的**充分性原则** 
### 6-4-4 克拉默-拉奥不等式
- **费希尔信息量**：设总体的概率密度函数 $p(x;\theta),\ \theta\in\Theta$ 满足下列条件：
	(1) 参数空间 $\Theta$ 是直线上的一个开区间
	(2) 支撑 $S = \{x:p(x;\theta)>0\}$ 与 $\theta$ 无关
	(3) 导数 $\dfrac{\partial}{\partial\theta} p(x;\theta)$ 对一切 $\theta\in\Theta$ 都存在
	(4) 对 $p(x;\theta)$，积分与微分运算可交换次序，即 $\displaystyle \dfrac{\partial}{\partial\theta} \int_{-\infty}^\infty p(x;\theta)\mathrm dx = \int_{-\infty}^\infty \dfrac{\partial}{\partial\theta} p(x;\theta)\mathrm dx$ 
	(5) 期望 $E\left[ \dfrac{\partial}{\partial\theta}\ln p(x;\theta) \right]^2$ 存在
	则称 $I(\theta) = E\left[ \dfrac{\partial}{\partial\theta}\ln p(x;\theta) \right]^2$ 为总体分布的**费希尔信息量** 
	- 很多的统计结果都与费希尔信息量有关
	- $I(\theta)$ 的种种性质显示，$I(\theta)$ 越大可被解释为总体分布总包含未知参数 $\theta$ 的信息越多
- **克拉默-拉奥不等式** 
	设连续总体分布 $p(x;\theta)$ 满足费希尔信息量的条件，$x_1,x_2,\cdots,x_n$ 是来自该总体的样本，$T=T(x_1,x_2,\cdots,x_n)$ 是 $g(\theta)$ 的任一个无偏估计，$g'(\theta) = \dfrac{\partial g(\theta)}{\partial\theta}$ 存在，且对 $\Theta$ 中一切 $\theta$，对 $\displaystyle g(\theta) = \int_{-\infty}^\infty \cdots \int_{-\infty}^\infty T(x_1,\cdots,x_n) \prod_{i=1}^n p(x_i;\theta)\mathrm dx_1 \cdots \mathrm dx_n$ 的微商可在积分号下进行，即
	$$
	\begin{aligned}
	g'(\theta) =& \int_{-\infty}^\infty \cdots \int_{-\infty}^\infty T(x_1,\cdots,x_n) \dfrac{\partial}{\partial\theta}\left( \prod_{i=1}^n p(x_i;\theta) \right)\mathrm dx_1\cdots \mathrm dx_n \\
	=& \int_{-\infty}^\infty \cdots \int_{-\infty}^\infty T(x_1,\cdots, x_n) \left[ \dfrac{\partial}{\partial\theta} \ln \prod_{i=1}^n p(x_i;\theta) \right] \prod_{i=1}^n p(x_i;\theta)\mathrm dx_1\cdots \mathrm dx_n
	\end{aligned}
	$$
	（对离散总体，则将上述积分改为求和符号后等式仍然成立）
	则有 $\mathrm{Var}(T) \ge \dfrac{[g'(\theta)]^2}{nI(\theta)}$，该不等式称为**克拉默-拉奥(C-R)不等式**，$\dfrac{[g'(\theta)]^2}{nI(\theta)}$ 称为 **$g(\theta)$ 的无偏估计的方差的 C-R 下界**，简称 **$g(\theta)$ 的 C-R 下界**。
	特别地，对 $\theta$ 的无偏估计 $\hat\theta$，有 $\mathrm{Var}(\hat\theta) \ge (nI(\theta))^{-1}$ 
- *克拉默-拉奥不等式的证明* 
	以连续总体为例证明
	由 $\displaystyle \int_{-\infty}^\infty p(x_i;\theta)\mathrm dx_i = 1,\ (i=1,2,\cdots,n)$，两边对 $\theta$ 求导，由于积分与微分可交换次序
	于是有 $\displaystyle 0 = \int_{-\infty}^\infty \dfrac{\partial}{\partial\theta} p(x_i;\theta)\mathrm dx_i = \int_{-\infty}^\infty \left[ \dfrac{\partial}{\partial\theta}\ln p(x_i;\theta) \right] p(x_i;\theta)\mathrm dx_i = E\left[ \dfrac{\partial}{\partial\theta}\ln p(x_i;\theta) \right]$ 
	记 $Z = \dfrac{\partial}{\partial\theta}\ln \prod\limits_{i=1}^n p(x_i;\theta) = \sum\limits_{i=1}^n \dfrac{\partial}{\partial\theta} \ln p(x_i;\theta)$，则 $E(Z) = \sum\limits_{i=1}^n E\left[ \dfrac{\partial}{\partial\theta} \ln p(x_i;\theta) \right] = 0$ 
	从而 $E(Z^2) = \mathrm{Var}(Z) = \sum\limits_{i=1}^n \mathrm{Var}\left( \dfrac{\partial}{\partial\theta} \ln p(x_i;\theta) \right) = \sum\limits_{i=1}^n E\left[ \dfrac{\partial}{\partial\theta} \ln p(x_i;\theta) \right]^2 = nI(\theta)$ 
	而 $g'(\theta) = E(TZ) = E((T-g(\theta))Z)$，根据施瓦茨不等式，有 $[g'(\theta)]^2 \le E[(T - g(\theta))^2]E(Z^2) = \mathrm{Var}(T)\mathrm{Var}(Z)$ 
	由此，克拉默-拉奥不等式得证，关于离散总体可类似证明
- **有效估计**：如果克拉默-拉奥不等式中等号成立，则称 $T=T(x_1,x_2,\cdots,x_n)$ 是 $g(\theta)$ 的**有效估计** 
	- 有效估计一定是 $\mathrm{UMVUE}$ 
- **注意**：能达到 C-R 下界的无偏估计并不多，大多数场合无偏估计都达不到其 C-R 下界
## 6-5 贝叶斯估计
### 6-5-1 统计推断的基础
- 在统计学中有两个大的学派：频率学派（也称经典学派）和贝叶斯学派
- **总体信息**、**样本信息**、**先验信息**：统计推断是根据样本信息对总体分布或总体的特征数进行推断，经典学派认为这里的统计推断使用到两种信息：**总体信息**和**样本信息**。而贝叶斯学派认为，除了上述两种信息以外，统计推断还应该使用第三种信息：**先验信息** 
	- **总体信息**：总体信息即总体分布或总体所属分布族提供的信息。
		- **例子**：若已知“总体是正态分布”，则我们就知道很多信息
		- 总体信息是很重要的信息，为了获取此种信息往往耗资巨大
	- **样本信息**：样本信息即抽取样本所得观测值提供的信息
		- **例子**：在有了样本观测值后，我们可以根据它大概知道总体的一些特征数在一个什么范围内
		- 这是最“新鲜”的信息，并且越多越好，希望通过样本对总体分布或总体的某些特征作出较精确的统计推断
	- **先验信息**：先验信息即是抽样（试验）之前有关统计问题的一些信息
		- 一般说来，先验信息来源于经验和历史资料
- **贝叶斯统计学**：基于上述总体信息、样本信息、先验信息进行统计推断的统计学称为**贝叶斯统计学** 
	- 它与经典统计学的差别就在于是否利用先验信息
- **贝叶斯学派的基本观点** 
	- 任一未知量 $\theta$ 都可看作随机变量，可用一个概率分布去描述，这个分布称为**先验分布** 
	- 在获得样本之后，总体分布、样本与先验分布通过贝叶斯公式结合起来得到一个关于未知量 $\theta$ 的新分布，称为**后验分布** 
	- 任何关于 $\theta$ 的统计推断都应该基于 $\theta$ 的后验分布进行
### 6-5-2 贝叶斯公式的密度函数形式
- **贝叶斯公式的密度函数形式引入过程** 
	1. 总体依赖于参数 $\theta$ 的概率函数在经典统计中记为 $p(x;\theta)$，它表示参数空间 $\Theta$ 中不同的 $\theta$ 对应不同的分布。在贝叶斯统计中应记为 $p(x\mid \theta)$，它表示在随机变量 $\theta$ 取某个给定值时总体的**条件概率函数** 
	2. 根据参数 $\theta$ 的先验信息确定**先验分布** $\pi(\theta)$ 
	3. 从贝叶斯观点看，样本 $\boldsymbol X = (x_1,x_2,\cdots,x_n)$ 的产生由两步进行。首先设想“上帝”从先验分布 $\pi(\theta)$ 产生一个个体 $\theta_0$，然后人们从 $p(\boldsymbol X \mid \theta_0)$ 中产生一组样本。这时样本 $\boldsymbol X = (x_1,x_2,\cdots,x_n)$ 的**联合条件概率函数** $p(\boldsymbol X \mid \theta_0) = p(x_1,x_2,\cdots,x_n \mid \theta_0) = \prod\limits_{i=1}^n p(x_i \mid \theta_0)$，这个分布综合了总体信息和样本信息
	4. 由于 $\theta_0$ 是设想出来的，仍然是未知的，它是按先验分布 $\pi(\theta)$ 产生的。为把先验信息综合进去，不能只考虑 $\theta_0$，对 $\theta$ 的其他值发生的可能性也要加以考虑，故要用 $\pi(\theta)$ 进行综合。这样一来，样本 $\boldsymbol X$ 和参数 $\theta$ 的**联合分布**为 $h(\boldsymbol X, \theta) = p(\boldsymbol X \mid \theta)\pi(\theta)$，这个联合分布把总体信息、样本信息、先验信息三种可用信息都综合进去了
	5. 我们的目的是要对未知参数 $\theta$ 作统计推断。在没有样本信息时，我们只能依据先验分布对 $\theta$ 作出判断。在有了样本观测值 $\boldsymbol X = (x_1,x_2,\cdots,x_n)$ 之后，我们应依据 $h(\boldsymbol X,\theta)$ 对 $\theta$ 作出推断
	6. 若把 $h(\boldsymbol X, \theta)$ 作分解 $h(\boldsymbol X, \theta) = \pi(\theta\mid \boldsymbol X)m(\boldsymbol X)$，其中 $m(\boldsymbol X)$ 是 $\boldsymbol X$ 的边际概率函数 $\displaystyle m(\boldsymbol X) = \int_\Theta h(\boldsymbol X, \theta)\mathrm d\theta = \int_\Theta p(\boldsymbol X\mid \theta)\pi(\theta)\mathrm d\theta$，它与 $\theta$ 无关，或者说 $m(\boldsymbol X)$ 中不含 $\theta$ 的任何信息。因此能用来对 $\theta$ 作出推断的仅是条件分布 $\pi(\theta\mid \boldsymbol X)$，它的计算公式为 $\displaystyle \pi(\theta\mid \boldsymbol X) = \dfrac{h(\boldsymbol X,\theta)}{m(\boldsymbol X)} = \dfrac{p(\boldsymbol X \mid \theta)\pi(\theta)}{\displaystyle \int_\Theta p(\boldsymbol X\mid \theta)\pi(\theta)\mathrm d\theta }$，这个条件分布称为 $\theta$ 的**后验分布**，它集中了总体、样本、先验中有关 $\theta$ 的一切信息
	7. $\displaystyle \pi(\theta\mid \boldsymbol X) = \dfrac{h(\boldsymbol X,\theta)}{m(\boldsymbol X)} = \dfrac{p(\boldsymbol X \mid \theta)\pi(\theta)}{\displaystyle \int_\Theta p(\boldsymbol X\mid \theta)\pi(\theta)\mathrm d\theta }$ 就是**用密度函数表示的贝叶斯公式**，它也是用总体和样本对先验分布 $\pi(\theta)$ 作调整的结果，它要比 $\pi(\theta)$ 更接近 $\theta$ 的实际情况
- 从贝叶斯公式可以看出，整个贝叶斯统计推断只要先验分布确定后就没有理论上的困难
- 关于先验分布的确定有多种途径，后面将介绍一类最常用的先验分布类——**共轭先验分布** 
### 6-5-3 贝叶斯估计
- 由后验分布 $\pi(\theta\mid \boldsymbol X)$ 估计 $\theta$ 有三种常用方法
	- 使用后验分布的密度函数最大值点作为 $\theta$ 的点估计的**最大后验估计** 
	- 使用后验分布的中位数作为 $\theta$ 的点估计的**后验中位数估计** 
	- 使用后验分布的均值作为 $\theta$ 的点估计的**后验期望估计** 
- **贝叶斯估计**：用的最多的是后验期望估计，它一般也简称为**贝叶斯估计**，记为 $\hat\theta_B$ 
- **贝叶斯假设**：指在缺乏关于参数的先验知识时，采用均匀分布作为参数的先验分布，即参数在其变化范围内取得各值的机会均等，即“同等无知”
- 在某些极端情况下，贝叶斯估计比最大似然估计更符合人们的理念
### 6-5-4 共轭先验分布
- **共轭先验分布（族）**：设 $\theta$ 是总体分布 $p(x;\theta)$ 中的参数，$\pi(\theta)$ 是其先验分布，若对任一来自 $p(x;\theta)$ 的样本观测值得到的后验分布 $\pi(\theta\mid \boldsymbol X)$ 与 $\pi(\theta)$ 属于同一个分布族，则称该分布族是 $\theta$ 的**共轭先验分布（族）** 
	- 在方差已知时正态总体均值的共轭先验分布是正态分布
## 6-6 区间估计
### 6-6-1 区间估计的概念
- **置信区间**、**置信下限**、**置信上限**：设 $\theta$ 是总体的一个参数，其参数空间为 $\Theta$，$x_1,x_2,\cdots,x_n$ 是来自该总体的样本，对给定的一个 $\alpha\ (0<\alpha<1)$，假设有两个统计量 $\hat\theta_L = \hat\theta_L(x_1,x_2,\cdots,x_n)$ 和 $\hat\theta_U = \hat\theta_U(x_1,x_2,\cdots,x_n)$，若对任意的 $\theta\in \Theta$，有 $P_\theta(\hat\theta_L \le \theta\le \hat\theta_U) \ge 1-\alpha$，则称随机区间 $[\hat\theta_L, \hat\theta_U]$ 为 $\theta$ 的**置信水平为 $1-\alpha$ 的置信区间**，或简称 $[\hat\theta_L, \hat\theta_U]$ 是 $\theta$ 的 $1-\alpha$ 的**置信区间**，$\hat\theta_L$ 和 $\hat\theta_U$ 分别称为 $\theta$ 的（双侧）**置信下限**和**置信上限** 
	- 置信水平 $1-\alpha$ 的频率解释：在大量重复使用 $\theta$ 的置信区间 $[\hat\theta_L, \hat\theta_U]$ 时，每次得到的样本观测值是不同的，从而每次得到的区间也是不一样的。对一次具体的观测值而言，$\theta$ 可能在 $[\hat\theta_L, \hat\theta_U]$ 内，也可能不在。平均而言，在这大量的区间估计观测值中，至少有 $100(1-\alpha)\%$ 包含 $\theta$ 
- **同等置信区间**：沿用上面定义的记号，如果对给定的 $\alpha\ (0<\alpha<1)$，对任意的 $\theta\in\Theta$，有 $P_\theta(\hat\theta_L \le \theta\le \hat\theta_U) = 1-\alpha$，则称 $[\hat\theta_L, \hat\theta_U]$ 为 $\theta$ 的 $1-\alpha$ **同等置信区间** 
- **置信下限**、**同等置信下限**：设 $\hat\theta_L = \hat\theta_L(x_1,x_2,\cdots,x_n)$ 是统计量，对给定的 $\alpha\in(0,1)$ 和任意的 $\theta\in\Theta$，有 $P_\theta(\hat\theta_L \le \theta) \ge 1-\alpha,\ \forall\ \theta\in\Theta$，则称 $\hat\theta_L$ 为 $\theta$ 的置信水平为 $1-\alpha$ 的（单侧）**置信下限**。假如等号对一切 $\theta\in\Theta$ 成立，则称 $\hat\theta_L$ 为 $\theta$ 的 $1-\alpha$ **同等置信下限** 
- **置信上限**、**同等置信上限**：设 $\hat\theta_U = \hat\theta_U(x_1,x_2,\cdots,x_n)$ 是统计量，对给定的 $\alpha\in(0,1)$ 和任意的 $\theta\in\Theta$，有 $P_\theta(\hat\theta_L \le \theta) \ge 1-\alpha,\ \forall\ \theta\in\Theta$，则称 $\hat\theta_U$ 为 $\theta$ 的置信水平为 $1-\alpha$ 的（单侧）**置信上限**。假如等号对一切 $\theta\in\Theta$ 成立，则称 $\hat\theta_U$ 为 $\theta$ 的 $1-\alpha$ **同等置信上限** 
- 单侧置信下限和单侧置信上限都是置信区间的特殊情形，故寻求置信区间的方法可以用来寻找置信限
### 6-6-2 枢轴量法
- 构造未知参数 $\theta$ 的置信区间的最常用的方法是**枢轴量法**，共三步：
	1. 设法构造一个样本和 $\theta$ 的函数 $G=G(x_1,x_2,\cdots,x_n,\theta)$ 使得 $G$ 的分布不依赖于未知参数。一般称具有这种性质的 $G$ 为**枢轴量** 
	2. 适当地选择两个常数 $c,d$，使对给定的 $\alpha\ (0<\alpha<1)$，有 $P(c\le G\le d) = 1-\alpha$（在离散场合，该式等号改为大于等于）
	3. 假如能将 $c\le G\le d$ 进行不等式等价变形化为 $\hat\theta_L \le \theta \le \hat\theta_U$，则有 $P_\theta(\hat\theta_L \le \theta \le \hat\theta_U) = 1-\alpha$，这表明 $[\hat\theta_L, \hat\theta_U]$ 是 $\theta$ 的 $1-\alpha$ 同等置信区间
	- **说明**：上述构造置信区间的关键在于构造枢轴量 $G$，故把这种方法称为**枢轴量法** 
	- 枢轴量的寻找一般从 $\theta$ 的点估计出发，而满足 $P(c\le G\le d) = 1-\alpha$ 的 $c,d$ 可以有很多，选择的目的是希望 $P_\theta(\hat\theta_L \le \theta \le \hat\theta_U) = 1-\alpha$ 的平均长度 $E_\theta(\hat\theta_U - \hat\theta_L)$ 尽可能短
- **等尾置信区间**：在枢轴量法中，假如可以找到 $c,d$ 使得 $E_\theta(\hat\theta_U - \hat\theta_L)$ 达到最短是最好的，不过在不少场合很难做到这一点。故常这样选择 $c,d$，使得两个尾部概率各为 $\dfrac \alpha2$，即 $P_\theta(G<c) = P_\theta(G>d) = \dfrac \alpha 2$，这样得到的置信区间称为**等尾置信区间** 
	- 实用的置信区间大都是等为置信区间
### 6-6-3 单个正态总体参数的置信区间
正态总体 $N(\mu,\sigma^2)$ 是最常见的分布，本小节我们讨论它的两个参数的置信区间
#### 6-6-3-1 $\sigma$ 已知时 $\mu$ 的置信区间
在这种情况下，由于 $\mu$ 的点估计为 $\overline x$，其分布为 $N(\mu, \sigma^2/n)$，因此枢轴量可选为 $G = \dfrac{\overline x - \mu}{\sigma/\sqrt n} \sim N(0,1)$，$c$ 和 $d$ 应满足 $P(c\le G\le d) = \varPhi(d) - \varPhi(c) = 1-\alpha$ 
经过不等式变形可得 $P_\mu(\overline x - d\sigma/\sqrt n \le \mu \le \overline x - c\sigma/\sqrt n) = 1-\alpha$，该区间长度为 $(d-c)\sigma/\sqrt n$ 
由于标准正态分布为单峰对称的，故在 $\varPhi(d) - \varPhi(c) = 1-\alpha$ 的条件下，当 $d=-c=u_{1-\frac\alpha2}$ 时，$d-c$ 达到最小
由此给出了 $\mu$ 的 $1-\alpha$ 同等置信区间为 $\left[\overline x - \dfrac{u_{1-\alpha/2}\sigma}{\sqrt n}, \overline x + \dfrac{u_{1-\alpha/2}\sigma}{\sqrt n}\right]$ 
这是一个以 $\overline x$ 为中心，半径为 $\dfrac{u_{1-\alpha/2}\sigma}{\sqrt n}$ 的对很区间，常将之表示为 $\overline x \pm \dfrac{u_{1-\alpha/2}\sigma}{\sqrt n}$ 
#### 6-6-3-2 $\sigma$ 未知时 $\mu$ 的置信区间
这时可用 $t$ 统计量，因为 $t = \dfrac{\sqrt n(\overline x - \mu)}{s} \sim t(n-1)$，因此 $t$ 可以用来作为枢轴量
完全类似上一小节，可得到 $\mu$ 的 $1-\alpha$ 置信区间为 $x\pm \dfrac{t_{1-\alpha/2}(n-1)s}{\sqrt n}$ 
此处 $s^2 = \dfrac 1{n-1}\sum\limits_{i=1}^n (x_i - \overline x)^2$ 是 $\sigma^2$ 的无偏估计
#### 6-6-3-3 $\mu$ 未知时 $\sigma^2$ 的置信区间
此时虽然也可以就 $\mu$ 是否已知两种情况讨论 $\sigma^2$ 的置信区间，但在实际中 $\sigma^2$ 未知时 $\mu$ 已知的情形是极为罕见的，所以我们只在 $\mu$ 未知的条件下讨论 $\sigma^2$ 的置信区间
枢轴量不难给出，由于 $\sigma^2$ 可用样本方差 $s^2$ 估计，而在 5.4 中已经证明 $\dfrac{(n-1)s^2}{\sigma^2} \sim \chi^2(n-1)$，由于 $\chi^2$ 分布是偏态分布，寻找平均长度最短区间很难实现，一般都改为寻找等为置信区间：
把 $\alpha$ 平分为两部分，在 $\chi^2$ 分布两侧各截面积为 $\dfrac \alpha 2$ 的部分，即采用 $\chi^2$ 的两个分位数 $\chi_{\alpha/2}^2(n-1)$ 和 $\chi_{1-\alpha/2}^2(n-1)$，它们满足 $P\left( \chi_{\alpha/2}^2 \le \dfrac{(n-1)s^2}{\sigma^2} \le \chi_{1-\alpha/2}^2 \right) = 1-\alpha$ 
由此给出 $\sigma^2$ 的 $1-\alpha$ 置信区间为 $\left[ \dfrac{(n-1)s^2}{\chi_{1-\alpha/2}^2(n-1)}, \dfrac{(n-1)s^2}{\chi_{\alpha/2}^2(n-1)}  \right]$ 
将上式的两端开方即得到标准差 $\sigma$ 的 $1-\alpha$ 置信区间
### 6-6-4 大样本置信区间
- 在有些场合，寻找枢轴量及其分布比较困难。在样本量充分大时，可用渐近分布来构造近似的置信区间
- **典型的例子**：关于比例 $p$ 的置信区间
	设 $x_1,x_2,\cdots,x_n$ 是来自二点分布 $b(1,p)$ 的样本，现要求 $p$ 的 $1-\alpha$ 置信区间
	由中心极限定理可知，样本均值 $\overline x$ 的渐进分布为 $N\left(p, \dfrac{p(1-p)}{n}\right)$，因此有 $u = \dfrac{\overline x - p}{\sqrt{p(1-p) / n}} \overset\cdot\sim N(0,1)$，这个 $u$ 可作为近似枢轴量
	对给定 $\alpha$，利用标准正态分布的 $1-\dfrac \alpha 2$ 分位数 $u_{1-\alpha/2}$ 可得 $P\left( \left| \dfrac{\overline x - p}{\sqrt{p(1-p)/n}} \right| \le u_{1-\alpha/2} \approx 1-\alpha \right)$ 
	括号里的事件等价于 $(\overline x - p)^2 \le u_{1-\alpha/2}^2 p(1-p)/n$ 
	记 $\lambda = u_{1-\alpha/2}^2$，上述不等式可化为 $\left( 1 + \dfrac \lambda n \right)p^2 - \left( 2\overline x + \dfrac \lambda n \right) p + \overline x^2 \le 0$ 
	左侧 $p$ 的二次三项式的判别式 $\left( 2\overline x + \dfrac \lambda n \right)^2 - 4\left( 1 + \dfrac{\lambda}n \right) \overline x^2 = \dfrac{4\overline x(1-\overline x)}n \lambda + \dfrac{\lambda^2}{n^2}>0$ 
	故此二次三项式的图形是开口向上并与 $x$ 轴有两个交点的曲线
	记此两个交点的横坐标为 $\hat p_L$ 和 $\hat p_U$，则有 $P(\hat p_L \le p \le \hat p_U) = 1-\alpha$ 
	这里 $\hat p_L$ 和 $\hat p_U$ 是该二次三项式的两个根，它们可表示为 $\dfrac 1{1 + \dfrac \lambda n} \left( \overline x + \dfrac\lambda{2n} \pm \sqrt{\dfrac{\overline x(1-\overline x)}n\lambda + \dfrac{\lambda^2}{4n^2}} \right)$ 
	由于 $n$ 比较大，在实用中通常略去 $\dfrac\lambda n$ 项，于是可将置信区间近似为 $\left[ \overline x - u_{1-\alpha/2}\sqrt{\dfrac{\overline x(1-\overline x)}{n}}, \overline x + u_{1-\alpha/2}\sqrt{\dfrac{\overline x(1-\overline x)}{n}} \right]$ 
- 关于泊松分布中参数 $\lambda$ 的置信区间亦可用类似方法确定
### 6-6-5 样本量的确定
- **样本量的确定**：在统计中，样本量越大，估计的精度越高，但大样本量需要的经费高，实施的时间也长，投人人力也多，所以实用中人们往往关心如下问题：在一定要求下，至少需要多大的样本量？这就是**样本量的确定**问题
- **保证概率**、**绝对误差**：在抽样调查中，置信水平 $1-\alpha$ 也称为**保证概率**，置信区间的半径（长度的一半）$d_0$ 也称为**绝对误差** 
### 6-6-6 两个正态总体下的置信区间
设 $x_1,x_2,\cdots,x_m$ 是来自 $N(\mu_1,\sigma_1^2)$ 的样本，$y_1,y_2,\cdots,y_n$ 是来自 $N(\mu_2,\sigma_2^2)$ 的样本，且两个样本相互独立。$\overline x$ 与 $\overline y$ 分别是它们的样本均值，$s_x^2 = \dfrac 1{m-1}\sum\limits_{i=1}^m (x_i - \overline x)^2$ 和 $s_y^2 = \dfrac 1{n-1}\sum\limits_{i=1}^n (y_i - \overline y)^2$ 分别是它们的样本方差
下面讨论两个均值差和两个方差比的置信区间
#### 6-6-6-1 $\mu_1 - \mu_2$ 的置信区间
- $\sigma_1^2$ 和 $\sigma_2^2$ 已知时
	此时有 $\overline x - \overline y \sim N \left( \mu_1 - \mu_2, \dfrac{\sigma_1^2}m + \dfrac{\sigma_2^2}n \right)$，取枢轴量为 $u = \dfrac{\overline x - \overline y - (\mu_1 - \mu_2)}{\sqrt{\dfrac{\sigma_1^2}m + \dfrac{\sigma_2^2}n}} \sim N(0,1)$ 
	沿用前面多次用过的方法可以得到 $\mu_1 - \mu_2$ 的 $1-\alpha$ 置信区间为 $\overline x - \overline y \pm u_{1-\alpha/2}\sqrt{\dfrac{\sigma_1^2}m + \dfrac{\sigma_2^2}n}$ 
- $\sigma_1^2 = \sigma_2^2 = \sigma^2$ 未知时
	此时有 $\overline x - \overline y \sim N\left( \mu_1 - \mu_2, \left( \dfrac 1m + \dfrac 1n \right)\sigma^2 \right)$ 和 $\dfrac{(m-1)s_x^2 + (n-1)x_y^2}{\sigma^2} \sim \chi^2(m+n-2)$ 
	由于 $\overline x, \overline y, s_x^2, s_y^2$ 相互独立，故可构造服从 $t$ 分布 $t(m+n-2)$ 的枢轴量 $t = \sqrt{\dfrac{mn(m+n-2)}{m+n}} \dfrac{\overline x - \overline y - (\mu_1 - \mu_2)}{\sqrt{(m-1)s_x^2 + (n-1)s_y^2}} \sim t(m+n-2)$ 
	记 $s_w^2 = \dfrac{(m-1)s_x^2 + (n-1)s_y^2}{m+n-2}$，则 $\mu_1-\mu_2$ 的 $1-\alpha$ 置信区间为 $\overline x - \overline y \pm \sqrt{\dfrac{m+n}{mn}}s_w t_{1-\alpha/2}(m+n-2)$ 
- $\dfrac{\sigma_2^2}{\sigma_1^2} = c$ 已知时
	此时的处理方法与 $\sigma_1^2 = \sigma_2^2 = \sigma^2$ 未知的情形中完全类似
	只需注意到 $\overline x - \overline y \sim N(\mu_1 - \mu_2, \dfrac{\sigma_1^2}m + \dfrac{\sigma_2^2}n) = N\left( \mu_1 - \mu_2, \sigma_1^2\left( \dfrac 1m + \dfrac cn \right) \right)$，$\dfrac{(m-1)s_x^2 + (n-1)s_y^2/c}{\sigma_1^2} = \dfrac{(m-1)s_x^2}{\sigma_1^2} + \dfrac{(n-1)s_y^2}{\sigma_2^2} \sim \chi^2(m+n-2)$ 
	由于 $\overline x, \overline y, s_x^2, s_y^2$ 相互独立，仍可构造如下服从 $t$ 分布 $t(m+n-2)$ 的枢轴量 $t = \sqrt{\dfrac{mn(m+n-2)}{mc+n}} \dfrac{\overline x - \overline y - (\mu_1 - \mu_2)}{\sqrt{(m-1)s_x^2 + (n-1)s_y^2/c}} \sim t(m+n-2)$ 
	记 $s_w^2 = \dfrac{(m-1)s_x^2 + (n-1)s_y^2/c}{m+n-2}$，则 $\mu_1-\mu_2$ 的 $1-\alpha$ 置信区间为 $\overline x - \overline y \pm \sqrt{\dfrac{mc+n}{mn}}s_w t_{1-\alpha/2}(m+n-2)$
