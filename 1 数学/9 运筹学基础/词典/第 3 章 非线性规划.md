# 3 非线性规划
## 3-1 基本概念
- **非线性规划问题** 
	一个一般的**非线性规划问题**通常表示为
	$$
	\begin{aligned}
	\min & \quad f(x) \\
	\text{s.t.} & \quad c_i(x) = 0,\ i = 1, 2, \cdots, m' \\
	& \quad c_i(x) \geq 0,\ i = m' + 1, m' + 2, \cdots, m
	\end{aligned} \tag{*}
	$$
	其中 $x \in \mathbb{R}^n$，$m' \leq m$，$\mathcal{E} = \{1, 2, \cdots, m'\}$，$\mathcal{I} = \{m' + 1, \cdots, m\}$ 分别为等式约束的指标集和不等式约束的指标集。
- **非线性规划**：当目标函数和约束函数中至少有一个是变量 $x$ 的非线性函数时，问题称为**非线性规划** 
- **无约束优化问题**：如果问题 $(*)$ 中不含约束条件，则这样的非线性规划问题称为**无约束优化问题** $\min\limits_{x \in \mathbb{R}^n} f(x)$ 
	- *例子*：$\min \ 100\bigl[(x_2 - x_1^2)^2 + (1 - x_1)^2\bigr]$ 
- **约束优化问题**：如果问题 $(*)$ 含有约束条件，则称为**约束优化问题** 
	- *例子*：$\begin{aligned} \min &\  x^2 \\ \text{s.t.}&\ -1 \leq x \leq 1 \end{aligned}$，$\begin{aligned} \min & \ x_1 - x_2^2 \\ \text{s.t.} & \ (x_1 - 1)(x_2 - 2) \geq 0 \\ &\ 2 \leq x_1 \leq 4 \end{aligned}$ 
- **非线性方程组问题和非线性不等式问题**：如果问题不含有目标函数，则问题是**非线性方程组问题和非线性不等式问题** 
- *注意*：在上述优化问题中我们考虑的是极小化目标函数 $\min f(x)$，对于极大化目标函数 $\max f(x)$，我们可以写成 $\min -f(x)$ 
- *注意*：对于不等式约束，我们考虑的是 $c_i(x) \geq 0$。对于 $c_i(x) \leq 0$ 的不等式约束，可以写成 $-c_i(x) \geq 0$ 来处理。
- **可行性**、**最优性**：对于非线性规划问题，**可行性**和**最优性**是最重要的概念。
- **可行点**、**可行域**：满足约束条件的点 $x \in \mathbb{R}^n$ 称为**可行点**。所有可行点的集合称为**可行域**。
	- 对于问题 $(*)$，可行域为 $X = \left\{ x \,\bigg|\, \begin{aligned} & c_i(x) = 0, \quad i = 1, \cdots, m', \\ & c_i(x) \geq 0, \quad i = m' + 1, \cdots, m \end{aligned} \right\}$ 
- **有效约束** (**起作用约束**)、**边界**、**无效约束** (**不起作用约束**)、**内点**：在一个可行点 $\bar{x}$ 考虑不等式约束 $c_i(x) \geq 0$，如果有 $c_i(\bar{x}) = 0$，就称不等式约束 $c_i(x) \geq 0$ 在点 $\bar{x}$ 是**有效约束**或**起作用约束** (**active constraint**)，并称可行点 $\bar{x}$ 位于约束 $c_i(x) \geq 0$ 的**边界**。如果有 $c_i(\bar{x}) > 0$，就称不等式约束 $c_i(x) \geq 0$ 在点 $\bar{x}$ 是**无效约束**或**不起作用约束** (**inactive constraint**)，并称 $\bar{x}$ 是约束 $c_i(x) \geq 0$ 的**内点**。
	- 在任意可行点，所有的等式约束都被认为是有效约束。
- **有效集**：在一个可行点 $\bar{x}$，所有有效约束的全体被称为该可行点的**有效集** (**active set**)，其指标集记为 $\mathcal{A}_{\bar{x}} = \left\{ i \,\big|\, i = 1, 2, \cdots, m', m' + 1, \cdots, p, \, c_i(\bar{x}) = 0 \right\}$ 
- **内点**、**边界点**：在一可行点 $\bar{x}$ 如果没有一个不等式约束是有效的，就称 $\bar{x}$ 是可行域的**内点**，不是内点的可行点就是可行域的**边界点**

- **全局最优解** (**总体最优解**)、**严格全局最优解** (**严格总体最优解**)、**局部最优解**、**严格局部最优解**：一个可行点 $x^* \in X$ 称为问题 $(*)$ 的**全局最优解** (**总体最优解**)，如果有 $f(x^*) \leq f(x),\ \forall\ x \in X$ 成立；如果上述不等式对所有不同于 $x^*$ 的可行点 $x$ 严格成立，即 $f(x^*) < f(x),\ \forall x \in X, \, x \neq x^*$，则 $x^*$ 称为**严格全局最优解** (**严格总体最优解**)；对于可行点 $x^*$，如果存在一个邻域 $\mathcal{N}(x^*) = \left\{ x \,\big|\, \| x - x^* \| \leq \delta \right\}$，使得 $f(x^*) \leq f(x),\ \forall\ x \in \mathcal{N}(x^*) \cap X$ 成立，则称 $x^*$ 为优化问题 $(*)$ 的**局部最优解**，其中 $\delta > 0$ 是一个小的正数，范数 $\| \cdot \|$ 可以是任意向量范数，但一般常用 $\ell_2$ 范数 $\| x \|_2 = \left( \sum\limits_{i=1}^n x_i^2 \right)^{\frac{1}{2}}$；如果不等式 $f(x^*) \leq f(x),\ \forall\ x \in \mathcal{N}(x^*) \cap X$ 对所有 $x \in \mathcal{N}(x^*) \cap X,\ x \neq x^*$ 严格成立，则称 $x^*$ 为**严格局部最优解**

- 下面引进凸集与凸函数的概念
- **凸集**：集合 $D \subset \mathbb{R}^n$ 称为**凸集**，如果对于任意 $x, y \in D$ 有 $\lambda x + (1 - \lambda) y \in D,\ \forall \ 0 \leq \lambda \leq 1$ 
	- *几何直观*：集合 $D\subset \mathbb R^n$ 称为凸集，如果对任意两点 $x, y \in D$，连接 $x$ 与 $y$ 的线段上的所有点都在 $D$ 内。
	- *平面上凸集与非凸集的例子* 
		![[Pasted image 20260324090634.png|180]]
- **凸集的性质** 
	- 两个凸集的交、和以及差仍然是凸集。即如果 $D_1, D_2 \subset \mathbb{R}^n$ 是凸集，则 $D_1 \cap D_2 = \left\{ x \mid x \in D_1 \text{ 且 } x \in D_2 \right\}$，$D_1 + D_2 = \left\{ x + y \mid x \in D_1,\, y \in D_2 \right\}$，$D_1 - D_2 = \left\{ x - y \mid x \in D_1,\, y \in D_2 \right\}$  都是凸集
	- 对于任意非零实数 $\alpha$，集合 $\alpha D_1 = \left\{ \alpha x \mid x \in D_1 \right\}$ 也是凸集
	- 凸集的任意有限个点的凸组合仍属于凸集
- **凸函数**、**严格凸函数**：设函数 $f(x)$ 在凸集 $D$ 上有定义，如果对任意 $x, y \in D$ 和任意 $\lambda \in [0, 1]$ 有 $f(\lambda x + (1 - \lambda) y) \leq \lambda f(x) + (1 - \lambda) f(y)$，则称 $f(x)$ 是凸集 $D$ 上的**凸函数**。如果上述不等式对 $x \neq y$ 与任意 $\lambda \in (0, 1)$ 严格成立，则称 $f$ 是凸集 $D$ 上的**严格凸函数** 
	- 凸函数的定义表明：如果 $f(x)$ 是凸集 $D$ 上的凸函数，则对于凸集 $D$ 上的任意两点 $x, y$，连接点 $(x, f(x))$ 与点 $(y, f(y))$ 之间的直线段位于函数图形 (曲线或曲面) 的上方，
	- 下图给出了凸函数的几何直观表示

- **凹函数**、**严格凹函数**：如果对任意 $x, y \in D$ 和任意 $\lambda \in [0, 1]$ 有 $f(\lambda x + (1 - \lambda) y) \geq \lambda f(x) + (1 - \lambda) f(y)$，则称 $f(x)$ 是凸集 $D$ 上的**凹函数**。如果上述不等式对 $x \neq y$ 与任意 $\lambda \in (0, 1)$ 严格成立，则称 $f$ 是凸集 $D$ 上的**严格凹函数** 
	- *更精简的定义*：一个函数 $f(x)$ 称为是凸集 $D$ 上的 (严格) 凹函数，如果 $-f(x)$ 是凸集 $D$ 上的 (严格) 凸函数
	- *例子*：对于 $x \geq 0$，$f(x) = x^2$ 和 $f(x) = e^x$ 是凸函数；而 $f(x) = x^{\frac{1}{2}}$ 是凹函数。线性函数 $f(x) = ax + b$ 既是凸函数，也是凹函数
- **凸规划**：目标函数是凸函数，可行域是凸集的最优化称为**凸规划** 
	- 凸规划问题的局部最优解也是全局最优解
- **定理 1**：设 $x^*$ 是凸规划问题的一个局部最优解，则 $x^*$ 也是全局最优解。
	- *证明过程* 
		用反证法
		设 $x^*$ 是凸规划问题的一个局部最优解，但不是全局最优解，则存在另一可行点，设为 $y$ 满足 $f(y) < f(x^*)$ 
		由可行集的凸性，对于任意 $0 < \lambda < 1$，点 $\lambda x^* + (1 - \lambda) y$ 都是可行点。又根据目标函数的凸性有  
		$$
		\begin{aligned}
		f(\lambda x^* + (1 - \lambda) y) &\leq \lambda f(x^*) + (1 - \lambda) f(y) \\
		&< \lambda f(x^*) + (1 - \lambda) f(x^*) \\
		&= f(x^*)
		\end{aligned}
		$$  
		这表明在 $x^*$ 的任意小的邻域内都存在函数值小于 $f(x^*)$ 的可行点，这与 $x^*$ 是局部最优解相矛盾。
		证毕！
	- **推论**：进一步，当目标函数严格凸时，凸规划问题的局部最优解 $x^*$ 是唯一全局最优解。(证明是类似的)
- *例子*：线性函数 $c^T x = c_1 x_1 + c_2 x_2 + \cdots + c_n x_n$ 既是凸函数也是凹函数。
- *例子*：对于二次函数 $q(x) = \dfrac{1}{2} x^T G x + b^T x + d$，当对称矩阵 $G$ 正半定时，$q(x)$ 是凸函数；当 $G$ 是正定时，$q(x)$ 是严格凸函数；当 $G$ 是负半定时，$q(x)$ 是凹函数；当 $G$ 是不定矩阵时，$q(x)$ 既不是凸的也不是凹的。
- **定理 2**：考虑非空可行域 $X = \{ x \mid c_i(x) \geq 0,\ i = 1, 2, \cdots, m \}$，如果每一个约束函数 $c_i(x)$ 是凹函数，则可行域 $X$ 是凸集
	- *证明过程* 
		设 $x \in X$，$y \in X$ 为两个不同的可行点，即有 $c_i(x) \geq 0$，$c_i(y) \geq 0,\ i = 1, 2, \cdots, m$ 
		由函数 $c_i(x)\ (i = 1, 2, \cdots, m)$ 的凹性，知 $-c_i(x)\ (i = 1, 2, \cdots, m)$ 是凸函数
		再由凸函数的定义，对 $\lambda \in (0, 1)$，有 $-c_i(\lambda x + (1 - \lambda) y) \leq -\lambda c_i(x) - (1 - \lambda) c_i(y) \leq 0, \ i = 1, 2, \cdots, m$ 
		从而 $c_i(\lambda x + (1 - \lambda) y) \geq 0,\ \forall\ \lambda \in (0, 1),\ i = 1, 2, \cdots, m$  
		这就证明了 $\lambda x + (1 - \lambda) y \in X$，即 $X$ 是凸集，证毕！
	- 最优化问题的可行域由约束条件确定。该定理给出什么样的约束确定的可行域是凸的
	- 因此，利用凸函数与凹函数的关系，如果考虑的可行域是 $X = \{ x \mid c_i(x) \leq 0,\ i = 1, 2, \cdots, m \}$，则当每一个约束函数 $c_i(x)$ 是凸函数时，可行域 $X$ 是凸集。
## 3-2 最优性条件
- **单变量函数的极值问题**：$\begin{aligned} \min \quad & f(x) \\ \text{s.t.} \quad & a \leq x \leq b \end{aligned}$ 
	- *解题过程* 
		*情形 1*：$a < x < b$，$f'(x) = 0$ 
		设 $a < x_0 < b$，$f'(x_0)$ 存在
		若 $x_0$ 是局部极小点，则 $f'(x_0) = 0$。反过来，若已知 $f'(x_0) = 0$，则 $x_0$ 不一定是局部极小点
		这时，我们有：
		如果 $f'(x_0) = 0$，$f''(x_0) > 0$，则 $x_0$ 是局部极小点
		如果 $f'(x_0) = 0$，$f''(x_0) < 0$，则 $x_0$ 是局部极大点
		进一步，如果 $f'(x_0) = 0$ 且 $f''(x_0) = 0$，则需要利用高阶导数来确定 $x_0$ 是极小点、极大点，还是非极值点。
		*情形 2*：$f(x)$ 在 $x_0$ 不存在导数
		那么我们可以在 $x_0$ 的近旁找两点 $x_1$ 和 $x_2$，满足 $x_1 < x_0$ 和 $x_2 > x_0$ 
		如果 $f(x_0) \leq f(x_1)$ 且 $f(x_0) \leq f(x_2)$，则 $x_0$ 是局部极小点
		如果 $f(x_0) \geq f(x_1)$ 且 $f(x_0) \geq f(x_2)$，则 $x_0$ 是局部极大点
		其他情形，$x_0$ 不是局部极值点
		*情形 3*：关于区间 $[a, b]$ 端点处极值性质的确定。
		如果 $f'(a) > 0$，则 $a$ 是局部极小点
		如果 $f'(a) < 0$，则 $a$ 是局部极大点
		如果 $f'(b) > 0$，则 $b$ 是局部极大点
		如果 $f'(b) < 0$，则 $b$ 是局部极小点
