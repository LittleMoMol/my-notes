# 3 函数基本逼近（二）——最佳逼近
## 3-1 最佳逼近问题的提出
- **定理**：对任意插值点集合，都存在某个连续函数 $f(x)$，其插值多项式在给定区间上不一致收敛于 $f(x)$ 
- **Weierstrass 定理**：设函数 $f(x)$ 在区间 $[a, b]$ 上连续，则对任何 $\varepsilon > 0$，总存在一代数多项式 $p(x)$，使得 $\max\limits_{a \leqslant x \leqslant b} |f(x) - p(x)| < \varepsilon$ 
	- 该定理启发我们可通过其他逼近方法对被逼近函数 $f(x)$ 构造整体逼近效果更好的多项式序列 $\{p_{n}(x)\}_{n=0}^{\infty}$ 
	- 特别地，按如下方式进行选取：选取 $p_{n}\in P_{n}$，使 $\max\limits_{a \leqslant x \leqslant b} |f(x) - p(x)| < \varepsilon$ 的左端取最小值。由此，可导出如下最佳一致逼近的定义。
- **Chebyshev(切比雪夫)逼近**（**最佳一致逼近**、**最佳逼近**、$E_n(f)$）、**最佳一致逼近代数多项式**：设 $f(x)$ 是 $[a,b]$ 上的连续函数，称 $E_{n}(f;P_{n})=\inf\limits_{p_{n}\in P_{n}}\max\limits_{a\leqslant x\leqslant b}|f(x)-p_{n}(x)|$ 为逼近子空间 $P_{n}$ 对函数 $f(x)$ 的**最佳一致逼近**，简称**最佳逼近**或 **Chebyshev(切比雪夫)逼近**，并简记为 $E_{n}(f)$；而使 $E_{n}(f;P_{n})$ 达到最佳逼近值的多项式 $p_{n}^{*}\in P_{n}$（即满足 $E_{n}(f)=\max\limits_{a\leqslant x\leqslant b}|f(x)-p_{n}^{*}(x)|$），称为 $f(x)$ 的 $n$ 次**最佳一致逼近代数多项式** 
- *注意*：由于求解最佳一致逼近的困难性，本章还将讨论其他最佳意义下的逼近问题，如**最佳平方逼近**等
## 3-2 线性赋范空间的最佳逼近及存在性定理
- **最佳逼近**、**最佳逼近元素**：设 $E$ 为一线性赋范空间，$H_{m} \subseteq E$ 为其 $m$ 维子空间，$f \in E$ 为任意给定的元素，称量 $E(f;H_{m}) = \inf\limits_{\phi \in H_{m}} \| f - \phi \|$ 为**子空间 $H_{m}$ 对元素 $f$ 的最佳逼近**，而使式该式成立的元素 $\phi^{*} \in H_{m}$（即满足 $E(f;H_{m}) = \| f - \phi^{*} \|$），称为 $f$ 的**最佳逼近元素** 
	- *易于分析的等价定义*：设 $H_{m} = \operatorname{span}\{ \phi_{1}, \phi_{2}, \cdots, \phi_{m} \}$，其中 $\phi_{i} \in E$, $i = 1, 2, \cdots, m$，且元素系 $\phi_{1}, \phi_{2}, \cdots, \phi_{m}$ 线性无关。这时，对于 $\forall\ \phi \in H_{m}$，有 $\displaystyle \phi = \sum\limits_{i=1}^{m} \alpha_{i} \phi_{i}, \ \alpha_{i} \in \mathbb{R}, \ i = 1, 2, \cdots, m$，即 $\phi$ 与 $\mathbb{R}^{m}$ 中的元素 $( \alpha_{1}, \alpha_{2}, \cdots, \alpha_{m})^{T}$ 一一对应。则称 $\phi^{*} = \displaystyle\sum_{i=1}^{m} \alpha_{i}^{*} \phi_{i} \in H_{m}$ 为 $f$ 的最佳逼近元素，如果它满足 $\displaystyle \left\| f - \sum_{i=1}^{m} \alpha_{i}^{*} \phi_{i} \right\| = \inf\limits_{(\alpha_{1},\alpha_{2},\cdots,\alpha_{m}) \in \mathbb{R}^{m}} \left\| f - \sum_{i=1}^{m} \alpha_{i} \phi_{i} \right\|$ 
	- 有了最佳逼近问题的提法，自然会产生以下问题
		1. 最佳逼近元素 $\phi^{*}$ 是否存在？
		2. 如果最佳逼近元素存在，是否唯一？
		3. 最佳逼近元素应具有什么特征？
		4. 最佳逼近元素的构造及其应用。
- **存在性定理**：对任意 $f \in E$，在 $H_{m}$ 中存在 $f$ 的最佳逼近元素。
	- *证明过程* 
		**第 1 步**：构造两个新函数
		令 $\alpha = (\alpha_{1}, \alpha_{2}, \cdots, \alpha_{m})^{T} \in \mathbb{R}^{m}$，定义两个多元函数 $\displaystyle g(\alpha) := g(\alpha_{1}, \alpha_{2}, \cdots, \alpha_{m}) = \| \phi \| = \left\| \sum_{i=1}^{m} \alpha_{i} \phi_{i} \right\|$ 和 $\displaystyle h(\alpha) := h(\alpha_{1}, \alpha_{2}, \cdots, \alpha_{m}) = \| f - \phi \| = \left\| f - \sum_{i=1}^{m} \alpha_{i} \phi_{i} \right\|$ 
		故只需证明 $h(\alpha)$ 在 $\mathbb R^m$ 上存在最小值点 $\alpha^*$ 
		**第 2 步**：证明两个函数连续
		只证明 $g$ 连续，$h$ 同理可得
		令 $M = \max\limits_{1\le i\le m} \| \phi_i \|$，对于任意的 $\varepsilon>0$，取 $\delta = \max \left(\dfrac{\varepsilon}{mM}, \max\limits_{1\le i \le m} |\alpha_i - \beta_i| \right)$，则对于任意的 $\alpha, \beta \in \mathbb R^m$ 有
		$$
		\begin{aligned}
		| g(\alpha) - g(\beta) | =& | \|\phi_\alpha\| - \|\phi_\beta\| | \le \| \phi_\alpha - \phi_\beta \| =  \left\| \sum_{i=1}^m \alpha_i\phi_i - \sum_{i=1}^m \beta_i\phi_i \right\| \\
		=& \left\| \sum_{i=1}^m (\alpha_i - \beta_i)\phi_i \right\| \le \sum_{i=1}^m |\alpha_i - \beta_i| \| \phi_i \| \le M \sum_{i=1}^m |\alpha_i - \beta_i| \\
		\le & Mm \max\limits_{1\le i\le m} |\alpha_i - \beta_i| \le Mm\delta \le \varepsilon
		\end{aligned}
		$$
		故 $g$ 是 $\mathbb R^m$ 上的连续函数
		**第 3 步**：证明对任给的 $f \in E$，$\alpha = (\alpha_{1}, \alpha_{2}, \cdots, \alpha_{m})^{T} \in \mathbb{R}^{m}$，当 $\displaystyle\sum_{i=1}^{m} \alpha_{i}^{2} \to \infty$ 时，有 $h(\alpha) \to \infty$ 
		由于连续函数在紧集上必能取到最小值，故 $g$ 在 $\mathbb{R}^{m}$ 中的单位闭球面 $\left\{ \alpha \left| \displaystyle\sum_{i=1}^{m} \alpha_{i}^{2} = 1 \right. \right\}$ 上可达到它的最小值 $\mu$ 
		又由 $\phi_{i},\ i = 1, 2, \cdots, m$ 的线性无关性，必有 $\mu > 0$ 
		这样，若令 $\beta = \sqrt{\displaystyle\sum_{i=1}^{m} \alpha_{i}^{2}}$，则 $\displaystyle h(\alpha) \geqslant \left\| \sum_{i=1}^{m} \alpha_{i} \phi_{i} \right\| - \| f \| = \beta \left\| \sum_{i=1}^{m} \dfrac{\alpha_{i}}{\beta} \phi_{i} \right\| - \| f \| \geqslant \beta \mu - \| f \|$ 
		由此可知，当 $\displaystyle\sum_{i=1}^{m} \alpha_{i}^{2} \to \infty$ 时，$h(\alpha) \to \infty$ 
		故多元函数 $h$ 的最小值点不会出现在无穷远处。
		**第 4 步**：证明原命题
		由第 3 步 知，必存在充分大的 $r > 0$，使在闭球 $K_{r} = \left\{ \alpha \mid \displaystyle\sum_{i=1}^{m} \alpha_{i}^{2} \leqslant r^{2} \right\}$ 外，总有 $h(\alpha) = h(\alpha_{1}, \alpha_{2}, \cdots, \alpha_{m}) > \| f \|$ 
		而在闭球 $K_{r}$ 内，由 $h$ 的连续性可知，必存在点 $\alpha^{*} = ( \alpha_{1}^{*}, \alpha_{2}^{*}, \cdots, \alpha_{m}^{*} )^{T} \in \mathbb{R}^{m}$，使 $h$ 在 $\alpha^{*}$ 处达到最小值
		又 $h(\alpha_{1}^{*}, \alpha_{2}^{*}, \cdots, \alpha_{m}^{*}) = \min\limits_{\alpha \in K_{r}} h(\alpha_{1}, \alpha_{2}, \cdots, \alpha_{m}) \leqslant h(0, 0, \cdots, 0) = \| f \|$ 
		这样，综合闭球内外情况可知，$( \alpha_{1}^{*}, \alpha_{2}^{*}, \cdots, \alpha_{m}^{*} )$ 是 $h$ 在 $\mathbb{R}^{m}$ 上的最小值点，证毕！
	- 该定理回答了一般线性赋范空间最佳逼近元素的存在性问题。
- 关于其他的几个问题，以后各节会针对具体的线性赋范空间逐一讨论。
- **严格凸的**、**狭义线性赋范空间**：对 $\forall\ x, y \in E$，若 $\| x + y \| = \| x \| + \| y \|$，则存在正常数 $\alpha$ 使 $x = \alpha y$，此时，称满足此性质的范数是**严格凸**的，相应空间 $E$ 称为**狭义线性赋范空间**。
	- 需要指出的是，在一般情况下，最佳逼近元素的唯一性并不能够得到保证，它依赖于引入的范数和子空间 $H_{m}$ 的性质。
	- 可以证明对狭义线性赋范空间存在唯一的最佳逼近元素。
## 3-3 最佳一致逼近多项式
### 3-3-1 最佳一致逼近问题
- 本节主要讨论定义 3-1 所引入的最佳一致逼近问题。由 3-2 的一般描述，它可视为 $n+1$ 维代数多项式子空间 $P_{n}$ 对线性赋范空间 $C[a,b]$ 的最佳逼近。这时，$E_{n}(f) := E_{n}(f;P_{n}) = \inf\limits_{p_{n} \in P_{n}} \| f - p_{n} \| = \inf\limits_{p_{n} \in P_{n}} \max\limits_{a \leqslant x \leqslant b} | f(x) - p_{n}(x) |$ 
	- 由**存在性定理**知，最佳逼近元素是存在的。
- 现在讨论最佳一致逼近多项式的特征性质。直观上可知：最佳逼近误差应在整个逼近区间上均匀分布，即误差函数的最大、最小值大小相等符号相反，且交错分布
- **交错点组**、**交错点**（**$(e)$ 点**）：设 $f \in C[a,b]$，称满足 $a \leqslant x_{0} < x_{1} < \cdots < x_{k} \leqslant b$ 的点集 $\{ x_{i} \}_{i=0}^{k}$ 为 $f(x)$ 在 $[a,b]$ 上的**交错点组**，如果它满足 $f(x_{i}) = (-1)^{i} \sigma \| f \|, \ i = 0, 1, \cdots, k, \ \sigma = 1 \text{ 或 } -1$。我们还称 $x_i$ 为**交错点**，简称 **$(e)$ 点** 
	- *例子*：令 $f(x)=\cos 5\pi x,\ 0 \le x \le 1$，则 $x_i = i/5$，$i = 0, 1, \cdots, 5$ 构成了 $f(x)$ 在 $[0, 1]$ 上的交错点组。
- **Vallee-Poussin 定理**：设 $f \in C[a,b]$，若存在多项式 $p \in P_n$，使 $f(x) - p(x)$ 在 $[a,b]$ 上至少在 $n+2$ 个点 $x_0, x_1, \cdots, x_{n+1}$ 处的取值正负相间，则 $E_n(f) \geqslant \lambda = \min\limits_{0 \le i \le n+1} |f(x_i) - p(x_i)|$ 
	- *证明过程* 
		用反证法。设 $p_n^* \in P_n$ 为 $f(x)$ 的最佳一致逼近多项式，且 $E_n(f) < \lambda$ 
		注意到 $p_n^*(x) - p(x) = f(x) - p(x) - \left(f(x) - p_n^*(x)\right)$ 
		则 $n$ 次多项式 $p_n^* - p$ 在 $x_i$ $(i = 0, 1, \cdots, n+1)$ 处的符号完全由 $f(x_i) - p(x_i)$ 决定，故 $p_n^* - p$ 在这些点处交错地取正负值。
		于是，由介值定理知，$p_n^* - p$ 在 $[a,b]$ 上至少有 $n+1$ 个零点，因此，必有 $p_n^* \equiv p$，从而与假设矛盾。
		证毕！
	- 该定理给出了 $E_n(f)$ 的下界估计式。
- **Chebyshev 定理**：对任意函数 $f \in C[a,b]$，$f \notin P_n$，$p$ 是 $f$ 的 $n$ 次最佳一致逼近多项式 $\iff$ $f - p$ 在 $[a,b]$ 上存在至少有 $n+2$ 个点组成的交错点组。
	- *证明过程* 
		这里只给出充分性证明
		设 $f - p$ 在 $[a, b]$ 上有一交错点组 $\{ x_{i} \}_{i=0}^{n+1}$ 
		由 **Vallee-Poussin 定理**，有 $E_{n}(f) \geqslant \min\limits_{0 \leqslant i \leqslant n+1} \left| f(x_{i}) - p(x_{i}) \right| = \| f - p \|$ 
		另一方面，由最佳逼近多项式的定义知 $E_{n}(f) \leqslant \| f - p \|$ 
		结合上面两不等式，可得 $E_{n}(f) = \| f - p \|$，即 $p$ 是 $f$ 在 $[a,b]$ 上的 $n$ 次最佳一致逼近多项式。
	- 该定理可以认为是最佳一致逼近的特征定理
- **推论 1**：如果 $f \in C[a,b]$，那么，在 $P_{n}$ 中只存在一个关于 $f(x)$ 的最佳一致逼近多项式。
	- *证明过程* 
		设 $p_{1}, p_{2}$ 均为 $P_{n}$ 对 $f$ 的 $n$ 次最佳逼近多项式
		令 $p_{0} = \dfrac{p_{1} + p_{2}}{2} \in P_{n}$，则由 $\| f - p_{0} \| \leqslant \dfrac{1}{2} \left( \| f - p_{1} \| + \| f - p_{2} \| \right) = E_{n}(f)$ 可知 $p_{0}$ 也是 $f(x)$ 的最佳逼近多项式。
		这样，由**Chebyshev 定理**可知，存在交错点组 $a \leqslant x_{0} < x_{1} < \cdots < x_{n+1} \leqslant b$，使 $E_{n}(f) = \left| f(x_{i}) - p_{0}(x_{i}) \right| = \left| \dfrac{f(x_{i}) - p_{1}(x_{i})}{2} + \dfrac{f(x_{i}) - p_{2}(x_{i})}{2} \right|$ 
		但 $\left| f(x_{i}) - p_{1}(x_{i}) \right|$ 和 $\left| f(x_{i}) - p_{2}(x_{i}) \right|$ 均不大于 $E_{n}(f)$，于是有 $f(x_{i}) - p_{1}(x_{i}) = f(x_{i}) - p_{2}(x_{i}) = \sigma E_{n}(f), \quad \sigma = 1 \text{ 或 } -1$ 
		从而 $p_{1}(x_{i}) = p_{2}(x_{i})$, $i = 0, 1, \cdots, n+1$，即 $p_{1} - p_{2}$ 有 $n+2$ 个根，由此推得 $p_{1} \equiv p_{2}$，证毕！
		注意，上述证明利用了 $P_{n}$ 中的非平凡代数多项式的零点数 $\leqslant n$ 的性质，这点很重要，否则，唯一性不一定成立。
- **推论 2**：设 $p(x)$ 是 $f(x)$ 的 $n$ 次最佳一致逼近多项式，如果 $f(x)$ 在 $[a,b]$ 上有 $n+1$ 阶导数，并且 $f^{(n+1)}(x)$ 在 $[a,b]$ 上保号，那么，$f-p$ 的交错点组恰有 $n+2$ 个交错点，并且区间 $[a,b]$ 的端点属于 $f-p$ 的交错点组。
	- *证明过程* 
		假设 $f - p$ 的交错点的个数超过 $n+2$ 个，或者 $a$ 和 $b$ 中有一个不属于 $f - p$ 的交错点组，则至少有 $n+1$ 个交错点落在 $(a,b)$ 内。由于这些点是 $f - p$ 的极值点，所以在 $(a,b)$ 内存在 $n+1$ 个点 $\{ \xi_{i} \}_{i=0}^{n}$，使得 $f^{\prime}(\xi_{i}) - p^{\prime}(\xi_{i}) = 0, \ i = 0, 1, \cdots, n$ 
		反复利用 **Rolle 定理**知，必有一点 $\eta \in (a,b)$，使 $f^{(n+1)}(\eta) - p^{(n+1)}(\eta) = f^{(n+1)}(\eta) = 0$ 
		这与 $f^{(n+1)}(x)$ 在 $[a,b]$ 上保号的假设矛盾，从而推论得证！
	- 一般情况下，交错点组的确定是困难的，但当 $f(x)$ 满足一定条件时，该推论可以保证区间 $[a,b]$ 的两个端点一定是交错点。
- 至此，已就最佳一致逼近问题中的几个主要理论问题进行了比较系统的讨论。
	- 虽然 **Chebyshev 定理**从理论上给出了最佳一致逼近的特征性质，但在一般情况下，求最佳一致逼近多项式是很困难的，通常只能近似计算。
### 3-3-2 Remes 算法
- **Remes (列梅兹) 算法**：下面简要介绍一种最常用的求解近似最佳一致逼近多项式的算法——**Remes (列梅兹) 算法** 
- 设 $f(x)$ 的 $n$ 次最佳一致逼近多项式为 $p_{n}^{*}(x) = \displaystyle\sum_{i=0}^{n} a_{i}^{*} x^{i}$，由前面分析知 $f - p_{n}^{*}$ 在 $[a,b]$ 上存在 $n+2$ 个 $(e)$ 点 $\{ x_{i} \}_{i=0}^{n+1}$，使 $p_{n}^{*}(x_{i}) - f(x_{i}) = (-1)^{i} \mu, \ i = 0, 1, \cdots, n+1 \quad (*)$，其中 $\mu = \sigma E_{n}(f),\ \sigma = 1 \text{ 或 } -1$ 
	- 由式 $(*)$ 可见，求 $p_{n}^{*}(x)$ 的关键在于寻找这 $n+2$ 个 $(e)$ 点，因为一旦找到该交错点组后，就可由线性代数方程组 $(*)$ 唯一地解出最佳逼近多项式 $p_{n}^{*}(x)$ 的系数和最佳逼近值 $E_{n}(f)$。下面介绍的 **Remes 算法**将给出寻找交错点组近似值的一种方法，它属于逐次逼近法。
- *Remes 算法步骤*：
	1. **步骤 1**：给定精度 $\varepsilon > 0$，在区间 $[a,b]$ 上任选点集 $a \leqslant x_{0}^{0} < x_{1}^{0} < \cdots < x_{n+1}^{0} \leqslant b$ 代入方程组 $(*)$，求得逼近多项式 $p_{0}(x) = \displaystyle\sum_{i=0}^{n} a_{i}^{0} x^{i}$ 及 $\mu^{0}$ 
	2. **步骤 2**：设在第 $l$ 步 $(l \geqslant 0)$ 已有 $\mu^{l}$，$[a, b]$ 上的点集 $X^{(l)} = \{ x_{i}^{l} \}_{i=0}^{n+1}$ 及逼近多项式 $p_{l}(x) = \displaystyle\sum_{i=0}^{n} a_{i}^{l} x^{i}$，令 $v^{l} := \max\limits_{a \leqslant x \leqslant b} \left| f(x) - p_{l}(x) \right| = \left| f(\hat{x}^{l}) - p_{l}(\hat{x}^{l}) \right|$。若 $v^{l} - |\mu^{l}| < \varepsilon$，则算法结束；这时，点集 $X^{(l)}$ 可作为所需的 $f - p_{n}^{*}$ 的近似交错点组，$p_{l}(x)$ 可作为 $p_{n}^{*}$ 的近似最佳一致逼近多项式。否则，分以下情况，通过用 $\hat{x}^{l}$ 替换 $X^{(l)}$ 的某一点，得到新的点集 $X^{(l+1)}$ 
		- **情况 1**：当 $\hat{x}^{l} \in (x_{j}^{l}, x_{j+1}^{l}),\ 0 \leqslant j \leqslant n$ 时，如果 $f(x_{j}^{l}) - p_{l}(x_{j}^{l})$ 与 $f(\hat{x}^{l}) - p_{l}(\hat{x}^{l})$ 同号，则在 $X^{(l)}$ 中将点 $\hat{x}^{l}$ 置换点 $x_{j}^{l}$，否则将点 $\hat{x}^{l}$ 置换点 $x_{j+1}^{l}$ 
		- **情况 2**：当 $\hat{x}^{l} < x_{0}^{l}$ 时，如果 $f(\hat{x}^{l}) - p_{l}(\hat{x}^{l})$ 与 $f(x_{0}^{l}) - p_{l}(x_{0}^{l})$ 同号，则在 $X^{(l)}$ 中将点 $\hat{x}^{l}$ 置换点 $x_{0}^{l}$；否则取如下新的点集 $\{ \hat{x}^{l}, x_{0}^{l}, \cdots, x_{n}^{l} \}$ 来置换点集 $X^{(l)} = \{ x_{0}^{l}, x_{1}^{l}, \cdots, x_{n+1}^{l} \}$ 
		- **情况 3**：当 $\hat{x}^{l} > x_{n+1}^{l}$ 时，可同情况 2，作类似的处理。
	3. **步骤 3**：将新的点集 $X^{(l+1)} = \{ x_{i}^{l+1} \}_{i=0}^{n+1}$ 代入方程组 $(*)$，求得 $p_{l+1}(x) = \displaystyle\sum_{i=0}^{n} a_{i}^{l+1} x^{i}$ 及 $\mu^{l+1}$；令 $l := l+1$，返回**步骤 2** 
- 关于上述 Remes 算法，给出一些评注。
	- *注 1*：若 $f^{(n+1)}(x)$ 于 $[a,b]$ 保号，则总可将迭代点集 $X^{(l)}$ 的首尾点分别取为区间的端点 $a$ 和 $b$；而初始点集 $X^{0}$ 通常可取为 $n+1$ 次 Chebyshev 多项式的交错点组。
	- *注 2*：步骤 2 中的最大值点 $\hat{x}^{l}$ 一般只能近似求出；另外，关于算法结束的条件，并不仅限于我们这里给出的 $v^{l} - |\mu^{l}| < \varepsilon$ 
	- *注 3*：本算法中，每迭代一步，只改变点集 $X^{(l)}$ 中的一个点，所以称之为 Remes 第一算法。类似还可一次变动多个点，相应的算法称为 Remes 第二算法；另外，Remes 算法对初值的选取不敏感，并且收敛速度也是相当快的。
- *缺点*：由于 Remes 算法的计算量较大，所以，实际计算中，常使用其他近似方法，其中一类重要的近似方法将用到所谓的 Chebyshev 多项式。
## 3-4 与零偏差最小的多项式——Chebyshev 多项式
### 3-4-1 问题的引入
- 本节将讨论在区间 $[-1,1]$ 上，子空间 $P_{n-1}$ 对函数 $x^{n}$ 的最佳一致逼近问题。它可描述为：求 $p_{n-1}^{*} \in P_{n-1}$，使之满足 $E_{n-1}(x^{n}) = \min\limits_{p_{n-1} \in P_{n-1}} \| x^{n} - p_{n-1} \| = \| x^{n} - p_{n-1}^{*} \|$，其中，范数 $\| f \| = \max\limits_{-1 \leqslant x \leqslant 1} |f(x)|$ 
- 记集合 $P_{n}^{1}$ 为所有首项系数为 $1$ 的 $n$ 次代数多项式的全体，则上述最佳逼近问题等价于问题：求 $p_{n}^{*} \in P_{n}^{1}$，使之满足 $\| p_{n}^{*} - 0 \| = \min\limits_{p_{n} \in P_{n}^{1}} \| p_{n} - 0 \|$ 
- 因此，常称上述最佳逼近问题为**与零偏差最小问题**。利用前面一般理论，我们可圆满地解决该最佳逼近问题。
### 3-4-2 Chebyshev 多项式
- **Chebyshev 多项式**：考虑变换 $x = \cos \theta$，它为 $[0, \pi] \rightarrow [-1, 1]$ 上的一一映射，则 $T_{n}(x) = \cos n\theta = \cos (n \arccos x), \ n = 0, 1, \cdots$ 即为 **Chebyshev 多项式** 
- **性质 1**（**递推公式**）：$\left\{ \begin{array}{l} T_{n}(x) = 2x T_{n-1}(x) - T_{n-2}(x), \quad n = 2, 3, \cdots, \\ T_{0}(x) = 1, \quad T_{1}(x) = x \end{array} \right.$ 
	- *证明过程* 
		由三角恒等式 $\cos n\theta + \cos (n-2)\theta = 2\cos\theta \cos (n-1)\theta$ 可知上述性质成立！
- **性质 2**：$T_{n}(x)$ 是首项系数为 $2^{n-1}$ 的 $n$ 次代数多项式，且 $T_{2k}(x)$ 只含 $x$ 的偶次幂，$T_{2k-1}(x)$ 只含 $x$ 的奇次幂。
	- *证明过程* 
		由递推公式即可得到
- 进一步，还可给出函数系 $\{ T_{k}(x) \}_{0}^{n}$ 和幂函数系 $\{ x^{k} \}_{0}^{n}$ 的互为表示式。为今后应用方便起见，给出下表

- **定理**：在首项系数为 $1$ 的所有 $n$ 次多项式中，$p_{n}^{*}(x) = 2^{1-n} T_{n}(x)$ 对零的偏差最小。
	- *证明过程* 
		由式 $T_{n}(x) = \cos n\theta = \cos (n \arccos x), \ n = 0, 1, \cdots$ 知，当 $\theta_{k} = \dfrac{k\pi}{n}$，即 $x_{k} = \cos \dfrac{k\pi}{n}$ $(k = 0, 1, \cdots, n)$ 时，$T_{n}(x)$ 在 $x_{k}$ 处交错地取最大值 $1$ 和最小值 $-1$ 
		这样，由 Chebyshev 定理知，$p_{n-1}^{*} = x^{n} - 2^{1-n} T_{n}(x)$ 是 $f = x^{n}$ 在 $[-1,1]$ 上的 $n-1$ 次最佳逼近多项式。
		再由与零最小偏差问题的提法，定理得证！
	- **推论**：设 $p_{n}(x)$ 是首项系数为 $1$ 的 $n$ 次多项式，则 $\| p_{n} \| = \max\limits_{|x| \leqslant 1} |p_{n}(x)| \geqslant 2^{1-n}$
- **性质 3**：Chebyshev 多项式序列 $\{ T_{k}(x) \}_{0}^{n}$ 在区间 $[-1,1]$ 上关于权函数 $\dfrac{1}{\sqrt{1-x^{2}}}$ 正交，且有 $\displaystyle \int_{-1}^{1} \dfrac{T_{m}(x) T_{n}(x)}{\sqrt{1-x^{2}}} dx = \begin{cases} 0 & m \neq n \\ \pi / 2  & m = n \neq 0, \\ \pi & m = n = 0 \end{cases}$ 
- **性质 4**：$T_n(x)$ 在区间 $[-1, 1]$ 上恰有 $n$ 个不同的实根 $x_k = \cos  \dfrac{(2k-1)\pi}{2n},\ k=1,2,\cdots,n$ 
### 3-4-3 Chebyshev 多项式应用：代数插值多项式余项的极小化
- *前置知识*：由第 2 章知，函数 $f(x)$ 关于 $[-1, 1]$ 上彼此互异的节点 $x_{0}, x_{1}, \cdots, x_{n}$ 的 $n$ 次插值多项式 $p_{n}(x)$，有余项估计式 $\left\| f - p_{n} \right\| \leqslant \dfrac{\left\| f^{(n+1)} \right\|}{(n+1)!} \max\limits_{|x| \leqslant 1} \left| \left( x - x_{0} \right) \left( x - x_{1} \right) \cdots \left( x - x_{n} \right) \right|$ 
- **代数插值多项式余项的极小化***问题*是：如何选取节点 $x_{i},\ i = 0, 1, \cdots, n$，使 $\max\limits_{|x| \leqslant 1} \left| \left( x - x_{0} \right) \left( x - x_{1} \right) \cdots \left( x - x_{n} \right) \right|$ 尽可能地小。换句话说，是在首项系数为 $1$ 的 $n+1$ 次多项式中，寻找与零偏差最小的代数多项式。
- *结论*：当上述插值节点取成 $n+1$ 次 Chebyshev 多项式的零点时，即 $x_{k} = \cos \dfrac{(2k-1)\pi}{2(n+1)}, \ k = 1, 2, \cdots, n+1$，$\max\limits_{|x|\leqslant 1} \left| (x-x_{0}) \cdots (x-x_{n}) \right|$ 可达到最小，这时有截断误差估计 $\left| f(x) - p_{n}(x) \right| \leqslant \dfrac{\left\| f^{(n+1)} \right\|}{(n+1)!} \cdot 2^{-n} \left\| T_{n+1} \right\| = \dfrac{\left\| f^{(n+1)} \right\|}{(n+1)!} \cdot 2^{-n}$ 
- *注意*：由估计式 $\left| f(x) - p_{n}(x) \right| \leqslant \dfrac{\left\| f^{(n+1)} \right\|}{(n+1)!} \cdot 2^{-n}$ 知，当 $f^{(n+1)}(x)$ 在 $[-1,1]$ 上变化不大时，$p_{n}(x)$ 可作为 $f(x)$ 的近似最佳逼近多项式。
- *注意*：另外，如果插值区间是 $[a,b]$，不是 $[-1,1]$，经过简单仿射变换，上述插值节点可取为 $x_{k} = \dfrac{a+b}{2} + \dfrac{b-a}{2} \cos \dfrac{(2k-1)\pi}{2(n+1)}, \ k = 1, 2, \cdots, n+1$ 
### 3-4-4 Chebyshev 多项式应用：降低近似多项式项数
- Taylor 逼近是一种局部逼近，现利用 Chebyshev 多项式，可对它进行改造，以提高计算效率和改善其整体逼近效果。
- *例子*：现以 $e^{-x}$ 的 Taylor 展开为例说明该过程是如何进行的
	- 在 $[-1,1]$ 上函数 $e^{-x}$ 的 Taylor 展开式的前 13 项为 $e^{-x} \approx p_{12}(x) := 1 - x + \dfrac{x^{2}}{2!} - \dfrac{x^{3}}{3!} + \cdots + \dfrac{x^{12}}{12!}$
	- 由表 3-2 知，上式可由 Chebyshev 多项式 $T_{0}, \cdots, T_{12}$ 表成：
		$$
		\begin{aligned}
		p_{12}(x) \approx& \, 1.2661\,T_{0} - 1.1303\,T_{1} + 0.2715\,T_{2} + 0.0443\,T_{3} \\
		+& \, 0.005474\,T_{4} - 0.000543\,T_{5} + 0.000045\,T_{6} \\
		-& \, 0.000003198436\,T_{7} + 0.000000199212\,T_{8} \\
		-& \, 0.000000011037\,T_{9} + 0.000000000550\,T_{10} \\
		-& \, 0.00000000025\,T_{11} + 0.00000000001\,T_{12}.
		\end{aligned}
		$$
	- 可见 $k$ 越大，$T_{k}(x)$ 的系数就越小，由于 $|T_{k}(x)| \leqslant 1$，因此可略去含次数高的 $T_{k}(x)$ 的项。这时，逼近多项式的次数降低了，从而大大节省了计算工作量。
	- 例如，为了求 $[-1,1]$ 上逼近 $e^{-x}$ 的绝对误差不超过 $0.00005$ 的代数多项式，只需取 $T_{5}(x)$ 以前的项作近似。这时，将 $T_{0}(x), \cdots, T_{5}(x)$ 用 $1, x, \cdots, x^{5}$ 表示，则有 $\begin{aligned} e^{-x} \approx \phi_{5}(x) :=& \, 1.000045 - 1.000022x + 0.499199x^{2} \\ -& \, 0.166488x^{3} + 0.043794x^{4} - 0.008687x^{5} \end{aligned}$ 
	- 而若按 Taylor 展开式 (3.11) 截断到 $x^{5}$ 这一项则有 $e^{-x} \approx p_{5}(x) := 1 - x + \dfrac{x^{2}}{2!} - \dfrac{x^{3}}{3!} + \dfrac{x^{4}}{4!} - \dfrac{x^{5}}{5!}$。这时，$\left| e^{-x} - p_{5}(x) \right| \leqslant \dfrac{1}{6!} + \dfrac{1}{7!} + \cdots \approx 0.0016$，约为前者绝对误差的 $33$ 倍。

## 3-5 内积空间的最佳逼近
- **最佳逼近 $E(f)$**、**最佳逼近元素**：设 $X$ 为一内积空间，$M \subseteq X$ 为有限维子空间，对 $\forall\ f \in X$，称量 $E(f; M) = \inf\limits_{\phi \in M} \| f - \phi \|$ 为**子空间 $M$ 对元素 $f$ 的最佳逼近**，并简记为 $E(f)$。而使式 $E(f; M) = \inf\limits_{\phi \in M} \| f - \phi \|$ 成立的元素 $\phi^{*} \in M$（即满足 $E(f) = \| f - \phi^{*} \|$），称为 **$f$ 的最佳逼近元素**。这里范数由内积空间 $X$ 的内积定义导出。
- **定理**：对 $\forall\ f \in X$，在 $M$ 中存在 $f$ 的唯一最佳逼近元素。
	- *证明过程* 
		用反证法。设在 $M$ 中有两个不同的最佳逼近元素 $\phi_{1}^{*}, \phi_{2}^{*}$，令 $\phi_{0}^{*} = \dfrac{\phi_{1}^{*} + \phi_{2}^{*}}{2}$，并记 $\mu = \| f - \phi_{1}^{*} \| = \| f - \phi_{2}^{*} \|$ 
		则有 $\mu \leqslant \left\| f - \dfrac{1}{2} \left( \phi_{1}^{*} + \phi_{2}^{*} \right) \right\| \leqslant \dfrac{1}{2} \left\| f - \phi_{1}^{*} \right\| + \dfrac{1}{2} \left\| f - \phi_{2}^{*} \right\| = \mu$，即 $\phi_{0}^{*}$ 亦为 $f$ 的最佳逼近元素。
		这样由**性质 2** 可推得
		$$
		\begin{aligned}
		\mu^{2} &= \left\| f - \phi_{0}^{*} \right\|^{2} = \left\| \frac{f - \phi_{1}^{*}}{2} + \frac{f - \phi_{2}^{*}}{2} \right\|^{2} \\
		&= \frac{1}{2} \left( \left\| f - \phi_{1}^{*} \right\|^{2} + \left\| f - \phi_{2}^{*} \right\|^{2} \right) - \left\| \frac{f - \phi_{1}^{*}}{2} - \frac{f - \phi_{2}^{*}}{2} \right\|^{2} \\
		&= \mu^{2} - \frac{1}{4} \left\| \phi_{1}^{*} - \phi_{2}^{*} \right\|^{2}.
		\end{aligned}
		$$
		因此，$\phi_{1}^{*} \equiv \phi_{2}^{*}$，这与假设矛盾。证毕！
- **定理**：对于任意的 $f \in X$，设 $M \subseteq X$ 为有限维子空间。$\phi^{*} \in M$ 是 $f$ 的最佳逼近元素 $\iff$ 误差元素 $f - \phi^{*}$ 与 $M$ 中的任意元素正交，即 $\left( f - \phi^{*}, \phi \right) = 0, \ \forall\ \phi \in M$ 
	- *证明过程* 
		**必要性** 
		证明其逆否命题
		设存在某一 $\phi \in M$，使 $(f - \phi^{*}, \phi) \neq 0$，令 $\varphi = \dfrac{\phi}{\|\phi\|}, \ \alpha = (f - \phi^{*}, \varphi)$，则：
		$$
		\begin{aligned}
		\| f - \phi^{*} - \alpha\varphi \|^{2} &= (f - \phi^{*} - \alpha\varphi, f - \phi^{*} - \alpha\varphi) \\
		&= \| f - \phi^{*} \|^{2} - 2\alpha (f - \phi^{*}, \varphi) + \alpha^{2} \\
		&= \| f - \phi^{*} \|^{2} - \alpha^{2} < \| f - \phi^{*} \|^{2}
		\end{aligned}
		$$
		这表明 $\phi^{*}$ 不是 $f$ 的最佳逼近元素，从而必要性得证！
		**充分性** 
		若对 $\forall\ \phi \in M$，有 $(f - \phi^{*}, \phi) = 0$，则：
		$$
		\begin{aligned}
		\| f - \phi \|^{2} - \| f - \phi^{*} \|^{2} &= \|\phi\|^{2} - \|\phi^{*}\|^{2} - 2(f, \phi) + 2(f, \phi^{*}) \\
		&= \|\phi - \phi^{*}\|^{2} + 2(f - \phi^{*}, \phi^{*} - \phi) \\
		&= \|\phi - \phi^{*}\|^{2} \geqslant 0
		\end{aligned}
		$$
		因此，$\phi^{*}$ 为 $f$ 的最佳逼近元素。充分性得证！
	- 该定理刻画了内积空间最佳逼近元素的特征性质
	- 该定理的几何意义见下图，从图中可见，$f$ 在 $M$ 中的正交投影 $\phi^{*}$ 便是 $f$ 的最佳逼近元素。
		![[Pasted image 20260205104748.png|180]]
	- **推论**：最佳逼近值有表达式 $E^2(f; M) = (f,f) - (f,\phi^*)$ 
- **法方程组**（**正规方程组**）：设 $X$ 的 $n$ 维子空间 $M = \operatorname{span} \{ \phi_{1}, \phi_{2}, \cdots, \phi_{n} \}$，且 $\phi_{1}, \phi_{2}, \cdots, \phi_{n}$ 是 $X$ 的线性无关元素系。对 $\forall\ f \in X$，设其最佳逼近元素 $\phi^{*}$ 可表示为 $\phi^{*} = \sum\limits_{i=1}^{n} c_{i}^{*} \phi_{i}$，由上面定理有 $\left( f - \sum\limits_{i=1}^{n} c_{i}^{*} \phi_{i}, \phi_{j} \right) = 0, \ j = 1, 2, \cdots, n$，即 $\sum\limits_{i=1}^{n} (\phi_{i}, \phi_{j}) c_{i}^{*} = (f, \phi_{j}), \ j = 1, 2, \cdots, n$，称 $\sum\limits_{i=1}^{n} (\phi_{i}, \phi_{j}) c_{i}^{*} = (f, \phi_{j}), \ j = 1, 2, \cdots, n$ 为最佳逼近元素的**法方程组**（或**正规方程组**）。
	- 记 $n \times n$ 阶对称矩阵 $G = \begin{bmatrix} (\phi_{1}, \phi_{1}) & (\phi_{1}, \phi_{2}) & \cdots & (\phi_{1}, \phi_{n}) \\ (\phi_{2}, \phi_{1}) & (\phi_{2}, \phi_{2}) & \cdots & (\phi_{2}, \phi_{n}) \\ \vdots & \vdots & & \vdots \\ (\phi_{n}, \phi_{1}) & (\phi_{n}, \phi_{2}) & \cdots & (\phi_{n}, \phi_{n}) \end{bmatrix}$，利用 $\{ \phi_{i} \}_{i=1}^{n}$ 的线性无关性，容易证明矩阵 $G$ 是正定的。因此，法方程组 $\sum\limits_{i=1}^{n} (\phi_{i}, \phi_{j}) c_{i}^{*} = (f, \phi_{j}), \ j = 1, 2, \cdots, n$ 的解存在且唯一。
- **正交基**、**广义 Fourier 展开**、**广义 Fourier 系数**：从法方程组可见，若 $\phi_1, \phi_2, \cdots, \phi_n$ 两两正交（这时称该元素系为空间 $M$ 的**正交基**），则矩阵 $G$ 成为对角矩阵,这样可直接得解。这时，最佳逼近元素为 $\phi^* = \sum\limits_{j=1}^n \dfrac{(f, \phi_j)}{(\phi_j, \phi_j)}\phi_j$，称 $\phi^* = \sum\limits_{j=1}^n \dfrac{(f, \phi_j)}{(\phi_j, \phi_j)}\phi_j$ 为 $f$ 的**广义 Fourier 展开**，相应的系数称为**广义 Fourier 系数** 
- **Bessel 不等式**：$\sum\limits_{i=1}^{\infty} \left( c_{i}^{*} \right)^{2} \| \phi_{i} \|^{2} \leqslant \| f \|^{2},\ c_{i}^{*} = (f, \phi_{i}) / (\phi_{i}, \phi_{i})$ 
	- *证明过程* 
		利用 $\{ \phi_{i} \}_{i=1}^{n}$ 的正交性，由式 $E^2(f; M) = (f,f) - (f,\phi^*)$ 有 $\| f - \phi^{*} \|^{2} = \| f \|^{2} - \sum\limits_{i=1}^{n} \left( c_{i}^{*} \right)^{2} \| \phi_{i} \|^{2}$，其中 $c_{i}^{*} = (f, \phi_{i}) / (\phi_{i}, \phi_{i})$ 
		由此并令 $n \to \infty$，便得 Bessel 不等式，证毕！
	- **广义 Parseval (帕塞瓦尔) 等式**：特别地，若最佳逼近元素序列收敛于 $f$，则上述不等式成为等式，称之为**广义 Parseval (帕塞瓦尔) 等式** 
- **定理**：任何 $n$ 维内积空间 $M$ 都存在正交基。
	- *证明过程* 
		下面从 $\phi_{1}, \phi_{2}, \cdots, \phi_{n}$ 出发，通过所谓的 **Gram–Schmidt (格拉姆–施密特) 正交化过程**，构造出 $M$ 的正交基 $e_{1}, e_{2}, \cdots, e_{n}$。具体做法如下：
		令 $e_{1} = \phi_{1}$，求元素 $e_{2} = \phi_{2} + \alpha e_{1}$，使 $(e_{1}, e_{2}) = 0$ 
		经简单计算知，待定系数 $\alpha = - (\phi_{2}, e_{1}) / (e_{1}, e_{1})$ 
		因为 $\phi_{2}$ 与 $e_{1}$ 线性无关，所以 $e_{2}$ 与 $e_{1}$ 线性无关，当然不是零向量
		设已构造了 $k-1$ 个两两正交且异于零的向量 $e_{1}, e_{2}, \cdots, e_{k-1}$，它们与 $\phi_{1}, \phi_{2}, \cdots, \phi_{k-1}$ 互为线性表出。
		现求 $e_{k}$，它具有形式  $e_{k} = \phi_{k} + \lambda_{k-1}e_{k-1} + \cdots + \lambda_{1}e_{1}$，使 $e_{k}$ 与 $e_{j}$ $(j = 1, 2, \cdots, k-1)$ 均正交，即 $(e_{k}, e_{j}) = 0, \ j = 1, 2, \cdots, k-1$ 
		将 $e_{k} = \phi_{k} + \lambda_{k-1}e_{k-1} + \cdots + \lambda_{1}e_{1}$ 代入 $(e_{k}, e_{j}) = 0, \ j = 1, 2, \cdots, k-1$，并注意 $e_{1}, e_{2}, \cdots, e_{k-1}$ 两两正交，可得 $\lambda_{j} = -\dfrac{(\phi_{k}, e_{j})}{(e_{j}, e_{j})}, \ j = 1, 2, \cdots, k-1$ 
		由 $\phi_{k}$ 与 $e_{1}, e_{2}, \cdots, e_{k-1}$ 线性无关，知 $e_{k}$ 不是零向量。
		将上述正交化过程进行下去，最后可得正交元素系 $e_{1}, e_{2}, \cdots, e_{n}$，它构成了 $M$ 的一组正交基。
		从而定理得证！
	- **正规化的正交基**：进一步，如将 $e_{k}$ 换成 $e_{k}' = \dfrac{e_{k}}{\| e_{k} \|}$，就得到了长度为 $1$ 的正交基，称为**正规化的正交基**。
	- 该定理保证了：关于有限维空间正交基的存在性
## 3-6 最佳平方逼近与正交多项式
### 3-6-1 连续情形的最佳平方逼近
- **连续情形的最佳平方逼近问题**：本节主要讨论内积空间 $L_{\rho}^{2}[a,b]$ 中的最佳多项式逼近问题，称之为**连续情形的最佳平方逼近问题** 
- *假设*：对于 $L_{\rho}^{2}[a,b]$ 空间（当 $\rho(x)$ 取 $1$ 时，简记为 $L^{2}[a,b]$），相应的内积及范数分别为 $\displaystyle (f,g) = \int_{a}^{b} \rho(x) f(x) g(x) \mathrm dx,\ \forall\ f,g\in L_{\rho}^{2}[a,b]$，$\|f\|=\sqrt{(f,f)},\ \forall\ f\in L_{\rho}^{2}[a,b]$。
- *方法*：对 $\forall\ f\in L_{\rho}^{2}[a,b]$，在 $n+1$ 维多项式子空间 $P_{n}$ 中，存在唯一最佳平方逼近多项式：$p_{n}^{*}(x) = \sum\limits_{j=0}^{n} a_{j}^{*} x^{j}$，其中系数 $\{a_{i}^{*}\}_{i=0}^{n}$ 满足法方程组 $\sum\limits_{j=0}^{n}(x^{i},x^{j})a_{j}^{*}=(f,x^{i}),\ i=0,1,\cdots,n$，其中 $\displaystyle (x^{i},x^{j}) = \int_{a}^{b} \rho(x) x^{i+j} \mathrm dx,\ (f,x^{i}) = \int_{a}^{b} \rho(x) f(x) x^{i} \mathrm dx$ 
- *缺点*：上面利用 $P_n$ 的幂函数基 $x^k\ (k=0,1,\cdots,n)$ 求最佳平方逼近多项式。当 $n$ 较大时，法方程组 $\sum\limits_{j=0}^{n}(x^{i},x^{j})a_{j}^{*}=(f,x^{i})$ 的系数矩阵是高度病态的，因此求解时，舍入误差很大。
- *改进方法*：这时，最好利用下面引入的正交多项式基函数，可保证计算的可靠性。另外，正交多项式本身在其他领域也有重要的应用。
### 3-6-2 正交多项式
#### 3-6-2-1 带权正交多项式的概念
- **带权正交基**、**带权正交多项式**：定义在 $[a, b]$ 上的函数系 $\{ g_{l}(x)\}_{l=0}^{n}$ 称为 $P_{n}$ 的**带权 $\rho(x)$ 正交基**（$g_{l}(x)$ 称为 $[a, b]$ 上的**带权 $l$ 次正交多项式**），如果它满足：
	(1) $g_{l}(x)=\sum\limits_{k=0}^{l}\alpha_{k}x^{k}$ 恰为 $l$ 次多项式，即 $\alpha_{l}\neq0$ 
	(2) $(g_{i},g_{j}) = \begin{cases}  0, & i\neq j \\ \displaystyle\int_{a}^{b}\rho(x)g_{i}^{2}(x)dx > 0, & i=j \end{cases}$ 
	- **正规正交基**：特别地，若 $(g_{i},g_{i}) = 1$，$i = 0,1,\cdots,n$，则称 $\{ g_{l}(x)\}_{l=0}^{n}$ 为 $[a, b]$ 上 $P_{n}$ 的**正规正交基** 
- **性质**：对任给的 $k$ 次多项式 $p_{k}(x)$ 有 $(p_{k},g_{l}) = 0,\ l>k$
- **性质**：记 $g_{l}^{*}(x) = g_{l}(x)/\alpha_{l},\ l = 0,1,\cdots,n$，则 $\{ g_{l}^{*}\}_{l=0}^{n}$ 构成了 $P_{n}$ 的首项系数为 $1$ 的带权正交多项式基。
- **定理**（**递推公式**）：上述带权正交基有递推公式 $\begin{cases} g_{k+1}^{*}(x) = (x-\beta_{k})g_{k}^{*}(x) - \alpha_{k}g_{k-1}^{*}(x), & k = 1,2,\cdots,n-1 \\ g_{0}^{*}(x) = 1, & g_{1}^{*}(x) = x-(xg_{0}^{*},g_{0}^{*})/(g_{0}^{*},g_{0}^{*}) \end{cases}$，其中常数 $\beta_k = \dfrac{(xg_k^*, g_k^*)}{(g_k^*, g_k^*)},\ \alpha_k = \dfrac{(g_k^*, g_k^*)}{(g_{k-1}^*, g_{k-1}^*)}$ 
- **定理**：带权正交多项式 $g_l^*(x)\ (l\ge 1)$ 有 $l$ 个互异的实根，并且全部位于区间 $(a,b)$ 内
	- *证明过程* 
		由递推公式和反证法可证
- **定理**：设 $\{ g_{l}(x)\}_{l=0}^{n}$ 为带权正交多项式系。对 $l\ge 1$，多项式 $g_{l}(x)$ 和 $g_{l+1}(x)$ 的零点必交错，即若 $\xi_{1}<\xi_{2}<\cdots<\xi_{l}$，$\eta_{1}<\eta_{2}<\cdots<\eta_{l+1}$ 分别为 $g_{l}(x)$ 和 $g_{l+1}(x)$ 的零点，则 $a<\eta_{1}<\xi_{1}<\eta_{2}<\xi_{2}<\cdots<\xi_{l}<\eta_{l+1}<b$ 
	- *证明过程* 
		由递推公式和数学归纳法可证
#### 3-6-2-2 几类特殊重要的带权正交多项式 
1. **Legendre (勒让德) 多项式**：设 $\rho(x)\equiv 1$，$\{ l_{i}(x)\}_{0}^{n}$ 为 $[-1,1]$ 上 $P_{n}$ 的正规正交基，则称 $l_{i}(x)$ 为 **Legendre 多项式** 
	- *计算公式*：利用正交多项式的定义，可直接构造 Legendre 多项式，具体表达式为 $l_{k}(x)=\dfrac{1}{2^{k}k!}\cdot\sqrt{\dfrac{2k+1}{2}}\cdot\dfrac{\mathrm{d}^{k}}{\mathrm{~d} x^{k}}\left[\left(x^{2}-1\right)^{k}\right],\ k=0,1,\cdots,n$ 
	- *递推公式*：实用中，由于求高阶导数较麻烦，所以常按以下递推公式计算：$l_{k+1}(x)=\dfrac{\sqrt{(2k+1)(2k+3)}}{k+1}xl_{k}(x)-\dfrac{k}{k+1}\sqrt{\dfrac{2k+3}{2k-1}}l_{k-1}(x),\ k = 1, 2,\cdots$ 
	- **性质**：当 $k$ 为偶数时，$l_{k}(x)$ 为偶函数；当 $k$ 为奇数时，$l_{k}(x)$ 为奇函数。（由递推公式及数学归纳法可以证明该性质）
2. **第一类 Chebyshev 多项式**：Chebyshev 多项式 $T_{j}(x)=\cos (j\arccos x),\ j=0,1,\cdots$ 是区间 $[-1,1]$ 上带权 $\rho(x)=(1-x^{2})^{-1/2}$ 的 $j$ 次正交多项式。由上式定义的多项式又称为**第一类 Chebyshev 多项式** 
3. **第二类 Chebyshev 多项式**：$U_{n}(x)=\dfrac{\sin((1+n)\arccos x)}{\sqrt{1-x^{2}}},\ n=0,1,\cdots$，它是区间 $[-1,1]$ 上带权 $(1-x^{2})^{1/2}$ 的 $n$ 次正交多项式。
4. **Laguerre (拉盖尔) 多项式**：$L_{n}(x)=\mathrm{e}^{x}\dfrac{\mathrm{d}^{n}}{\mathrm{d} x^{n}}\left(x^{n}\cdot\mathrm{e}^{-x}\right),\ n=0,1,\cdots$，它是区间 $[0,+\infty)$ 上带权 $e^{-x}$ 的 $n$ 次正交多项式
5. **Hermite 多项式**：$H_n(x) = (-1)^n e^{x^2} \dfrac{\mathrm d^n}{\mathrm dx^n} (e^{-x^2}),\ n=0,1,\cdots$，它是区间 $(-\infty, +\infty)$ 上带权 $e^{-x^2}$ 的 $n$ 次正交多项式
### 3-6-3 正交多项式的重要应用：近似 Chebyshev 逼近
- *结论*：$L_{\rho}^{2}[-1,1]$ 的 $n$ 次最佳平方逼近多项式 $S_{n}(x)=a_{0}\dfrac{T_{0}(x)}{2}+\sum\limits_{j=1}^{n}a_{j}T_{j}(x)$，其中 $\displaystyle a_{j}=\dfrac{(f, T_{j})}{(T_{j},T_{j})}=\dfrac{2}{\pi}\int_{-1}^{1}\dfrac{f(x)T_{j}(x)}{\sqrt{1-x^{2}}}\mathrm dx,\ j=0,1,\cdots$ 
	- *证明过程* 
		利用带权 $\rho(x)=(1-x^{2})^{-1/2}$ 的 Chebyshev 正交多项式和 $\phi^* = \sum\limits_{j=1}^n \dfrac{(f, \phi_j)}{(\phi_j, \phi_j)}\phi_j$ 可证 
	- **按 Chebyshev 多项式展开的部分和**：称 $S_{n}(x)=a_{0}\dfrac{T_{0}(x)}{2}+\sum\limits_{j=1}^{n}a_{j}T_{j}(x)$ 为函数 $f(x)$ **按 Chebyshev 多项式展开的部分和** 
- *性质 1*：对于 $\forall\ f\in C^{1}[-1,1]$，当 $n\rightarrow+\infty$ 时，$S_{n}(x)$ 一致收敛于 $f(x)$，
	- **Chebyshev 级数**：称 $S_n(x)$ 称为 $f(x)$ 的 **Chebyshev 级数** 
- *性质 2*：Chebyshev 多项式展开式的系数 $a_{k}$ 随着 $k$ 的增大，迅速趋向于零。
- *性质 3*：$S_{n}(x)$ 可作为 $f(x)$ 的近似 Chebyshev 逼近多项式
	- *证明过程* 
		由上面性质可知，当 $n$ 充分大时，$f(x)-S_{n}(x)\approx a_{n+1}T_{n+1}(x)$ 
		因为 $T_{n+1}(x)$ 在 $[-1,1]$ 上具有 $n+2$ 个交错点，所以由 Chebyshev 定理即证原命题
## 3-7 最佳逼近的应用：Gauss 型数值积分
### 3-7-1 问题引入
- 考虑带权积分 $\displaystyle I=\int_{a}^{b} \rho(x) f(x) \mathrm{d} x$，其中权函数 $\rho(x) \geqslant 0$。特别地，当 $\rho(x) \equiv 1$ 时即为普通的积分。
- 可以仿照处理普通积分的方法讨论带权积分的数值积分问题。考虑求积公式 $\displaystyle \int_{a}^{b} \rho(x) f(x) \mathrm{d} x \approx \sum_{k=1}^{n} A_{k} f\left(x_{k}\right)$，其中 $x_{i} \neq x_{j}$（当 $i \neq j$ 时）。
- 可以证明，积分公式 $\displaystyle \int_{a}^{b} \rho(x) f(x) \mathrm{d} x \approx \sum_{k=1}^{n} A_{k} f\left(x_{k}\right)$ 至少具有 $n-1$ 次代数精度 $\iff$ 它是插值型的，即带权系数 $A_{k}$ 满足：$\displaystyle A_{k}=\int_{a}^{b} \rho(x) l_{k}(x) \mathrm{d} x, \ l_{k}(x)=\prod_{\substack{j=1 \\ j \neq k}}^{n} \dfrac{x-x_{j}}{x_{k}-x_{j}}$ 
- *问题*：是否存在积分节点 $\{x_{k}\}$ 和求积系数 $\{A_{k}\}$，使 $\displaystyle \int_{a}^{b} \rho(x) f(x) \mathrm{d} x \approx \sum_{k=1}^{n} A_{k} f\left(x_{k}\right)$ 具有 $2n-1$ 次代数精度？答案是肯定的。
### 3-7-2 问题的大致思路
- **$n$ 点 Gauss (高斯) 型求积公式**、**Gauss 点**：若形如 $\displaystyle \int_{a}^{b} \rho(x) f(x) \mathrm{d} x \approx \sum_{k=1}^{n} A_{k} f\left(x_{k}\right)$ 的求积公式具有 $2n-1$ 次代数精度，则称它为 **$n$ 点 Gauss (高斯) 型求积公式**，积分节点 $\{x_{k}\}$ 称为 **Gauss 点**  
- *求解思路*：为求得 $\{x_{k}\}$、$\{A_{k}\}$，分别将 $f(x)=x^{i}(i=0,1,2,\cdots, 2n-1)$ 代入 $n$ 点 Gauss 型求积公式并令其精确成立，则得到含有 $2n$ 个方程和 $2n$ 个未知数的代数方程组：$\displaystyle \sum_{k=1}^{n} A_{k} x_{k}^{i} = \int_{a}^{b} \rho(x) x^{i} \mathrm{~d} x,\ i=0,1,2, \cdots, 2n-1\quad (*)$ 
	- *例子*：当 $n = 1$ 时，由 $(*)$ 可得 $\displaystyle A_{1}=\int_{a}^{b} \rho(x) \mathrm{d} x, \ A_{1} x_{1}=\int_{a}^{b} x \rho(x) \mathrm{d} x$，可解得 $\displaystyle A_{1}=\int_{a}^{b} \rho(x) \mathrm{d} x, \ x_{1}=\left[\int_{a}^{b} x \rho(x) \mathrm{d} x\right] \bigg/ \int_{a}^{b} \rho(x) \mathrm{d}x$ 
- **中矩形公式**：$n=1$ 且权函数 $\rho(x)=1$ 的一点 Gauss 型求积公式 $\displaystyle \int_{a}^{b} f(x) \mathrm{d} x \approx(b-a) f\left(\dfrac{a+b}{2}\right)$，它就是**中矩形公式** 
	- 中矩形公式具有 $1$ 次的代数精度。
- 对一般的 $n$，由于 $(*)$ 是非线性的，求解比较困难，所以另辟寻找 $\{x_{k}\}$，$\{A_{k}\}$ 的途径。
	- 由前面讨论知道，$n$ 点 Gauss 型求积公式必定是插值型的，因此只要找到了 Gauss 点 $\{x_{k}\}$，求积系数 $\{A_{k}\}$ 就可按 $\displaystyle A_{k}=\int_{a}^{b} \rho(x) l_{k}(x) \mathrm{d} x, \ l_{k}(x)=\prod_{\substack{j=1 \\ j \neq k}}^{n} \dfrac{x-x_{j}}{x_{k}-x_{j}}$ 算得。
	- 下面从研究 Gauss 点的基本特性入手来解决 Gauss 公式的构造问题。
### 3-7-3 Gauss 点的基本特性
- **定理**：互异节点 $x_{k}\ (k=1,2,\cdots,n)$ 是 $n$ 点 Gauss 求积公式的 Gauss 点$\iff$ $\omega_{n}(x)=\prod\limits_{k=1}^{n}(x-x_{k})$ 与任何次数 $\le n-1$ 的多项式关于权函数 $\rho(x)$ 正交，即成立 $\displaystyle \int_{a}^{b} \rho(x) \omega_{n}(x) \cdot x^{j} \, dx = 0, \ j=0,1,2,\cdots,n-1$ 
	- *证明过程* 
		**必要性** 
		由于 $n$ 点 Gauss 求积公式具有 $2n-1$ 次代数精度，所以对次数 $\le 2n-1$ 的多项式 $\omega_{n}(x)\cdot x^{j},\ j=0,1,\cdots,n-1$ 精确成立，即 $\displaystyle \int_{a}^{b} \rho(x) \omega_{n}(x) x^{j} \, dx = \sum_{k=1}^{n} A_{k} \omega_{n}(x_{k}) x_{k}^{j}$ 
		注意到 $\omega_{n}(x_{k}) = 0\ (k=1,2,\cdots,n)$，因而 $\displaystyle \int_{a}^{b} \rho(x) \omega_{n}(x) \cdot x^{j} \, dx = 0, \ j=0,1,2,\cdots,n-1$ 成立。
		必要性证毕！
		**充分性** 
		以 $x_{k} (k=1,2,\cdots,n)$ 为求积节点，构造插值型求积公式 $\displaystyle \int_{a}^{b} \rho(x) f(x) \, dx \approx \sum_{k=1}^{n} A_{k} f(x_{k}) \quad (*)$ 
		对任何次数 $\le 2n-1$ 的多项式 $f(x)$，以 $\omega_{n}(x)$ 除 $f(x)$，商和余分别记为 $p(x), q(x)$ 
		于是 $f(x) = \omega_{n}(x) p(x) + q(x)$，$f\left(x_{k}\right)=\omega_{n}\left(x_{k}\right) p \left( x_{k} \right) + q\left( x_{k} \right) = q \left(x_{k}\right)$，其中 $p(x), q(x)$ 的次数 $\leqslant n-1$ 
		于是  $\displaystyle \int_{a}^{b} \rho(x) f(x) \mathrm{d} x=\int_{a}^{b} \rho(x) \omega_{n}(x) p(x) \mathrm{d} x+\int_{a}^{b} \rho(x) q(x) \mathrm{d} x$ 
		由假设，上式右边第一项为 $0$，第二项应用 $(*)$ 并注意 $(*)$ 至少具有 $n-1$ 次代数精度，于是有 $\displaystyle \int_{a}^{b} \rho(x) f(x) \mathrm{d} x=\int_{a}^{b} \rho(x) q(x) \mathrm{d} x=\sum_{k=1}^{n} A_{k} q\left(x_{k}\right)=\sum_{k=1}^{n} A_{k} f\left(x_{k}\right)$ 
		这表明 $(*)$ 具有 $2n-1$ 次代数精度，从而 $x_{k}\ \left(k=1,2,\cdots,n\right)$ 是 $n$ 点 Gauss 求积公式的 Gauss 点。
		充分性证毕！
- *一些关于正交多项式的结论*：
	1. $[a,b]$ 上关于权函数 $\rho(x)$ 的正交多项式系 $\left\{\varphi_{m}\left(x\right)\right\}$ 是存在的，而且 $\varphi_{m}\left(x\right)$ 的次数恰为 $m$，在 $(a,b)$ 内恰有 $m$ 个互异的零点，并与任何次数 $\leqslant m-1$ 的多项式 $q(x)$ 正交，即 $\displaystyle\int_{a}^{b} \rho(x) \varphi_{m}\left(x\right) q\left(x\right) \mathrm{d} x=0$ 
	2. 若 $\{ g_{m}(x) \}$ 是 $[a,b]$ 上关于权函数 $\rho(x)$ 的另一个正交多项式系，则 $g_{m}(x)=c_{m}\varphi_{m}(x)$，$c_{m}$ 为常数，$m=0,1,2,\cdots$。
- **定理**：对任何正整数 $n$，$n$ 点 Gauss 求积公式是存在的，其 Gauss 点就是求积区间上关于权函数的正交多项式系 $\left\{\varphi_{m}(x)\right\}$ 中 $\varphi_{n}(x)$ 的零点
	- *证明过程* 
		记 $x_{1},x_{2},\cdots,x_{n}$ 为 $\varphi_{n}(x)$ 的 $n$ 个互异零点，$\omega_{n}(x)=\prod\limits_{k=1}^{n}(x-x_{k})$，则 $\varphi_{n}(x)=a_{n}\omega_{n}(x)$，其中常数 $a_{n}$ 为 $\varphi_{n}(x)$ 的首项（$x^{n}$ 的项）的系数。
		于是，对任何次数 $\le n-1$ 的多项式 $q(x)$，有 $\displaystyle\int_{a}^{b}\rho(x)\omega_{n}(x)q(x) \mathrm dx=a_{n}^{-1}\int_{a}^{b}\rho(x)\varphi_{n}(x)q(x)\mathrm dx=0$，由上面定理可知，$x_{1},x_{2},\cdots,x_{n}$ 为 $n$ 点 Gauss 求积公式的 Gauss 点。
		反之，若求积点 $x_{1},x_{2},\cdots,x_{n}$ 是 $n$ 点 Gauss 求积公式的 Gauss 点，则由上面定理可知，$\displaystyle\int_{a}^{b}\rho(x)\omega_{n}(x)q(x) \mathrm dx=0$ 对任何次数 $\le n-1$ 的多项式成立
		从而 $\displaystyle \left(\omega_{n},\varphi_{k}\right)=\int_{a}^{b}\rho(x)\omega_{n}(x)\varphi_{k}(x)dx=0,\ 0\le k\le n-1$ 
		注意到 $\omega_{n}(x)$ 可由 $\varphi_{k}(x)\ (k=0,1,2,\cdots,n)$ 线性表出：$\omega_{n}(x) = \sum\limits_{j=0}^{n} \alpha_{j} \varphi_{j}(x)$ 
		于是 $\left(\omega_{n}, \varphi_{k}\right)=\sum\limits_{j=0}^{n} \alpha_{j}\left(\varphi_{j}, \varphi_{k}\right)=\alpha_{k}\left(\varphi_{k}, \varphi_{k}\right)$ 
		从而 $\alpha_{n}=\dfrac{\left(\omega_{n}, \varphi_{n}\right)}{\left(\varphi_{n}, \varphi_{n} \right)}, \ \alpha_{k}=0, \ 0 \leqslant k \leqslant n-1, \ \omega_{n}(x)=\alpha_{n} \varphi_{n}(x)$ 
		可见 $x_{1}, x_{2}, \cdots, x_{n}$ 就是 $\varphi_{n}(x)$ 的 $n$ 个互异零点，定理证毕！
### 3-7-4 Gauss 型求积公式的余项和稳定性
- *符号规定*：记 $E_{n}[f]$ 为 $n$ 点 Gauss 型求积公式的余项，即 $\displaystyle E_{n}[f]=\int_{a}^{b} \rho(x) f(x) \mathrm{d}x - \sum\limits_{k=1}^{n} A_{k} f\left( x_{k} \right)$，其中 $x_{k}, A_{k},\ (k=1,2,\cdots,n)$ 为 Gauss 点和求积系数。再记 $\omega_{n}(x)=\prod\limits_{k=1}^{n}(x-x_{k})$ 
- **定理**：若求积函数 $f(x)$ 在 $[a, b]$ 上有 $2n$ 阶连续导数，则 $E_{n}[f] = \dfrac{ f^{(2n)}(\xi) }{ (2n)! } \left( \omega_{n}, \omega_{n} \right)$，其中 $\xi \in (a, b)$，$\displaystyle \left( \omega_{n}, \omega_{n} \right) = \int_{a}^{b} \rho(x) \, \omega_{n}^{2}(x) \, \mathrm{d} x$ 
	- *证明过程* 
		构造 $2n-1$ 次 Hermite 插值多项式 $h(x)$，满足 $h(x_{i}) = f(x_{i}),\ h^{\prime}(x_{i}) = f^{\prime}(x_{i}),\ i = 1, 2, \cdots, n$ 
		由 2-3 可以验证，$h(x)$ 可表示成 $h(x) = \sum\limits_{i=1}^{n} l_{i}^{2}(x) \left( \alpha_{i} x + \beta_{i} \right) f(x_{i}) + \sum\limits_{i=1}^{n} l_{i}^{2}(x) \left( x - x_{i} \right) f^{\prime}(x_{i})$，其中 $\alpha_{i} = -2 l_{i}^{\prime}(x_{i}),\ \beta_{i} = 1 - \alpha_{i} x_{i},\ i = 1, 2, \cdots, n$，$l_{i}(x)$ 为关于 $x_{1}, x_{2}, \cdots, x_{n}$ 的 Lagrange 插值基函数。
		记 $r(x) = f(x) - h(x)$ 
		由第 2 章 Hermite 插值多项式余项的结果，可得 $r(x) = \dfrac{ f^{(2n)}(\tilde{\xi}) }{ (2n)! } \, \omega_{n}^{2}(x),\ a < \tilde{\xi} < b$ 
		于是由积分中值定理知 $\displaystyle\int_{a}^{b} \rho(x) \, r(x) \, \mathrm{d} x = \dfrac{1}{ (2n)! } \displaystyle\int_{a}^{b} \rho(x) \, f^{(2n)}(\tilde{\xi}) \cdot \omega_{n}^{2}(x) \, \mathrm{d} x = \dfrac{ f^{(2n)}(\tilde{\xi}) }{ (2n)! } \left( \omega_{n}, \omega_{n} \right)$ 
		注意到 $h(x)$ 为 $2n-1$ 次多项式，所以
		$$
		\begin{aligned}
		\int_{a}^{b} \rho(x) r(x) \mathrm{d} x &= \displaystyle\int_{a}^{b} \rho(x)  f(x) \mathrm{d} x - \displaystyle\int_{a}^{b} \rho(x) h(x) \mathrm{d} x \\
		&= \int_{a}^{b} \rho(x) f(x) \mathrm{d} x - \sum\limits_{k=1}^{n} A_{k}h\left( x_{k} \right) \\
		&= \int_{a}^{b} \rho(x)f(x) \mathrm{d} x - \sum\limits_{k=1}^{n} A_{k} f\left( x_{k} \right) = E_{n}[f]
		\end{aligned}
		$$
		证毕！
- 对于 Gauss 型求积公式中的求积系数 $A_{k}$，有以下定理。
- **定理**：
-
